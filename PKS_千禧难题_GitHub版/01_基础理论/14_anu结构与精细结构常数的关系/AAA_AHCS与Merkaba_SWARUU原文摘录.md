## 0. 一句话结论

原文里**确实有一套叫 AHCS 的机器**，也确实说它能**跨时间线把「已经存在的结果」取回来**（连「藏起来的手表」这个比喻都有）。
但**没有任何一句**说这台机器的内核是金字塔形，也**没有一句**说超导来自金字塔形状。
「双金字塔」在原文里指的是**两件别的东西**：①石英存储单元里被粒子加速器写出来的 merkaba 微结构；②人本身就是一个能量环面（＝两个互锁的金字塔）。
本页画的那个双锥，是**把「4 对行星的位置」投影成 merkaba 的几何对应**——形状对上了，**功能没对上**。这一步必须标成立论。

## 6. 几何层 · 本页画的那个双金字塔（全部可复算）

构造（页面 §9.2 与 HUD 同源，运行时算）：

| 量 | 闭式 | 默认值（4 行星 / 2 层 / 层距 1.90） |
|---|---|---|
| 4 对 | 2 层 × 4 行星 | 4 对 |
| 底面四角与行星方位偏差 | — | **0.000°**（N=4 时行星就在 0/90/180/270） |
| 轨道半径 d_orb | d_orb = R_s + R_p | 3.683 |
| 底边长 a | a = √2·d_orb | **5.209** |
| 上下底距 | = 层间距 | 1.900 |
| 电极半间距 e | 滑条 | 0.55（电极间距 2e = 1.10） |
| 锥高 h | h = 层距/2 − e | **0.400** |
| 侧棱 ℓ | ℓ = √(d_orb² + h²) | 3.705 |
| 顶角（相邻两侧棱） | 2·asin((a/2)/ℓ) | **89.33°** |
| 扁度 h/a | — | **0.077（很扁）** |
| 面数 | 2 × 4 | **8 个三角面** |

**两条从数里读出来的结论：**

1. **正方双锥与八面体同构**（6 顶点 / 8 面 / 12 棱）——8 个行星本身就是 8 个八面体，
   它们围出来的「双锥」正好是彼此的**对偶**。这是这一层唯一「漂亮且不牵强」的地方。
2. 🔴 **「相握」与「立体金字塔」互相拉扯**：锥高 h = 层距/2 − e。
   想让金字塔看起来立体，必须加大层距；层距一大，两层行星就**握不上**（HUD「咬合深度」变负）。
   所以本页默认参数下它是一个**极扁的双锥**（h/a = 0.077），不是照片里那种瘦高金字塔——
   **这不是画错了，是这套机构本身给不出瘦高形状**。

## 8. 如果真想做成一次可验证的实验（缺什么，能替什么）

| 环节 | 原文给的 | 地球上现在能替的 |
|---|---|---|
| 取数 | 粒子爆发读石英里的 merkaba 存储 | **没有**：要常温超导 + 非周期表合金，原文自认地球做不到 |
| 搜索空间 | 跳时间线、同时问所有「房间」 | 没有：等价手段是概率搜索 / 穷举，复杂度不是 0 |
| 地址 | "the address is the data" | **有**：最后一次见到的时间地点 + 照片 + 材质描述 |
| 验收 | — | 🔴 唯一硬判据：**它必须先说出一个你还没告诉它的具体位置，而东西真的在那儿**。只说「在某个平行版本里没丢」＝零信息 |

**一句话**：「去平行时空找钥匙」的原文内核是「**从概率场里取一个已经存在的结果**」，不是「穿越」；
它能被检验的形式是**说出一个你不知道的具体坐标**，而不是给你一段量子玄谈。
