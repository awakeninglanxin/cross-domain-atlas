§1 · 这个环面到底怎么画的 参数化与真实比例

环面（torus）的标准参数化是 x = (R + r·cos v)·cos u、y = (R + r·cos v)·sin u、z = r·sin v， 其中 u 是环向角（绕大圈）、v 是极向角（绕管子截面）。 Reed 图里的每一条关系都能落到这两个半径上：

大半径
R = R_tbw = c/ω_p = —
管半径
r = R_c = ħ/(m_e c) = —
比值
r/R = R_c/R_tbw = —（= α）
数值层 · 一个图上没写、但很关键的结果 因为 ω_p = α·ω_c 且 R_c = c/ω_c，所以 R_tbw = c/ω_p = c/(α·ω_c) = R_c/α = —， 而 R_c/α 正是玻尔半径 a₀（差 —，纯舍入）。 也就是说：这个「电子环面」的大半径不是别的，就是玻尔半径。 这句话本身是真的，但它同时说明 —— α 在这个模型里是半径比的另一种写法，不是被推出来的。

还有一个老实说的问题：按 α 画，这个环面细到看不见。 管半径只占大半径的 —，管径只有外径的 —。 下面画布里给出两个档：真实比例（就是这个数）与示意 1.0（管子粗到贴着轴心、中心孔闭合的那个极限， 比真实值粗 — 倍）。原图显然是示意画法，不是按 α 的比例画的 —— 这不是错， 但读者容易把"图上看到的粗细"误当成模型的一部分。

数值层 · 为什么 r/R 的上限就是 1 参数化里管的中心线到轴的距离是 R，管自己的半径是 r； 内侧壁到轴的距离是 R − r。r/R = 1 时这个距离归零 —— 中心孔正好闭合，内圈退化成轴心上的一点（horn torus）。再往上 R − r < 0， 管子自己穿过轴心，环面变成 spindle torus（两半互相插进去）， 已经不是图里那种中间有孔的圆环了。所以 1 不是随手挑的上限，是几何能画成"环"的上限。
一句话 环面模型的可视化很有说服力，恰恰因为它把 α 画成了肉眼能看见的粗细； 按真实比例画出来，管径只有大半径的 1.45% —— 这也是它难以被实验直接检验的原因（见 §4）。

§4 · 一个不能回避的问题：如果环面是实空间的，它有多大 这条比"能不能凑上 α"更硬

Reed 模型把 R_tbw = c/ω_p 取作R_c/α，数值 —， 也就是玻尔半径的量级。这在数学上没问题，但它给电子安了一个 10⁻¹¹ m 量级的实空间结构。

实验上，e⁺e⁻ 对撞给电子"有限大小"的上限是 ~10⁻¹⁸ m （PDG 对 R_e < 10⁻¹⁸ m 的量级约束），比 a₀ 小 — 倍。 也就是说：若把环面读成电子的实空间形状，它已经被散射实验排除了七个数量级。

于是只有两种读法，必须选一个：

  1. 读法 A（实空间结构）：环面就是电子的形状，半径 ~10⁻¹¹ m。→ 与实验矛盾。
  2. 读法 B（波函数 / 相空间的几何）：环面不是电子的物理轮廓，而是它的波函数在某个参数空间里的拓扑。 → 不被散射限制，但那样它就不再解释 α 的"大小"，只解释"形状"； 而 α 的大小恰恰是这个模型最想解释的东西。
这不是挑刺，是判别标准 任何"把 α 几何化"的模型，都要先回答它几何里的长度是不是可测的物理长度： 是 → 必须过散射上限；不是 → 就退回数学改写。蛋形模型属于后者（纯曲率比，没有尺寸）， 所以它躲过了这一关，代价是它也就没有物理内容。环面模型属于前者，所以它撞上了这一关。

§5 · 这个模型能被什么检验 三条，按可操作性排

  1. 绕数能不能不调参给出 α。这类模型的唯一"硬"自由度是整数对 (m, n)。 本页把 m、n 都做成了滑块：若存在某一对整数使 f(m,n) = α 而不是靠 "先令 ω_p = αω_c"，那才叫预言。现在的页面里，改 m、n 只改图形，不改 α —— 因为这正是模型的现状。
  2. 进动能量是可以查的。ω_p = α·ω_c ⇒ ħω_p = α·m_e c² = —。这是一个"α 倍静止能量"的量子，落在 X 射线能区。 若真有这样一支进动模，它应当以谱线形式出现；没有对应的观测，这个"进动"就只是坐标选择。
  3. 尺寸判据（§4）。若模型坚持实空间环面，那它与 R_e < 10⁻¹⁸ m 直接冲突； 若退到相空间，则必须放弃"解释 α 的大小"。两条路只能选一条，不能两边都要。

§6 · 本页结论 不替任何一方圆场

  1. 环面图像在几何上自洽，而且比蛋形"更像物理"。它有流动、有自旋、有进动、有绕数， 两个半径（R_c 与 a₀）都是可测的 —— 这三点是蛋形模型没有的。
  2. 但 α 在这张图里是输入，不是输出。ω_p = α·ω_c 与 R_tbw = c/ω_p 把 α 写进了定义，于是后面所有"α = ⋯"都是同一个式子的换写。本页复算出来的 5 条成立项， 全部是定义或恒等式，没有一条把 α 算出来。
  3. 它还多背了一个包袱：尺寸。R = a₀ 意味着 10⁻¹¹ m 的实空间结构，与散射上限差 7 个数量级。 要绕开，就只能承认这是波函数几何 —— 那就等于承认它不解释 α 的大小。
  4. 和蛋形模型的关系：不是"谁对谁错"，是两种不同的失败方式。 蛋形把一个可调参数调到 α（解存在但零信息量）；环面把 α 塞进定义再拿出来用（恒等式）。 判据是同一条：不调参能不能命中，命中后能不能再预测一个独立的量。
留给老师的一句话 这张图的可贵之处不在 α，而在它把"电荷"画成了环向流、把"自旋"画成了极向流—— 这是可以被"绕数 / 拓扑"接住的语言。若要把这条线做实，最短的一步是： 找到一对整数 (m,n)，让某个纯几何量不调参地等于 α（本页滑块就是为此留的）。 在那之前，它是一张很好的示图，不是一次推导。

§7 · 1680 匝：把 anu 的一条 whorl「展开成环」 Phillips 图 4.9 的几何还原

原文层 · Phillips《here》p.71 §4.4「The UPA as superstring」+ Figure 4.9 原文：“A whorl is a helical coil that winds 1680 times around the surface of a torus (fig. 4.9).” ——一条 whorl = 一条绕 1680 匝的螺旋线，盘在一个环的表面上。 紧接着一句：每一匝（叫「1 阶螺旋丝」）本身又是 7 个更小的圈（2 阶）， 再每个又 7 个（3 阶）……共七级，一级比一级细。图上那张 Figure 4.9 画的就是这个环。

7.1　一个不用查表就能确认的等式：(1, 1680) 纽结 ≡ whorl

本页主台上那条绿线是环面纽结 (m, n)，参数化 x = (R + r·cos(nu))·cos u、y = (R + r·cos(nu))·sin u、z = r·sin(nu)。 把 m = 1, n = 1680 代进去，它的几何是：u 绕大圈走 1 周的同时，v 在管截面上转 1680 圈 —— 这正是「一条绕了 1680 匝的弹簧，被弯成一个环」。
所以 Phillips 的 whorl 不需要另建模型，它就是本页主台的 (m,n) = (1, 1680)。 这也是把 n 滑块上限从 8 抬到 1680 的唯一理由 —— 不抬到 1680，这个页面画不到他图里那条线。

数值层 · 一句话说清「为什么图 4.9 一定是示意的」 1680 匝要挤在一个环上，每匝分到多少像素是可以现算的（见右下读数）： 在本页这个环上（画布宽 — px），每匝只分到 — px。 人的眼睛分辨两条相邻线需要 ≳2 px ⇒ 按真实 1680 匝画，画出来不是「一圈一圈」，是一条连续的带。 所以 Phillips 图 4.9 上那些能一个一个数清的小圈，必然是采样示意（他画的是约一百多个）， 不是 1:1 的 1680。这不是他的错 —— 换谁画都一样。

7.2　这条曲线上的三个数

  1. 1680 = 8!/24 = 7!/3。它是 1×2×3×4×5×6×7/3，也是 7 的阶乘除 3。 本项目早前已记过这一条（1680 页 §1）；它同时是「1 阶圈数」和这条纽结的 n，是同一个 1680。
  2. 1680 与七级嵌套是两件事。1680 只数「1 阶」的圈；再往里每一级都是上一级一匝里的 7 个圈。 若真的按每级 ×7 连续外推六级，第 7 阶的圈数是 — —— 这是外推，不是原文给出的数字， 原文只说到「七级，一级比一级细」。
  3. 它的「匝」不是绕轴，是绕丝。每一匝的平面垂直于前一级丝在该点的走向（原文原话）， 所以这七个层级不是同心套娃，是一级缠着一级 —— 这正是本页参数化里 v 方向所做的事。

7.3　老师的读法：R₀ : R_c = 弹簧直径 : 环中心线径 —— 逐条核验

老师提出的对应是：上面这张图画的那条 whorl 曲线，就是 anu 展开成的那个环的中心线； 而 R₀、R_c 分别是弹簧（1680 匝小圈）的直径与环中心线的直径。 这条读法能一步落到几何上，所以它可以被算死，不需要争论"像不像"。下面全部现场算。

量值算式 / 含义
判定 · 结构对，数量不对 —

换句话说，这不是"差一点"，是差一个整数因子： 1680 匝要排在一圈上，每匝能分到的长度是 2πR/1680； 而弹簧直径若取 2αR，它就比这个间隔大 — 倍。 圈与圈不是"相扣"，是同一段被绕了四遍 —— 画出来不是弹簧，是一团缠住的线。

数值层 · 三个数只要给两个，第三个就被锁死 N · 2a ≤ 2πR（不重叠的必要条件）⇔ α⁻¹ ≥ N/π。
  • 取 N = 1680 ⇒ 要求 α⁻¹ ≥ —，而真值是 137.036 ⇒ 差 — 倍。
  • 取 α⁻¹ = 137.036 ⇒ 最多只能排 — 匝，而 anu 是 1680 匝 ⇒ 差 3.90 倍。
  • 两者不可能同时成立 —— 这条读法在几何上被否掉，不是被物理否掉的。

但要分清两件事，别把整条线一起扔了：错的是"a/R = α"，不是"whorl = anu 展开成环"。 前者是一个数值猜测；后者是本页 §7.1 已经验到 10⁻¹³ 的几何等式（(1,1680) 纽结 ≡ whorl）。 把 a/R 换成几何允许的值（— 以内），这条曲线照样成立，只是那时它不再给出 α。

那 α 还剩什么位置？ α 在这条线里只有两个可能的落点，二者都不是被推出来的： ① 比值 a/R（本页判定：与 1680 匝冲突，差 3.90 倍）； ② 这个环的绝对半径与下一个尺度（a₀）之比 —— 但 a₀ ≡ R_c/α 本来就是定义，命中率 100%，零信息。 所以 α 在这条线上没有被解释，只是被搬了一次家。
口径 · 这条线在本页成立的边界 几何成立：1680 匝螺旋盘成环，与 (1,1680) 环面纽结是同一个集合，可以逐点验算（本页读数表给了偏差）。 不成立的部分：这条曲线不解释 α，也不解释为什么是 1680 而不是 1679 —— 1680 在这里是输入（Phillips 数出来的），不是输出。要它变成输出，得有一个不调参的机制 把 1680 逼出来（例如某个 7 进制/阶乘的计数论据），那一步本页没有，也不能假装有。
