结构参数

D 现在是真的生效（爱心与阶梯共用同一台逐级细分引擎）： 第 1 阶 = 丝绕 1680 匝（1st-order spirillae）；第 2–7 阶 = 每级在上一级的最后一匝上再绕 7 匝。 爱心模式把 D 拖到 7 就会一路画到 7th-order spirillae （该阶 7 匝 × 每匝 7 颗 = 49 颗 koilon 珍珠/丝）。

这一次它真的生效了（此前有三处断点，下拉框完全空转）。三种模式的差别：
· 全环向（默认）= 每一级的缠绕平面都 ⊥ 该处切向 ⇒ 就是文献那根 tightly twisted endless coil（经典超螺旋）；各级缠绕平面互相平行。
· 全轴向 = 每一级的缠绕平面都含切向 ⇒ 第 1 阶从「立体螺旋」变成 平面锯齿，一眼可辨。
· 交替正交 = 奇数级环向、偶数级轴向 ⇒ 相邻两级缠绕平面严格 90° （文献：each finer coil to which its axis lies at right angles）。
⚠️ 第 1 阶在「全环向」与「交替正交」下本来就是同一条骨架 （两者都从 normal 起步）⇒ 差别要到第 2 阶才出现（第 2 阶只有 1/7 大，要放大才看得清）。 这是几何事实，不是没修好 —— HUD 标题里会显示逐级模式链（环=全环向 / 轴=全轴向）， 切换时还有一条提示告诉你到底变了什么。

点一下就把整个 Anu 以中轴为镜翻面（φ → −φ，等价 z → −z）： 半径与高度逐点不变（同一条闭轨道、同一组上下孔，孔处的 C∞ 接头一点都不会坏）， 只有绕向翻过来。于是俯视图里内程（沿直锥下旋那一程）由顺时针变逆时针（再点一次变回去）。
这两种 Anu 都是真实存在的，对应两种磁荷极性 —— 顺时针（俯视）沿直锥下旋 = negative 负磁荷、 逆时针 = positive 正磁荷。 当前极性实时显示在舞台左上角标签里。 中央螺旋（中轴芯）也一起翻，否则「整个 Anu 镜像」只做了一半。

外场（形态 / 锥管）

苹果切片（默认）= 老师红线描的那条轮廓：上半两个圆肩 + 下半椭圆苹果底。 球形态切片 = 端部向内凹陷的球（腰部仍是半径 1），被同一根中轴锥管切出的两个孔之间那段弧 ⇒ 外场边界变成一个「鼓腹 + 上下收口」的环状体，丝在上下孔处向内向球心凹陷、交接到锥面上。 两条切片同参数化（u = 0 上孔、u = 1 下孔、按弧长等距）⇒ 滑块一动就是连续形变。

🔴 这个滑块同时驱动中轴直锥的半锥角（两根滑块会一起动）： 锥高 h = 1 / 外场边界形态值（口沿半径锁死 0.1428 ⇒ tan(半角) = 0.1428 / h）。于是越接近球面，锥角越小、锥越长： 1.00 → 2.950°（锥高 ×1.00，= 原直锥，逐位不变）、 0.50 → 1.475°（×2.00）、0.10 → 0.295°（×10.01）。 这正是老师要的「接近球面时直锥角更小、从底到顶点的高更大」。 下限锁死 0.1（这一项在 h 公式的分母上，取 0 会让锥顶跑到无穷远）。

🔴 这一根与外场边界形态联动、会一起动（呼吸动画时尤其明显）： 当前生效半角 = 参考角（苹果态）× 外场边界形态 —— 苹果态取最大 2.950°、球形态取最小 0.295°。 当前：参考角 2.95° → 生效 2.950°， 锥高 ×1.00。
把这一根滑到最左（0.050°）就是老师要的「接近但不等于直圆柱管」： 口沿半径锁死 0.1428（= 原直锥上底面半径，管径恒定）， 而 apexY = mouthY − mouthR/tan(半角) ⇒ 半角越小，锥顶越快地向下远离 （半角 → 0 时锥顶沉到无穷远），锥壁半径 wallR(y) = (y − apexY)·tan(半角) 随之从「上大下小」变成「上下等径」⇒ 下孔被撑开、外场边界自动趋近球面。

本页实现的核心机制

  1. 先定整体形态，再谈细分（预设 ①）：子午线 = 上半两个圆肩 + 下半椭圆苹果底。 · 上半：绕 (±lobeC, 0) 的圆（lobeC = 0.45）⇒ 两个宽圆肩， 中央自然形成 cusp 凹口； · 下半：四分之一椭圆弧 r = cos φ, y = −bottomHe·sin φ （bottomHe = 1.00，底端切向水平 ⇒ 苹果式圆底）； 接缝处两段切向都铅垂 ⇒ C¹ 连续。 因为它是旋转体的子午线，正视时本身就是外轮廓。 🔴 旧版用经典心形线 r = sin³t，它的两瓣半宽只有最宽的 0.49（天生上窄下宽 ⇒ 像梨）； 按原图 anu直锥红色线.png 逐行量得的半宽分布（近顶处仍有 0.54~0.67）重做成圆肩 + 苹果底。
  2. 一程内、一程外，2.5 + 2.5 = 5 圈： 外程 = 顺着苹果的边界缠绕（半径取子午线本身，贴苹果壳外侧）； 内程 = 顺着绿色直锥缠绕（半径取锥壁 r = (y − apexY)·tan2.95°）—— 于是内程从上孔 0.1364 一路收到下孔 0.0422，真正贴着锥管下行。 两程在上下孔处严格重合（因为孔就是子午线与锥壁的交点）⇒ 曲线自闭合，不需过渡弧； 触底前另有 flipSoft 一段 smoothstep 圆角，让翻转丝滑。
  3. 苹果壳有厚度 ⇒ 外程分居两层（老师 2026-10-07 追加）： 3 粗丝的外缘贴「外壁」（= 子午线本身，半径 0.9857）⇒ 中心线 prof − coilRThick·win； 7 细丝的外缘贴「内壁」（= 外壁内向一个参考壳厚 shellGap = 0.072，半径 0.9137）⇒ 中心线 prof − (shellGap + coilR)·win。 两层中段间隔 = coilRThick + coilR = 0.0600（正好相切堆叠）； 内程则由下拉框决定：默认 both ⇒ 也外移一个弹簧半径、弹簧内缘贴锥外壁 （shell 才是「中心线即在锥壁上」的旧画法）。 win(u) 是两端归零的平滑窗口 ⇒ 两族在上/下孔处收拢重合， 丝仍精确落在孔上（逐点偏差 5.55e-17，闭合 1.67e-16）。 「双丝分离」滑块再以中性面为轴把两族对称拉开（粗 +Δ/2 / 细 −Δ/2）； Δ = 0 时就是上表这个相切状态（原「苹果壳厚」滑块与之重复，已并入本项）。 三档（下拉「弹簧边贴壁方式」）：both （默认）内程也外移一个弹簧半径； shell 只外程贴苹果内/外壁；off 中心线落在壁面上（仅对照）。
  4. 「反向缠绕」已作废 —— 文献说的「反向」其实是翻转 （2026-10-08 老师裁定）：文献里那个词描述的只是「内程下到底 → 翻转 → 走外程回到上孔」 这一件事，不是两根丝对着扭。所以十丝在内外两程一律同向： 下行 φ₀ → φ₀ + 2.5 圈，到底翻转，上行 → φ₀ + 5 圈 ≡ φ₀。 旧版那个「回程段 3 粗反向 / 7 细正向」的复选框已被删除 —— 它正是下面 180° 对望被破坏的根源。
  5. 为什么 2.5 这个半整数是对的：相位取 φ下行=φ₀+2πm·u、φ上行=φ₀+2πm(2−u)（m = 2.5）。 u=1 处严丝合缝接上尖端；u=0 处回到 φ₀+2π·2m = φ₀+2π·5 ≡ φ₀， 要求 2m 为整数 —— 所以每程 2.5 圈、合计 5 圈能闭合，而 2.3 圈就不行。 「一粗一细正视像爱心」也是这 5(1−u) 匝相位差织出来的。
  6. 3 粗 ↔ 7 细 严格 180° 对望（2026-10-08 老师裁定：「只是两族螺旋线绕中轴圆周阵列 180° 旋转的关系」）：10 丝按 36° 均分，粗丝落 0°/36°/72°，其对面 180°/216°/252° 恰是细丝（3 对，偏差 0.00°），且整个 10 丝阵列旋转 180° 后自身不变。
  7. 一个方程管 10 根丝（老师 2026-10-08：「两族的动力学公式是一样的， 为何计算结果不一样？两族就是旋转了 180 度」）： 10 丝共用唯一的相位方程 —— 内程 φ_j(u) = φ_j0 + ω·2π·u、 外程 φ_j(u) = φ_j0 + ω·2π + ρ·ω·2π·(1−u)，其中 ω = turnsPerLeg = 2.5（唯一的动力学参数）、 ρ = +1（外程方向，两族共用），唯一的族间差异是初始相位 φ_j0 = 2π·j/10。粗 / 细的差别只在几何半径 （coilRThick vs coilR、外壁 vs 内壁），不在动力学。
  8. 于是「180° 对望」是直接推论，不是调参调出来的： φ_(j+5)0 − φ_j0 = π ⇒ 第 j+5 根的整条路径 = 第 j 根绕中轴旋转 180° （逐点偏差 < 1e-13）。所以 3 粗（j = 0,1,2）的对面必然是 7 细（j = 5,6,7）。
  9. 底端是环形回转，不是针尖（老师订正：「上端像爱心、下端像苹果」）： 下半段是椭圆弧（椭率 bottomHe = 1.00，底端切向水平 ⇒ 圆润苹果底）， 子午线止于下孔 r = 0.0422 ⇒ 底部是一个有孔的回转环（whorl 在此掉头）。 方案由老师 2026-10-07 从四选一裁决图（预览_Anu形状候选.png）中选定。
  10. 中轴锥管是直锥体：原图 FUNNEL TUBE 放大后可见「口沿是张开的椭圆、两壁向下缓慢收拢」。 沿管壁最小二乘拟合两条边线，得半锥角 2.95°（锥角 5.90°）——是根细长尖锥； 口沿半径取 0.1428（= 管口处的实测径），反解出 apexY = mouthY − mouthR/tan2.95° ≈ −2.078 ⇒ 锥管穿过底尖（−0.976）一直沉到 TORRENT 段，与原图画法一致。 上孔 0.1364（落在凹口内壁上）、下孔 0.0422，都精确落在锥壁上。
  11. 整条轨迹其实是一个「吸引子」（老师问「怎么做成混沌吸引子公式」）： "贴哪一层壳"不必靠 if/else 分段 —— 它可以写成一个 4 维自治系统 （见 Anu七级螺旋_使用与原理.md §2.6 与 _scratch/anu_attractor.js）： ρ̇ = κρ[Rw(y) − ρ]、ẏ = v·tanh(λω)、θ̇ = ω、 ẇ = μ[w − w³ + a(y)]。 w 是"壳选择"变量，a(y) 的倾斜双稳让它在到底 / 到顶时自动翻壳。 数值积分结果：贴锥壁 2.53 圈 + 贴苹果壳 2.43 圈 ≈ 5 圈， 轴向自动停在上下孔（偏差 < 0.007），无人为分段。
  12. 局部永远是弹簧：每根 whorl 的 5 圈宏观路径再作为父曲线，交 AnuGeo.subdivide() 绕 1680 匝 ⇒ 每根丝本身就是一根弹簧； 10 丝合计 16800 匝 1 阶 spirillae。
  13. 两族正交缠绕平面：父丝标架 (T,N,B) 给出 span(N,B)（法向 T）与 span(N,T)（法向 B）， 因 T ⊥ B 二面严格垂直。
  14. 逐阶交替：相邻两阶分别取这两族平面 ⇒ 缠绕平面相差 90°。
  15. 逐级细分：每阶把上一阶的丝替换为 T 匝更细的弹簧， 累计匝数按 ∏T 增长。
  16. 七级阶梯的画法：全量细分需 1680×7⁶ ≈ 2×10⁸ 匝，不可渲染。 故每一级只取上一级最后那一匝作基准 —— 与文献图版 “Piece of Atomic Spiral with 1st, 2nd and 3rd Spirillae” 同一做法， 顶点数恒定，第 7 级仍然看得见。
  17. 半径比是自然涌现的：每匝长度 = √(pitch² + (2πr)²)，代入 r = fill·pitch/2 与下级匝数 T 得 rk+1/rk = √(1+(π·fill)²) / T。 fill = 1（匝刚好相接）时 = 0.471 ≈ 1/2 —— 不用手调，由几何自洽唯一确定。
  18. 最深一级：第 7 阶 spirilla 由 7 个 koilon 泡泡组成 （“串在看不见的线上的珍珠”）。
