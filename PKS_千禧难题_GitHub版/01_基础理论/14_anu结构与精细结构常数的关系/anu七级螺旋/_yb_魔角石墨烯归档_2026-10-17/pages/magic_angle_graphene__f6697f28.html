魔角谱 · 贵金属比 · 分形莫尔

把两层石墨烯的 1.1° 推广成任意层、任意排列 —— 看看哪些数学常数会自己冒出来。

0先说清 θ 是什么角

θ 不是把平面掀起来的倾角，而是面内旋转角：各层始终保持平行（间距 ~0.34 nm），θ 指上下层绕垂直于层面的轴 ẑ 相对转过的角度。像把两张透明胶片平放在桌上，按住中心原地旋转一张。

1统一公式：魔角 = 界面耦合矩阵的谱

在手性极限（关掉 AA 位隧穿 wAA=0）下，N 层交替转角石墨烯的平带条件可以精确求解：把每层看作一个顶点、每个扭转界面看作一条边，得到一张界面耦合图，于是

θ魔 = θTBG × λ ， λ = 界面耦合矩阵的正本征值， θTBG = 1.1°

对最常见的均匀链（N 层、N−1 个等强界面），这张图就是路径图 PN，本征值有闭式解：

λk = 2 cos( kπ / (N+1) ) ,  k = 1, 2, … , ⌊N/2⌋  →  θk = 2θTBG cos( kπ/(N+1) )
这就是 Khalaf 等人 2019 年的结果，也是实验上 3 层 1.56°、4 层 1.78°、5 层 1.95° 的来源。魔角个数 = ⌊N/2⌋ —— 层数越多，超导夹角越多。
关键约束：λ ≤ 2。因为路径图的最大本征值趋于 2，所以均匀链的魔角永远不会超过 2θTBG = 2.2°。这一条决定了下面所有关于"贵金属比"的讨论。

哪些层数能凑出哪些常数

规律很干净：λ = 2cos(kπ/(N+1))，把分数 k/(N+1) 约简成 p/q 后，常数只由 q 决定。所以想要 √3（q=6）、√2（q=4）、1（q=3）、φ（q=5）同时在同一个 N 出现，就要 N+1 同时被 3、4、6 整除 → N+1 = 12，即 N = 11；再把 φ 也拉进来需要 q=5 → N+1 = 60，即 N = 59。

3贵金属比：为什么进不来，又怎么把它请进来

贵金属比（metallic means）定义为 λm = (m + √(m²+4))/2，即矩阵 [[m,1],[1,0]] 的 Perron 根：

黄金比 φ = 1.618 可以直接当 λ（N = 4, 9, 14, 19, 24 …，即 N+1 是 5 的倍数）；√2 = δ银 − 1 也可以（N = 3, 7, 11, 15, 19 …）。但银比 2.414、铜比 3.303 都 > 2，撞上了第 1 节那条天花板，永远不可能成为某个 N 层均匀链的 λ。
出路：让不同界面取不同的耦合强度。贵金属比不再作为"放大倍数 λ"，而是作为两类界面耦合之比 ρ = tA/tB。这时层数序列本身变成一条"字"（word）——A 类界面、B 类界面按某种顺序排列 —— 于是我们得到一条一维准晶链，它的谱就是魔角谱。

物理上怎么实现不同的 t？层间耦合对层间距极其敏感（所以静水压能把魔角推向更大角度）。给不同界面插入不同厚度的 hBN 隔层、或用局部压力/间隔物分别调控，原则上就能独立设定每个界面的 t —— 这样可以在保持同一莫尔周期的前提下实现任意权重。

怎么构造：贵金属比替换序列

要得到自相似的（分形）谱，界面序列不能随便排，而要按贵金属比替换规则生成：

σm : A → AmB ,  B → A

m=1 → 斐波那契字（A→AB），A:B 数量比 → φ；m=2 → 银均字（A→AAB），比 → 1+√2；m=3 → 铜均字（A→AAAB），比 → (3+√13)/2。把耦合设成 tA/tB = λm，就得到一条严格自相似的准晶链。

组与组之间的排列组合确实会改变谱 —— 但它有一个漂亮的对称性：把整个序列倒过来读，谱完全不变（路径图的转置相似）。所以 AAB 与 BAA 同谱，真正不同的排列数是" bracelet（不计反转的项链）"数，不是全排列数。下面的"排列对比"表会算给你看。

5分形嵌套莫尔：莫尔的莫尔

当不同界面有不同转角时，会出现多代莫尔：第 1 代莫尔（周期 L）自己再形成莫尔 → 超莫尔（周期 ~L/θ），再形成 → 超超莫尔。这就是分形六边形嵌套的来源。

L1 = a/θ  →  L2 ≈ L1/θrad  →  L3 ≈ L2/θrad  →  …
AA 区（电子局域） AB/BA 区 各代莫尔原胞（嵌套六边形）

理想化的自相似极限：六边形雪花（Hexaflake）

一个六边形 = 7 个 1/k 缩小的六边形；维数 = log7/log3 ≈ 1.771（k=3）
注意：真实的莫尔层级比例是 1/θrad，θ=1.1° 时约 52 倍，远不是 3 —— 所以真实的嵌套只有 2–3 代能进入视野（这正是螺旋四层石墨烯里 aM ≈ 6 nm、aMM ≈ 0.1 μm、aMMM ≈ 几 μm 的原因）。Hexaflake 是把比例压到 3 后的理想化自相似版本，用来展示层级结构本身。

6螺旋堆叠：天然的多代莫尔发生器

交替堆叠（+θ/−θ/+θ…）所有界面共用一个莫尔周期，只有一代莫尔。而螺旋堆叠（每层都沿同一方向转 +θ）会产生 N−1 个方向彼此错开的莫尔图案，它们互相干涉，天然生成多代结构：

螺旋三层的超莫尔周期 ~0.1 μm、螺旋四层的超超莫尔可达几 μm —— 都被实验观测到。但螺旋体系的魔角不属于上面那套图谱公式（它不满足手性极限分解），数值来自具体计算，本页按文献值列出，不参与实时公式。

7这一切和超导有什么关系

魔角区：半填充 ±2 出现关联绝缘体，两侧冒出超导穹顶

每多一个魔角，就多一个可以用栅压去"对焦"的强关联窗口 —— 这就是多层体系的价值：它不是简单的重复，而是把 1.1° 这一个点，变成了一整族可调的平带条件。

8诚实边界：哪些是文献，哪些是本页外推

✅ 文献确立：
· 手性极限下 N 层交替转角石墨烯的魔角谱 θk = 2θTBGcos(kπ/(N+1))（Khalaf et al. 2019；实验 3/4/5 层 ≈ 1.57°/1.77°/1.95°）。
· 螺旋体系的多代莫尔与超超莫尔（aM / aMM / aMMM）。
· 层间耦合对间距敏感 → 静水压可移动魔角（Yankowitz et al., Science 2019）。

⚠️ 本页外推（思想实验，未经实验验证）：
· 把"界面耦合图"推广到加权路径图 / 准晶字，并声称其本征值给出魔角 —— 这是把已确立的手性极限公式做了推广，物理前提是能独立调控每个界面的耦合且保持共同莫尔周期。真实样品中不同界面转角不同会立刻引入多代莫尔，破坏单周期假设。
· 贵金属比作为"耦合比 ρ"的说法、蝶形谱的具体形状、以及"ρ = λm 时自相似性最强"，都属于这一推广框架内的推论。
· Hexaflake 是纯几何示意，不是任何真实样品的实空间图像。

⚠️ 数值口径：表中为手性极限解析值；真实体系 wAA≠0 且存在晶格弛豫，实测魔角会偏移百分之几到十几。层数超过约 8 层在制备上极不现实，N>8 的表格仅供看数学结构。
