魔角谱 · 贵金属比 · 分形莫尔

把两层石墨烯的 1.1° 推广成任意层、任意排列 —— 看看哪些数学常数会自己冒出来。

0先说清 θ 是什么角

θ 不是把平面掀起来的倾角，而是面内旋转角：各层始终保持平行（间距 ~0.34 nm），θ 指上下层绕垂直于层面的轴 ẑ 相对转过的角度。像把两张透明胶片平放在桌上，按住中心原地旋转一张。

1统一公式：魔角 = 界面耦合矩阵的谱

在手性极限（关掉 AA 位隧穿 wAA=0）下，N 层交替转角石墨烯的平带条件可以精确求解：把每层看作一个顶点、每个扭转界面看作一条边，得到一张界面耦合图，于是

θ魔 = θTBG × λ ， λ = 界面耦合矩阵的正本征值， θTBG = 1.1°

对最常见的均匀链（N 层、N−1 个等强界面），这张图就是路径图 PN，本征值有闭式解：

λk = 2 cos( kπ / (N+1) ) ,  k = 1, 2, … , ⌊N/2⌋  →  θk = 2θTBG cos( kπ/(N+1) )
这就是 Khalaf 等人 2019 年的结果，也是实验上 3 层 1.56°、4 层 1.78°、5 层 1.95° 的来源。魔角个数 = ⌊N/2⌋ —— 层数越多，超导夹角越多。
关键约束：λ ≤ 2。因为路径图的最大本征值趋于 2，所以均匀链的魔角永远不会超过 2θTBG = 2.2°。这一条决定了下面所有关于"贵金属比"的讨论。

哪些层数能凑出哪些常数

规律很干净：λ = 2cos(kπ/(N+1))，把分数 k/(N+1) 约简成 p/q 后，常数只由 q 决定。所以想要 √3（q=6）、√2（q=4）、1（q=3）、φ（q=5）同时在同一个 N 出现，就要 N+1 同时被 3、4、6 整除 → N+1 = 12，即 N = 11；再把 φ 也拉进来需要 q=5 → N+1 = 60，即 N = 59。

3贵金属比：为什么进不来，又怎么把它请进来

贵金属比（metallic means）定义为 λm = (m + √(m²+4))/2，即矩阵 [[m,1],[1,0]] 的 Perron 根：

黄金比 φ = 1.618 可以直接当 λ（N = 4, 9, 14, 19, 24 …，即 N+1 是 5 的倍数）；√2 = δ银 − 1 也可以（N = 3, 7, 11, 15, 19 …）。但银比 2.414、铜比 3.303 都 > 2，撞上了第 1 节那条天花板，永远不可能成为某个 N 层均匀链的 λ。
出路：让不同界面取不同的耦合强度。贵金属比不再作为"放大倍数 λ"，而是作为两类界面耦合之比 ρ = tA/tB。这时层数序列本身变成一条"字"（word）——A 类界面、B 类界面按某种顺序排列 —— 于是我们得到一条一维准晶链，它的谱就是魔角谱。

物理上怎么实现不同的 t？层间耦合对层间距极其敏感（所以静水压能把魔角推向更大角度）。给不同界面插入不同厚度的 hBN 隔层、或用局部压力/间隔物分别调控，原则上就能独立设定每个界面的 t —— 这样可以在保持同一莫尔周期的前提下实现任意权重。

怎么构造：贵金属比替换序列

要得到自相似的（分形）谱，界面序列不能随便排，而要按贵金属比替换规则生成：

σm : A → AmB ,  B → A

m=1 → 斐波那契字（A→AB），A:B 数量比 → φ；m=2 → 银均字（A→AAB），比 → 1+√2；m=3 → 铜均字（A→AAAB），比 → (3+√13)/2。把耦合设成 tA/tB = λm，就得到一条严格自相似的准晶链。

组与组之间的排列组合确实会改变谱 —— 但它有一个漂亮的对称性：把整个序列倒过来读，谱完全不变（路径图的转置相似）。所以 AAB 与 BAA 同谱，真正不同的排列数是" bracelet（不计反转的项链）"数，不是全排列数。下面的"排列对比"表会算给你看。

5无限级莫尔的莫尔：通项公式与三种命运

① 差频递推：莫尔的本质是拍频

两个周期图案叠加，其差频（拍）给出莫尔：若母图案倒格矢长 g、两套互成 α，则莫尔倒格矢 Δg = 2g·sin(α/2)，周期 L = 2π/Δg。把上一层莫尔再当作"母图案"，就得到递推：

gj = 2 gj−1 sin(αj/2)   ⟺   Lj = Lj−1 / [ 2 sin(αj/2) ]

② 通项公式（螺旋堆叠：所有代间夹角都 = θ）

令缩放因子 σ ≡ 2 sin(θ/2)，放大倍数 M ≡ 1/σ，从原子晶格 L₀ = a = 0.246 nm 起算：

Lj = a · Mj = a / [2 sin(θ/2)]j   ·   gj = G · M−j = G·[2 sin(θ/2)]j
这就是你要的通项。实空间是公比为 M 的几何级数，倒空间是公比 σ 的几何衰减 —— 尺度级联（scale cascade），比例恒定。小角下 M ≈ 1/θrad：θ=1.1° → M ≈ 52。

广义版（代间夹角成序列 α1, α2, …，例如不同界面转角不同）：

Lj = a / ∏i=1..j [ 2 sin(αi/2) ]  →   ln Lj = ln a − Σi ln[2 sin(αi/2)]
这个求和式意味着：对数尺度上的层级是"可加"的。每一代贡献一个"尺度增量" −ln[2sin(α_i/2)]，总尺度就是这些增量的累加。这是整套结构最简洁的不变量。

③ 用真实体系验证

螺旋四层 θ=2.3° 的验证尤其干净：L1 = 6.1 nm（文献 aM ≈ 6 nm）、L3 = 3.8 μm（文献 aMMM 达"几 μm"）。螺旋三层 θ=1.8° 的 L2 算出 0.25 μm、文献报 ~0.1 μm —— 同量级，差异来自域尺寸 vs 完整周期的定义差别与晶格弛豫。

④ 无限级？三种命运

(a) 数学上发散：Lj = a·Mj，M>1 时 j→∞ 就 L→∞，平移周期性消失。
(b) 物理上截止：任何真实器件都有尺寸 D。能装下的最高级数

jmax = ⌊ logM(D/a) ⌋ = ⌊ ln(D/a) / ln M ⌋

(c) 守恒律（最要紧的一条）：由 Mj_max ≈ D/a 立刻得到 ——

放大倍数 M 与级数 jmax 互为反比，乘积被样品跨度锁死。你想让莫尔"大"（θ 小 → M 大），级数就只能少；想让级数多（M→1，θ→60°），每一代就几乎一样大、不再是莫尔。这就是实验上永远只看到 2–3 代的根本原因 —— 不是技术限制，是几何必然。
量化：真正称得上"莫尔"至少要 L1 > 10a（即 M > 10，θ < 5.7°）。代入 D = 10 μm：jmax < 4.3。想突破 4 级，L1 已经缩到 2.8 nm 以下，退化成原子尺度调制，不再是莫尔。

⑦ 之二：代数最多能堆多少代 —— 三条硬边界

先把"代"说清：第 j 代的莫尔周期 Lj = L1 · Rj−1（R = 代间比）。 想"多演示几代"只有两条路：把 R 压小（相邻代长得近），或把跨度拉大（L1 更小 / LG 更大）。 每条路都会撞墙，而且墙不止一堵 —— 分别来自像素、浮点、样品、算力。

同屏上限　n ≤ 1 + log(w / 20) / log R
双精度上限　n ≤ 1 + 49·ln2 / ln R
样品上限　n ≤ log(D / a) / log R
w = ⑦ 画布实际像素宽（现 430 px；8 px/周期 = 人眼分辨下限，2.5 个周期 = 能看出"这是个周期"的下限）；双精度的 249 是留了 1/8 周期 ulp 余量的保守值；样品上限按 D = 10 μm、a = 0.246 nm 算。
注意：R < 10 的几行只是数学示意 —— 真实体系中 R = M = 1/[2sin(θ/2)]，R < 10 对应 θ > 5.7°， 那时 L1 已经接近晶格常数，严格说不叫莫尔；表里保留它们只是为了看清"R 越小、同屏代数越多"这条趋势。 真正称得上莫尔的区间是 R ≥ 10（θ ≤ 5.7°），也就是表里唯一那行 R = 52.1。
直接回答"数学上最多能演示多少代"：
① 同屏（一张图里同时看到）：R = 2.5、画布 430 px 时 4 代封顶 —— 这不是参数没放开，是 Rn−1 ≤ w/20 直接算出来的（L1 恰好 8 px、L4 恰好 2.5 个周期）。 想同屏 8 代，R 必须压到 ≤ 1.5，而那时相邻代只差 50%，图案已经糊成"同一张网"，层级看不出来（能画≠能分辨）。
② 逐代对焦（不同屏，一代一代看）：只受浮点与样品限制。R = 2.5 时约 38 代（双精度）／11 代（10 μm 样品）； 真实 R = 52 时只有 10 代（浮点）／2 代（样品）—— 这就是实验上永远只看到 2–3 代的原因。
③ 纯数学（无限精度、只要解析式）：没有上限。你可以把 Lj 写到任意 j，公式照样成立； 但"演示"必须有可观测量 —— 一旦要画出来就退回①②，一旦要造出来就退回样品墙。
所以"最多多少代"不是物理问题，而是你要的是同屏还是逐代。本页滑块放到 36 代，就是按 R=2.5 的双精度顶（38）向下取整。

④ 再往上（为什么不是"无限"）：本页所有代共享同一个坐标系（一个视场），所以 L1 与 LG 必须同时落在 double 的 53 位有效数字里 —— 这才是 249 天花板的真正来源。 若改成"每代独立定标"（每次重画时重新算视场，坐标不跨代），这堵墙就没了，只剩 double 的数值范围 1.8×10308： 从 12.8 nm 起、R=2.5，约 780 代才会溢出。再往上只剩"解析式"这一种存在方式 —— 那已经不是"演示"，是"写出公式"。
一句话总结：同屏 4 代（像素）、单坐标系 38 代（double 尾数）、每代独立定标 ≈780 代（double 指数）、纯解析式 ∞。
第三条墙（工程）：其实不是墙 —— 这页的算法只算"落在分辨窗口内"的那几代。 每像素只对 Lj 落在 [8px, 视场/2] 窗口内的代做 cos； 其余代权重为 0，直接 continue。所以复杂度是 O(可见代数)，不是 O(G)： 实测 G = 4 时 82 ms、G = 36 时 33 ms（同一视场），代数加到 36 反而没有变慢。 真正的成本只随"同屏代数"涨（R=1.5 塞 8 代时约 2 倍）。
顺带一条诚实说明：代数超过 jmax = logM(D/a) 的部分，物理上不存在（图上标红）。 把「忽略样品尺寸 D」勾上只是让它们继续参与绘图，不会让它们变成真的。

⑧ 理想化的自相似极限：六边形雪花（Hexaflake）

递归规则：一个六边形 = 7 个缩小 1/k 的六边形（中心 1 个 + 六个角各 1 个）。第 d 层有 7d 个、最小半径 R/kd。数学上没有上限 —— 深度滑块已放到 14（714 ≈ 6.8×1011 个）；真正的限制是屏幕分辨率，不是数学。
诚实结论：真实的莫尔嵌套不是分形。理由很硬 —— 每一级莫尔是空间填充的：面积放大 M² 倍、子原胞数也是 M² 个，于是盒维数 d = ln(M²)/ln(M) = 2。整数维数，没有"空洞"。Hexaflake 之所以维数 1.771 < 2，是因为它人为挖掉了 2/9 的面积。

真正的分形性不在这里，而在能谱：第 4 节的蝶形图、以及平带在磁场下的 Hofstadter 谱，才是康托集式的分形对象。实空间的莫尔层级是"尺度级联"，不是分形。

7这一切和超导有什么关系

魔角区：半填充 ±2 出现关联绝缘体，两侧冒出超导穹顶

每多一个魔角，就多一个可以用栅压去"对焦"的强关联窗口 —— 这就是多层体系的价值：它不是简单的重复，而是把 1.1° 这一个点，变成了一整族可调的平带条件。

8导电性与超导的演化：层数加到 ∞ 会怎样

答案是不是超导了 —— 趋近石墨意味着趋近平庸的半金属。但过程不是简单衰减，而是三股力量在拉扯。

机制 ①：并联短路（最直接的导电性变化）

N > 2 时，平带之外共存 N−2 条色散狄拉克带。实验明确观察到"远离电中性时，总有来自共存色散带的残余电导"。就算平带那部分超导了，色散带仍并联导电，总电阻不为零 —— 这就是为什么多层体系必须加位移场先在色散带里打开能隙，才看得清平带的相变。

机制 ②：屏蔽增强（削弱配对）

色散带越多，可屏蔽库仑相互作用的电子态越多 → 有效 U 被压低 → U/W 变小 → 强关联减弱。2026 年曼彻斯特大学（PRX）做了决定性实验：在魔角石墨烯上方 0.3 nm 处放一个可调扭转双层作屏蔽层，开启屏蔽后超导被完全抑制，Tc 下降一个数量级以上，关联绝缘态同时消失 —— 而声子机制在屏蔽下应该基本不变或略增，所以这直接排除了常规电声配对。

机制 ③：平带权重稀释（本页算出来的）

实验只能调一个 θ，所以 N 层交替石墨烯里只有 1 个子系统落在魔角，其余全是色散带（N=2 时例外，唯一子系统就是它自己）：

三机制随层数的演化

一个反直觉的转折：层数增加并非全是坏事。Zhang 等（Science 2022）发现超导穹顶随层数变宽，五层体系超导延伸到 ν ≈ 5，超过每原胞 4 个电子的平带容量 —— 说明色散带参与了配对，而不只是稀释。所以真实物理是「稀释+屏蔽」与「色散带参与」的竞争。2026 年 Nat. Commun. 对交替四层（ATQG）的工作进一步把两者解耦，量化了电场依赖的 Tc 与相干长度，发现平带费米速度趋于零、超流刚度很大。

N → ∞ 的极限

Khalaf 原文的漂亮结论：N→∞ 时 θ ≲ 2° 存在连续统的魔角。本页算出来 —— N=1000 时有 500 个魔角，最大相邻间距仅 0.007°，θmax → 2θTBG = 2.2°。后果很微妙：

任意小角都"几乎"是魔角（对角度不再挑剔，稳健性↑），但每个平带的权重 → 0，淹没在越来越多的色散带海洋里。所以不是"超导突然消失"，而是平带信号被稀释到测不出来。

真正的终点：石墨

注意：交替转角 N→∞ 不等于石墨 —— 石墨是 AB 伯纳尔堆叠。真正"每层乱转"的叫乱层石墨（turbostratic graphite）：层间电子解耦，每层保留单层石墨烯的线性狄拉克锥，本质是"一堆并联的独立单层石墨烯"。

体相石墨在常规条件下不超导（虽有"局域超导"的争议性报道，块体零电阻未被确立）。所以这条路的终点是：半金属、高面内导电、c 轴几乎不导、无超导。

9诚实边界：哪些是文献，哪些是本页外推

✅ 文献确立：
· 手性极限下 N 层交替转角石墨烯的魔角谱 θk = 2θTBGcos(kπ/(N+1))（Khalaf et al., PRB 2019；实验 3/4/5 层 ≈ 1.57°/1.77°/1.95°），且第一魔角最大不超过 θ∞ = 2θTBG = 2.2°。
· 螺旋体系的多代莫尔与超超莫尔（aM / aMM / aMMM）。
· 魔角超导源于强电子相互作用：0.3 nm 近距屏蔽可完全抑制超导（Manchester, PRX 2026）。
· supermoiré 会碎裂超导穹顶：EPFL（Nat. Phys. 2026）用顶/底层相对中间层转不同角度打破镜面，造出 supermoiré，观测到 Brown–Zak 振荡与 Hofstadter 蝴蝶，超导穹顶被切成多个小穹顶、出现超导–绝缘体级联。

⚠️ 本页外推（思想实验，未经实验验证）：
· 把"界面耦合图"推广到加权路径图 / 准晶字 —— 物理前提是能独立调控每个界面的耦合且保持共同莫尔周期。注意与 EPFL 体系的冲突：一旦不同界面转角不同（那是产生 supermoiré 的方式），单周期假设立刻失效，本页这套"谱 = 魔角"的映射不再严格成立。所以本页的准晶链与 supermoiré 是竞争的两条路线，不是同一件事。
· 贵金属比作为"耦合比 ρ"、蝶形谱形状、"ρ = λm 时自相似性最强"—— 均属该推广框架内的推论。另注：arXiv 2512.11248 也从实验数据提出"多层石墨烯超导转角可能构成斐波那契数列"，但那是从 vHs 与氢化石墨纤维出发的另一条路径（且含 440 K 的高度可疑声称、作者自承机制是推测），与本页的谱构造无关，不应互相印证。
· Hexaflake 与"三机制曲线"是定性的几何/示意，不是任何真实样品的实空间图像或定量计算结果。

✅ 本页被文献间接佐证的判断：
· "分形性在能谱不在实空间图案" —— EPFL 观测到的 Hofstadter 蝴蝶正是能谱分形，与实空间莫尔层级 D=2（空间填充、非分形）的判断一致。
· "多代嵌套莫尔必须由不同界面不同转角产生" —— 正是 EPFL 造 supermoiré 的做法。
· "屏蔽增强削弱配对" —— Manchester 2026 的屏蔽实验直接证实。
