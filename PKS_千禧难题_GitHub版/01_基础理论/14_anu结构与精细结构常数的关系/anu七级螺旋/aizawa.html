🫧 泡泡膜（粒子一开就有）：粒子外面会裹一张蓝色网格膜。 它不是画上去的球壳 —— 膜半径逐高度取自粒子自身的半径（每层一个数）， 再过 3 点空间核 + 非对称时间低通（撑开快 τ≈70 ms、松弛慢 τ≈340 ms）⇒ 撒入时膜被撑开、粒子被卷进去时膜跟着收。
每层取的不是"最大半径"，是稳健上界（层内第 k 大）。这一条是 2026-10-20 那次"肩部不自然"的主因：最大值是极值统计，一颗飞在外面的粒子就能把整层撑大 —— 实测第 4 层 77 颗粒子里最大值 2.18、而 95% 的分位只有 1.05， 于是泡在云已经收窄的地方反而鼓出去，画面上就是两道"耳朵"。
母线是一条样条，不是"筒身＋两个帽"拼的：把每层的半径和两个极点连成 一条 C² 连续的 r² 三次样条 ⇒ 没有接缝，也就没有"过渡不自然"可言： 层与层之间没有折点，两端自然收成 r∝√(z远−z) 的正规圆顶。 （旧的椭球帽在接缝处曲率从 0 跳到 2.45，切线虽接上、弯法却换了零件 —— 这就是那道肩折。）
环的取样是余弦分布（两极密、赤道疏）：极点附近半径按 √ 变化， 均匀取样会把最靠近极点的那一环画在半径 0.4 上，泡顶当场变成锥尖。
泡壁压着不抖：外界往里压 ⇒ 鼓动只留原来的 1/4（±1.25%）， 两端再收干净，泡顶基本不动；基线抬高 2% 保证粒子不刺破膜。
膜是纯渲染层：不参与积分、不改 ODE / 粒子 / 十丝。包裹率约 98–99% （稳健上界会放过个别刚注入/正在逃逸的点，读数照实显示，不再报 99.7%）。 底部 z≈−1.105 是 ż 的稳定平衡点、约 38% 的粒子堆在轴上 ⇒ 泡在底部自然收成细尾。
怎么读：涡环的闭合环流 = 环外下沉 / 环心上喷。 粒子从上方环外被卷下来 → 到底部收向中轴 → 再沿中轴向上喷出， 全程还绕轴转 dθ/dt ≡ d（所以是螺旋，不是直线）。 但它不是源：进去多少、出来多少，总量一分不多 —— 与 §6t 第 ② 句是同一条账。
老师说的"上下梯度差"，在方程里就是 z = b 这一条线： ṙ = (z−b)·r ⇒ z<b 收向中轴，z>b 散向外圈；而 ż 在环外被 −r² 项压着向下、 在环心被 +c 推着向上。两条合起来才是闭合环流（本页 A 级，可当场复算）。
实测单粒子一圈（默认 c=0.6 b=0.7）：上方 → 进中轴 3.0 个单位、 中轴 → 喷到顶 6.0 个单位、整圈约 15 个单位。
默认 c=0.6 时底端 z≈−1.105 是 ż 的稳定平衡点，粒子会在底部积一层（实测 33%）； 把 c 调到 0.8，该平衡点消失，堆积降到 0.4%，喷射最干净。

为什么这是「混沌吸引子表达」—— 定理 + 实测（点开看）

A 级 · 本页可复算的定理：Aizawa 方程前两式 ẋ=(z−b)x−d·y、ẏ=d·x+(z−b)y，令 u=x+i·y 得 du/dt=[(z−b)+i·d]·u ⇒ dr/dt=(z−b)·r、dθ/dt ≡ d。 方位角速度恒等于 d，与 x、y、z 完全无关 —— 故任取 10 个相位差 36° 的状态，它们的方位角之差永远精确保持 36°； 环上编号相距 5 的一对（k 与 k+5）永远精确对望 180°。对任意 f 都成立。

这正是 Anu「十根丝沿 36° 均分」＋「3 粗的对面恰恰是细丝」的精确动力学依据： 10 根按 36° 编号 0…9，编号差 5 即 180°；粗丝取 0,1,2，其余 7 根为细， 则 0↔5、1↔6、2↔7 —— 三根粗丝的对面全是细丝。

破坏旋转对称的只有一项：z 方程里的 f·z·x³ 含 cos³θ，不是旋转不变量。它只让十丝的 (r,z) 失相，方位角不受影响。 实测（f=0.1，十丝同 (r,z)、方位差 36°）：6000 步后方位角偏离 36° 网格 < 1e-4 度（数值误差量级，即定理成立）；而 (r,z) 相对失相 ≈50 步到 8%、≈200 步到 25%、≈1000 步饱和到约 80%。

⇒ 本页给两种画法。① 严格十丝：把一条真轨道 绕 z 刚性旋转 36°k 画 10 份 —— 方位角动力学上精确， 视觉上是与 Anu 原典一一对应的十根齐整螺旋丝。 ② 独立积分：真跑 10 条独立轨道 —— 真混沌， 方位角仍精确 36°、对望仍精确 180°，但 (r,z) 会按上表如实失相（看得见「十丝交织」）。

★ 粗丝外膨 / 细丝内收（形态层 · C 级 · 两个独立滑块）： 渲染时按分组给半径乘一个系数 —— 粗丝 k₁ = 1 + bo/100、 细丝 k₂ = 1 − bi/100，只缩 (x, y)，Z 完全不动。 默认 3.8% 时 k₁/k₂ = 1.039/0.962 = 1.0790，与 Anu 主界面 「贴外壁 0.9857 / 贴内壁 0.9137 = 1.0788」一致（差 0.02%）。 口径必须分清：这是形态层操作 —— 不碰 ODE、不碰积分、不碰时间； 径向缩放是绕 z 旋转的标量倍数，与旋转可交换，故 36° 均分与 180° 对望的定理完全不受影响。 换言之：定理管方位角，这两个滑块管半径，两者正交，不许混为一谈。 取 0% 时系数恒等 1、十根严格共面，等价于本参数加入前的原行为。

与元宝「Anu 十旋 · 参数化可视化」的口径差别（C 级 · 对照）： 那份是解析参数曲线 —— r = sin v·(1+δcos v)·(1−β((1−cos v)/2)²)、 θ = 2πk/10 + 2πT·t、z = Rz·cos v·(1+(γ−1)(1+cos v)/2)， 半径与转角全部是手写死的闭式，没有微分方程、没有不变集、没有吸引子， 属「形态翻译」（它自己也标了「非物理模型」）。本页的十丝来自 Aizawa 混沌系统的真实轨道 —— 36° 均分与 180° 对望是 方程自身的对称性定理（f→0 时严格 SO(2) 等变）， 不是曲线构造里塞进去的参数。两侧都标注清楚，不把话圆过去。

与 Anu 主界面（几何细分路线）的分工： AAA_Anu七级螺旋主界面.html 走的是文献形态路线 （子午线爱心+苹果底、2.5 圈下行 + 2.5 圈上行 = 5 圈、每丝 1680 匝 1 阶 spirilla、 逐级 ×7 到 7 阶、3 粗贴外壁 / 7 细贴内壁）； 本页走的是动力学路线（Aizawa 轨道的 SO(2) 等变轨道）。 两条路线独立给出「十根 36° 均分 + 3 粗 7 细 + 粗的对面是细」这同一个结构。

★ 跨领域对照：魔角石墨烯的「尺度级联」不是分形（2026-10-17 新增）： 元宝那份《双层石墨烯 1.1° 超导夹角》里算出一条对本页有用的判据 —— 多代莫尔 Lj = a·Mj、M = 1/[2sin(θ/2)] 看着像分形， 但每一级都是空间填充的（面积放大 M²、子原胞也是 M² 个）⇒ 盒维数 D = ln(M²)/ln M = 2，整数维，不是分形。 真正分形的是能谱（Hofstadter 蝶 / 康托集），不是实空间图案。 ⇒ 同一条判据搬回本页：「逐级 ×7」本身不构成分形，要看有没有留空洞 （六方雪花 Hexaflake 挖掉 2/9 面积 ⇒ D = ln7/ln3 = 1.771244 才是真分形； Anu 的七级细分若填满，D 就是 3）。「有 7」判不出分形，得看维数。
另有一条数论读数：贵金属比族 (m+√(m²+4))/2 只有 φ=1.618 落在魔角天花板 λ≤2 之内（银比 2.414、铜比 3.303 全超）⇒ 四层魔角 = 1.1°×φ = 1.7798°， 正是文献的 1.78°。即 φ 是唯一能直接当放大倍数的贵金属比，与本页 d = φ+3 = 4.618 同源。

曲面公式 · 尖为什么朝下 · 为什么它像蛋而不像梨（点开看）

原式（参数台那颗「八度蛋」）： x² + y² = 1/(b − z·sin a)² − (z·cos a)²， 默认 a = 33.7°、b = 1.666。 它在 ζ>0 侧有两个 ρ=0 的根，取跨过 0 的那一段就是完整的闭合蛋。

① 尖朝哪边，判据是「哪一段更长」（这条我判错过两次，写死在这里）
剖面 ρ 从腰 rmax 落到 0 的那一段：越长，侧壁越接近平直锥面 ⇒ 看起来越「尖」； 越短，侧壁弯得越快 ⇒ 看起来越「钝」（球冠）。
实测 a=33.7°、b=1.666：+ζ 段长 0.99、−ζ 段长 0.815 ⇒ 原式是 +ζ 长 ⇒ 上尖下钝（尖朝上），与参数台截图完全一致。
⇒ 要让蛋尖朝下，把 ζ 取向整体镜像：b + ζ·sin a， 长段（0.99）落到 −ζ（下方）⇒ 下尖上钝 ✓

② 本页用来覆膜的式子
x² + y² = Sr²·[ 1/(b + ζ·sin a)² − (ζ·cos a)² ]， z = z₀ + h·ζ，r = Sr·ρ(ζ)。
后两式必须同时成立，合起来才叫那张旋转面 —— 这是下面所有结论的前提。 a=0 时两式都退化成半径 1/b 的正球， 所以「近圆球 → 蛋尖朝下」是同一个式子连续变过去的，不是两个形状硬切。

③ b 必须贴着「闭合临界」bc = 2√(tan a)
· b < bc：D2<0，钝端那两个根不存在 ⇒ 不闭合，退化成开口锥面；
· b 一大：两个根分开 ⇒ 曲线立刻退化成对称椭球。 实测 a=26°、b=2.2 时半高比 1.00、L/W 只剩 0.51 —— 这就是之前那颗「梨」的第二个来源。
所以自动绑定把 b 锁在 1.02·bc，正好复现参数台的 a=33.7° / b=1.666。

④ 屏幕长宽比是「形状」之外唯一影响观感的旋钮
ρ(ζ) 决定形状，h/Sr 决定胖瘦 —— 两者在数学上互相独立。
上一版把 h 绑在「两个蛋尖贴住数据边界」，等于把胖瘦交给数据： 数据本身是宽扁的（H/W≈0.77），蛋就被压成 L/W=0.9 的宽蛋 ⇒ 洋葱/梨的观感 （这是「梨」的第一个来源）。
现在 h 由目标 L/W 反解（面板滑块，默认 1.30，鸡蛋实测 1.30~1.35）， 呼吸时 L/W 从 1.00（正球）连续长到 1.30。

④-b 「松紧」是独立的一个数，别拿 L/W 去当松紧用
松紧 = 外膨 margin（默认 18%）。它在 Sr = 最紧外接 × (1+margin) 这一步进，并且因为 h ∝ Sr·(1+margin)（L/W 锁住）⇒ 横向松多少、纵向就跟着松多少，整壳等比张开，ρ(ζ) 一个系数都不动， 所以蛋形不随松紧变化。
反过来把 L/W 从 1.30 压到 1.05~1.15 也能"更贴"，但那是在 把蛋压扁换贴合（ρ 不变、h/Sr 变）—— 形状变了，所以那一档只适合"要贴不要蛋形"。 要松、还要像蛋 ⇒ 只动松紧：6%（贴丝最紧）/ 12%（标准）/ 18%（默认，明显离丝）/ 30%（很松）。

⑤ 蛋壳不吃孔径律（这条是最关键的一处修正）
孔径律 s(z) = exp[ ln(1/(R·C_A))·(1−smooth u) ] 是按高度非线性压半径的 （R=2.5 时底部只剩 38%）。如果壳也乘它，屏幕上的半径就是 Sr · ρ(ζ) · s(z) —— 两个函数相乘，它就不再是旋转面了： 下半部被额外压窄、上半部保留 ⇒ 轮廓必然鼓成「上宽下缩颈」的梨。
现在壳在显示空间里原生生长：横向直接给 Sr·ρ(ζ)、纵向直接用显示 z （与丝同一根纵轴，所以仍然对齐）；s(z) 只保留在 「把丝的原半径换算成屏幕半径」那一步 —— 那是丝的口径，不是壳的形状。

⑥ 包裹怎么保证： Sr = max层[ 包络(z) / ρ(ζ) ] × (1+外膨%)， 逐层取最紧外接 ⇒ 构造上不可能漏； __az.eggCover() 再用十丝的原始采样点独立复核一遍（默认 0 漏出）。 分桶时桶内取 ρ 最小的那个 z（桶中心 ± 半桶宽），否则桶化会让边缘的点漏出去。

⑦ 口径：这是纯渲染层（形态层 · C 级）—— 不碰 ODE、不碰积分、不碰十丝配色；关掉勾选即逐位恢复原画面 （包括取景，见 ⑧）。

⑧ 取景（2026-10-20 补的，直接后果是"画面小了一圈"）
松紧一放大，蛋的钝端就跑到十丝上方；原来取景只框十丝的包围盒， 蛋顶会被画布顶边直接切掉（实测 R=2.5、松紧 18% 时蛋顶超出顶边 245 px， 画面上只剩一排被砍断的金色经线）。
现在取景把蛋壳的 13×12 个采样点也并进包围盒（用上一帧解出的蛋； EGG 只由数据包络反解、不看 K ⇒ 无循环依赖），所以整个蛋一定在画面内。
⇒ 代价说明：同一个 R 下，十丝比"只框十丝"时小约 18% （蛋比十丝高约 27%，纵向约束先到）。要恢复原来的取景大小：关掉蛋形覆膜， 或把右下角缩放 1.00x 往上推（推太多蛋顶会重新出画）。

公式、外网出处与证据分级

建模假设（C 级·工程类比）：把吸引子外壳层中面当作曲速泡壁 Rw(z)=(PRO+PRI)/2·s，壳层肉厚当作泡壁厚度 Δ(z)=(PRO−PRI)/2·s； 形状函数 f=F(ξ)、ξ=ρ−Rw(z)、F=½(1−tanh(ξ/Δ))。 s 即本页孔径呼吸 / 端面收口映射（与 3D 视图、剖面小图完全同源）。 这是几何建模选择，不是对任何实物飞碟的物理实测。

度规（B 级文献）：随动系 ds² = −dt² + (dz − βf·dt)² + dx² + dy² + ρ²dφ² —— Alcubierre 1994（Class. Quantum Grav. 11, L73）；Natário 2001 给出零膨胀保体积的等价形式。 f=1 泡内（平直，船不动）、f=0 泡外（平直）、壁上过渡；β=v/c。

能量密度（A 级·本页数值验证）： ρ_E = −(c⁴β²/32πG)[(∂_x f)² + (∂_y f)²] = −(c⁴β²/32πG)F′² 轴对称下第二式精确成立（无方位角平均近似）。 恒负 ⇒ 违反弱 / 强 / 主导能量条件 ⇒ 需要奇异物质。

膨胀场（York 时）：θ = −∂_iβ^i = βF′R_w′ 文献符号：后端扩张 > 0、前端收缩 < 0，峰 |θ| = β|F′||R_w′|。

动量密度：j_z = −(c³β/16πG)(F″ + F′/ρ)； 净动量恒等式 ∫j_z dV = −(c³β/8G)[ρF′]₀^∞ = 0 对任意轴对称泡精确成立。

总能量：E = −(c⁴β²/16G)∫∫F′²ρ dρ dz。

量子不等式（B 级文献）：Pfenning & Ford 1997（CQG 14, 1743） ⇒ 壁厚须压到数百普朗克长度；球形薄壁标度 E = −(c⁴/G)β²R²/(24Δ)（本页默认算例精确复现其 a quarter solar mass 结论）。 van den Broeck 1999 可把需求压到约 1 M☉。

推进边界（B 级文献）：Bobrick & Martire 2021 （arXiv:2102.06824）证明亚光速曲速泡 = 惯性运动的物质壳，本身不推进； Bondi–Sachs 转向定律（arXiv:2606.22531）：渐进平广驱动器只能靠辐射改变 Bondi 四动量， 光子火箭的 Tsiolkovsky 常数与化学火箭相同 ⇒ 真正转向 / 加速必须向外辐射。 Finazzi et al. 2009：β>2 视界量子不稳定性。

分级速查： A = 页面内可复算的恒等式 / 标度（ρ_E 轴对称闭式、P_z ≡ 0、E ∝ β²R²/Δ）； B = 文献标准结果（度规、QI、Natário、Bobrick–Martire、Bondi–Sachs、van den Broeck）； C = 工程类比假设（轮廓→泡壁映射、实物飞碟）。 一切输出都是度规框架下的模型量；空白 ≠ 已证伪，臆测 ≠ 已证实。

蛋形覆膜 ↔ Aizawa 的联动口径
（回答「是不是在公式根上建立因子关联」）
它是不是「在公式根上建立因子关联」？（2026-10-20 已订正：松紧 / 取景口径 · 点开看，可再收起）

一句话答案：一半是，一半不是。 没有把 Aizawa 的 ODE 系数 (a,b,c,d,e,f) 代进蛋形曲面公式； 真正在公式根上同源的只有一条 —— 孔径律 s(z) （而且它只作用在「丝的屏幕半径」上，不作用在壳的形状上，理由见上一块⑤）。
其余靠 3 个几何因子（z₀ / zp / Sr）+ 1 个纵向比例（h，由 L/W 锁定） + 1 个呼吸律（a）+ 1 条临界约束（b=1.02·bc）+ 1 个松紧旋钮（Sr 的 ×(1+18%)）。 松紧排在最后但最"人话"：它只放大壳、不改 ρ(ζ)， 所以「更松 / 更紧」永远不动蛋形（见上一块 ④-b）。

① 唯一真正同源的一条：孔径律
丝的屏幕半径 = 世界半径 × s(z)， s(z)=exp[ ln(1/(R·C_A))·(1−smooth u) ]，u 是 z 在数据范围内的归一化高度。
蛋壳的包络比较（eggScan / eggCover）用的就是这一份 eggApMul()，与 trPt() 里那段逐字相同。 所以 R 一动，「要包住的那一圈丝」和「算出来的 Sr」是接在同一个形变算子上的。

② 三个几何因子（全部由吸引子数据反解）
· z₀（蛋腰）← 包络最宽那一层：对 ≥98.5% 峰值的所有桶做加权重心 （直接取 argmax 会在相邻两桶间跳，蛋腰抖 0.08、Sr 抖 15%）；
· zp（曲线真实最宽处）← dρ²/dζ=0 的解析根，不是 ζ=0。 把 zp 对齐数据最宽层，轮廓在腰上才有水平切线； 拿 ζ=0 当腰会留一道看不见的折角（ρ′(0)≠0）；
· h ← 由目标 L/W 反解：h = LW·2·Sr·(1+松紧)·ρmax/(tHi−tLo)。 而 Sr 又依赖 h（ζ 位置变化）⇒ 外层扫 h（对数 72 点）、内层解 Sr， 取「所有层都在蛋内 + L/W 最接近目标」的那个。扫描而不是迭代： 这个目标函数在「刚好放下」的拐点处极陡，迭代会来回跳（实测 L/W 在 0.66~1.35 乱飞）。
· Sr ← max层[ 包络(z) / ρ(ζ) ] × (1+松紧%)（松紧默认 18%）， 逐层取最紧外接 ⇒ 包裹由构造保证。
⚠ 三处 L/W 必须同一口径：扫描评分、就近微调、最终读数 都必须用含松紧的宽度 2·Sr·(1+margin)·ρmax。 微调那处原来漏了 (1+margin) ⇒ 它把 h 一路往下拽， 目标 1.30 实际只到 1.22，松紧开得越大偏得越多 —— 纵向那部分"松"被悄悄吃掉了（已修，见⑦）。

③ a 跟呼吸走、b 锁在闭合临界
a = apeak · ln R / ln Rref：R=1 ⇒ a=0 ⇒ ρ ≡ 1（正球）； R=Rmax ⇒ a=apeak。
b = 1.02 · 2√(tan a) —— 贴着闭合临界取，此时曲线最不对称、最像蛋； b 一偏离，钝端两根分开、迅速退化成对称椭球（半高比 1.00、L/W 0.51）， 观感立刻变成「梨」。这不是拟合参数，是几何约束定出来的。

④ 那 Aizawa 的 a,b,c,d,e,f 到底起什么作用？
诚实交代，逐个说：
· d = 3.5：u=x+iy ⇒ dr/dt=(z−b)r、dθ/dt ≡ d。 d 只决定方位角速度，(r,z) 的轮廓里根本看不到 d —— 进不了蛋形公式，也不需要进；
· e = 0.25：只改 z 方程里 −r²·e·z 这一项的权重；
· f = 0.1：+f·z·x³ 破坏旋转对称，含 cos³θ ⇒ 只让 (r,z) 失相； 那点非轴对称已被「逐层实测包络」整条吸收；
· c=0.6 / a=0.95：定 z 的平衡位置 ⇒ 影响包络的高度与最宽层，同样是通过实测包络进来。
⇒ (a蛋, b蛋) 与 (c,d,e,f) 之间没有解析闭式。 硬造一个对应只会是假的；这里走的是 数值反解（几何配准）。

一、真正的参数不是 d，是 N

N(d) = d · T(d) / 2π　　　← 一个 z 循环里实际绕了几圈 Δφ = 360° · frac(N)　　← 每循环错开多少度 σ = 逐圈 Δφ 的标准差　← 判"真锁相"还是"糊" q = 分母(最简 frac(N)) ← 画面上看到几条带 R = sw · d　　　　　← 孔径不是独立参数，≤0.50d 安全 / ≥0.91d 崩解

d 只改绕速（θ̇ ≡ d 精确成立），不改 (r,z) 投影。但 z 的周期由 f·z·x³ 这一项偷偷吃到 d，于是 T 会自己动： 从 5.44 到 6.79 都出现过。N 才是那个被系统钉住的量。

二、N–d 阶梯：看得到"台阶"，才叫锁相

锁相 σ<0.11°（N 精确整数） 弱锁 0.11°–17° 未锁 >17°（sweep 里最高 73.5°） 虚线 N=d 是"T 恰好=2π"的标称线；所有点都贴在它附近，但真正落在整数上的只有台阶。

台阶宽度随 N 急剧变窄：N=3 宽 0.76，N=7 宽 0.47，N=10 只 0.08，N=11 只 0.02。 所以 d=8 不锁、d=8.2 反而锁——不是"8 这个数犯忌"， 而是 8.0 正好掉在 [7.47, 8.15] 这条缝里。这条判据可当场证伪。

三、每圈起点的方位角（n = 第几圈）

注意第 4 格：3+√2 = 4.414 是无理数，画面却和整数 6 一样只有一条带。 它被 N=4 的锁相带吞了。"含不含根号"在这里不起作用，起作用的是"离最近整数 N 有多远"。

σ 是逐圈错开角的标准差。σ 精确为 0 ⇒ 周期轨道；σ 大到几十度 ⇒ 每圈都不一样，条带被打散。

五、两类"最优"，各有各的道理

最闭合：落在整数台阶正中 ⇒ N 整数、σ=0、1 条带，永久清晰。 d=6（N=6，R 安全线 2.75）、d=7（N=7，R 3.25）是这一类的代表。

最均匀：落在两条台阶之间最宽的缝里 ⇒ σ 最大、条带被彻底打散。 实测最深处是 d≈4.56（σ=73.5°）与 d≈3.50（σ=70.7°）。 3+φ=4.618 就在这条缝里（σ=68°），所以它确实铺得最匀——理由是"抖散了"， 不是"137.5° 黄金角"。

页面原口径必须改一处：原文案 "N = d ⇒ frac(d) 就是错开比例" 只在 T = 2π 时成立。而 T=2π 基本只出现在整数 d（锁相把它拉回 2π）。于是逻辑上： 要 137.5° 就得 T=2π，要 T=2π 就得 d 近似整数，而整数 d 的 frac 是 0。 所以 137.5° 在本方程里不可达。实测：4.618 → Δφ=176°±68°，7.618 → 120°（1/3）， 10.618 → 78°。三个 φ 档位没有一个给出 137.5°。

六、为何 6+φ 不考虑 —— 它其实该考虑，但落点差

三个 φ 档位同族（frac(d) 都是 0.618），可 N 落点完全不同：

· 4.618 → N≈4.50，卡在最大缝里，σ=68° ⇒ 糊得最匀，视觉最优
· 7.618 → N=22/3 精确，σ=11.5° ⇒ 3 条带，不是糊，是"三瓣"
· 10.618 → N=235/23，σ=4.8° ⇒ 23 条带挤在一起，接近均匀但 R 安全线要 5.3

所以 6+φ 不是"不能考虑"，而是它落到 1/3 共振上，出来是三瓣不是均匀一片。 若目标是"最均匀"，4.618 更好；若目标是"大 d 且别锁相"，10.618 更稳。

七、R 的通项：R ≈ 0.5 d

把页面那张实测安全线表按 R/d 归一，除 d=3.5 外全部落在 0.46–0.54： R*(45°) ≈ 0.50 d，R**(60° 崩解) ≈ 0.88 d。 因为判据本来就是 sw=R/d（>0.91 崩、>0.52 临界）——R 从来不是独立参数。

表里 d=3.5 那行口径不一致：R*=2.50 ⇒ R/d=0.714，比同类高 43%； R**=4.50 ⇒ 1.286。其余 9 行都在 0.5 附近。要么改成 R*=1.75，要么单独注明 3.5 用的是另一套判据。

口径限制：以上"锁相/未锁"结论绑定 f=0.1 这一组参数。f 调大 ⇒ 周期窗出现、 锁相带整体变宽；f→0 ⇒ z 子系统与 d 完全解耦，T 恒为 2π，那时 frac(N)=frac(d) 的老口径才真正成立。
