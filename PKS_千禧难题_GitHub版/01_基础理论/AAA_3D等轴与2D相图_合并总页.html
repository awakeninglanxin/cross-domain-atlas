§5背后的公式与源码口径

5.1 参数台里那条 2D 蛋形曲线

AAA_PKS代码族_3D参数台.html 中同一个「蛋」有三种逐字同源的写法： L13552 f0HexProf2D（红色实线剖面，即老师箭头所指）、L2704 f2Egg（极坐标闭合曲线）、 L3090 f2EggProf（母线，默认 α=33.7° / b=1.666）。

// f2Egg（L2704 思路）
di  = sqrt(sin²φ + cos²φ·cos²α)
ins = z0² − 4·cosφ·sinα / di
den = 2·cosφ·sinα
rr  = (z0 − sqrt(ins)) / den          // 取较小根
(x, y) = (rr·sinφ, rr·cosφ)

// f2EggProf 母线（L3090）
R(u) = sqrt( 1/(b − u·sinα)² − (u·cosα)² )

把 rr 那行反解，其实是一个二次方程的较小根（这一步是推导，源码注释没写）：

cosφ·sinα·q² − z₀·q + 1/√(sin²φ + cos²φ·cos²α) = 0，　q = r / amp

数值自检：997 个 φ 上 max|左式| = 5.129×10⁻¹⁴。定义域闸：φ=0 处 ins = z₀² − 4k > 0 （k = tanα）；参数台 f2KB() L2801 用 k ≤ 0.96b²/4 夹紧，并注明「b²≤4k 无实解 ⇒ 截面长出尖刺」。

5.2 为什么 (z, r) 与蛋形母线能对上

剖面浮窗横轴 u = 半径、纵轴 t = 轴向；相图横轴 z = 轴向、纵轴 r = 半径 ⇒ (z, r) = (t, u)，只是轴互换。 再加 Aizawa 极坐标化后的 ṙ = (z−b)·r：z−b 就是离轴的径向偏移，z>b 发散、z<b 收缩， 与母线「一侧鼓一侧收、轴在 u=0」是同一个几何分工。

// Aizawa（90_js.html L1512 逐字复现），RK4，DT=0.02，2600 步瞬态 + 24000 步每 3 点
xdot = (z − b)·x − d·y
ydot = d·x + (z − b)·y
zdot = 0.6 + 0.95·z − z³/3 − r²·(1 + 0.25·z) + 0.1·z·x³

// z-nullcline（忽略破坏 SO(2) 的 0.1·z·x³ 项）
r² = (c + a·z − z³/3) / (1 + e·z)

5.3 2D → 3D 壳

把 2D 那条闭合 (z, r) 曲线绕 z 轴旋转，得到的是带中心洞的环面 / 桶形壳，不是实心蛋。 外壁 Ro(z)、内壁 Ri(z) 由曲线多边形逐边精确求交得到（按 z 分箱取点会系统性低估外壁，第一版就栽在这里）。

§6结论与诚实边界

能当「外包络模板」，不能当「解析边界」。 三组数据 7 参数自由拟合的蛋形 RMS = 3.53% / 2.30% / 3.51%，比椭圆好 30.8% / 35.4% / 30.9%； 拟合 α 几乎精确等于 αcrit = atan(z₀²/4)（差 0.02–0.08°）—— 相图上下两端是尖的，而 f2Egg 只有在 b²=4k 临界处才收得出真尖点，是数据把公式顶到了它自己的定义域边界。
三条不能忽略的限制： ① 边界是 ODE 的不变集（积分出的轨道），不是代数曲线。用蛋形母线去贴 z-nullcline，α 撞下限、b 撞上限， 归一化纯形状比对最小差 0.419，同族假设被拒。 ② 默认 d=3.5 时 λ₁≈+0.09、DKY≈2.28，是分形点云；原截图自己标了「σr = 1.191 · 厚度不为零」。 只有 λ₁≈0 的准周期窗口才有薄环可拟合。 ③ 蛋形关于轴严格对称（r(φ) 只依赖 cosφ），而 +0.1·z·x³ 破坏 SO(2)，相图左右不对称； 7 参数拟合里 rot≈1.8°–2.5° 就是在补这个差。3D 壳包含率只有 56%–82%，因为内支 r≈0.15 落在中心洞里。
可直接抄走：只用来画包络 / 套外框 / 做初始猜测时，取 q(φ) 为上述二次方程较小根 → (x,y)=(q sinφ, q cosφ) 归一化到 [−1,1]² → z = zc + hz·x、r = rc + hr·y； α 取 30°–31° 且必须 tanα < z₀²/4。三组的盒参数见 §4.2。

§7与环形托克马克位形仿真的关系：能建立什么、不能建立什么

一句话结论：这个页面不是托克马克的 MHD 求解器，但两者共用同一组柱坐标， 且「闭合 (z, r) 曲线绕对称轴旋转成环面」与「极向截面绕主轴旋转成环面」是同一个几何构造。 因此能建立的是 ① 坐标恒等 → ② 几何同构 → ③ 动力学形态类比 三层关系； 能当位形 / 约束演化的可视化沙盘，不能算安全因子 q、不能算 Grad–Shafranov 平衡、 不能预测 kink / tearing 不稳定，更不能给能量约束时间 τE。下面逐层把边界画清楚。

闭合磁面（ι≠0）v9 八-3 安培环路、本页 §7.4 磁力线绕满磁面、无端点 ✅ 唯一真正禁锢；靠 ∮B_p·dl=μ₀I_p 给出的极向场与旋转变换， 不是「弹回来」而是「跑不出去」 ✅ 依据
🔴 最关键的一句：真正禁锢等离子体的不是一面镜子，而是「磁力线不跑出去」。 闭合磁面没有朝向、没有反射面，因此「把镜子朝外放 / 朝内放」在物理上不是一个可执行的自由度； 能调的是 ι、|B| 的空间分布与磁面拓扑。
真算佐证（见 9.4 第 ⑥ 组）：10 keV 氘离子在 5 T 下拉莫尔半径 4.0865 mm、 回旋周期 26.2 ns；在 v9 八-2 算出的 0.375 ms 漂移逃逸前它已回旋约 1.43×10⁴ 圈。 粒子是螺旋着撞上壁，不是像光子那样弹回 —— 所以「泡内壁放镜子」在微观上就不成立。

9.5 四条互斥判据：为什么「反过来设计」不能兼得

① 尺度互斥 ✅ 依据： 磁帆要 R_mp ≫ R₂ 才有推力（同向双环 84 km / 16 km = 5.25，间隙 68 km）； 约束腔要 R_out/R_in≈1.1 才谈得上「间隙」。而反向会切时 R_mp=6 km < R₂=16 km， 泡壁缩到环里面，夹层根本不存在。两个尺度要求相差约 10⁴，不可兼得。

② 拓扑互斥 ✅ 依据： 夹层里没有中心螺线管位置。按 v9 八-3 ∮B_p·dl=μ₀I_p，若绕磁轴一圈的回路套不住净极向电流 ⇒ B_p≡0 ⇒ ι≡0，v9 八-2 现算 10 keV / 5 T / 3 m 下 0.375 ms 横穿 1 m。 要救回来只能让内侧双环变成承载 MA 级电流的中心柱（球托 / STPP：IAEA FT/1-5 给 30.2 MA）， 或把线圈做成三维（仿星器化）——两者都改写了「这是双环磁帆」这个前提。 无中心螺线管的电流爬升至今没有成熟方法（EXL-50 ECRH 仅 50–150 kA）。

③ 损失互斥 ✅ 依据： 要「禁锢」就要求场线闭合无端点；但「镜子」若指磁镜，它必然是开放系统： f_loss=1−√(1−1/R_m)，R_m=2 立即丢 29.29%， R_m=10 仍丢 5.13%，要压到 <1% 需 R_m≥50.25； 碰撞散射最终仍把粒子送进损失锥，外加损失锥不稳定与 1/ν 输运（v9 八-5 已点名）。 外部佐证：Phys. Plasmas 2017（doi 10.1063/1.5003359）给出磁镜 nτ 距 breakeven 约低 100 倍。

④ 工程互斥 🔶 推测： 两面「壁」让受热 / 溅射面积变成 2.10×（薄间隙）或 6.25×（磁帆比例）。 而球形托卡马克的设计方向恰恰是扔掉内侧包层、屏蔽、PF 与 OH 螺线管，只留单匝 TF 中心柱； 夹层构想把内侧结构又加回来还加两道镜面，与低 A 高 β 的工程逻辑相反。 另外泡壁要挡的星际介质动压 9.6e-10 Pa 与聚变等离子体 2nkT=3.2e5 Pa 相差 3.34×10¹⁴ 倍（即使取极端分子云核密度仍差 1.2×10¹⁰）—— 挡得住风 ≠ 挡得住等离子体。
✅ 但它不是全盘否定：v9 Ⅲ 页第 5301 行已经替这个构想答过一半 —— 「会切场把等离子体关在环之间（适合聚变约束），恰恰不适合当磁帆」。 老师提的「反过来设计」正是把这句反着用，逻辑自洽；代价是放弃推力（0.6 N） 并接受上面四条互斥。这一条属于 🔶 推测：结构类比成立，可行性 ⚪ 需验证。

9.6 这一节能做什么、不能做什么

✅ 可以：讲清「约束靠闭合磁面而非反射面」；用同一套几何语言把单环 / 双环 / 会切 / 夹层并排对照； 演示「磁帆要撑大泡、约束要压薄间隙」的尺度二选一；把六组量级差作为工程直觉的锚点； 按口径三分标清每一句能站多稳。
