ℹ 等轴 ≠ 等角视角（SOUL 铁律 244）：等轴是物体空间 x:y:z=1:1:1， 由单一尺度 sc 保证，与相机角度无关；等角 / 等轴测只是沿 (1,1,1)/√3 的一个初始取景。 本页保留 26_sec10.html 图 10 的绕 z 轴 yaw 口径，可自由拖不同角度（yaw + pitch）的版本在 3D + 2D 合并总页。 轴测缩短如实显示在读数里（|ex| |ey| |ez|），不隐瞒、不用分轴 scale 去补。

口径：壳由 (z, r) 闭合曲线逐边精确求交拆成外壁 Ro(z) 与内壁 Ri(z)， 再绕 z 轴旋转。点 Ri(z) ≤ r ≤ Ro(z) 记「壳内」；r > Ro(z) 记溢出； r < Ri(z) 记中心洞。对照壳沿用 90_js.html AZ.env 的 0.97 / 0.16 分位口径。

数据可信度：shot3 组的薄切片算出 A = 0.2650 / B = 1.4560 / σr = 1.1910， 与老师截图 3 标注的 0.27 / 1.46 / 1.191 逐位吻合。页面里的 3D 点云由 JS 用同一套 RK4 实时重算， 上表数字由 Python 独立算一遍，两者前 8 个点在 §2 里逐点核对。
