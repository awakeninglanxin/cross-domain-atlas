L3 · 六族代码的最终升级版

PKS 代码族 · 3D 参数台 把 PKS_千禧难题_GitHub版 里六个代码目录的最后一代 py 各搬成一页可拖参数的 3D： 双波纹盘（本次纠正）、蛋螺旋、螺旋锥管、蛋形均轮、钟形水轮、双曲锥几何阻尼。 每族的参数与默认值都取自原脚本，滑条一动整个网格按方程重算，不是截图。

这一页解决的问题：仓库里有 1457 个 .py，绝大多数是同一想法的一代代改稿；只有每个目录里的最后一代才是"定型版"。 这一页先做了一件事——扫每一族有没有配套的 md 说明，再按最后一代的方程做成参数台。 凡是原脚本里数值会崩的地方（NaN、开方为负、曲线提前终止），这一页都不偷偷修掉，而是照实标出来。

三 · 逐族说明（含原脚本的坑）

① 双波纹盘 —— 本页纠正的那一个

之前错在哪：我上一版把波纹盘画成 z = A·sin(nθ)，也就是"盘子边缘一圈起皱"。那是周向波纹， 属于克拉德尼那一类"沿圆周的驻波"，跟 22_双波纹盘最佳截面曲线.py 不是一回事。

原脚本实际做的事（三行就说完）：它不画参数曲线 (x(t),y(t))，而是把蛋的两个分量拆开， 各自以 t 为横轴当成一条截面曲线——蓝线一条、绿线一条，绕盘心转一圈就得到一张双面盘：

amp(t) = 1 / [ (1 + t/2π) · ln(n+1) ] ← 衰减包络（连续对数积分） 蓝面 A(t) = amp(t) · a · [ 2·sin t / (b + √(b²−4k·cos t)) − t_min ] 绿面 B(t) = amp(t) · a · [ m·term₁ + term₂(t) + t_min ] a = 2π , m = 2/3 , k = 2/3 , b = 5/3 , t_min = 2π/(n+1) , t ∈ [t_min, 2π+2nπ]

所以"双波纹"指的是两张面各自带波纹，波纹沿半径方向一圈圈往外走，振幅按 1/[(1+t/2π)·ln(n+1)] 递减。 n 越大，衰减越快、纹越密；n 与 ln(n+1) 一起决定了整体厚薄（实测 n=1 很肥、n=12 很薄）。

27 号文件是"衰减内化"版：不再外乘 amp，改成让蛋自己的参数随时间演化 —— k(t)=1/2π、b(t)=2t/(T√t)=2√t/T，于是"蛋自己选择慢慢变圆"。 代价是它的定义域变窄：b²−4k = 4t/T² − 4/T，当 t<T=2π 时为负，原脚本直接 np.sqrt 会出 NaN。 本页照实处理：从 t=2π 起画，内圈那一段留空，并在读数里报"无效点"个数。

读图提醒：本页把两条截面的颜色照原脚本（蓝 = x_minus，绿 = y_add）， 不叫"上/下"——因为蓝面在 z<0、绿面在 z>0，谁在上取决于你从哪边看，硬叫上下反而会误导。 盘心留 5% 的孔也不是我加的：原脚本从 t_min 起画，本来就不经过圆心；孔边那一圈"小尖"是因为 t_min 处厚度最大（n=5 时是该盘最厚的 6.4，厚径比在这一处取到 0.093），原式如此，不是建模多画了一笔。

② 蛋螺旋（Die Ei-Kurve · √n 缩放）

斐波那契比值喂参数，是这一族最"不像凑数"的地方：k=F_{n+1}/F_{n+2}、b=F_{n+3}/F_{n+2}， 随 n 增大同时收敛到 1/φ=0.618 与 φ=1.618——也就是说 n 越大，蛋就越接近黄金蛋，只是个头按 √n 长大。

蛋曲线： r(φ) = amp·[ z₀ − √( z₀² − 4·cosφ·sinα / √(sin²φ + cos²φ·cos²α) ) ] / (2·cosφ·sinα) x = r·sinφ , y = r·cosφ , tanα = k , z₀ = b , amp = √n 叠层： z_n = (n−1)·Δz , 第 n 层整体转 θ_n = (n−1)/(N−1) · 2520°

原脚本出的是 2D 叠图 GIF；本页做的是把这个叠层抬进 3D（每层给一个 z，保留原来的旋转角），所以能看出它其实是一条会膨胀的螺旋壳—— 舒伯格"羚羊角"那类形状的骨架。φ 在 π/2、3π/2 处 cosφ=0，分母为零，原脚本靠 valid_mask 跳过； 本页同样跳过，所以每条曲线在那两处有两个小缺口，不是画错了。

③ 螺旋锥管（黄金比 · 管波动纹）

这是六族里代码最长（28 KB）的一个，三件事叠在一起：指数螺旋锥 + 断面渐变 + 管的波纹。

螺旋线： R(t) = R_top·e^{b·t} , b = ln(R_bot/R_top) , R_top = R_bot/2 − tan(α)·h θ(t) = 2π·turns·t , z(t) = h·(e^{b t} − 1)/(e^b − 1) 扭转： ψ(t) = twist·2π·turns·t （linear） ψ(t) = twist·2π·turns·(2^{3t}−1)/(2³−1) （exponential，原脚本默认） 断面： r_s(t) = amp·(1 − taper·t) （原脚本 a[]=linspace(1,1/3) → taper=2/3） 波纹： 相位 = Bands·(φ^{p·t}−1)/(φ^p−1) , 锯齿 = 2 − (相位 mod 1) ∈ (1,2] 断面半径 × [1 + cAmp·(锯齿−1.5)]

关键点：波纹的频率随 t 增大而变密（相位是 φ 的幂的积分，不是线性相位），所以管子下端疏、上端密—— 这就是原脚本 _precompute_exp_wave 里那段 minimize 在干的事：反解 k 使总带数正好落在 47 带。 本页用同样的归一化形状，但把"总带数"直接做成滑条，省掉优化那一步（结果等价，可自己数带子）。

原脚本要从两个 DXF 里读"咬一口的蛋"断面做首尾混合；本页把断面简化为圆 + 波纹， 不再复刻断面渐变——这一条是降级，不是等价，写在这里免得误会。

③-1 本页对族③ 的三处改造（都是"看得见 / 用得上"的改动）

① 管形从封闭实体改成开口曲面。原脚本的管是封闭实体，两端看着像被封住了。 真正的原因不是材质，而是标架退化：Frenet 标架用中心差分 d₁、二阶差分 d₂ 构造， 在曲线两端 d₂ 会退化成 ±d₁ ⇒ cross(T,N)=0 ⇒ 副法向 B 塌成零向量 ⇒ 管口断面被压扁成一条线，看上去就"封口"了。本页改用旋转最小化标架（RMF · 双反射法）： 全程 T/N/B 正交且非退化，两端不会塌。附带好处是 RMF 不含曲线自身的挠率， 所以红线缠绕角就严格等于读数里的 ψ(1)（实测 twist=±1.5 时两者差 < 3°）。 入口画深蓝亮圈、出口画亮红亮圈 + 一张极淡的断口盘，一眼能看出这是开口管。

② 红色扭转母线。贴着管内壁的一条母线，随 ψ(t) 绕切线一起转 ⇒ twist 一改， 缠绕圈数立刻变。注意用的是 TubeGeometry 而不是 THREE.Line—— WebGL 不支持 linewidth>1，用 Line 画出来只有 1 px，根本看不见"这里在扭"。

③ 圆周阵列 + 两个几何反算按钮。六族全部支持"绕该族对称轴旋转复制 n 份"（n ≤ 12）， 每份转 360°/n ⇒ 严格 n 重旋转对称，副本用色相平移区分。族③ 因为要排很多份， 所以额外给了几何反算：

不重叠判据（保守充分条件）： 把每份管看成沿中心线扫掠的圆截面管，局部半径 r_s(t) = tr · k(t) 其中 k(t) = (1 − taper·t) · wave(t) 是无量纲因子 任意两份（份0 的 t1 点 vs 第 g 份的 t2 点）须满足 d(t1,t2) > tr·(k1+k2) ⇒ tr 上限 = min over 所有点对 d / (k1+k2) （tr 只线性出现 ⇒ 一次遍历直出，无需二分） 同一份内部还要查"圈间自重叠"：真正角对齐的一圈是 t2 = t1 + m/turns，取 ±半圈窗口内真实最近点

按钮①：已知 n ⇒ 算最大管径 tr（向下取整到 0.1 并吸附滑条刻度，保证"显示值 == 渲染值"）， 并写回滑条；按钮②：固定当前管径 ⇒ 算最大阵列份数 n（≤12），写回阵列滑条。 读数区同步给出不重叠管径上限 / 当前是否安全 / 当前管径最大阵列数三行。 默认参数（底径 108、高 144、α=13.28°、2 圈、tr=4.5、taper=0.667、47 带波纹）下： n=4 安全（上限 4.878），n=5 起开始穿插（上限 3.819）。

④ 蛋形均轮（托勒密偏心模型）

M(t) = ( C_x + R·cos t + r·cos(w·t) , C_y + R·sin t + r·sin(w·t) ) k_E = max(M_y) / |min(M_y)|

这一族的配套 md 写得最诚实，直接给结论：它是外旋轮线（epitrochoid），不是蛋形方程。 w=1 偏心圆、w=2 蜗线（limaçon）、w=3 三尖外摆线；只要 C_y≠0 就打破对称，看起来就像蛋。 所以本页的读数里专门给一行"曲线类型"，就是不让"像蛋"被当成"是蛋"。

⑤ 钟形水轮（内进水锥）

母线半径： r(t) = √[ 1/(b − t·sinα)² − (t·cosα)² ] 中心线： x = r·sin(3ft) , y = r·cos(3ft) , z = −t·z_v , t ∈ [0, 2π/3] 叶片断面： x_s(τ) = −a·π·sinτ/τ , y_s(τ) = a·π·cosτ/τ , a: 0.3 → 0.1 断面相位： φ₀ = 横断面相位角（曲线起点方位，0° = x 正半轴，逆时针为正） 施加的总旋转 = φ₀ + 90°（原始图起点在 −90°）⇒ φ₀ = 270° 时与原脚本朝向一致

"钟形"不是抛物线也不是圆锥，而是那个根号：t 小的时候 r≈1/b（近似圆柱段）， t 一大 (b−t·sinα)² 变小、r 加速膨大，再大就开方为负、曲线当场终止。 本页把这个终止点（cut）直接报出来：把 α 拧到 25° 以下、或把 t_max 比例拧大，就会看到"钟"还没长完就断了。

横断面相位：叶片断面那条 2D 曲线（−aπ sinτ/τ, aπ cosτ/τ，等价于半径 aπ/τ、方位角 τ+90°）可以整体绕原点逆时针旋转。本页以 "x 正半轴 = 曲线起点"为基准：相位角 0° 时起点正好落在 x 正半轴，逆时针为正； 因为原始图的起点在 −90°，所以实际施加的总旋转是 φ₀+90°，取 φ₀=270° 就回到原脚本朝向。 参数台右侧的 2D 预览与 3D 模型共用同一条断面方程，预览里画的就是模型上用的那条曲线。

⑥ 双曲锥 · 几何阻尼

锥面： z(r) = C₁ − C₂·ln r , C₂ = z₀/ln10 , C₁ = z₀ + C₂·ln10 （r=1→z=2z₀，r=10→z=z₀） 曲率： κ(r) = C₂ / ( r·√(r² + C₂²) ) 几何力：f_cone^r = −κ(r)·|u_r|

颜色就是 κ(r)：越靠近锥顶（r 小）曲率越大、阻尼越强，r 大则趋近于零。 但必须说清楚：task3_conical_ns.py 的抬头自己写着"不声称 NS 在锥面上有光滑解、不声称几何阻尼保证不爆破"。 这一页照抄它的立场——画的是曲率，不是证明。

本页的取舍（写明白，免得当成"全复刻"）：
① 断面渐变（③）、DXF 输入（③⑤）、trimesh 导出与 Rhino 里 InterpCurve 的插值方式，这些没有搬上来——它们要文件、要软件，不是方程。
② 所有"旋成体"都按三角网格实时重算，分辨率取到能看清纹路为止（双波纹盘约 4 万顶点），不追求加工级精度。
③ 六族各自独立，没有强行把它们塞进同一条公式——仓库里它们确实同根（都从蛋 / 双曲线来），但"同根"是叙述，不是可以互推的等式。
