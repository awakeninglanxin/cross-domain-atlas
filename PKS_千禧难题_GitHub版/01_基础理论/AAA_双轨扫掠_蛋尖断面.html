"双轨"到底是哪两条 不是我原先以为的两条等宽边界，而是：① 中心线（螺旋本身）+ ② 蛋尖轨—— 断面第 0 个点（那个尖）随扫掠走出来的轨迹。脚本里它写成 spline = msp.add_spline(egghead_points)，颜色单独给了 5 号。 所以「双轨」= 中心线 + 特征点轨，不是"左右两条边"。

两个容易看错的点 ① 这里的 N 不是主法线，是二阶导数方向（加速度方向）。两者一般不重合， 这决定了断面的"朝向"，也是各家脚本形状差异的来源之一。
② ψ 是线性增长，不是 t²。文件名写"阴阳-t平方"，但 set_default_psi() 里是 np.linspace(0, twist·t_length/2, num_t)——直的。t² 那一支要看别的版本 （…-t平方.py 系列），本页复原的是简化版。
本页与原脚本的差别 原脚本用 Rhino/ezdxf 输出样条线（中心线、蛋尖轨、若干断面），是"线框"； 本页把断面连成曲面以便看形体，另外保留了蛋尖轨与断面肋这两层线框。 数值上：zv 由"总高 H ÷ 总弧长"反推，d=1 归一，其余符号（sign / r / twist）原样保留。
