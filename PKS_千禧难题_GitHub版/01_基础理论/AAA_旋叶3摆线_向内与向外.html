中心线 = 三次谐波 + 七次谐波叠成的三叶形 × 指数放大 2t/π；断面 = aπ·sin(t)/t（半径 1/t 的螺线）

拖动旋转 · 滚轮缩放
方向 阴阳
扫掠面 中心线（三叶摆线） 叶尖轨（断面第 0 点）
这族"3 摆线"是什么 中心线是 1 次 + 7 次谐波、按 1/3 加权的叠加：
x = −(cos t + cos7t/3)·2^(t/π)·r
y = (sin t + sin7t/3)·2^(t/π)
z = t

⚠ 默认只走 2π/6（原脚本的 t_max），此时 7 次谐波只完成 1.17 个周期， 所以画面里是一个 S 弯的卷片，不是"三瓣"——这是公式本身的结果，不是画漏了。 想看多瓣，把上面「扫掠角」拉到 0.66π（= 2π/3），7 次谐波会走 2.3 个周期，叶形才展开。 另：断面是半径 1/t 的螺线（不是闭合管），扫出来本来就是"卷起的叶片"，不是圆管。 指数项 2^(t/π) 让每一转半径翻倍（对数螺旋），所以整体是向外张开的喇叭。
向内 / 向外 只是 r 的符号 脚本里叫 sign_spiral_dir（本页 r=±1），它只把 x 取反 ⇒ 整体镜像， 不是"往里缩"。真正的"向内"来自断面半径 aπ/t 随 t 递减（断面越走越小）。
