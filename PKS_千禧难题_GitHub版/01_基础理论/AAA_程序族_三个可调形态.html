② 拉瓦尔喷蛋族：等体积 × 八度蛋 原脚本生成 N 个八度蛋，第 i 个的 k = 2·2ⁱ/3、b = 5·2ⁱ/3——k/b 恒为 2/5，绝对尺度每段翻倍； 然后按 a_i 缩放，使每段截面积相等（脚本用 scipy.quad 数值积分）。 一串等体积蛋首尾相接，侧面看就是收缩—喉道—扩张的拉瓦尔喷管轮廓。
本页的近似 本页取 a_i = a₀ / 2ⁱ（面积 ∝ a²·尺度² ⇒ 等面积要求 a ∝ 1/尺度）， 是等体积的一阶近似，不是把 quad 的结果搬过来。 所以相邻段的"体积相等"会有几个百分点的偏差；要看严格等体积，得回原脚本跑。
③ 舒伯格锥面：R(θ, z) 的参数曲面 原脚本一行公式（a=161.8, b=100, c=0.5）：
R = π(1/a − 1/b) / [ (z − 1/a)(z − (1/b)·sin(cθ)e^{cθ}) + ((1/b)³ − (1/a)³)·c·cos²(cθ)·e^{cθ} / 3 ]
注意 a = 161.8 = 100φ，是黄金比的整数倍——这不是随手取的数。 面在 z = 1/a 与 z = (1/b)sin(cθ)e^{cθ} 两条线附近会发散， 本页把 |R| > 8 的点剔掉（原脚本没剔，靠 z 范围避开）。
④ 单弦律：倒数的占比 原脚本一族算的是 Lucas 数列 / 太阳数列的倒数，以及"等体积线"（lcm）。 核心是一个很朴素的观察：把 1/a, 1/b, 1/c… 归一到 100%，谁占多少—— 这是毕达哥拉斯单弦琴 l·f = 1 的离散版本：弦长与频率互为倒数。
