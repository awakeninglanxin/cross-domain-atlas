§1红箭头那条线，公式是怎么生成的

老师第二张截图里，右侧「剖面」浮窗的红色实线是 f0HexProf2D()（L13552）画的 pf.pr——子午线 / 母线，坐标是 (t, u)：纵轴 t = 轴向位置，横轴 u = 半径。 绿色虚线是内层 λ 缩放后的同形母线，水平蓝线是每一行的纬圈。左侧那个蛋形网格就是这条母线绕轴转出来的。

这个「蛋」在项目里一共有三种逐字等价或同源的写法，都在同一个 HTML 里：

位置名字公式 / 作用
L2704f2Egg极坐标闭合蛋曲线 r(φ)，画「蛋螺旋」的横截面
L3090f2EggProf母线 R(u) = √[1/(b−usinα)² − (ucosα)²]，绕轴旋成实体；注释明说与 C15/C19 逐字相同

f2Egg 的源码与它背后的二次方程

// AAA_PKS代码族_3D参数台.html  L2704（逐字抄，变量名未改）
function f2Egg(z0, ta, amp, nPts){
  var al=Math.atan(ta), sa=Math.sin(al), ca=Math.cos(al), out=[], i;
  for(i=0;i<=nPts;i++){
    var ph=TAU*i/nPts, sp=Math.sin(ph), cp=Math.cos(ph);
    var di=Math.sqrt(sp*sp+cp*cp*ca*ca);
    var ins=z0*z0-4*cp*sa/di, den=2*cp*sa;
    if(ins<0||Math.abs(den)<1e-6)continue;
    var rr=amp*(z0-Math.sqrt(ins))/den;
    out.push([rr*sp,rr*cp]);
  }
  return out;
}

把 rr = amp·(z0−√ins)/den 反解，它其实是下面这个二次方程的较小根。 这一步是我推的，不是源码注释里写的，所以做了数值自检：

cosφ·sinα·q² − z₀·q + 1/√(sin²φ + cos²φ·cos²α) = 0，  q = r/amp 自检：997 个 φ 上 max|左式| = 5.129 × 10⁻¹⁴ —— 推导无误

定义域闸：φ=0 处 ins = z₀² − 4k（k=tanα）。必须 > 0 才有实解； 参数台自己在 f2KB()（L2801）里用 k ≤ 0.96·b²/4 夹紧， 并注明「b² ≤ 4k 无实解 ⇒ 两侧分支变号 ⇒ 截面长出尖刺」。 这条闸在 §4 会变成关键证据。

§2为什么语义上能对上

关键不是「两个图都长得像蛋」，而是两个坐标系本来就是同一对物理量：

参数台剖面浮窗

横轴 u = 半径；纵轴 t = 轴向位置。
母线 u = R(t)，绕 u=0 的轴旋转成蛋。

(z, r) 相图

横轴 z = 轴向位置；纵轴 r = 半径。
即 (z, r) = (t, u)，只是坐标轴互换。

而且 Aizawa 极坐标化后（26_sec10.html L67–73）： ṙ = (z − b)·r、θ̇ ≡ d。所以 z − b 就是「离轴的径向偏移」： z > b 一侧半径指数发散、z < b 一侧指数收缩， z = b 是不增不减的中性面。这与「母线一侧鼓、一侧收，轴在 u=0」是同一个几何分工。 截图里那条红色竖虚线 z=b 穿过环的两个端点（分支 A / B），正是这个对应。

§4蛋形度到底该取多少：一条被定义域锁死的断崖曲线

判据本来是：如果「像蛋」只是撞脸，残差对 α 应该不敏感，也不该有内部极小值。 实测结果比这更硬——有效域内残差随 α 单调缓降，一越过 b²=4k 就断崖式跳升。 也就是说，最优点不是拟合「挑」出来的，而是被公式自己的定义域边界锁死的。 我把 α 从 5° 扫到 60°，每个值都自动对齐包围盒后算外包络 RMS：

三组数据的最优 α 全落在 30°–31°，而定义域临界 z₀²=4k 分别是 31.78° / 30.52° / 31.86°——最优点全在临界线内侧 0.5°–0.9° 处，一步都迈不过去。 再往右跨过临界，f2Egg 的 φ=0 处无实解、曲线退化出尖刺，残差立刻跳 3–5 倍 （参数台「标准蛋」默认 33.7° 正好落在失效区，RMS 0.21–0.24；那段锯齿不是物理，是公式失效）。

这一条最值得记下来

相图上下两端是尖的，而 f2Egg 只有在 b²=4k 的临界处才收出真尖点。 所以拟合不是随便挑了个好看的角度，而是被数据顶到了公式定义域的边界。 好处是形状对上了；代价是这个工作点数值病态——α 再大 1° 就整个失效， 不能拿它当稳定的解析边界用。

§6三条硬限制：为什么不能直接拿它当边界

#限制依据
1边界是 ODE 的不变集，不是代数曲线 蛋形是几何约束；相图那条线是 ṙ=(z−b)r 与 ż=… 的解轨道。 没有闭式解，只有积分出来的轨道。§5 的同族检验已把「两者同源」判掉。
2混沌态根本没有闭合边界 老师截图上写着「λ₁ ≈ 0（非混沌）· 准周期环面」「σr = 1.191 · 厚度不为零」。 只有准周期 / 周期窗口才有可拟合的薄环；页面默认 d=3.5 时 λ₁≈+0.09、DKY≈2.28， 是分形点云，不存在一条「边界线」可设。
3蛋形关于轴严格对称，Aizawa 不是 f2Egg 的 r(φ) 只依赖 cosφ ⇒ 关于轴镜像对称； 而 Aizawa 的 +0.1·z·x³ 破坏 SO(2) 对称，相图左右两支不对称。 7 参数拟合里那个 rot≈1.8°–2.5° 就是在补这个差值。

还有一层要提醒：这与上一个专题里那条「临界线是 Weil 泛函驻点、信息在二阶」的教训是同一类—— 形状相似不等于机制相同。蛋形能当「画图时的包络 / 初始猜测 / 视觉参照」， 不能当「推出 RH 或推出不变集的方程」。

§7可以直接抄走的转换公式

若只是想在相图上画一条蛋形包络（例如做视觉参照、给点云套一个外框），这是完整可用的写法：

① 取 q(φ) = 方程 cosφ·sinα·q² − z₀q + 1/√(sin²φ+cos²φ·cos²α) 的较小根
② 蛋形点 (x, y) = (q sinφ, q cosφ)，归一化到 [−1,1]²
③ 仿射到相图：z = zc + hz·x， r = rc + hr·y (zc, rc) = 数据包围盒中心，(hz, hr) = 半宽半高； α 取 30°–31°，且必须满足 tanα < z₀²/4
