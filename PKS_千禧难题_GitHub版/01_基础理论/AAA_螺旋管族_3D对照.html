螺旋管族 · 五种中心线 3D 对照

从 16_schauberger系数学与书籍与出dxf图的程序/DXF生成程序集/ 与 舒伯格公式/波纹盘代码演化/ 里 挑出的公式自包含、参数可调的五族中心线，按同一套参数实时生成管体。 拖动可旋转、滚轮缩放。

断面 圆管
这页画的是什么、不是什麼 是：五族中心线方程的可旋转管体，参数实时可调；断面可选 圆管 或 蛋尖断面（36 点，取自 E:/pythonProject/program/spline_points.csv， 就是原 py 里 spline_data_path 吃的那份样条），后者用 Frenet 标架沿中心线放样。
不是：完整的双轨扫掠（Rhino 的 AddSweep2：一根中心线 + 两条边界轨 + 若干断面）。 这里只有一根中心线 + 一条断面，所以是"单轨 + 真断面"—— 断面形状对了，但那条"第二边界轨"带来的扭转/收放没有。 旋叶、斜流泵那几族还用到外部样条与干涉检查，仍需回 Rhino 跑。
注意：sin/t 那一族的中心线在半径→0 处切线剧变，Frenet 标架会退化（管子会断）， 所以它固定用等圆管；这不是偷懒，是这条曲线本身的奇点。

为什么挑这五个 判据是「公式自包含 + 参数少」：不依赖外部样条数据（spline_data_path）、不依赖 Rhino 的扫掠 API， 一条参数方程就能画出来。DXF 程序集里另有一批「双轨扫掠 + 多断面 + 阴阳 t²」的脚本（旋叶、斜流泵、花洒水龙头等）， 它们的断面由外部样条给出，搬过来只能得到半成品，所以没有纳入。
