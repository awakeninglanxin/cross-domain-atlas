公式、外网出处与证据分级（A 本页可复算 / B 文献 / C 工程类比）

建模假设（C 级·工程类比）：把本页外鞘面 ρe(z) 当作曲速泡壁 Rw(z)=ρe(z)·sc；壁厚 Δ(z)=σw/√(1+(dρe/dz)²)， σw=SIG 是本页软壁过渡宽度（场被鞘面约束的那个 tanh 宽度，默认 2×10⁻³×s， 随相似律锁定自动缩放）——斜壁上沿法向看会投影变薄，尖端最薄。 形状函数 f=F(ξ)、ξ=ρ−Rw(z)、F=½(1−tanh(ξ/Δ))；τ 按钮把两端按 √(1−((τ−u)/τ)²) 收口。呼吸时 λ(t)、R 实时变 ⇒ 泡壁几何随之变（每 4 帧重算）。 这是几何建模选择，不是对任何实物飞碟的物理实测。

度规（B 级文献）：随动系 ds² = −dt² + (dz − βf·dt)² + dx² + dy² + ρ²dφ² —— Alcubierre 1994（Class. Quantum Grav. 11, L73）；Natário 2001 给出零膨胀保体积的等价形式。 f=1 泡内（平直，船不动）、f=0 泡外（平直）、壁上过渡；β=v/c。

能量密度（A 级·本页数值验证）： ρ_E = −(c⁴β²/32πG)[(∂_x f)² + (∂_y f)²] = −(c⁴β²/32πG)F′² 轴对称下第二式精确成立（闭式 ∫(∂_y f)²dφ = πF′²，无方位角平均近似）。 恒负 ⇒ 违反弱 / 强 / 主导能量条件 ⇒ 需要奇异物质。

膨胀场（York 时）：θ = −∂_iβ^i = βF′R_w′ 文献符号：后端扩张 > 0、前端收缩 < 0，峰 |θ| = β|F′||R_w′|。

动量密度：j_z = −(c³β/16πG)(F″ + F′/ρ)； 净动量恒等式 ∫j_z dV = −(c³β/8G)[ρF′]₀^∞ = 0 对任意轴对称泡精确成立 ⇒ 曲速泡本身净动量为零、不产生推力。

总能量：E = −(c⁴β²/16G)∫∫F′²ρ dρ dz。

量子不等式（B 级文献）：Pfenning & Ford 1997（CQG 14, 1743） ⇒ 壁厚须压到数百普朗克长度；球形薄壁标度 E = −(c⁴/G)β²R²/(24Δ)（R=100 m、Δ=1 m、β=1 ⇒ −0.282 M☉， 即原文 a quarter solar mass，可当场复算）。van den Broeck 1999 可把需求压到约 1 M☉。

推进边界（B 级文献）：Bobrick & Martire 2021（arXiv:2102.06824） 证明亚光速曲速泡 = 惯性运动的物质壳，本身不推进； Bondi–Sachs 转向定律（arXiv:2606.22531）：渐进平广驱动器只能靠辐射改变 Bondi 四动量 ⇒ 真正转向 / 加速必须向外辐射。Finazzi et al. 2009：β>2 视界量子不稳定性。

分级速查：A = 本页可复算的恒等式 / 标度 （ρ_E 轴对称闭式、P_z ≡ 0、E ∝ β²R²/Δ）； B = 文献标准结果（度规、QI、Natário、Bobrick–Martire、Bondi–Sachs、van den Broeck）； C = 工程类比假设（外鞘→泡壁映射、实物飞碟）。
