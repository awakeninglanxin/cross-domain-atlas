Ⅰ原理总览 · SEG 凭什么"飞"

这一页把元宝那场对话里散在七个仿真中的物理收敛成一条链。先给结论：它不需要"喷出什么"， 它需要的是把介质挡在外面——挡住的是空间介质（koilon / 星际氢 / 大气）， 介质撞在磁边界上被偏转 180°，动量反作用就是推力。这条机制有现成的工程名字：磁帆（Magsail）， Zubrin 拿过 NASA NIAC 资助做过完整研究。

一、链条四环（每一环都有算式，也都有判据）

1超导环建立磁边界

磁压与来流动压相等的那个面，就是"帆面"。它不在硬件上，在场里 —— 这是磁帆唯一值钱的地方。

B²/2μ₀ = ρV² ⟹ Rmp = R·(B₀/√(2μ₀ρV²))1/3
2反射介质，而不是收集它

收集式（ramscoop）必亏：把介质加速到超过自身速度才净赚，而收进来的介质本来就带着相对动能。

T = 2ρ·Aeff·V² ｜ 收集式 T/D = u/V < 1
3涡环卷吸放大截面

尾迹卷成涡环，把周围介质一并卷进来 —— 有效截面比几何截面大，实测卷吸占环体积 30–40%。

Aeff = πRmp²·(1+Ce)·ηform
4非对称才给净推力

对称的闭环循环只给稳定，不给推力；把上下（或两极）的动量差打开，净推力才出现。

Fnet ∝ ε（场非对称度）｜ ε = 0 ⟹ F⊥ ≡ 0

二、三个自检闸门（原件自己算的，不是形容词）

1越界 = 0

统计有多少采样点跑出了外鞘。一旦 > 0，「再循环」这条几何前提就不成立了 —— 不是画得难看，是定义域错了。

越界 = 0 ⟺ 轨道 ⊆ 壳体
2闭合残差 → 0

走完整圈回到起点的距离。这是「闭合」唯一可验算的判据：残差大 = 环没闭上 = 每绕一圈漏一点，「再循环」就退化成「螺旋外泄」。

|P(T) − P(0)| → 0
3三条恒等式

尖/钝比应与 kE(λ) 相等；k·b−1 与 z₀−b 应恒为 0。 原件在这三处都打了 ✓ —— 它们不是可调参数，是几何自洽的校验位。

尖/钝比 ≡ kE(λ) ｜ k·b−1 = 0 ｜ z₀−b = 0

🔑 黄金比在这里到底干什么：k = λ/φ、b = 1 + λ(φ−1)。 φ 的作用不是神秘学，是最不容易被共振锁住的无理数：呼吸周期与绕行周期之比取 φ 时， 轨道不会在几次呼吸之后就自我重合 —— 一旦自我重合，「再循环」就退化成一个普通周期轨道， 再没有「越舍越有」可言。 这一条是形态层的选择（C 级），不是从方程里解出来的。

三、闭合给稳定，不对称才给推力

蛋外鞘本身只给稳定，不给推力：闭合环在外鞘内上下对称地绕，两极动量抵消，净推力严格为 0。 要它推进，必须把「尖/钝比」从 1 推开 —— 尖端收、钝端张，两极喷流的动量不再抵消。 这就是 Ⅰ 页 ε 的几何版本 —— Ⅵ 页（原粒子 3D，已撤）里那条「蛋形不对称度 e」说的也是它，现在由本页的尖 / 钝比直接量。 三张图说的是同一件事，只是用了三种画法：唯象的 ε、流体的 e、几何的尖/钝比。

⚠️ 别读成「太极生推力」。 这张图能给的是： 几何上，一个「闭合 + 不对称」的再循环结构必然带净动量输出。 它不能给的是输出比投入多。后者要能量账闭合 —— 见 Ⅵ（点火时序）与 《SEG 是聚变推进器吗》。 这两件事混谈，是本项目踩过最大的叙述级错误。

一、为什么 d 恰好是「每循环圈数」—— 一行可验算

Aizawa 前两式：ẋ = (z−b)·x − d·y，ẏ = d·x + (z−b)·y。令 u = x + i·y，则

du/dt = [(z − b) + i·d]·u ⟹ dr/dt = (z − b)·r ， dθ/dt ≡ d

方位角速度恒等于 d，与 x、y、z 完全无关。 一行就是全部：d 不是一个「缠绕密度」旋钮， 它是方程的等变速度。所以取 10 个相位差 36° 的初值，它们的方位角差 永远精确保持 36°；编号相距 5 的一对（k 与 k+5）永远精确对望 180°。 粗丝取 0、1、2，其余 7 根作细，则 0↔5、1↔6、2↔7 —— 三根粗丝的对面全是细丝，这不是摆出来的，是定理。

🔴 破坏旋转对称的只有 z 方程里的 f·z·x³（含 cos³θ，不是旋转不变量）。 它只让十丝的 (r, z) 失相，方位角一点不受影响。所以原件给两种画法： 严格十丝（一条真轨道绕 z 刚转 36°k 画 10 份，方位精确、视觉齐整）与 独立积分（真跑 10 条轨道，真混沌，(r, z) 如实失相、看得见交织）。 默认 f = 0.1：实测 6000 步后方位角偏离 < 1e-4 度（数值误差量级）， 而 (r, z) 约 50 步到 8%、约 1000 步饱和到约 80%。

四、α 那条：R₀ : R_c = 1 : 137.036 是定义式的另一种写法

这一节跟 1680 无关，但它是同一类"数字撞上了"的算例，放在一起看最省事。 两把尺：R_c = ħ/(m_e c) 是约化康普顿波长（这个质量能造出多长的波，量子尺度的定义量，不是任何物体的半径）； R₀ = e²/(4πε₀ m_e c²) 是经典电子半径（把电子当球、令静电自能 = m_e c² 时的半径，一个记账半径，从未被测到）。

R₀ / R_c = [e²/(4πε₀ m_e c²)] ÷ [ħ/(m_e c)] = e²/(4πε₀ ħ c) ≡ α

同一个 e²、同一个 m_e，比值必然把它们约掉，只剩 α。 所以"破解这个比值的意义"与"破解 α 为什么等于 1/137.036"是同一个问题， 前者不可能比后者多出任何信息 —— 这不是发现，是恒等式的换写法。

① 位阶越"负"，对应越虚 —— 但位阶 0 现在有一格例外。 位阶 0 那一行除「现代物理侧」外几乎全是比附：因为"未分"只能被否定地描述 （无极 / Ain / ἄπειρον / śūnya 全是否定式命名）。否定式命名彼此必然长得像，这是语法造成的相似，不是内容相同。 唯一的例外之所以能标「同构」，是因为它能落到一个数：普朗克长度 1.616×10⁻³⁵ m —— 它不是"什么都没有"，而是"还能谈长度"的下限，与"未分化"（有本体、无区分）同构； 一旦把"未分"读成"零 / 空无"，这一格立刻退回比附。
② 位阶 2 是最硬的一格。阴阳 ↔ 正反旋站得住，不是因为"都是两个"，而是两侧能给出同一个生成规则（见第四节那条定理）； anu 的正 / 负就是把这一格落到实物上的候选 —— 判据同一条：两者互为镜像、反向旋转，只差一个手性。
③ 位阶 5 的"八"要分两类。八卦是 3 条独立二值轴（2³，穷尽等权）； 埃及八柱神是 4 个属性 × 固定性别对（4×2）。数一样，生成式不一样 ⟹ 只能叫同构，不能叫"同一个东西"。
2026-10-31 四格改判 —— 位阶不是尺度序，是生成序
普朗克尺度 ⟹ 量子本体，在位阶 0（即 koilon 这层泡膜）； koilon 本体内部的第一层结构 = 黄金极限蛋外鞘（太极式再循环），在位阶 1； anu 在位阶 2 —— 因为 anu 有 positive / negative 互为镜像、反向旋转； 位阶 5 原来的"五种相态：不成立"换成 anu 的 d = 5 ⟺ 五种柏拉图立体。
🔴 由此必须钉住一条读法：位阶 = 分化层数（生成序），不是大小序。 anu 的尺寸最小，却排位阶 2；蛋外鞘比 anu 大，却排位阶 1。 原因是"一"只需要自返闭合（蛋外鞘的太极式再循环本身就是一条首尾相接的闭合回路，不需要第二个东西）， 而 anu 必须成对才成立（正旋 / 反旋互为镜像）—— 一对就已经是"二"了。 拿尺子去读这张表，这四格会全读反。
位阶 5 那一格的原文底本（Besant & Leadbeater《Occult Chemistry》）
该书图 11「THE PLATONIC SOLIDS」—— 本扫描版 PDF 第 34 页（共 448 页）。 版面上半是手绘的五种正多面体，逐个标注 I 正四 · II 正六 · III 正八 · IV 正二十 · V 正十二面体 （正十二面体在右下角），旁边另附几幅互相穿插（interlaced）的复合体； 版面下半是五种立体的剪影与面数表：Fig 1–5 = 4 / 6 / 8 / 12 / 20 面， 并写「In each solid, lines, angles and surfaces are equal」。
正文写：「除氢、氧、氮外，所有化学元素的构造方式似乎都与众所周知的柏拉图立体相似 —— 四面体、立方体、八面体、十二面体和二十面体」， 并明说「没有发现任何暗示十二面体的元素」。
⚠️ 这两句不矛盾，必须分清：十二面体是画在图里的（V）， 「没有发现」说的是元素里找不到十二面体外形的实例。 把"图上没画"与"实测没有"混成一句，是这一格最容易犯的错。
⚠️ 但同一本书对元素外形的分类是七组：尖刺 · 哑铃 · 四面体 · 立方体 · 八面体 · 交叉杆 · 星形。 七组里只有三个是柏拉图体，尖刺 / 哑铃 / 交叉杆 / 星形都不是。 所以「五种柏拉图立体」在 OC 里是理论序列（且实际只指认出四种），不是实测分类。 本页把它挂在位阶 5，依据是两侧"五"的来源：一侧是 d = 5 这一档的圈数（选参）， 一侧是凸正多面体恰好五种（欧几里得《几何原本》卷十三已证的穷尽性）。 一个是选参、一个是定理 ⟹ 只标同构，不标"同一个东西"； 要升级成机制同一，得先给出「5 圈 ⟹ 5 个外接正多面体」的生成式，目前没有。

二、核心术语十二组：谁在说同一件事

每一组都写两行：能对到哪里，以及对不上在哪里。只写前一行的是宣传，不是考据。

组能对到哪里对不上在哪里
气 / prāṇa / pneuma / spiritus / ruaḥ / aether / koilon 气 ↔ πνεῦμα ↔ spiritus ↔ ruaḥ：四者词根都是风 / 呼吸，希腊化时期经阿拉伯—拉丁转译，是真实链条 气 ↔ aether 是历史上最贵的误配：aether 是 19 世纪力学介质（有弹性模量，可被迈克耳孙–莫雷实验否掉）； 气是过程性概念，从没有"以太风"这种可测对象。气 ↔ prāṇa 功能像，但 prāṇa 属数论五种风、绑三德，解剖学不兼容
道 / Logos / Dharma / Ṛta / Ma'at 四者都指使万物各安其位的那个秩序，且都有实践面：顺之则吉、逆之则凶 约翰福音的 Logos 会"成了肉身"（1:14），是位格；道"生而不有，为而不恃"，非位格。 这条差异比所有相似点都重要，不许抹平

阴阳 / Puruṣa–Prakṛti / Śiva–Śakti / 有限–无限 都是"一对互补原理撑起世界" 只有阴阳强调互含（阴中有阳、阳中有阴）；数论是两种实体不互转；Śiva–Śakti 是位格与能力； 有限–无限是形式与质料。互含这一条是阴阳独有的，别送人

天 / Dyaus / Anu / Caelum 都是"上面那个" 苏美尔 Anu（𒀭，天空之神）与梵语 aṇu（极微 / 原子）毫无词源关系。 神智学的 anu 取自后者 ⟹ 本项目天天写 anu，必须分清（见第三节第一行）

四、三条判断规则（用这张表而不被骗）

1同数 ≠ 同构

"8"在三处出现：八卦、八柱神、八风塔。只有八卦能给出 2³ 的穷尽等权生成式，另外两个是"恰好有八个"。 判据就一句：写不写得出生成式。写不出，只是计数巧合。

2同形 ≠ 同源

形状相似只有两条出路：要么给出传播证据（有译本、有商路、有中间文本），要么老实标"同构"。 默认不许假定传播。佛教四大 vs 希腊四根就是典型：形态极像，传播链查了两百年没定论。

3同名 ≠ 同指

先查词源，再配概念。Chaos、anu、aether、五行 四个反例全部栽在这一步 —— 前面三个都是中文译名撞车， 最后一个是被英文译名撞车。

4可验性分级

凡能落到一个数或一个不等式上的对应，强度高于只有修辞的对应。 「阴阳 ↔ 正反旋」能落到 dθ/dt ≡ ±d 这个符号上；「位阶 0 ↔ 量子本体」能落到一个尺度 （普朗克长度 1.616×10⁻³⁵ m）—— 但尺度只标定层位，不担保同一； 「太极 ↔ 普罗提诺的 ἕν」落不到任何数：一个含内在二重性，一个严格无差别。

那条"一行可验算"的定理

为什么"阴阳 ↔ 正反旋"这一格能标"同构"而不是"比附"？因为它有生成式，不是比喻：

du/dt = [(z − b) + i·d]·u  ⟹  dθ/dt ≡ d

极角速度恒等于常数 d，与 x, y, z 全都无关。所以：d = +1 与 d = −1 给出两支严格互为镜像的解； 36° 均分、180° 对望这些"看起来像摆拍"的对称，是定理的推论，不是画图时的安排。 这就是"两种极性"在可测层面的确切含义 —— 旋向，不是电荷符号。
对照：阴阳没有任何一个可测的量能写成这样的式子。所以 —— 结构同构 ✓，机制同一 ✗。

五、回指本项目：四条对应，各自能站多稳

对应强度理由怎么用
