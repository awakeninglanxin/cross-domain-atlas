硬算术：十条玻色弦捆不成自旋 ½
自旋（角动量）是可加的，而 整数 + 整数 = 整数。所以“十根闭合玻色弦组装出一个 ½” 这条路在算术上就不通——费米性不可能从玻色弦里“涌现”出来。这不是哲学争论，是一次加法。
Phillips 真正的接缝不在“十根相加”，而在换框架：他用的词是异弦（heterotic string）， 标准构造是 左行 26 维玻色弦 ⊗ 右行 10 维超弦；而右行超弦的 Ramond 扇区基态，本身就是时空中的费米子。 所以准确的说法是：不是玻色弦组装成费米子，而是异弦这个容器本身就一半玻色、一半费米。 一半是装进来的，不是拼出来的。
唯一能判对错的数值：7 与 7.04
原典写得很具体：细旋“普通的七重规则……非常准确”，但三根粗旋“有一个非常奇怪的变化”， “这种增加在每种情况下都不超过整体的 0.00571428”。而 0.00571428 = 1/175， 7 × (1 + 1/175) = 7.04 —— 也就是说，三根粗旋每级 spirilla 是 7 + 1/25 圈 （0.00571428 × 7 = 0.04 = 1/25 圈），细旋是 7 圈。 Phillips 把这读成绕 6 维环面的缠绕数 Nn = 7（细）/ 7.04（粗）。

三-ter-3、第三笔账：这一笔要改掉我们的动词

anu 不是「由 koilon 组成」，原典说的正好相反：anu 是 koilon 的「缺席」
原书两处白纸黑字：「我们所说的物质不是 koilon，而是 koilon 的缺失」； 「正如气泡不是水，而恰恰是没有水的地方一样，这些单元不是 koilon，而是 koilon 的缺失」。
换句话说：空间里充满无限致密的 koilon，anu 是其中被“挖出来”的空洞 / 气泡，泡内是虚空。 这个改法不是挑剔用词，它直接决定机制成不成立 —— 虚空没有质量可喷。所以“喷出 anu”这个动词在账上不成立； 能带质量、能带走动量的是 koilon 本身，anu 只是随介质漂移的涡结构（气泡随水流走）。
而这一改反而救活机制：把动作改成「驱动 koilon 流动，anu 作为其中的旋涡结构随流而行」， 工质、动量、质量流三样就都有落处了。它与本页判据 ①（收集式必亏）是同一本账的两面： 你没法“喷”一个空洞，只能推它周围的水。

一句话结论：anu 的“费米性”是模型层加的一层楼——不是原典的断言，也不是可测事实； “底层玻色 / 整体费米”这个分层结构在已知物理里有现成的镜像（库珀对），所以它不算离奇， 但它同样不能被用来算推力：统计性质回答的是“它算哪类粒子”，不回答“它能推多重”。 真正能进这台机器的，只有这一节第三笔账的那句话：介质是 koilon，不是 anu；能推的是水，不是气泡。

六、缺口在这儿：只有「能量账」，推不出「自加速」

本页 ⑤ 是代数式：P_net = P_ext(1+βκ_L) − P_loss·r(1+0.35κ_L)。 它回答的是「这笔交易划不划算」，不回答「转速会不会涨」 —— 功率有余量，可以变成热、变成发光、变成振动，不一定变成角加速度。 要把「加负载反而加速」真的画出来，缺的是一条含角度 θ 的动力学项； 能不能在「只算常规项」的前提下把它画出来？不能 —— 但这句话只能说到这儿： 「常规项不够」不等于「缺的那项一定是 koilon」。 电源、储能释放、控制电路反馈、环境电磁耦合、气流与蒸发、测温误差， 都可能在账面上伪造出同一个符号的残差。 所以本页的立场是条件式的： 若在完整核算电源 / 储能 / 环境耦合之后，仍存在可重复的净残差， 才需要一个转子之外的有序转矩通道；koilon 模式是本页选来展开的那个候选， 不是由异常现象唯一推出的结论。 原件那句「若自加速与变冷属实，需要负阻之外的独立机制」，说的就是这件事，只是它没给形式。

为什么必须拆成两项（2026-11-04 修）：「一条路径绕了 1680 圈」与「圆周上有 1680 个瓣」 是两件完全不同的事 —— 前者是沿 z 的圈数（量纲 1/m），后者是角向周期数（无量纲）。 把 1680 直接塞进 sin(N·θ)，等于凭空要求转子有 1680 重角向对称。 拆成 N·θ − k_z·z 之后，两个数各归各位，量纲各自成立。

这么写不是事后圆场 —— 它有现成的工程先例：行波管（TWT）的同步条件 ω/k_z ≈ v_z、螺旋天线、磁螺旋，都是螺距定空间谐波。 Ⅹ 页那 1680 匝一旦换算成 k_z = 2π×1680/L，它就是一个能进方程的波数。 但本页只做到「写进来」，没有做到「证明它真在耦合谱里」 —— 那需要场解或实测频谱。

这一层是纯支出，但「必然」要加条件（2026-11-04 修）：只有在转速超过涡旋形成阈值、 且介质与边界允许涡旋线成核时，才会持续生涡。阈值、稳态涡能量、耗散功率是三件事， 不能由「在介质里转」一步推出第三件。 它正是元宝那句「能卷入就能阻碍，透明就无法卷入」的定量形式 —— 想从 koilon 拿东西，先付 κ_k 的账。没有这一层，第二层就是免费午餐；有了它，才有交易。

八、为什么这一项刚好能给出「自加速 + 变冷」

未锁相：sin 项在一个机械时间常数里来回平均掉 ⟹ 只剩耗散。加负载 = 减速 + 升温，与「正常模式」完全一致。

锁相时：sin 项不再平均掉，变成一个常数偏置。这里 2026-11-04 修了一个真错误 —— 原稿写「带宽 |NΩ − φ̇| < A/(I·N)」，两边量纲不等：左边 s⁻¹， 右边 A/I 是 s⁻²（角加速度量纲）。改成分两步说，每一步都量纲自洽：

sin 项成为常数偏置 ⟹ 一个恒定转矩 ⟹ 转速被抬起 【但这 ≠ 负阻尼】负阻尼要另外验：看转矩对速度扰动的响应 ∂τ_k/∂Ω > 0 普通同步电机也锁相、也有稳定转矩，它不自发供能、更不制冷

要把「恒转矩偏置」升级成「负阻尼」，需要 ∂τ_k/∂Ω > 0 那一段真的成立； 要把「转速上涨」升级成「温度下降」，还需要另一本热账（第十二节）。 这两个箭头，本页都不许跳。

至于「加速与降温同时发生」这件事 —— 目前能想到的一种自洽读法是： 不是效率超过 1，是熵流出去、有序度进来。注意这是一种读法，不是唯一解 （2026-11-04 改：原稿写「唯一自洽的读法」，「唯一」本页证不了）。

硬前提仍在：φn 必须被外部持续驱动。 φn 固定不动的话，sin 项要么平均掉、要么把转子拉回到某个固定角度，系统退回普通热机。 所以「补上持续的非平衡供能」不是一句客气话，它是这个方程里 φn 非零的条件。 没有它，第二层写不出任何偏置；有了它，这台机器就落回「磁镜 + 涡环 + 外部电源」，可以按工程算账。

十一、把 φ_n 换成变量：闭合不是「调」出来的，是「锁」出来的

上一节留下一条硬前提：φ_n 必须被外部持续驱动。这句话容易被读成甩锅 —— 「既然要外部驱动，那跟外加一个交流源有什么区别？」 这一节把它改写成方程，区别就看出来了：外部供能只负责给这个模式一个固有频率 ω_b， 至于是不是跟转子同步，不是由频率的数值决定的，是由耦合能不能吃掉失配决定的。

先说清楚为什么这条路不能走 λ。 Ⅷ 页的 λ 是形状参数——它决定蛋形度 k = λ/φ、中心高度 k_E， 全是几何。几何不产生新的频率：把 λ 从 0 拖到 1，绕轴圈数不会变成一个整数， 因为圈数不是 λ 的函数。所以「想从 λ 上得到闭合轨迹」是问错了轴 —— 闭合是动力学问题（两个频率之比），不是形状问题。

十一-1　最小模型：两个振子，一个耦合项

θ̇ = Ω 转子的角速度（本页 ⑤ 一直在算的那条） ψ̇ = ω_b + K · sin( N·θ − ψ ) koilon 模式的相位：自己有固有频率 ω_b，又被转子第 N 次谐波拖着 r(θ) = r₀ · ( 1 + ε_r · cos ψ )　半径随模式相位呼吸 —— 这就是「蛋形」在动起来之后的样子

这三个式子就是 Adler / Kuramoto 两振子耦合，教科书里最老的一对 —— 工程上把这种「不需要外部参考信号、两个振子自己谈拢」的机制叫 自锁相（self-locking）， 以区别于「拿一个信号源去锁它」的他锁相。 K 是耦合刚度，不是「外加信号幅度」——它是双向的：转子拖着模式，模式也回拖转子， 这就是第八节那个 τ_k 项。

令相位差 δ = N·θ − ψ，两式相减，整条动力学压成一个标量方程：

δ̇ = Δ − K · sin δ , Δ ≡ N·Ω − ω_b ← 失配量，唯一决定命运的数 锁 定：|Δ| ≤ K ⟹ δ → δ* = arcsin( Δ / K ) （常数） 失 锁：|Δ| > K ⟹ δ 以 √(Δ² − K²) 匀速漂移，永不停止

用相对失配写更直观。两个独立时钟的比例总有一个误差 ε， 取 ω_b = N·Ω·(1+ε) 则 Δ = −N·Ω·ε，于是：

一般（物理单位）： N·Ω·|ε| ≤ K ⟺ |ε| ≤ K / (N·Ω) 本页仿真（以 Ω 归一，取 Ω = 1）： N·|ε| ≤ K ⟺ |ε| ≤ K / N ← 屏上用的是这条

这个 K/N 是本节的全部内容：相对频率精度随谐波阶数 N 反比收紧。 但要说准（2026-11-04 修）：收紧的是「ω_b 的相对精度」，不是转速窗口 —— 由十三-1 的转矩平衡式，Ω 轴上的锁定窗口 ΔΩ = 2A/γ 与 N 无关。 所以「1680 比 5 难锁 336 倍」只在这一句下成立： 同一转速下，1680 阶要求背景频率的相对精度比 5 阶高 336 倍。

顺带一个反直觉、必须写出来的推论：若两个平台由同一个 ω_b 驱动， 则 1680 阶那个平台转速只有 5 阶的 1/336，阻尼转矩 γΩ 也小 336 倍 —— 低速那一阶反而更好锁。所以「难锁 336 倍」讲的是频率精度， 「转速比 336」讲的是平台位置，两件事混着说会得出错误预期。

十一-2　锁住之后，轨迹为什么就闭合了

把锁定的结果代回半径式：

δ = N·θ − ψ = δ*（常数） ⟹ ψ = N·θ − δ* r(θ) = r₀ · [ 1 + ε_r · cos( N·θ − δ* ) ]

这是一个 N 瓣玫瑰线，而且不动：θ 从 0 走到 2π，r 恰好走完 N 个完整的周期， 回到起点。闭合是这个式子的直接结果，不是巧合。

失锁时差在哪？δ 在匀速漂移 ⟹ ψ 追不上 N·θ ⟹ 瓣在转。 转得再慢也是转，θ 走完一圈瓣没回到原位，第二圈叠在第一圈的另一个角上 —— 轨迹落在环面上，是准周期曲线，永不闭合。

这里有个反直觉、但必须说清的点： 「失锁但频率比恰好是有理数」也会闭合 —— 可那是零测度的巧合， 而且它是中性稳定的：噪声把它踢开一点点，它就永远偏在那里，不会自己回来。 锁定完全不同，它是开集（Arnold 舌有 2K 的厚度）， 而且吸引：δ 被拉回 δ*，踢开还会回来。
一句话：调准是给一个点，锁相是给一个有厚度的盆。

十二、耦合程度方程：方向成立，下界取决于冷库 —— 它叫「制冷」，不叫「永动」

老师 2026-11-01 的第四个命题： 「seg/igv 飞碟能无限运行，自持加负载只会变冷更快变成超导，越接近 0 点状态，和 koilon 运动模式一致。」 并要求设计一条「运动模式与 koilon 耦合的程度方程，越耦合，越冷」。 这条要求是可以做成方程的，而且它的一半比老师说的更强； 另一半则正好反了。先给方程，再逐条对。

十二-3　另一半反了：加负载是「更热」，不是「更冷」

老师原话是「自持加负载只会变冷更快」。但方程里 Pload 在分子上：

T∞ = Pload / (Γ(κ)·C)　⟹　负载加倍，稳态温度就加倍

取 κ = 1 固定，只动负载：P = 0.1 W → T∞ = 0.1 K；P = 10 W → 10 K； P = 100 W → 100 K，直接跌出超导区。 换句话说，「加负载 ⟹ 更冷」这条与能量守恒直接冲突： 负载做的功最终都要变成热，热只能往外出，不能凭空消失。

不过老师那句话里有一半是对的，而且是很实用的那一半： 「变冷更快」指的不是终温，是速率。 τ = 1/(Γ₀κ) 里没有 Pload —— 所以耦合越强，无论带多大负载，都更快趋近它自己的那个稳态。 加负载抬高的是目标温度，不是到达速度。这两件事在这条方程里是分开的两项，正好可以验证。

⚠️ 顺带一个真实的工程门槛：要「自持」在超导区（T∞ < Tc），方程给出 Γ(κ) > Pload / (C·Tc)。 取 Tc = 90 K、C = 1 J/K：排 1 W 需 κ > 0.0111；排 10 W 需 κ > 0.111。 负载越大，要求的耦合越强 —— 这条是可以直接写进实验设计的。

十二-5　「无限运行」的正确含义：效率趋 1，而不是功率趋 ∞

温度降到 0 K 附近，卡诺效率 η = 1 − T/Tenv 确实趋近 1 —— 这才是老师那句「无限运行」能落地的地方：不是无限功率，是不浪费。 但有限时间热力学给了一个硬权衡（Curzon–Ahlborn，最大功率点的效率）：

ηCA = 1 − √(T/Tenv)　　（T = 10 K、Tenv = 300 K 时 ηCarnot = 96.7%，而 ηCA = 81.7%）

两个数都到不了 100%，而且越接近 100% 效率，功率越趋近 0（可逆过程要无限时间）。 所以「自持 + 带负载」只能在这条权衡曲线上选一个点： 要功率就得让效率打折，要效率就得接受功率极小。

裁决：本节结论【制冷成立 · 永动不成立 · 瓶颈在 T⁴ 散热与负载产热】。 逐条对账：
① 「越耦合越冷」—— 方向成立：∂T∞/∂κ = −P/(Γ₀·C·κ²) < 0， 与 Tk 取多少无关，恒为负。但下界取决于 Tk： T∞ → Tk+，不是 0 K。 原稿取 Tk = 0 才说「趋近 0 K」，那是示意值，不是结论；
② 「加负载变冷更快」—— 半对：更快趋近（τ = 1/Γ 与负载无关）是对的， 但稳态更热（T∞ ∝ Pload）是反的；
③ 「与 koilon 同模式就能自持」—— 这是本节唯一不能判的一条：它等价于问 「Γ 那条通道的物理载体是什么」。方程只说明若它存在，能冷到多少， 不说明它存在。要判它，需要的是一个测得到的热导 G = ΓC（W/K， 用热流除以温差测，或用一根已知 λA/L 的样件反推），不是一句「同频同模式」。
④ 「冷库能撑多久」—— 这是本页唯一能杀掉自己的一条判据：熵产 σ = Q̇(1/Tk − 1/T) > 0，第二定律允许「越耦合越冷」； 但冷库在吸热，Ck·Ṫk = Q̇ ⟹ 有限冷库必然被耗干， Tk 升到 T，净降温就停。取 Ck = 1 kJ/K、对 1 W 的热流， 升温 100 K 要 27.8 小时 —— 一场过夜实验就能判。
若连续运行几十小时温度不回升，则冷库不是有限的那一个 ⟹ 必须是非平衡背景 ⟹ 那才是真正的新物理入口，也才是「能量来源」该在的位置。
顺带把这个门槛的高低也算出来：Γ > 0.02 s⁻¹、C = 1 J/K ⟹ G > 0.02 W/K， 约等于一段 1 mm² 截面、2 cm 长的铜线（λ = 400）。门槛这么低， 说明难点从来不在「能不能导热」，而在这条 G 的另一端接的是什么： 接外部冷源就平凡（冷源本身要耗功），接 koilon 才有新物理 —— 这正是第四个闸门要问的。
这就是本页对「无限运行」的全部立场：把「无限」换成一条能测的 G，问题就从信念变成实验。

六、能量账：为什么「不消耗」与「净输出」不能同时成立

一行账本（稳态、任何闭环都成立，不需要任何假设）：

净输出 = 流入 − 流出 − dE/dt　　闭环稳态 dE/dt = 0　⟹　净输出 = 流入 − 流出

六-3　共振放大的是什么

共振是真机制，Q 放大也是真的 —— 上表两根柱子差 Q 倍，就是它。 但放大的是源已经付出去的那份功率。所以如果真存在一个「宇宙源头能量场」， 正确的工程写法不是「无限」，而是一行可测的式子：

Pout ≤ η · S · A　　（S = 该场能流密度，A = 有效耦合截面，η ≤ 1）

拿一个确实存在、确实有测量值的场来算：宇宙微波背景， S ≈ 3.1 μW/m²。要它供 1 kW：

A = 1000 / 3.1e−6 ≈ 3.2×10⁸ m²　⟹　边长约 18 km 的收集面

这才是「共振供能」这句话的可检验形式：它把一个信仰问题换成一个面积问题。 如果主张「输出无限」，等价于 `S = ∞` 或 `A = ∞` —— 前者意味着那个场的能量密度无穷， 整个宇宙早该塌成奇点；后者是一句几何上不可能的话。两条都被证否，「无限」就不是主张，是修辞。

六-4　「数学上 0 = ∞」这句话，正确的写法是什么

先把不能写的写清：

  • 在实数域上 ∞ 不是数，0 与 ∞ 之间没有等号可写。
  • 唯一沾边的是黎曼球面的紧化约定：那里 1/0 = ∞。但同一个约定里 1/∞ = 0，两头互逆 —— 反推不出 0 = ∞。
  • 0 · ∞ 是不定式（可以等于 0、可以等于任意常数、也可以发散）， 它不是恒等式，不能拿来当等式用。

但老师心里那个东西是能写出来的，只是要写成比值的极限而不是等号：

limR→0　ω₀U / Pout　=　∞ / 0　⟶　∞　　　（比值发散，这是「∞」）
Pout ≡ 0　　　　　　　　　　　　　　　　　　　（净输出恒零，这是「0」）

这两行可以并存，而且正是本节那张表在算的东西。 「0 = ∞」不行，是因为它把两个不同量的两个极限写成了同一个量的等式。 这一步是这一步，不是措辞挑剔 —— 一旦允许这样写，账本里任何一项都能被它抹平， 本页一至五节所有判据（越界、闭合残差、尖/钝比、锁定阈值）会同时失去意义。

六-7　「和 koilon 同频同模式」，传递的是频率，不是能量

老师的第三句：「静止就是无限，和 koilon 同频同模式就会功能与它一致。」 这一条说出了真机制 —— 共振锁定确实是这么工作的，而且正是本页 Ⅵ 页第十一节在算的东西。 但有三处必须算清：

（一）无限频率根本锁不上。 Ⅵ 页的锁定判据是 |Δ| ≤ K，Δ = N·ε 是频率失配。 对方频率无限 ⟹ Δ 无限 ⟹ 任何有限 K 都锁不住。换成 Arnold 舌的说法就是 ε < K/N，ε → ∞ 必然落在舌外。所以「与 koilon 同频」这个操作， 前提本身在数学上不可达 —— 不是难，是那个极限不在解集里。

（二）就算锁上了，锁相只统一相位，不传递振幅。 锁定后 δ = 常数，两个振子频率完全相同、相位差固定 —— 这就是「同频同模式」，成立。 但各自的振幅 A₁、A₂ 一点没变；能传过去的功率是 K·sin δ，被 K 卡住，是个常数。 所以「同频」给的是节律一致（这正是它有效、能带动东西的原因），不是「能量共享」。

七-6　诚实边界

① 共性是数学结构层面的，不是「SEG 就是 koilon」。两侧物理量不同： 一侧是静磁场 + 机械几何（B、p=B²/2μ₀、F=p·S），一侧是不可压缩流的流函数 （ψ = zρ²(1−η²)）。共享的只有环向离散对称算子，不共享动力学。

② 方案 6 的 1/sin(π/N) 与 koilon 的瓣深系数 c(n) 数值不等价：前者放大的是半径（量纲 m）， 后者放大的是轴向幅值（量纲为 1 的系数）。它们只是「同一个离散化误差的两个写法」， 不能说「c(6)=1.285 所以半径也放大 28.5%」。

③ 共性 ② 的严格性依赖 rc=0。 一旦 rc>0，指数就变成「局部斜率」，只在 ρ≫rc 时才趋近 −1.5。 这一点页面 v9.26 的量程（rc 下限已放到 0）才让它可验。

④ 本节不主张「SEG 与 koilon 是同一台机器」。 两侧能对上的只有对称性与反问题结构； 推力是否能出、出多少，仍由各自那一节的账本（Ⅷ 六、能量账）裁决。

四、三条判断规则（用这张表而不被骗）

1同数 ≠ 同构

"8"在三处出现：八卦、八柱神、八风塔。只有八卦能给出 2³ 的穷尽等权生成式，另外两个是"恰好有八个"。 判据就一句：写不写得出生成式。写不出，只是计数巧合。

2同形 ≠ 同源

形状相似只有两条出路：要么给出传播证据（有译本、有商路、有中间文本），要么老实标"同构"。 默认不许假定传播。佛教四大 vs 希腊四根就是典型：形态极像，传播链查了两百年没定论。

3同名 ≠ 同指

先查词源，再配概念。Chaos、anu、aether、五行 四个反例全部栽在这一步 —— 前面三个都是中文译名撞车， 最后一个是被英文译名撞车。

4可验性分级

凡能落到一个数或一个不等式上的对应，强度高于只有修辞的对应。 「阴阳 ↔ 正反旋」能落到 dθ/dt ≡ ±d 这个符号上；「位阶 0 ↔ 量子本体」能落到一个尺度 （普朗克长度 1.616×10⁻³⁵ m）—— 但尺度只标定层位，不担保同一； 「太极 ↔ 普罗提诺的 ἕν」落不到任何数：一个含内在二重性，一个严格无差别。

那条"一行可验算"的定理

为什么"阴阳 ↔ 正反旋"这一格能标"同构"而不是"比附"？因为它有生成式，不是比喻：

du/dt = [(z − b) + i·d]·u  ⟹  dθ/dt ≡ d

极角速度恒等于常数 d，与 x, y, z 全都无关。所以：d = +1 与 d = −1 给出两支严格互为镜像的解； 36° 均分、180° 对望这些"看起来像摆拍"的对称，是定理的推论，不是画图时的安排。 这就是"两种极性"在可测层面的确切含义 —— 旋向，不是电荷符号。
对照：阴阳没有任何一个可测的量能写成这样的式子。所以 —— 结构同构 ✓，机制同一 ✗。

ⅩⅢ边界 · 这套本体跟希格斯是不是同一件事

这一节不参与前面任何推导，它是外部校准。提问的常见形状是： 「希格斯 125 GeV、约 1.6×10⁻¹⁸ m、自旋 0、不带色荷 —— 这些性质像不像 koilon 粒子模型？」 先给结论：不像。而且这个问句里最硬的两根柱子（那个"尺度"、那个"自旋 0"）都站不住。 下面五条逐条判，最后给唯一能接轨的东西 —— 不是"像"，是一个无量纲的数。
