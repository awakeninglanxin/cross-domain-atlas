15 avril 2013 - DLE-TEST23 : Voici un simple test de recharge régénératrice d'une batterie au plomb de 12V avec le moteur de Robert Adams (très similaire au moteur/générateur unipolaire de John Bedini) piloté par l'APMC v1.0 (Arduino Pulsed Motor Controller) déjà présenté dans le DLE-TEST22. Ce type de recharge régénératrice utilise uniquement les impulsions "Back EMF" de la bobine motrice pour recharger la batterie. Ce test permet de vous montrer l'APMC en utilisation réelle dans une simple expérience d'exploration. Un PC est connecté via le port USB sur la carte Arduino Mega 2560. Ce test DLE-TEST23 vous permet de voir comment le firmware de l'APMC envoie en temps réel le flux de données (base de temps, vitesse de rotation, retard et durée de l'impulsion, paramètres utilisateur et paramètres calculés) sur l'ordinateur.

La batterie qui est utilisée est une batterie au plomb de 12V 1.3Ah. Les impulsions Back EMF sont récupérées via une double diode rapide HFA25PB60.

Sur la photo ci-dessous :
la vitesse de rotation est de 1672 tours/minute,
l'impulsion motrice est envoyée 500 µS après le TDC
avec une durée programmée de 2000 µS
mais réajustée à 1198 µS par l'APMC pour optimiser l'énergie.

La tension initiale de la batterie était de 12.86 V et elle est montée à 13.18 V après 3 minutes de fonctionnement

Voici les données télémétriques envoyées sur le port USB par l'APMC v1.0

Voici le détail de la trame des données télémétriques : 260463860, 1697, 5872.00, 500, 2000, 1172

260463860 : référence temporelle,
1697 : Vitesse de rotation en tours/min (RPM),
5872.00 : Temps (en µS) entre 2 impulsions motrices,
500 : Retard (en µS) de l'impulsion après le passage au TDC (point mort haut),
2000 : Consigne de durée (en µS) de l'impulsion demandée par l'utilisateur,
1172 : Durée (en µS) de l'impulsion recalculée et optimisée par l'APMC.

  • La carte microcontrôleur Arduino MEGA 2560
  • L'écran LCD - clavier pour la carte Arduino
  • Le capteur à effet HALL TL4935L
  • Le transistor mosFet BUZ11
  • L'optocoupleur 4N25
  • Diode Rapide HFA25PB60
  • Documentation complète en Français sur l'Arduino Mega 2560
