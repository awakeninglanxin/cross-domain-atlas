The Inertial Drive Engine Aircraft (IDEA) uses the force from a rotating inertial mass (the centrifugal force) for producing a linear impulse.

An Inertial Drive Engine (IDE) is a mechanical device which uses a standard electrical motor drive for producing a motion.

This device has not yet been tested
