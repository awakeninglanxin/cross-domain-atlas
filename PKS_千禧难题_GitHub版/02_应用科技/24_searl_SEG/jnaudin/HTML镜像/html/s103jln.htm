S.M.O.T v 1.03 - Rollaway test

by Jean-Louis Naudin

created on 05 June 1997 - JLN Labs -updated on 06 June 97

WARNING : This Rollaway experiment is performed with the railroad entry just level with the entry of the ramp. Unfortunately the end of the railroad track has to be 2 mm BELOW the entry level of the ramp, so that the N-gauge exit track is sloping downhill........

  • SMOT V 1.03 :
    • Each magnetic ramp : 12 magnets in 3 layers of 4 magnets (length=160 mm),
      • Ceramic Magnets( ferrite ) : 25 x 40 x 10 mm
      • A wide steel backing : 25 x 160 x 4 mm
  • 25 mm steel ball ( weight 70 gr )
  • 20 x 20 mm aluminum U channel
  • Plywood and cardboard for the base

Magnetic ramps spec :

  • Input gauge : 90 mm
  • Output gauge : 60 mm
  • Height of slope : 25 mm
  • Length : 130 mm (slope) + 30 mm ( entrance ) : total length : 160 mm

ROLLAWAY TEST > 180 mm with aluminium U Channel

ROLLAWAY TEST > 400 mm with a plastic railroad
