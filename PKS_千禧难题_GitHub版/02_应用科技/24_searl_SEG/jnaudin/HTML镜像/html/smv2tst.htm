The SMOT V2 enhanced exit

SMOT V2.0 Specs :

  • 2 Magnetic RAMPS ( in parallel ) :
    • Each ramp : 15 magnets in 1-2-3-4-5 stacks,
      • Ceramic Magnets( ferrite ) : 25 x 40 x 10 mm
      • A 5 mm plywood base for the magnets : 25 x 200 x 5 mm
  • 25 mm steel ball ( weight 70 gr )
  • 20 x 20 mm aluminum U channel
  • Plywood and cardboard for the base

Magnetic ramps :

  • Ramp Input/Output gauge : 53 mm
  • Height of slope : 25 mm
  • Length : 180 mm (slope) + 30 mm ( entrance ) : total length : 210 mm

Magnets : Ferrite Barium 40 x 25 x 10 mm ( anisotrop )

  • Energy produced ( BxH ) max : 29.5 kJ/m^3 - 3.7 MGOe
  • Remanence ( Br) : 400 mT - 4000 G
  • Coercitivity ( T=20°C ) :
    • bHc : 160 kA/m - 2000 Oe
    • jHc : 165 kA/m - 2050 Oe
  • Permeability : 1.1 mT/(kA/m)
  • Temp. coef. -0.20%
  • Max operating temp. : 200 °C
  • Density : 4.9 g/cm^3
  • Curie point : 450 °C
