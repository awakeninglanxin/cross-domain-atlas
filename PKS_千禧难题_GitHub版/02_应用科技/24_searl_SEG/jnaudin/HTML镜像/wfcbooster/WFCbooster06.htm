6 février 2013 - TESTS02E06 : Ceci est la suite du TESTS02E05. Le but de ce test est de reproduire le plus fidèlement possible le signal d'excitation paramétrique produisant l'élongation de la liaison covalente de molécule d'eau que Stanley Meyer a décrit dans son brevet (voir ci-dessous):

Le montage du VIC (Voltage Intensifier Circuit) utilise les mêmes composants que le test précédent, j'ai amélioré le schéma précédent en ajoutant une nouvelle diode à commutation rapide HFA25PB60 (merci à Milan Manchich pour sa suggestion). Et effectivement, dans cette nouvelle configuration, le signal mesuré aux bornes de la WFC est assez similaire à celui décrit dans le brevet de Stanley Meyer.

Voici le schéma du WFC-VIC 1.1 modifié

Voici la configuration du TEST-S02E06 :

Le générateur de fonction N°1 module le générateur de fonction N°2 et le signal est envoyé sur un amplificateur à base de transistor MosFet IRFP450 alimenté à 30V DC.
La tension pulsée est envoyée sur la WFC via deux diodes ultra-rapide HFA25PB60 et la bobine bifilaire (L1,L2).

La fréquence de résonance a été ré-ajustée : 42.8 KHz modulé à 4.2 KHz avec un DTC de 50%

Voici le signal mesuré aux bornes de la WFC.

Le dégagement gazeux est encore plus important que dans le test précédent...

Voici donc une vidéo des essais du montage WFC-VIC v1.1

Commentaires : Le nouveau signal produit et plus proche de celui décrit dans le brevet de Stanley Meyer, semble améliorer de manière notable la décomposition de l'eau. Il est important de noter aussi que je n'ai pas constaté d'échauffement de la cellule WFC.
