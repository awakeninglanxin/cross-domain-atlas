> 本文只做一件事：**把"同一个东西在不同传统里叫什么"排成一张可核对的表，并把"只是名字像"的那些单独挑出来。**

## 0. 先立规矩：四档标注，不许混读

跨文化对表最大的病害不是"对不上"，而是**把对不上硬说成对上了**。所以每一格都必须带一个来源强度标记：

| 标记 | 含义 | 判据 |
|---|---|---|
| 【对译】 | 历史上有公认的翻译承继关系：有译本、有注疏、有连续的引用链 | 能指到具体译本与年代 |
| 【同构】 | 结构同形，但**无传播证据**，两边独立长出来的 | 能写出两侧各自的生成规则，且规则不同而骨架相同 |
| 【比附】 | 后人配上去的，缺文本依据 | 只能给出"感觉像"，给不出生成规则 |
| 【争议】 | 学界两说并存，本文不裁 | 能各举一派 |

第四档还有一层："同源 vs 独立发生"这类问题（如佛教四大与希腊四元素）**至今无定论**，凡遇此类，一律标【争议】，不替学界下结论。

**读表的三条纪律：**

1. **位阶越"负"，对应越虚——但位阶 0 现在有一格例外。** 位阶 0 那一行除「现代物理侧」外几乎全是【比附】——因为"未分"本身只能被否定地描述（无极 / Ain / ἄπειρον / śūnya 都是否定式命名）。否定式命名彼此必然长得像，这是**语法造成的相似**，不是内容相同。唯一例外之所以能标【同构】，是因为它能落到**一个数**：普朗克长度 1.616×10⁻³⁵ m——它不是"什么都没有"，而是"还能谈长度"的**下限**，与"未分化"（有本体、无区分）同构；一旦把"未分"读成"零/空无"，这一格立刻退回比附。
2. **位阶 2 是最硬的一格。** 阴阳 ↔ 正反旋 之所以站得住，不是因为"两个"，而是因为两侧都能给出**同一个生成规则**：一个量的两种符号（见第 3 节）。**anu 的正/负就是把这一格落到实物上的候选**——判据同一条：互为镜像、反向旋转，只差一个手性。
3. **位阶 5 的"八"要分成两类**：八卦是 **3 条独立二值轴**（2³ 穷尽等权）；埃及八柱神是 **4 个属性 × 固定性别对**（4×2）。数一样，生成式不一样 ⟹ 只能叫【同构】，不能叫"同一个东西"。

### 1.1 2026-10-31 四格改判：位阶不是尺度序，是生成序

- **普朗克尺度 ⟹ 量子本体，在位阶 0**（即 koilon 这层泡膜）
- **koilon 本体内部的第一层结构 = 黄金极限蛋外鞘（太极式再循环），在位阶 1**
- **anu 在位阶 2**——因为它有 positive / negative 互为镜像、反向旋转
- **位阶 5 原来的"五种相态：不成立"换成 anu 的 d = 5 ⟺ 五种柏拉图立体**

🔴 由此钉住一条读法：**位阶 = 分化层数（生成序），不是大小序。** anu 的**尺寸最小**却排位阶 2；蛋外鞘**比 anu 大**却排位阶 1。原因是"一"只需要**自返闭合**（蛋外鞘的太极式再循环本身就是首尾相接的闭合回路，不需要第二个东西），而 anu 必须成**对**才成立——**一对就已经是"二"**。拿尺子读这张表，四格会全读反。

### 1.2 位阶 5 的原文底本（Besant & Leadbeater《Occult Chemistry》）

该书**图 11「THE PLATONIC SOLIDS」——本扫描版 PDF 第 34 页（共 448 页）**。版面上半是手绘五种正多面体，逐个标注 **I 正四 · II 正六 · III 正八 · IV 正二十 · V 正十二面体**（正十二面体在右下角），旁边另附几幅**互相穿插（interlaced）**的复合体；版面下半是五种立体的剪影与**面数表**：Fig 1–5 = **4 / 6 / 8 / 12 / 20 面**，并写 "In each solid, lines, angles and surfaces are equal"。

正文写：「除氢、氧、氮外，所有化学元素的构造方式似乎都与众所周知的柏拉图立体相似——四面体、立方体、八面体、十二面体和二十面体」，并**明说**「没有发现任何暗示十二面体的元素」。

⚠️ 两句**不矛盾，必须分清**：**十二面体是画在图里的（V）**，「没有发现」说的是**元素里找不到十二面体外形的实例**。把"图上没画"与"实测没有"混成一句，是这一格最容易犯的错。

⚠️ 但同一本书对**元素外形**的分类是**七组**：尖刺 · 哑铃 · 四面体 · 立方体 · 八面体 · 交叉杆 · 星形。七组里只有三个是柏拉图体。所以「五种柏拉图立体」在 OC 里是**理论序列**（且实际只指认出四种），不是实测分类。

本页把它挂在位阶 5，依据是两侧"五"的来源：一侧是 **d = 5 这一档的圈数**（选参），一侧是**凸正多面体恰好五种**（欧几里得《几何原本》卷十三已证的穷尽性）。一个是选参、一个是定理 ⟹ 只标【同构】；要升级成机制同一，得先给出「5 圈 ⟹ 5 个外接正多面体」的生成式，目前没有。

## 2. 核心术语十二组：谁在说同一件事

这一节挑出十二组最常被并列的词，逐组说明**能对到哪里、对不上在哪里**。

### 2.1 气 / prāṇa / pneuma / spiritus / ruaḥ / aether / koilon

- 【对译】气 ↔ πνεῦμα ↔ spiritus ↔ ruaḥ：四者词根都是**风/呼吸**。这是真实的语言学链条（希腊化时期的斯多葛 pneuma 经阿拉伯与拉丁转译）。
- 【争议】气 ↔ prāṇa：功能相似（维系生命、随呼吸出入），但 prāṇa 在数论里是**五种风**之一，且与三德 gunas 绑定；气在中医里走的是**经络与升降出入**，两套解剖学不兼容。
- 【比附】气 ↔ aether：19 世纪 aether 是**力学介质**（有弹性模量、可被迈克尔逊–莫雷实验否掉）；气是**过程性**概念，从来没有"以太风"这种可测对象。这一对是历史上最贵的误配，直接导致"以太=气"的中文语汇污染。
- **结论**：气与 koilon 的关系，最多是"都指先于形体的填充物"，但 koilon 有可算的密度与弹性（原典给的数），气没有。**同名可以，同物不行。**

### 2.2 道 / Logos / Dharma / Ṛta / Ma'at

- 【对译】λόγος → 道：新教传教士译《约翰福音》"太初有道"时做的选择，之后两百年一直有人反对（主张译"言"）。
- 【同构】道 ↔ Ṛta（吠陀"宇宙秩序"）↔ Dharma ↔ Ma'at（埃及"真理/秩序"）：四者都指**使万物各安其位的那个秩序**，且都有"人顺之则吉、逆之则凶"的实践面。
- **对不上在哪**：约翰福音的 Logos 会"成了肉身"（1:14），是**位格**；道"生而不有，为而不恃"，是**非位格**的。这一条差异比所有相似点都重要，不许抹平。

### 2.3 太极 / 太一 / Bindu / Keter / Anima Mundi

- 【同构】四者都是"从无到有的第一点"。
- **对不上在哪**：太极**内含二重性**（"动而生阳，静而生阴"，一动就已经有两个了）；普罗提诺的太一**严格无差别**，"一"不生二，二是它"流溢"的衰减；Keter 之上还有 Ain Soph 三级否定。所以在"这一点里有没有二"这个问题上，三家答案不同 —— 这一格必须分开写。

### 2.4 阴阳 / Puruṣa–Prakṛti / Śiva–Śakti / Limit–Unlimited

- 【同构】都是"一对互补原理撑起世界"。
- **对不上在哪**：
 - 阴阳是**同一气之消长**（互根、可转化、有鱼眼互含）；
 - Puruṣa–Prakṛti 是**两种实体**（纯意识 vs 原质），数论里不互相转化；
 - Śiva–Śakti 是**位格与能力**的关系（不二论里是同体，二元论里是主仆）；
 - 菲洛劳斯的有限–无限是**形式与质料**的关系。
- **只有阴阳这一组强调"互含"**（阴中有阳、阳中有阴）。这一条是阴阳独有的，别送人。

### 2.5 五行 / 五大 / 五元素

- 【对译】只有"五"这个数被对上了。
- **五行是相位不是物质**：Needham 坚持译作 **five phases**，反对 five elements —— 木火土金水描述的是**过程与关系**（生克乘侮），不是五种基本材料。
- 印度的五大加了**空 ākāśa**（作媒介），希腊的五元素加了**以太**（作月上界的材料）。三套的第五个成员完全不同，**这一格是"数同物不同"的教科书案例**。

### 2.6 八卦 / 八柱神 / 八风

- 【同构】八卦与埃及八柱神 Ogdoad 都是"八元组"。
- **生成式不同**：八卦 = 3 条独立二值轴（阴阳 × 三爻，2³ = 8，穷尽且等权）；八柱神 = 4 组"男–女"对（Nun/Naunet 水、Heh/Hehuet 无限、Kek/Keket 黑暗、Amun/Amaunet 隐匿），本质是 **4 个属性各带一个配偶**，展开是 4×2 而不是 2³。
- 雅典风之塔（约前 50 年，八角，每面一位风神）是**建筑上的八分方位**，与八卦的"八风"功能同构（都是方位–气象的八分），但无传播链。
- **一句话**：三个"八"里，只有八卦能写出穷尽等权的生成式。

### 2.7 无为 / Wu wei / 不动心 ataraxia / 无执 niṣkāma

- 【同构】都是"不强行"的实践姿态。
- **对不上在哪**：无为是**不妄为**（顺自然之势而为），不是不行动；ataraxia 是**免于扰动**的心理状态（皮浪/伊壁鸠鲁的目標）；niṣkāma 是**不执着于果**（《薄伽梵歌》的行动瑜伽）。三者一个是宇宙论姿态，一个是心理状态，一个是伦理技术。

### 2.8 玄 / Ain Soph / Mysterium

- 【同构】都是"深不可测者"。
- 差别：玄是**形容词性**的（"玄之又玄"）；Ain Soph 是**层级**（否定神学的第二级，其上有 Ain、其下有 Aur）；Mysterium 是**礼仪/教义**对象。三者语法位置不同。

### 2.9 天 / Dyaus / Anu / Caelum

- 【同构】都是"上面那个"。
- **陷阱**：苏美尔 **Anu**（𒀭，天空之神，也作神符 dingir）与梵语 **aṇu**（极微/原子，胜论派的 paramāṇu）**毫无词源关系**。神智学的 "anu" 取自后者。项目里天天写 anu，必须分清。见第 3 节。

### 2.10 太极图 / 衔尾蛇 Ouroboros / 阴阳鱼

- 【同构】都是闭合环。
- **对不上在哪**：太极图的核心是**两条鱼互含对方之眼**（阴中有阳、阳中有阴），这是"互根"的图形化；衔尾蛇的核心是**自吞**（自足、永恒回归）。一个讲"互相包含"，一个讲"自我闭合"。形状像，语义反。

### 2.11 七曜 / 七脉轮 / 七重天

- 【同构】都是"七"。
- **对不上在哪**：七曜是**天体**（日月 + 五星），来源是**观测**——肉眼可见的游星恰好五个，加日月为七；七脉轮是**体内中心**，来源是**修行内景**；七重天是**宇宙分层**。三者的"七"来自三个不同的生成机制（观测计数 / 内景计数 / 教义分层）。

### 2.12 十二 / 六十 / 三百六十

- **十二**：可等分性极好（360 可被 12 整除），所以黄道十二宫、十二时辰、十二律吕、十二地支全都长成十二分 —— 这是**算术驱动**。
- **六十**：干支六十甲子与巴比伦六十进制同构，同样是**可除性驱动**（60 有 12 个约数）。
- **三百六十**：巴比伦 360° 与中国"周天三百六十五度四分度之一"并存 —— 中国取的是**回归年实测**（365¼），巴比伦取的是**可除性**（360）。这一对差异恰好证明：**同样是"分一圈"，动机可以完全不同。**
- **落到本项目**：SEG 转子 12 段是**磁齿轮传动比**的设计选择，不是"因为十二地支"。数一样，理由毫不相干。

## 3. 同名不同物：必须先查词源再配

这一节是**防身用**的。以下每一组都是"中文里撞名了，于是被当成一门学问"的实例。

## 4. 三条判断规则（用这张表而不被骗）

**规则一：同数 ≠ 同构。**
"8"在三处出现：八卦、八柱神、八风。只有八卦能给出 `2³` 的穷尽等权生成式；另外两个是"恰好有八个"。判据：**能不能写出生成式**。写不出，就只是计数巧合。

**规则二：同形 ≠ 同源。**
形状相似只有两条出路：要么给出**传播证据**（有译本、有商路、有中间文本），要么老实标【同构】。**默认不许假定传播**。佛教四大 vs 希腊四根就是典型：形态极像，传播链查了两百年没定论。

**规则三：同名 ≠ 同指。**
先查词源，再配概念。Chaos、anu、aether、五行 四个反例全部栽在这一步。

**加一条：可验性分级。**
凡能落到**一个数或一个不等式**上的对应，强度高于只有修辞的对应。比如：
- 「阴阳 ↔ 正反旋」可以落到 `dθ/dt` 的符号（见 4.1）；
- 「无极 ↔ koilon」落不到任何数 —— 因为无极是纯否定名；
- 「五行 ↔ 五元素」只有"五"这一个数，且第五个成员不同 ⟹ 弱。

### 4.1 那条"一行可验算"的定理

为什么"阴阳 ↔ 正反旋"这一格能标【同构】而不是【比附】？因为它有生成式：

```text
du/dt = [(z − b) + i·d]·u      ⟹      dθ/dt ≡ d
```

极角速度**恒等于常数 d，与 x, y, z 全都无关**。所以：
- `d = +1` 与 `d = −1` 给出两支**严格互为镜像**的解；
- 36° 均分、180° 对望这些"看起来像摆拍"的对称，是定理的推论，不是画图时的安排；
- 这就是"两种极性"在可测层面的确切含义 —— **旋向，不是电荷符号**。

对照：阴阳没有任何一个可测的量能写成这样的式子。所以 —— 结构同构 ✓，机制同一 ✗。
