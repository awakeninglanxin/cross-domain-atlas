1为什么 Thomas 恰好是 3 刀

Thomas 吸引子（René Thomas, 1999）只写了三条方程：

dx/dt = sin(y) − b·x
dy/dt = sin(z) − b·y
dz/dt = sin(x) − b·z （经典 b = 0.208186…）

它有三条互成 120° 的「腿」，看上去像三把搅拌刀。这不是调参调出来的，是方程自带的对称性叠出来的三层结果。

第一层：C₃ 等变 —— 转 120° 后方程一模一样

把三个变量循环移位 (x, y, z) → (y, z, x)，方程的原样不变：第一条变成第二条、第二条变成第三条、第三条回到第一条。这个置换在垂直 (1,1,1)/√3 轴的平面里正好是旋转 120°。

我按定义直接验：随机取点，比较 F(R·x) 与 R·F(x)（R 是那个循环置换），最大偏差是

max‖F(Rx) − R·F(x)‖ = 0.000e+00 b = 0.208186 样本 10⁴ 点

是严格零，不是「近似对称」。既然方程本身在 120° 旋转下不变，任何解的三条臂就必须互成 120°——三刀是几何必然，刀数等于对称群的阶数 3。

图 1　三条臂的 120° 不是巧合：方程在「循环置换」下逐点不变，该置换正是绕 转轴 (1,1,1)/√3（垂直纸面）转 120°。

第二层：全场一致收缩，b 只决定粗细

把三个方程相加取散度：

div F = ∂x'/∂x + ∂y'/∂y + ∂z'/∂z = −b − b − b = −3b = −0.624558

它与位置无关，是常数。所以整条流处处收缩、体积以 e−3bt 指数塌缩，这就是吸引子存在的原因；b 越大收得越快、轨迹越细越贴壁（筒壁半径 ≈ 4.13）。b 不决定刀数——很多人以为它是个「刀形参数」，其实不是。

2角谱：低阶谐波被对称性禁戒

把轨迹投影到垂直轴的平面上，按方位角 φ 做傅里叶展开：ck = ⟨eikφ⟩。如果场是 Cn 等变的，那么只有 k ≡ 0 (mod n) 的谐波能存活，其余在数学上被禁戒。

图 2　角谱实测：k=3 高出其余一个数量级，k=6、k=9 是它的谐波。k=1、2、4、5 被 C₃ 对称性禁戒。

谐波|ck|说明

k = 60.0682 倍谐波（C₃ 允许）
k = 90.0723 倍谐波（C₃ 允许）
其余 k≤ 0.036被对称性禁戒，小 8 倍以上
一般结论：Cn 等变场的角谱只保留 k ≡ 0 (mod n)。所以「刀数 = n」不是拟合出来的参数，而是对称群的阶数。想让刀数变成 5，就必须让场的对称群变成 C₅——只把某一项的阶数从 3 改成 5 是没用的。

3群平均推广为什么失败（n=3 是特例）

教科书式的推广是群平均（把场绕轴转一圈，按 n 个位置平均，天然得到 Cn 等变场）：

Fn(x) = (1/n) · Σk=0..n−1 R−k F(Rk x)

结果很干脆：

n群平均后 n=3 的还原误差末点 |x|主谐波结论
34.4e-16—k=3逐位还原 Thomas ✅
2—4.133k=1退化成绕轴规整环 ❌
4—4.133k=1同上 ❌
5—4.133k=1同上 ❌
6—4.133k=1同上 ❌

原因：把三条半周期的正弦（sin y、sin z、sin x）按 n≠3 个方向平均，非线性被削平，只剩一条贴着筒壁绕轴的规整环。末点全都落在同一个 |x| = 4.133，就是「退化成同一条几何」的铁证。

所以：「3 刀」是 Thomas 这条方程特有的，不是可调参数。 任意 n 刀不能靠搬 Thomas 得到，必须换构造。

4换成圆柱筒化：任意 n 刀怎么造

思路：不搬 Thomas，只保留「圆柱筒 + 面瓣化」的几何骨架，让吸引半径随方位角按 n 阶调制。

ρe(φ, z) → ρe · [ 1 + B · cos(n·φ + kz·z) ]

B 是瓣化幅度、kz 是沿轴的螺旋拧（像搅拌机的斜叶，kz=0 时是直刀）。三条机制我都单独实测过：

机制做法实测结果
径向推力ε 项直接给 n 阶谐波无效：被 −KR·a₁（KR=200）的向心约束压回去
面瓣化吸引半径随角度变：ρe·(1+B·cos(nφ+kzz))有效：轨迹被钉到 n 条棱上
整场 Cn 化vz 也换成 n 阶（原来是写死的 m=2）必须：否则整场对称群仍是 C₁

最后一条是最容易漏的坑。页面原来径向用 m=3、轴向用 m=2，整场的对称群是

Cgcd(3,2) = C₁ ←→ 再叠什么阶数都切不出刀

两处必须同阶，场才真的是 Cn。改完后实测等变误差（n=2…12）：

max‖F(R2π/nx) − R2π/nF(x)‖ ≈ 3.6e-15 θ = π/n 时偏差 3.4e-2 ~ 1.0e-1

后半句同样重要：如果只是「2n 阶」而不是「n 阶」，转 π/n 也会对称。实测转 π/n 时明显不等 ⟹ 对称群恰好是 Cn，不是 C2n。

5判据：为什么不能数「密度」

验收时我先用了最直觉的指标——角向数密度对比度 |Σeikφ|/N。结果几乎读不出差别，导致我一度误判「没有刀」。换成瓣形幅度才测出来：

a = | Σ ρ·ei·k·φ | / Σ ρ （平均半径随 φ 的 n 阶谐波，相对平均半径）

两者差别在于：密度看的是「点在角向堆不堆」，而瓣形看的是「半径随角度有没有起伏」。前者对少数几根丝很不敏感，后者直接量形状。

40.052k=4
50.042k=5

峰全部精确落在 k = n。同时也能看出：n 越大瓣越浅是几何必然（同样的 B 要摊到更多瓣上），不是 bug。想在 n≥6 时看得清楚，把 B 拉到 0.35~0.40。

6流向可选项：反流与严格时间反演

原场是「赤道内聚 → 南北极喷射」。想反过来（南北极吸聚 → 赤道旋出），最直觉的做法是时间反演 t → −t，也就是把速度整体取反。但这里有个陷阱。

陷阱：耗散系统逆时，吸引子会变排斥子

第 1 节已经算出 div F = −3b < 0。取 v → −v 后散度整体变号：

div(−F) = +3b = +0.624558 > 0

散度为正意味着相体积处处膨胀——原来的吸引子变成排斥子，轨迹指数飞离。这不是数值不稳定，是数学必然。实测：6 个种子分别在 2.3 / 3.4 / 3.7 / 4.5 / 7.8 / 10.6 秒后 |r| > 1000，被页面的清空判据踢掉。

正解：只反「输运」，保留「软墙」

把速度拆成两部分：

v = vT + vC
vC = −KR·a₁（径向软墙） + KZ·(a₃ − a₂)（轴向软墙）

vT 是几何输运（曲面向心项、喷流、谐波），vC 是永远指向可行域的约束项。反流只反前者：

vflip = −vT + vC = −v + 2·vC

软墙不反号 ⟹ 粒子跑不出去 ⟹ 有界。实测（6 个种子 × 100 s）：

采样点正流反流
赤道 z=0, ρ=0.60ρe 的径向 vr−1.4882（向内聚）+1.4879（向外旋出）
极区 z=0.80 ZTOP, ρ=0.35ρe 的轴向 vz+9.0659（向上喷）−9.0662（向内吸）
环向 vφ+6.2958+6.2958（不变）
100 s 内 max|r|7.1 ~ 7.37.1 ~ 7.3（有界 ✅）

三个数字说明三件事：赤道确实从「聚」变成「出」、极区确实从「喷」变成「吸」、环向自转不跟着反（所以画面是「倒流但仍同一个转向」）。

严格逆时：把软墙也一起反

若坚持做真正的 t → −t（连软墙、连自转一起取反），就是 vrev = −v。它必然发散，但可以看——正好用来演示「排斥子」的行为。两者的关系：

7σ 族通项：正流与反流其实是同一个吸引子

「能不能把正流和反流两种混沌吸引子提取共性，合成一条通项公式？」 答案是：它们本来就不是两个吸引子，而是同一个向量场 F 的两种定向。 所谓「共性」不用提取，它就在定义里。

先把「输运」和「约束」拆开

页面里的速度场可以逐项拆成两部分 —— 一部分真正搬运粒子，一部分只负责把粒子挡在泡壁内：

v(x) = vT(x) + vC(x)

vC = −KR·a1(ρ)·ρ̂ + KZ·[a3(z) − a2(z)]·ẑ
a1(ρ) = ½[(ρ − ρe) + √((ρ − ρe)² + σ²)] ，a2、a3 同理

vC 是「软墙」：只在越界时才不为零，它不是物理流动，是数值约束。 分清这两项，通项就只剩一个符号。

通项：vσ = σ·(v − vC) + vC，σ = ±1

σ = +1 ⟹ vσ = v （赤道内聚 → 南北极喷射）
σ = −1 ⟹ vσ = −v + 2vC （南北极吸聚 → 赤道旋出）

所以「两种吸引子」的全部差别只有一个符号。σ 改的是流形上的定向，不是几何 —— −F 的吸引子与 F 的吸引子是同一个点集，一个顺走、一个倒走。 这正是两条流线在 (ρ, z) 剖面上能严丝合缝重合的原因（实测见下）。

再加一个开关 τ，「严格逆时」也一起收进同一个式子：

vσ,τ = σ·(v − vC) + τ·vC ，σ, τ = ±1

τ = +1 ⟹ 软墙仍往泡内吸 ⟹ 有界（就是页面上的「⇄ 反流」）
τ = −1 ⟹ 软墙一起反号 ⟹ v = −v ⟹ div 由 −3b 变 +3b ⟹ 排斥子，指数逃逸
这解释了「严格逆时必然发散」的全部原因：耗散系统的时间反演不是 「倒放录像」，而是把吸引子换成排斥子。它不属于同一个动力系统，只是同一个公式换了符号。 换句话讲：真正能"倒流又不炸"的，只有 σ=−1、τ=+1 这一格。

「双线并绕」= 两族共存，不是两个场相加

把 σ=+1 与 σ=−1 两族粒子放进同一个结构，密度记作 n+、n−， 各自被自己的场输运：

∂t nσ + ∇·( nσ vσ ) = 0 ，σ = ±1

n(x, t) = n+(x, t) + n−(x, t) ← 屏幕上"叠加"的是密度
不是「把两个场加起来」，而是「同一批粒子走两遍、各走各的场」。 形式上确实有 v+ + v− = 2vC ≈ 0，但这条式子只回答一个问法： 「能不能先把两个速度合并成一个场」—— 答案是不能，也不需要。 页面的做法是轨迹层的相位错位：第 i 颗粒子按 σ(i)=±1 选自己的场 vσ 独立积分一遍， 两族各得一条轨迹，再分别上色、同屏绘制 ⟹ 根本不经过「相加」这一步，不存在零场问题。
渲染层也没有任何相互作用项 ⟹ 两族不会"相互影响、达成平衡"。
看着更饱满、更平衡，原因有两个：① 两族填对方的空隙，同一块体积被采样两遍； ② 它们走在同一族流线上、方向相反 ⟹ 剖面上「一出一入」的丝成对出现，轮廓更实。
2026-11-02 起两族默认同时开启，并互为反色：正流暖（琥珀→奶白，色相 ≈35°）、 反流冷（深靛→天蓝，色相 ≈212°），同明度、实测色相差 ≥157° ⟹ 一眼分得出正/反； 泡壁网格在双线档自动转灰白，不跟反流抢色相。

一共只多出两个自由度

符号含义页面控件
σ定向（正流 / 反流）按配对号分族，不按奇偶
Δφ两族的方位相位差「双线相位差」滑条 0–180°（默认 90°；双线默认开）

族的分配用 (i≫1)&1 而不是 i&1：种子是 (i, i+1) 成对的镜像对（只差 z 符号）， 按奇偶分会让 σ=−1 那族只落在下半空间 —— 俯视图上就看不到交替了。

8流函数 ψ：一条精确通项，以及和瑟尔幻方公式的交集核查

本节回答两个问题：①「流线形状到底有没有通项？」②「页 A ⑨『共享线和 · bonding 数』那些公式，和这里有没有交集？」 结论先放这里：通项有，是一条精确的代数不变量；和幻方的交集只存在于「守恒量 / 存在性障碍 / 一值多载体」这三层， 在「函数形式」这一层则没有。

8.1 先证明「求通项」这件事本身合法

有流函数的前提是场无散。把速度场拆成四件可独立开关的部件，逐件量散度 （笛卡尔差分 h = 10⁻⁵，走页面自己的 fieldAt）：

Thomas 环面核 vT0（精确） 中位 2.2×10⁻¹¹，最大 1.2×10⁻¹⁰ ⟹ 只剩差分截断误差
三刀项 εε(cos2φ + 2sin3φ) 24 个方位角上 |实测 − 式| 最大 7.7×10⁻¹⁰（精确命中）
极向喷流 J轴向源-汇偶极 +4.88×10² @ ρ=0.02, z=0；−8.36×10¹ @ z=±0.16
软墙 vC≤ 0（纯压缩） −5.50×10²（贴壁）→ 0（内部，10⁻⁷ 级）
核严格无散 ⟹ 存在流函数 ψ ⟹ 「求通项」是合法提法，不是拟合。 而且这条无散是代数的必然：把 vr、vz 代进柱坐标散度 (1/ρ)∂(ρvr)/∂ρ + ∂vz/∂z，ρ²/F 那几项逐项相消， 不需要 F(z) 取任何特殊形状。

8.2 反解出来的通项

ψ(ρ, z) = z · ρ² · (1 − ρ²/F(z)) = z · ρ² · (1 − η²) ， η ≡ ρ / ρe(z)

且 F(z) ≡ ρe(z)² —— 这是代码里的恒等式（Fpack 第三个返回值就是 √F）

流线 = ψ 的等值线： ρ² · (ρe(z)² − ρ²) · z = C · ρe(z)²

推导只用到代码里那两行：vr = −ρ(1 − ρ²/F + zρ²F′/F²)、 vz = 2z(1 − 2ρ²/F)。代进 vr∂ρψ + vz∂zψ 得到 −2zρ²·A·B + 2zρ²·A·B ≡ 0，与 F 的具体形状无关 ⟹ 对任意 λ、任意 R 都成立（相似律 s=R/4 只缩放 ρ、z，ψ 的零集不变）。

几何含义：ψ = 0 有三支 —— 赤道面 z=0、极轴 ρ=0、 外鞘曲面 ρ=ρe。也就是说外鞘本身就是那条分界流面， 一切内部流线都被它夹住，这与「泡壁是软墙」是同一件事的两种说法。

关键开关：「ε · 编织扰动强度」，默认 0.055。 ε ≠ 0 时流场不再可积：同一个种子跑 36 个时间单位，ψ 的相对摆幅从 < 0.1% 涨到 1393%。 换言之，屏幕上那些「丝会散开、看着像混沌」的观感，唯一的来源就是这 0.055。 把 ε 拉到 0，每条流线会永远停在 ψ = C 上（3D 里是嵌套环面）—— 那是完全可积的。 这也解释了为什么之前用单幂律拟合只能拿到 R² = 0.34：ε 项把每条「曲线」都变成了带厚度的「带」。

8.6 结论

三条真交集，全部在「结构层」而不在「函数形式层」：

① 一值多载体（k(S) ↔ ψ=C）； ② 可证明的共存障碍（定理 3 ↔ v++v−≡0）； ③ 局部非零 / 积分归零的守恒（每线和为零 ↔ 每圈净通量为零）。

两处硬性不相容，必须说清：

① 幻方是整数格点 + 取模判据，蛋流是连续场 + 代数不变量； ② 幻方式 S = Td(n) + n(L−1) 不能当流函数用 —— 它不含 ρ、z 的任何信息，自然满足不了 ∇ψ·v ≡ 0。

真正值得从页 A 搬过来的只有一句话：「中心归零幻方 ⟺ ∇·B = 0（无磁单极）」。 但搬过来必须改口径 —— 蛋流侧要读成「每圈净通量为零」，不能读成「逐点无散」： 三刀项 ε(cos2φ+2sin3φ) 是 C₃ 对称的，必然带 φ 依赖，逐点不可能为零； 但它绕轴一圈的积分恒等于 0。这就是「无净磁单极」在蛋流上的准确说法。
