## 一、几何模型总览

瑟尔效应发电机（SEG）和反重力装置（IGV）由三组同心环构成，从内到外依次为：

```
        定子环1 → 滚筒组1 → 定子环2 → 滚筒组2 → 定子环3 → 滚筒组3
        (inner)              (middle)              (outer)
```

每环定子为环形截面（内径 Brᵢ，外径 BRᵢ），每环滚筒在对应轨道半径 orbitᵢ 上公转。

## 三、9 种几何方案详解

### 方案1：已知尺寸求体积（ctrl=size）
- **驱动参数**：Yr, Br₀, n, e系数（全部可调）
- **公式**：`BR = Yr × num × n / 2`, `Brᵢ₊₁ = BRᵢ + su + sd + 2×Yr`, `Bh = D×e`, `Yh = min(D/tan22.5°, Bh/k)`
- **e系数**：生效（Bh 和 Yh 均由 e 驱动）

### 方案2：已知体积求高度（ctrl=volume）
- **驱动参数**：目标定子体积 Bv, Yr
- **公式**：`Bh = Bv / (π(BR²−Br²))`, `Yh = max(1, min(Bh/k, Bh/1−1.2))`
- **e系数**：不生效（高度由体积驱动，非 e）

### 方案3：已知参数求 b 系数（ctrl=size）
- 同方案1，预留 b 系数计算扩展

### 方案4：体积等差 + 等厚（ctrl=size, nFac=2）
- **nFac 固定为 2**：`BR = Yr × num × 2 / 2 = Yr × num`（用户可覆盖 n 滑条，默认 2）
- **等厚约束（软）**：`t = BR₀ − Br₀`, `Brᵢ = max(Brᵢ, BRᵢ − t)`，间隙优先

### 方案5：等差 + 等厚等间距（ctrl=size）
- **n 可调**（默认 1）
- **等间距约束（软）**：`g₀=Br₁−BR₀, g₁=Br₂−BR₁` → 取平均 → 均匀分配，间隙 ≥ `2Yr+gap` 时生效
- **等厚约束（软）**：同方案4，执行顺序：先等间距 → 后等厚 → 间隙复查

### 方案6：三角函数定子半径（ctrl=size）

**核心公式**：
```
BRᵢ = (2×Yr + n) / (2 × sin(π / numᵢ))
```

**数学推导（正多边形弦长法）**：
将 `num` 个滚筒均匀分布一圈，相邻圆心弦长 = `2 × orbit × sin(π/num)`。
假设相切：`2×Yr = 2 × orbit × sin(π/num)` → `orbit = Yr/sin(π/num)` → `BR = (2Yr+n)/(2sin(π/num))`。

n=12 时 `sin(π/12)≈0.259`（BR 比方案1~5 大 ~15%），n=32 时 `sin(π/32)≈0.098` 逼近弧长公式。

### 方案7：质量密度体积（ctrl=mass）
- **驱动参数**：三环各自质量 mᵢ, 密度 ρ
- **公式**：`Bv = mᵢ/ρ`, `Bh = Bv / (π(BR²−Br²))`, `Yh = max(1, min(Bh/k, Bh/1−1.2))`
- **e系数**：不生效

### 方案8：等体积质量模式（ctrl=mass）
- **驱动参数**：三环总质量 m₀+m₁+m₂, 密度 ρ
- **公式**：`Bv = (m₀+m₁+m₂) / (3ρ)`, 三环共用同一 Bv → `Bhᵢ = Bv / (π(BRᵢ²−Brᵢ²))`
- **效果**：内环面积最小 → Bh 最高，外环面积最大 → Bh 最低，自动满足高度排序
- **e系数**：不生效

### 方案9：等体积 + sp=质量数 + rp=P34（ctrl=mass）
- **驱动参数**：同方案8（三环总质量 m₀+m₁+m₂, 密度 ρ）
- **sp**：定子磁极数由 `massOverrides.m`（质量推荐）驱动，非滑条
- **rp**：滚筒磁极数固定为 `[34, 34, 34]`（P34 统一）
- **cfgSelect**：禁用，质量推荐自动填充
- **效果**：几何与方案8相同（等体积），但磁极数由 CSV 质量推荐确定，配合 P34 实现评分最大化
- **e系数**：不生效

## 四、全局约束与 9 步清洗流水线（所有方案强制，严格按序执行）

所有 BR/Br 计算完成后，统一执行以下 9 步约束：

| 步骤 | 约束 | 修正动作 | 说明 |
|---|---|---|---|
| ① 正厚度 | `BR[i] ≥ Br[i] + 1` | `BR[i]=Br[i]+1` | 防环反翻 |
| ② 间隙强制 | `Br[i+1] ≥ BR[i] + 2·Yr + clearanceGap` | 推大 `Br[i+1]` | 滚筒放得进 |
| ③ 后环正厚度 | `BR[i] ≥ Br[i] + 1`（步骤②推大了 Br） | 跟进扩大 `BR[i]` | 后环不反翻 |
| ④ **厚度排序** | `t₀ ≥ t₁ ≥ t₂`（`tᵢ=BR[i]−Br[i]`） | 缩 `Br[i]` 满足，软约束 | **全方案通用** |
| ⑤ 方案5等间距 | `Br[1]−BR[0] = Br[2]−BR[1]` | 取平均均匀分配 | 仅方案5 |
| ⑥ 方案4/5等厚 | `Br[i] = max(Br[i], BR[i]−t)`（`t=BR[0]−Br[0]`） | 软约束，间隙优先 | 仅方案4/5 |
| ⑦ 间隙复查 | `Br[i+1] ≥ BR[i] + 2·Yr + clearanceGap` | 推大 `Br[i+1]` | 等厚/等间距后再次验证 |
| ⑧ **绝对排序** | `Br[0]<BR[0]<Br[1]<BR[1]<Br[2]<BR[2]` | 最少 0.5cm 梯差强制修正 | 最后防线 |

### 7.2 定子极显示：unifiedVis（统一因子算法）

旧版使用 `bestDivisor(nP, 360)` 为每个环独立选择可显示段数。新版升级为 **unifiedVis(sp)**：

```
unifiedVis(sp₀, sp₁, sp₂):
  g = gcd(sp₀, sp₁, sp₂)       // 三环真正的 GCD
  若 g > 1:
    vis = 最大因子 ≤360 且 ≥60
  否则 (g = 1):
    收敛到最接近中位数的因子:
      med = 中位数(sp₀, sp₁, sp₂) 的因子
      选 ≤360 ≥60 的最大因子
  step = nP / vis（必为整数，无舍入）
```

**关键**：三环共享同一个 `vis` 值，保证在俯视图上显示**相同数量**的 N-S 段。`step = nP/vis` 始终为整数。

- **俯视图（卡片1）**：W×W 正方形，定子=环形材料层+红蓝磁极段（unifiedVis），滚筒=极点圆+公转轨道虚线+轨迹线可选
- **正视图（卡片2）**：宽度=W，高度自适应。定子=左右对称矩形条，滚筒=矩形居中悬浮，共用中线，间隙灰色带可视，中心虚线。8 段滚筒片在 info 行显示
