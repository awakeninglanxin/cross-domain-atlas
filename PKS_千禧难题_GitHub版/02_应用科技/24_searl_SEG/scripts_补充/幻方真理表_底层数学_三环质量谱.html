幻方真理表的底层数学：一张同余表，如何生成三环质量谱

01结论先行：六句话

  1. 幻方真理表 ≡ 一张同余表。 n 阶幻方每条线和 S 必须满足 S = T(n) + n·k，即 S ≡ T(n) (mod n)。（T(n)=n(n²−1)/2 是「最小行和」）
  2. T(n) mod n 只有两个值：n 奇 → 0；n 偶 → n/2。所以判据退化成「奇数阶整除 S」「偶数阶半整除 S」。
  3. N(S) 有闭式解，只由 S 的因式分解决定：奇数阶 = oddPart(S) 的因子；偶数阶 = 2v₂(S)+1·d（d | oddPart(S)，d 奇）。3,997 组零反例。
  4. 偶数阶被 2-adic 赋值锁死：凡是承载同一个 S 的偶数阶，v₂(n) 全部相等且 = v₂(S)+1。这就是 6/10/14/18 整体出局的真正原因，不是「筛掉了」，而是「不可能在」。零反例。
  5. 等差三环共享哪些阶，只由公差决定：∩N = { n ∈ N(首环) : n | 公差 }。3,997 组零反例 —— 一行就能验算，与几何侧的「等壁厚 / 等间隙」互为印证。
  6. 4410/6090/7770 是「4410 锚点下的数论上限」：公差 1680 保住 7 个阶、唯独丢掉 9；想保住 9 需要公差被 1260 整除，而 4410+1260=5670 根本不在池里。所以 7 已经是它能拿到的最高分。

02一行公式：从幻方定义到同余

n 阶幻方填 n² 个连续整数（0…n²−1），每条线 n 格。全部 n² 个数的和是 n²(n²−1)/2，共 n 条线（每格被数两次的细节先不管，它是常数项），把「最小排布」的每条线和记作 T(n)：

T(n) = n·(n² − 1) / 2 // 每条线的最小和：把 0..n²−1 排成最「均匀」的情形
S = T(n) + n·k , k ∈ ℤ, k ≥ 0
⟹ S ≡ T(n) (mod n) // 承载判据：只有这一句，全部筛选都从这里来

2.1定理：T(n) mod n 只有两种值

T(n)/n = (n² − 1)/2
n 为奇数 ⟹ n²−1 偶 ⟹ (n²−1)/2 整 ⟹ T(n) ≡ 0 (mod n)
n 为偶数 ⟹ n²−1 奇 ⟹ T(n)/n = (n²−1)/2 是「半整数」⟹ T(n) ≡ n/2 (mod n)

这条定理把「查表」变成了「两个整除条件」。原页面代码里的 residue(n) = (n%2===1) ? 0 : n/2 就是它（第 1900 行）。

n = 3…10 的门槛与余数（dim=2）。注意偶数行的余数恒为 n/2，与 n 无关地「错开半格」。

03闭式解：阶集合 = S 的因式分解

把 §2 的两个条件分别解到底，就得到一条不需要遍历阶数的公式。它说明：「一个 S 能被哪些阶承载」这件事，本质上不是幻方问题，而是因数问题。

3.1两条通道

设 S = 2^v · u ，u 为奇数（v = v₂(S)，u = oddPart(S)）

奇数阶通道：n 奇，判据 n | S ⟺ n | u（因 n 与 2^v 互素）
　　　　　　 ⟹ n ∈ { u 的奇因子 }，再被门槛 T(n) ≤ S 截一次

偶数阶通道：n = 2m，判据 S ≡ m (mod 2m) ⟺ S = m(2k+1)
　　　　　　 ⟹ v₂(S) = v₂(m)　（2k+1 是奇数，不贡献 2 的幂）
　　　　　　 ⟹ m = 2^v · d，d | u，d 奇　⟹ n = 2^(v+1) · d

这就是原页面 ordersClosed() 的实现（第 1860 行）：m0 = 2**(v+1)，偶数阶取 n % m0 === 0 且 u % (n/m0) === 0。本页把它和暴力法逐 S 比对了 79,989 个 S：反例 0。

3.2逐阶验算 S = 4410

4410 = 2¹ · 3² · 5 · 7²。所以 v=1、u=2205=3²·5·7²、m0=4。奇数阶只能取 2205 的因子，偶数阶只能取 4d（d 取 2205 的奇因子）。门槛 T(n) ≤ 4410 再砍一刀。

S = 4410 的八个承载阶，逐条复算。最后一列是「如果没有门槛会被多算进来的阶」——门槛的作用是把大阶挡住，这也是为什么 b=55 与 d=80000 必须配套（§5.2）。

042-adic 锁定：为什么 6/10/14/18 整体出局

§3 的偶数通道推出一条比「整除」更狠的约束：

凡是承载同一个 S 的偶数阶 n，必须满足 v₂(n) = v₂(S) + 1　// v₂ = 因子中 2 的幂次

4410 = 2·3²·5·7² ⟹ v₂(S)=1 ⟹ 所有偶数阶必须 v₂(n)=2 ⟹ n 是 4 的倍数但不是 8 的倍数
⟹ {4, 12, 20, 28, 36, 44, 52} 可以；{6, 10, 14, 18, 22, 26} 永远不行

这不是「筛掉」，是结构性不可能：6=2·3，v₂=1，要承载 S 就得让 S = 3·奇数，于是 v₂(S)=0，与 v₂(S)=1 矛盾。所以原页面上那句「6/10/14/18 整体出局」背后是一条定理，而不是一次实验。

同一个 S 的阶集合里，偶数阶的 v₂ 全部落在同一层。表中 4410 的三个偶数阶都是 4 的倍数、都不是 8 的倍数。

这解释了 SEG 与 IGV 两套为什么天生「不同轨」：SEG 锚点 4410 是偶的（v₂=1），走 4 倍数阶那一层；IGV 锚点 2205 是奇的（v₂=0），走 2 mod 4 那一层。两套的共享阶集合永远不会重合——这不是设计选择，是奇偶性决定的。

05幻方团 e=8：参数不是随便填的

「幻方团」= 恰好被 e 个阶承载的 S 的集合。e=8、a=3、b=55、c=12、d=80000 时，团里有 1,566 个 S；其中同时含 {3,4,5} 的 167 个，含 {3,5,6} 的 309 个。这三个数与页面实时重算逐位吻合。

图 1　|N(S)| 的分布（S ∈ [12, 80000]，共 79,989 个 S）。紫色柱 = e=8 这一层（1,566 个）。分布不是钟形而是长尾：|N| 最大能到 20（S=69,615），因为大 S 既有更多因子、门槛又几乎不截断。e=8 落在下降段——这意味着「恰好 8 阶」是一个相当稀缺的事件。

5.1为什么 e 恰好是 8

这不是先验设定，而是从 4410 数出来的：Searl 原文 Exercise 5 说「8 个 square 共享 value 4410」，而 N(4410) 恰有 8 个元素。所以因果链是：

4410 = 147 × T(4) = 147 × 30　// 147 个磁体单元 × 4 阶幻方基数
⟹ N(4410) = {3,4,5,7,9,12,15,20}，|N| = 8
⟹ 「8 个 square」= 「8 个承载阶」⟹ e = 8 被固定下来
口径提醒（会影响结论的方向） 页面把 e 当输入参数，但历史上它是输出。做考古时把 e 当输入没问题（能扫出 1566 个同构点）；但若要问「Searl 为什么选 8」，答案不是「他设了 8」，而是「4410 恰好有 8 个承载阶」。这两句话的方向相反。

5.2参数为什么是 b=55 与 d=80000 这一对

T(54) = 54·(54²−1)/2 = 78,705 ≤ 80,000 < T(55) = 83,160
⟹ S 上限 80,000 的自然阶上限就是 54（55 已越界）

所以 b=55、d=80000 不是两个独立旋钮，是同一条边界。谁把 d 改成 200,000 而 b 不动，就会把 55 以上的阶全部人为排除；反之把 b 加到 100 而 d 不动，新增的阶压根承载不了任何 S，白算。原表的这组参数本身自洽。

5.3反过来问：e 能不能不是 8？（能 —— 而且 8 不是最优）

5.1 说的是「历史上 e 是输出」。但老师问得对：如果反过来把 e 当目标，8 是不是最好的选择？ 把 e 从 4 扫到 13，只量三件与工程有关的事 —— 这一层有多少个 S（供给）、其中几个能同时承载 {3,4,5}（SEG 口径）、 这些 S 能凑出多少组三项等差（＝ 能派生多少套三环方案）。规模上限沿用原表（S ≤ 80,000、n ≤ 55）。

三个结论，都不利于「e 越大越好」：

  1. 峰值在 6，不在 8。可证 e=6 有 6,961 组可用三环方案 （其中公差 ≥1680 的还有 6,436 组，三环差异并不比 1680 小），是 e=8 的 6.3 倍； 而它的质量门槛只要 990，是 e=8（3,990）的 1/4。 峰值落在 6 的原因很直白：e < 5 时连 {3,4,5} 都放不下（供给再大也没用）； e > 6 之后「恰好 e 个阶」的 S 数量塌得更快（3,930 → 1,566 → 149）⟹ 供给衰减压倒了自由度增长。
  2. e=4 不是「更便宜」，是「几乎没有选择」。可证 全窗口只有 10 个 S 含 {3,4,5}，凑出 8 组等差，最大公差只到 600 （三环质量几乎一样，机械上没有意义）；扣掉 345 只剩 1 个自由阶 ⟹ 做不出「一个质量、多种结构」。 e=5 也弱（25 个 S / 56 组 / 最大公差 1,560）。
  3. e=8 买到的是「单个 S 的内部自由度」，不是「方案数量」。可证 e=8 比 e=6 多 2 个共享阶（8 个 vs 6 个，扣掉 345 后 5 vs 3）⟹ 同一个 4410 能同时被更多结构承载； 代价是可选 S 少 2.5 倍、质量门槛贵 4 倍。一句话：e=8 是「把一个质量榨到最深」，e=6 是「用最少的质量铺最宽的选择面」。
那 Searl 为什么偏偏是 8？—— 数学给不出答案，三条线索都在数学之外 ① 4410 = 147 × T(4)：147 个磁体单元 × 4 阶幻方基数，这个分解本身就把 S 钉死在 4410， 而 N(4410) 恰好 8 个阶 —— 先有 4410，e=8 是被数出来的，不是被挑的。
② 原文 Exercise 5 说「8 个 square 共享 4410」：若 square 就是阶，8 是他数出来的结果，不是参数。
③ 8 是他的母题（老师补充的传记线索）：多次梦境里出现的「跳房子」就是 8 格。 这一条无法验证，但它解释了「为什么所有落在 8 附近的选择，他都会觉得对」。
⟹ 结论：e=8 不是数学最优，是「4410 的既成事实 + 个人母题」叠出来的一个点。 今天若从零设计，e=6 更划算（方案多 6.3 倍、质量省 3/4），代价是每个质量少 2 个共享阶； 若目标是「同一块铁里塞进尽可能多的结构」，那 e 越大越好 —— 只要接受 S 指数变贵（e=12 的门槛 22,050，是 e=6 的 22 倍）。

06等差三环谱：公差就是共享开关

三环质量取 a, b, c 且成等差（b−a = c−b = d）。这件事在幻方语言里有确切含义，而且只需要一行判据。

6.1判据：三环共享的阶 = 公差在首环阶集合里的因子

N(a) ∩ N(b) ∩ N(c) = { n ∈ N(a) : d mod n == 0 }　// d = (c−a)/2
已在 SEG 1107 组 + IGV 2890 组 = 3,997 组上全量验证：反例 0。

推导很短：b = a+d、c = a+2d，所以对任何 n，n | d ⟹ a、b、c 三者在 mod n 下同余，判据 S ≡ T(n) 的成立与否完全一致；反过来若 n ∤ d，三者的余数必然错开，最多只有一个能命中。于是「共享阶数」完全由 d 的因子决定。

这就是「等差」在数论上的功能 公差 d 是一次「同步位移」。d 被哪些阶整除，那些阶就在三环上同时成立。所以 d 的因子集 = 三环的公共阶集。这与几何侧的结论（等壁厚 ⟺ 等间隙 ⟺ 质量等差 ⟺ 同一把刀）是同一件事的两个投影：几何说「同一把刀」，数论说「同一个同余类」。

07坐标化：4410/6090/7770 只是其中一组

把三环放进坐标系，这个组合的全部信息就是三行字 —— 但先别把这三行当成「唯一解」： 它们只是把「三项等差」归一化之后的写法，换一组同样合法（本节末尾给出四组同形式的实例）。

4410 = 210 × 21　　6090 = 210 × 29　　7770 = 210 × 37　　// 公差 1680 = 210 × 8
N(4410) = {3,4,5,7,9,12,15,20}　N(6090) = N(7770) = {3,4,5,7,12,15,20,21}
∩ = {3,4,5,7,12,15,20}（7 个）　内环私有阶 = {9}　中/外环私有阶 = ∅
这三行不是硬编码 —— 换成任意一组三项等差，形式一个字都不用改 4410 / 6090 / 7770 写成 210 × (21, 29, 37)，只是把它归一化：把三个数的公因子提出来， 剩下的三个数恰好差 8。任意一组三项等差都能这么写 —— (a, a+d, a+2d) ＝ g·(k, k+j, k+2j)，其中 g ＝ gcd(a, d)。 上面那三行同余式的结构完全不变，变的只是数字，以及交集里还剩哪几个阶。

08Searl 为什么用这套算法

把「可证」与「推测」分开写，前者能给判据，后者只能给动机。

8.1四条可证的

  1. 它不是「选」的，是幻方定义强加的。可证 S = T(n) + n·k 是幻方行和的唯一形式，所以 S ≡ T(n) (mod n) 没有第二种可能。任何「用幻方做设计」的人都只能得到这张同余表。
  2. 它其实在算因子。可证 闭式解说明 N(S) 由 S 的奇偶分解完全决定（零反例）。所以这套表的价值不是「幻方美学」，而是把整数 S 的因子格翻译成「能同时做几种幻方」。
  3. 它自带一条硬分层。可证 偶数阶被 v₂ 锁在同一层（零反例）。这给了一个天然分层：v₂(S)=0 的只能用 v₂(n)=1（2 mod 4 的阶）；v₂(S)=1 的只能用 v₂(n)=2（4 的倍数但非 8 的倍数）；一般地 v₂(n) = v₂(S)+1。一台机器不可能跨层 —— 这正是 SEG（偶）与 IGV（奇）两套谱系不重合的根源。
  4. 等差把「共享」变成可调节的量。可证 ∩N = {n ∈ N(a) : n | d}（零反例）。所以选公差就是在选「三环要共享哪些阶」。这与机械侧的约束（等壁厚 ⟹ 极距恒定 ⟹ 一把刀）指向同一个解，两条完全独立的路径收敛到「等差」，这才使等差成为一个可靠的设计传统，而不是审美偏好。

极距 τ（pole pitch）＝ 相邻两个磁极中心线之间、沿气隙圆周量出的弧长。 标准写法 τ = πD / 2p（D 外径、2p 极数），等价于 τ = 2πR / N—— 两条中心线夹的圆心角是 360°/N，落在中径上的那段弧就是 τ，它同时等于「一个极宽 + 一个齿槽宽」， 也就是「走一格」的完整周节。右图把三环圆周摊平：横条长度不同（12τ / 20τ / 28τ）， 但每一格的宽度是同一个 τ ＝ π·Yr ＝ 7.24 cm（方案 10：Yr ＝ 2.3041 cm， 2π·BR/num 逐环算 = 7.239 / 7.239 / 7.239 cm），所以三条的格子能对齐。

为什么「τ 恒定」比「壁厚恒定」更基本 —— 方案 11 正好是反例 在方案 10 这副骨架上，下面四条同时成立、互为等价写法： 等壁厚 t ≡ 3.61 ⟺ 恒间隙 5.61 / 5.61 ⟺ BR/num ≡ Yr/2 ⟺ τ ≡ 7.24。 而方案 11 把等壁厚放开了（壁厚变成 4.87 / 3.61 / 3.19 三个数、间隙 5.61 / 6.03 也不再相等）， 但 τ 仍然是 7.24——因为它的 Yr 没动（2.3041）、num 仍是 12/20/28。 ⟹ 「等壁厚」不是 τ 恒定的原因，二者是同一条「半径与极数按比例同步」的两个投影； 真正决定「能不能共用一把刀 / 一套绕线节距」的是 τ，而不是壁厚。
工程含义（推断，不是可证）：τ 一样 ⟹ 齿形、冲片模、绕线节距、刀具周进给全部通用， 换环只是「多转几格」；τ 不一样 ⟹ 三个环三套工装。这就是「等差」在机械上买到的东西， 也是 8.2 那条推测里「一个质量派生出多种极数方案」能落地的前提。

8.2两条推测（标明是推测）

  1. e=8 是「8 个 square」的数论翻译。推测 原书说 8 个 square 共享 4410，本页算出 N(4410) 恰好 8 个阶。「square」与「阶」是不是同一个东西，取决于原书语境；但从数字上看，二者一一对应，且 4410 = 147×T(4) 也自洽。
  2. 他真正要的是「一个质量，多重结构」。推测 e 越大，同一个 S 能被越多阶的幻方阵列承载，意味着「同一批磁体可以按多种极数排布而幻和守恒」。这在工程上等价于模块化：一个质量基准能派生出多种极数方案。三环等差再把这个性质锁成「三份拷贝 + 可调的共享子集」，与前面解出的几何闭式解（等壁厚 ⟹ 极距恒定）正好互锁。
