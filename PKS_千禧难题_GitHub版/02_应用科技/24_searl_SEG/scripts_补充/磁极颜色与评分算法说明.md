## 二、2D 俯视图磁极颜色规则

### 2.1 画布自适应

```
W = min(window.innerWidth − 32, 1400)  // 1400px 上限
H1 = W                                  // 2D俯视 = 正方形
H2 = max(W × 0.4, hS₀ × 3.2 + 60)     // 正视图自适高
scale = W × 0.45 / maxR                 // 俯视+正视统一缩放
```

窗口越宽 → 缩放越大 → 磁极段越清晰可辨。1400px 时磁极密度是原来 500px 的 2.8 倍。

### 2.2 定子环 (drawStator2D) — unifiedVis 统一因子算法

定子环由多层同心材料环构成。仅**磁性层**（`color==='mag'`）显示磁极颜色。

```
nP  = sp[i]                            // 定子磁极数
vis = unifiedVis(sp)                    // 三环 GCD → 最大因子 ≤360 ≥60
step = nP / vis                        // 每段代表的真实极对数（必为整数）

对于 i = 0 到 vis-1：
    isN = floor(i × step) % 2 === 0   // 偶数为 N 极，奇数为 S 极
    颜色 = isN ? 红(#ff5050) : 蓝(#5080ff)
    弧段 = [a, a + 2π/vis × 0.85]     // 0.85 留缝隙
```

**unifiedVis 算法**：
```
unifiedVis(sp₀, sp₁, sp₂):
  g = gcd(sp₀, sp₁, sp₂)
  若 g > 1: vis = g 的最大因子 ≤360 ≥60
  若 g = 1: vis = median(sp) 的最大因子 ≤360 ≥60
```

**关键改进**：旧版 `bestDivisor(nP, 360)` 各环独立选择 → 三环显示段数可能不同。新版 `unifiedVis(sp)` 三环共享同一 `vis`，保证俯视图三环显示**相同数量**的 N-S 段。`step = nP/vis` 始终为整数。

### 2.3 为何可见极段数 ≠ 实际极数（unifiedVis 示例）

方案9 `sp = [5250, 8250, 11250]`，但屏幕上看到的段数与实际极数不同。

**三环统一因子算法** `unifiedVis(sp)`：

```
1. 计算 g = gcd(sp₀, sp₁, sp₂)  // 三环最大公约数
2. 若 g > 1: vis = g 的最大因子 ≤360 且 ≥60
3. 若 g = 1: vis = median(sp) 的最大因子 ≤360 ≥60
4. step = nP / vis（必为整数）
```

| nP | 因子(≤360) | vis | step | 说明 |
|---|---|---|---|---|
| 5,250 | 350 | **350** | 15 | 每段恰好15个极对 ✓ |
| 8,250 | 330 | **330** | 25 | 每段恰好25个极对 ✓ |
| 11,250 | 250 | **250** | 45 | 每段恰好45个极对 ✓ |

### 2.4 全极数直绘模式（全局勾选）

物理系数行末尾的 `☑ 全极数直绘(不压缩)` 勾选框对所有方案生效：

- **不勾**（默认）→ 用 `unifiedVis` 压缩，vis = GCD 的最大因子 ≤360，三环统一段数
- **勾上** → `vis = nP`，直接绘制全部极数弧段，`step = 1`，像素级精确一对一

该选项仅影响俯视图磁极段显示，不改变几何引擎中的任何物理参数。
| 7,594 | 2 | 180(回退) | 42.2 | 2×3797，超大质因子→回退 |
| 12,286 | 2 | 180(回退) | 68.3 | 2×6143（质数）→回退 |
| 1,680 | 336 | **336** | 5 | 每段恰好5个极对 ✓ |

**核心改进**：对方案9的三环（5250/8250/11250），全部命中整数因子——350/330/250 段，每段分别精确代表 15/25/45 个真实极对。红蓝交替按 `floor(i×step)%2` 严格同步于真实极数结构。

**滚筒同理**：

```
pPerRoller = rp[i]                     // 滚筒磁极数（P34=34）
sz = pPerRoller > 30 ? 1.2 : 2       // >30极→缩点(1.2px), ≤30→正常(2px)
→ 方案9 P34: 34>30 → sz=1.2px, 每个滚筒内画 34 个迷你红蓝方点
```

**这样显示的 4 个好处**：

1. **性能** — 画布自适应宽 `min(vw−32, 900)`，最大 900² 像素。`vis` 可达 ~360 段，浏览器轻松渲染 60fps。

2. **视觉可读** — 900px 宽时弧段宽度是原 500px 的 1.8 倍，N-S 交替清晰可辨。方案9的 350 段（5250极）看起来像细密梳齿而非灰团。

3. **语义精确** — `bestDivisor` 保证 `step = nP/vis` 是整数，红蓝交替严格按真实极结构对齐。例如 5250 极 → vis=350, step=15 → 每 15 个极对一色，0 舍入误差。

4. **滚筒自保** — P34 自动缩点 1.2px，P22 保持 2px。极数不管多大都能渲染。

### 2.2 滚筒 (drawRoller2D)

每个滚筒是一个彩色圆，内部有**小方点**代表极：

```
pPerRoller = rp[i]                     // 滚筒磁极数

对于 k = 0 到 pPerRoller-1：
    k % 2 === 0 → 红色方点(N)
    k % 2 !== 0 → 蓝色方点(S)
```

同样纯索引驱动，不使用数学运算。极数 >30 时方点缩小到 1.2px，≤30 时为 2px。

## 三、几何约束体系（滑条层硬限制）

### 3.1 k1/k2 双重高度约束（二选一）

滚筒高度受限于两种约束模式，通过下拉菜单切换：

| 模式 | 约束公式 | 默认值 | 范围 |
|:---|:---|:---:|:---:|
| **k1 比例约束** | `hR ≤ hS / k` | k=1.2 | 1.0 - 1.5 |
| **k2 间隙约束** | `hR = max(1, hS − 2 × k2)` | k2=1cm | 0 - 9cm |

**物理含义**：
- k1：滚筒高 ≤ 定子高/k，控制比例。k=1 时滚筒可填满定子，k=1.5 时最多占 2/3
- k2：滚筒距定子上下各 k2 cm 间隙，滚筒高 = 定子高 − 2×k2

### 3.2 其他硬约束

| 约束 | 公式 / 范围 | 说明 |
|:---|:---|:---|
| V定子环min | `min(定子体积₀,₁,₂) ≥ threshold` | 仅检查定子环体积（不检查滚筒） |
| 间隙下限 | `gap ≥ 2×Yr + clearanceGap` | 1-5cm 滑条，默认 1cm |
| Br₀ 范围 | 0-2000cm, step=0.5 | 最内环内径 |
| 滚筒数量 | `num₀ < num₁ < num₂` | 硬排序 |
| 滚筒片质量 | 8片/滚筒, 1-120g/片 | 默认 34g (272g/颗) |
| 滚筒最小体积 | `min(单颗滚筒体积) ≥ minRollerVol` | 0.1-30cm³, 默认 3 |

## 四、评分算法 (smoothScore) — 此处使用 gcd/lcm

### 4.1 半极数

评分基于半极数 `hp = sp/2`、`hr = rp/2`（磁极总是成对出现，每对一N一S）。

### 4.2 评分公式（满分≈100）

| 项目 | 公式 | 满分 | 含义 |
|---|---|---|---|
| 互质奖励 | 每环 `gcd(hp[i], hr[i])===1` → +22 | 66 | 单环内定子/滚筒极数互质，避免共振 |
| 跨环耦合 | `cgS = Σ 1/(gcd(hp[i], hp[i+1])+1)`，换算 `18×cgS/(rings-1)` | 18 | 相邻环半极数互质程度越高，交叉干涉越小 |
| 滚筒多样性 | `diff = 不同滚筒极数对数 × 2` | 4~6 | 三环滚筒极数全相同额外+8 |
| LCM 寿命 | `log₁₀(lcm(hp₀, hp₁, hp₂) + 1) × 0.9` | ~10 | LCM 越大 → 退磁周期越长 → 寿命越高 |

**方案9特殊评分**：sp 使用质量推荐数（如 `[5250, 8250, 11250]`），rp 固定 `[34, 34, 34]`（P34统一）。评分中：
- gcd 项：检查每个环 `gcd(hp[i], 17)`（P34 半极数=17）
- 滚筒多样性：全相同 → +8 统一奖励，差异化=0
- diff 项：`2×(0) + 8 = 8`（P34 统一）
- smoothScore 总结构: gcd(66) + cross(9) + LCM(0.9×log₁₀) + diff: 2*(不等数)+8*(P34统一)

### 4.3 评分示例

以原版 Searl `sp=[7594,12286,19882], rp=[34,34,34]`：

```
hp = [3797, 6143, 9941]
hr = [17, 17, 17]

环1: gcd(3797, 17) = 17 → 不互质 → 0分
环2: gcd(6143, 17) = 17 → 不互质 → 0分
环3: gcd(9941, 17) = 17 → 不互质 → 0分
→ 互质奖励 = 0

跨环: gcd(3797,6143)=1, gcd(6143,9941)=1 → cgS=1 → 18分
滚筒全相同 → +8
LCM(3797,6143,9941)≈7.2×10¹⁰ → log10≈10.86 → +9.8分
总 ≈ 36分
```

这就是为什么原版 Searl 评分偏低——定子极数与滚筒 P34 有公约数 17。

## 五、颜色与评分的关系

| 层面 | 颜色 | 使用 gcd/lcm？ |
|---|---|---|
| 2D视图定子极颜色 | 红(N)/蓝(S)交替弧段 | ❌ 奇偶索引（bestDivisor选因子，整数step） |
| 2D视图滚筒极颜色 | 红/蓝方点交替（>30极自动缩点） | ❌ 奇偶索引 |
| 评分(smoothScore) | 绿≥80/黄≥50/红<50 | ✅ gcd + lcm |
| 状态栏"全互质" | 绿色✓/红色✗ | ✅ gcd 检查 |
| cfgSelect 行颜色 | 红色=✗失败 | 基于评分 |

**总结**：磁极的颜色显示（红蓝交替弧段/方点）只是可视化标记，不涉及数学运算。gcd/lcm 仅在**评分系统**中用于评估配置优劣——互质程度越高、LCM越大 → 评分越高 → 理论性能越优。
