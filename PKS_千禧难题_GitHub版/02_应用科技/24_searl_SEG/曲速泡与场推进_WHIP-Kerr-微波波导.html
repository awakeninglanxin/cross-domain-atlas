Ⅰ 三条路子 —— 先把「它们在做什么」分清

2.6 ★ 本页复算：式(4) 的灵敏度比原文说的还要差 C

Davis 给的判据是「B > 10⁹~10¹⁰ T 才能测到光速变慢」。本页把式(4) 的指数单独拿出来看：

把 L/a 用 K 改写 L / a = L · B / K 代入原文自己设的实验室参数（螺线管长 L ≈ 0.1 m、B = 1000 T）： L / a = 0.1 × 1000 / 3.4840×10¹⁸ = 2.87 × 10⁻¹⁷ 而 v(0)/c = 2·exp(ε/2) / (exp(ε) + 1)，ε ≡ L/a。ε → 0 时展开： v(0)/c ≈ 1 − ε² / 8 ε = 2.87×10⁻¹⁷ 时：v(0)/c = 1 − 1.03×10⁻³⁴ ⇒ 与 1 在双精度下完全不可分。

要让它进入「勉强可测」的区间（取 c²−v²(0) ≥ 10⁴ m²/s²，即原文自己给的下限），需要 ε ≥ 6.67×10⁻⁷；在 L = 0.1 m 时对应 B ≈ 2.3×10¹³ T。

复算结论

在桌面尺度的螺线管（L ~ 0.1 m）里，原文「>10⁹~10¹⁰ T 就能测到」这句话偏乐观约 3~4 个数量级。 要让「10⁹ T」这个数字成立，L 得到公里级（因为 ε = LB/K，且 a(B=10⁹ T) = 3.48×10⁹ m ≈ 3.5×10⁶ km）。
本页不是要否定 WHIP —— 恰恰相反，这说明 WHIP 的公式是可以被这样追问的： 它把 L、B、a、v(0) 四个量都写明了，所以别人能拿它算。这正是它与本页其余三份底本最大的不同。
C 本页复算，假设 ε²/8 展开在 ε < 10⁻⁶ 时有效（该处误差 < 10⁻¹²），其余用原文常数。

Ⅳ Kerr 环奇点 —— 为什么"理论上可以进去"

底本：A Brief Introduction to the Kerr Metric Space Warp（as extracted from the Glossary of StarDrive Engineering）， Archer Enterprises, Heanen, Geneva, NY。这是一份术语表条目，不是论文，请按科普材料读。

对象谁提出的奇点形状飞船能不能穿原文措辞
Schwarzschild 度规Karl Schwarzschild，1916 点状奇点（point-like singularity） 不能 只对「静态」（零自转、零净电荷）黑洞严格成立
Einstein–Rosen 桥由静态黑洞产生 点状奇点 不能 —— 「飞船无法穿越 E-R 桥，因为黑洞含有一个点状奇点」 原文说这是为保持 Schwarzschild 解内部自洽而必须存在的一个现象
Kerr 度规空间翘曲新西兰数学家 Roy Kerr 环形（annular / ring）奇点 理论上可以 —— 沿着一条横切黑洞自转平面的轨迹，可完整进入 「它仍然需要一条虫洞，但在这个情况下，理论上有可能沿某条横切自转平面的轨迹完好地进入这个空间翘曲」

原文还说清了「度规」这个词在这里的用法：度规就是「在给定参考系里求两点间距离的公式」； 所以 Kerr 度规空间翘曲就是「一个真的能算出虫洞所必须具有的缩短后长度的度规 —— 前提是飞船通过它的速度仍被正确地限制在小于光速」。 ⇒ 请注意这句话的形状：它把"能不能穿"换成了一个"能算的长度"，而不是给一个证据。

4.1 与 SEG 的关系：C 本页的判断

只有"环形"这一个词是共用的

SEG 的「环」是室温下的钕铁硼/钴钢圆环，靠磁力与涡流把滚筒托起来转； Kerr 的「环」是引力塌缩后的时空奇点，必须在黑洞里。 两者除了都写成"环"字，没有任何共同量 —— 没有共同的方程、没有共同的尺度、没有可互换的参数。 本页因此不把它们并列，只标注：这是同一份资料集里的两条互不相干的线。

⚠ 一处本页查不到出处的说法：此前交流中出现过「Kerr 的论文发表在赖特-帕特森空军基地」这一类说法。 本页复核了这份底本全文，其中没有这句话。因此本页不采用该说法，列在此处备查。

5.1 核心图示：碟的截面 = 圆形波导的 TM₁₁ 模式

原文的整个论证只有一句话的骨架：「把碟当成波导，与圆形波导里的横磁波（TM）作比较，两者的图形图案相似。」 然后给出关键一步：「把这一截面旋转一圈，得到的就是一个球面波导 —— 而那正是我们那台『运动模型（sportmodel）』的几何。」

Ⅶ 与 SEG 正面对照 —— 这四份底本里，什么能搬回 SEG

7.1 三条可以搬回 SEG 的做法（不是物理，是写法）

#搬什么从哪来搬回 SEG 具体怎么做
1 参数化的"配平"自检 Hull 表：面积配平 2×10⁻⁵、体积配平 3×10⁻⁵ SEG 的资料里没有任何一条"守恒/配平"式的自检。可以照 Hull 的做法，给三环 + 滚筒定一组几何（环外径、环厚、滚筒径、分段数、气隙）， 然后要求某一个量必须配平 —— 例如：三环的磁极带总数应为偶数且与滚筒分片数成整比（母页铁律③ 已有 4410/3990 的实例）， 或者环外径恒等于 A.C. 内缘（母页已作为不变量）。把已有不变量写成关系式，再报残差，就是这一步。
2 写清"多大的量才测得出来" WHIP：把 10⁹~10¹⁰ T 这个门槛写在摘要里 SEG 资料里最缺的就是这一句。母页里那条最可检验的设计 —— 「负载电流 vs 绕组温度」曲线 （SEG 说加负载降温、常规系统加负载升温）—— 正好需要配一个可测门槛： 用多大电流、升几度、用几分精度的温度计才算数。WHIP 的写法可以直接照抄格式。
3 一个"自曝其短"的段落 Davis 在自己论文里推翻自己引用的前提（第 Ⅲ 视图） SEG 的公开资料里没有这种段落。若要在 SEG 页面上加一段， 最诚实的候选是：「本页所有电磁数值都是假设，因为没有一篇 SEG 资料给出过工作磁场强度」 —— 这一句本身就是一条重要的空白（与母页"SEG 自运行态对外电位没有带仪器的直接读数"同源）。

7.2 四条绝不能对等的东西

看起来像实际差别为什么不能对等
SEG 的「环」 ↔ Kerr 的「环奇点」 室温钕铁硼圆环 ↔ 引力塌缩后的时空奇点 无共同方程、无共同尺度、无共同可观测量。只有一个汉字相同
「磁场造曲率」↔ SEG 的「磁场」 WHIP 用 10⁹~10¹⁰ T 级场；SEG 的充磁头用的是电容放电（充电电压级别） 两者相差 10 个数量级以上，且 SEG 从未给出过工作磁场强度。 把它们相除是典型的口径混用（母页铁律：不同口径不许相除）

8.1 十组禁止引伸

#禁止理由
1把「B = 1000 T ⇒ a = 0.368 光年」读成「有装置能造出 0.37 光年的曲率」 0.368 光年是曲率半径的值，不是"效果强度"；同一份论文自己说在 1000 T 下 c²−v²(0) ≈ 0 m²/s²
2把「1 光年虫洞只需 118.5 T」读成「118.5 T 能造虫洞」 原文是「假如已有 1 光年喉，118.5 T 的张力足以把它撑住」，是维持不是产生。见 Ⅱ.4
3把 Hull 的「配平误差 2×10⁻⁵」读成「这个几何已被验证」 它验证的是表自己内部自洽，表里没有任何磁场、功率、材料或实测数据
4把 Kerr 的「理论上可以沿某条轨迹进入」读成「已经可以穿越」 那是术语表里的一句定性描述，且前提是存在一个旋转黑洞
5把「效应期间碟对肉眼不可见」当作观测证据 该断言无法被证伪（看不见可以说成效应、也可以说成没来）
6把「每秒 7.5 次脉冲」当作物理常数 原文没有给出任何来源或测量方式
7把 S4 的「引力放大器」与 SEG 的滚筒混为一谈 一个是外部驱动、可定位的放大器；一个是靠磁引力/涡流斥力自持定位的滚筒。驱动方式相反
8把 WHIP 的公式代入 SEG 的数字 SEG 从未给出过工作磁场强度，代不进去。硬代属于凭空造参数
9把「10¹³ T 门槛」（本页复算）当作对 WHIP 的否定 这是对原文某一句话的精度追问，不是对机制的否证。机制能否成立，取决于实验，不取决于本页的算术
10把本页的 C 级内容当史实 凡标 C 的都是本项目推演，不构成任何一方的证据
