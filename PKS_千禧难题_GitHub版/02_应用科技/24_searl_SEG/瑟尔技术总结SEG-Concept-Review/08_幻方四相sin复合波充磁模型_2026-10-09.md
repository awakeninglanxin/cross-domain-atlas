## 0. 一句话结论

**中层 Phasing 不是"四段半正弦脉冲"，而是「幻方 level-2 数和」给出的四个频率各自的 sin 相加成的复合波——
四象限 = 四个独立绕组，一相一个频率，四路全用 sin。**

> ⚠️ **订正一（第一轮）**：项目内网页曾写「Phasing 四相 0/90/180/270°」，
> 那是把源文档的两句话（「**四段独立控流**」与「**上套 Phasing=0° / 下套 Phasing=90°**」）错拼在一起的产物。
> 后者的 90° 是**上下两套线圈之间**的相位差，**不是**单环内的四相。源文档里**没有**"0/90/180/270°"这个说法。

> ⚠️⚠️ **订正二（第二轮，★ 关键）**：上下两套之间的那** 90° 是「运行时驱动自转」档，不是充磁档**。
> 老师给的充磁波形示意图用的是 **「上套 0° / 下套 180°」——互为反相**。
> 因为 `sin(ft + π) = −sin(ft)`，180° 时**下半边恰好等于上半边取反** ⇒ 上下半边严格镜像 ⇒ 上下对称驻波、**全厚度一次写透**；
> 而 90° 时下半边变成 `Σcos`（正交相），上下不再镜像。**充磁必须用 180°，90° 只用于整机运转。**

## 1. 三种幻方 ↔ 三种磁纹 ↔ 三种机型

| 幻方阶（类型） | level-2 数和 | 四相频率（Hz） | 波 | 侧纹形态 | 机型 |
|---|---|---|---|---|---|
| 三阶（**奇阶**） | 15 | **17 / 19 / 21 / 23** | `sin17t + sin19t + sin21t + sin23t` | 疏而深、上下严格对称 = **驻波** | 炼丹 / Bedini 式自激电动机 |
| 四阶（**双偶阶**） | 34 | **34 / 68 / 102 / 136** | `sin34t + sin68t + sin102t + sin136t` | **V 字（&gt;&gt;&gt;）条纹循环** | **SEG（瑟尔机）** |
| 六阶（**单偶阶**） | 666 | **39 / 147 / 186 / 333** | `sin39t + sin147t + sin186t + sin333t` | **鱼骨纹**（147 / 186 为对冲频率） | **IGV（飞碟滚筒片）** |

Wolfram Alpha 一行复现：
```
plot (sin(34t) + sin(68t) + sin(102t) + sin(136t)) for t from -pi to pi
```

### 1.1 📐 为什么三种纹路"长得不一样"——本次的独立推导

- **四阶**：34 / 68 / 102 / 136 = **34 × {1,2,3,4}**，是一列**谐波**（最高是基频的整数倍）
  ⇒ 整个和式的严格周期 = 2π/34，**同一段子波被无限复现** ⇒ 侧面看到的是规整重复的"V 字/V 排"循环。
- **三阶**：17 / 19 / 21 / 23 四路**互质**（gcd = 1）⇒ 整体周期 = 2π，**没有任何更小的重复单元**
  ⇒ 只能看到四路拍频造成的疏密相间的深尖峰，且上下包络严格镜像（= 驻波）。
- **六阶**：39 / 147 / 186 / 333 **全是 3 的倍数**（gcd = 3）⇒ 周期 = 2π/3，每 2π 内出现 3 段
  ⇒ 单位长度上的条纹密度**远高于四阶**，同时仍保留 `>` 字斜纹 ⇒ 视觉上像"鱼骨"。

> 这一条是**从频率的整除关系直接读出来的**，与老师给的三种纹路命名**互相自洽**：奇阶 → 不重复 → 驻波；
> 双偶阶 → 谐波列 → 规整循环；单偶阶 → 公因子 3 → 高密度鱼骨。**这是本模型里最硬的一块。**

## 2. ★ 三条关键设计规则

| # | 规则 | 后果 |
|---|---|---|
| **1** | **四路必须全部用 sin，不许混 cos** | 只要有一路换成 cos（或某一套线圈反接成 cos 相），上下半边的包络就**不再镜像**，侧纹出现**「断纹路」** ⇒ **充磁失败**。这是**唯一能只看波形就判废**的判据。 |
| **2** | **四象限 = 四个独立绕组**：36 匝 ÷ 4 = **9 匝/象限** | Phasing 电源**通道数 = 4**（不是 1，也不是 2）。四路各自独立可调 —— 这是"雕刻任意磁极数"的硬件前提。 |
| **3** | **充磁档：上套 0° / 下套 180°（互为反相）**；**运行档：上套 0° / 下套 90°** | 充磁用 180° ⇒ 下半边 = −上半边 ⇒ 上下严格镜像 ⇒ 上下对称驻波、**全厚度一次写透**（老师给的图就是这一档）。90° 是**运行时驱动自转**用的（`sin` 与 `cos` 正交 ⇒ 产生切向驱动力 `T ∝ sin Δφ`，90° 时最大），**充磁时若误用 90° 则下半边变成 Σcos、上下不镜像 → 报废**。 |

**规则 1 的证据**（来自老师给的图，均已核对过画面）：
- 《瑟尔四阶seg…上半 Plot》下半排三格：`sin34+cos34+sin34+cos34`、`sin34+cos68+sin136`、`sin34+cos68` ——
  图上用**红虚线**画出上下包络，肉眼可见**两包络不重合** ⇒ 上半边与下半边不再对称。原文批注：
  「**以下波形是错误的侧面示意，明显看出上下不对称。**」
- 《六阶幻方充磁侧面三明治》右下格：`sin147 + cos186 + sin333 + cos39` —— 图上用**红圈**标出断口，
  原文批注：「**注意这种不可取，有断纹路**」。
- 同一张图的上排四格说明：**仅做符号翻转（±sin）仍是连续波形**，**只有换 cos 才断**。

> 📐 物理直觉：`sin` 与 `cos` 是同一频率上相差 90° 的两路。上下两套盘若一路走 sin、一路走 cos，
> 二者在时间上正交 ⇒ 叠加出的空间磁纹在"上半边"与"下半边"处的相位不一致 ⇒ 纹路在中缝处错位。
> 四路全 sin 时，上下两套只需**整体取反**即可（= 电流反向，即 180° 反相），纹路自然镜像闭合。
> **注意区分**：充磁要求"上下镜像"，所以取 **180°（反相）**；而整机运转要求"上下正交产生切向力"，
> 所以取 **90°**。同一对线圈，两个档位，**用途不同**，不要混用。

## 2.1 🔎 那张"断纹路"子图 —— 是 Wolfram 的**采样走样**，不是物理

老师指出《六阶幻方充磁侧面三明治》最后一张子图（`sin147t + cos186t + sin333t + cos39t`）
的红圈处"断口"**疑似软件 bug**。📐 本次核校结论：**不是物理、也不是公式错，是绘图采样率不足（aliasing）**。

| 幻方阶 | 最高频 f_max | Wolfram 默认（≈620 点） | 本页高密度（≈18×f_max 点） |
|---|---|---|---|
| 三阶 | 23 Hz | ≈ 27 点/周期 ✅ 正常 | 414 点/周期 ✅ |
| 四阶 | 136 Hz | ≈ 4.6 点/周期 🟡 临界 | 2448 点/周期 ✅ |
| **六阶** | **333 Hz** | **≈ 1.9 点/周期 ❌ 严重走样** | **5994 点/周期 ✅** |

- 六阶 `f_max = 333` 要在 `−π → π`（长 2π）的窗口里**走完 333 个整周期**；620 个采样点摊到 333 个周期上
  ⇒ **每个周期不到 2 个点** ⇒ 视觉上必然出现"断口 / 缺齿"。**数学上该式处处连续，不该断。**
- 对照实验：网页 ④-ter 里点一下「采样：Wolfram 默认级 ↔ 高密度」，**同一个公式**就能让断口出现 / 消失。
  ⇒ 那条断纹**不可作为物理判据**。
- ⚠️ 但要**分开看**：**规则 1 的"混 cos → 上下包络不镜像"是真物理**（那是 `sin`/`cos` 相位正交，
  降采样也不会消失）；而六阶这张的"断口"是**纯数值伪影**。两者长得像，**成因完全不同**，别混为一谈。

> 正因为如此，本页所有波形图**一律用 Canvas 实算 + 高密度采样**，不复用截图，
> 从根上排除"截图里带的软件伪影"。

## 5. 《searl充磁设备.jpg》补充要点（实物 / 访谈）

S. Moore / AAG 访谈（含 1986 年 Paul Brown 试验台照片）：

- 🔑 **「交通堵塞（traffic jam）」效应**：不正确构造的自制 SEG 里，滚筒会在环内**互相推挤、前后抖动**。
  Moore 的原话是 —— **正确构造完全取决于零件的精确尺寸 + 每个部件磁场的精确浸渍；做到之后"交通堵塞"效应就消失了**
  （"Once the second ring/plate is added, the 'traffic jam' effect is eliminated."）。
- 输入激励约 **5 V / 600 mA（3 W）**；0 → 436 mA 电流平滑上升，电压再升 2 V 转速骤增。
- 他同时说 **SEG 本身几乎没有电流输出**（"there has been virtually no current from the SEG"）。
- 专利申请因"方案不可行"被驳回。

> ⚠️ 访谈属**口头主张**，无第三方复现记录。此处仅作**工艺线索**（尺寸公差 + 逐件磁化浸渍）记录，**不作性能背书**。

**④-quater 的模型与边界（务必如实转述）**：
- 模型：环被写成 `p` 对极径向磁化 `M(θ) = M₀·cos(pθ)·r̂` ⇒ 外圆柱面等效磁荷 `σ_out = +cos(pθ)`、
  内圆柱面 `σ_in = −cos(pθ)`；对全部面磁荷（内外各 132 个）做**二维库仑叠加**得 `H`；
  磁力线用**中点法（RK2）双向积分**，种子在内 / 外表面、每极 2 个倍率（0.5 / 1.0）。
- ⚠️ **只是二维静磁模型，只看形态**；未含**磁滞 / 各向异性 / 三维端部效应**，**不是 FEA 精确算**，**量值不可直接用于设计**。
- 📐 **曲率算法的一处踩坑与修正**：初版用"转角 / 弧长"差分 `asin(cross/(d1·d2))/((d1+d2)/2)`，
  在离散折线上相邻点距极小时 `asin(1) = π/2` 再除以极小弧长 ⇒ **算出假峰 κ_max ≈ π（3.1416 /px）**，纯属数值假象。
  改用**三点外接圆公式** `κ = 4A / (|ab|·|bc|·|ca|)`（A = 三角形面积）并要求三点间距 ≥ 1.2 px；
  同时软化半径² 由 0.6 提到 3.0、种子点由 `RO±2.4` 外移到 `RO±8`、着色标尺改为**每次重建按 92 分位自动定标**。
  修正后 **κ_max ≈ 0.37–0.64 /px**（有界、随极数增加而增大），与"极数越多 → 极间急剧弯折越甚"的定性预期一致。
- 默认 `p = 17 对（34 极）`，与文档 **「34 DECERNABLE POLES」**数值相同（136 ÷ 4 = 34）。
- 磁力线默认 **136 条**、最长约 **1400 px**、极距约 **65 px**，每极清晰一对花瓣。

### 7.1 ⑥-bis-2「11 种错极」的统一相位模型（v3.9 新增）

麦格雷博册 **P18 列了 11 种错极名称**（V 型 / V+一型 / 双 V 型 / 双 V+一型 / 多 V 型 / 双一型 /
U+一型 / 单向错极 / V 型错极 / AB 对称错极 / 不对称错极），**但全册没有给出统一的成因模型**。
本节把它们全部化为**同一个函数**：

```
θ_k(z) = ( kπ − 2π·δ(z) ) / p          极带边界角；p = 极对数
δ(z)   = 0.5·ph(z) + ps(z) + ( magicEnv(ord, z) − 0.5 ) · 0.30 · am(z)
```

δ(z) 的单位是**极距**，由**五个自由度**叠加而成：

| # | 自由度 | 含义 |
|---|---|---|
| ① | **段数 nSeg** | 沿轴向分几段写（两套盘对写 = 1 段）；页面由「站点数 − 1」推得 |
| ② | **相位 ph** | 同相 0 / 反相 1（= 半极距），站点之间线性插值 |
| ③ | **周向错移 ps** | 斜充磁 / 斜极，整体周向挪几个极距 |
| ④ | **幅值 am** | 写入强度，1 = 满幅 —— **这正是「AB 对称」与「不对称」的分野** |
| ⑤ | **细纹** | 该段幻方阶——四路 sin 复合波【DC 整流后】的脉冲包络（`magicEnv`） |

**11 种错极的建模参数（SKEW11 表，站点 = z, 相位 ph, 错移 ps, 幅值 am）**

### 7.2 ⑨ 立体磁极显影 · 单滚筒片（v3.9 新增视图）

把 ④-quater 的**二维** B 场升到三维：

- **模型**：单滚筒片写成 `p` 对极**径向磁化** `M(θ,z) = M₀·cos( pθ + 2π·δ(z) )·r̂`，
  其中 δ(z) 就是 7.1 的错极相位分布 ⇒ **错极在三维里自然变成磁极带沿轴向的螺旋 / 折线走向**。
  外柱面等效面磁荷 `σ_out = +cos( pθ + 2πδ )`、内柱面 `σ_in = −cos( pθ + 2πδ )`；
  对全部面磁荷（默认 768 个）做**三维库仑叠加**得 H，磁力线用 **RK2（中点法）双向追迹**。
- **★ 关键加速 —— 对称性复制**：M 只通过 `(pθ + 2πδ(z))` 依赖 θ ⇒ 场对 θ 严格以 `2π/p` 为周期。
  故磁场线**只需在一个扇区内追迹少量原型线，再旋转复制 2p 份**
  （旋转 π/p 等价于 M → −M ⇒ H → −H，磁场线的**曲线集合**不变）⇒ 省 2p 倍算力。
- **几何**：`Ro = 1.00 / Ri = 0.769 / 高 1.0`（滚筒片外径 2.0、高 1.0）。
- **投影**：**自研正交相机**（yaw / pitch）+ **画家算法**（按相机深度排序）+ 深度调色 + 自动定标，
  **不依赖 three.js**。自动定标 `bound = max(磁力线最远点, Ro·|sin pitch| + HZ·|cos pitch|, Ro)`，
  保证任何 p / 精度 / 俯仰角下都撑满视口而绝不出界。
- **三种显示模式**：① **3D 磁力线**（滚筒画成玻璃壳，避免前后壁花纹重影）
  ② **3D 极带显影**（实体，明度表达 `|cos|`）③ **半剖**（切在世界坐标 θ∈[0,π]）。
- **配套面板**：「**极带展开**」（θ × z 展开图，红 = N 带 / 蓝 = S 带）与
  「**极面法向 |H| 衰减**」（多极 vs 单对极归一化对比，标出「|H| 掉到 10% 只在 Δr ≈ 0.30 Ro」）；
  另有**四种典型错极的立体缩略对照**（V 型 / 双 V 型 / 单向错极 / AB 对称错极，同一 p、只改 δ(z)）。
- **交互**：拖拽旋转 · 滚轮缩放 · 自转 · 复位视角 · 模式切换 · 极对数 2–24 · 精度档 · 错极型下拉。

**模型边界（页面已明标）**：三维**面磁荷**静磁模型，只看**形态**；
未含磁滞 / 各向异性 / 端部退磁 / 体积磁荷项（径向磁化的 `∇·M = M_r/r ≠ 0`，薄壁下量级小）；
**不是 FEA，量值不可用于设计**。

## 8. v3.10 订正：`f₁ → 极数` 的**闭合性判据**（老师指正 + 溯本求源）

> 老师原话：「**17/2 对或 39/2 对**：你要考虑到可能三阶和六阶对应要充磁**两个周期**，
> 刚好起点和终点磁力线能够**对接闭合**。当然你可以溯本求源看看 seg concept 那书 docx 里有没有讲 igv 具体要多少磁极。」

### 8.1 判据：极带总数必须为偶数

绕环一周的 **极带总数 N_band 必须为偶数**（N 带 / S 带成对出现），
等价于 **极对数 `p = N_band / 2` 必须是整数**。

若 N_band 为**奇数**，绕一圈回到 θ = 2π 时，那里的极带与 θ = 0 处的极带**同号**（N 挨着 N）
⇒ 接缝处凭空多出一个「假 S」⇒ 磁力线在接缝处**无法对接、无法闭合** ⇒ 这就是 **seam defect（接缝缺陷）**。

| 幻方阶 | f₁ | 若取 N_band = f₁ | p = f₁/2 | 单圈闭合？ |
|:---|:---:|:---:|:---:|:---:|
| 三阶（驻波） | 17 | 17 带 | **8.5**（非整数） | ✗ 不闭合 |
| 四阶（SEG） | **34** | 34 带 | **17** ✓ | ✓ 闭合（与「34 DECERNABLE POLES」对得上） |
| 六阶（IGV） | 39 | 39 带 | **19.5**（非整数） | ✗ 不闭合 |

⇒ **四阶恰好落在偶数上，SEG 单圈即可闭合**；三阶 / 六阶的 f₁ 都是奇数，必须处理。

### 8.2 三条闭合方案（待老师定夺）

| 方案 | 做法 | 三阶 | 六阶 | 代价 / 要点 |
|:---|:---|:---|:---|:---|
| **① 就近取偶** | 17→16 或 18；39→38 或 40 | 8 或 9 对 | 19 或 20 对 | 结构最简单、上下两面一次写透；但 f₁ 被改 ±1，**不再忠于幻方频率**。④-quater 现表用的即此案 |

| **DC · 上半边** | 取 **0V 以下**（削正保负 · 负半波） | 该行**顶部** | **向下垂** |
| **DC · 下半边** | 取 **0V 以上**（削负保正 · 正半波） | 该行**底部** | **向上立** |

⇒ 两行的波形在**行交界处头对头相接**，围绕零轴**严格镜像**。

**为什么这样才是对的（数学）**：180° 反相档下 `wgLo = −wgUp`，于是

```
第 3 行 = min( wgUp , 0 )
第 4 行 = max( −wgUp , 0 ) = −min( wgUp , 0 ) = −第 3 行      ← 严格互为相反数
```

两行互为相反数 ⇒ 图像围绕零轴镜像，正是「**上下两套线圈反接、同一路 DC 母线供电**」的真实电激励图景。

**顺带得到的判据图像**（三档相位下的表现）：

| 下套相位 | 第 1、2 行（AC 原始波） | 第 3、4 行（DC 整流后） |

## 10. 充磁后磁纹的走向：俯视图 vs 侧视图（v3.11 新增 ⑥-ter）

### 10.1 老师指正（原文）
> 「……磁纹应该是与中心垂直的，不是斜的，你在网页画的 B · 斜充磁/错极(P18 内转子式)-11 种
> 【冲片磁钢槽布局】不对，应该如图：`searl滚筒片磁环俯视图磁极观察照片.jpg`。
> 注意此图由 3 张图拼接……你可以看到**明显是从内到外直的**。
> **但这只是俯视图横截面；但侧面，也就是滚筒正视图磁纹理是怎样的，不清楚，你要想清楚。**」

### 10.2 判定：老师说得对 —— 而且这是**纯径向磁化的必然结果**
滚筒片的磁化强度矢量场是 `M(θ,z) = M_r(θ,z)·r̂`（**只有径向分量**）。
⇒ **任一 z 截面上，磁化方向都沿半径** ⇒ 观察膜贴在端面时，看到的只能是
**沿半径的直条**（N/S 相邻 ⇒ 边界即径向直线）。这与有没有「错极 / 斜充磁」工艺**无关**。

**⇒ 俯视图上磁纹【永远径向直】—— 不是"应该"，而是"必然"。**

### 10.3 那侧视图呢？（老师问"要想清楚"的那一问）
把外柱面展开（横轴 = 圆周角 θ、纵轴 = 轴向 z），极带边界
`θ_k(z) = ( kπ − 2π·δ(z) ) / p`：

| δ(z) 的形态 | 展开图上的条纹 | 对应错极型 |
|---|---|---|
| ≡ const | **竖线**（平行于轴） | 无错极 |
| 线性 | **斜线** | 单向错极 / 斜充磁 |
| 折线 | **折线** | V 型 / 双 V 型 / 多 V 型 |
| 段间跳变 | **Z 形台阶** | 双一型 |

**⇒ 「错极 / 斜充磁」的「斜」只在侧视图上看得见；俯视图永远径向直。**
等价说法：**观察膜贴端面 = 看俯视（径向）；贴外柱面 = 看错极（轴向走向）。**

### 10.4 量化：为什么侧视小图必须取低极对数
δ 的单位是**极距**，一个「反相半极距」在展开图上恰好横移 **半个带距**：
`Δθ = 2π·0.5/p = π/p` = 半个带距。

⇒ p 越大带越窄，「折」越看不出来。**p = 3 对（6 带）时折位移 ≈ 13 px 才一眼可辨**；
p = 5 时只有 ≈ 8 px，看起来就退化成"斜条纹"。这是纯作图参数、与物理无关，
但**不写下来下次一定还会踩**。

## 11. ⑥-quater「充磁原理与工业对照」（v3.12 新增）

### 11.1 老师四问（原文）
> ① ⑥-bis-2 底下那张图，是不是「瑟尔滚筒的**正视图**展开」？画错没有？
> ② 为何 Phasing 环形线圈 + AC 复合波经 DC 整流，能让**夹层磁环**长出那种纹理？
> ③ 假设 AC 复合波**不经过 DC 整流**，充磁纹理会怎样？是否就**没有**径向多极效果了？
> ④ 工业界（麦格雷博等）到底**怎么**给磁环写多极径向？「充磁这块我不专业，你教教我。」

### 11.2 ⑥-bis-2 的身份正名（**是外柱面展开，不是正视图**）

| 项 | 此前写法 | 订正后 |
|---|---|---|
| 几何 | 「正视图 / 正视图展开」 | **外柱面展开（θ × z）** —— 横轴 = 圆周角，纵轴 = 轴向 |
| 来源 | 被读作「瑟尔滚筒的复原」 | 11 个名称来自**麦册 P18「内转子式」**，是**通用转子错极工艺分类** |
| 身份 | —— | **「错极工艺的相位参数化模型 / if 工具箱」**，不是实物复原 |

⇒ 本页据此新增「**11 种错极名称 ↔ 工业实现 ↔ 本页模型参数**」三列对照表。
结合 §10 的结论：**「斜」只在侧视（θ×z 展开）上成立；俯视图永远径向直。**

### 11.3 工业标准的多极径向充磁夹具（画布 `cMagPrin`）
工业做法**与我们推测的"绕线写波"完全不同**，它是**夹具（fixture）一次性脉冲成形**：

1. **硅钢叠片铁芯**做成环形，**槽数 ≡ 目标极数**；
2. 每槽内嵌导体，**相邻极绕向相反**（这是"多极"的来源，不是靠波形）；
3. 全部导体**串联**，接一台**大电容充磁机**，**一次脉冲放电**成形；
4. 磁环套进铁芯内圈（或插进外圈），磁场从极齿**径向**灌入。

⇒ 关键判据：**极数由"槽数"决定，极界陡度由"脉冲波形 / 过渡区宽度"决定**。
这与本页 ⑨-bis/⑨-ter 的结论**完全同构**（波形只改陡度，不改极数）。

### 11.4 AC 不整流 = 退磁 / DC 单向脉冲 = 充磁（画布 `cMagRul`）
回答老师第 ③ 问 —— **是的，不整流就写不出（净）径向多极**：

| 驱动 | 结果 | 机理 |
|---|---|---|
| **纯 AC（无整流）** | **退磁 / 反复翻转，净剩磁 ≈ 0** | 半周正写、半周反写，磁畴来回摆，末态落在**局部最无序**处（工业磁粉探伤正是**用 AC 退磁**） |
| **DC 单向脉冲** | **充磁** | 单向场把磁畴推到饱和后撤场，落到 B_r 永久保留 |
| **RLC 自由放电** | **危险：会反向** | 欠阻尼回路在首峰后**必然反向过零**；工业用 **IGBT 截波**在首峰切断，保证**单向** |

⇒ 「**Phasing 环 + AC 复合波 + DC 整流**」这条链，在工业口径下**恰好等价于"把复合波整形成单向脉冲列"**，
即：**复合波负责"波形形状"，DC 单向负责"可保留"**。两条缺一不可。
⇒ 这也解释了页面 ④-ter 里 DC 整流两张图的必要性。

### 11.5 环形绕组三拓扑（为什么"随便绕个 toroid"写不出径向多极）

| 拓扑 | 外部场 | 能否写径向多极 |
|---|---|---|
| **普通 toroidal**（导线沿环周绕满） | **环外 ≈ 0**（安培环路：环内封闭，环外相消） | **❌ 根本写不出** |
| **沿环面走线含径向分量**（Phasing 双线并绕） | 环面两侧为**交替 N/S 面** | ✅ 可写**面内**多极 |
| **定子式轴向导体**（工业夹具） | 极齿把它们**导成径向** | ✅ 标准多极径向 |

### 11.6 ⚠️ 自曝物理疑点（已列入 ⑧ 可证伪清单）
**严格意义的 toroidal 绕组外部场 ≈ 0** ⇒ 若 Phasing 真的按"教科书 toroidal"绕，**它写不出任何径向多极**。
⇒ 因此**必须**假设 Phasing 是 **11.5 的第 2 类（双线并绕、含径向分量）**，才与观察膜照片相容。
⚠️ 这条**不是结论，是本模型的一条强假设**，请以 ③-bis 的 Naudin 观察膜实拍为唯一裁决。

### 11.7 口径：AC 是"助剂"，不是"主写手"
SEG 的 A.C. 层电流量级仅 **100~200 mA @ 1–10 MHz**，**远不足以翻转钕铁硼**（见 §12 的 H_sat 门槛）。
⇒ 更自洽的口径是：
> **外层 DC 脉冲负责"写磁"，内层 AC 只做"抖松磁畴"的助剂。**

这与 §17（⑨-ter）从工业侧得到的结论**方向一致**。

## 12. ②-bis「磁性材料优化 · 复合波频率充磁」（v3.13 新增）

### 12.1 老师第二轮提问
复合波频率充磁的原理是什么？**磁性材料怎么优化**？**瑟尔当年用铁氧体意味着什么**？

### 12.2 趋肤深度 —— 为什么"不同频率写不同深度"（画布 `cSkin`）
```
δ = √( 2 / (2π f · μ₀ μ_r · σ) )
```
双对数曲线 1 kHz → 100 MHz，五条材料曲线（1 MHz 读数）：

| 材料 | δ @ 1 MHz | 对 10~20 mm 壁厚 |
|---|---|---|
| **永磁铁氧体** | **≈ 0.5 m** | **完全透明（全厚度一次写透）** |
| 软磁铁氧体 MnZn | ≈ 11.3 mm | 穿透大半 |
| **NdFeB** | **≈ 0.60 mm** | **只在表层写** |
| 电工钢 Fe-Si | ≈ 5.03 µm | 皮都不敢说 |

⇒ **这是本页"分层写入"唯一有教科书支撑的一块**：频率越高，写进去越浅。
⚠️ 但「**复合波 = 多频同时 → 由内到外分层**」这一步**是机理假设**，主流工业充磁文献**未见对应做法**（见 §17 四条纪律）。

### 12.3 材料四步倒推链（画布 `cMatLayer`）
```
要复合波写得进深  ⇒ 要 σ 极小
要 σ 极小          ⇒ 只能是铁氧体（金属 σ 高 4~6 个数量级）
还得是永磁         ⇒ 排除软磁铁氧体
⇒ ★ 唯一交集 = 各向同性永磁铁氧体
```

### 12.4 ★【硬结论】瑟尔用铁氧体是**物理必然**（不是"当年只能用便宜货"）
把"高频 AC 要穿透 10~20 mm 壁厚"当约束，**材料类别就被锁死在铁氧体上**：
- NdFeB 1 MHz 只写 **0.60 mm** 皮层 ⇒ **高频根本进不去**；
- 金属配方（Fe-Al-Si-Ti）B_sat 可达 1.5~2.0 T，但 σ 高 ⇒ **1~10 MHz 只写 5 µm** ⇒ 同样写不进去。

⇒ **两条路不能同时满足**（B_sat 高 ↔ 高频穿透好，是**互斥**的）。

### 12.5 ⚠️ 连带订正：② 校核表的 B_S 行「偏乐观」→「**材料上不可能**」
- 文档给的理论值 **17,320 G ≈ 1.73 T**；
- **各向同性永磁铁氧体 B_sat 上限 ≈ 0.48 T**、取向烧结铁氧体 B_r 仅 **0.38~0.44 T**
  ⇒ 差 **3.6~4.5 倍**，不是"偏乐观"，是**在材料类别上不成立**。
- 页面 ② 校核表该行已由 `badge q`（解释存疑）**升格为** `badge bad`（材料上不可能 · 口径待裁）。

### 12.6 【线索·非证明】黄金角 → 斐波那契 34 → 瑟尔 34 极 / 136

### 19.5 ★ 三方共性 / 差异判据

| 家 | 磁环 | 充磁工艺 |

### 19.6 美方（Morningstar）实测数据摘要（第三方对照用）
- 稳态掉 **2~5 lb**（190 lb 本体的 ~1~2.6%）；瞬态旋转掉 **20~40 lb**；

- **共振**：480 rpm 与 810 rpm（Fig.11）；Fig.13 在 220 与 400 rpm 有共振尖峰；
- **无自加速**（self-acceleration 从未确认）；拆下 carousel 时闻到 **Ozone**；
- **环印痕**：停机静置数月后 HyMu-80 环被磁化，**用手转动后每隔约 10° 方位角就反向弹回**，且**与转向无关**

- 对 Searl 的批评：*"Searl identifies the law of squares or the magic squares but **we found there is basically
  no real science to validate this concept**"*；*"no evidence has ever shown any working apparatus with
  **more than a single ring**"*。
