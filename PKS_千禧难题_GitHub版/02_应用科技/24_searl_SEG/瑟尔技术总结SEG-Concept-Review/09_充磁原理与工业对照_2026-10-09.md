## 0. 一句话结论

> **工业界写多极径向磁极，靠的是「夹具决定极数、脉冲决定陡度」；
> 而不是「靠绕线波形自己长出极数」。**
> 因此本页 Phasing 环那条"绕线写波"的路线**在工业上没有直接对应物** ——
> 它是一条**假设**，必须由观察膜实拍裁决，不能拿工业做法当证明。

## 1. 工业标准的多极径向充磁（**夹具型**）

### 1.1 四种磁化线圈（麦册 **P12**）

| 线圈形式 | 磁场方向 | 能写什么 |
|---|---|---|
| **螺线管线圈（solenoid）** | 轴向 | 轴向单极 / 短圆柱零件 |
| **产品外周磁化线圈** | 径向（由外向内） | **外转子 / 环外表面多极** |
| **产品内周磁化线圈** | 径向（由内向外） | **内转子 / 环内孔多极** |
| **产品平面磁化线圈** | 面法向 | **盘式 / 平面多极**（麦册 P19「背面有磁轭的盘式电机 · 单面充磁」） |

⚠️ **SEG 的 Phasing 环形（torus）绕线，不在这四类里** —— 这是后文 §3 那条"物理疑点"的来源。

### 1.2 整体充磁 / 后充磁技术（麦册 **P13**）

> 麦册原文：「**整体充磁技术（后充磁技术）：先组装，后整充。**」
> 「充磁电源充满电，通过磁化线圈放电，**放电脉冲电流的峰值可达上万安培**，此电流脉冲在线圈内产生一个强大的磁场，
> 该磁场使置于线圈中的转子磁石进行**永久磁化**。」
> 「**如转子分段错极，线圈磁轭按照转子错极方式一一对应。**」

工艺链：**待充磁转子 → 确认磁路方向 → 定制线圈 → 匹配充磁电源 → 磁石永久磁化（电磁原理）**

★ 三条可直接迁移到本项目的判据：
1. **极数由夹具（磁轭 + 绕组）决定，不由波形决定**；
2. **电流是"上万安培"量级**（对照本页 ⑦ 的 8,640 A / 15.9 kA，**同量级**）；
3. **"后充磁"= 先装配后充磁** ⇒ 错极只需**把磁轭按错极方式一一对应**，
   **不需要"在绕线时写相位"** —— 这是本页"错极 δ(z)"最省事的工业实现路径。

### 1.3 多极充磁的工艺形态（麦册 **P14**）
**平面多极充磁 / 扭转多极充磁 / 表贴式外充磁 / 嵌入式内充磁 / 大型尺寸充磁**。
⇒ 「**扭转多极（twisted / skew）**」= 工业对**错极 / 斜极**的正式叫法。

### 1.4 麦册 **P16** 的四条硬指标（**这是全套材料里最硬的一组工程数字**）

| 指标 | 值 |
|---|---|
| 可实现极数 | **400+ 极充磁** |
| **最小极间距** | **0.1 mm** |
| **峰值偏差** | **±1%** |
| **极间相位偏差** | **±1%** |
| 充磁方向 | 轴向 / 径向 / 平面 |

★ 与 SEG 对照：SEG 定子环 4,410 极、滚筒 34 极 —— **4,410 极已超出工业样本的 400+ 极一个数量级**（📐 数量级差 ≈ 11×）。
⚠️ **不是"不可能"，是"没有现成实测可比对"** ⇒ 引用时**不得**写成"工业已验证 4410 极"。

## 2. ★ 老师第 ③ 问：AC 复合波**不整流**会怎样？

### 2.1 判据：**AC 不整流 = 退磁 / DC 单向脉冲 = 充磁**（画布 `cMagRul` 三栏）

| 驱动 | 结果 | 机理 |
|---|---|---|
| **纯 AC（无整流）** | **退磁、净剩磁 ≈ 0** | 半周正写、半周反写 ⇒ 磁畴来回摆 ⇒ 末态落在**局部最无序**处 |
| **DC 单向脉冲** | **充磁** | 单向场推到饱和后撤场 ⇒ 落在 B_r 永久保留 |
| **RLC 自由放电** | **危险：必然反向** | 欠阻尼回路在首峰后**反向过零** ⇒ 半周反向场把刚写好的磁畴又推回去 |

### 2.2 工业怎么保证"单向"：**IGBT 截波**
工业充磁机不是"让 RLC 自由振荡"，而是用 **IGBT（或晶闸管）在首峰之后立刻切断**，
把脉冲裁成**单向单峰**。这就是麦册 P13「脉冲电流波形」那张图的真实含义。

### 2.3 旁证：**磁粉探伤本来就靠 AC 退磁**
磁粉探伤（MT）行业标准做法：**工件检测后必须用 AC 退磁**。
⇒ 「**AC 能把磁畴洗乱**」不是本页的猜测，是**另一个行业的成熟工艺**。
⇒ 因此：
> **「Phasing 环 + AC 复合波 + DC 整流」这条链，在工业口径下等价于"把复合波整形成单向脉冲列"。**

- **复合波**负责"**波形形状**"（决定极界陡度）；
- **DC 单向**负责"**可保留**"（决定写进去以后留不留得住）。

**两条缺一不可。** —— 这是网页 ④-ter 那两张 DC 整流图在物理上必须存在的理由。

## 3. ⚠️ 环形绕组三拓扑（**本文件唯一的"自曝疑点"**）

| 拓扑 | 外部场 | 能否写径向多极 | 工业对应 |
|---|---|---|---|
| **普通 toroidal**（导线沿环周绕满） | **环外 ≈ 0**（安培环路：环内闭合、环外相消） | **❌ 根本写不出** | 变压器 / 电感（本来就不要外场） |
| **沿环面走线含径向分量** | 环面两侧为**交替 N/S 面** | ✅ 可写**面内**多极 | 麦册 **产品内周 / 外周磁化线圈** |
| **定子式轴向导体 + 极齿** | 极齿把它们**导成径向** | ✅ 标准多极径向 | 麦册 **整体充磁磁轭（P13）** |

### 3.1 这条为什么要单列
**教科书 toroidal 绕组的外部场 ≈ 0** ⇒ 若 Phasing 真的按"toroidal"绕，**它写不出任何径向多极**。
⇒ 本页**必须**假设 Phasing 是 §3 的**第 2 类（双线并绕、相邻异向）**，才与 Naudin 1999 观察膜实拍相容。
⚠️ **这条不是结论，是本模型的一条强假设。**
⇒ 已列入网页 **⑧ 可证伪清单**；裁决证据 = ③-bis 的 5 张 Naudin 观察膜实拍（`../figs/naudin_*.jpg`）。

### 3.2 口径推论：AC 是"助剂"，不是"主写手"
SEG 的 A.C. 层电流量级仅 **100~200 mA @ 1–10 MHz**，**远不足以翻转钕铁硼**（门槛见 §6.2 / `10_….md`）。
⇒ 更自洽的口径：
> **外层 DC 脉冲负责"写磁"，内层 AC 只做"抖松磁畴"的助剂。**

## 4. 错极的工业实现 ↔ 本页模型参数

### 4.1 麦册 **P18** 的 11 个名称（**原页之名，勿改**）
**V 型 / V + 一型 / 双 V 型 / 双 V + 一型 / 多 V 型 / 双一型 / U + 一型 / 单向错极 / V 型错极 / AB 对称错极 / 不对称错极**

⚠️⚠️ **口径纪律（网页 ⑥-bis-2 已正名）**：
- 这 11 个名称来自麦册 **P18「内转子式 · 整体充磁实例」**，是**通用转子错极工艺分类**；
- **不是瑟尔滚筒的复原**；本页的对照表是「**错极工艺的相位参数化模型 / if 工具箱**」；
- 画布上的几何是**外柱面展开（θ × z）**，**不是正视图**；
- **「冲片磁钢槽是 V 形 / 斜的」≠「磁纹是斜的」**（见 `08_….md` §10）。

### 4.2 工业实现错极的三条路径（**与本页"绕线写相位"完全不同**）

| 路径 | 做法 | 备注 |
|---|---|---|
| **① 磁轭转位** | 磁轭（夹具）按错极方式**一一对应**，分段错极（麦册 P13 原文） | **最主流** |
| **② 分段装配** | 磁钢分段，各段**独立充磁后转位粘装** | 俄方 Roschin-Godin 走的就是这条（**代价：磁能降低**，见 §9.3） |
| **③ 斜极充磁** | 夹具本身就带斜角（**扭转多极**） | 谐波按 **sinc** 被选择性压掉（§4.3） |

★ **三条路径都不需要"在绕线时写相位"** ⇒ 这反过来说明：
**若 SEG 的 Phasing 真靠"绕线写波"成形，那它是工业上的一条"孤例路线"。**

### 4.3 📐 斜极的谐波 sinc 衰减因子
```
k_sn = sin( n p α_s / 2 ) / ( n p α_s / 2 )
```
其中 `α_s` 为**斜极角**，`p` 为极对数，`n` 为谐波次数。

**本页自算的简化结论**：把 `α_s` 以**极距**为单位（`α_s = k` 个极距），则参数化为 `n · k · π / 2`
⇒ **衰减只取决于"斜了几个极距"，与极数 p 无关。**
- 斜 **1 个极距** ⇒ `n = 2` 处**整零**；
- 斜 **1/2 个极距** ⇒ `n = 4` 处**整零**。

⇒ 这是"**斜极能选择性消谐波**"的干净数学表述，也是本页 ⑥-bis-2「错极 δ(z)」的工业依据。

### 4.4 反例警示（**别把工业当证明**）
工业界**所有**做法都在**压谐波**（谐波 = 转矩脉动 = 振动 = 噪声）；
而本页对 SEG 的解读是**用谐波**（细纹 = 极界畸变，可能是特性）。
⇒ **方向相反**。引用工业数字时**必须**注明这一条（见 §8 纪律②）。

## 6. 📐 极界过渡带 → 谐波含量（**2048 点数值傅里叶实算**）

### 6.1 实算结果（网页 `cIndEvi` 面板②）

| 过渡带宽度 `w`（以极距为单位） | 波形 | 3 次谐波 | THD |
|---|---|---|---|
| `w = 0` | 理想方波 | **33.3%** | **44.5%** |
| `w = 1` | 三角波 | **11.1%** | **12.1%** |
| **`w ≈ 0.30`** | —— | **7 次谐波降到 0.7%**（**选择性零点**） | —— |

⚠️ **一个真实巧合**：`w = 0.5` 与 `w = 1` 的 3 次谐波**同为 11.1%** —— 是 **π/4 零点**造成的，不是笔误。

### 6.2 ★ 与工业口径的对应
工业口径「**过渡区 < 极距 15%**」⇔ **本图 `w < 0.30`**。
⇒ 两条独立来源（AIC 的工程经验 + 本页的数值傅里叶）**在同一数量级上对齐**。

### 6.3 ★ 与本页 ⑨-bis「三段阶梯」的关系（**别混**）
- **波形振幅**（`a₂`）是**极数杠杆**：`a₂ = 1` 长"触零凹陷"（视觉细纹）、`a₂ > 1` 把 `2p` 变 `4p`；
- **过渡带宽度**（`w`）是**谐波杠杆**：只改谐波含量，**不改极数**。
⇒ 两条杠杆**正交**，网页分别在 ⑨-bis 与 ⑨-ter 落地。

### 6.4 极数 → 良品率与代价（`cIndEvi` 面板③）
**4 极 98% / 6 极 90% / 8 极 85%**（CSDN）。
⇒ **极数越高，良品率越低**。SEG 的 34 极 / 4410 极属于**远超工业统计样本**的区间，
**引用时不得外推**（见 §8 纪律④）。

## 9. 与 SEG 三家的对照（**本文件与 `08_….md` §19 的分工**）

### 9.1 共性
三家（Searl 原版 / Roschin-Godin 俄方 / Morningstar 美方）都要：
① **滚筒与环不接触**；② 确定**极比**；③ **滚筒同极性**（美方实测：交替极性会被相邻滚筒抵消）；④ 都用**铜层**。

### 9.2 差异（**充磁/磁环工艺维度**）

| 家 | 磁环 | 充磁工艺 | 本文件对应 |
|---|---|---|---|
| **Searl 原版** | **整体环** | 声称「**恒磁场 + 变磁场组合**在板面与滚子面写出**正弦波图案**」；nylon 作"**电子控制闸门**" | §1.2 后充磁 / §3.2 AC 助剂 |
| **Roschin-Godin（俄）** | **拼装环**（110 kg Nd 定子 + 115 kg Nd 转子） | **常规电容-电池组放电逐段充磁 → 组装粘进铁电枢（磁能降低）→ 未用高频充磁** | §4.2 路径② |
| **Morningstar（美）** | **不用永磁环**（软磁 **HyMu-80 + 铁磁流体**） | —— | 无对应（换材料路线） |

### 9.3 ★ 老师点名的这一条：「俄方磁环是塞小磁铁整合做的」
**有原文直接支持，而且代价原文自己写了**（俄方论文原文，粗体为本项目所加）：
> *"separate magnetized segments of rare earth magnets … were magnetized **in a usual way by discharging
> a capacitor-battery system through a coil**. Afterwards the segments were **assembled and glued together
> in a special iron armature, which reduced the magnetic energy**."*
> 紧接着：*"**High frequency field magnetization was not applied.**"*

⇒ **分段常规放电充磁 → 拼装粘合 → 磁能降低 → 没用高频。**
代价原文也认了：**不敢超过 600 rpm**，理由 *"insufficient mechanical durability … which was built from
separate pieces"* —— 恰好卡在**临界转速（550 / 600 rpm）之上那一段**。

**美方那侧的意外实测**：原以为 ~100 g 离心加速度会把小磁铁甩出，结果
**小磁铁没被甩出、反而吸附在环上** ⇒ **HyMu-80 + 铁磁流体**的磁吸力**远强于离心力**。

★ **判据**：用**拼装环**做的实验，对「**波形印痕是否必要**」**既不否证也不支持**。
⇒ **本文对 SEG 充磁工艺的判定，不能被俄方数据当作任何一方的证据。**
