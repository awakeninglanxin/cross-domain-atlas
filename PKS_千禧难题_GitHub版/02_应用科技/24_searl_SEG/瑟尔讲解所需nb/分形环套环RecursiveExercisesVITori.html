层级账本 · 间隙校验每级的环数 / 主半径 / 管半径 / 与下一级的间隙

自相似模式下 sU(L)=a·q^L、r(L)=ρ·sU(L)：每级严格等比 ⇒ 比例匀称、梯度一致。父子间隙 Δ 是拿真实的两只环量出来的（取第一只 L 环与它的第一只子环， 量两条管轴圆的最小距离再减两个管半径）—— 挂到曲线上以后，解析式 sU(L+1) − r(L) − r(L+1) 就不再成立了。
Δ ≥ 0 只说明相邻两级不穿；隔了两三层的环会绕回来撞外层，那要下面那条全对复核才能定。

按下面四条约束解出来的：
① 每级主半径 sU(L)=a·q^L、管半径 r(L)=ρ·sU(L) ⇒ 比例匀称、梯度一致；
② 父子 ρ ≤ q/(1+q)；③ 兄弟 ρ ≤ sin(π/p)/q−1；
④ 全对（含跨层）ρ ≤ 0.1495 ← 真正绑定的一条（逐级挂曲线后的实测值）。

p=7 实测（2026-10-21）：③ 那条 ρ ≤ sin(π/p)/q−1 只对 「挂主圆」成立；挂曲线时子环不在极向平面内，实际能到 q≈0.489（ρ→0）／ 0.44（ρ=0.06、L0–L3），绑定点是 L2 兄弟中轴圆相交（q=0.49 时 gap=−0.13）。 所以 p=7 下原来那套 q=0.62 用不了；且 q 上限随层数走（g=1 时 0.93、g=2 时 0.49、g=3 时 0.44）， 它不是结构的常数。⚠ gap(q) 在这套几何里非单调（0.45 咬、0.46 又不咬）， 别用二分法求 q_crit——会给出假临界值。

「环轴 ∥ 切线」在几何上与「不切穿父环」互斥，不是参数问题： 切线 T 恒在管面切平面内，与管面法向 N 严格正交 （实测 2000 点 max|N·T| = 2.2e-16）；而环不切穿父环要求环轴靠近 N —— 两者正好差 90°。取环轴 = T 时环面必然扫过父管轴线， 解析间隙 Δ = sU·|ρ−q| − ρ·sU(1+q) 恒为负（q=0.08 时公式 −0.4560、实测 −0.4560）， 实测 g=6 时为 −1.02。所以默认取 贴管壁（环轴 = N×B）： 它是唯一能做到 Δmin > 0 的朝向（ρ=0.140 时 +0.0078）。

⑦ 怎么读这张图

① 先看默认（g=6）：一个大环绕着环面转 (5,1680) 圈，它上面挂 p 个环、每个再挂 p 个……一共七级（L0…L6）。
② 把 g 从 6 往回调：每减一级就砍掉一整层，配合「四个层次定格」能看清第 g 级从哪冒出来。
③ 看「层级账本」的间隙列：绿色 Δ>0 = 两只管不相交（子环的孔套着父管）；红色 = 两管互相穿插了。
④ 把 ρ 往上拉：环变胖好看，但超过 q/(1+q) 之后父子环就开始重叠 —— 账本立刻变红，这就是那条上限的来历。
⑤ 切到「nb 原版」：管半径恒为 0.5 而主半径逐级减半，深层环会被"管"塞满 —— 账本里 ρ 一路涨到 >1，这正是 nb 的样子。
⑥ n、k 逐级给：L0 一条、L1 及以下共用另一条。(n,0) 是绕洞的整圈，(0,k) 是穿洞的整圈，(n,k) 是环面上的 (n,k) 环面结。
⑦ 相机绕 z 轴（屏幕竖直方向）公转；p 为偶数且不开曲线时场景有半圈对称，GIF 会只扫 180° 换取角分辨率。
⑧ 「子环挂在哪」切一下看差别：曲线 = 每一级环的中心落在父环的彩虹线上，环被曲线穿过孔心（像穿在绳上的环）； 主圆中心线 = nb 原式，子环铺在父环管轴那个大圆上。前者是「沿曲线的项链」，后者是「沿管道的刻度」。
⑨ 点「↻ 一键公转」（或按 G）：L0 完全不动，L1 绕 L0 的中轴、L2 绕 L1 的中轴、L3 绕 L2 的中轴…… 每一级只认自己父环，子环连同整棵子树被刚体带走，转完再进下一层 —— 一台逐级减速的齿轮组。 父子之间只做刚体相对转动，所以父子永不互穿；但子环沿父环面滑行会扫到「父环面与祖父管面相切」那一圈， 所以摆幅有硬上限（实测 L2 只到 ±16°，默认就取 ±15°）。把摆幅拉到 180 就能亲眼看它穿。

⑧ 与 nb 的对照

一字未改（nb 模式下）：torus 的参数式（同一套 û, v̂, ŵ 三正交方向 + sU 主半径 + r 管半径）； generate 的两个定义（基例 {{u,v,t,0.5}}、递归里 u1=(sU/(2 sV))v、v1=(t1−t)×v、α=2π/n、 i=1..n 与 Flatten[Append[p, generate[…,0]], 1] 的拼接顺序）； 1.{{a,0,0},{0,a,0},{0,0,0},p} 的初值；φ,θ ∈ [0,2π]；Boxed→False, Axes→False； ImageSize→{500,350}；ViewPoint→{0,0,100} + ViewAngle→0.01 的正交投影。
本页新增：g 上限 4→7；「自相似」模式（把 u1=(sU/(2 sV))v 里的 1/2 换成 q、把基例的常量 0.5 换成 ρ·sU）； L0 环面绕行曲线 (n,k)；间隙校验；LOD；拖动旋转 / 缩放 / 层级配色 / 线框 / 半透明 / 四个层次定格 / GIF·PNG 导出。
