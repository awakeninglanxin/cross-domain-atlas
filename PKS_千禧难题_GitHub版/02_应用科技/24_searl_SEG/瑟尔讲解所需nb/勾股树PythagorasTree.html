原理（与原版逐行对应）

递归函数 PythagorasTree[p1, bend] 用 显式栈（不是递归调用）走一棵二叉分形树： 每次拿当前「父边」向量 (x, y) = (u1 − x1, v1 − y1)，由两个复乘子算出两个子边

  • a = −cc·ss + i·cc² —— 模长 cc = cos(π/bend)
  • b = a·(1 − i) —— 模长 ss = sin(π/bend)

两个子方块边长就是 cc 和 ss，而 cc² + ss² = 1 恰好等于父边长² —— 这就是「勾股」二字的来源。
每个多边形是 7 个顶点：两个子方块的并集（只在公共角点相碰）， 按非零环绕规则填充即得并集，描边也只走真实的方边。
绘制顺序 MapIndexed：第 i 块（共 N 块）用 Rainbow[i/N] 填、Rainbow[1 − i/N] 描边， 半透明叠加 → 就是那种「由内向外渐层」的观感。
