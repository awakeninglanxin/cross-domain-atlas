## 1. 一句话：这是什么

环面（甜甜圈）表面上的一条**缠绕曲线**：绕洞 `n` 圈的同时穿洞 `k` 圈。
`(2,3)` 是**三叶结**，`(2,5)` 是**外科结**。原版是一个 `Manipulate` 交互演示，
本网页把它的**全部 9 个控件、8 种场景元素、以及颜色联动逻辑**逐字复刻过来。

## 2. 数学原理（与原版逐字对应）

```mathematica
Torus[u_,v_,R_]                 := {Cos[u](1+R Cos[v]), Sin[u](1+R Cos[v]), R Sin[v]}
TorusNormal[u_,v_]              := Torus[u,v,1] - {Cos[u],Sin[u],0}     （原版未使用）
TorusPath[a_,R_,n_,k_]          := Torus[n a, k a, R]
TorusPathPoints[R_,n_,k_,p_,s_] := Table[TorusPath[2Pi(i+s)/p, R,n,k], {i,0,p-1}]
close[{a_,z___}]                := {a,z,a}
```

- **环面**：中心圆半径 1，管半径 `R`。参数 `u` 绕大圈、`v` 绕管截面一圈。
- **路径**：`u = n·a`、`v = k·a` 同时推进 —— 绕洞 `n` 圈时正好穿洞 `k` 圈。
- **绕洞圈**（around）：`Torus[a, π, R]`，即 `v` 固定在 π 的整圈（环面**内**赤道）。
- **穿洞圈**（through）：`TorusPath[a, R, 0, 1]` = `Torus[0, a, R]`，即 `u` 固定在 0 的整圈（从洞心射出的径向圈）。
- **`n` 与 `k` 的含义**（原版说明原话）：`n` 是曲线与「穿洞圈」相交的次数，`k` 是曲线与「绕洞圈」相交的次数。
- **`p` 个等分点**的相位 `a = 2π(i+s)/p`；`s` 是沿路径的整段平移；`close` 把首尾接上，`p` 个点连成 `p` 段（首尾相接）。

## 3. 全部 9 个控件（与原版一一对应，一个不少）

| # | 原版控件 | 原版范围 | 网页实现 |
|---|---|---|---|
| 1 | `R` torus radius | 0.05 ~ 2 连续，默认 **0.5** | 滑条 + 可敲数字框 |
| 2 | `n` around the hole | 0 ~ 10 步长 1，默认 **2** | 滑条 + 数字框（整数） |
| 3 | `k` through the hole | 0 ~ 10 步长 1，默认 **3** | 滑条 + 数字框（整数） |
| 4 | `r` tube radius | 0.01 ~ 0.5 连续，默认 **0.05** | 滑条 + 数字框；**受 Enabled 联动**（见 §5） |
| 5 | `p` number of points | 1 ~ 100 步长 1，默认 **24** | 滑条 + 数字框（整数） |
| 6 | `s` point shift | 0 ~ 1 连续，默认 **0** | 滑条 + 数字框 |
| 7 | `t` torus opacity | 0 ~ 1 连续，默认 **0.8** | 滑条 + 数字框；**受 Enabled 联动** |
| 8 | `show` TogglerBar | {torus, path, tube, points, lines, tubes}，默认 **{torus, path}** | 6 个可点按钮（多选，高亮） |
| 9 | `extra` TogglerBar | {mesh, around, through}，默认 **{mesh}** | 3 个可点按钮（多选，高亮） |

滑条与数字框**双向同步**、超范围自动夹取；`R/r/s/t` 是连续量所以**不量化**（`π` 之类特殊值不会被打断）。
参数全部收在**右侧浮窗**里，点浮窗右边缘的 **▸** 可整块收起，看图不受打扰。

## 4. 8 种场景元素与「颜色联动」（原版 select 语义，逐条照抄）

原版用一个 `select` 决定每个元素画不画：

```mathematica
select[what_,obj_,alt_] := If[MemberQ[show,what] || MemberQ[extra,what], obj, alt]
```

| 场景元素 | 出现条件 | 颜色 / 粗细 |
|---|---|---|
| 环面曲面 | `torus` ∈ show | **Cyan**，`Opacity[t]` |
| 网格线 Mesh | `torus` ∈ show **且** `mesh` ∈ extra | 黑；密度照抄 `Mesh->Automatic` = **15 条/方向** |
| 路径 path | `path` ∈ show | **Black**，粗（Thick） |
| 绕洞圈 around | `around` ∈ extra | **torus 开** ⇒ 黄 + 粗；**torus 关** ⇒ 蓝 + 细 |
| 穿洞圈 through | `through` ∈ extra | 同上 |
| 管 tube | `tube` ∈ show | **White**，半径 `r` |
| 点 points | `points` ∈ show | **torus 开** ⇒ 黄；**torus 关** ⇒ 红（`PointSize[Large]`） |
| 折线 lines | `lines` ∈ show | **Black**，粗；连接 `close[pts]`（**直线段**，非光滑曲线） |
| 管段 tubes | `tubes` ∈ show | **Green**，每段一根管，半径 `r` |

**两个容易忽略的原版细节，都照抄了：**

1. **网格线是「环面」的属性**（`Mesh->select["mesh", Automatic, None]` 写在 `ParametricPlot3D[Torus...]` 里），
   所以**关掉环面 ⇒ 网格线也一起消失**，哪怕 `mesh` 还勾着。界面上会实时给出提示。
2. **绕洞圈 / 穿洞圈的粗细也随环面切换**：`{select["torus", Thick, {}], ...}` ——
   环面在时是黄粗线（在实心环面上看得清），环面关掉后变成蓝细线（否则黄粗线太抢眼）。

## 5. Enabled 联动（原版 `Enabled -> MemberQ[...]`）

| 控件 | 可用条件 |
|---|---|
| `r` 管半径 | `show` 里有 **tube 或 tubes**（否则没管可调） |
| `t` 环面不透明度 | `show` 里有 **torus** |

不可用时滑条变灰、数字框禁用，并把整行调到 42% 透明度。

## 7. 与原版的差异（如实说明）

1. **光照照抄了 `Lighting->Automatic` 的显式设置**：环境光 `RGB(0.4,0.2,0.2)` + 四个**随画面固定**的方向光
   `RGB(0,0.18,0.5)`、`RGB(0.18,0.5,0.18)`、`RGB(0.5,0.18,0)`、`RGB(0,0,0.18)`。
   所以环面上那种**暖冷交错的彩色明暗**和原版一致（不是随便加的白光）。
   注意 Three.js r155+ 光照改用物理单位，实现时强度×π 做了补偿，否则整体会暗一档。
2. **曲线描边方式**：Mathematica 的 `Thick` 是**屏幕空间**线宽；Three.js 的 WebGL 线宽锁死 1px，
   所以用**细管**（TubeGeometry）来实现「粗线」。缩放到很近时管的粗细微妙差异于原版。
3. **`tube` 与 `tubes` 同时开启会互相套住**：两者半径都是 `r`，本就会重合——原版也如此，不是 bug。
4. **抗锯齿**：网页是实时 WebGL 抗锯齿，原版是静态光栅化，边缘像素分布必然有细微差别（几何本身经桩测对齐到 1e-9）。
5. `p = 1` 时 `close` 得到两点重合 ⇒ 折线/管段退化为零长度段，程序会自动跳过（不崩、不报警）。

## 10. 一分钟上手

1. **双击** `圆环表面绕行模拟TorusPaths.html`（需 Chrome / Edge；WebGL 不可用时会直接在画布上给出提示）。
2. 右侧浮窗「预设」点 **(2,3) 三叶结** 或 **(2,5) 外科结**，先认一认这两个经典结。
3. 在「显示元素」里把 **绕洞圈 / 穿洞圈** 打开 —— 对照理解 `n`、`k`：
   `n` = 路径与穿洞圈的交点数，`k` = 与绕洞圈的交点数。
4. 把 **环面** 关掉，看绕洞圈/穿洞圈**从黄粗变蓝细**、点**从黄变红**（原版联动）。
5. 拖 **p** 和 **s**，看等分点沿路径滑动；再打开 **折线 / 管段** 把它们连起来。
6. **拖拽**画布旋转、**滚轮**缩放、**双击**复位；点「▶ 自动演示」看 R→n→k 轮播（原版 `AutorunSequencing`）。
7. 想留档：**保存 PNG**；想复现：**复制参数**。
