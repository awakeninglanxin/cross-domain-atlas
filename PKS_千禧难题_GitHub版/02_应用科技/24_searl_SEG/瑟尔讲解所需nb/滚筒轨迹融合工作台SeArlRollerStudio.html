原理（统一核）

三份 nb 的曲线全部可以写成两个旋转向量之和：
P(t) = A·cis(ω_A·t + φ_A) + B·cis(ω_B·t + φ_B)，cis x = (cos x, sin x)。

① 单滚筒（滚动式）：定子 R、滚筒 r、笔距比 ρ →
A = R+r，ω_A = 1，B = ρ·r，ω_B = (R+r)/r（∓ 号即 ρ 的正负）。
滚动条件 ω_B = A/r 是它与自由本轮的分水岭。

③ 双生成：取 A = (n+1)r，B = −r，ω_B = n+1，正好满足滚动条件， 所以它既是「半径 r 的圆在半径 n r 外滚」，也是「半径 (n+1)r 的圆在半径 r 外滚」——同一条线两种生成。

④ 四滚筒：第 i 轮取 A = 开关，φ_A = iπ/2，B = 开关·r_i，ω_B = s_i·d_i。 大轮周期长（ω=1）、小轮周期短，正是原版说明里「大轮用小频率、小轮用高频率的正弦和」。
