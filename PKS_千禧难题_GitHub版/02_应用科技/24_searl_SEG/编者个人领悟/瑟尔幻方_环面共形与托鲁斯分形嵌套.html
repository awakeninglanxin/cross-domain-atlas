保角为什么封死球面：Liouville 卡住了「有限」

球极投影是共形的，但它需要整张无穷大的平面才能覆盖球面（再补上无穷远点当北极）。

正方形是有限单连通区域，共形等价于开圆盘；而圆盘 ≇ 整个平面 ℂ （否则会有非常数有界整函数，违反 Liouville）。

所以正方形保角地最多只能贴满球面的一大块，必然剩一条缝或一个洞； 想把缝缩成一个点，那里共形因子就发散 —— 纹理被拉成无限大，实际是退化点。

一句话：球面 χ=2，拓扑和曲率双重封死了「平面无缝全覆盖」；环面 χ=0，是唯一能被平面片真正无缝、 且在合适模参数下完美保角覆盖的闭曲面。这也是 CG 里球体 UV 永远有极点挤压和接缝、而环面 UV 是一块能无缝平铺的矩形的原因。

⑤ 托鲁斯分形 · 无限套娃（大环套小环，无穷嵌套）

这就是老师要的那个结构：一个托鲁斯里面还有一个托鲁斯，且无限循环。数学上称为 自相似托鲁斯嵌套 / 托鲁斯分形（Torus Fractal）。

两条性质

  • 自相似性（Self-Similarity）：镜头无限放大推进到里层子托鲁斯，内部结构与外层母托鲁斯一模一样 —— 视觉上的「无限回廊」。
  • 空间填充（Space-Filling）：嵌套层数趋于无限时，它在数学上演变成类似康托尔集（Cantor dust）的复杂分形结构 —— 表面积看似有限，却包含无限的拓扑层次。

维数公式（诚实版本）

设每层按比例 λ 缩放，每层有 N 个分支（子环）。按 Hutchinson 的自相似集理论，极限集的豪斯多夫维数：

dH = ln N / ln(1/λ)

⚠️ N = 1（就是老师描述的那种单链套娃）时 dH = 0 —— 极限集退化成一个点。 这不是缺陷，而是自相似的代价：无限自相似的单链套娃，体积/面积在极限下全部归零， 但它的拓扑层次仍是无限的。

要得到真正的分形（Cantor dust，维数 0<d<3），需要每层≥ 2 个分支。把 N 调到 2–4 就能看到。

⑦ 为什么 Searl 要用幻方：磁荷总和归零的普适规律

这是全页最核心的一节。幻方不是装饰，它是一台「每一线的代数和恒为零」的机器 —— 这正是磁荷守恒的离散形式。

第 1 步：幻方的定义

n 阶幻方把 1…n² 填进 n×n 格，使每一行、每一列、两条对角线的和都等于同一个数：

Searl 的「方」不限于奇数阶 —— n ≥ 3 的任意整数阶都能造（三类阶三种构造法，见本节末「三种阶 · 三种构造法」）。

S = n(n² + 1) / 2

第 2 步：中心归零

整体减去 (n²+1)/2，值域变成关于 0 对称，于是每一线的和都变成 0：

M' = M − (n²+1)/2　⟹　∀ 线 ℓ：Σℓ M' = 0

第 3 步：读成磁荷

把 M' 的值读成离散磁荷。那么「每一线和 = 0」就是：

每一线上的净磁荷 = 0　⟺　∇·B = 0

即不存在磁单极。反过来，任何非平衡的填充都会在某些线上留下净磁荷 —— 那就是"磁单极泄漏"，Searl 体系里叫 NO-GO。

阶 n 构造法 —
三种形态对照：① 中心归零幻方（值域 ±(n²−1)/2，每线和 = 0，中心格 = 0）； ② Searl 原式幻方（把标准幻方整体 −1 ⇒ 值域 0 … n²−1， 每线和 = T(n) = n(n²−1)/2，不是 0；奇数阶中心格 = (n²−1)/2 ≠ 0）； ③ 随机填充（人为 NO-GO）。 三者共用同一套配色与同一条判据：各线值是否恒定 —— 常数偏置（含 0）都属规范自由度， 只有线间离散才是净磁荷泄漏。② 的每线和 T(n) 正是原书 §61 / §62 的 DNA（T(3) = 12、T(4) = 30）。 另：奇数阶下 ② 与 ① 只差一个常数平移 ⇒ 画面同形、数字不同（整体平移不改物理）。

⑩ 结论与边界

四句话的结论

  1. 球面做不到，环面做得到。「把平面无缝包到曲面上」只有在 χ=0 的环面上才能既无缝又保角；球面 χ=2 被拓扑和曲率双重封死， 雷达图/UV 上那条接缝是数学的必然，不是工程疏忽。
  2. 保角 = 无接缝 = 无局部磁单极源。环面正好是那个"天生没有缝"的形状，而且只有 R/r = √2 那一档能把平面域做成正方形 —— 这是"为什么必须用环、而且是那个比例"的几何答案。
  3. 环的嵌套 = 层次的贯通。大环套小环无限嵌套（自相似托鲁斯分形）给出层次之间"能量信息贯通"的几何载体； 单链套娃的极限集维数为 0（退化成点），要真分形需每层 ≥2 分支。
  4. 幻方 = 磁荷总和归零的通用骨架。中心归零的幻方使每一线代数和为 0 ⟺ ∇·B = 0 ⟺ 无磁单极； 而真理表给出"哪些阶能共享同一个 S"——同一个 S 就是跨层次贯通的频率。Searl Ex5 的 4410 ↔ 恰 8 个阶， 是这条规律的一个可复算的实例。

一、定律：三行推导，而且与「幻方」无关

偶数阶方阵的中心 2×2，在「自然序 1,2,3,… 按 n 列排布」下必为紧凑块：

中心四数 = { a, a+1, a+n, a+n+1 }, a = n(n−1)/2 （本页面板摆法：左上 a　右上 a+n　左下 a+1　右下 a+n+1） 横合差 |H| = |(a + a+n) − (a+1 + a+n+1)| = 2 ← 两行各错开 1 ⇒ 两行和只差 2 竖和差 |V| = |(a + a+1) − (a+n + a+n+1)| = 2n ← 换列跳 n ⇒ 两列和差 2n 对角差 D = (a + a+n+1) − (a+1 + a+n) = 0 ← 恒等 比 值 = 2 : 2n = 1 : n

n = 4…40 全偶数阶验证通过 ⇒ 分母就是阶数。LEVEL 平移（131–166 还是 1–36）不改变差值 —— 平移不改变步长。

二、交互：任选偶数阶，理论紧凑块 vs 本页实测

阶 n = 6 只有偶数阶（Searl 的 GROUP 2/3）才有 2×2 中心块；奇数阶是单点中心，用「十字归零」而非 1/n。

三、边界（本节新发现）：谁是 1/n 律的忠实携带者

双偶·十字互补法天然保住紧凑中心块（拿到 n : 1 方向）；单偶·Conway LUX 法保不住 —— 中心换成 4 连号 { n²/2−1 … n²/2+2 }，横差直接塌成 0。
⇒ 「1/n 律」既不是幻方通则、也不是偶数阶通则，而是「保住了自然序中心 2×2」这一族构造的指纹。 这正好解释了 Searl 为什么要把偶数阶单列为 GROUP 2/3（四单位中心），而不与 GROUP 1 混用。
本表为什么没有奇数阶？因为这张表的度量对象是中心 2×2 块 —— 奇数阶的中心是单点， 凑不出 2×2 块，横差 / 竖差在这张表的口径下根本无从定义（边界二）。奇数阶的构造法是 暹罗法 Siamese（本页 ⑦ 节末已实现 magicSiamese）， 它携带的对应指纹是 Searl 原文说的 「单杠十字」（single bar cross），见下一卡 三-bis。 但奇数阶也能进表 —— 只要把中心数纳入四象限，见下面 三-α。

三-α　补齐：奇数阶也能有「横差 / 竖差 / 比」—— 把中心数纳入四象限（2026-10-14 新增）

奇数阶的中心是单点，切不出中心 2×2；但只要让四个象限各「吃进」中心格， 就得到四个共享中心格的 2×2。以 3 阶 8 1 6 / 3 5 7 / 4 9 2 为例，四块 = 8 1 / 3 5、1 6 / 5 7、 3 5 / 4 9、5 7 / 9 2（中心格 5 是四块的公共角）。 四块的并集恰好 = 中心 3×3 去掉四个角 —— 紧挨中心格的「小十字」，正是 Searl 说的 single bar cross 的核。 所以奇数阶不是被排除在外，而是必须换一个「含中心格」的口径。

换完口径后出现两条不同的律，所以下表并列两个口径：

  • 口径 A · 自然序窗口 —— 把该窗口按自然序 1…n² 填，四数必是紧凑块 { b, b+1, b+n, b+n+1 } ⇒ 与第一节逐字相同：H = 2、V = 2n、比 1 : n。 奇数阶同样携带 1/n 指纹（负号只来自面板摆法方向，比取绝对值）。
  • 口径 B · 暹罗法实填值 —— 不是 1/n，而是另一条 (n+1) : (n+2)； 且 n ≥ 7 时四块完全相同。

口径 B 的四块在 n ≥ 7 时完全相同：|H| 恒 = 2n + 2、|V| 恒 = 2n + 4（比 (n+1) : (n+2)），可解析证明：暹罗法中心 3×3 有通式
c−(2n+3)　c−(n+1)　c+1　／　c−(n+2)　c　c+(n+2)　／　c−1　c+(n+1)　c+(2n+3)
四块各含中心 c，逐块算和差都只与 n 有关 —— 与 c 无关。越界判据：首格 A = c − (2n+3) ≥ 1 ⇔ n² − 4n − 7 ≥ 0 ⇔ n ≥ 7；故 n = 5 只有 A、I 两格越界（2/4 块成立）、n = 3 四格越界（0/4）。
另有一条不依赖通式、全 n 恒成立的：对角两块 (H, V) 恒相等 —— 来自暹罗法的中心对称性 f(i,j) + f(n+1−i, n+1−j) = n² + 1，且 f(中心) = (n²+1)/2 恰好是中心值。

三-bis 补齐（本节新发现）：奇数阶怎么造，它的「十字」长什么样 —— Searl 原文 Group 1 = single bar cross

奇数阶的构造法是暹罗法（Siamese / de la Loubère，中文常称「连续摆数法」「罗伯法」）： 从顶行正中放下 1，之后每步向右上走一格；越界就回绕，若该格已被占，改为下移一格再继续。 本页 ⑦ 节的 magicSiamese(n) 就是它 —— 所以奇数阶从来不是缺失， 只是它进不了上一张表（那张表量的是 2×2 中心块，奇数阶的中心是单点）。 奇数阶的对应物是十字（中行 ∪ 中列），瑟尔把它叫 single bar cross（单杠十字）。

“…it is clear that all odd numbers have a central cross in its construction. Notice that the horizontal bar steps from left to right in steps of two. Whereby, the vertical bar steps by four from top to bottom. Total both bars = six which fits the game of hopscotch absolute. Also clearly shows odd numbers are of lower energy than the even numbers.” SearlFX-Math-1.pdf · p.35 附近（IMA 知识库「searl瑟尔飞碟」）—— 奇数阶的定义性特征就是「中央十字」
“…the horizontal bar steps in 10, while the vertical bar steps in 20 to form that central cross. This mean that the horizontal bar adds it power of 10 to the vertical bar of 10 thus double the energy level?” 同书 p.83。该页的「方」是 60 25 50 / 35 45 55 / 40 65 30（幻和 135）—— 正是基础 3 阶方逐项 ×5 再 +20，于是 横 2→10、竖 4→20，比例不变
“All odd numbers belong to group one … as witnessed in above sample of a group one there is a single bar cross. Group 2 has no cross at all. But group 3 has a double bar cross, which makes it hard to work out. Group ones will pair with any even number to create pairs at higher energy levels.” 同书 p.79 —— 与本页三类阶一一对应：Group 1 = 奇数阶「单杠」／Group 2 = n≡0 (mod 4)（中心是纯等差方块，看不出十字）／Group 3 = n≡2 (mod 4)（中心 4 连号成环 = 双杠，最难算）
读表的三个层次：① 瑟尔写的「横 2」是普适的 —— 所有奇数阶的中行里都恒定夹着两个步长为 2 的接缝（左右对称），n = 3 时整行只剩它，于是退化成「整行步长 2」； ② 他写的「竖 4」是 n = 3 专属，一般 n 是 n + 1（n = 3 恰好 = 4）； ③ 所以「合计 6」也只在 n = 3 成立，可自然推广为 2 + (n+1) = n + 3（我方推广，原文未给）。
⇒ 奇数阶的十字近乎对称（竖 n+1 vs 横 n+2），两臂差值趋零 —— 方向上正对应瑟尔那句「奇数阶能量低于偶数阶、只作输入助推器」。
一条诚实说明（我先把错的路走过）：在库里搜 Siamese 确实命中过一条，读原文后确认是假阳性 —— 那句是商业统计教材语境的 “control is … the Siamese twin of planning”（控制的孪生兄弟），与幻方的暹罗法无关。
换句话说：瑟尔书里并没有给奇数阶的构造步骤（他假定你本来就会，只说「每个 value set 有自己的 DNA，square 4 我 12–17 秒就能算完」）， 他给出的是奇数阶的结构描述（中央十字）与角色定位（group one / 输入助推器）。上面的暹罗法步骤是本页按经典做法补的，不是引原文。
