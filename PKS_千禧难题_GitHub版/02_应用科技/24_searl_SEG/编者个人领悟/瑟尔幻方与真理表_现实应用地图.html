纪律一 · 只迁「结构」，不迁「数字」

可迁走的是：全局约束 + 多尺度嵌套 + 等价冗余。 不可迁走的是：870 / 918 / 34 这类具体数值作为物理因果。

纪律二 · 判据必须可一行验算

例如「共享线值」写成 V_n(L) = n(n²+2L−3)/2，代进去就对； 「线和 = 某个神秘数」不可测量、不可证伪，一律不作设计依据。

纪律三 · 解不出来 ≠ 放低标准

约束集下求解器无解时，结论是「自然界不允许这件事」， 而不是把阈值降一降再宣布成功。

6A.2 「除以 m 取余」的准确数学：等原子 ⇔ m | n²

把 1 … n² 逐格取 mod m，余数 0 … m−1 就是 m 个组元， 组元 j 的原子分数 = 余数为 j 的格数 / n²。于是问题变成一个纯计数问题， 而且与幻方怎么排布完全无关（幻方只改「哪些格归哪个组元」的位置，不改计数）：

余数为 j 的个数 = floor[ (n² − j + m) / m ] ⇒ 严格等原子（每个余数 n²/m 个） ⇔ m | n² 由 p^a ‖ m 得 2·v_p(n) ≥ a ⇔ v_p(n) ≥ ceil(a/2) ⇒ 令 h(m) = ∏ p^ceil(a/2) （m 的「半次幂」），则 等原子 ⇔ h(m) | n

6A.3 幻方在这一步真正给了什么（按可迁移度排序）

① 配比发生器 — 强

mod m + 半次幂定理，直接给出严格等原子配比与「该用几阶」， 并可反向查：给定 n 阶，能等原子配到几元（n² 的约数 ≤ 15 的那几个）。 可一行验算，可当场复现。

② 正交区组设计 — 强，最实用

n 阶幻方的「每行和 = 每列和」等价于一张 n×n 平衡安排： 行 = n 个批次 / 炉次，列 = n 个位置（炉位、坩埚位、样品位）， 则每个批次在每个位置各出现一次 ⇒ 位置效应与批次效应正交。 这就是拉丁方 / 随机化区组设计，是统计学的现成工具。 能直接排实验、能做方差分析。

③ 壳层 = 配位壳 — 弱，只作启发

n 阶壳格数 4(n−2k+1)−4 与 FCC/BCC 配位数（12 / 8 / 6）没有对应关系。 只能说「多尺度同时自洽」这个口号成立，不能说「同构」。 不可作设计依据。

④ 混合焓矩阵 = 格子配对 — 无效

二元 ΔHij 是 m×m 的反对称矩阵（Cm2 个独立数）， 幻方里没有这个结构，硬套只会得到「配对 = 任意两格」。审稿人会当场毙，别写进论文。
必须写明的一条边界：幻方不能预测相。相由热力学定（CALPHAD / ΔH、ΔS、VEC）， 幻方只管配比与实验排布。任何「按幻方排就能出单相高熵合金」的说法都是把编码当因果。
不可迁移清单（这三条不要写进申请/论文）：
· 「幻方数值 = 原子半径」——原子半径由电子结构决定，与序号无函数关系，这是类比不是映射。
· 「幻方数值 = XFS / X 射线频率」——同上；序号可当随机化标签，不能当物理量。
· 「除以 m 的余数 = 五元高熵的自然分组」——数学上只是 mod 同余类， 它保证计数均匀，不保证能量均匀。

II·6B专题 B · 芯片与半导体开关阵列：4-bit、12 态、垃圾桶与热斑

笔记那条链是：4 bit 16 格 → 四阶幻方重排 → 留 4 格当垃圾桶 → 12 态对应十二支 → 729 九宫 → 分布均匀所以不发热。 这一节把它拆成五段，逐段标「能验算」/「不成立」/「待实测」。先说结论：这条链里有两段是真的、一段方向对但量级差 5 个数量级、一段是编码不是物理。

6B.1 第一段：CPU 的热到底从哪来（先把账算清）

Landauer 极限（擦除 1 bit 的最小代价）： EL = kBT·ln2 T = 300 K → 2.871×10⁻²¹ J = 0.0179 eV T = 350 K → 3.349×10⁻²¹ J T = 400 K → 3.828×10⁻²¹ J 现代 CMOS 单次门翻转： ≈ 1×10⁻¹⁵ J ⇒ 是 EL(300K) 的 3.5×10⁵ 倍 ≈ 5.5 个数量级

再看整机口径（120 W、4.5 GHz、10¹⁰ 晶体管、活动率 10%）：

每次有效翻转 = 120 / (4.5×10⁹ × 10¹⁰ × 0.10) = 2.7×10⁻¹⁷ J ≈ 9×10³ kT·ln2 其中 Landauer 那一份占 2.871×10⁻²¹ / 2.7×10⁻¹⁷ = 0.0001%
当代 CPU 功耗构成占比公式与「擦除」的关系
动态（开关）~50%P = α C V² f充放电，可回收（绝热充电），但不是必然耗散
漏电（静态）~30–40%P = V·Ileak，I ∝ e−qVth/kT与信息无关，纯粹是「关不断」

6B.2 第二段：笔记真正指对的那件事 —— 局部不均

「半导体矩阵分布不够平均和均匀」这个直觉是对的，而且它说的是产业里最硬的骨头之一：

热点局部功率密度可达 100–300 W/cm²，远高于芯片平均值（现代 SoC 平均约 10–30 W/cm²） 正反馈漏电随温度指数上升：结温每升 10 °C，漏电约翻倍 ⇒ 热点更热 后果触到 Tjmax（约 100 °C）就降频（thermal throttling）⇒ 标称性能拿不到 产业名dark silicon（暗硅）、thermal-aware placement、任务迁移、DVFS

注意它衡量的对象：版图与供电域的功率密度，而不是「数字怎么排」。 下面这一段才是「数字怎么排」能插手的地方。

6B.3 第三段：四阶幻方 → 16 单元状态编码（三条可验算）

先把映射说清楚（这是人为指派，不是发现）： 4 bit → 16 个码 → 分配给 16 个物理开关单元；一行 = 一个功能块 / 一个供电域； 该行 4 个单元的 popcount（二进制里 1 的个数）之和 = 这个域「同时导通的位数预算」，作为功耗代理量。

(a) 等概率模型下，任何重排的平均翻转位数都等于 2.0

16 个码，任取两码 a、b，每一位独立各 50% 相同 ⇒ 平均 Hamming 距离 = 4 × ½ = 2。 所以「用幻方重排能降低平均翻转功耗」在最理想化的等概率模型下收益为 0。 真正的收益只能来自真实负载的 locality —— 那就不是幻方能先验保证的了。

(b) 四行 popcount 全等 —— 算术上不可能（纪律三的活例子）

popcount(1..16) = 1,1,2,1,2,2,3,1,2,2,3,2,3,3,4,1 ← 注意 pc(16)=1（16 = 10000） 总和 = 33 33 / 4 = 8.25 33 % 4 = 1 ≠ 0 ⇒ 任何 4 阶幻方的四行 popcount 之和恒为 33，永远不可能四行全等 算术上最接近的分布 = 8+8+8+9 = 33（极差 1；最差行 9 比均值 8.25 高 9.1%） 注：8+8+8+9 是「整数上最理想」，能不能真构造出来需另证，本页未给实例。

这一条特别适合当「纪律三」的样板：不是设计得不够好，是33 除不尽 4。 想要四行全等，唯一的办法是改口径（换代理量、或把 16 拆成 8+8 两组各 16.5 —— 也不行）。 所以幻方在这里的诚实价值是：给出下界，而不是给出完美。

10.1 DNA 侧的真实落点是拓扑，不是片段

知识库里那份 SearlFX-DNA-1 讲的不是「剪一段插一段」，而是 DNA 的高阶结构： 超螺旋（supercoiling）、打结（knotting）、连锁（catenation）、连接数（linking number）、扭转（twist）、缠绕（writhe），以及改变拓扑的拓扑异构酶。同一文档把细胞看作能量转换装置。

Lk = Tw + Wr （连接数 = 扭转 + 缠绕） ΔLk = Lk − Lk₀ （连接差；负 = 负超螺旋） σ = ΔLk / Lk₀ ★ 比连接差：归一化后跨长度可比 ΔLk = ΔTw + ΔWr （Lk 不变时，Tw 与 Wr 等值反向）
「线和守恒」在 DNA 里本来就有实证版本，不用去幻方里找：
转录时双链并不断裂 ⇒ 总 Lk 不可能改变 ⇒ 聚合酶两侧的 Tw + Wr 变化必须大小相等、符号相反。 这就是一个天然的、可测量的守恒实例。
再加一条硬数字：单个核小体贡献 ΔLk ≈ −1（实测 −1.01 ± 0.08）⇒ 每个核小体都在改变全局拓扑账本， 这正是「改一处必须全局补偿」的约束来源。

10.2 为什么 σ 才配得上「共享线值」

同样的 ΔLk 在小分子里产生的扭转应力比大分子大，所以连接差必须归一化到分子长度。
