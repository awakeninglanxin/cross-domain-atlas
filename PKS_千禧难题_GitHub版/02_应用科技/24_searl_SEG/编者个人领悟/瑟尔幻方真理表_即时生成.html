维度 d 的统一引理（d = 2 / 3 / 4 通用）

维度 d：
把 a, a+1, …, a+nd−1 填进 n 阶 d 维阵列（nd 格），总和 nd·a + nd(nd−1)/2； 沿任一主轴有 nd−1 条线、每条 n 格，若它们全都相等则 
S = n·a + Td(n),   Td(n) = n(nd−1)/2
d = 2 → n(n²−1)/2（幻方，复现现有全部结论）｜d = 3 → n(n³−1)/2（幻立方， 即 ⑩ 页与源 VBA 的 j*(j^3+1)/2−j）｜d = 4 → n(n⁴−1)/2。
线条数（只数 d 个主轴方向，不含体对角）= d·nd−1： d=2 得 2n｜d=3 得 3n²｜d=4 得 4n³。若把 2d−1 条体对角也算进「全等」， 那是更强的条件（d=2 → 2 条、d=3 → 4 条、d=4 → 8 条），本页真理表延用瑟尔/xlsm 口径不算体对角。
关键：判据与 d 无关。 Td(n) mod n：n 奇 ⇒ nd−1 偶 ⇒ Td/n = (nd−1)/2 是整数 ⇒ n | Td；n = 2m 偶 ⇒ nd−1 奇 ⇒ Td = m(nd−1) ≡ m (mod n)。 所以 n 能承载 S ⇔ (S−Td(n)) 是 n 的非负整数倍，其中「奇 n：n | S」「偶 n=2m：n | (S−m)」 这一分岔对一切 d 一字不改 —— 换 d 只把「哪些阶落进 Td(n) ≤ S 的窗口」换掉。

引理：n 阶幻方填连续整数 ⇒ 线和是一条直线

把 a, a+1, …, a+n²−1 填进 n 阶幻方，总和 n·a + n(n²−1)/2，平分到 n 行： 
S = n·a + T(n),   T(n) = n(n²−1)/2 = 3·C(n+1,3)
VBA 里那句 u = i*(i^2+1)/2 − i 就是 T(n) 的另一种写法。

定理 1：可承载判据

n 能承载线和 S ⟺ (S − T(n)) / n 是非负整数。奇偶分岔： 
n 为奇数 :  S ≡ 0    (mod n)
n 为偶数 :  S ≡ n/2  (mod n)

定理 3：一组阶数能否共享同一条线

上面那组同余式有解 ⟺ 其中所有偶数阶的 2-adic 赋值 v₂ 完全相同。
直接推论：4 与 6 永不共享（v₂(4)=2，v₂(6)=1）。本页「判定」走的是通用 CRT（更普适），结论与该定理一致。

定理 4：N(S) 的闭式解

N(S) = { 奇数阶 n : n | S }  U  { 2^(v2(S)+1) * q : q 为 S 奇部之奇因子 }
带阈值 T(n) ≤ S。
例：4410 = 2·3²·5·7²，v₂ = 1 ⇒ 偶数阶被锁成「4 的倍数」，6 / 10 / 14 / 18 整体出局， 最终 N(4410) = {3,4,5,7,9,12,15,20}。
关于「即时生成」：以上四条把三张表全部化成了可算的表达式。本页唯一的循环是 (d−c+1) × (b−a+1) ≈ 4.24×10⁶ 次整除判断（约 20–40 ms）， 其余（布局表逐像素、直方图、CRT）全部按需现算。因此 4 MB 数据可以完全删掉。

⑤ 等差列（t 项）：SEG / IGV 两条线是怎么分开的

把「线和是奇数」和「线和是偶数」这对互补条件写进 N(S) ⊇ 必含阶数： 
必含 6 阶  ⟺ S ≡ 3 (mod 6)  ⟹ S 必为奇数   → IGV（池 719 个）
必含 4 阶  ⟺ S ≡ 2 (mod 4)  ⟹ S 必为偶数   → SEG（池 465 个）

于是任意一项等差数列（公差 d）能同时落在池里，必须 d ≡ 0 (mod 6)（IGV）或 d ≡ 0 (mod 12)（SEG）—— 实测 igv.csv 的公差全是 6 的倍数、seg.csv 的公差全是 12 的倍数，一条不差。

⑫ mi(q) 语言 —— 吴硕辛的模运算演算体系，用「行源 ⊕ 列源」生成任意阶幻方

与 ⑪ 是两条不同的路线：⑪（高治源 27 阶程序）走的是自相似嵌套（种子套种子，3→9→27→81）； ⑫（吴硕辛）走的是模运算线性演算 —— 把每个格子写成「行源与列源的 mi(q) 和」，一步得出整张方阵， 而且能做偶数阶里 2 的幂（瑟尔用的四阶就属这一类）。
mi(q) 加法（本页全部计算的地基）：把两个数各自写成 q 进制数字串，逐位 mod q 相加，不进位。 q=2 时它退化成 按位异或 XOR —— 也就是计算机里的「按位加」。
例：mi(3) 37 ⊕ 13 ：37 = 11013、13 = 01113 → 逐位加模 3 得 12123 = 50
mi(2) 14 ⊕ 7 ：14 = 11102、7 = 01112 → XOR 得 10012 = 9
五个基本要素（吴硕辛原话）：映射（数 ↔ q 进制数字串）｜法相（每位的取模类）｜结合法（逐位 mod q 相加）｜ 排列及其浸染（排列 + 通加常数，仍为幻方）｜矩阵及其浸染之合体（整表合成）。另有 0 约定：项号、起始行、起始列都从 0 起 —— 所以吴硕辛的方阵里 0 不是空位，是「无极」（本页 0 起 / 1 起两档都提供，见 ⑫-C）。

⑫-E 浸染演算 —— mi(q) 通加一个常数，还是幻方吗？

浸染＝给全表每一格都做一次 mi(q) 通加（数字逐位 mod q 加 K）。源文断言瑟尔那张四阶幻方「不受任何浸染的影响」。 本页把这件事推广验证了一遍，结论截然分成两半 —— 这正是 mi(q) 幂法与 2 位线性法的本质差别：
· mi(q) 幂法（n = qk，瑟尔四阶在内）：M = 列源 ⊕ 行源，通加 K 只是把列源整体平移，每一位的均衡性自动保持 ⇒ 任意 K 都仍是幻方（本页对 n=4/8/9/16/25/27 把全部 n² 个 K 都试过，无一例外）。
· 2 位线性法（奇数阶闭式）：K 写成两位 (k0, k1) = (K mod n, ⌊K/n⌋)，通加 K 就等于给偏移量 e、f 各加 k0、k1； 而行、列和与偏移无关，两条对角和却只认偏移，且幻方要求 e ≡ (n−1)/2、f ≡ (n+1)/2（mod n） ⇒ 在 K = 0…n²−1 这 n² 个取值里，恰好只有一个 K 能让它成为幻方（本页对 n=3,5,7,9,11,15,27 全域实算，安全者都只有 1 个）。 本页的基线已经把 e、f 取成那两个值，所以那个唯一的 K 就是 0 —— 其余 K 一律破对角线。 源文那个 mi(3) 算例正好相反：它的基线是 e = f = 0（本来不是幻方，两对角和 9 / 21 ≠ 12）， 而它唯一的那个 K 就是 7 —— 所以源文才必须「浸染 7」，浸完再 +1 才落到洛书（见 ⑫-F 第 1 行）。
· 经典法完全没有 mi(q) 结构，通加 K 不属于它们的演算体系 —— 这时参数浮窗里的「浸染 K」会自动置灰。

⑫-H 方法与源流 —— 每种方法管哪些阶、给哪些属性、出自谁

三条硬边界（都是数学结论，不是本页没做）：
· 单偶阶 n ≡ 2 (mod 4) 没有泛对角幻方 —— A.H. Frost（1878）与 C. Planck（1919）证明。 这一档只能做到 near-pandiagonal：恰好 4 条折断对角失准，而这已是极小值 （Planck：每个方向至少 1 条失准，为补偿同方向必有第 2 条 ⇒ 最少 2+2 = 4）。 本页已实现：生成法选「三步近泛对角法」即可现算 —— 图案阵成对互补且每块列偏差和为 0 ⇒ 半幻方（中心对称只坏中央 2×2）⇒ 一次 Planck A–D ⇒ 每个方向只剩 2 条坏对角 ⇒ 移列把 4 条推到折对角上。
· n = 3 只有一种方阵（洛书） —— 而且洛书不是泛对角方（折断对角 1+7+4 = 12 ≠ 15）。
· 3 整除 n 的奇数阶：线性方法（骑士步 / Step method）永远做不出泛对角。理由是一句话的模 3 论证： 条件要求 a、b、a+b、a−b 都与 n 互素；模 3 时 a, b ∈ {1, 2}，a = b 则 a−b ≡ 0，a ≠ b 则 a+b ≡ 0， 两种情况必有一败 ⇒ (a, b) 不存在。本页把 n = 9 / 15 / 21 / 27 / 33 的全部单位对都枚举过，符合条件者 0 对。 这类阶数的泛对角方阵存在，但必须用非线性构造（Margossian 1896/1908、Rouse Ball 第 208 页），本页不做构造 —— 但下面直接给出两张已公开发表、可逐行核对的实例，本页对它们当场审计。

⑫-J 双幻方 bimagic —— 每个数换成平方之后，方阵依然是幻方

定义：把方阵里每个数换成它的平方，得到的方阵仍然是幻方（行 / 列 / 两条主对角各自全相等）， 就叫双幻方（bimagic，也叫 2-multimagic）。于是有两条线值同时成立： V = n(n²+1)/2（1 起口径）与 Vb = n(n²+1)(2n²+1)/6。 本页对 0 起（无极）口径同样判定 —— 整体平移不改变「平方和相等」这条性质。
最小阶 = 8：Benson 与 Jacoby 1976 提出「8 阶以下不存在」的猜测，Boyer 与 Trump 2002 就 1…n² 口径给出证明。 （3 阶另有一条短证：由 a + i = 2e 与 a² + i² = 2e² 联立得 (a−i)² = 0 ⟹ a = e = i —— Lucas 1891 / Hendricks 1998； 4 阶用连续整数同样不可能，Pebody 与 Rosa 2004 各自独立证明。）
本页做法：n = 8 直接给 Pfeffermann 1890 年那张历史上第一张双幻方（1 起，V = 260、Vb = 11180，逐格现算核对）； n = pk 用数字网格法 M = 1 + Σt pt·Gt、 Gt[i][j] = (mt 点乘 x) mod p 现算，其中 x = （i 的 k 位 p 进制数字 ‖ j 的 k 位数字）—— 关键是每张网格都要用到全部 2k 位，且四族向量 {A}、{C}、{A+C}、{A−C} 必须两两 2 阶满秩、整个 2k×2k 系数矩阵可逆 （漏掉 {A−C} 一族时：p = 2 下 a+c 与 a−c 同余会「碰巧」通过，奇数 p 的阶则全部失败 —— 这是本页踩过的坑）。
历史：Pfeffermann 1890 找到历史上第一张双幻方（8 阶），1891-01-15《Les Tablettes du Chercheur》第 2 期以谜题形式刊出、两周后公布完整解； 9 阶首例见该刊 1891-07-15 第 14 期（完整解见 OEIS A381001）｜ 陈钦梧（Qinwu Chen，汕头大学）等 2006-02-06 给出首张 13 阶双幻方（1 起 S1 = 1105、S2 = 124865）， 后以《A Bimagic Square of Order 13》刊于 American Mathematical Monthly 2007 年 10 月号 p.702｜ Kejun Chen & Wen Li《Existence of normal bimagic squares》Discrete Math. 312(21) 2012, 3077–3086｜ Trump & Gaspalou 2014（2013-12 起算、2014-04 完成）：8 阶双幻方共 192 × 136,244 = 26,158,848 张（本质不同 136,244 张）。
为什么要「烘表 + 现搜」两条腿走路：双幻方极稀疏。本页实测数字网格法的随机命中率 —— n = 9 与 n = 16 都 < 1/20000（所以这两阶直接烘已核实的解）， n = 25 约 1/70、n = 27 约 1/1700、n = 32 约 1/500、n = 64 约 1/200，现场限额搜索即可； 其余 pk 阶走现场搜索兜底（限额 6000 次 / 400 ms，失败就如实说明，不编造）。
