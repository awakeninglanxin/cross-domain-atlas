2.2 3:6:9 的数学骨架（→ K2 页）

#笔记主题核心结论
321 个八度 / 105 / 三个八度21 = 每种能量形式的罗盘宽度，105 = 21×5；"三个八度"是相对编号（620 Hz 音叉的第 1/2/3 位）
43:6:9 = 2 的幂的指数序列2³=8 / 2⁶=64 / 2⁹=512；系数必须是 3——"质数 2 以其任何幂都不产生新音符"
5绝对八度编号log₂ 换算表；静止分子 20,000 cps = 第 14.3 个八度（振荡域），激发到 100 MHz = 第 26.6 个（振动域）
63:6:9 在 21 八度罗盘中的定位v4 新增节；更正：3:6:9 分别落在 1–21 / 21–42 / 42–63 三段，不是全落在 21–42
7×3 vs ×2 矛盾的化解★ 撤销此前的"矛盾"判定：Keely 原文写了"分子级为 1:3:9:27:81:243（算术），这个算术级数在原子级变为几何级数 3:9:81:6561:43046721"。分子域 ×3，原子域 3^(2ⁿ) 平方递进
8原子间频段核实300,000–780,000 cps 不是原子间固有频率——原文说"在第一个原子间之下"，那是磁致伸缩驱动频段；现实原子间是 1–40 THz 声子

"Keely 打到原子核里"⚠️ 改为「原子内三单元」。Keely 早于卢瑟福 17 年，无核概念；3¹⁶ 那级才对应核尺度K4
装置是否用了黄金比 / Fibonacci✅ 都没用。φ 是"去耦合工具"，Keely 要的是"最大化耦合"，两个相反方向01、总入口
