定律清单、公式、八度换算表与实验方案

生成日期：2026-10-17 资料基础：知识库「keely信息包」+ 联网检索来源编号说明：[pdf_x] = 知识库文档；[web_x] = 联网检索结果用途：实验室对照 / 实验方案设计 / Keely 比例理论的可证伪性检验

0. 一句话总纲

所有"看起来不是 1/L"的标度律，本质都是某个无量纲形状比（如 h/L）在变。 只要把所有尺寸锁死成同一比例（几何相似）+ 材料相同 + 边界条件相同，频率标度就无条件回归 f ∝ 1/L。

1. 总律（上位定律）

L0 · 几何缩尺律（similitude）

「如果你做一个结构的缩尺复制品，所有尺寸按同一因子缩放，那么所有频率都按该因子的倒数缩放。例如把木琴条或小提琴缩小 6%，所有频率上升一个半音（假设用相同材料）。」[web_130]

量纲分析过程（以梁为例）：

  • 频率 ∝ √(弯曲刚度) / √(单位长度质量) / L²
  • 矩形截面时：与宽度无关、正比于厚度、反比于长度平方
  • 「任何使 厚度/长度² 之比降低 6% 的改动，音高就降半音」[web_130]

推论（本文推导）：f = (c/L) · F(无量纲形状比)。F 恒定时 f ∝ 1/L。

2. 分对象标度律清单

L1 · Chladni 第一定律（板 · 厚度）

同形状、同细分图形的两块板，振动数正比于厚度；厚度 ×2 → 高一个八度。[web_107]

L2 · Chladni 第二定律（板 · 等厚变径）

同厚度、直径比 1:2 的两块板，小者高两个八度；振动数反比于直径的平方。[web_107]

定量形式：

f = (h·π / (4√3 · d²)) · √(E / (ρ(1−ν²))) · (n + 2m)²

h = 厚度，d = 直径，m = 节径数，n = 节圆数。[web_144]

L3 · Chladni 第三定律（板 · 相似固体）★ 即 Keely 所引述者

「若厚度与其他尺寸成比例，即两板为相似固体，振动数反比于对应边。取厚和直径都是另一块两倍的板，大板发出的音比小板低一个八度。」[web_107]

「这最后一条定律对固体、液体和气体同样成立……Savart 证明：同材料同形状的棒，振动数反比于对应边。对同物质的球、立方体、圆柱或其他可比较尺寸的固体，该定律同样成立。」[web_107]

L4 · 历史实验证据（19 世纪 · 铁球）

「这里悬挂着两个铁球——一个直径 6 英寸，另一个 3 英寸。敲击以获得基音，我们发现大球比小球低一个八度。」[web_107]

6″ : 3″ = 半径 1:2 = 体积 1:8 = 一个八度。

知识库对应原文（Keely / Dale Pond）：

「线性尺寸定律可以这样表述：两个环境相似的同源体的振动周期彼此为它的立方体积，因此同源金属板的振动频率彼此为它们的线性尺寸的反比。给定板的八度音阶将是具有其体积的 1/8 的同源板。直径二十英寸、厚一英寸的圆盘振动例如每秒 1024 次。」[pdf_3]

「通过准确地确定……能够以（每秒 1024）的音调振荡的任何金属球体的体积音高，然后通过其本身的 1/8，我们得到周期频率中越来越高的连续八度音高。」[pdf_3]

实验条件（自由边界）：

「一个矩形的，或者最好是圆形的圆盘以这样一种方式悬挂在房间的天花板上，使得振动不能从房间的振动墙壁传递到它。」[pdf_3]

L5 · 圆板 / 圆盘（板极限 · 现代写法）

f₀ ≈ (10.215 / 2π) · √(E_Y / (12·ρ·(1−ν²))) · t / r²

f ∝ 厚度 t / 半径² r²；适用前提：γr²/D → 0（张力可忽略、抗弯刚度主导）。[web_124]

经验 Chladni 圆板定律：

ω_mn ≈ √(E / (12ρ(1−σ²))) · (π²h / 4r²) · (m + 2n)²

[web_146]

L6 · 薄板标度的实验验证（2024 · 可复现）

同材料、同厚度的两块铁方板（20 cm 与 25 cm），f′ = (L²/L′²) · f

  • 九组模态拟合斜率：1.534 ± 0.002
  • 理论值 (25/20)² = 1.56
  • 相对误差：1.9% [web_141]

绝对数值对照：

试件最低模态频率
240 mm 见方 × 1 mm 厚钢板（E=200 GPa, ρ=7850, ν=0.29）57.0 Hz
同尺寸 × 2 mm 厚114 Hz（正好加倍）

[web_105]

L7 · 细棒 / 细条

纵向（longitudinal）

f_n = n · v / (2L),   v = √(Y/ρ)

f ∝ 1/L，且与厚度无关。[web_126] [web_128]

横向弯曲（自由-自由）

f = (π·ν·K / (8L²)) · m²,   扁条 K = 厚度 / 3.46

f ∝ h / L²；模态比 1 : 2.76 : 5.40 : 8.93，完全非谐。[web_126] [web_127]

L8 · 实心弹性球（Lamb 1882）★ 球体的严格解

无量纲频率：

s = ω·a·√(ρ/μ)      a = 球半径

s 只依赖模式编号，不含尺寸 ⇒ ω ∝ (1/a)·√(μ/ρ)，即 f ∝ 1/a 严格成立。[web_153]

Lamb 原文算例：

  • 半径 1 cm 的钢球，二阶球谐基模频率约 136,000 次/秒
  • 「对于任何其他尺寸的钢球，这个结果必须除以以厘米为单位的半径」
  • 地球大小的钢球，周期 1 小时 18 分 [web_91]

Lamb 理论同时适用于行星（~mHz）与纳米颗粒（~GHz）。[web_149]

近似式：

f_L ≈ (v_L / 2R)·(l + 2n_L + 1)
f_T ≈ (v_T / 2R)·(l + 2n_T)

[web_90] [web_92]

实验验证（纳米尺度）：Si 纳米晶受限声学声子，「频率正比于颗粒中的声速、反比于颗粒尺寸」。[web_95]

L9 · 膜（张力驱动）

f_mn = (x_mn / (2πa)) · √(T/σ),    x₀₁ = 2.405

f ∝ 1/a，∝ √张力。[web_117] [web_119]

注意：膜的波速 √(T/σ) 不是材料常数，因此膜可在尺寸不变时靠调张力改变音高——这是膜与板/球的根本区别。[web_118]

3. 边界情形：指数为什么会变

L10 · Rayleigh 液滴（表面张力驱动）

f_n² = n(n−1)(n+2)·γ / (4π²·ρ·R³)   ⇒   f ∝ R^(−3/2)

[web_135]

→ 一个八度对应半径 ×2^(−2/3) ≈ 0.63，体积 ×1/4，不是 1/8。（本文换算）

L11 · Minnaert 气泡（气体压缩性驱动）

f_M ∝ (1/R₀) · √(P₀/ρ_L)   ⇒   f ∝ 1/R

水中空气泡近似 f₀ · R ≈ 3（SI 单位）：4 μm 气泡共振于 1 MHz；20 kHz 对应共振半径约 160 μm。[web_134] [web_136] [web_137]

同一气泡的平移模态却是 f ∝ R^(−3/2)，实测 R^(−1.34)；径向（体积）振荡 R⁻¹ 由气体压缩性决定，平移模态 R^(−3/2) 由表面张力与附加质量决定。[web_138]

L10 / L11 的意义：同一个球体，换一种恢复力，标度指数就从 −1 变成 −3/2。 "球成立"不是因为它是球，而是因为它是"体弹性驱动的相似体"。

6. 实验方案

第一条（硬约束，必须写进方案）

试件必须严格三维等比：直径（或边长）与厚度按同一因子缩放。 依据：Chladni 第三定律的前提是"相似固体"[web_107]；圆板定量式为 f ∝ t/r² [web_124]；实验已验证等厚变径时 f ∝ 1/L²（斜率 1.534 vs 理论 1.56）[web_141]。 若厚度不缩，会测到 −2 斜率并误判定律错误。

三组试件

组试件尺寸序列预期频率比验证对象
A 球组（主实验）同一批轴承钢球直径 40 / 20 / 10 mm（半径 1:2:4，体积 1:8:64）1 : 2 : 4L8 + Savart 铁球实验复现 [web_107]
B 盘组（严格等比）同批铝板或钢板200×5 / 100×2.5 / 50×1.25 mm1 : 2 : 4L3（Keely 那条）
C 盘组（等厚对照）同上材料厚度锁死 2 mm，直径 200 / 100 / 50 mm1 : 4 : 16L2（等厚变径分支）

C 组不是"对照组"那么简单——它验证的是 Chladni 第二定律，是另一条定律。 一次实验验三条。

测量方法

  • 悬挂软线 / 泡沫支撑（自由–自由边界），各尺寸支撑方式必须一致
  • 力锤或小球敲击；麦克风或压电片拾音 + FFT
  • 激励点不得落在待测模态的节点上，否则"怎么敲都敲不响"
  • 先算预期频率再扫频，别盲扫

绝对数值预估工具

薄板：

f = π/(2L²) · √(D/(ρh)) · (m² + n²),   D = E·h³/(12(1−ν²))

两个坑

  1. 边界条件：悬挂/夹持方式一变，形状因子就不再是常数，1/L 直接失效 [web_112]
  2. 材料批次：E、ρ、ν 必须一致，否则 √(E/ρ) 变化混入

判据

  • log–log 图斜率 = −1 → 支持 Keely / Chladni 第三定律
  • 斜率 = −2 → 说明你做的是等厚变径，落进第二定律分支
  • 球体组：半径 1:2 的两球基频比 = 2.000 即判决性结果

7. 附录：黄金比（φ）在现代工程中的「抗共振 / 非谐波」应用

本节为联网查证结果，用于回答"Keely 装置何时才需要黄金比"。

7.1 核心判定

Keely 用低整数比 = 最大化共振耦合；现代工程用 φ（无理数）= 最大限度避免整数比关系。两者是同一原理的两面。

Keely 规则原文：

「冒号两侧较低的两个数字决定了比率的一致性。例如，3:2 的纯五度比 135:128 的大半音更一致或和谐。数字越低，和谐和吸引力越大；数字越大，不和谐程度越大，并导致排斥作用。」[pdf_3]

现代工程的反向应用（日本 OTONOHA 声学扩散体）：

「若用整数比设计扩散体，效果会偏向特定频率，因此采用无理数比之一的黄金比来设定叶状立体的形状、放大率，成功获得自然的声音扩散。」[web_171]

7.2 力学抗共振：Fibonacci 区间阻尼螺旋桨叶片（专利）

  • 桨叶模态 1/2/3 的节点位置在 16.67%、25%、50%、75%、83.33% 波展处（无扭转直叶片）[web_183]
  • 斐波那契数列 1,1,2,3,5,8,13；相邻项之比收敛于 φ = 1.6180339887 [web_178]
  • 关键论述：

「这些区间之间持续的不规则性造成一种差异：它使这些区间与正弦声波在梁结构（树枝或螺旋桨叶片）中振动节点之间通常规则的区间本质上不同相（inherently out of phase）。本发明利用这一差异作为阻尼螺旋桨叶片共振的手段。」[web_178]

  • 做法：φ × Fibonacci(3,5,8,13) = refined Fibonacci series 3.236, 4.854, 8.09, 12.944，和 = 29.124
  • Fibonacci quotient = 波展 ÷ 29.124；10 英尺桨（波展 53.468 英寸）→ 1.835874 → 区间 5.94 / 8.91 / 14.85 / 23.76 英寸，自叶尖向内依次布置阶梯刚度变化，使其落在节点之间 [web_179] [web_180]
  • 需迭代收敛：改形状 → 节点位置变 → 重算 Fibonacci 区间，直至变化渐近 [web_179]

7.3 声学去周期性

(a) 黄金比准分形散射体（专利 US20080164094 / US7604094）

  • 散射体宽/高 = φ，高/鼻深 = φ [web_176]
  • 序列 A–N 中，每级放大 ×1.618，构成 quasi-fractal arrangement [web_174]
  • 有效频率下限由尺寸决定：λ ≈ 2H [web_174]

(b) 黄金角 137.5° + Vogel 螺旋排布

  • 用于扩散体单元在曲面上的排布，实现宽带扩散并规避周期性伪影 [web_172]

(c) 相控阵换能器（US 12,100,288）

  • 规则阵列 → 共线单元 + 均匀间距 → 构成离散傅里叶变换 → 产生"鬼影"（ghost images） [web_177]
  • 叶序螺旋由无理数支配的曲线布置单元，最小化共线性 [web_177]
  • 指数取 φ−1 = 0.618 时，单元更向边缘分布，噪声抑制更优 [web_177]

(d) 主流扩散体走的是另一条路：数论序列，不是 φ

Schroeder 二次余数扩散体（QRD，1975）：

d_n = (n² mod N) · λ / (2N),   N 必须为素数
  • N 为素数时序列在周期内最大程度不重复，保证各散射角频谱均匀 [web_164] [web_167]
  • 该序列的离散傅里叶变换幅值恒定 ⇒ 每个衍射级携带相等能量 [web_170] [web_164]
  • 高频上限由井宽决定 f_max = c/(2w)；低频下限由最深井决定 [web_166] [web_169]
  • 周期性 tiling 会产生 lobing（波瓣集中），需用优化序列规避 [web_167]

"去周期化"有两条技术路线：数论序列（QRD/MLS）与无理比（φ）。φ 不是唯一解。

7.4 波动准周期：Fibonacci 声子准晶

  • 一维 Fibonacci 准晶中，段长比遵循 φ = 1.618；「这个比值是无理数，确保结构永不精确重复，同时在不同尺度上保持自相似」[web_158]
