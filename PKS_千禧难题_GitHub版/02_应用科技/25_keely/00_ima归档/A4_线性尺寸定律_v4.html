0. 一句话总纲

所有"看起来不是 1/L"的标度律，本质都是某个无量纲形状比（如 h/L）在变。 只要把所有尺寸锁死成同一比例（几何相似）+ 材料相同 + 边界条件相同，频率标度就无条件回归 f ∝ 1/L。

1. 总律（上位定律）

L0 · 几何缩尺律（similitude）

「如果你做一个结构的缩尺复制品，所有尺寸按同一因子缩放，那么所有频率都按该因子的倒数缩放。例如把木琴条或小提琴缩小 6%，所有频率上升一个半音（假设用相同材料）。」[web_130]

量纲分析过程（以梁为例）：

  • 频率 ∝ √(弯曲刚度) / √(单位长度质量) / L²
  • 矩形截面时：与宽度无关、正比于厚度、反比于长度平方
  • 「任何使 厚度/长度² 之比降低 6% 的改动，音高就降半音」[web_130]

推论（本文推导）：f = (c/L) · F(无量纲形状比)。F 恒定时 f ∝ 1/L。

2. 分对象标度律清单

L1 · Chladni 第一定律（板 · 厚度）

同形状、同细分图形的两块板，振动数正比于厚度；厚度 ×2 → 高一个八度。[web_107]

L2 · Chladni 第二定律（板 · 等厚变径）

同厚度、直径比 1:2 的两块板，小者高两个八度；振动数反比于直径的平方。[web_107]

f = (h·π / (4√3 · d²)) · √(E / (ρ(1−ν²))) · (n + 2m)²

h = 厚度，d = 直径，m = 节径数，n = 节圆数。[web_144]

L3 · Chladni 第三定律（板 · 相似固体）★ 即 Keely 所引述者

「若厚度与其他尺寸成比例，即两板为相似固体，振动数反比于对应边。取厚和直径都是另一块两倍的板，大板发出的音比小板低一个八度。」[web_107]

「这最后一条定律对固体、液体和气体同样成立……Savart 证明：同材料同形状的棒，振动数反比于对应边。对同物质的球、立方体、圆柱或其他可比较尺寸的固体，该定律同样成立。」[web_107]

L4 · 历史实验证据（19 世纪 · 铁球）

「这里悬挂着两个铁球——一个直径 6 英寸，另一个 3 英寸。敲击以获得基音，我们发现大球比小球低一个八度。」[web_107]

6″ : 3″ = 半径 1:2 = 体积 1:8 = 一个八度。

知识库对应原文：

「线性尺寸定律可以这样表述：两个环境相似的同源体的振动周期彼此为它的立方体积，因此同源金属板的振动频率彼此为它们的线性尺寸的反比。给定板的八度音阶将是具有其体积的 1/8 的同源板。直径二十英寸、厚一英寸的圆盘振动例如每秒 1024 次。」[pdf_3]

「通过准确地确定……能够以（每秒 1024）的音调振荡的任何金属球体的体积音高，然后通过其本身的 1/8，我们得到周期频率中越来越高的连续八度音高。」[pdf_3]

实验条件（自由边界）：

「一个矩形的，或者最好是圆形的圆盘以这样一种方式悬挂在房间的天花板上，使得振动不能从房间的振动墙壁传递到它。」[pdf_3]

L5 · 圆板 / 圆盘（板极限）

f₀ ≈ (10.215 / 2π) · √(E_Y / (12·ρ·(1−ν²))) · t / r²

f ∝ 厚度 t / 半径² r²；前提：γr²/D → 0（张力可忽略、抗弯刚度主导）。[web_124]

经验 Chladni 圆板定律：

L7 · 细棒 / 细条

纵向：f_n = n·v/(2L)，v = √(Y/ρ) —— f ∝ 1/L，与厚度无关。[web_126] [web_128]

横向弯曲（自由-自由）：f = (π·ν·K/(8L²))·m²，扁条 K = 厚度/3.46 —— f ∝ h/L²；模态比 1 : 2.76 : 5.40 : 8.93，完全非谐。[web_126] [web_127]

L8 · 实心弹性球（Lamb 1882）★ 球体严格解

无量纲频率 s = ω·a·√(ρ/μ)（a = 半径）——s 不含尺寸 ⇒ ω ∝ (1/a)·√(μ/ρ)，即 f ∝ 1/a 严格成立。[web_153]

  • 半径 1 cm 钢球，二阶球谐基模约 136,000 次/秒
  • 「对于任何其他尺寸的钢球，这个结果必须除以以厘米为单位的半径」
  • 地球大小钢球，周期 1 小时 18 分 [web_91]

Lamb 理论同时适用于行星（~mHz）与纳米颗粒（~GHz）。[web_149] 纳米验证：Si 纳米晶受限声学声子「频率正比于声速、反比于颗粒尺寸」。[web_95]

L9 · 膜（张力驱动）

f_mn = (x_mn/(2πa))·√(T/σ)，x₀₁ = 2.405 —— f ∝ 1/a，∝ √张力。[web_117] [web_119] 膜的波速 √(T/σ) 不是材料常数，故可尺寸不变调音高改变。[web_118]

3. 边界情形：指数为什么会变

L10 · Rayleigh 液滴（表面张力驱动）

f_n² = n(n−1)(n+2)·γ/(4π²·ρ·R³) ⇒ f ∝ R^(−3/2) [web_135] → 一个八度对应半径 ×2^(−2/3) ≈ 0.63，体积 ×1/4，不是 1/8。（本文换算）

L11 · Minnaert 气泡（气体压缩性驱动）

f_M ∝ (1/R₀)·√(P₀/ρ_L) ⇒ f ∝ 1/R；水中空气泡 f₀·R ≈ 3（SI）：4 μm → 1 MHz；20 kHz → 约 160 μm [web_134] [web_136] [web_137] 同一气泡平移模态却是 f ∝ R^(−3/2)，实测 R^(−1.34) [web_138]

同一个球体，换一种恢复力，标度指数就从 −1 变成 −3/2。

6. 实验方案

第一条（硬约束）

试件必须严格三维等比：直径（或边长）与厚度按同一因子缩放。 依据：Chladni 第三定律前提是"相似固体"[web_107]；圆板 f ∝ t/r² [web_124]；等厚变径实测斜率 1.534 vs 理论 1.56 [web_141]。 若厚度不缩，会测到 −2 斜率并误判定律错误。

三组试件

组试件尺寸序列预期频率比验证对象
A 球组（主实验）同一批轴承钢球直径 40 / 20 / 10 mm1 : 2 : 4L8 + Savart 铁球实验复现 [web_107]
B 盘组（严格等比）同批铝板或钢板200×5 / 100×2.5 / 50×1.25 mm1 : 2 : 4L3（Keely 那条）
C 盘组（等厚对照）同上材料厚锁死 2 mm，直径 200/100/50 mm1 : 4 : 16L2（另一条定律）

测量方法

  • 悬挂软线 / 泡沫支撑（自由–自由），各尺寸支撑方式一致
  • 力锤或小球敲击；麦克风或压电片拾音 + FFT
  • 激励点不得落在待测模态节点上
  • 先算预期频率再扫频

预估工具：

f = π/(2L²) · √(D/(ρh)) · (m² + n²),   D = E·h³/(12(1−ν²))

判据

  • log–log 斜率 = −1 → 支持 Keely / Chladni 第三定律
  • 斜率 = −2 → 落进第二定律分支
  • 球体组：半径 1:2 两球基频比 = 2.000 即判决性结果

7. 黄金比（φ）在现代工程中的「抗共振 / 非谐波」应用

7.1 核心判定

Keely 用低整数比 = 最大化共振耦合；现代工程用 φ（无理数）= 最大限度避免整数比关系。同一原理的两面。

「冒号两侧较低的两个数字决定了比率的一致性。例如 3:2 的纯五度比 135:128 的大半音更和谐。数字越低，和谐和吸引力越大；数字越大，不和谐程度越大，并导致排斥作用。」[pdf_3]

「若用整数比设计扩散体，效果会偏向特定频率，因此采用无理数比之一的黄金比来设定叶状立体的形状、放大率，成功获得自然的声音扩散。」（OTONOHA 扩散体）[web_171]

7.2 力学抗共振：Fibonacci 区间阻尼螺旋桨叶片（专利）

  • 桨叶模态 1/2/3 节点位于 16.67%、25%、50%、75%、83.33% 波展处 web_183
  • Fibonacci 相邻项之比收敛于 φ = 1.6180339887 [web_178]

「这些区间之间持续的不规则性造成一种差异：它使这些区间与正弦声波在梁结构中振动节点之间通常规则的区间本质上不同相（inherently out of phase）。本发明利用这一差异作为阻尼螺旋桨叶片共振的手段。」[web_178]

9.5 ★ 核心矛盾：级间是 ×3，不是 ×2

Keely 实测频率链×31.585

×3 是"纯十二度"（八度 + 纯五度），不是纯八度。 故"在三个八度中敲击相同的和弦"与这条 ×3 频率链对不上——除非"三个八度"指音叉的相对把位，而实际能级按十二度堆叠。
