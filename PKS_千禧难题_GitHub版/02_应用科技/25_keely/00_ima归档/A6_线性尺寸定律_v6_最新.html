0. ★ 工作方法（最高优先级）

Keely（1837–1898）写作时，现代物理的术语和公式体系尚未成型。 他手里没有"声子""德拜温度""太赫兹""磁致伸缩""夸克""偏导数"这些词，只能用"原子间""以太""磁流""接近微波""三重秩序"去逼近同一个物理实在。

操作规则

凡遇到 Keely 含糊、矛盾或看似荒谬之处，正确动作不是二选一，也不是判他错，而是回现代物理里找那个被他绕着圈描述的量。

已建立的术语映射

Keely 的说法现代对应判定
「原子间（interatomic）」声子 / 晶格振动，1–40 THz✅ 他说的"接近微波带宽"方向对，实为 THz
「磁流（magnetic flow）」磁致伸缩驱动✅ 300–780 kHz 是驱动频段，非原子间频率
「原子摩尔（atomole）」夸克 / 亚原子粒子✅ Dale Pond 自己明说 [pdf_3]

「六个原子细分」1×2×3 = 3! = 三个模态的全部排列✅ 原文即此 [pdf_53]

1. 几何缩尺律（总律）

「如果你做一个结构的缩尺复制品，所有尺寸按同一因子缩放，那么所有频率都按该因子的倒数缩放。」[web_130]

f = (c/L) · F(无量纲形状比)。F 恒定时 f ∝ 1/L。

Chladni 三定律

律内容来源
第一同形状同图形，振动数 ∝ 厚度；厚 ×2 → 高一个八度[web_107]
第二等厚变径，振动数 ∝ 1/直径²；直径 1:2 → 两个八度[web_107]
第三相似固体（厚与径同比），振动数 ∝ 1/对应边 → 一个八度[web_107]

「这最后一条定律对固体、液体和气体同样成立……Savart 证明：同材料同形状的棒，振动数反比于对应边。对同物质的球、立方体、圆柱同样成立。」[web_107]

历史实验

「两个铁球——一个直径 6 英寸，另一个 3 英寸……大球比小球低一个八度。」[web_107]

6″:3″ = 半径 1:2 = 体积 1:8 = 一个八度。

Keely 原文

「两个环境相似的同源体的振动周期彼此为它的立方体积，因此同源金属板的振动频率彼此为它们的线性尺寸的反比。给定板的八度音阶将是具有其体积的 1/8 的同源板。直径二十英寸、厚一英寸的圆盘振动例如每秒 1024 次。」[pdf_3]

实心球严格解（Lamb 1882）

无量纲频率 s = ω·a·√(ρ/μ) 不含尺寸 ⇒ ω ∝ (1/a)·√(μ/ρ) [web_153]

  • 半径 1 cm 钢球二阶球谐基模约 136,000 次/秒
  • 「对于任何其他尺寸的钢球，这个结果必须除以以厘米为单位的半径」
  • 地球大小钢球周期 1 小时 18 分 [web_91]

4. ★ 第12律与第14律的统一（德拜公式）

「德拜温度 θ_D ∝ v·(ρ/M)^(1/3)，其中 v 是平均声速，M 是离子质量，ρ 是质量密度。」[web_228]

展开：θ_D ∝ v · ρ^(1/3) · M^(−1/3)

固定条件得到Keely 对应
固定 ρ、变 Mf ∝ M^(−1/3)第14律「原子重量立方反比」 ✅
固定 M、变 ρ（即变原子间距 a，ρ ∝ M/a³）f ∝ ρ^(1/3) ∝ 1/a第12律「线性尺寸反比」 ✅

「德拜温度与原子质量 M 的平方根成反比，T_D ∝ M^(−1/2)」[web_225]

结论：Keely 把德拜公式拆成了两条独立的"律"，因为他那个时代没有偏导数的表达方式。不是错误，是表达受限。

5.2 为什么系数必须是 3

「质数 2 以其任何力量都不会产生新的音符。质数 3 总是产生新的音符，因此它的力量被限制为第一个幂、平方和立方……」[pdf_87]

  • 3 才产生新的音程级 → 指数必须按 3 递增

7. ★ Trexar 几何定案

7.1 √n 规律（数学证明）

设三层外半径 r₁ : r₂ : r₃ = 1 : √2 : √3。

累积截面积（从轴心到各层外表面）：

层π·r²累积比
银（内圆）π·1 = π1
金（到第二边界）π·2 = 2π2
铂（到第三边界）π·3 = 3π3

每一环自己的面积：

环面积
银π·1² − 0 = π
金π·2 − π·1 = π
铂π·3 − π·2 = π

一般规律：若 r_n = √n · r₁，则

  • 累积面积 ∝ n（1:2:3:…:n）
  • 第 n 环单独面积 = πr₁²·[n−(n−1)] = 常数

等长圆柱 ⇒ 每环体积完全相等。

8. ★ 三元嵌套与夸克对应

8.1 Keely 原文就是"三个"

「原子具有与分子相同的旋转包层……旋转包层怀抱着原子间物质和静息于其中的三个原子（three atomoles）……三重秩序是绝对普适的（The threefold order is absolutely universal）。」[pdf_53]

「任何分子中的原子数不能多于或少于三个，它们在内部排成一个三角形……」[pdf_53]

嵌套三元：分子 = 3 原子，原子 = 3 atomole。

8.2 Dale Pond 自己点破 atomole = 夸克

「原子摩尔（atomole）类似于我们的夸克，因为电子中包含三个夸克，我们可以假设质子甚至中子中也包含三个夸克。」[pdf_3]

8.3 "6"的出处：1×2×3 = 3!

「没有任何力流能仅由一种振动模态构成，而必须总是由三个模态以不同的三分（thirds）结合而成，于是我们有 1 × 2 × 3 = 6 作为交感重合的全部可能形式……这些就是基利所说的六个原子细分秩序。」[pdf_53]

六个细分 = 三个模态的全部排列数 = 3!。

8.4 数值：几何级数末项落在核尺度

  • E = hf ⇒ ≈ 1.8 MeV（本文计算）

9. 黄金比（φ）的角色

9.1 核心判定

Keely 用低整数比 = 最大化共振耦合；现代工程用 φ（无理数）= 最大限度避免整数比。同一原理的两面。

「数字越低，和谐和吸引力越大；数字越大，不和谐程度越大，并导致排斥作用。」[pdf_3]

「若用整数比设计扩散体，效果会偏向特定频率，因此采用无理数比之一的黄金比来设定叶状立体的形状、放大率。」[web_171]
