Trexar GDR 核信号检验方案

判据体系 · 分级实验 · SOP · 统计方法

建立日期：2026-10-17 关联文档：《Keely线性尺寸定律-现代声学对照与实验方案.md》v6 第 8 节定位：证伪性检验——阴性结果同样是有效且更有价值的结论

0. ★ 实验定位（先读这段）

0.1 硬约束：机械振动到不了核

能量尺度数值
THz 声子（1 THz）4.14 meV
核第一激发态~1 MeV
GDR 共振（¹⁹⁷Au）13.7 MeV [web_299]

相差 8–9 个数量级。

GDR 是被 γ 光子激发的光核反应 (γ,n)，不是被机械振动直接激发 [web_291][web_293][web_295]。

0.2 因此本检验的正确定位

结果含义
测到核信号装置内发生了非机械的能量集中过程 → 异常，值得追查
测不到（理论预期）层级说到第六级（Interetheric）为止，第七级 Compound Interetheric 不成立

阴性结果是本实验最有价值的产出。 它把 Keely 层级说的适用边界钉死在"未达核尺度"。

1. 物理基础

1.1 GDR 是什么

「最重要的一个被称为巨偶极共振，通常描述为核内质子相对中子的受激集体振荡。这个激发态通常通过发射一个或多个光中子（photoneutron）退激。」[web_291]

「巨偶极共振（GDR）代表核内中子相对质子的集体振动运动。」[web_293]

1.4 中子产物的能谱

「巨共振中子是低能的（1–3 MeV），最大产生截面为 1–2 mb/核子。」[web_295]

「大部分 GDR 中子服从 Maxwellian 能量分布，即所谓蒸发谱：dN/dE = (E/T²)·exp(−E/T)，T（核温度）典型范围 0.4–1.4 MeV，T 是最概然能量，2T 是平均中子能量。」[web_291]

衰变通道：中重核以 (γ,n) 为主；重核因库仑势垒，质子发射被强烈压低 [web_293][web_295]。

2. ★ 判据体系

2.1 关键事实：天然本底的能量上限

天然 γ 本底最高只到 ²⁰⁸Tl 的 2614.5 keV。 超过约 2.62 MeV 基本无天然 γ 源（宇宙射线除外）[web_300][web_301][web_302][web_304]。

任一信号被承认，必须同时满足：

  1. 在差分谱（实验 − 对照）上超过 Currie 探测限 L_D
  2. 两次独立重复可复现

4. ★ 统计判据（必须写死）

Currie 探测限公式 [web_282]

L_D = 2.71 + 4.65·√B

MDA = L_D / (ε · y · t)
  • B = 本底计数
  • ε = 计数效率（必须用可溯源标准源实测，不能假设 [web_282]）
  • y = γ 产额（每次衰变发射的光子数）
  • t = 计数时间

算例：B = 100 counts（1 min），ε = 0.30，y = 0.85 → L_D = 2.71 + 4.65·√100 = 49.2 counts MDA = 49.2 / (0.30 × 0.85 × 60) ≈ 3.2 Bq [web_282]

「用效率和本底都更差的便携 GM 计做同样计算，MDA 会大几个数量级——这正是为什么擦拭检验用闪烁计数器而不是便携 GM 探头。」[web_282]

效率必须实测

ε = 净计数率(cps) / (A × y)

A = 源活度（Bq），y = 该光电峰的 γ 产额。效率必须针对每个核素、每种几何、每个能量窗分别建立 [web_282]。

6. SOP

步骤

  1. 本底：装置移走，NaI 测 24 h → 建立本底谱 + 四峰校正曲线
  2. 对照：装置就位、不通电，同几何测 24 h
  3. 实验：按 3:6:9 设定激励，测 24 h（或更长）
  4. 差分：实验谱 − 对照谱 → 检查 511 keV / 2.223 MeV / >2.62 MeV 三处
  5. 活化箔：全程置于装置旁 → 结束后立即计数 → 追踪衰减曲线 → 验证半衰期

9. 一句话总结

天然 γ 本底到 2614.5 keV 就断了。任何中子、任何 2.223 MeV 峰、任何 511 keV 增强，都是自然界不会平白给你的东西。 测到 = 有大事；测不到 = 把 Keely 层级说的边界钉死在核尺度之下。两者都是硬结论。
