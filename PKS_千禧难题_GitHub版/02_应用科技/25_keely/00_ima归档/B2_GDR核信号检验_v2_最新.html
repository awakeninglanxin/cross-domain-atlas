0. ★ 实验定位（先读这段）

0.1 硬约束：机械振动到不了核

能量尺度数值

核第一激发态~1 MeV
GDR 共振（¹⁹⁷Au）13.7 MeV

相差 8–9 个数量级。

GDR 是被 γ 光子激发的光核反应 (γ,n)，不是被机械振动直接激发。

「最重要的一个被称为巨偶极共振，通常描述为核内质子相对中子的受激集体振荡。这个激发态通常通过发射一个或多个光中子（photoneutron）退激。」

「巨偶极共振（GDR）代表核内中子相对质子的集体振动运动。」

0.2 因此本检验的正确定位

结果含义
测到核信号装置内发生了非机械的能量集中过程 → 异常，值得追查
测不到（理论预期）层级说到第六级（Interetheric）为止，第七级 Compound Interetheric 不成立

阴性结果是本实验最有价值的产出。 它把 Keely 层级说的适用边界钉死在"未达核尺度"。

2. ★ 判据体系

2.1 关键事实一：天然本底的能量上限

天然 γ 本底最高只到 ²⁰⁸Tl 的 2614.5 keV。 超过约 2.62 MeV 基本无天然 γ 源（宇宙射线除外）。

2.2 关键事实二：★ 金箔一物二用（v2 新增，解决了高能判据）

同一片金箔可同时给出两个独立的核信号：

¹⁹⁸Au¹⁹⁷Au(n,γ)9.88 b（另源 83.7 b 热 / 25.3 b 超热）2.69 天411.8 keV存在中子

「Gold nuclei interact with high-energy photons and neutrons. These interactions produce radioactive activation products.」

★ 这条救活了判据 5。 便携 NaI 无法直接测 13.7 MeV 的 GDR 峰（康普顿主导、效率低），但 Au 的 (γ,n) 阈值约 8 MeV，远低于 GDR 峰位——只要 GDR 区被触及，(γ,n) 必然发生，生成的 ¹⁹⁶Au 用 355.73 keV 峰就能测到。

而且两个半衰期相差 2.3 倍（2.69 d vs 6.16 d），可用双指数衰变拟合干净分离。

2.4 承认标准

任一信号被承认，必须同时满足：

  1. 在差分谱（实验 − 对照）上超过 Currie 探测限 L_D
  2. 两次独立重复可复现
  3. 对活化产物：实测半衰期与文献值（2.69 d / 6.16 d）在误差内吻合
  4. 已排除对应干扰项（见第 6 节）

4.2 厚度定案：50 μm（0.05 mm）

自吸收修正（本文计算）

「自吸收修正因子 Fg = μm·tm / (1 − e^(−μm·tm))，μm 为质量衰减系数，tm 为质量厚度，数据取自 NIST-XCOM。」「对 ¹⁹⁸Au 放出的 411.80 keV 特征γ射线在金片内的 μm 为 0.207 cm²·g⁻¹，对 ¹⁹⁶Au 的 355.73 keV 则是 0.228 cm²·g⁻¹。」

50 μm 金箔（ρ = 19.30 g/cm³）：

  • 质量厚度 tm = 19.30 × 0.005 = 0.0965 g/cm²
  • 411.8 keV：μm·tm = 0.207 × 0.0965 = 0.01998 → Fg = 1.0102（+1.0%）
  • 355.73 keV：μm·tm = 0.228 × 0.0965 = 0.02200 → Fg = 1.0110（+1.1%）

两峰自吸收均约 1%，可忽略但应做修正。

4.3 纯度与几何

  • 纯度 ≥99.998%（Alfa Aesar 级）。杂质（Ag、Cu）会活化出干扰峰，直接污染 411.8 keV 区。
  • 首选井型 NaI（效率 0.7659）；若无，金箔直接贴 NaI 端面中心并固定几何。
  • 计数窗口：411.8 keV 取 292–518 keV；同时开 355.7 keV 窗口监测 ¹⁹⁶Au。
  • 点面源修正：若用点源标准刻度，需做 Fd = Nd/Nm 修正（MCNP5 模拟点源 vs 面源）。

4.4 ★ 镉比法（Cd ratio）—— 强烈建议采用

原理：镉吸收 <0.4 eV 的热中子。

  • 裸箔 = 热中子 + 超热
  • 镉包箔 = 只有超热
  • 差值 = 纯热中子
公式说明
R_Cd = A_bare / A_Cd镉比
F_Cd = (R_Cd − 1)/R_Cd热中子份额因子
φ_th = exp(λt_d)·A_tot·F_Cd / (σ_th·G_th·N·(1−exp(−λt_i)))热中子通量
φ_epi = exp(λt_d)·A_Cd·I / (G_epi·N·(1−exp(−λt_i)))超热通量

参数：

  • 镉材料层厚度 1 mm
  • Cd 截止能量 ~0.4 eV；Au 的超热活化主要来自 0.4–2 eV 的大共振
  • G_th = 箔对热中子的自屏蔽因子；I = 超热积分截面

→ 能把"有中子"升级为"有热中子"，并把热中子与超热分开定量。这是中子判据的强证据版本。

4.7 活度计算

饱和活度：

A_sat = λC / [ε × (1 − e^(−λt)) × (e^(−λt₁) − e^(−λt₂))]

λ = 衰变常数，C = 411.8 keV γ 总计数，ε = 探测效率，t = 总照射时间，t₁/t₂ = 测量起止时刻。

¹⁹⁸Au 原子数（中国专利 CN118068394 口径）：

N198 = N412 / (C412 × Pγ × ε × t₁相关项)

N412 = 411.8 keV 净计数，C412 = 自吸收修正系数，Pγ = 0.9554，ε = 探测效率。

5. 统计判据（必须写死）

Currie 探测限公式

L_D = 2.71 + 4.65·√B
MDA = L_D / (ε · y · t)

B = 本底计数；ε = 计数效率；y = γ 产额；t = 计数时间。

算例：B = 100 counts（1 min），ε = 0.30，y = 0.85 → L_D = 2.71 + 4.65·√100 = 49.2 counts MDA = 49.2 / (0.30 × 0.85 × 60) ≈ 3.2 Bq

「用效率和本底都更差的便携 GM 计做同样计算，MDA 会大几个数量级——这正是为什么擦拭检验用闪烁计数器而不是便携 GM 探头。」

效率必须实测

ε = 净计数率(cps) / (A × y)

A = 源活度（Bq），y = 该光电峰的 γ 产额。每个核素、每种几何、每个能量窗各建一次，不能假设。

7. SOP

  1. 本底：装置移走，NaI 测 24 h → 建立本底谱 + 四峰校正曲线
  2. 对照：装置就位、不通电，同几何测 24 h
  3. 布置箔片：裸金箔 + 镉包金箔（间隔 ≥2 cm）+（可选）铟箔，固定于装置旁
  4. 实验：按 3:6:9 设定激励，测 24 h（或更长）
  5. 差分谱：实验 − 对照 → 检查 511 keV / 2.223 MeV / >2.62 MeV
  6. 箔片计数：取出后立即用井型 NaI 测 411.8 keV 与 355.73 keV
  7. 衰变追踪：连续测 ≥40 天，双指数拟合分离 2.69 d 与 6.16 d
  8. 镉比计算：R_Cd = A_bare / A_Cd → 得热中子通量
