★ 史料复原，逐字对照：
内环（Keely 原文，SVP 20.02）："a ring which has seven tubes or graduating resonators, the ring being 2/3 the diameter of the globe (or 8" ID), the resonators three inches long and 3/4 in. diameter, each one to be set on the chord of B flat" ⇒ 7 根，环半径 = 球半径 × 2/3，七根全部同调 B♭（不是七个不同的音）。
外环（Dale Pond 注）："The 24 resonators, tuned to musical thirds, placed in eight triplets around the Ring of Resonation are coincident to each of the three-sided corners of the cube" ⇒ 24 = 8 组 × 3 根，对应立方体的 8 个三面角。
⚠ 必须诚实的一点：SVP 原文没有任何角度数值 —— 7 根是否等分、8 组是否按 45° 等分， 两处都查不到。所以这里把角分布做成可选，默认等分只是"无依据时的最无偏假设"，不是史实。 想验证等分与非等分的差别，把"内环角分布"切到七声音阶即可：角间隔会从 51.43° 变成 60.9 / 61.5 / 27.0 / 61.2 / 60.9 / 61.2 / 27.3°。

外环 24 管在数值里是怎么进来的：它们不是装饰。每根管按 Helmholtz 共振器处理 （x″ + (ωH/Q)·x′ + ωH²·x = G·p管口）， 管口声压驱动它，它再把体积速度 x′ 反作用回该格点 —— 于是 24 根管组成一圈局部阻抗阵列：在 kaH 附近吸能，偏离时接近透明。 想验证它是否真的在起作用，把"外环 24 管"按钮关掉，就退回纯硬壁球腔，两张平均场图会明显不同 （本轮实测 cv2 均值 342.36 → 328.36）。

这页到此为止能说什么、不能说什么：能说的是「给定球径、源数 m、源半径、角分布与管阵参数， 线性声学在硬壁球腔里会长成什么花纹」；不能说的是「这些花纹就是 Keely 的振动形态」—— Keely 体系里的"交感"没有可用的本构方程，把它当声学处理只是一种可计算的工作假设。 所以图 1b 右图的对应关系我按 n（角向阶数） 建立，而不是按"声音听起来像"。

先划边界：本页算的是线性声学 —— 理想流体、小振幅、硬壁边界。 它算不出 Keely 记述里的"分子结构被激活到 42,800 次/秒""球体两分钟 1500 转"那类效应 （09 号页已把那些标为 C 级）。本页能回答的只有一件事： 给定球径、频率、源数与源位，声波在硬壁球腔里会长成什么花纹。

②模态表与选择定则：m 为什么会改变花纹

硬壁圆腔（Neumann 边界 ∂p/∂n = 0）的驻波解是 p ∝ Jn(k r)·cos(nθ)， 允许的 k 由 Jn′(ka) = 0 决定。下表列出低阶零点 （第 1 列是 ka，最后一列换算成默认 12 in 空气球里的实际频率）。

图 2 · 硬壁圆腔低阶模态表（ka 零点 → 12 in 空气球的实际频率）
淡橙行 = 与当前驱动 ka 相差 5% 以内的模态（会被明显激发）； 淡绿行 = 按 m 重对称选择定则 允许被 m 个均布同相源激发的模态（n 是 m 的整数倍）。

选择定则是这一页最值得记的一条：m 个等强度、同相的点源均布在圆周上， 它们的角向分布在傅里叶意义上只有 n = 0, m, 2m, 3m … 这些分量。 换句话说 ——

m 个均布源、相邻初相 Δ  ⇒  只能激发  n ≡ Δ ÷ (360°/m)  (mod m)  的模态
  Δ = 0°      ⇒ n ≡ 0 (mod m)：花纹带 m 重旋转对称（本页默认）
  Δ = 360°/m ⇒ n ≡ 1 (mod m)：最低阶变成 n = 1（2 瓣），花纹不再 m 重对称
  Δ 不是 360°/m 的整数倍 ⇒ 无严格禁戒，所有模态都漏一点进来（图样开始糊）

于是 m 一变，能"上场"的模态就换了一批：m = 1 什么都不限制（所以最乱）；m = 2 只能出 n = 2,4,6…（偶数瓣）； m = 3 只能出 n = 3,6,9…；m = 7 要等到 n = 7（ka ≈ 8.578）才出现七重花纹。 这就是"不同 m 值形成不同形状回音"的底层原因 —— 不是玄学，是源分布的角向对称性把一部分模态直接禁掉了。
把驱动从"同频同相"换成"异频音程"，对称性破了，禁戒解除，所有模态都能被碰到 ⇒ 图样开始漂移、不再锁形。
相位差 Δ 是同一件事的连续旋钮：Δ = 0 时花纹 m 重对称；把 Δ 推到 360°/m，能上场的模态从 n ≡ 0 挪到 n ≡ 1， 花纹整体掉到"2 瓣"上去；Δ 取非整数倍时连禁戒都没了。

这条定则在本页是真的"严格"成立，不是近似 —— 已定量验证：
做法：等稳态后开锁相放大（把 p 分别乘 cos ωt / sin ωt 积分，取出 ω = ka 的复振幅）， 再在精确极坐标环上做角向傅里叶变换，直接读出各 n 分量的幅度。
实测（本页 _check/verify_cav_modes.js）：
  • m = 5、ka = 6.4156（正好是 J5′ 首根）：只有 n = 5 出场； 被禁戒的 n = 4 只剩 5×10−16 —— 就是浮点机器零。
  • m = 7、Δ = 0：允许分量（n = 7, 14）与禁戒分量之比 ≈ 104。
  • m = 7、Δ = 360°/7：主导 n 由 7 搬到 1，"n ≡ 1 (mod 7) ÷ 其余" ≈ 103。
  • 反过来把驱动换成异频音程，谱立刻"胖"起来（n = 1…9 都冒头）⇒ 禁戒确实是被对称性禁掉的。
★ 顺带说明一件容易搞错的事：ka 命中某个 Jn′ 零点，并不保证你真能看见那个花纹。 还要看源所在半径处的径向因子 Jn(ka·rsrc) —— 源正好落在该模态的节圆上时，激励为零。 例如 m = 5、ka = 6.4156 时 J5(4.279) = 0.166，只有 J4(4.279) = 0.321 的一半 （虽然 n = 4 被禁戒，它在方形网格上确实会"诈尸"—— 见 ③ 解释）。 表格里的「源耦合」列和 #q7 预测卡就是干这个的。

想亲眼看到七重花纹，把 球内径拉到 30 in 左右（或把 f₀ 推到 2 kHz 以上）—— 屏幕上那个 ka 读数要爬到 8.6 附近，n = 7 才会被点亮。 也可以直接按 🔄 扫 ka 让它自己从 0.8 慢扫到 14，看花纹一阶一阶换形。

③方法与数值边界（可复算）

∂²p/∂t² = c²∇²p   （圆盘域 r ≤ a）
极坐标拉普拉斯：∇²p = ∂²p/∂r² + (1/r)·∂p/∂r + (1/r²)·∂²p/∂θ²
硬壁：∂p/∂r = 0（r = a） →  网格上用"域外邻居取内圈值"实现  →  一阶 Neumann
显式二层格式：pn+1 = 2pn − pn−1 + Δt²·[ ∇²p ]n（∇² 用上述极坐标 5 点格式）
稳定条件（2D CFL）：c·Δt/hmin ≤ 1/√2，hmin = min(Δr, Δθ)  →  本页取 0.90/√2（约 64% 余量）

为什么是极坐标而不是方形网格：方形网格上的圆形域只有【4 重】旋转对称 —— 台阶边界本身不圆，加上各向异性差分算子，会把禁戒模态大量耦合进来。 实测（改造前）：m = 5 时被选择定则禁戒的 n = 4 反超了允许的 n = 5； m = 7 时禁戒的 n = 1 / n = 3 / n = 5 全被叫醒 ⇒ 选择定则整个糊掉。 换成极坐标后：角向是均匀周期网格，边界是精确圆弧，格点数还更省。具体做法：

  • 径向避开原点：ri = (i + ½)·Δr（i = 0 … NR−1），r = 0 的坐标奇异就不出现了； 再用"i = 0 处 ∂p/∂r = 0"的镜像条件封闭（这恰好等价于轴心圆盘的有限体积通量格式）。
  • 角向格点数取 2m 的倍数：NT = 1.5·NR 向下取整到 2m 的倍数 ⇒ NT 既是 m 的倍数又是偶数；第 s 个源精确落在第 (NT·s/m + 偏移) 号角向格点上 ⇒ 整圈源的 m 重对称在离散层面严格成立（这是选择定则能干净复现的关键）。
  • 角向半径截断化解轴心刚性：角向弧长是 r·Δθ，越靠轴心越短，若严格按 min(r·Δθ) 取 Δt，Δt 会被 r₀ = Δr/2 处拖小两个量级。本页改令 1/r² 里的 r 取 reff = max(ri, rcap)、rcap = Δr/Δθ， 于是 a₃ = Δt²/(reff²Δθ²) ≤ Δt²/Δr² = CC，稳定裕度与 r 无关。 截断只影响 r < rcap ≈ 0.24 的轴心小盘（面积约 6%），那里 n ≥ 1 的模态振幅 ∝ (kr)n → 0，物理上几乎无感。
  • 别把 a₃ 写成 CC/(r²Δθ²)：那会凭空多出一个 1/Δr²（≈10⁴ 倍）， 角向刚度被放大到稳定域之外 ⇒ 全场爆成 NaN。极坐标移植最常踩的坑。

无量纲化：以腔半径 a 为长度单位、a/c 为时间单位，于是唯一的频率参数就是 ka = 2πfa/c。这样"换球径 / 换介质 / 换频率"三种操作在数学上是同一件事 —— 都是把 ka 挪一挪，所以你能用一只 12 in 球模拟任意大小球腔的模态结构。

模态零点的求法：硬壁条件是 Jn′(ka) = 0，所以模态 ka 就是 Jn′ 的正零点。 求导用递推恒等式 Jn′(x) = [ n·Jn(x) − x·Jn+1(x) ] / x （不用 ½[Jn−1 − Jn+1] —— 它在 n = 0 时要引入负阶 J−1， 级数在 (n + k + 1) = 0 处除零 ⇒ NaN）。 Jn(x) 用幂级数取 200 项（在 x ≤ 24、n ≤ 10 区间足够到机器精度）。 零点在 (0, 24] 上扫描符号变化、再二分 60 次到 ~1e−12。_check/ 下有 JS 版复算脚本， 实测 j0/j1/j2/j5 的前三根与 NIST DLMF / Abramowitz–Stegun 9.5 表完全吻合（容差 1e−5）。

"选择定则真的严格吗"是怎么验的：这不能靠眼看，得把图样翻译成谱。做法分两步 —— ① 锁相放大：稳态之后把 p 分别乘 cos ωt 与 sin ωt 再对时间积分， 得到频率 ω = ka 处的复振幅 A(r,θ) = ∫p·e−iωtdt。 （不能用"时间平均 |p|"或"包络 √(p²+p(t+T/4)²)" —— 多个 n 叠加时会留下 ni±nj 的交叉项，凭空造出禁戒的假谱峰。） ② 在精确极坐标环上做角向傅里叶变换 |∫A·e−inθdθ|/2π。 （不能在笛卡尔网格上等角度采样 —— 采样密度随 θ 变，也会造假峰。） 核验脚本：_check/verify_cav.js（55 项：网格几何 / 稳定性 / Bessel 零点对表 / ka 换算 / 反射 / 大球径摸到 n = 7 / 选择定则推广到 Δ）、 _check/verify_cav_modes.js（25 项：角向谱实测 + 禁戒压制量级 + 单脉冲回音）。 两套目前全绿。

本页算不出什么：① 真实金属壳的弹性壳振（那是结构声学，要耦合壳方程，本页壁是刚性的）； ② 非线性（大振幅、激波、空化）；③ 三维球腔的真实三维模态（本页是赤道截面，等价于二维圆形腔， 它给出的是三维球腔在赤道面上的截面行为，作为定性图样演示足够，但不能当球腔本征值表用）； ④ 任何"声致超导 / 声致核聚变"类推论。
