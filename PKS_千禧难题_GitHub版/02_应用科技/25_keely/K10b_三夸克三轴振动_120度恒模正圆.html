① 模型：三条正交环 + 一个相位差，只有 3 个参数

把三个夸克放在三条互相垂直的圆环上，同一个角频率、同一个半径，只在相位上错开。 坐标系取右手系，三个夸克分别绕 X / Y / Z 轴运行（即各自的轨道平面垂直于对应的轴）：

A(θ) = r·( 0, cos θ, sin θ ) // 在 yz 平面内 → 绕 X 轴
B(θ) = r·( sin(θ+φ), 0, cos(θ+φ) ) // 在 zx 平面内 → 绕 Y 轴
C(θ) = r·( cos(θ+2φ), sin(θ+2φ), 0 ) // 在 xy 平面内 → 绕 Z 轴
合成 = S(θ) = A + B + C　　自由参数只有三个：r、ω、φ

三颗都在半径为 r 的球面上，各自匀速圆周。φ 是三者的相位差（A→B→C 逐级递增 φ，一周共 3φ）。 下面这张图就是它的全部动力学——拖动可转视角，滚轮旁没有陷阱，所有读数都是当场现算的，页面里没有一个预先写死的结论数字。

② 命题一：永不重叠的唯一相位区，而且它同时给出最大间距

老师原话里最要紧的四个字是「空间错位不重叠」。这不是修辞，它在模型里是一个可判定的条件： 只要任意两颗的坐标在某一时刻相等，就是一次碰撞。下面把碰撞条件解出来。

PROOF 1碰撞相位集

设 α=θ、β=θ+φ、γ=θ+2φ。以 A 与 B 相撞为例，令 A(θ)=B(θ)：

( 0, r cos α, r sin α ) = ( r sin β, 0, r cos β )

逐分量比较，立刻得到三个必要条件：cos α = 0、sin β = 0、sin α = cos β。
由 sin β = 0 得 β ≡ 0 (mod π)；代入 cos β = ±1，再由 sin α = cos β 得 α ≡ ±π/2 (mod π)。 两式相减：φ = β − α ≡ ±90° (mod 180°)。

同法作用于 B=C 与 C=A，条件分别是 γ−β = φ ≡ ±90°、α−γ = −2φ ≡ ±90°，即 2φ ≡ 90° (mod 180°)。

合并：任一碰撞 ⟺ φ ≡ 45° (mod 90°)，即 φ ∈ {45°, 135°, 225°, 315°} 及其平移。 120° 不在这个集合里，所以 φ=120° 时三颗粒子在任何时刻都互不重合。∎

注：这是纯代数结论，不依赖 r 与 ω，也不依赖时间取值 —— 是"整体不发生"，不是"暂时不发生"。

更进一步：不只是"不相撞"，120° 还让三者尽可能互相远离。把一周期内两两间距的最小值 dmin(φ) 扫一遍 0°–360°，全局最大值恰好落在 120°，值为 (1+√3)/2 · r ≈ 1.3660 r；而另一个恒模相位 −120°(=240°) 落在相反的一端，dmin 只有 (√3−1)/2 · r ≈ 0.3660 r。

③ 命题二：只有 ±120° 能让合成矢端模长恒定，轨迹变正圆

元宝那份回答把合成包络说成「闭合的李萨如型曲线」。这句话不算错，但偏保守—— 李萨如曲线的模长一般是起伏的，而这里在 φ=120° 时模长一点起伏都没有，结果是正圆而不是椭圆。

PROOF 2恒模条件

先看一个更强的结构事实：把 S 按 cosθ 与 sinθ 拆开，记成两个常量向量 P、Q 的组合

S(θ) = P cosθ + Q sinθ　（P、Q 只依赖 φ）

由于 cosθ、sinθ 只张成一个二维平面，S(θ) 永远落在 span{P,Q} 里 —— 也就是说， 不管 φ 取什么值，合成轨迹恒为一条过原点的平面曲线（一般是椭圆，特殊时退化成直线或圆）。

再算 |S|²。用 A·B = sin α cos β 之类的点积，配合积化和差：

|S|²/r² = 3 + 2(A·B + B·C + C·A)
      = 3 + (1 + 2cos φ)·sin(2θ+2φ) + 2 sin φ (cos φ − 1)

最后一项与 θ 无关，是常数；与 θ 相关的只有系数 (1+2cos φ)。要让 |S| 不随 θ 变，唯一条件就是

1 + 2cos φ = 0　⟺　cos φ = −1/2　⟺　φ = ±120°

此时 |S|²/r² = 3 − 3√3/2 = (3/2)(2−√3) ≈ 0.4019，即 |S| = 0.6340 r，恒定。∎

同理，P·Q = 0 且 |P|=|Q| 也是 φ=±120° 才成立 —— 椭圆的长短轴相等，正是"变圆"的同一个条件。

而"圆"这件事还有一个意外附赠：这个圆所在的平面，法向正好是立方体体对角线 (1,1,1)/√3。 理由不用算，用对称性一句话就到：三条坐标轴绕体对角线互为 120° 轮换， 而三个相位也正好错开 120°，于是整个构型在"轴轮换 + 相位推进 120°"这个操作下不变—— 这个操作是绕 (1,1,1) 的三次旋转。轨迹若有固定的法向，它只能沿着旋转轴，所以法向被锁死在体对角线上。

为什么"恒模"值得专门说一句。S 是三者之和，可以看作"重心 ×3"。模长恒定意味着 这个重心沿一条正圆做匀速圆周运动：速率不变、离原点距离不变、没有呼吸式的胀缩。 一旦 φ 偏离 120°，重心就会在椭圆上忽远忽近地"喘"，同时三颗粒子的间距也跟着周期性逼近与拉开。 换句话说，120° 是让这套三轴机构唯一不发抖的配相。

还有一个量值得记下来：φ=120° 时合成圆半径 0.6340 r 小于环半径 r。 这不是算错——三颗在空间上彼此拉得很开（互成 120° 的三轴方向），矢量相加自然不会全长叠加。 反过来 φ=240° 时三颗挤在一条"浅螺旋"上，合成就长到 2.3660 r。 半径大小与"散得开"程度是这个模型里的同一枚硬币。

⑤ 从夸克跳到原子核外：八度用 ×2，124875 属 mod 9

模型之外那一层才是老师真正关心的联系：原子核外的分子振动按"八度谐振"组织，所以是 2 的幂。 这一步是干净的——简正模的泛音列正是整数倍频，×2 就是升一个八度。问题出在"取模"这一步。

×2 取模 9（数字根）→ 6 环 1·2·4·8·7·5

gcd(2,9)=1，×2 在九个点上可逆，是置换，因此裂成干净轨道。这就是常说的 124875。

×2 取模 12（十二平均律的点位）→ 塌成 {4,8} 与 {12}

gcd(2,12)=2≠1，×2 不可逆，每步都在压掉一个因子，所有点只能落进少数吸引子。 1→2→4→8→4→8…，三次之后就卡住。

×2 取模 13 → 走遍 12 个位置

2 是 mod 13 的原根，2¹²≡1，单环 12 步闭合： 1·2·4·8 → 3·6·12 → 11 → 9 → 5 → 10 → 7 → 1。想在 12 个等分点上跑出不塌缩的倍频环，这是唯一干净的走法。

下面这个轮盘可以单步走，亲眼看着三者在哪儿闭合、在哪儿卡死。点的颜色按数字根上色： 数字根属 {1,2,4,5,7,8} 涂蓝（物质侧）、属 {3,6} 涂橙（以太侧）、为 9 涂紫 —— 所以 12 在 mod 12 和 mod 13 两个轮上都是橙色。

⑥ 边界：这是几何模型，不是质子内部图像

必须把话说清楚，否则这张动图会误导人。

现代核物理里的质子不是这个样子的。
  • 质子是 uud 价夸克 + 胶子场 + 夸克–反夸克海 的相对论性束缚态，不是三个小球在轨道上跑。
  • 夸克没有可指认的确定轨道，只有波函数与概率分布；"绕轴旋转"在量子力学里没有对应物。
  • 夸克自旋对质子总自旋的贡献只有约 30%（EMC/COMPASS，ΔΣ≈0.3），其余来自胶子与轨道角动量—— 所以即便退一步做经典图像，"三个夸克在转"也解释不了质子自旋。
  • 夸克不能被单独分离（色禁闭），"三颗粒子"这个提法本身就只在束缚态内部有效。
但这不影响本页两个命题的有效性。 本页算的是一个明确定义的几何系统：三条正交圆环、等幅、同频、相位差 φ。 在这个系统里，"120° ⇒ 无碰撞"和"±120° ⇒ 恒模成圆"都是真的，可以逐项验算，不依赖任何物理诠释。 它成立的理由是对称性（绕体对角线的 C₃），而对称性论证从来不需要"它是什么"作为前提。
还要挡住一个诱惑：把"三个夸克"对应到"3·6·9"是数字命理学，不是物理。 3 是夸克数目、6 是夸克种类（u/d/c/s/t/b）、9 什么都不是——这三个数字之间没有任何模型会用到它们的结构关系。 同理，把"绕三轴"对应"三进制"也是文字游戏。能用的是 ×2 与八度那一条（频率的乘法），不是数字的象征义。
