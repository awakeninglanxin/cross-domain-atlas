混沌吸引子能不能画成磁力线

这个问题分两半，答案刚好相反：拿混沌吸引子直接当磁力线——不行，而且是被散度一票否决的硬不行；但把它的骨架换成无散的双曲零点——可以，而且「穿过中间那道壁、方向翻转」不是靠混沌，是靠零点。

下面先给否证（带数字），再给能跑的正解（带可拖的图）。结论是：你要看的那条"从 N 侧穿墙、出来已经反了方向、在 S 侧反着绕回去"的线，在数学上只有一种身份——穿过零点的分界线（separatrix）。
否定 · 混沌吸引子
∇·f ≠ 0，一票否决
Lorenz 的散度是常数 −13.6667：相体积每单位时间缩掉 e13.67 倍。磁力线必须 ∇·B = 0（磁通守恒、线永不相交合并）。这不是"调参数能修好"的偏差，是方程类型不同。
症状 · 线会停住
吸引子上的轨迹会收敛到不动点
吸引子的定义就是"附近轨道被吸过去"。轨迹一旦贴到不动点就永远停在那里。磁力线不能停——它没有源也没有汇，只能绕、只能穿。所以"穿过壁继续走"这件事，吸引子天生做不到。
正解 · 无散零点
穿墙的门只有零点一个
把场写成流函数 ψ 的形式，∇·B ≡ 0 自动成立。壁的两侧 B 反向 ⇒ 壁中必有一处 B = 0，那里就是唯一能"过去并翻转"的门。剩下的都是拓扑：分界线怎么绕过门。

一、否定：为什么混沌吸引子当不了磁力线

不是"效果不像"，是方程类型不同。看两条判据，都是一行字能算完的：

Lorenz：ẋ = σ(y−x), ẏ = x(ρ−z)−y, ż = xy − βz ∇·f = −σ − 1 − β = −10 − 1 − 8/3 = −13.6667（∝ 常数，处处相同） 磁力线：B 由 ∇·B = 0 约束 ⇒ 沿场线的通量管截面 × |B| 守恒 ⇒ 两条相邻场线永远不会靠拢合并（不相交）

第一条说：三维相体积在加速收缩；第二条说：磁通管截面积只能靠 |B| 变弱来变大，线本身不许合并。这两条不可能同时成立。所以你在 Lorenz 上看到的"两条轨道越来越像"这件事，在磁力线里是禁止的。

更直观的一条：吸引子会把轨迹吸到不动点上停住。这页的姊妹页（黄金极限蛋）自己就记着这个现象——28 颗种子里有个别颗沿 vr≈−ρ 指数塌到轴上 z≈−3.717 的不动点，此后每一步只走 1×10−7，再积分一万步也添不出一个新点。磁力线"停在墙上"是物理上不可能的：B = 0 的点不吸线，它只是让线的方向失去定义，线必须挑一个出射方向继续走。

所以"用混沌吸引子公式生成磁力线"这条路，只能做出长得像的图：线条缠绕、有涡、有折叠。但它画的不是场，是耗散系统的轨道。你要的"能量沿场线循环、穿墙翻转"，需要的是守恒结构，不是吸引子。

二、正解：把骨架换成「无散 + 零点 + 分界线」

二维情形有个一步到位的写法：只要把场写成流函数 ψ(x,z) 的旋度，散度自动为零，一辈子不用检查：

B = ∇×(ψ ŷ) = ( ∂ψ/∂z , 0 , −∂ψ/∂x ) ⇒ ∇·B = ∂²ψ/∂x∂z − ∂²ψ/∂x∂z ≡ 0 （恒等，不是近似） 场线 = ψ 的等值线（这是最关键的一句：ψ 的等高线就是磁力线）

于是"磁力线怎么走"变成了"ψ 的等高线怎么走"——纯几何问题。现在只需要让 ψ 具备三件事：

要素在 ψ 上是什么在图上看到什么
① 中间那道壁壁两侧 ∂ψ/∂z 反号（Bx 反向）上半区箭头朝右、下半区朝左
② 门ψ 的鞍点：∂ψ/∂x = ∂ψ/∂z = 0一个 X 形的交叉点，B = 0
③ 翻转的那条线过鞍点的那条等值线（分界线）一条线在两个 X 点之间围成一个眼，上半支与下半支绕行方向相反

我用的是磁流体里最标准的一张底图：Harris 电流片 + 撕裂模扰动（磁岛）。它的 ψ 和 B 都只有两行，可以手算核对：

为什么闭合场线就等于"能量循环"？沿场线的能量流是坡印廷矢量的平行分量 S∥ ∝ E×B·B̂。场线闭合 ⇒ 沿它走一圈回到起点 ⇒ 这一圈的净能量收支必须配平：从某段注入的，必然在另一段被抽走。它不是"耗散掉"，是"倒了个方向"。而分界线把这个闭合回路缝到另一个绕行方向相反的回路（上下两叶），能量就在两叶之间来回倒——这才叫循环。

反过来说，混沌吸引子上永远做不出这个循环：它的不变测度是耗散的，能量只能被单向抽走，轨迹最后落到不动点上。这也是为什么用吸引子画出来的"能量线"看着热闹，却永远不会回到起点。

3D 里多出来的这一层信息，平面图上永远看不到。平面图里"上下两半绕行方向相反"只能靠两个点分别跑给你看；立体里它是一条连续曲线在零线上换了个方向——翻转不是某处突然掉头，是同一条线在穿过零线时把切向甩了过去。而零线是一条缝，也解释了为什么"缝上任何一处都能翻"：缝上处处 |B| = 0，方向就处处没定义。

反过来问：为什么两极的螺旋一定一顺一逆

这是这张图最容易被跳过、也最该被追问的一步。上一版我只说了"相邻两个岛拧的方向是反的"，那只是 By 里 sin(kx/2) 换号的结果，属于沿壁方向的反；而 N 极和 S 极（沿 z 方向）为什么也反，我当时没交代。下面把这一条补上——它其实有三重独立的理由，任一条都足以把它钉死，三条同时成立才叫"必然"。

理由一：闭合条件（拓扑）。磁力线必须闭合、且不能相交。沿一条闭合线上绕一圈，绕轴的方位角 φ 必须回到 2π 的整数倍：

上半 +Δφ ／ 下半 −Δφ ⇒ 合计 0 ✓ 线能闭合 上半 +Δφ ／ 下半 +Δφ ⇒ 合计 2Δφ ✗ 闭不上，必然在壁上交叉 ⇒ 只要这组场线是「拧着的」，两端的手性就只能是反的。 「反旋」不是额外加了一个机制，是「闭合」这件事本身的代价。

换句话说：你要么不拧，要么两端一顺一逆。没有第三种可能。而实测的磁体明显是拧的（下一段给证据），所以反旋是唯一出路。

理由二：旋向是赝标量（场论），它只能在 B = 0 处换号。手性密度 h = B·(∇×B) 在镜像反射下变号（就像左右手互换），所以"旋向"这个量本身带手性。而 h 是坐标的光滑函数：要从 +h 变到 −h，中途必须经过 h = 0。恰好，整条零线上 B = 0 ⇒ 那里 h 恒等于 0。所以：

h = B·(∇×B) 赝标量，光滑 ⇒ 变号必过 h = 0 零线上处处 B = 0 ⇒ 零线上处处 h = 0 ⇒ 旋向的翻转点，被「B = 0 的集合」整条包住。 那条「门」不是通道，是旋向的接缝 —— 它必须在那里，也只能在那里。

这一条正好把前文的主题焊上了：零点不是磁力线的"隧道"，而是旋向无处定义、只能归零的一道缝。你以为在讲一个点，其实在讲一个界面的边。

理由三：几何形状本身——两个反向的双曲面在 Bloch 区对接。这不是我的比喻。用纳米磁性铁磁透镜（ferrolens）直接看磁体两极的磁通轨迹，实测结果是：N 极面上磁通逆时针（CCW），S 极面上顺时针（CW），两侧严格对称反向。Markoulakis 等人的 ferrolens 论文用两个双曲面把这个画了出来（原文图 13a）：两条反向对称的磁通轨迹各自贴在一个双曲面上滑行，一个对应 N 极、一个对应 S 极，而两个双曲面相接的那一圈，就是 Bloch 区。原文还配了图 13b，用红箭头标 N 极 CCW、蓝箭头标 S 极 CW，明写"counter geometrical rotation of the flux on the two different poles"。

把这三条摞在一起，画面就非常具体了：两个喇叭口朝外的双曲面，喉部在 Bloch 区对接；一个顺时针拧出去，另一个逆时针拧出去。图 2 就是照这个拓扑画的——你转动视角，会看到紫的那半和青的那半螺纹方向相反，而在 z = 0 的接缝处，两边的螺纹正好对上、旋向归零。这正是"两个反向旋转的双曲面在 Bloch 区对接"。

顺便校正一个流行说法。教科书默认的画法是"磁力线从 N 极出来、绕到外面回到 S 极"。而长期用 CRT / ferrocell 拍磁场的 ufopolitics 给的是另一种读法：磁流是从中心（即壁）向外同时流向两个极，不是从 N 穿到 S；每个极呈现为"双泡"结构，两极方向 180° 相反，而且这些力线是空间弯曲的三维曲线，不是直线（原话见 overunitymachines 论坛）。

需要说清的是：这是他的观测与建模主张，不是主流教科书结论。但把它和 ferrolens 论文的图 13a 并排看，两者对"两极反向双曲面 + Bloch 区对接"这件事是一致的——差别只在场的整体拓扑怎么闭合。图 2 采用的正是这个"从中心向两极分头拧出去"的画法，因为它能让"反旋"一眼可见；而它同样满足 ∇·B = 0，并且零线仍是那条缝。

无论采信哪一版拓扑，上面三重理由都不依赖它——闭合条件、赝标量、以及 ferrolens 的实测，三条各自独立成立。

最后补一句操作上的对照：点「同旋（错）」，By 就从奇函数变成偶函数，两极被硬拧成同向。这时读数卡里「dy/ds：上半 / 下半」会从 +0.50/−0.50 变成 +0.50 / +0.50——同号，反旋没了。那个版本不满足理由一：线要么闭不上，要么在壁上交叉；同时它在壁上要求 ∇·M ≠ 0，也就是壁上凭空出现磁荷、静磁能发散。所以它不是"另一种设计"，它是无解的那一支。

视觉上还有一个很好认的差别，可以拿来当判据：反旋时上下两半的扭转互相抵偿，整叠磁面收成一片薄的、自己闭起来的叶；一旦切成同旋，扭转就朝同一侧叠加，磁面被推到一边、鼓成一片 S 形的"蝴蝶"，怎么转视角都收不回一片叶。这也是为什么真实的磁体两极看起来是"两个抱在一起的气泡"，而不是一整条从 N 甩到 S 的弧。

三、为什么"门"只有一个：这是拓扑，不是参数

有人会想：既然壁两侧 B 反向，那场线直接穿过去不就行了？不行，理由只要一行连续性论证：

若 B 在壁上处处不为零、且壁上 B 有法向分量 Bn ≠ 0 ⇒ 那一小片壁上的磁通 tube 是穿透的，两侧方向连续 ⇒ 但两侧方向相反 ⇒ 矛盾 ⇒ 要么壁内某处 B = 0（零点，磁重联的位置） ⇒ 要么壁上处处 Bn = 0（场线平行于壁，永远穿不过去）

换句话说：「穿墙并翻转」和「B 在壁上不为零」不能同时成立。所以你要的那条线必然经过零点。在我这张图上，零点就是 X 点：B 在那里精确为 0，四条分支以 ±42.91° 张开，进来的方向和出去的方向不是同一个方向——这就是"翻转"的数学本体。

顺便说清一个容易混的点：磁力线不会"停"在壁上。壁内 B 可以很小，但除了零点外不为零，所以线照样穿过去；只有零点处方向未定义，线在那里换支。这跟吸引子"被吸住就停"是相反的两件事。

四、如果一定要搬到那个蛋上：最小改动

黄金极限蛋现在的极向分量是这样一个结构（页面里的原文）：

out = [ vr·x/ρ − w·y , vr·y/ρ + w·x , vz ] 其中 vz ≈ 2z + J·e−z²/RJ²·sign(z) ⇒ z>0 全正、z<0 全负、轴上无驻点

这就是它出不了 8 字的真正原因：vz 在 z 上不换号，轴上没有驻点，场线到不了"中间那道壁"，更谈不上穿过。要改成正确的能量循环，不是加个混沌项，而是把 (vr, vz) 从"直接写分量"改成"由 ψ 求导"：

[1] 选 ψ(ρ,z) = δ·ln cosh(z/δ) + (ε/k)·cos(k·ρ) ← 把上式的 x 换成 ρ [2] 令 vρ = −(1/ρ)·∂ψ/∂z , vz = (1/ρ)·∂ψ/∂ρ （柱坐标的无散写法） [3] 保留原来的环向项 w = Ω₀/(ρ+RC)^1.5 ，叠加成 B = vρ·ρ̂ + w·φ̂ + vz·ẑ 这样 ∇·B = 0 自动成立（改用 ψ 求导后不必再检查）， 且 ∂ψ/∂ρ = 0 的位置给出零点环 ρ = π/k，那就是新的「壁中心」。

代价要说清楚：蛋的外形会变。ψ 一旦决定，外形就被 ψ 的等值线定死了，不能再随便"呼吸"。想两者都要，只能让 ψ 乘一个随时间变化的共形因子（整体缩放），而不能改 ψ 的拓扑——这是硬约束。

五、三条路的对照

做法∇·B能不能穿壁翻转能不能"循环"本质

ψ 等值线 + 电流片磁岛（本页）0（恒等）能，且零点位置可解析给出能，闭合场线真闭合MHD 平衡场（可验算）

中间那条路值得单独提一句：ABC 流（u = A sin z + C cos y, …, 1930s 的 Beltrami 流，后来成了等离子体物理里研究「磁力线混沌」的标准模型）是真正的无散混沌流——散度逐项为零（ux 不含 x、uy 不含 y、uz 不含 z），本机 2000 点随机抽样最大偏离 0.00e+0。它在数学上有资格当磁力线的替身，而且确实有孤立驻点。

但它的问题是零点不可控：驻点位置由三个系数 (A,B,C) 隐式决定，你没法直接指定"壁在 z=0、门在原点"。真要用，还得在外面套一层坐标变换把驻点搬到想要的位置——工程量比直接用 ψ 大得多。结论：混沌不是目的，零点位置才是。

一句话回答你：混沌吸引子给你的是"缠绕感"，不是"场的结构"。要"穿墙、翻转、反向绕行"，缺的三样东西是——∇·B=0（保证线不合并、不停止）、一个零点（唯一的门）、过零点的分界线（那条能量线本身）。这三样都在 ψ 里，一行都不用改方程类型。

六、动手核对

下面这些数都能在浏览器控制台里三行复现（δ=1, ε=0.55, k=π/2）：

A(x,z) = Math.log(Math.cosh(z)) + (0.55/(Math.PI/2))*Math.cos((Math.PI/2)*x) Bx(x,z) = Math.tanh(z) Bz(x,z) = 0.55*Math.sin((Math.PI/2)*x) A(0,0) → 0.350141 ← 分界线的值（X 点就在这） A(Math.PI/(Math.PI/2),0) → −0.350141 ← O 点（磁岛中心） Math.sqrt(0.55*(Math.PI/2)) → 0.9295 ← X 点分支斜率，≡ tan(42.91°)

把 ε 拖小，磁岛会缩成一个小眼，零点靠得更近；拖大，眼会撑开到近乎占满整个周期。不管怎么拖，穿墙的仍然只有那一条。
