Trexar 几何定案：走 C（同心），√n 等体积

2026-10-17 定案：采用 C 方案 —— 芯银 / 中铂 / 外金的同心复合线，三环等体积，半径比 1 : √2 : √3。
√n 这条规律在数学上不只是成立，而是必然 —— 只要 rn = √n·r₁，累积面积自动 1:2:3、每环面积自动相等。 原文两段话分别支持 A（轴向分段）与 C（同心），资料本身没定；是本项目按「1:2:3 能被几何严格兑现」选了 C， 并把 A / B 保留在本页作对照，方便随时回头复核这个选择。

▲ 2026-10-19 更正：三层顺序为「芯银 → 中铂 → 外金」，金在最外层。 此前本页把中、外两层写反（记为「中金 / 外铂」），与 10 页图纸复原（外金 0.866 / 中铂 0.693）相矛盾，现已全页对调； 几何、√n 证明、2ln2 废弃结论全部不受影响（它们只跟半径次序有关，与金属名无关），受影响的只有材料属性标注与电学/声学推论。

①三方案对照：为什么最后选 C

定案（2026-10-17，老师拍板）：走 C · 同心。
芯 银 / 中 铂 / 外 金，三层等长、等体积，外半径比 1 : √2 : √3（= 0.5 : 0.7071 : 0.8660 归一）。 三环截面积各占 1/3 ⇒ 累积面积比精确 1 : 2 : 3。
定案的实际含义：从此试件只有一种图纸；A / B 降级为"对照与退路"，留档备查，不再作为待选项。
「Trexar 是由以下部分组成的线：第一段银、第二段金和第三段铂，尺寸均一致。」 — Keely 原文，另有 "a sectional wire of platinum and silver" [pdf_3][pdf_55]

「第一段 / 第二段 / 第三段」+「sectional wire」⇒ 读起来是轴向串联、等长等径。 但另一处又说：

「新型超导线材和材料是由按 Keely 的 1:2:3 比例组合的元素制成的。」 — 元素配比口径 [pdf_3]
A轴向分段 · 未采用

三段等长等径串联。1:2:3 指段长或元素量。
好做：三段线焊接 / 压接。
依据：「尺寸均一致」「sectional wire」。
另一个代价：串联 ⇒ 电阻 3.07 倍纯银，比 C 的 1.80 倍高 70%（见 §6.4）。

B元素配比 · 未采用

三种金属合金化，1:2:3 是三种金属的量比。
难做：需要熔炼配比控制。
依据：「按 1:2:3 比例组合的元素」。
真正的致命点：合金化后没有三层界面，"三段料"的物理图像整体消失。

C同心 · ✅ 已定案

芯银 / 中铂 / 外金，r ∝ √n。
1:2:3 指累积截面积，且各环等体积。
难做：需包覆拉丝工艺。
依据：本项目推导 + √n 证明；1:2:3 只有它能被几何严格兑现。

定案之后必须诚实标注的一件事：C 是本项目的设计推演，不是 Keely 原文。
原文两段话各支持一边 —— 「尺寸均一致 / sectional wire」偏向 A，「按 1:2:3 比例组合的元素」偏向 C。 资料本身没有给出裁决，本页选 C 的依据是：只有 C 能让「1:2:3」变成一条可测量、可复算的几何约束 （累积面积 1:2:3 且三环等体积）；A 里的 1:2:3 只能指"段长"，与「尺寸均一致」自相矛盾。
所以：C 成立 ⇒ 拿到一条可证伪的试件；C 不成立 ⇒ 退路是 A，图纸另存（见 §⑥）。

②√n 规律：为什么它是必然而不是巧合

设三层外半径为 r₁ : r₂ : r₃。若取 rn = √n · r₁，则两件事同时成立：

层外半径累积截面积 πr²累积比该环单独面积
银（内圆）1·r₁π r₁²1π r₁²（= 1 份）
铂（中环）√2·r₁2π r₁²22π−π = π r₁²（= 1 份）
金（外环）√3·r₁3π r₁²33π−2π = π r₁²（= 1 份）
一般规律：若 rn = √n · r₁，则
① 累积面积 ∝ n　（1 : 2 : 3 : … : n）
② 第 n 环单独面积 = πr₁²·[n − (n−1)] = 常数
⇒ 等长圆柱时，每环体积完全相等
一条规律干掉两个矛盾：「累积 1:2:3」与「各环等体积」被证明是同一个几何的两个侧面， 不是两个互斥的方案。
推广：任意 n 层（七细分、Trexnonar 九节点）只要 rn ∝ √n，就自动每层等体积、累积 1:2:…:n。

★ 顺带一个反证：1:2:3 原本就不是几何比
若按 √n 做（三环等体积），三层质量比就是密度比：
10.49 : 21.45 : 19.30 = 1 : 2.045 : 1.840（按层序：银 : 铂 : 金）
对照 Keely 的 33⅓ : 66⅔ : 100 = 1 : 2 : 3：铂差 32%，金差 8%。
⇒ 「等体积」和「1:2:3」在质量口径下是两件事。这反过来说明 1:2:3 更可能是元素配比或累积面积口径， 而不是"三环物理体积比"。

6.3 公差：到底要卡到多紧（算给你看，别凭感觉）

铂环面积 A = π(r₂² − r₁²)。若两个界面的圆心跳动为 e₂、e₁，最坏（反向）叠加时 一阶面积偏差 ≈ 2π(r₂e₂ + r₁e₁)，归一后：

ΔA / A ≈ 2(r₂e₂ + r₁e₁) / (r₂² − r₁²)　→　取 e₁=e₂=e 时　≈ 4.83 · e/r₁
同心度误差 e / r₁铂环面积偏差判定
1.0 %≈ 4.8 %包覆拉拔的常规水平，可接受
0.5 %≈ 2.4 %优于常规，需要挑料
0.2 %≈ 1.0 %接近工艺极限，成本跳一档
这里的正确结论不是"必须做到 1%" —— 而是：C 的目标是「等体积到 ±5% 量级」。
理由有两条，都成立：① 只要 ±5%，就已经与 A / B 的结构级差异（100% 量级）完全不在一个层级； ② Keely 的「三分之一和谐调整」没有任何 1% 精度的原文依据，硬卡 1% 是自我加戏。
工艺上真正要紧的一点：拉拔过程本身按比例缩小壁厚，所以相对偏差在拉细中守恒 —— 装配阶段（大直径、公差宽松）做对，拉成细线后仍然对。这就是为什么①号路线优于②电镀。

▲ 2026-10-19 数值校核（本轮顺手改错）：上一版这里写的是 2.648×10⁻⁸ / 1.67× / 55.5 : 36.2 : 8.3。 复算发现那三个数把铂的 106 nΩ·m 当成了 10.6 nΩ·m （1/1.59 : 1/2.44 : 1/10.6 = 55.5 : 36.2 : 8.3 正好对上）。 用正确的 106 重算：R·S/L = 3/(0.6289+0.4098+0.00943) = 2.862×10⁻⁸ ⇒ 1.80× 纯银， 分流 60.0 / 39.1 / 0.9。A 方案（串联）不受影响，仍是 3.07×。因此 A/C 的差距是 1.70 倍（70%），不是 1.84 倍。
这条改动直接决定 §6.5 的验收判据，所以必须改 —— 判据写 2.65 而实测会落在 2.86，会被误判成"没做成 C"。
这里要克制：A 与 C 的电阻只差 1.70 倍，不是"差一个数量级"。
因为 A 是三段串联，每段只有 L/3 长；铂段虽然 ρ 高 6.7 倍，但只占三分之一的长度， 摊到整根线上只有 (1.59+2.44+106)/3 = 36.7 nΩ·m，折合 3.07 倍纯银。
所以「选 C 不是为了省电」—— 选 C 是因为只有 C 能把 1:2:3 变成一条可测量的几何约束。 电阻差在这里只是验收时可以一刀切开两者的指纹（70% 的差距，四探针足够分出）。

· 64 kHz 以下：三层都远薄于各自的 δ ⇒ 电流按面积均匀分布，§6.4 的并联结论（1.80×、60.0/39.1/0.9）严格成立。 这是"准直流区"，也是这套尺寸真正该用的频段。
· 64 kHz 起：银芯先开始趋肤（中心出现死区），银的有效截面略缩。
· 983 kHz 起：金外环先成壳 —— 不是因为它阻抗高，而是因为它最薄（0.0794 mm）。 但金的 ρ 只有银的 1.54 倍，成壳对总电阻的影响温和，这一档不致命。
· 2.50 MHz 以上：铂层（0.1036 mm）也厚于 δ，电流被限制在铂壳里 ⇒ 交流电阻趋向纯铂（ρ 是银的 6.7 倍）， C 的"银芯"在电学上等于不存在。
⚠ 口径声明：这三个频率是逐层独立估计（把每层当成孤立导体看 δ 与壁厚的比）， 用来判"哪个频段还行"是够的；要精确的交流电阻曲线，得做多层同心圆柱的 Bessel 联解 —— 本页没做，也不假装做了。 另：2.50 MHz 只由 ρPt 与铂层壁厚决定，改外径就要重算（壁厚同比例变，f 变 (D₃/0.866)²）。

⑦选材的声学论证：为什么是这三种金属，以及为什么金必须在最外

这一节来自老师 2026-10-19 的一篇笔记《Trexar 选材的声学论证》（ima 笔记，原文归档于 00_ima归档/C1_Trexar选材声学论证_2026-10-19.md）。 它把「银 / 铂 / 金」从"三种贵金属"变成三个各有不可替代角色的声学元件。
⚠ 两个前提必须先说清：① 本节按更正后的层序（芯银 → 中铂 → 外金）重排了笔记里"金中 / 铂外"的表述， 笔记原文的顺序与图纸相反；② 笔记用的是超声换能器的正入射模型，而 Trexar 的主传播方向沿轴、界面平行于波前 —— 两者适用的场合不同，7.4 节专门交代这个边界。

7.1 三种金属的声学数据（多源，次序一致）

声阻抗 Z = ρ·c（密度 × 纵波声速），取 KARL DEUTSCH 口径：

层金属密度 g/cm³纵波声速 m/s声阻抗 Z（MRayl）角色
芯银 Ag10.4–10.5360037.4传输：内摩擦最低、Q 最高
中铂 Pt21.4326069.8钳制：阻抗峰 + 加 Pt 降衰减
外金 Au19.3324062.6封套：与铂同速、化学最惰、最延展

另一套资料（ULTRASONIC REFERENCE，退火态）给 Pt 84.7 / Au 63.8 / Ag 38.0，次序不变、数值更高； 差异来自热处理状态与声速取法（Pt 取 3960 而非 3260）。本页统一用上表一套，保证每个数可互相复算。

「银、金和铂因其晶体金属结构而具有特征声学性质：轻敲后以高而持久的频率振动…… 贵金属在固体中声速高且内阻尼低，结果是明亮悠长的余音。」 — 笔记引 [web_352][web_353]
「低内阻尼是最重要的因素。银的内摩擦极低，振动每个周期损失的能量极少，所以余音很长。 技术指标是品质因数 Q——银币的 Q 值可达数百；铅只有 5–15。」 — 笔记引 [web_354]

所以"声超导"的严格物理对应不是电阻为零，而是 高 Q、低内摩擦、无内部界面散射。 Keely 挑的不是"贵金属"，是声学高 Q 金属，恰好它们都贵。 这一条把"SVP 说它是 superconducting wire"翻译成了一个可测量的量：Q 值。

7.2 更正顺序之后：径向阻抗阶梯是「内高外低」的峰，不是单调爬升

这是本次更正真正改变结论的地方。原来的写法（金中 / 铂外）是一条单调爬升的阶梯 37 → 63 → 70，正好照抄超声换能器的"多层阻抗渐变匹配层"。 改成铂中 / 金外以后，阶梯变成：

Ag 37.4 → Pt 69.8（峰）→ Au 62.6（回落）→ 环境

也就是说，阻抗峰被关在中间，最外层反而比中间低 10%。这在声学上不是"渐变匹配"， 而是「内钳制 + 外回落」：铂层像一道闸把能量堵在银芯里，金层再把这道闸"软化"一点、 接到环境上。两种结构都真实存在于超声工程里，但用途不同 —— 单调渐变是为了把能量送出去（发射换能器匹配层），中间加峰是为了把能量关住（解匹配层 / 背衬）。 Keely 要的是"交感流在芯内不中断"，后者更贴。这是本项目推论，判 C+。

7.3 界面反射率（可复算）

正入射能量反射 R = [(Z₂−Z₁)/(Z₂+Z₁)]²：

界面Z₁ → Z₂R透射 1−R读法
Ag | Pt37.4 → 69.89.1 %90.9 %唯一"有分量"的界面，能量在此被钳一下
Pt | Au69.8 → 62.60.30 %99.70 %近乎声学透明 —— 两层声速只差 0.6%
Ag | Au37.4 → 62.66.4 %93.6 %（对照：没有铂层时的跳变）

把铂夹在中间，等于把一个 6.4% 的跳变拆成 9.1% + 0.30% 两次。 合起来看总反射并没有变小（9.4% vs 6.4%，反而略大），所以不能说"这样更透"； 它真正的好处是把反射位置挪到了内界面：能量在 Ag|Pt 被挡一下、留在芯里， 而 Pt|Au 几乎不反射 —— 外表面不会把能量甩回环境。 这正是"解匹配层"的用法：故意在内侧造一个高阻抗界面，把能量往芯部推。

「解匹配层具有高于压电元件的声阻抗，以增加发送出去的超声波功率…… 以在声学上'钳'住压电元件，使大部分声能被发送出压电元件的前面。」 — 笔记引 [web_345]（超声换能器结构：匹配层—晶体—解匹配层—透镜）

7.4 边界的诚实交代：这套反射率什么时候能用

正入射模型的前提是「波垂直穿过界面」。Trexar 的主传播沿轴，界面平行于波前 —— 此时 R 公式不适用。
两套模型各管一段，别混用：
① 径向分量 / 端面耦合（芯部呼吸、把线端贴到换能器上、声波斜入射到柱面）→ 用本节的 Z 与 R， 结论是"Ag|Pt 钳制、Pt|Au 透明"。
② 轴向主传播（Keely 的 sympathetic flow 沿线的方向）→ 用 10 页 §5.4 的并联（Voigt）模型： 三层等应变、力相加，得到等效声速与等效声阻抗，界面不产生法向反射。
两份结论并不冲突：一份讲"横向怎么漏"，一份讲"纵向怎么传"。谁也不能替代谁。

7.6 一个顺手推翻的旧说法

「Au/Pt 阻抗差最小所以放外面做匹配」—— 这条不成立。 Au/Pt 的 Z 差 7.2 MRayl（相对差 10.3%），而 Ag/Au 差 25.2 MRayl（40.3%）， 所以 Au/Pt 界面确实最"透明"；但界面透明是界面的性质，不是层序的性质 —— 把铂放外面、金放中间，Pt|Au 这道界面一样透明（它就在那儿）。 真正只能靠层序解释的，是阻抗峰在不在中间（见 7.2）和谁去接触环境（见 7.5）。 写这段是为了防止"用一条对称的理由去证明一个不对称的结论"。

7.8 可选项 H：空心 + 充气 + 外覆膜 —— 通向「热超导棒」的一条候选路径

老师给出的定义很关键：里面做成空心，但三环的体积比保持 1:1:1 不变；空心管外径可调。 这句话把问题从"挖掉芯部"变成了"三层同步向外让位"，几何上一个字都不用改设计准则：

给定空心管外径 D₀（内腔半径 r₀ = D₀/2），外径 R₃ 不变，令每环面积相等：
A = (R₃² − r₀²) / 3　　⇒　　r₁ = √(r₀² + A)　　r₂ = √(r₀² + 2A)

③ 要跨到"热超导"量级（λ_eff ≫ 金属），只有两条路：
　(a) 腔内装相变工质（水/乙醇/氨/丙酮 + 抽真空 + 毛细或沟槽），即真正的热管 —— 这时"充气"要改成"抽真空后充液"；
　(b) 外覆膜换成高导热碳（CVD 金刚石 ~2000、石墨烯面内 ~3000–5000 W/m·K）并做够厚， 让它承担主要热流 —— 此时"膜"不是封装，而是主导热通道。
所以这个可选项值不值得做，取决于填的是气体还是工质、膜是封装还是导热层。 在这两个问题定下来之前，它只是一个结构想法，不是一条已验证的升级路径。证据等级：D（待验证假设）。

但"空心但仍等体积"这个改动，在声学上有一处真实收益，值得单独记一笔： 内腔把实心银芯换成了一个低声阻抗软层（Z 约 400 Rayl vs 银 37.4 MRayl，差 5 个数量级）， 它会把轴向驻波的节点位置整体拉动 —— 这正是 09b 页球腔声场在做的事。 换句话说，充气对热学是负分，对声学是新的调节旋钮，而且这个旋钮的外径 D₀ 是连续可调的。 试验台切到空心模式，右图会看到那一段几乎贴着对数轴底部的"气体台阶" —— 它就是这根线里唯一的一段声学软层。
