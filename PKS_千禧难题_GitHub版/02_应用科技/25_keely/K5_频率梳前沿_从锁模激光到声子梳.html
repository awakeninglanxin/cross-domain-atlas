K5 · Frequency Comb

频率梳：从锁模激光到声子梳，
Keely 的「三个八度」落在哪一格

Keely 的外环是「三个八度 + 每隔第三销钉调 B♭」——一句话里同时有齿列和周期性， 这与 2005 年拿诺贝尔奖的光学频率梳、与 2023 年的磁振子频率梳、与 2024 年的 MEMS 声子梳， 在几何形象上高度相似。本页做三件事：把「梳」这个词钉死在三类齿列上； 把现代四条路线的真实齿距与齿数排出来；然后逐条判定 Keely 的装置究竟落在哪一格 —— 结论是他有齿列，没有齿距，更没有锁相。缺的那一样，恰好是 130 年后才有的技术。

文献：Phys. Rev. Lett. 131, 243601 (2023) · J. Microelectromech. Syst. 33(3) 384–394 (2024) · Photonics Insights 3(4) R09 (2024) · preprint DOI 10.21203/rs.3.rs-4168088/v1

①先把「梳」这个词钉死：三种齿列，只有两类配叫梳

「频率梳」（frequency comb）这个名字来自图形：频谱上立着一排间距均匀的竖线，像梳齿。 但「一排竖线」不是定义，齿距恒定才是。世纪之交以来这个术语被泛化得太厉害， 以致于任何多峰谱都有人叫它"梳"。本页用三条判据把它收窄：

C1 齿距恒定：相邻齿的频率差 Δfk = fk+1 − fk 与 k 无关
C2 相位相干：齿与齿之间保持固定相位关系（不是各自随机游走）
C3 有共同来源：所有齿由同一个泵浦/同一个腔产生，而不是 N 台独立振荡器拼起来

按这三条，齿列可以分成三类。下面这张图是本页的地基，先把它看清楚 —— 后面所有的判定都回到这张图的颜色上。

三类的名字与来历

A1
算术梳（等间隔）

fn = n·frep。齿距恒为 frep，与 n 无关。
物理来源：任何严格周期信号。周期 T ⇒ 频谱只含 1/T 的整数倍 —— 这不是技术，是傅里叶定理。
谐波列（一个音的泛音）就是 frep = f0 的特例。

A2
平移算术梳（现代频率梳）

fn = n·frep + fceo。齿距仍是恒定的 frep， 但整把梳被 fceo 整体平移了一点。
来源：锁模激光的载波–包络相位每圈滑动 Δφ，等效于整个频谱搬移 fceo = frep·Δφ/2π。
这两个自由度（frep 与 fceo）都落在微波频段，可以被电子学直接测量和锁定 —— 这就是它拿诺奖的原因：把几百 THz 的光，接上了一把 GHz 的尺子。

A3
几何梳（等比齿列）· 音乐音阶属于这一类

fk = f0·rk，rk 是音阶比（如 9/8、5/4、3/2）。
在对数频率轴上看起来等间隔（这就是"音阶"的含义）；在线性频率轴上，齿距在一个八度内递增，跨八度整体 ×2 后重置，所以呈锯齿形 —— 不是单调递增。
它不满足 C1，而且不用跨八度就能看出来。在同一个八度内，纯律七音通分成 24 分音后，相邻齿距依次是 3, 3, 2, 4, 4, 5（单位 f0/24），即 0.125, 0.125, 0.083, 0.167, 0.167, 0.208 f0； 最小 0.083、最大 0.208，八度内跨度 2.5 倍。同一个音阶内部，齿距就已经不相等。
⚠ 口径提醒：上面这组数是一个八度内的。图 5-1 的橙行横跨多个八度，整条跨度会更大（跨 2 个八度时 0.083 → 0.250，3.0 倍）—— 两个数都对，只是范围不同。图下方读数写的是"整条橙行"的口径。

所以，"Keely 用三个八度做出了频率梳"这句话是错的 —— 错在把 A3 当成了 A1。
音阶是几何齿列（比值恒定），频率梳是算术齿列（差值恒定）。两者在图上都是"一排竖线"， 但一个是乘法结构、一个是加法结构。
这不是抠字眼：乘法结构下，齿距随频率增长 ⇒ 高频端齿越来越疏 ⇒ 无法用单一 frep 拍频读出。 而"能用单一 frep 读出"正是频率梳的全部工程价值。详见 ⑦。

②时域与频域是同一件事：为什么"闭合"必然长出梳

上面说"任何严格周期信号，频谱就是等间隔齿"，这句话值得单独证一遍 —— 因为它是本页唯一一条不需要实验、纯数学成立的桥，也是 Keely 那套"闭合"要成立时必须满足的条件。

若 s(t + T) = s(t) 对一切 t 成立，则傅里叶展开只允许
  s(t) = Σn an ei2πn t/T   ⇒   频率只能取 fn = n/T = n·frep
齿距 = 1/T。周期越短，齿距越大；周期趋于无穷（非周期），齿距趋于 0，谱变连续。
由此得到本页最重要的一条推论（后面反复用）：
Keely 追求的"闭合"，本质是在追求周期性。而周期性的直接后果， 就是频谱自动变成一把齿距 = 1/T 的算术梳。
换句话说：如果他真的做到了闭合，那把梳自己就长出来了，不需要他另外去造。 反过来说，一把稳定的梳，就是"周期性成立"的可测证据。
这条推论把"闭合"这个玄学词，变成了一个能不能测出来的工程量：测梳齿间距稳不稳、齿间相位锁不锁。

但这里有个陷阱：周期 ≠ 音阶闭合

09 页图 3a 的闭合判据是：m 个音程比连乘，回到 2n（Σq = Σs = 0）。 它保证的是音阶走完一圈后，音高回到某个八度。这确实会产生一个公共周期 T = 1/fgcd，其中 fgcd 是所有分量频率的最大公约数。

问题在 fgcd 的大小。取纯律七音 {1, 9/8, 5/4, 4/3, 3/2, 5/3, 15/8} × f0 = f0·{1, 1.125, 1.25, 1.333…, 1.5, 1.666…, 1.875}，通分成 24 分音：

{1, 9/8, 5/4, 4/3, 3/2, 5/3, 15/8} = {24, 27, 30, 32, 36, 40, 45} / 24
⇒ fgcd = f0/24   ⇒   公共周期 T = 24/f0
f0 = 432 Hz 时，T = 24/432 = 55.6 ms，齿距 = 432/24 = 18 Hz。这是一把齿距 18 Hz 的梳 —— 不算离谱。

但如果音阶里混进一个分母 81 的比（比如 81/64，毕氏大三度），fgcd 立刻掉到 f0/648， 齿距变成 0.67 Hz。再加一个分母 243 的，齿距 0.2 Hz。每加一层 3 的幂，齿距就掉 3 倍。

于是得到一条可算的判据（本页原创，C 级）：
一个纯律音阶的"梳"是否工程上存在，不看它闭合不闭合， 而看它的公分母 D = lcm(各比的分母)：
  齿距 = f0/D，  齿数（一个八度内）= D
若 f0/D 低于器件带宽或人耳分辨率，这把梳在实践上等于不存在（谱是连续的）。
这解释了为什么现代频率梳不用音阶比：不是音阶"错"，是音阶的公分母不可控。 工程上宁可用 frep = 10 GHz 的等间隔梳 —— 简单、可控、齿数固定。

3.1 光学那一支：fceo 为什么是诺奖级的一步

锁模激光的脉冲串是周期的，但"脉冲里的光波"与"脉冲包络"之间每圈会错开一点相位 Δφ。 这一点错位，等效于整把梳在频率轴上平移：

fn = n·frep + fceo，   fceo = frep · Δφ / 2π
frep 由腔长定（≈ c/2L），fceo 由色散定。两个都在 GHz 以下，电子学能直接数。

在 2000 年之前，光学频率（~1014 Hz）与微波（~109 Hz）之间隔着五个数量级， 中间靠"频率链"一级一级往上乘，需要一整个实验室。频率梳把这件事变成一台仪器： 只要测出 frep 和 fceo 两个射频数，第 n 根齿的绝对频率就精确知道。 2005 年 Hall 与 Hänsch 因此获诺贝尔物理学奖。

「齿距 frep 对应微谐振腔的自由光谱范围（FSR）；当级联四波混频产生等间距光梳线时， 该间距与 FSR 一致，实测与光纤频率梳比对，等间距程度可达 10−17 量级。」 — 微梳综述对 2007 年首次微梳实验的描述 [综述 Photonics Insights 3(4) R09, 2024]

3.2 声子那一支：为什么它和 Keely 的装置最像

声子梳（phononic comb）是把同样的机制搬到机械振动上。它的齿距不是光频，而是机械模的频率—— 正好落在 Keely 装置工作的频段（Hz 到 MHz）。目前有三个可查的节点：

声-1
磁振子频率梳：20 根齿，齿距 10.08 MHz

中科大董春华组（徐冠庭、张劢共同一作），Phys. Rev. Lett. 131, 243601，2023-12-11。
做法：磁–力学谐振腔，加一个蓝失谐强泵浦，磁致伸缩非线性被显著增强， 出现类克尔级联四波混频，产生 20 根梳齿，齿距 10.08 MHz 恰等于机械模谐振频率。
✅ 与 Keely 的关键差别：他们用注入锁定稳定齿距 —— 这一点后面 ⑤ 会专门讲，那是"同情振动"的现代实现。

声-2
MEMS 声子梳：齿距 25 Hz → 200 Hz 可调

Jiahao Wu 等，J. Microelectromech. Syst. 33(3) 384–394，2024-03-29，DOI 10.1109/JMEMS.2024.3379195。
做法：非线性模态耦合的 MEMS 谐振器，构成 1:3 内共振；单音激励就能触发。 通过倍周期分岔、循环折叠分岔与混沌，齿距从 25 Hz 连续调到 200 Hz 以上，跨一个数量级。
✅ 这一条对 Keely 最友好：单频驱动 + 结构非线性 ⇒ 多齿。不需要激光、不需要低温，桌上就能做。

声-3
相干声学频率梳（AFC）：104 根齿，跨六个数量级

Guanzong Xiao 等，Broadband nonlinear phonon-laser frequency comb， DOI 10.21203/rs.3.rs-4168088/v1，2024-04-11。
⚠ 这是预印本，未经同行评审，引用时必须标明。文中称：SiN 膜 + 光力腔， 两种非线性耦合（增益辅助的光–运动耦合 + 机械波混频）可调，齿数达 104， 覆盖六个数量级频率，齿距近乎完全均匀。

证据分级提醒（本页立场）： 声-1、声-2 是正式发表；声-3 是预印本。 在 09 页的 A/B/C/D 分级里，声-3 应记作 D 级（存疑）， 不能因为"数字最漂亮"就当结论用。
这条纪律对本页同样适用：下面 ④ 里凡是标了 C 的，都是我自己算的，不是文献直述。

③-bis非线性：一根泵浦怎么变成一把梳

③ 列了四条路线，却没说它们共用一个发动机。这一节专讲发动机 —— 非线性。
先把一句话钉在这里：非线性不是"更强的放大"，而是唯一能凭空造出新频率的机制。 线性系统里，把 432 Hz 放大一千倍，出来的还是 432 Hz，只是更响。

3b.1 三件套：非线性只是第一件

媒体常把"非线性"说成万能钥匙。实际上它只是三个必要条件之一，缺一件都不出梳。

条件它负责什么缺了会怎样
A · 非线性
χ(2) 或 χ(3)		 让输出不再正比于输入：y = a1x + a2x² + a3x³ + …， a2、a3 非零 ⇒ 出现 2f、3f、f1±f2 只剩 a1 ⇒ 叠加原理成立 ⇒ 频率一个不变。这就是"线性"的定义
B · 相位匹配
Δk = 0 / 落在腔模上		 新产生的频率必须与已有场同相叠加，否则走几微米就被相消掉 频率在局部瞬间产生了，但传不出去也积不起来，谱上只剩噪声鼓包
C · 高 Q 储能
Q = ω₀·储能 / 每弧度损耗		 把泵浦场在腔内放大 Q 倍（强度 Q² 倍），才够得着非线性阈值 只能靠外部把功率推到很大 —— 这就是 Keely 需要的 160 dB 的来历
最常被误解的是 A。很多资料把"非线性"和"放大"混成一件事。反例很好举： 一台普通功放是线性的，把 432 Hz 推到 2,000 Pa 也不会自己冒出 1296 Hz。
要 1296 Hz，必须存在某个 x³ 项（或级联的 x² 项）把它混出来。能量可以从泵浦来，频率不能。

① ② ④ 是"自发"—— 给单频，自己长出齿；③ 是"驱动"—— 齿距由外部时钟强迫。
Keely 的音阶是几何排布出来的固定音高：管多长、调什么音，全是加工时定死的。 它既不自发，也没有外部时钟。它是"设计好的七个频率"，不是"长出来的梳"。

3b.3 阈值：为什么现代只要 25 mW，而声学要 2.8 kW

微腔里的这一整套动力学被压缩成一个方程 —— Lugiato–Lefever 方程（LLE）， 本质是一个"受驱、失谐、带阻尼的非线性薛定谔方程"：

∂A/∂T = −(κ/2)·A − iδω·A + i(D2/2)·∂²A/∂φ² + i·g|A|²A + √(κePin / ħω0)

五项依次是：腔损耗 · 泵浦失谐 · 二阶色散 · 克尔自相位 · 泵浦注入。 四波混频的起振阈值由它解出：

Pth = ħω0κ³ / (8 g κe)　，　g = ħω0²c n2 / (n0²Veff)

把 g 代进去，再代入 κ ∝ 1/Q、κe ∝ 1/Qe，得到一个只看数量级的标度律：

Pth ∝ Veff · Qe / Q³　→（当 Qe ≈ Q）→　Pth ∝ Veff / Q²

把同一把尺子架到 Dynasphere 上：
09 页 ⑥·ter 算过，要在 12 in 球内维持 160 dB（2,000 Pa）需要 ≈ 2.8 kW 声功率； 现代电泵浦孤子微梳只要 25 mW。两者相差 112,000 倍（50.5 dB）。
按 Pth ∝ 1/Q² 反推：把 Q 提高 √112,000 ≈ 335 倍就能打平。
换句话说 —— 差的不是"技术代差"，是"没有 Q"。 Keely 的七根管是自由辐射的，球壳是结构件而不是共振腔；Q 大概只有 10¹–10³ （钢的内耗 + 橡胶囊支撑 + 气动驱动）。
⚠ 这是标度类比，不是同量纲换算 —— 光学腔与声学腔的 ħω 差 12 个数量级， 绝对阈值不能直接比。这里只用来看"数量级上差在哪一个旋钮"，属 C 级推演。

3b.5 声学参量阵：唯一做成消费产品的「空气造频器」

上面说的都是坏消息。但"靠空气非线性造出新频率"这件事，真的被做成了产品 —— 就是声学参量阵（parametric acoustic array，市面上的"定向扬声器"）。它用两束强超声在空气里 非线性差频，变出可听声。定量公式是 Berktay 远场解：

p2(t′) ≈ [ β p0² a² / (16 ρ0 c0⁴ z α0) ] · d²/dt′² E²(t′)

[web_215]　z = 轴向距离，α0 = 一次波吸收系数，E(t′) = 调制包络。

这里 β = 1 + B/(2A) 是介质的非线性系数：空气 β ≈ 1.20（B/A ≈ 0.4），水 β ≈ 3.50。 注意 p2 ∝ p0² —— 二次波正比于一次波的平方，这是纯非线性特征， 线性系统里绝不会出现。

它的实测代价，正好是 Keely 那笔账的工业版：
典型参量扬声器一次波（超声载波）在 1 m 处约 130 dB，解调出的可听声约 72 dB —— 转换损失约 58 dB，即功率只剩约 63 万分之一（105.8 = 6.3×105）。
而且产出是一个差频（宽带调制时是一段连续谱），不是梳：没有等间隔齿、没有相位锁定、没有 fceo。
这恰好从工业侧印证了 09 页 ⑥·ter 的判断：空气非线性真实存在、能用、已量产 —— 但代价是 ~58 dB，收益是 1 根齿。

3b.6 那 Keely 的装置里到底有没有非线性？

公正地说：有，但都不是"梳"要的那种。逐条清点：

有
几何非线性

1/32 in 厚的旋压薄壳在大振幅下会明显硬化（振幅可比厚度时，膜/壳方程的高阶项不可忽略）。 这确实是 χ(3) 型的结构非线性。

有
接触非线性

外环的销钉、轴端橡胶囊、配重黄铜球与内壁的接触 —— 这些都是强非线性源（干摩擦、间歇接触）， 比材料本身的非线性强得多。MEMS 那篇 1:3 内共振走的正是这条路。

有
空气非线性

β = 1.20，客观存在。但 3b.4 已算过：在 160 dB 下只对应 M = 1.4 %，而 81 次谐波 ∝ M80 = 9.7 × 10−149（即 10−148），还差 148 个数量级。

缺
腔 —— 没有东西来定齿距

七根管是自由辐射的，不是耦合进一个谐振腔。没有腔，就没有 FSR，就没有"齿距"这个概念。 齿距是腔给的，不是管子给的。

缺
色散平衡 —— 没有东西把孤子稳住

孤子 = 非线性（自相位调制）与色散（展宽）相抵。球腔里既没有设计过的色散，也没有反常色散区， 所以即使偶然出现脉冲，也会立刻塌掉。

缺
锁相 —— 没有东西管住相位

现代梳靠注入锁定 / 自注入锁定把齿与齿的相位钉住（TFLN 那台就把 DFB 线宽从 44.1 kHz 压到 4.7 kHz）。 Keely 的七个音高由几何定死，但在时间上彼此不相干 —— 这是"七个音"与"一把梳"的分水岭。

缺
振幅 —— 差几十个 dB

按 3b.3，2.8 kW 才够 160 dB；而装置由气动/机械驱动，输入声功率在瓦级。 差 3 个数量级，且已顶到 3b.4 的物理天花板。

所以"给 Keely 补非线性"的正确做法，不是加大声压，而是换结构。三条按可行性排序：
  1. 把七根管改成非线性耦合梁，做 1:3 内共振 —— 照 [web_202] 的结构： 单音激励自己长出齿，齿距 25–200 Hz 随幅值连续可调。桌上就能做，不需要激光、不需要低温。
  2. 给它一个真腔：Helmholtz 腔或管腔把 Q 提到 10³–10⁴，再靠空气非线性起振。 按 3b.3 的 Q² 标度，这是唯一可能把 2.8 kW 降下来的路径。
  3. 或者干脆改口：承认它是音阶发生器，不是频率梳。音高是设计出来的，不是长出来的 —— 这句话同时是 ⑦ 的结论。

3b.7 从谱上认机制：四个问题

拿到一张谱，不用看论文，先问这四句，机制基本就定了：

问答案结论
齿距等于腔的 FSR 吗？是① 克尔或 ② 二次级联（自发型）
齿距等于外部微波频率吗？是③ 电光梳（驱动型，齿距可任意设）
齿距等于某个机械模频率吗？是④ 结构非线性 / 声子梳

对 Dynasphere 试一遍：齿距既不是 FSR（没有腔），也不是外部时钟（没有调制器）， 更不是某个机械模（七根管调的是 B♭ 和弦，不是整数倍）。四个问题全部落空 —— 这不是"证据不足"，而是"它本来就不属于这四类中的任何一类"。

④Keely 的装置落在哪一格：逐项判定

现在把 ① 的三条判据（C1 齿距恒定 / C2 相位相干 / C3 共同来源）套到 Dynasphere 上。 下表每一行只判一件事，不合并。

  • 绿底（同一物）：Keely 的做法与现代梳的对应环节是同一件事，只是名字不同。
  • 黄底（结构同构）：形状/数学结构相同，但物理机制不同，不能互推结论。
  • 红底（本质不同）：看起来像，实质是两回事；混用会导致错误预测。

按 ① 的三条判据：C1 ❌、C2 ❌、C3 部分（同一个气源，但无相位耦合）。三条里缺两条 ⇒ 它不是频率梳。
这不是贬低：1870 年代没有"相位"这个概念的可测形式，χ(3) 要等到 1961 年二次谐波、1962 年三次谐波才被看见。 按 K4 的时间线硬约束，他不可能做出频率梳。

⑤落地：把他的五个环节，逐个换成现代器件

④ 讲的是"他缺什么"。这一节讲"他那套东西，今天能接到哪里" —— 每个环节给出具体的现代对应物 + 可查参数，并且标出哪一环是断的。

S1
激发 → 泵浦

他：气流吹管 / 弦振。今天：连续激光（微梳）、蓝失谐泵浦（磁振子梳）、 压电换能器（MEMS 声子梳，单音激励即可）。
要补的：加一个"失谐"旋钮。泵浦频率相对腔模的位置决定了是加热（红失谐）还是参量放大（蓝失谐）， 这是现代梳能起振的必要条件，气动驱动没有这一维。

S2
谐振体 → 高 Q 腔

他：12 in 旋压球壳 + 7 管（Q 大约 101–102，金属壁、有缝）。 今天：声学腔 Q ~ 103；石英声腔更高；光学微腔 Q ~ 106–109。
要补的：Q 提高 3 个数量级。齿线宽 ∝ 1/Q，Q = 102 时齿线宽达齿距的百分之一以上，齿与齿糊在一起。

S3
「放大」→ 非线性介质（断点）

他：声称靠"极性/中性中心"聚集能量。今天：χ(3) 四波混频、χ(2) 和频差频、 机械波混频（MEMS 的 1:3 内共振）。
这一环是断的，而且是唯一不能绕过的：线性系统里，多个频率叠加只会产生原来的频率， 不会产生新频率。要让齿长出来（而不是只有泵浦那一根），必须有非线性。
空气的 χ(3) ≈ 10−22 m²/V² 量级 ⇒ 要 ~160 dB SPL 才可见（09 页 6t.3：2,000 Pa、2.8 kW）。装置里没有这种条件。

S4
「同情振动」→ 注入锁定（这是最漂亮的一处对应）

他在 1875 年就用这个词描述了"一个振子带动另一个振子"。今天与之最接近的机制是 注入锁定：给自激振子注入一个外部信号，当失谐小于锁定带宽时，从振子频率被拉到主振子频率上，相位被锁住。
✅ 磁振子梳就是用它来稳齿距的（PRL 131, 243601 原文摘要：通过注入锁定实现梳齿间距的稳定与控制）。
但差一层：同情振动是被动响应（Q 放大），注入锁定要求从振子自己已经在自激。 所以判据是：把 7 根管中的一根轻微失谐，看其余各管的频率是否被"拉"过来 —— 如果只是幅度变化、频率不动，那就是共振，不是锁定。

S5
读出 → 拍频 / LDV / 光谱仪

他：人耳 + 手感。今天：激光测振仪（LDV，可测 nm 级位移）、FFT 分析仪、 光电探测 + 射频谱分析。
这是最容易补的一环，成本也最低：一个麦克风 + 声卡 + FFT 软件，就能看到 20 kHz 以内的全部齿结构。 Keely 时代没有这个，所以他只能"听"，而人耳对齿距的分辨率远低于 FFT。

五个环节里，四个能接上，一个（S3 非线性）接不上。
这就是"Keely 技术在现代怎么落地"的准确答案：不是把他的装置放大，而是给他补一个非线性腔。
补上以后，他想要的"多齿频谱"确实会出现 —— 但代价是必须接受 S3 的物理： 齿的功率从泵浦里来，总功率不增加。他当年要的"净增益"，恰恰是补上非线性以后仍然拿不到的那一样东西。

⑥三个判决性实验：用一台声卡就能判生死

前面所有判定都是"从原理推"。但 09 页的立场一直是能验的才做。下面三个实验都只需要 "可调单音驱动 + 麦克风 + FFT"，成本几百元，而每一个都能直接证伪一类说法。

E1相干度：7 源叠加到底是 ×49 还是 ×7
做什么
7 根管（或用 7 个扬声器代替）同频驱动，麦克风置于球心。记录声压时间序列，算二阶相干度 g(2)(0)。
判据
g(2)(0) = 1 ⇒ 完全相干 ⇒ 球心强度 ∝ N² = 49；
g(2)(0) = 2 ⇒ 完全非相干 ⇒ 球心强度 ∝ N = 7；
介于两者之间 ⇒ 部分相干。
为什么硬
这是 09 页 ⑥ 那个"×49"的直接检验。若实测 g(2)(0) ≈ 2，则 ×49 从未发生，整个"球心汇聚"的叙述要改写。
成本
一个测量麦克风（~¥300）+ 声卡 + 免费 FFT 软件
E2注入锁定带宽：同情振动是共振还是锁定
做什么
让 A 管自激（稳定单音），B 管由外部信号驱动、频率可调。逐步改变 B 的频率失谐 δ，测 A 的频率是否跟着变。
判据
锁定：存在一段 |δ| < δlock 的区间，A 的频率被拉到 B 的频率上（跳变或平台），且 δlock 随驱动幅度增大。
共振：A 的频率始终不动，只有幅度随 δ 起伏（洛伦兹型）。
为什么硬
这是"同情振动"这个词能否翻译成"注入锁定"的唯一实测依据。若能测出锁定平台，则 ⑤-S4 的对应成立；若只有幅度响应，则只是共振。
成本
同上 + 一个可调信号源
E3边带结构：有没有非线性，看斜率
做什么
用单音 f 驱动，扫驱动幅度 A（例如 −20 dB 到 +20 dB，20 个点），在每个 A 上测 2f、3f 分量的幅度，做双对数图求斜率。
判据
斜率 ≈ 1：线性（无新频率，只是原频率被放大）
斜率 ≈ 2：二次非线性（χ(2) 型）
斜率 ≈ 3：三次非线性（χ(3) 型，微梳就是这一类）
斜率 ≈ 0：饱和/平台 ⇒ 进入强非线性或测量被限幅
为什么硬
这是 ⑤-S3 那个"断点"的定量检验。若 2f/3f 的斜率接近 1，说明装置里根本没有可用的非线性，"多齿"就不可能自发产生。
成本
同上，不需要额外硬件
三个实验的优先级：E3 > E1 > E2。
理由：E3 判的是"有没有产生新频率的能力"，这一条不成立，后面两条都无意义； E1 判的是"相干叠加有没有发生"，直接检验 ×49；E2 判的是术语对应是否成立，学术价值高但不影响装置能不能工作。
三个实验共用同一套硬件，一次搭台可以全做完。建议按 E3 → E1 → E2 顺序，每个 1 小时。

⑦结论：他缺的不是增益，是相干

把 ①–⑥ 收成一句话：

Keely 想要的是「能量变多」（净增益）；现代频率梳做到的是「频率变准」（相干）。
这两件事在数学上是正交的：前者要求非线性 + 有源介质 + COP > 1（线性系统恒 ≤ 1）； 后者只要求锁相，而锁相完全不增加能量 —— 它只是把已有的能量约束到一根根确定的齿上。
所以他失败的地方（拿不到净增益）和现代成功的地方（拿到相干），根本不是同一件事。 这也解释了为什么"用现代技术实现 Keely"这个说法永远落不了地：它想实现的那一半，物理上不允许； 它没想实现的那一半，现代已经做到了，而且做得比他精确 1012 倍。

7.1 那张"落地"清单，按可行性排序

要做的事难度说明
用 FFT 测出 7 管的实际频谱很低麦克风 + 声卡。先看清"齿"到底长什么样 —— 大概率是 7 个宽峰 + 一堆谐波，不是梳
按 E3 测非线性斜率很低同一套硬件。这一步定生死：斜率 ≈1 就没有非线性，后面全部不用做
按 E1 测相干度 g(2)(0)低直接检验 ×49。这是 09 页 ⑥ 的实证版
把球壳换成高 Q 声腔（石英/玻璃）中Q 从 102 提到 103–104，齿线宽收窄一个数量级以上。这是"能不能看到齿"的关键
加一个真正非线性的耦合（MEMS 式 1:3 内共振）中照 JMEMS 33(3) 那篇的结构做：非线性模态耦合梁，单音激励出多齿。这是最接近"Keely 装置 + 现代补丁"的方案
注入锁定稳齿距高需要自激振子 + 单向耦合 + 相位检测。磁振子梳是靠这个才把齿距稳住的
拿到净增益（COP > 1）不可能不是难度问题。线性无源腔恒 ≤ 1；要 > 1 必须另有能量入口，且那时它已经不叫"增益"了

7.2 一句话回答老师的问题

「Keely 的技术在现代怎么落地？」
落地在"齿"上，不落地在"增益"上。 他那套"三个八度 + 每隔第三钉"给出的是一个可设计的频率网格， 这正是频率梳的前身思想；但要把网格变成梳，必须补上三样他那个时代不存在的东西： 非线性介质（1961 年后才有）、相位锁定（1946 年 PLL / 1970s 注入锁定）、 以及能把相位测出来的仪器（FFT / 光谱仪）。
