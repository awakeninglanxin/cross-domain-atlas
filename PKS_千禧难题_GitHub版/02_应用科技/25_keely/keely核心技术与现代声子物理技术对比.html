Keely 核心技术与现代声子物理技术对比

John Keely（1837–1898）写他的体系时，「声子」「德拜温度」「太赫兹」「磁致伸缩」「夸克」这些词都还不存在。 他能用的只有「原子间」「以太」「磁流」「接近微波」。所以判断他说的对不对， 正确动作不是二选一，也不是判他错，而是回现代物理里找那个被他绕着圈描述的量。 本页是这条方法论的落点，也是整套 Keely 资料的入口。

③时间线硬约束：判定任何一条之前先查这张表

这是防止「用后来的知识去夸 Keely」的最有效工具。凡是晚于他写作年代的发现，他都不可能知道。 遇到"Keely 说对了夸克"这类说法，先看年份。

这条约束怎么用：
「Keely 提前说中了夸克」是错的说法（1964 年的概念，他不可能知道）； 但「他用三个一组的递归结构描述物质层次，这与夸克的三重性同构」是对的—— 说的是结构同构，不是预知。
一字之差，性质完全不同。前者是民科话术，后者是可讨论的观察。

⑥未决：六条还没有答案，另有一条刚刚定案

✅ 已定案（2026-10-17）：Trexar 几何走 C（同心）。 芯银 / 中金 / 外铂，三层等体积，半径比 1 : √2 : √3 ⇒ 累积面积精确 1:2:3。
选 C 的依据是可兑现性：只有 C 能让「1:2:3」变成一条可测量、可复算的几何约束；A 里的 1:2:3 只能指"段长"，与「尺寸均一致」自相矛盾。 A / B 不再作为待选项，在 K3 保留为对照与退路。
代价与待验项已量化写进 K3 §⑥：等体积要不要卡到 1%（结论：不必，±5% 足够）、 A 与 C 的电阻只差 1.84 倍（并联 1.67× vs 串联 3.07× 纯银，但这个差刚好够四探针把两者切开）、 约 4.26 MHz 以上铂外套会遮住银芯、以及四探针 + 金相两道验收筛。

本页的立场，一句话：
