# Schauberger 水工艺（CO₂ + 制冷）与嬗变两段法：同构在哪、反号在哪

> 老师的观察：Champion 那套「阶段一恒温吸气 → 阶段二骤冷锁频」，和 Schauberger 处理水要「充 CO₂ + 制冷」是一个路子。
>
> **这个联想一半对，而且对的那一半正好是最值钱的一半。**
>
> 复算脚本：`calc_两工艺对照.py`（8 组判据全过）

---

## 0. 结论先行

| 层次 | 判定 | 说明 |
|---|---|---|
| **操作序列** | ✅ **真同构** | 都是「气氛置换 + 降温锁定」。连动作顺序都只差一个位置 |
| **热力学方向** | ❌ **反号** | 气体溶解度对温度：水是「越冷溶越多」，金属是「越热溶越多」 |
| **由此决定的工艺形态** | ✅ **可推导** | 正是这个反号，决定了舒伯格能一步、Champion 必须两段 |
| **锁定的对象** | ⚠️ 差三个数量级 | 水锁氢键簇（~nm）、金属锁间隙原子（~0.1 nm），尺度其实同阶，但**性质**不同 |
| **元素身份是否改变** | ❌ 都不改 | 水侧不主张；金属侧声称改，无证据（见白皮书 §5） |

一句话：**表面动作一模一样，内部方向截然相反。** 这就是「看着像」的精确位置。

## 1. 先把舒伯格那边的原话说准

我手头有两句直接引用，都能落到专利/可行性报告上：

**奥地利专利 No.117749 系列（冷却螺旋）：**

> 「水被冷却螺旋从 17 °C 降至 4 °C……**冷却增加水对气体的吸收能力**，使得不施加压力就能使游离碳酸与水结合富集。」

**可行性报告（防氧化流程）：**

> 「注意要让金属表面保持亮洁，若银被氧化后，水的效果就差一些，**处理水要低温同时要抽真空后加 CO₂ 也是为了杜绝氧化**。」

注意第二句里 CO₂ 的角色：**它是保护气，不是反应物**。先抽真空把 O₂ 抽走，再充 CO₂ 顶替，水温和 4 °C —— 三件事合起来的目的只有一个：**别让银氧化**。

另有一句可参（专利 146141 关于 Repulsine 组装）：

> 「考虑到操作过程中产生的电磁和**原子反应**，各种组件须部分或完全彼此绝缘。」

他说了「原子反应」这个词，但**没说是元素嬗变**，全文也没给出任何元素身份改变的证据。这句话不能拿来给「舒伯格也搞嬗变」背书。

## 2. 一条硬判据：溶解度对温度的方向，两边相反

这是全篇唯一一条不依赖任何解释的判据。

### 2.1 水这边：CO₂ 冷溶得多

亨利定律 + van't Hoff，溶解焓由实测两点（25 °C / 1.45 g/L、0 °C / 3.35 g/L）反推：

```
c(T) = c₂₅ · exp( −ΔH/R · (1/T − 1/298.15) )      ΔH_sol = −22.68 kJ/mol
```

| T °C | CO₂ 溶解度 g/L | 相对 25 °C |
|---:|---:|---:|
| 0 | 3.350 | 2.31× |
| **4** | **2.900** | **2.00×** |
| 10 | 2.354 | 1.62× |
| **17** | **1.866** | **1.29×** |
| 25 | 1.450 | 1.00× |
| 40 | 0.935 | 0.65× |

**17 °C → 4 °C，溶解量涨到 1.55 倍。** 舒伯格那句话物理上完全正确。

> ⚠️ 一个容易记错的细节：**4 °C 是水的密度极大点，不是 CO₂ 的溶解度极大点**。后者在 0 °C 更高（比 4 °C 多 15.5%）。两件事相差 4 K，别混为一谈。舒伯格取 4 °C 取的是「体积最小」，顺带获得了「溶解度很大」，但不是最大。

### 2.2 金属这边：碳热溶得多

ASM 相图，碳在铁中：

| T °C | 相 | C wt% | 相对室温 |
|---:|---|---:|---:|
| 1147 | γ-Fe | 2.11 | **42,200×** |
| 1000 | γ-Fe | 1.45 | 29,000× |
| 900 | γ-Fe | 1.15 | 23,000× |
| 727 | α-Fe | 0.0218 | 436× |
| 400 | α-Fe | 0.0015 | 30× |
| 20 | α-Fe | 5×10⁻⁵ | 1× |

### 2.3 判据

```
d(ln c)/d(1/T)    水  : +2728 K   > 0  ⇒  升温减溶
                  金属: −3886 K   < 0  ⇒  升温增溶
```

**符号相反，这是硬事实。**（水取 CO₂ 溶解焓，金属取 γ-Fe 四个温度点的最小二乘）

## 3. 这个反号，直接决定了工艺是「一段」还是「两段」

### 3.1 水：降温和吸气同向 ⇒ 一步法可行

想让水多吸气，就得降温；降温顺带完成了「锁定」（4 °C 密度最大、体积最小、氢键网络最完整）。**两件事一个动作就办完了**，所以舒伯格的装置是「边冷边涡旋」的单一连续过程。

复核：`c(4)/c(17) = 1.55 > 1` ✓

### 3.2 金属：降温和吸气反向 ⇒ 一步法必然失败

若照搬舒伯格——冷的时候吸气：

```
室温 α-Fe 溶碳 5×10⁻⁵ wt%  ÷  1147 °C 的 2.11 wt%  =  2.37×10⁻⁵
```

**进气量掉 42,200 倍。** 冷的时候金属几乎是「拒气」的。

所以 Champion 的工艺**只能**写成两段：

```
阶段一  高温   + 气氛   →  这时候才吸得进气（溶解度是热态）
阶段二  骤冷            →  溶解度暴跌 ⇒ 过饱和 ⇒ 动力学冻结 ⇒ 气体被卡在里面
```

这不是设计者的偏爱，是**热力学的唯一出路**。反过来说：Champion 这套两段式工艺本身，恰好是「金属溶解度随温度升高而升高」这个常识的**独立确认**——设计它的人（不管有意无意）踩对了材料学。

### 3.3 这就是两套工艺「像又不像」的准确位置

```
Schauberger : 抽真空 → 充 CO₂ → 降温至 4 °C →（涡旋）→ 出活水
Champion    : 充 CO₂/O₂ → 保温 3 h（热）→ 骤冷 → 锁住 → 循环
                    ↑                    ↑
              共同：气氛置换 + 降温      分歧：降温在吸气【前】还是【后】
```

动作清单几乎重合，只是「降温」这个动作的地位完全不同：舒伯格用它**促进吸收**，Champion 用它**终止吸收并锁死**。

## 4. 尺度和量级：两边的「冷缩」差一个数量级

| | 温度跨度 | ΔV/V |
|---|---:|---:|
| 水 17 → 4 °C | 13 K | **0.120%** |
| Ag 淬火 ΔT=300 K | 300 K | **1.701%** |
| Cu 淬火 ΔT=300 K | 300 K | 1.485% |
| Fe 淬火 ΔT=400 K | 400 K | 1.416% |
| Al 淬火 ΔT=300 K | 300 K | 2.079% |

**比值 ≈ 14 倍。** 原因很简单：水到 4 °C 就到头了，只动 13 K；金属能动几百 K。

这一条的意义在于：舒伯格的「冷」是**精巧的、贴着反常点的**（4 °C 上下 1 K 都很关键）；Champion 的「冷」是**粗暴的、大 ΔT 的**（几百 K 的冲击）。**同样是「冷」，工程性格完全不同。**

## 5. 为什么金属吸气必然伴随晶格被撑开

这一步把「吸气」和「骤冷」连成一对可逆机械功，也是 Champion 工艺里**唯一真正符合材料学**的部分。

γ-Fe（fcc，a = 0.3591 nm，R_Fe = 0.127 nm）：

| 间隙类型 | 半径 |
|---|---:|
| 八面体 `0.414·R` | 0.0526 nm |
| 四面体 `0.225·R` | 0.0286 nm |

| 溶质 | 原子半径 nm | r / r_oct | 结论 |
|---|---:|---:|---|
| C | 0.077 | **1.46** | 撑开间隙，必须膨胀 |
| N | 0.075 | 1.43 | 撑开间隙 |
| O | 0.066 | 1.26 | 撑开间隙 |

**碳比八面体间隙大 46%**，想进去就必须把铁原子推开。实测每 1 wt% C 使点阵常数增大约 0.0044 nm ⇒ 2.11 wt% 时 Δa ≈ 0.0093 nm（2.59%）。

于是：

```
阶段一 吸气 → 晶格被撑开（真实的膨胀，可测）
阶段二 骤冷 → 晶格收缩 → 反过来把间隙原子夹住（真实的机械锁，可测）
```

**这套流程在材料学里有名字：固溶 + 淬火。** 渗碳钢就是这么做的，工业上做了上百年。它百分之百是真的、可复现的、可测量的。

它唯一不能做的，是改原子核。

## 6. 逐项对照表

| 项目 | Schauberger（水 + CO₂） | Champion（金属 + CO₂/O₂） |
|---|---|---|
| 气相物种 | CO₂ / 碳酸（H₂CO₃、HCO₃⁻） | C、O、H（间隙原子） |
| 溶进什么 | 水的氢键网络间隙 | 金属晶格间隙位 |
| 溶解度 vs T | 升温**减**溶 | 升温**增**溶 |
| 一步法可行？ | ✅ 可以：边冷边吸 | ❌ 不行：必须热吸→冷锁 |
| 低温的作用 | ①增溶 ②防氧化 ③密度极大 | ①体积收缩夹持（唯一） |
| 真空的作用 | 抽走 O₂ 防氧化，再充 CO₂ 顶替 | 原文未提真空步骤 |
| 锁定对象 | 氢键簇 / 碳酸结合态 | 间隙原子位置 |
| 单次定量 | 无任何数字 | 12.5%（1/8，无物理依据） |
| 改原子核？ | 否（也不主张） | 声称是（无证据） |
| 「冷」的性格 | 贴反常点，ΔT ~ 13 K | 大冲击，ΔT ~ 300 K |
| 额外变量 | 蛋形、涡旋、Au/Ag 电极 | 共振频率、多轮循环 |

## 7. 不能迁移的（别硬套）

| 舒伯格的要素 | 为什么迁不到金属上 |
|---|---|
| **蛋形 / 双曲面** | 那是流体力学几何（消除死水区、稳定双螺旋涡）。晶格是**周期性的**，没有宏观旋涡，也没有「蛋形截面」。几何层完全不迁移。 |
| **涡旋 / 内爆** | 靠流体剪切与空化。固体里没有流动，只能靠声子。动力学来源不同。 |
| **4 °C 反常点** | 是水分子氢键的独有性质（密度极大）。金属没有对应现象。 |
| **Au/Ag 电位差电极** | 舒伯格的金银是**电极**（不消耗、只催化）；Champion 的 Ag 是**被转化的原料**。角色相反。 |
| **「原子反应」字样** | 专利 146141 提到过这个词，但没有任何元素身份改变的证据，不能当背书。 |

## 8. 能迁移的（这才是这个联想的价值）

三条工程细节，直接可用：

### 8.1 气氛置换的正规做法：抽真空 → 充气

Champion 的工艺只写「通入气体纳米气泡」，**没有真空步骤**。这在实际操作里是个漏洞：炉膛里残留的 O₂ 会在升温阶段就把金属表面氧化，而氧化层正是气体进不去的第一道墙。

舒伯格的做法更硬：**先抽真空，再充 CO₂ 顶替**。这在现代热处理里就是标准的「真空退火 + 气氛回充」，一点不玄。

### 8.2 「表面必须亮洁」这条红线，在金属上更致命

原文自己给了作用深度：**0.03 mm**。

而金属氧化膜（Al₂O₃、Cu₂O、Ag₂O）的典型厚度在 2–10 nm，加热到几百度的炉内气氛中会长到几十到几百 nm。**几十纳米的氧化层足以挡住 0.03 mm 深度内的扩散通路**——因为它挡在入口。

舒伯格说「银一氧化，水的效果就差一些」，这条在金属上不是「差一些」，是**直接归零**。

### 8.3 低温同时抑制副反应

舒伯格用低温做两件事：增溶 + 防氧化。Champion 的低温只用来做一件事：收缩夹持。

可以叠加：**骤冷阶段用惰性气氛保护**（而不是淬水或淬油），既保住收缩带来的机械锁，又不让回温时氧化。这是两套工艺里唯一能「相乘」的地方。

## 9. 一个三天能做完的检验方案

要判断这套工艺到底做成了什么，**不要先去测元素**（质谱贵、争议大），先测气体到底进没进去：

| # | 测什么 | 方法 | 判读 |
|---|---|---|---|
| 1 | 增重 | 分析天平（0.1 mg） | 增重 = 吸收的气体质量。若 <0.01% 则「吸气」这一步就是空的 |
| 2 | 点阵常数 | XRD，测 a | Δa 直接反映间隙浓度。按 §5，1 wt% C ⇒ +0.0044 nm |
| 3 | 释放总量 | 热脱附谱 TDS / 惰气熔融 | 升温到 1200 °C，测放出多少 H/C/O |
| 4 | 元素身份 | ICP-MS / GDMS | **放在最后做**，因为前 3 项决定它有没有意义 |

**预期的两种结果：**

- **结果 A**：1–3 测出明显吸气（比如 0.1–1 wt%），但 4 测不出 Z 变化。
  ⇒ 结论：**这套工艺确实是一套优秀的吸气/固溶工艺，但不改变元素身份。** 这是我认为最可能的结果。
- **结果 B**：1–3 也测不出吸气。
  ⇒ 结论：**连「吸气」都没发生**，工艺描述本身不成立。

无论哪种，都比争论「能不能嬗变」有价值：**它把玄学争议压成一个三天、几千块钱的材料学实验。**

## 10. 诚实的边界

1. **水的「结构化」我没验证。** 舒伯格主张冷 + 涡旋使水形成「成熟水 / 活水」，这部分我只承认其中可测的物理量（气体溶解度、密度极大点、电位差），**不承认**「水的记忆力」这类说法。
2. **AH 与溶解度数据来自标准手册**（CO₂ 亨利常数 Sander 汇编、碳-铁相图 ASM），不是舒伯格文献。舒伯格文献只提供了「17 °C → 4 °C」这个操作条件，**物理内核是我补的**。
3. **「舒伯格说冷却增溶」这句，是他对的现象、对的理由**——这在舒伯格体系里不常见（多数地方是直觉对、机制错），值得单独记一笔。
4. **Champion 一侧的所有批评不变**：两条式子的单位/口径问题、Z 账 10/16 不守恒、12.5% 无物理依据、6 条 Bi 系算出来是 −2×10⁴ °C。本次对照没有为它增加任何可信度。
