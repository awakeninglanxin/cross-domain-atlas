## 路径核算的三条硬结论（详见配套页）

| 判据 | 内容 | 结果 |
|---|---|---|
| **D1 方向** | `T > 20 °C ⟺ a止 > a起`（与 α 无关，只看符号） | H、Pb 的 `a` 都比 Pt **大** ⇒ 两条路径方向从一开始就反了 |
| **D2 单调** | 由 D1，合法路径的 `a` 必须严格递增 | H→Pt：0.2870 ⇒ 0.2471；Pb→Pt：0.3123 ⇒ 0.2471，**均递减** |
| **D3 同位素** | `a ∝ m^(1/3)`，换同位素能翻转符号 | Ag-107 → 43.4 °C，天然银 → **−131.6 °C**；Zn-64 → 48.8 °C，天然锌 → **−198.9 °C** |

61 步（32 + 29）逐步代入后：**0 步**落在原文已发表温区，**30 步**温度低于 −273.15 °C，**22 步**超 1600 °C。

## 五条通项规律（摘要）

1. **温度 = 间距失配 ÷ 膨胀率**。`T = ln(f起/f止)/Ec + 20 ≈ (Δa/a)/α + 20`。想要低温，只能找等效间距极接近的元素对（Ag↔Au 差 0.08%、O↔H 差 0.05%、Zn↔Pd 差 0.09%）。
2. **两条温区是同一公式的两个档位**。气体对 ln 比 ~10⁻⁴（37.8–48.8 °C），金属对 ~6×10⁻³（269–308 °C）。不是两套机制。
3. **加质量走控气炉，减质量走真空炉**。16 条案例全部符合，无例外。
4. **单次转化率被晶格几何卡住，累计靠循环**。`1 − (1−0.125)ⁿ`；n=10 得 73.7%，n=20 得 93.1%。
5. **真正的通项只有一句**：两个同位素的「等效原子间距 a = 1/∛n」相等时发生嬗变。温度、气体、介质、炉型都是为达成这一条件的手段。

## 必须记住的三件事

1. 🔴 **那个「Hz」不是频率，是 cm⁻¹。** 当振动频率用等于漏乘声速 10³ m/s，与真声子频率差 3.2×10⁵ 倍。乘上声速得到 1.26×10¹³ Hz —— 正好是金属德拜频率量级，反过来印证漏乘。
2. 🔴 **质量账配平 ≠ 反应成立。** A 只是整数加减，Z 才是约束。10/16 条 Z 不守恒，最大缺口 12 个正电荷。要补只能靠 β 过程，而 β 过程必然留下 γ 或 β 活性 —— **这是这套体系唯一一次测量就能证伪的地方**。
3. 🔴 **假红比假绿更会骗人。** 本文档初版曾写「式二复算 61.7 °C vs 原文 43.4 °C，差 18.5 K，内部不一致」，原因是**跨年份来源混用了金密度**（19.30 vs 19.32）。按原文配对复算，43.41 对 43.4，分毫不差。错的是参考量，不是原文。脚本里已把这个假红做成一条断言保留。

## 与 Schauberger「CO₂ + 制冷」的对照（一句话版）

两套工艺共用同一个操作范式「**气氛置换 + 降温锁定**」，但**溶解度对温度的方向相反**：

- **水**：冷 ⇒ 溶得更多（CO₂ 17→4 °C 多溶 **1.55 倍**）⇒ 降温与吸气同向 ⇒ **一步法**可行
- **金属**：冷 ⇒ 溶得更少（1147 °C 是室温的 **42,200 倍**）⇒ 降温与吸气反向 ⇒ **必须两段法**

**所以 Champion 那套「吸气 → 骤冷」不是玄学，它是固溶 + 淬火**，渗碳钢的工业流程。
它唯一做不到的是改原子核。

三条能真借的工程细节：① 真空/惰气保护（原文自己写作用深度只 0.03 mm，几十纳米氧化膜就把它堵死）；
② 表面必须亮洁；③ 骤冷阶段用惰性气氛而不是淬水/淬油。
