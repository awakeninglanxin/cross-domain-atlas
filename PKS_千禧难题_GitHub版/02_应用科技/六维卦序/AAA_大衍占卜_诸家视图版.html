大衍占卜

问对 · 一卦四观

在右侧参数面板输入问题 → 用原版同一起卦器随机起一个本卦 → 按「错综复杂」展开四卦 → 依四卦给出结构化回应。起卦结果与下方卦纹、九种视图共用同一状态，不另开随机源。
口径三分（互不替代）：
有原文八卦卦德取《说卦传》「乾健、坤顺、震动、巽入、坎陷、离丽、艮止、兑说」；爻位取《系辞下》「二多誉、四多惧、三多凶、五多功」「其初难知，其上易知」。
能复算四卦的 6-bit 码、文王序号、两两汉明距离、动爻数、Klein 四元群闭合性，全部由本页 Q₆ 变换现算并列在「复算表」里逐项打勾，不是写死的文案。
立论四卦之名历代有异说：错（六爻全变）、综（上下颠倒）各家一致；复或指六爻重卦／八纯卦、或指互卦；杂或指交互卦、或指八纯之外的五十六卦；亦有「错综复杂实只三变」之说。本页取可复算的一套：错 = code^63、综 = rev6(code)、复 = rev6(code^63)（错而复综，Klein 四元群第四元）、杂 = 中爻互体（二三四为下、三四五为上）。此为本页编排，非古法定论。
本页回应是象数推演，不是事实判断，也不构成医疗、法律、投资建议；四卦的吉凶语义不进入任何数字计算。

大衍之数五十，其用四十有九。分二 · 挂一 · 揲四 · 归奇，三变成一爻，十有八变而成卦。

卦纹

诸家视图

把网上几套不同路数的《易经》可视化作品，各自抽象成一张程序化示意图，都挂到同一卦上。勾选即显示，可叠加对照。全部本地生成，无外部图片与依赖。

熵源：crypto.getRandomValues（CSPRNG）。快速模式按古典四象 1/16 : 3/16 : 7/16 : 5/16 精确采样（16 桶拒绝采样，无模偏差），并记录熵消耗。正宗模拟为分二揲四过程模拟，其真实分布与古典值有系统偏差（均匀分裂下 P(6)≈1.28%）。
卦纹映射：下卦三爻作横向频率码、上卦三爻作纵向频率码，各取 0–7 映射为 1–8 档；动爻数定相位 δ；之卦低透明度叠影。李萨如外接框本是方形，用 tanh 径向压缩内接进单位圆并裁剪，故外轮廓恒为圆形。上下卦同码的 8 卦改画 18 条相位递增椭圆，包络成圆。闭合周期开启时，Harmonograph 去掉阻尼与无理失谐、改用整数倍频双摆叠加，在 t∈[0,2π] 严格闭合；关闭时保留 exp 阻尼与微失谐，是向内收束、不闭合的摆锤衰减轨迹。
诸家视图为程序化致敬，非原作截图，对应关系：六十四卦结构动画（加一倍生成树 / 伏羲方圆图 / 文王序长卷·消息卦）、爻变 · AR 易经（逐层生长·意象）、Yijing Explorer（6-bit 超立方节点）、YichingWebapp 与 YiMatrix 每日一卦（抽签转盘）、I-Ching Fortune Teller（三枚铜币）、洛阳《河图洛书》沉浸式舞台剧（光笔实时绘卦）、太极八卦动图（阴阳鱼呼吸）。此为视觉映射实验，不对应传统易学定则。
