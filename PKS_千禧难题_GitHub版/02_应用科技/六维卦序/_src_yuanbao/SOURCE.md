## 原件里就有的四处结构问题（整合时不能跟着抄）

1. **章节顺序错位**：正文 h2 顺序是 `前言 → 〇 → 一…七 → 十 → 十一 → 十二 → 十三 → 八 → 九 → 十五 → 十六 → 十四`。八、九被挤到十三之后，十四被甩到全文末尾（还排在「本文档由四支视频合并整理」这句之后）。目录本身写的是正确顺序，**目录与正文不一致**。
2. **没有第十四章之外的断号**：编号从 〇 跳到十六，但正文里 十四 出现两次位置不对；没有「十四」的缺失，只是位置错。
3. **Doob 表与正文自相矛盾**：表里 β=4 → 熵率 0.7020、β=8 → 0.6932（≈ ln 2，压不下去了）；正文与图注却写「β=4 时熵率≈0.02，系统麻木」。同一个人写的同一份文档，两处不能同时成立。
4. **「谦卦六爻全正」与位序定义不符**：按「当位」定义（初三五阳、二四上阴），六爻全当位的唯一卦是**既济**，谦只有 4 爻当位。文档说「64 卦中只有一卦六爻全是正分：谦卦」—— 这一条查不得。
