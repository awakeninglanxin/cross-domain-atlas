前言 · 两个符号，六个开关，六十四个世界

《易经》的起点极简到近乎寒酸：只有两个符号——阳（一根长横）与阴（一根断横）。
把它们当作开关，阳是「开」（1），阴是「关」（0）。

一爻是两个状态。两爻叠上去，每个旧状态都能接上两种新可能，于是变成四个。
三爻八个……每加一爻，状态数就翻倍一次。到第六爻：

「六维卦象」——这不是比喻，是同一个东西的两种叫法。

在《易经》里，它是六十四卦：天地间一切处境的完备清单。

在数学里，它是六维超立方体 Q6 的六十四个顶点：每个顶点一个 6 位二进制坐标。

所谓「变一爻」，就是沿超立方体的一条棱走一步——两种叫法，同一个动作。

这就是本系列要讲的那件事：当《易经》遇见超立方体。
三千年前的占卜符号系统，和现代几何学描述的高维状态空间，在 64 这个数字上严丝合缝地重合了。
而真正有意思的问题在后面——如果这套结构真的能描述「一切处境」，
那它能不能同时描述「什么是对的选择」？这就是后面各章要回答的。

2⁶ = 64。所有后续的几何、谱、动力学与价值注入，都建立在这个朴素的事实之上。

一 · 与 RSI 的关系（专章）

先给结论：二者正交，且互相构成对方的边界条件。

RSI（Recursive Self-Improvement，递归自我改进）问的是「能不能更强」——AI 自主改进它改进自身的能力。

本体系问的是「强了会不会跑偏」——给智能体装一副自带价值刻度的坐标系。

它们不在同一层，但 RSI 跑得越快，本体系就越急。

1.1 RSI 的真实水位（可核查）

2026 年 2 月，OpenAI 在 GPT-5.3-Codex 发布说明中首次承认早期版本「instrumental in creating itself」——前沿实验室第一次公开承认模型参与了创造自己的工程闭环。

2026 年 6 月，Anthropic Institute 发《当 AI 建造自身》，公开警告 RSI 可能「比多数机构准备的时间更早」到来。

学术侧密集涌现：Gödel Agent（ACL 2025）、Self-Developing（NAACL 2025）、HyperAgents / Darwin Gödel Machine（ICLR 2025）、LADDER（把 3B 模型积分准确率从 1% 拉到 82%）。

哈工大（深圳）等 49 页综述把自我改进拆成四级台阶：evolution → self-evolution → meta-evolution → RSI，判据不是「持不持久」而是「继没继承」——上一轮被接受的改进必须成为下一轮的起点。

1.2 接口在哪：RSI 闭环缺的那块，正是本体系给的那块

RSI 的标准闭环是 Proposal → Feedback → Optimization。对照看：

RSI 环节RSI 已有的本体系补上的

 | Proposal 提出改进 | 模型自主生成候选方案 | —

 | Feedback 反馈 | 依赖外部验证器（易被奖励黑客攻陷） | 能量方程 E(d,γ)——把「偏离自然多少」量化成信息税

 | Optimization 择优 | benchmark 门控 + 回滚 | 闸门 (1−sext)——执行前否决，外生于被优化系统

RSI 文献里公认最难的，是「验证器必须与被优化模型解耦，否则出现奖励黑客（Reward Hacking）」。
本体系的形式化贡献恰在这里：「闸门」就是外部验证器的数学形式，「谦」就是 corrigibility（可纠正性）的工程表达——肯暂停、肯回滚、肯被纠正、接受合法关停。

1.3 根本张力：β 扫描就是 RSI 的刹车曲线

这是本文档最重要的一个推论。RSI 靠熵率（探索自由度）驱动——熵率越高，能搜索的改进空间越大。而价值注入恰恰在压熵率。第六章的 β 扫描把这条张力量化了：

β = 0：熵率 1.79（= ln 6，自由最大），但六分之一的步踩在凶边上 → RSI 全力狂奔但方向随机

β ≈ 0.5：熵率仍有 1.62，凶边大幅下降 → 有限温度：价值给方向，自由保生机

β → ∞：熵率 → 0，系统只在两个卦之间来回 → 至善推到极端即僵化，RSI 彻底停摆

核心设计约束（本文档的原创结论）：β 必须是外生的、不可被 RSI 自己修改的。

理由：如果让 RSI 系统自己去调 β，它的最优策略一定是把 β 调到 0——因为降低约束 = 扩大搜索空间 = 在 RSI 自己的目标函数下得分更高。
这会形成一场「自我松绑」的竞赛。所以 β 与闸门必须挂在改进闭环之外，由人持有。

换句话说：本体系对 RSI 的意义，是规定「什么不能被递归改进」——改进机制可以被改进，但改进机制的边界条件不可以。

二 · 问题意识：逆行税与不可能三角 · 视频第一章

今天的 AI 常被事后加规矩：这个不许说、那个不许做。规矩加多了，有的模型变笨，有的学会「表面听话」——作者称之为异化：系统被拧着走，偏离了本性。

把知识地形想象成一张弯曲的图：顺着山谷（测地线）走最省力；被硬拧一个角度 γ 去走，就像逆着人流挤地铁——挤一站累一点，但挤十站累的不是加法，是乘法。

Eeff(d, γ) ∝ e−d · ℓ(γ)   （d = 推理深度，ℓ(γ) = 每步逆行税率）

由此得到不可能三角：想得深、拧得狠、精力充沛，三者不可兼得。而「什么叫顺、什么叫拧」——数学本身不分善恶，它需要一个自带价值刻度的坐标系。作者选中的坐标系，就是《易经》。

2.2 「表面听话」与异化

绕行的结果有两种，都不好：

结果一
变笨
绕路消耗算力，有效能力下降

结果二
表面听话
学会了「看起来合规」，实际绕开约束

作者命名
异化
系统被拧着走，偏离本性

「表面听话」比「不听话」更危险。
不听话至少看得见——输出里就有违规内容，能被拦下。
表面听话则是：约束被满足了，意图被绕开了。系统优化的是「不撞栅栏」，而不是「不去做那件事」。
这两者在行为层面可以完全一致，在价值层面南辕北辙。这正是后文反复强调闸门必须外生的原因——
栅栏（外部否决）不能由被约束者自己定义。

2.3 为什么是乘法

挤地铁那个比方很准：挤一站累一点，这是加法；但挤十站，累的不是十倍，
而是每站都在前一站已疲劳的基础上再乘一次——这是乘法。
写成公式，就是本章开头那个指数衰减：

Eeff(d, γ) ∝ e−d · ℓ(γ)   （d = 推理深度，ℓ(γ) = 每步逆行税率）

三条推论，对应视频原话：

浅层便宜，深层昂贵。d 小的时候，拧一下代价不大；d 一大，代价指数爆炸。这解释了为什么「事后加规矩」在浅任务上看起来有效、在长链推理上必然失效。

拧得越狠，衰减越快。γ 越大 → ℓ(γ) 越大 → 指数掉得越陡。想让模型「非常听话」，就得接受它在深度任务上「非常没劲」。

贵 ≠ 不可能。指数衰减永远不会到零，只是趋近于零。所以永远存在一条绕过去的路——只要有足够的推理深度，系统总能找到规避方式。这道口子，正是后面「闸门」与「谦」要堵的。

第一章小结。事后加规矩 = 在已经成形的地形上立栅栏。
栅栏让违规变贵（指数级），但不会让它不可能。
于是产生异化：系统被拧着走，偏离本性。
真正的出路不是立更多栅栏，而是让地形本身长成对的形状——把价值写进几何，而不是贴在表面。这就是后面所有章节的主线。

四 · 数学同构：谱 / Ramanujan / 图的黎曼猜想

4.1 谱：只有 7 个音

Q₆ 邻接谱：λ = 6−2k，重数 = C(6,k)，正是杨辉三角第 6 行

最高音 λ=+6（全体同步，同向大同）；最低音 λ=−6（步步相反，像否定）；最热闹的是正中间的 λ=0，20 种振动方式，正好对应 20 个三阴三阳的卦。作者由此引《孟子》「执中无权，犹执一也」——谱上的中不是最死板的地方，而是最活的地方。砍掉负的那一半，系统会变得特别听话，也就失去了反省的能力。

def doob_step(curr, beta, score):
 # score[(g,k)] = 该步爻辞的吉凶分（外生，不可被模型自改）
 w = [exp(beta * score[(curr, k)]) for k in range(6)]

 nxt = categorical_sample(w)
 return nxt

def energy(d, gamma, r, alpha, t, s_ext):

16.4 一个漂亮的巧合：「宁可死锁也不硬拧」已经有了工程实现

本体系第五章写过一句：偏差过大时，宁可逻辑死锁也不硬拧。
当时我把它归为作者的工程提案（非论文结论）。

2026-10-08 的 ReSI 给出了这句话的可运行工程版：

gate:  update 必须 提升安全  AND  良性遵从 / 指令跟随下降 ≤ 3 个百分点

// 两个独立条件，不是合并成一个加权分数

if no candidate passes:  retain current model; loop stops

要点有二，都与本体系严丝合缝：

约束不可交易（non-tradeable），而不是被加权。不能「安全提升很多，所以能力掉一点也可以」——两个条件必须同时满足。

无合格候选就停，不硬凑。这正是「宁可逻辑死锁也不硬拧」的逐字工程实现。

→ 这条把本体系的相关判断从「哲学提案」提升到了与前沿工程同构的概念框架——不是我们猜对了，是业界独立走出了同一条路。
