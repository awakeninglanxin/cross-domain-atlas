## 网格（不是猜的）

`_panels.cjs` 缩到 200×300 后逐行/逐列算**行内亮度的标准差**：面板之间是一条完全均匀的黑缝，
std 趋零；面板内部再暗也有起伏。于是「std < 2.2 的连续行/列 = 分隔带」，其余为面板。

## 去重（三次才成）

| 试法 | 命中 | 判据 |
|---|---|---|
| md5 | 0 | 同一内容被缩放过，字节永不相等 |
| 整图相关性（24×32 灰度，零均值单位方差） | 0，最高 0.51 | 拿整图比一个角，宽高比一拉就失真 |
| **按面板逐块比** | **16/16，0.898–0.992** | 面板边界由黑缝给出，取景比例 0.7/0.85/1.0 取最大 |

结论：**22 ＝ 3 已用（17、19、20）＋ 19 新增**；16 帧 ＝ 17/19/20 的全部 16 块，
顺序逐格对应（s1_01→R1C1、s1_02→R1C2 …）。新增面板 **139 − 16 ＝ 123 块**。

逐帧明细见 `_match4.cjs` 输出的 `frame2panel.json`（临时），结论已固化进 `sources.cjs` 的
`ZIP_ITEMS[].used` 字段，并由 `test-hex.cjs` O 段 10 条断言守护。
