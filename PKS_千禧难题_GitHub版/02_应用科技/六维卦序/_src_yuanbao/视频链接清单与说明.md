## 七、几点需要守住的边界

1. **未找到作者本人署名的论文**。视频原话是「有一篇论文盯上了这 64 个符号」，属解说他人成果（主为 Radisic arXiv:2601.07175）。
2. **几何/谱/拉马努金/黎曼猜想（V1–V4）是真数学，可复现可证伪**；价值注入、谦卦为最高原则、Ω/Φ/Σ 三层（V5）是作者工程与哲学延伸，**非论文结论**。
3. **本体系与 RSI 的关系**：本体系补的是 RSI 缺的「外部验证器/闸门」（对齐层），**不是 RSI 算法本身**；二者根本张力在于「熵率是 RSI 的燃料，却是价值注入的代价」→ 故 β 必须外生、不可被 RSI 自改。
4. **「4 与 6 对应以太侧/物质侧」**：在本体系内部成立（2⁶ = 4³ = 8² 对偶：6 = 态侧定方向，4 = 相位侧定相位），但**是否即外星框架所指，无法判断、不背书不反驳**。
