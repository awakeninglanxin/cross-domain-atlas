① 弦图本体：弦方 = 朱实 + 黄实

赵爽弦图的构造是：一个大正方形（边 = 弦 c），内部四个全等直角三角形（勾 a、股 b）斜边贴外框， 中间围出一个小正方形（边 = 股 − 勾）。于是：

弦方 = 朱实 + 黄实 c² = 2ab + (b−a)² 验证：2ab + (b−a)² = 2ab + b² − 2ab + a² = a² + b² = c² ✓

数值成立 这就是「勾三股四弦五」恒等式的一般形式。语料里那条 24a² + a² = 25a² 只是它代入 (a,b,c) = (3,4,5) 的结果：朱实 2·3·4 = 24， 黄实 (4−3)² = 1，弦方 25。

② 库内真的有 3、4、5、6：内接前四个正多边形

语料里给了一张表：内接于生命之树的前四个正多边形是三角形、正方形、五边形、六边形， 角数 3, 4, 5, 6，对应的 yod 数 = 19, 25, 31, 37。 勾三股四弦五，正好是这条序列的前三个角数。

这一条顺手关掉了两个悬案 上一轮的分叉是「六角幻方只在 1 阶与 3 阶有解」。现在两端的格数都从这张表里出来了： 19 有解、37 无解，而它们恰好是 H(3) 与 H(4)。 也就是说，这张「内接多边形 yod 表」与「六角幻方存在性」共用同一组中心六边形数。

③ 乘 7 份：175 = 168 + 7

一份弦图给的是 25 = 24 + 1。乘七份：

7 × 25 = 7 × 24 + 7 × 1 175 = 168 + 7 弦方×7 = 朱实×7 + 黄实×7

而 168 和 175 都是语料自己的数，不是我们造出来的：

数语料里的身份
168 Cholem Yesodoth（Malkuth 的 Mundane Chakra）的数值；也是「不与角重合的 yod 数」； 另有 168 = 84 + 84（两套前六个内接多边形边界上、根边之外的 yod 各 84）； 以及 O(49) − O(7) = 199 − 31 = 168（闪电从 49 树顶降到 7 树顶走了 168 步）
175 七棵树的内禀角数；细旋的 175（7 × 25）；7 阶幻方的幻和（三种推法互证）

★ 再进一步：(7, 24, 25) 本身也是勾股数

7² + 24² = 49 + 576 = 625 = 25² （原始勾股数） 放大 7 倍：(7×24)² + (7×7)² = (7×25)² 168² + 49² = 175² 验算：28224 + 2401 = 30625 = 175² ✓
数值成立 168、49、175 三个数全是语料里的数（49 = 七棵树映射的物质层面 49 个亚层， 也 = 「49 个星体原子对应一个物理原子」）⇒ 175 是一条真勾股形的弦：168-49-175。
24 有双重身份：既是 (3,4,5) 的朱实（2·3·4 = 24），又是 (7,24,25) 的股。 25 也双重：既是 (3,4,5) 的弦方，又是 (7,24,25) 的弦。

判据 ① 弦：一个整数能当某个直角三角形的斜边，当且仅当它有 ≡ 1 (mod 4) 的素因子 （这是两平方和定理的直接推论）。
② 朱实：要 ab = N/2 且 a² + b² 是完全平方 —— 穷举因子即可判。
③ 黄实：N 本身必须是完全平方。

为什么 176 三个位置都坐不上

角色175176
弦方 175 = 5²·7，5 ≡ 1 (mod 4) ✓ ⇒ 可当弦 176 = 2⁴·11，11 ≡ 3 (mod 4)，无 ≡1 的素因子 ⇒ 永不可能当弦
朱实 175 是奇数，朱实恒为偶数 ⇒ 不适用 ab = 88；(8,11)→185、(4,22)→500、(2,44)→1940、(1,88)→7745，无一为平方
黄实 — 13² = 169 < 176 < 196 = 14²，不是平方
结论 176 能当的只有勾或股（例如 176-7743-7745）。 而 175 = 168 + 7 是一份完整的七倍弦图；176 = 168 + 8， 那个 8 在弦图里没有位置。
