把 k(ρ) 当反射系数用：这个映射在电磁学里能干什么

ρ = 股/勾 为几何参数；z = √2/ρ 为归一化阻抗；Γ = (z−1)/(z+1) 与 k(ρ) 是同一个函数。本页只做一件事：把这条恒等式翻译成可读的工程读数。
一句话：这条恒等式不产生新物理，但它把「内倒四面体的边长比」翻译成「一段传输线的反射系数」， 于是驻波比、回波损耗、薄膜反射率这些现成公式可以直接套上去。 代价是：σ⁴ = 33.970563 从此有了第二个身份 —— 回波损耗 30.62 dB。

2. 四个电磁学落点（都可以直接代公式）

2.1 介质分界面正入射：k 就是那个振幅反射系数

Fresnel（1823）正入射振幅反射系数为 r = (n₁−n₂)/(n₁+n₂)。令 n₂/n₁ = ρ/√2，则

r = (1 − ρ/√2)/(1 + ρ/√2) = (√2 − ρ)/(√2 + ρ) = k(ρ)
逐点核对：ρ = 4/3 时 n₂/n₁ = 0.94281，r = +0.029437，反射率 R = r² = 0.0866 %。

2.2 四分之一波长抗反射膜：ρ=√2 就是"镀好了"

单层膜、膜厚 λ/4、膜折射率取几何平均 n_f = √(n₀·n_s) 时，正入射反射为零。 在本参数化里，零反射 ⇔ Γ=0 ⇔ ρ=√2 —— 而这恰好也是"内倒四面体塌成一点"的位置。 一边是光学上的完全匹配，一边是几何上的完全收拢，是同一条代数式 Γ=0 的两个读法。

实数量级：玻璃 n_s=1.50、空气 n₀=1 ⇒ 理想膜 n_f=1.2247；常用 MgF₂ 是 1.38， 残余反射约 1.3%（不理想但可用）。

2.3 传输线失配：σ⁴ 读作 30.62 dB

ρ 与归一化阻抗严格互为倒数标度 z = √2/ρ，于是 VSWR = max(z,1/z)、 回波损耗 RL = −20·lg|Γ|。ρ = 4/3（3-4-5）落在 VSWR 1.0607 / RL 30.62 dB， 这是一个"几乎算匹配好了"的工程位置 —— 不是只能看的漂亮常数。

2.4 阻抗变换段 / 天线罩：这个映射的实用价值

工程上真正拿来用的是反向读法：给定一个想要的 Γ（或 VSWR 指标），反解出薄膜折射率比或变换段阻抗比。 本页提供的 ρ ↔ z 一一对应，使得"几何上换个三角形"与"换一段阻抗变换"成为同一个动作。 但这只能用于纯电阻性、无耗、单频的示意计算，见 §7 边界。

失谐之后：两个门槛，别混成一个

横轴 8–12 MHz，纵轴 |Γ|。绿色带是几何段能覆盖的幅度范围（|Γ| ≤ 0.1716，即 VSWR ≤ √2），两端在 8.69 与 11.51 MHz。但要注意：只要离开 10 MHz 一丁点，Γ 就带上相位了（9 MHz 时 −69.8°，11 MHz 时 +69.2°），而 k(ρ) 是实数。所以严格讲 ——

  • 相位门槛：任何失谐都立刻破（Im Γ ≠ 0 即出界）
  • 幅度门槛：要 |X| > 17.68 Ω 才破，也就是频率出 [8.69, 11.51] MHz

把两件事压成一句「一失谐就超出几何范围」是夸大：幅度上没有，相位上有。这也是为什么 k(ρ) 只能描述一条线段，不是一个区域。

3. 实验一 · 驻波：把 VSWR 画成看得见的波

反射系数 Γ 的直接后果：传输线上电压、电流不再是行波，而是峰谷固定的驻波。 波腹 |V|max = 1+|Γ|、波节 |V|min = 1−|Γ|，两者之比就是 VSWR —— 与上面交互区的读数同一个数。
蓝线 = 电压驻波，绿线 = 电流驻波，两者相位差 λ/4（波腹对波节）。 VSWR = 1.0607，波节几乎没掉下去 —— 这就是"接近匹配"的样子。

6. 符号翻转：k < 0 在光学里就是半波损失

k(ρ) 在 ρ > √2 时变负，对应的正是主界面里"不可内接"那一组（组④）。 在反射公式里 Γ < 0 的含义是 反射波与入射波反相（π 相位跳变）：

ρ 区间几何侧z = √2/ρΓ 符号光学含义
1 ≤ ρ < √2内倒四面体成立（组①③）z > 1Γ > 0从光密射向光疏，无相位跳变
ρ = √2塌成一点z = 1Γ = 0完全匹配，无反射
ρ > √2直角顶落到四面体外（组④）z < 1Γ < 0从光疏射向光密，半波损失（π 跳变）
别读过头：几何上"翻到外面"与光学上"反相"只是同一个负号的两种解释。 不构成"四面体在反射光"，也不构成任何机制。这是形式对应，只能当记法用。

7. 边界：这套映射能用到哪、不能用到哪

项目能不能用说明
纯电阻性失配的读数（VSWR / RL / 反射率）可以本页全部读数属此列，代数恒等，无近似
单层 λ/4 抗反射膜的"匹配点"概念可以只借用 Γ=0 这一个条件，不涉及膜厚计算
真实器件的频率响应、带宽、损耗不行本几何给出的 Γ 是实数、与频率无关；真实 Γ(f) 是复数且随频率转圈
金属／有耗介质表面不行需要复阻抗 z = r+jx，本几何取不到虚部
把"空腔"直接当成一段传输线不行只能说"比例关系可以按反射系数来读"，不能说"它是传输线"
斜入射 / 偏振需扩展s、p 分量的 Fresnel 式含 cosθ，不再是单一 (a−x)/(a+x)
为什么这块"小"反而有用：整段几何只覆盖 Γ ∈ [0, 0.1716]，即 Smith 圆图实轴上的一小截。 正因如此，它天然落在"高回波损耗"区 —— 任何想用这套几何去描述强失配的尝试， 都会立刻跑到 ρ > √2（也就是"结构已经不成立"的那一侧）。几何的成立域与工程的良好匹配域，恰好是同一段。
