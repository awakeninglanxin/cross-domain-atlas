¹H–¹H 偶极耦合：20.6 kHz 从哪来，为什么 54.7356° 就没了

两个质子相距 1.8 Å（典型 CH₂）· 角因子 (3cos²θ−1)/2 · 静态粉末谱 → 魔角单晶 → MAS 边带 · 本页所有数字由页面现算，非引用实验数据

两个质子各带磁矩，会在对方位置上产生一个额外磁场。这个额外场沿 B₀ 的分量只有一个角度依赖：(3cos²θ−1)/2，其中 θ 是核间连线与 B₀ 的夹角。

θ = 0（连线平行 B₀）时因子 = 1，分裂最大；θ = 90° 时因子 = −1/2；而 θ = 54.7356° 时因子精确等于 0，分裂消失。整页要讲的就是这一条。

下面第一节可以拖动 θ，第二节是同一条曲线的全貌，第三节把「一个夹角」变成「一条谱」——这是核磁里真正被测量的对象。

二 · 角因子：一条曲线，一个零点

零点为什么正好是 54.7356°：令 3cos²θ = 1，得 cosθ = 1/√3，于是 tanθ = √2。也就是说，魔角就是立方体体对角线与棱的夹角（一个棱长为 1 的立方体，体对角线是 (1,1,1)，与 z 轴夹角余弦 1/√3）。白银比那边的 σ = 1+√2 只是同一件事的另一种写法，它并不参与这个零点。

一句必须说清的话：这里不需要白银比。cos²θ = 1/3 直接给出精确角，整数勾股三元组只能无限逼近、永远取不到（tanθ = √2 是无理数）。所以「用 Pell 三元组逼近魔角」没有任何工程价值 —— 直接算 arctan√2，精度是无穷位。反过来才有用：如果某实验在 54.74° 附近出现反常，那是 P₂ = 0 的功劳，不是 σ 的功劳。

三 · 谱：一个夹角如何变成一条 20 kHz 宽的鼓包

单晶只有一个 θ，谱上是两条锐线。粉末样品里每个晶粒的 θ 都不同，取向在空间均匀分布 ⇒ 无数条线叠起来，就成了下面这条静态粉末谱（Pake 双峰）。θ 的分布密度在 θ→90° 处趋于无穷（因为 cosθ 在 0 附近变化最慢），所以谱在 ±b/2 处堆出两个尖峰，而外缘 ±b 处是有限值、突然截断。

为什么边带间隔正好等于转速：旋转让角因子以频率 νr 周期变化，信号被频率 νr 调制，频谱上就出现以 νr 为间隔的一串分量。这不是巧合，是傅里叶变换的直接结果 —— 所以边带间隔可以用来反读转速：谱上量两个相邻边带差多少 kHz，转子就是多少 kHz（1 kHz = 1000 转/秒 = 60000 rpm）。本页的边带正是按这个规则画的。
