    哪些情况的比是「整数比」？—— 三条判据（带证明）

    判据一 · 凡「÷ 弦方」的比，永远是分数，一条整数都没有

    把弦方当作分母去看三种面积（内方 = (股−勾)²、天元数 = 2·勾·股、外方 = (勾+股)²）： 内方 / 弦方 = (股−勾)² / 弦² ∈ (0, 1)　·　 天元数 / 弦方 = 2·勾·股 / 弦² ∈ (0, 1)　·　 外方 / 弦方 = (勾+股)² / 弦² ∈ (1, 2) 证明：① 0 < 股−勾 < 弦 ⇒ 第一个比是真分数； ② 弦² − 2·勾·股 = (股−勾)² > 0 ⇒ 第二个比也在 (0,1)； ③ 外方 − 弦方 = 2·勾·股 > 0、且 2·弦² − 外方 = (股−勾)² > 0 ⇒ 第三个比严格落在 (1, 2)。 三个比值都卡在 0 与 1（或 1 与 2）之间，永远取不到整数分子 —— 这也解释了为什么「弦里弦外共天元」这句话只在面积层面成立，一写成比就再也回不到整数。 机械核验：弦 ≤ 1000 的全部 881 组（含整数倍），违反条数 0。

    判据二 · 凡「÷ 内方」的比，取整 ⟺ 股 − 勾 = 1（Pell 家族，别无他家）

    天元数 / 内方 = 2·勾·股 / (股−勾)²　·　 弦方 / 内方 = 弦² / (股−勾)²　·　 外方 / 内方 = (勾+股)² / (股−勾)² 证明：这三个比都是尺度不变量（勾、股、弦同乘 k，分子分母同乘 k² ⇒ 比值不变）， 所以只需讨论最简本原形（gcd(勾,股) = 1）。 ① 记 D = 股 − 勾。由 gcd(D, 勾) = gcd(股, 勾) = 1、gcd(D, 股) = gcd(勾, 股) = 1 得 gcd(D², 勾·股) = 1，于是 D² | 2·勾·股 ⟺ D² | 2 ⟺ D = 1（第一个比）； ② 弦方/内方 取整 ⟺ D² | 弦² ⟺ D | 弦 ⟹ D | 弦² = 勾² + 股² ≡ 2·勾² (mod D) ⟹ D | 2·勾²， 再配合 gcd(D, 勾) = 1 得 D | 2 ⇒ D = 1（第二个比；D = 2 虽满足 2 的幂，但此时勾、股同奇偶，与本原性矛盾）； ③ 外方/内方 取整 ⟺ D | (勾+股) ⟹ D | (勾+股) + (股−勾) = 2·股 且 D | 2·勾 ⟹ D | 2·gcd(勾,股) = 2 ⇒ D = 1（第三个比）。 三个比的方向不同、证法不同，最后全都落到同一条条件 股 − 勾 = 1 上 —— 而这条正是 Pell 方程 (2·勾+1)² − 2·弦² = −1。 机械核验：弦 ≤ 1000 的 881 组里，违反条数 0；「÷内方」取整的共 240 组（含倍数），更强的核验（弦 ≤ 2×10⁶、318 320 组）与完全分类见下方小节「Pell 家族 —— 完全穷举」， 全部是最简形为 3:4:5 / 20:21:29 / 119:120:169 / 696:697:985 … 的整数倍。

    判据三 · 其余六个方向 永不取整；能取整的只有「÷ 内方」这三条

    把六个「÷ 勾方 / ÷ 股方 / ÷ 外方 / ÷ 天元数」方向一并机械扫描（弦 ≤ 1000，881 组）： 内方/勾方、内方/股方、天元数/勾方、天元数/股方、外方/勾方、外方/股方、外方/天元数、天元数/外方、弦方/天元数 —— 取整条数全部 = 0。 证明：它们都要求 勾 | 股 或 股 | 勾 或 勾 | 2·股 之类；由 gcd(勾,股) = 1、股 > 勾 立即得 勾 = 1、股 = 2， 而 1² + 2² = 5 开不尽 ⇒ 整数勾股数里无解。（另：天元数/外方 与 弦方/天元数 一侧小于 1、一侧大于 1， 但 gcd(勾·股, 勾+股) = 1 同样封死了整除的可能。） 合起来一句话 —— 在整数勾股数这一族里，「能写成整数比」的路只有一条：把内方当分母。 而它又只有一个条件：股 − 勾 = 1，即 3 : 4 : 5 → 20 : 21 : 29 → 119 : 120 : 169 → 696 : 697 : 985 → 4059 : 4060 : 5741 → … （每一项 = 前一项 × (3 + 2√2) 附近，也就是 σ² = (1+√2)² 在勾股三边上的投影）。 这和三维页（`AAA四面体_主界面.html`）里「无分母 ⟺ 3 : 4 : 5 一整族」的结论互为印证 —— 3 : 4 : 5 同时是两边的第一条。

    第一步 · 把「股 − 勾 = 1」翻译成 Pell 方程

    勾 = a、股 = a + 1、弦 = c： a² + (a+1)² = c² ⟹ 2a² + 2a + 1 = c² ⟹ (2·勾+1)² − 2·弦² = −1 记 x = 2·勾+1、y = 弦，就是标准负 Pell 方程 x² − 2y² = −1。 于是「股 − 勾 = 1 的勾股数」与「Pell 方程的解」是同一件事，一一对应、不多不少。

    第二步 · 全部解 = (1+√2) 的奇次幂（"穷举"的合法性就来自这里）

    xk + yk√2 = (1+√2)2k+1　(k = 0, 1, 2, …) 为什么只有这些：① 若 x+y√2 是解，乘 3+2√2 = (1+√2)² 仍是解 （(3+2√2)(x+y√2) 的范数 = 1·(−1) = −1），所以幂序列全是解； ② 反之任一解乘 (1+√2)⁻² = (3−2√2) 仍是解且严格变小，反复下降必落到最小的正解 1+√2， 于是它只能是 (1+√2) 的奇次幂 —— 没有第 ③ 类解。 等价的一阶递推（下表就是照这个算的，纯整数、无浮点、无误差）： xk+1 = 6xk − xk−1　，　yk+1 = 6yk − yk−1， 起点 (x₀, y₀) = (1, 1) → (7, 5) → (41, 29) → (239, 169) → …

    第三步 · 为什么「外方 ÷ 内方」在这族里必然是整数 —— 以及它反过来锁死了这一族

    外方 ÷ 内方 = (勾+股)² / (股−勾)² 充分性（一算就懂）：股 − 勾 = 1 ⟹ 内方 = 1² = 1， 外方 = (勾+股)² 本身就是整数 ⇒ 商 = (勾+股)² = 2·弦² − 1，永远是整数。 必要性（反过来只有它）：记 D = 股 − 勾。要求 D² | (勾+股)²。 由 d² | s² ⟹ d | s 得 D | 勾+股；又 D | 股−勾，两者相加相减得 D | 2·股 且 D | 2·勾 ⟹ D | 2·gcd(勾,股)。 本原时 gcd = 1 ⟹ D | 2；而 D = 2 会让勾、股同奇偶（与 gcd = 1 矛盾）⟹ D = 1。 非本原时令 g = gcd(勾,股)、勾 = gA、股 = gB，条件化为 g(B−A) | 2g ⟹ B − A = 1，同上。 所以：能取整的 ⇔ 最简形是 Pell 家族成员，倍数 g 任意。 机械反查（欧几里得通项全枚举，不是抽样）： 弦 ≤ 2 000 000 的本原勾股数共 318 320 组，满足「外方÷内方 ∈ ℤ」的只有 8 组， 恰好就是下表的 k = 1…8，反例 0 条； 把整数倍也算进来共 4 181 998 组，满足判据的 483 247 组 = Σ⌊2·10⁶/弦⌋ over Pell，反例 0 条。

    倍数 g 不改比值 —— 以 3 : 4 : 5 为例
    一句话：「外方 ÷ 内方 是整数」把勾股数切成了一条射线套一条射线 —— 本原骨架只有 Pell 家族这一条（弦 5, 29, 169, 985, 5741, 33461, 195025, 1136689, …）， 每条骨架上再乘任意倍数 g；商只认骨架、不理 g（尺度不变量）。
    所以答案是：不止 2 个，是无穷多个，而且一个不多、一个不少 —— 就这一族。
    通项公式 —— 三种等价写法 · 以及「商」自己的三阶递推
    有，而且整族的通项只有一个源头：(1+√2)2k+1。 同一个序列可以写成三种等价式子，各有用处 —— 递推式（最好算，全程整数）、代数闭式（最短，一个 ⌊ ⌋ 从无理数直接落到整数）、 整数闭式（纯二项式系数，连 √2 都不出现）。三条都列在下面，并在页面里现算对账。
    先把否定的那一半说清：不存在「k 的多项式」通项。 本族按 5.8284…k 指数增长，任何多项式 km 去除它都趋于 0， 而序列本身趋于无穷，两者不可能相等。所以「通项」只能是指数型（线性递推型）， 这不是"没找到"，而是这一类序列的本质 —— 和费马数、Mersenne 数一样，只接受指数型闭式。

    写法一 · 递推式（纯整数，工程实现就用它）

    勾 ak+1 = 6·ak − ak−1 + 2　　　a1 = 3，a2 = 20 股 bk+1 = 6·bk − bk−1 − 2　　　b1 = 4，b2 = 21 弦 ck+1 = 6·ck − ck−1　　　　　c1 = 5，c2 = 29 系数 6 不是凑的：3 + 2√2 = (1+√2)² 是唯一的正单位（范数 +1）， 连乘两步在二阶递推里就表现为「迹 = 6、范数型常数 = −1」， 于是特征方程 r² − 6r + 1 = 0，两根 3 ± 2√2。 勾序列比别人多一个 +2（它是从 xk 里「减 1 再除 2」抠出来的）。 把常数项消掉就升成三阶，而且系数回文： ak+2 = 7ak+1 − 7ak + ak−1　，　特征多项式 r³ − 7r² + 7r − 1 = (r−1)(r² − 6r + 1) 多出来的那个根 r = 1，正是常数项 +2 留下的痕迹。

    写法二 · 代数闭式（最短：一个 ⌊ ⌋ 就够）

    勾 ak = ⌊ (1+√2)2k+1 / 4 ⌋ 勾 ak = [ (1+√2)2k+1 + (1−√2)2k+1 − 2 ] / 4　　（去掉 ⌊ ⌋ 的严格式） 股 bk = ak + 1 弦 ck = [ (1+√2)2k+1 − (1−√2)2k+1 ] / (2√2) ⌊ ⌋ 一定成立，可以证，不必试：记 S = (1+√2)2k+1、ε = −(1−√2)2k+1。 因 |1−√2| = 0.41421… < 1 且指数为奇数，所以 0 < ε < 1。由严格式 S/4 = ak + 0.5 + ε/4　，且 ε/4 < 0.25 故 S/4 ∈ (ak+0.5, ak+0.75) ⊂ (ak, ak+1)，取整必得 ak。 实测正是这个形状：k=1 → 3.5178，k=5 → 4059.50002，k=12 → 927538920.5000000000。 顺带得到一个显式误差项：ak 与连续近似 S/4 之差恒为 0.5 + ε/4， 而 ε 按 |1−√2|2k+1 指数衰减 —— k 越大，"差半个整数"就越精确。 这也是为什么大 k 时直接用浮点 S/4 四舍五入也不会错（误差 < 0.25）。

    写法三 · 整数闭式（把 √2 彻底消掉，只剩二项式系数）

    xk = Σj=0k C(2k+1, 2j)·2j　，　yk = Σj=0k C(2k+1, 2j+1)·2j 勾 = (xk − 1) / 2　，　股 = (xk + 1) / 2　，　弦 = yk 由 (1+√2)n = Σj C(n,j)·2j/2：j 偶 → 有理部，j 奇 → √2 部。 n = 2k+1 时正好收成两个纯整数有限和，这就是"完全没有无理数的闭式"， 也是理论推导时最有用的形式（证明"必为整数"完全不碰浮点）。
    例（k=2，n=5）：x = C(5,0)·1 + C(5,2)·2 + C(5,4)·4 = 1 + 20 + 20 = 41； y = C(5,1) + C(5,3)·2 + C(5,5)·4 = 5 + 20 + 4 = 29 ⇒ 20 : 21 : 29 ✓

    写法四 · 「外方 ÷ 内方」这个商自己的通项

    Nk = 外方 ÷ 内方 = (勾+股)² = (2·勾+1)² = xk2 = 2ck2 − 1 Nk = ⌊ (1+√2)4k+2 / 4 ⌋　　（与 ak 同一个函数，只是指数翻倍） Nk+2 = 35·Nk+1 − 35·Nk + Nk−1　　N0=1，N1=49，N2=1681 特征多项式 r³ − 35r² + 35r − 1 = (r−1)(r² − 34r + 1)，根 1 与 17 ± 12√2。 系数 1, −35, 35, −1 是回文（反幂等）的 —— 这是"单位根型"线性递推的标志， 也意味着 N 序列在 k ↔ −k 下对称。
    为什么是平方：内方 = (股−勾)² = 1² = 1，所以商就等于分子本身 = (股+勾)²。 这一句也解释了为什么"取整"在这族里毫无难度 —— 分母恒等于 1。     增长比：Nk+1/Nk → 17 + 12√2 = 33.970562… = (3+2√2)²。 倍数列 (gA, gB, gC) 的通项也就是把 A、B、C 各乘 g，N 完全不变 —— 通项对 g 无感。

    生成函数（整条序列压成一个分式）

    Σ xk zk = (1 + z) / (1 − 6z + z²) Σ ck zk = (1 − z) / (1 − 6z + z²) Σ ak zk = z(3 − z) / [(1 − z)(1 − 6z + z²)] 分母 (1 − 6z + z²) 与特征方程 r² − 6r + 1 一一对应； ak 多出来的那个 (1 − z) 因子，就是常数项 +2 的痕迹。

    增长率（量一量这条射线有多快）

    ak+1 / ak → 3 + 2√2 = 5.828427124746190… 每加一步，十进制位数 + log₁₀(3+2√2) = 0.76555… 弦 / 勾 → √2 = 1.41421356…　，　股 / 勾 → 1 实测：k = 50 时弦已 39 位，k = 100 时 77 位，k = 120 时 92 位 —— 增长不快不慢，恰好"永远够大、又永远算得动"。

    上机实现（BigInt，零浮点、零取整误差）

    通项在实际代码里不必真去算 (1+√2)n：一次乘单位就推进一格， 每步三次大整数乘加，k 到几百位也秒出，且全程精确： 
    // 第 k 条（k ≥ 1）：返回 [勾, 股, 弦] 的 BigInt 三元组
// 本质：连续乘 (3+2√2) k 次，取 (1+√2)^(2k+1) 的实部与 √2 部
function pellTriple(k){
  let x = 1n, y = 1n;              // x = 2·勾+1（有理部）,  y = 弦（√2 部）
  for (let i = 0; i < k; i++){      // (x + y√2)(3 + 2√2) = (3x+4y) + (2x+3y)√2
    const nx = 3n*x + 4n*y, ny = 2n*x + 3n*y;
    x = nx;  y = ny;
  }
  return [ (x - 1n)/2n, (x + 1n)/2n, y ];
}
// 恒等式自检（任取 k）：勾² + 股² === 弦² ，股 − 勾 === 1n
// k=100 时弦已是 77 位十进制数，BigInt 依旧精确。
    三种写法数学上恒等，但分工不同：递推式给计算机（无精度损耗）、 代数闭式给渐近估计（误差项 0.5+ε/4 显式可算）、 整数闭式给证明（"必然整数"不碰浮点）。
