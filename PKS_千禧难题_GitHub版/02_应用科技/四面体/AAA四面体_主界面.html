    判据一 · D外/D内 恒为无理数 ⟹ 「整数比」一条都没有

    比值 = (√2·勾 + 股) / (√2·勾 − 股)，分子分母都含 √2， 永远不可能写成两个整数之比（有理数）。 证明（两行）：设 (√2p+q)/(√2p−q) = r ∈ ℚ。若 r ≠ 1，则 (r−1)·√2·p = (r+1)·q ⟹ √2 = q(r+1) / [p(r−1)] ∈ ℚ，与 √2 无理矛盾； 若 r = 1 则 q = −q，不可能（q > 0）。∎

    判据二 · 「无分母」（C = 1）的情况恰好唯一：(勾, 股) = (3k, 4k)

    把最简式写成 (A + B√2) / C。则 C = 1  ⟺  (勾, 股) = (3k, 4k)（k = 1, 2, 3, …）， 此时 D外/D内 = 17 + 12√2 = (1+√2)⁴ = σ⁴ ≈ 33.9705627。 枚举印证：弦 ≤ 2000 的 500 条 C = 1 情况，100 % 是 3:4:5 的整数倍，别无他家。 证明（三步）：C = |2勾²−股²| 要同时整除 A = 2勾²+股² 与 B = 2勾股。 ① A − C = 2股²，C | A ⟹ C | 2股²；又 C | 2·勾·股。 ② 取 C 的奇素因子 s ⟹ s | 股 ⟹ 由 C = 2勾²−股² 得 s | 勾，与本原性矛盾 ⟹ C 只能是 2 的幂。 ③ 本原勾股数中 勾、股 一奇一偶：若 勾 奇 股 偶，则 C ≡ 2 (mod 4) ⟹ C = 2， 即 q² − 2p² = −2（Pell 型）；解 (3,4)、(17,24)、(99,140)… 其中只有 (3,4) 的弦 5 是整数。 若 勾 偶 股 奇，则 C 为奇数 ⟹ C = 1，即 q² − 2p² = −1；解 (1,1)、(5,7)、(29,41)… 而 p²+q² = 3p²−1 ≡ 2 (mod 3) 永不可能是完全平方 ⟹ 弦恒开不尽。∎
    所以：整数弦 + 无分母 两个条件的交点，有且只有 3-4-5 一个。

    判据三 · 「无分母」⟺ D外/D内 是 σ 的整数次幂（σ = 1+√2）

    判据五 · 商为有理数 ⟺ 商 = ±1 ⟹ 整数倍只可能是 1 或 −1

    记第 i 行的精确式 Vi = (Ai + Bi√2) / Ci， 其中 Ai = 2勾²+股²、Bi = 2勾股、Ci = 2勾²−股²（带符号）。 因为恒有 A² − 2B² = C²（分母平方，可约掉），所以
    V₁ / V₂ = [ (A₁A₂ − 2B₁B₂) + (B₁A₂ − A₁B₂)·√2 ] / (C₁C₂)
    证明：商是有理数 ⟺ 上式里 √2 的系数为零。把 A = 2勾²+股²、B = 2勾股 代进去因式分解：
    B₁A₂ − A₁B₂ = 2 · 勾₁勾₂ · (2勾₁勾₂ − 股₁股₂) · (股₁/勾₁ − 股₂/勾₂)
    其中 2·勾₁勾₂ ≠ 0，所以商要有理，只能让后面两个因子之一为零 —— 于是只有两条出路：
    ① 股₁/勾₁ = 股₂/勾₂（同一形状）⟹ V₁ = V₂（比值只依赖「股÷勾」这一个数）⟹ 商 = +1；
    ② 股₁股₂ = 2·勾₁勾₂（即 股₂/勾₂ = 2 ÷ (股₁/勾₁)，互为「2/r 搭档」）⟹ 商 = −1（推导见判据六）。
    有理数只可能是这两个值，而整数 ⊂ 有理数 ⟹ 商若为整数，只能 = ±1；想凑出 ×2、×3、×4 之类，数学上办不到。∎

    判据六 · ×(−1) 搭档的构造式：把「股 : 2·勾」约分即成（分子相同、分母变号）

    给定一行 勾 : 股，令 搭档 = (股 : 2·勾) ÷ gcd(股, 2勾)。它的「股÷勾」恰好是原来的 2/r， 两者乘积 = 2，商正好 = −1。 精确结构（已逐例核验 0 反例）：设 搭档 = λ·(股, 2勾)（λ 为有理数），则 A₂ = 2λ²A₁、B₂ = 2λ²B₁、而 C₂ = −2λ²C₁ —— 约分后写作：「分子一模一样，分母只是变号」。于是 V搭档 = −V原 精确成立， 两行的商 = −1。本页表格按 |C| 显示（不可内接那行取绝对值）， 所以这一对在表里会显示成完全相同的精确式与数值。

    判据七 · 为什么「整数弦」表里 ×(−1) 一对都找不到（Euler 1770）

    搭档也要是整数弦 ⟺ 存在本原勾股数 (勾, 股) = (m²−n², 2mn)，使 Q₁ = m⁴ − m²n² + n⁴ 或（勾、股两个角色对调时） Q₂ = m⁴ + 14m²n² + n⁴ 是完全平方。 关键恒等式：Q₂(m, n) = Q₁(m+n, m−n)（已数值验证无例外） ⟹ 两个式子一并归到 Euler 1770 年的经典结论：
    x⁴ − x²y² + y⁴ = z² 只有平凡解（x = y 或 xy = 0），标准证法是无穷递降； 见 Dickson《History of the Theory of Numbers》Vol. II, Ch. XXII（p.634 起）， Euler 在《代数》中陈述、1800 年代初补出证明。
    而 x = y ⟹ 勾 = 0、xy = 0 同样退化 ⟹ 非退化情形无解： 搭档永远不可能是整数弦。

    判据八 · 大的比值 ÷ 小的比值 = 整数？一对都没有 —— 不是「没找到」，是恒不成立

    问题：把大的那个 D外/D内 除以小的（商 > 1）， 会不会碰巧等于 2、3、4…？
    答：永远不会。两个不同形状的比值相除，商一定还带着 √2，是无理数。 商若要有理，只能落在 +1（两行同形状，含整数倍）或 −1（互为搭档）—— 这两种都不是「大 ÷ 小 的整数倍」。把「只看本原」打开后连 +1 都没有： 表里任意两行相除都不是整数。

    ② 两行相除，把含 √2 的项归拢到一起：
    V₁ / V₂ = [(r₁r₂ − 2) + (r₂ − r₁)·√2] / [(r₁r₂ − 2) − (r₂ − r₁)·√2]
    记 X = r₁r₂ − 2、Y = r₂ − r₁（都是有理数）， 有理化得 V₁/V₂ = (X² + 2Y² + 2XY√2) / (X² − 2Y²)。
    分子里的 2XY√2 要消失（商才有理），只能 X = 0 或 Y = 0：
    条件 含义 商
    Y = 0 r₁ = r₂ ⟺ 两行同形状（同一勾股形的整数倍） +1
    X = 0 r₁r₂ = 2 ⟺ 互为「2/r 搭档」（判据六） −1
    ⟹ 商 ∈ ℚ ⟹ 商 = ±1 ⟹ 商 > 1 的整数（2、3、4…）永远不存在。∎
    「含根号 2」正是要害：只要 r₁ ≠ r₂ 且 r₁r₂ ≠ 2，√2 就消不掉， 商必落在 ℚ(√2) ∖ ℚ 里 —— 那是无理数，永远不可能等于整数。

    存在条件（很重要）：股 / 勾 ≤ √2
    直角顶点的可行位置是「以棱为直径的球」∩ 四面体。可算出这条球与四面体的交线只在 勾 ≥ a/√3 时才存在 ⇒ 等价于 股/勾 ≤ √2 ≈ 1.41421，也等价于 三角形较大的锐角 ≤ arctan√2 = 54.7356°（正是四面体自己的「魔角」）。
    所以 5-12-13（股/勾 = 2.4）、8-15-17（1.875）、7-24-25（3.43）都超范围： 直角顶点落到四面体外面，这套嵌套结构压根不存在。硬代公式只会得到负值。
    极限与「塌缩」：股/勾 → √2 时比值 → ∞
    k = (√2 − λ)/(√2 + λ)（λ = 股/勾）。 当 λ → √2，分子 → 0，内倒四面体塌缩成一个点，比值发散。所以在 √2 附近 （3-4-5 的 1.333 就离得不远）比值极大 —— 33.97 这个「大数」正是这么来的。

    为什么 3-4-5 恰好落到 (1+√2) 的偶次幂？
    一个「偶次幂」家族：取 Pell 族 勾 : 股 = 1:1、3:4、5:7、17:24、29:41、99:140… （由 σ2m = x + y√2 反解得 股/勾 = 2y ∕ (x+1)），则 2R/2r = (1+√2)2m： m=1 → 1:1 给 (1+√2)²；m=2 → 3:4 给 (1+√2)⁴；m=3 → 5:7 给 (1+√2)⁶；m=4 → 17:24 给 (1+√2)⁸。
    3-4-5 的算理：(3√2+4)/(3√2−4) 有理化后分母 (3√2)² − 4² = 18 − 16 = 2，分子 34 + 24√2，约掉 2 得 17 + 12√2 —— 而 17² − 2·12² = 289 − 288 = 1，正是 Pell 方程 x²−2y²=1 的 (17,12)。
    Pell 层面：(1+√2)n = x + y√2 恰好枚举 x²−2y²=1 的全部解 —— n=1→(1,1)、2→(3,2)、3→(7,5)、4→(17,12)。 3-4-5 命中第 4 项，所以指数 = 4。
    半角 / 八边形层面：tan22.5° = √2 − 1、故 cot22.5° = 1 + √2 = σ（白银比）；正八边形的「长对角 ÷ 边」 也是 1+√2，其旋转步长恰为 45°。于是 σ 的幂就是这套 45° 系统的封闭形式。
