0. 一句话结论

设构成嵌套结构的直角三角形的两条直角边为

  • 勾 = P（短边）
  • 股 = Q（长边，Q ≥ P）
  • 弦 a = √(P² + Q²) ＝ 正四面体的棱长

则内倒四面体的棱长比与双球直径比只由「股 / 勾」这一个数决定：

k=2​P+Q2​P−Q​​2r2R​=k1​=2​P−Q2​P+Q​=2P2−Q22P2+Q2+22​PQ​​

成立前提（存在条件）：股 / 勾 ≤ √2，即较大锐角 ≤ arctan√2 = 54.7356…°，否则结构不存在。

反例（股/勾 > √2）怎么办？ 上面的式子分母变负，2R/2r 成为负数 —— 它不再表示「外球/内球」，而是表示「外球/同向内四面体」的棱长比 k 的一个负号版本。但只要把页面里画出的两个球按直径的绝对值相比，|2R / 2r| 仍然精确等于同一个通项式的绝对值（见 §3.1），并且照样是「开不尽」的无理数。所以通项公式在反例区依旧成立，只是几何含义从「倒插」换成「同向」。

3-4-5 只是代入 P=3、Q=4 的一个特例：

k=17−122​=(2​−1)4,2r2R​=17+122​=(1+2​)4=cot422.5∘.

2. 定理与推导

定理

绕顶点 Vₖ 的中轴 OVₖ 旋转 120°，会把「落在 Vₖ 三条棱上、从其余三个顶点出发的 3 条股腿」循环置换；因此配置是刚性的、只有一个自由标量 k，这 3 条股腿必交于轴上同一点

Pk​=O−k(Vk​−O),k=2​P+Q2​P−Q​.

4 条中轴给出 4 个交合点 P₀…P₃，两两距离都等于 k·a，恰构成一个倒置正四面体，棱长 b = k·a，其外接球半径 r = k·R。

推导（四步，全部闭式）

第 0 步：正四面体的三个基本量

对任意正四面体（棱长 a）：外接球半径 R = a√6/4；中心角满足（用余弦定理，两边都是 R、对边是 a）

cos∠Vk​OVx​=2R22R2−a2​=−31​,sin∠Vk​OVx​=322​​.

即常见的四面体角 109.4712…°。

第 1 步：交点在轴上（对称性）

两条股腿分别躺在 Πₖₓ 与 Πₖᵧ 内。两镜面的交线 = 二者公共的直线 VₖO（都含 Vₖ 与 O）。所以只要两条腿相交，交点必落在中轴 OVₖ 上。120° 旋转对称再把第 3 条腿拉进来，三者共点。

记这个点为 P_k = O − k(V_k − O)（k 待定；k = 0 表示塌到 O，k = 1 表示落到 Vₖ）。

最后，因为内倒四面体每个顶点都比 O 更靠近 Vₖ（k < 1），且 4 点两两距离 = k·a，内四面体外接球半径 r = k·R，于是

3. 存在条件（为什么 5-12-13 不行）

k > 0 要求 √2·P > Q，即

Q/P<2​≈1.41421.

更强的约束来自「直角顶点必须落在四面体内部」：折点在棱上的垂足位置要求

P≥3​a​⟺PQ​≤2​⟺较大锐角≤arctan2​=54.7356…∘.

这个 54.7356° 正是正四面体自身的「魔角」的一半关系（与二面角 70.5288°、中心角 109.4712° 同源）。

  • Q/P < √2：正常嵌套，0 < k < 1，内外两枚正四面体倒插（内四面体的顶点朝外棱中点方向）。
  • Q/P = √2：k = 0，内倒四面体塌缩为 O 一点，直径比发散到 +∞。
  • Q/P > √2：k < 0。12 枚三角形的直角顶点全部落到四面体外面（数值验证 0/12 在内），围合机制断裂，倒插结构不存在；内四面体由「倒插」变为同向（棱长仍恰为 |k|·a，见 §3.2）。

不存在组：5-12-13（2.4）、8-15-17（1.875）、7-24-25（3.4286）、9-40-41（4.4444）、3-5-√34（1.6667）、7-10-√149（1.4286，仅差一点仍越界）……

3.1 反例照样能算出直径比 —— 它满足通项公式的「绝对值」

虽然三角形围不成倒插结构，但 P = O − k(Vₖ − O)（k 为负）这个点仍然在轴上，4 个这样的点仍然是同向的、棱长恒为 |k|·a 的正四面体顶点（§3.2 有数值验证）。把两球半径取绝对值：

​2r2R​​=​k1​​=​2​P−Q​2​P+Q​=∣2P2−Q2∣2P2+Q2+22​PQ​(Q/P>2​).

这个数的性质（与正例完全同类，只是分子带负号被绝对值抹掉）：

  • 它是 ℚ(√2) 中的数，形状 (A + B√2)/C，不含任何其它根号（只有 √2 一个开方）；
  • 它的 √2 系数是 B = 2PQ > 0，永远不为零 ⇒ 恒为无理数，永远「开不尽」。这就是老师要的那种「有趣的含开方开不尽的数」—— 每一组勾股数都给出一个 (整数 + 整数·√2)/整数 的封闭形式。
  • 反对称性（反例 ↔ 正例的桥梁）：由 |(√2+x)/(√2−x)| = (√2+y)/(√2−y) ⟺ xy = 2，得
    ​ratio(PQ​)​=ratio(Q2P​).

    也就是把「股/勾」换成它的「2 倍倒数」对偶 2P/Q。举例：3:5（股/勾 = 5/3）↔ 5:6（股/勾 = 6/5，因 (5/3)(6/5) = 2），两者 |2R/2r| 同为 12.2038；7:10（10/7）↔ 5:7（7/5），同为 197.9949。只要 1 < 股/勾 < 2，它的对偶就 ≥ 1，正好落回正例表（5:12、7:24、9:40 的股/勾都 > 2，对偶 < 1，就找不到正例伙伴了，只能留在反例区）。

  • 值域对偶：正例区比值 ∈ [5.8284, +∞)，反例区 ∈ (1, +∞)。反例区把 (1, +∞) 整个铺满（股/勾 → ∞ ⇒ → 1⁺，股/勾 → √2⁺ ⇒ → +∞）。⇒ 任何大于 1 的实数，都能被某一组勾股数实现为两球直径比（结构是否成立另说）。

3.2 为什么反例不是「整体消失」而是「同向」

数值复算（meet.js，与页面同一套三维构造）确认：当 k < 0 时，

  • 从三个相邻顶点出发、长 = 股的 12 条股腿仍然全部穿过 O + k(V − O)（12/12 命中，偏差 ≤ 1e−15）；
  • 12 条股腿共点后，相邻顶点 PᵢPⱼ 的距离精确等于 |k|·a（六棱全部等长）；
  • 唯一的变化是：那 12 枚直角顶点从「落在四面体内」变成「全部落在四面体外」（0/12 在内）。

也就是说，股腿的共点结构和等边结构都保住了，坏的只是「直角顶点要落在体内」这一条围合条件。于是内四面体不再倒插、而是与外四面体同向，此时 |b| = |k|·a 仍然是它真实的棱长，|2R/2r| = |1/k| 仍然是真实的直径比。

5. 极限行为

Q/P→2​⟹k=2​+Q/P2​−Q/P​→0,2r2R​→∞.

例如 P=1000、Q=1414（股/勾 = 1.4140，已逼近 √2）：k ≈ 7.551×10⁻⁵，比值 ≈ 1.324×10⁴。而股/勾 → 1（等腰直角三角形）时 k → (√2−1)² = 3−2√2，比值降到最小可能值 (1+√2)² = 5.8284。

所以（正例区）比值范围是 [ (1+√2)² , +∞ )，下界在 1:1 取得。

若把反例也纳入（结构不成立、但 |2R/2r| 仍可算，见 §3.1），函数在 股/勾 = √2 处有一条竖直渐近线：左侧（正例）从 +∞ 落到下界 5.8284（在 1:1 处），右侧（反例）从 +∞ 一路降到 1⁺（股/勾 → ∞）。两段合起来，只要 股/勾 > 0（且 ≠ √2），|2R/2r| 就能取遍 (1, +∞) 的每一个值 —— 而它们都落在 ℚ(√2) 里，恒为「开不尽」的无理数。

用对偶式 \|ratio(x)\| = ratio(2/x) 看更清楚：反例下半段 x ∈ (√2, ∞) 的像 2/x ∈ (0, √2)，正是正例上半段的参数区间；x → √2⁺ 与 2/x → √2⁻ 两头都发散到 +∞，所以渐近线两侧是「镜像」的。

10. 两行之间相除能得整数吗？—— 只有 ×1 与 ×(−1)

前面 §6.3 问的是「单独一行的比值是不是有理数（整数比）」，答案是「一条都没有」。这里问的是一个新问题：把表里两行相除，V_i / V_j 能不能是整数？（老师的原话：「有没有可能这里面有一对是整数倍关系，比如 #32 的 (D外/D内) 除以 #1 的 (D外/D内) 等于整数？」）

10.1 判据五 · 商若为有理数，只能是 +1 或 −1

记带符号精确式

V(勾,股) = (A + B√2) / C ,   A = 2勾² + 股² ,  B = 2勾股 ,  C = 2勾² − 股²

（C 可负：股/勾 > √2 时 C < 0，即「不可内接」那一类；页面表格显示时取 |C|。）

恒等式：A² − 2B² = C²（把 (2勾²+股²)² − 2(2勾股)² 展开即得）⟹ 可直接有理化：

V₁ / V₂ = [ (A₁A₂ − 2B₁B₂) + (B₁A₂ − A₁B₂)·√2 ] / (C₁C₂)

判据五：V₁/V₂ ∈ ℚ ⟺ V₁/V₂ ∈ {+1, −1}。

证明：商为有理数 ⟺ 上式 √2 的系数为零。代入 A = 2勾²+股²、B = 2勾股 因式分解（已对 1 ≤ 勾 ≤ 59 的全部有序对数值核对，0 反例）：

B₁A₂ − A₁B₂ = 2 · 勾₁勾₂ · (股₁/勾₁ − 股₂/勾₂) · (2勾₁勾₂ − 股₁股₂)

其中 2勾₁勾₂ ≠ 0，所以只能让后面两个因子之一为零：

情形条件商几何含义
①股₁/勾₁ = 股₂/勾₂+1同一形状（互为整数倍，如 3:4:5 与 6:8:10）
②股₁股₂ = 2·勾₁勾₂（即 股₂/勾₂ = 2 ÷ (股₁/勾₁)）−1互为「2/r 搭档」（见 10.2）

有理数只有这两个取值，而 整数 ⊂ 有理数 ⟹ 商若为整数，只能等于 ±1； 想凑出 ×2、×3、×4 这样的倍数，数学上办不到。∎

10.2 判据六 · ×(−1) 搭档的构造式：(股 : 2·勾) 约分即成

给定一行 勾 : 股，取

搭档 = (股 : 2·勾) ÷ gcd(股, 2勾)

它的「股÷勾」恰好是原来的 2/r，两者乘积 = 2，商 = −1。精细结构（0 反例）：把搭档写成 λ·(股, 2勾)（λ 为有理数），则

A₂ = 2λ²A₁ ,   B₂ = 2λ²B₁ ,   C₂ = −2λ²C₁

即约分后：分子一模一样，分母只是变号。所以

V(搭档) = − V(原形状)     精确成立（不是近似）

页面上看起来是「两行完全相同」：因为表格按 |C| 显示（不可内接那行取绝对值），正负号被抹掉，两行的精确式与数值显示成同一个数。

方向的限制：只有当 股/勾 ≤ 2 时，搭档才仍是「股 ≥ 勾」的形状（1 ≤ r ≤ 2）。 r > 2（如 5:12、7:24）时搭档会翻进「股 < 勾」的镜像，本表约定下没有搭档行。

10.3 判据七 · 为什么「整数弦」表里一对都找不到（Euler 1770）

搭档也要是整数弦 ⟺ 存在本原勾股数 (勾, 股) = (m²−n², 2mn)（m > n ≥ 1、gcd = 1、m−n 为奇），使

Q₁ = m⁴ − m²n² + n⁴            （勾 = m²−n², 股 = 2mn 的情形）
Q₂ = m⁴ + 14m²n² + n⁴          （勾 = 2mn, 股 = m²−n² 的情形）

是完全平方。

关键恒等式：Q₂(m, n) = Q₁(m+n, m−n)（数值核对 0 反例，例如 Q₂(2,1) = 73 = Q₁(3,1)）。于是两式一并归到 Euler 1770 年的经典结论：

x⁴ − x²y² + y⁴ = z² 只有平凡解：x = y 或 xy = 0。 Euler 在《代数》中陈述、1800 年代初补出证明，标准证法是无穷递降；见 L. E. Dickson, History of the Theory of Numbers, Vol. II, Ch. XXII（p. 634 起）。

10.6 判据八（2026-10-15 补）· 「大 ÷ 小」也一对都没有

问题（老师）：把大的那个 D外/D内 除以小的（商 > 1），会不会碰巧等于 2、3、4…？ 答：不会。 而且是「恒不成立」，不是「还没找到」。

更简的写法（莫比乌斯形）：记 r = 股 / 勾（有理数），则

V(r) = D外/D内 = (r + √2) / (r − √2)

两行相除，把含 √2 的项归拢到一起：

V₁ / V₂ = [(r₁r₂ − 2) + (r₂ − r₁)·√2] / [(r₁r₂ − 2) − (r₂ − r₁)·√2]

记 X = r₁r₂ − 2、Y = r₂ − r₁（都是有理数），有理化得

V₁/V₂ = (X² + 2Y² + 2XY√2) / (X² − 2Y²)

条件含义商

X = 0r₁r₂ = 2 ⟺ 互为「2/r 搭档」（判据六）−1

⟹ 商 ∈ ℚ ⟹ 商 = ±1 ⟹ 商 > 1 的整数（2、3、4…）永远不存在。∎
