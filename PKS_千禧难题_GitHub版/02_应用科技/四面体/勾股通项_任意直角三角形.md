## 0. 一句话结论

设构成嵌套结构的直角三角形的两条直角边为

- **勾 = P**（短边）
- **股 = Q**（长边，Q ≥ P）
- 弦 **a = √(P² + Q²)** ＝ 正四面体的棱长

则内倒四面体的棱长比与双球直径比只由「股 / 勾」这一个数决定：

$$\boxed{\;k=\frac{\sqrt{2}\,P-Q}{\sqrt{2}\,P+Q}\;}\qquad
\boxed{\;\frac{2R}{2r}=\frac{1}{k}=\frac{\sqrt{2}\,P+Q}{\sqrt{2}\,P-Q}
=\frac{2P^{2}+Q^{2}+2\sqrt{2}\,PQ}{2P^{2}-Q^{2}}\;}$$

**成立前提（存在条件）：股 / 勾 ≤ √2，即较大锐角 ≤ arctan√2 = 54.7356…°**，否则结构不存在。

> **反例（股/勾 > √2）怎么办？** 上面的式子分母变负，`2R/2r` 成为负数 —— 它不再表示「外球/内球」，而是表示「外球/同向内四面体」的**棱长比 k 的一个负号版本**。但只要把页面里画出的两个球按**直径的绝对值**相比，`|2R / 2r|` **仍然精确等于同一个通项式的绝对值**（见 §3.1），并且**照样是「开不尽」的无理数**。所以通项公式在反例区依旧成立，只是几何含义从「倒插」换成「同向」。

3-4-5 只是代入 P=3、Q=4 的一个特例：

$$k=17-12\sqrt2=(\sqrt2-1)^4,\qquad \frac{2R}{2r}=17+12\sqrt2=(1+\sqrt2)^4=\cot^4 22.5^\circ .$$

## 2. 定理与推导

### 定理

绕顶点 Vₖ 的中轴 OVₖ 旋转 120°，会把「落在 Vₖ 三条棱上、从其余三个顶点出发的 3 条股腿」循环置换；因此配置是刚性的、只有一个自由标量 k，**这 3 条股腿必交于轴上同一点**

$$P_k = O - k\,(V_k - O),\qquad k=\frac{\sqrt{2}P-Q}{\sqrt{2}P+Q}.$$

4 条中轴给出 4 个交合点 P₀…P₃，两两距离都等于 k·a，恰构成一个**倒置正四面体**，棱长 b = k·a，其外接球半径 r = k·R。

### 推导（四步，全部闭式）

**第 0 步：正四面体的三个基本量**

对任意正四面体（棱长 a）：外接球半径 R = a√6/4；中心角满足（用余弦定理，两边都是 R、对边是 a）

$$\cos\angle V_kOV_x=\frac{2R^2-a^2}{2R^2}=-\frac13,\qquad \sin\angle V_kOV_x=\frac{2\sqrt2}{3}.$$

即常见的四面体角 109.4712…°。

**第 1 步：交点在轴上（对称性）**

两条股腿分别躺在 Πₖₓ 与 Πₖᵧ 内。两镜面的交线 = 二者公共的直线 **VₖO**（都含 Vₖ 与 O）。所以只要两条腿相交，交点必落在中轴 OVₖ 上。120° 旋转对称再把第 3 条腿拉进来，三者共点。

记这个点为 P_k = O − k(V_k − O)（k 待定；k = 0 表示塌到 O，k = 1 表示落到 Vₖ）。

**第 2 步：两点距离的闭式**

以 Vₖ 的轴为参照，对任一 x ≠ k：

$$|P_k-V_x|^2=\big|{-k(V_k-O)-(V_x-O)}\big|^2
=R^2\Big(1-\frac{2k}{3}+k^2\Big)
=\frac{a^2}{8}\big(3-2k+3k^2\big).$$

（用到 u·v = −R²/3，u = Vₖ−O，v = Vₓ−O。）

**第 3 步：令腿长吻合，解出 k**

自 Vₓ 出发、沿方向指向 P_k、长度为 **股 = Q** 的腿，其远端

$$A=V_x+Q\cdot\frac{P_k-V_x}{|P_k-V_x|}.$$

要求 △VₖVₓA 就是那枚镜面内的直角三角形，即 |A − Vₖ| = **勾 = P**。记 L = |P_k − Vₓ|，展开：

$$|A-V_k|^2=a^2+\frac{a^2Q}{L}(k-1)+Q^2=P^{2}=a^{2}-Q^{2}$$

$$\Longrightarrow\quad L=\frac{a^2(1-k)}{2Q}.$$

两边平方并令 s = Q²/a²：

$$2(1-k)^2=s\,\big(3-2k+3k^2\big)\quad\Longrightarrow\quad
\boxed{(2-3s)\,k^{2}+(2s-4)\,k+(2-3s)=0}$$

**第 4 步：两根恰互为倒数**

上式 k² 项与常数项系数相同 ⇒ 若 k 是根，则 1/k 也是根。取 k < 1 的那一根：

$$k=\frac{(2-s)-2\sqrt{2s(1-s)}}{2-3s}
=\frac{2P^{2}+Q^{2}-2\sqrt{2}\,PQ}{2P^{2}-Q^{2}}
=\frac{\big(\sqrt{2}P-Q\big)^{2}}{2P^{2}-Q^{2}}
=\frac{\sqrt{2}P-Q}{\sqrt{2}P+Q}.$$

而**另一根**就是

$$\frac1k=\frac{\sqrt{2}P+Q}{\sqrt{2}P-Q}=\frac{2R}{2r}.$$

> 这是本通项最漂亮的一点：**「内倒棱长比 k」与「双球直径比 2R/2r」本来就是同一个二次方程的两根**，天然互为倒数。它解释了为什么 3-4-5 的答案 (1+√2)⁴ 与棱长比 (√2−1)⁴ 互为倒数。

最后，因为内倒四面体每个顶点都比 O 更靠近 Vₖ（k < 1），且 4 点两两距离 = k·a，内四面体外接球半径 r = k·R，于是

$$\frac{2R}{2r}=\frac{R}{r}=\frac1k .$$

## 3. 存在条件（为什么 5-12-13 不行）

k > 0 要求 √2·P > Q，即

$$Q/P<\sqrt2\approx1.41421 .$$

更强的约束来自「直角顶点必须落在四面体内部」：折点在棱上的垂足位置要求

$$P\ge \frac{a}{\sqrt3}\iff \frac QP\le\sqrt2\iff \text{较大锐角}\le\arctan\sqrt2=54.7356\ldots^\circ .$$

这个 54.7356° 正是正四面体自身的「魔角」的一半关系（与二面角 70.5288°、中心角 109.4712° 同源）。

- **Q/P < √2**：正常嵌套，0 < k < 1，内外两枚正四面体**倒插**（内四面体的顶点朝外棱中点方向）。
- **Q/P = √2**：k = 0，内倒四面体塌缩为 O 一点，直径比发散到 +∞。
- **Q/P > √2**：k < 0。12 枚三角形的直角顶点**全部落到四面体外面**（数值验证 0/12 在内），围合机制断裂，**倒插结构不存在**；内四面体由「倒插」变为**同向**（棱长仍恰为 |k|·a，见 §3.2）。

**不存在组**：5-12-13（2.4）、8-15-17（1.875）、7-24-25（3.4286）、9-40-41（4.4444）、3-5-√34（1.6667）、7-10-√149（1.4286，仅差一点仍越界）……

### 3.1 反例照样能算出直径比 —— 它满足通项公式的「绝对值」

虽然三角形围不成倒插结构，但 `P = O − k(Vₖ − O)`（k 为负）这个点**仍然在轴上**，4 个这样的点仍然是**同向**的、棱长恒为 `|k|·a` 的正四面体顶点（§3.2 有数值验证）。把两球半径取绝对值：

$$\left|\frac{2R}{2r}\right|=\left|\frac{1}{k}\right|=\frac{\sqrt2\,P+Q}{\left|\sqrt2\,P-Q\right|}
=\frac{2P^{2}+Q^{2}+2\sqrt2\,PQ}{\left|\,2P^{2}-Q^{2}\,\right|}\qquad(Q/P>\sqrt2).$$

**这个数的性质**（与正例完全同类，只是分子带负号被绝对值抹掉）：

- 它是 `ℚ(√2)` 中的数，形状 `(A + B√2)/C`，**不含任何其它根号**（只有 √2 一个开方）；
- 它的 √2 系数是 `B = 2PQ > 0`，**永远不为零** ⇒ **恒为无理数**，永远「开不尽」。这就是老师要的那种「有趣的含开方开不尽的数」—— 每一组勾股数都给出一个 `(整数 + 整数·√2)/整数` 的封闭形式。
- **反对称性（反例 ↔ 正例的桥梁）**：由 `|(√2+x)/(√2−x)| = (√2+y)/(√2−y) ⟺ xy = 2`，得
  $$\left|\operatorname{ratio}\!\left(\tfrac{Q}{P}\right)\right|=\operatorname{ratio}\!\left(\tfrac{2P}{Q}\right).$$
  也就是把「股/勾」换成它的**「2 倍倒数」对偶** `2P/Q`。举例：3:5（股/勾 = 5/3）↔ 5:6（股/勾 = 6/5，因 (5/3)(6/5) = 2），两者 \|2R/2r\| 同为 12.2038；7:10（10/7）↔ 5:7（7/5），同为 197.9949。**只要 1 < 股/勾 < 2，它的对偶就 ≥ 1，正好落回正例表**（5:12、7:24、9:40 的股/勾都 > 2，对偶 < 1，就找不到正例伙伴了，只能留在反例区）。
- **值域对偶**：正例区比值 ∈ `[5.8284, +∞)`，反例区 ∈ `(1, +∞)`。反例区把 `(1, +∞)` **整个铺满**（`股/勾 → ∞ ⇒ → 1⁺`，`股/勾 → √2⁺ ⇒ → +∞`）。⇒ **任何大于 1 的实数，都能被某一组勾股数实现为两球直径比**（结构是否成立另说）。

### 3.2 为什么反例不是「整体消失」而是「同向」

数值复算（`meet.js`，与页面同一套三维构造）确认：当 k < 0 时，

- 从三个相邻顶点出发、长 = 股的 **12 条股腿仍然全部穿过** `O + k(V − O)`（12/12 命中，偏差 ≤ 1e−15）；
- 12 条股腿共点后，相邻顶点 PᵢPⱼ 的距离**精确等于 |k|·a**（六棱全部等长）；
- 唯一的变化是：那 12 枚**直角顶点**从「落在四面体内」变成「全部落在四面体外」（0/12 在内）。

也就是说，**股腿的共点结构和等边结构都保住了**，坏的只是「直角顶点要落在体内」这一条围合条件。于是内四面体不再倒插、而是**与外四面体同向**，此时 `|b| = |k|·a` 仍然是它真实的棱长，`|2R/2r| = |1/k|` 仍然是真实的直径比。

## 4. σ（白银比）偶次幂家族

令 σ = 1+√2，记 σ^(2m) = x + y√2（Pell 方程 x² − 2y² = 1 的解）。由通项式反解 股/勾：

$$\frac{Q}{P}=\frac{2y}{x+1}\ \ \text{(约至最简)} .$$

于是 **2R/2r 恰为 σ 的偶次幂**，家族是：

| m | 勾 : 股 : 弦 | 2R / 2r = σ^(2m) | 数值 |
|------|------|------|------|
| 1 | 1 : 1 : √2 | 3 + 2√2 | 5.82842712 |
| 2 | 3 : 4 : 5 | 17 + 12√2 | 33.97056275 |
| 3 | 5 : 7 : √74 | 99 + 70√2 | 197.99494937 |
| 4 | 17 : 24 : √865 | 577 + 408√2 | 1153.99913285 |
| 5 | 29 : 41 : √2522 | 3363 + 2378√2 | 6725.99985135 |
| 6 | 99 : 140 : √29401 | 19601 + 13860√2 | 39201.99997449 |
| 7 | 169 : 239 : √85682 | 114243 + 80782√2 | 228485.99999573 |

推导要点：

- σ^(2m) = (x+y√2) 给出 Pell 方程 x² − 2y² = 1 的**全部**解；(1+√2)ⁿ 只取偶数次幂才落回「勾、股 为整数比」这一族（奇次幂给出的比值是 (整数)+√2 的形式，不对应任何勾股形）。
- 由 r = √2(σ^m − σ^(−m))/(σ^m + σ^(−m)) 化简即得 r = 2y/(x+1)。
- **该家族全部满足 股/勾 < √2**：因为 (2y)² = 2x² − 2 < 2(x+1)² = (√2(x+1))² 恒成立（等价于 −2 < 4x+2）。所以 m 可以任意大，越往后 股/勾 → √2、k → 0。
- 22.5° = 45°/2，且 cot 22.5° = 1+√2 = σ，故 2R/2r = cot^(2m) 22.5°。
- 注意 **m 与勾股形不是「(2m−1) : (3m−2)」这种等差数列**：m=1,2,3 时恰好等于 1:1、3:4、5:7，但 m=4 是 17:24（不是 7:10，7:10 的股/勾 = 1.4286 > √2，结构不存在）。
- 一般勾股形（如 4:5、20:21、119:120）不落在这一族里，但**通项式依然精确成立**，结果是有理数域 Q(√2) 中的元素 (A + B√2)/C。

## 5. 极限行为

$$Q/P\to\sqrt2 \;\Longrightarrow\; k=\frac{\sqrt2-Q/P}{\sqrt2+Q/P}\to0,\qquad \frac{2R}{2r}\to\infty .$$

例如 P=1000、Q=1414（股/勾 = 1.4140，已逼近 √2）：k ≈ 7.551×10⁻⁵，比值 ≈ 1.324×10⁴。而股/勾 → 1（等腰直角三角形）时 k → (√2−1)² = 3−2√2，比值降到最小可能值 (1+√2)² = 5.8284。

所以**（正例区）比值范围是 [ (1+√2)² , +∞ )，下界在 1:1 取得**。

> 若把反例也纳入（结构不成立、但 \|2R/2r\| 仍可算，见 §3.1），函数在 `股/勾 = √2` 处有一条**竖直渐近线**：左侧（正例）从 `+∞` 落到下界 5.8284（在 1:1 处），右侧（反例）从 `+∞` 一路降到 `1⁺`（股/勾 → ∞）。两段合起来，**只要 股/勾 > 0（且 ≠ √2），\|2R/2r\| 就能取遍 `(1, +∞)` 的每一个值** —— 而它们都落在 `ℚ(√2)` 里，恒为「开不尽」的无理数。
>
> 用对偶式 `\|ratio(x)\| = ratio(2/x)` 看更清楚：反例下半段 `x ∈ (√2, ∞)` 的像 `2/x ∈ (0, √2)`，正是正例上半段的参数区间；`x → √2⁺` 与 `2/x → √2⁻` 两头都发散到 +∞，所以渐近线两侧是「镜像」的。

### 6.3 三条判据：「哪些情况的比是整数比？」

**一句话结论：真正的「整数比」（有理数）一条都没有，而且可以证明；「无分母」的情况则恰好唯一 —— 3 : 4 : 5 一整族。**

**判据一 · D外/D内 恒为无理数 ⇒「整数比」一条都没有。**

记 `r = (√2·勾 + 股)/(√2·勾 − 股)`。若 r 为有理数：r = 1 会要求 股 = 0，不可能；
r ≠ 1 时可反解 `√2 = 股·(r+1) / [勾·(r−1)]`，右边是有理数、左边是无理数 —— 矛盾。
（等价说法：最简式 `(A + B√2)/C` 里 `B = 2·勾·股 ≠ 0`，所以比值必是 ℤ[√2] 中的二次无理数。）
**实测：弦 ≤ 2000 的全部 885 条可内接情况，D外/D内 为有理数的有 0 条。**

**判据二 ·「无分母」（C = 1）恰好唯一：(勾, 股) = (3k, 4k)。**

证明三步（C = |2勾² − 股²| 必须同时整除 A = 2勾² + 股² 与 B = 2·勾·股）：

1. A − C = 2股²，C | A ⇒ C | 2股²；又 C | 2·勾·股；
2. 取 C 的奇素因子 s ⇒ s | 股 ⇒ 再由 C = 2勾² − 股² 得 s | 勾，与本原性矛盾 ⇒ **C 只能是 2 的幂**；
3. 本原勾股数中 勾、股 一奇一偶：
   - **勾奇股偶** ⇒ C ≡ 2 (mod 4) ⇒ C = 2，即 `股² − 2勾² = −2`（Pell 型），
     解 (3,4)、(17,24)、(99,140)、(577,816)… 其中**只有 (3,4) 的弦 5 是整数**；
   - **勾偶股奇** ⇒ C 为奇数 ⇒ C = 1，即 `股² − 2勾² = −1`，解 (1,1)、(5,7)、(29,41)…
     此时 `弦² = 勾² + 股² = 3勾² − 1 ≡ 2 (mod 3)`，**永远不可能是完全平方** ⇒ 弦恒开不尽。

## 9. 姊妹页：二维赵爽弦图的六个比 → 「哪些比是整数比」

三维页（§6.3）问的是「D外/D内 哪些是整数比」，答案：**一条都没有，但「无分母」唯一是 3 : 4 : 5 一族**。
二维页（`AAA勾股弦外之音_演示.html`）问的是同一类问题的另一半 —— 赵爽弦图里有四个面积量：

$$\text{内方}=(股-勾)^2,\qquad \text{天元数}=2\cdot 勾\cdot 股,\qquad
\text{外方}=(勾+股)^2,\qquad \text{弦方}=勾^2+股^2$$

它们之间只有两条关系（就是本页两条恒等式）：`弦方 = 天元数 + 内方`、`外方 = 弦方 + 天元数`。
两两相除共十二个方向，机械扫描（弦 ≤ 1000 的全部 881 组，含整数倍）后规律**收敛得极干净**：

| 方向 | 取整条数 | 结论 |
|------|------|------|
| ÷ 弦方（内方/弦方、天元数/弦方、外方/弦方） | 0 | **永远是分数**：分别 ∈ (0,1)、(0,1)、(1,2) |
| ÷ 内方（天元数/内方、弦方/内方、外方/内方） | 240 | **取整 ⟺ 股 − 勾 = 1** |
| ÷ 勾方 / ÷ 股方 / ÷ 外方 / ÷ 天元数（九条） | 0 | **永不取整** |

### 9.1 判据一 · ÷ 弦方的三个比永远是分数

- `内方/弦方 = (股−勾)²/弦²`：由 `0 < 股−勾 < 弦` ⇒ 真分数；
- `天元数/弦方 = 2·勾·股/弦²`：由 `弦² − 2·勾·股 = (股−勾)² > 0` ⇒ 也在 (0,1)；
- `外方/弦方 = (勾+股)²/弦²`：由 `外方 − 弦方 = 2·勾·股 > 0` 且 `2·弦² − 外方 = (股−勾)² > 0` ⇒ 严格落在 (1,2)。

⇒ **三个比都卡死在 0 与 1（或 1 与 2）之间，永远取不到整数**。
「弦里弦外共天元」这句话只在**面积**层面成立，一写成比就再也回不到整数。

### 9.2 判据二 · ÷ 内方的三个比取整 ⟺ 股 − 勾 = 1

关键观察：**这三个比都是尺度不变量** —— 勾、股、弦同乘 k，分子分母同乘 k²，比值一字不变。
所以只需讨论最简本原形（`gcd(勾,股) = 1`）。记 `D = 股 − 勾`：

1. `天元数/内方 = 2·勾·股 / D²`：由 `gcd(D, 勾) = gcd(股, 勾) = 1`、`gcd(D, 股) = gcd(勾, 股) = 1` 得
   **`gcd(D², 勾·股) = 1`**，于是 `D² | 2·勾·股 ⟺ D² | 2 ⟺ D = 1`；
2. `弦方/内方 = 弦² / D²`：取整 ⟺ `D | 弦` ⟹ `D | 弦² = 勾² + 股² ≡ 2·勾² (mod D)` ⟹ `D | 2·勾²`，
   配合 `gcd(D, 勾) = 1` 得 `D | 2 ⟹ D = 1`（D = 2 虽满足「整除 2」，但此时勾、股同奇偶，与本原性矛盾）；
3. `外方/内方 = (勾+股)² / D²`：取整 ⟺ `D | (勾+股)` ⟹ `D | (勾+股) + (股−勾) = 2·股` 且 `D | 2·勾`
   ⟹ `D | 2·gcd(勾,股) = 2 ⟹ D = 1`。

**三个比方向不同、证法不同，最后全都落到同一条条件 `股 − 勾 = 1` 上** —— 而这条正是
Pell 方程 `(2·勾 + 1)² − 2·弦² = −1`。它的解序列就是：

| # | 勾 : 股 : 弦 | 天元数 ÷ 内方 | 弦方 ÷ 内方 | 外方 ÷ 内方 | 外方 − 内方 |
|------|------|------|------|------|------|
| 1 | 3 : 4 : 5 | 24 | 25 | 49 | 48 |
| 2 | 20 : 21 : 29 | 840 | 841 | 1681 | **1680** ★ = Anu 螺旋线匝数 |
| 3 | 119 : 120 : 169 | 28560 | 28561 | 57121 | 57120 |
| 4 | 696 : 697 : 985 | 970224 | 970225 | 1940449 | 1940448 |
| 5 | 4059 : 4060 : 5741 | 32959080 | 32959081 | 65918161 | 65918160 |
| 6 | 23660 : 23661 : 33461 | 1119638520 | 1119638521 | 2239277041 | 2239277040 |

> 表里两个加一关系就是恒等式「除以内方」后的样子：`弦方/内方 = 天元数/内方 + 1`、
> `外方/内方 = 弦方/内方 + 天元数/内方` —— **内方 = 1 的那一族，恰好把整套恒等式变成了三个整数**。

最后新加的 `外方 − 内方` 一列**不是新的独立量**：`外方 − 内方 = (勾+股)² − (股−勾)² = 4·勾·股`，
正好是「天元数」的 2 倍；本表 `内方 ≡ 1`，所以它也等于「外方 ÷ 内方」列减 1。
**#2 那一格的 1680 标星**，是因为它恰好等于 Leadbeater 记录的那条 Anu 螺旋线的总匝数 ——
两者来源完全独立，本文档只记「数值相等」，不作因果解释，逐格扫描见 §9.5。

**关于整数倍**：因为是尺度不变量，`6 : 8 : 10` 的比值与 `3 : 4 : 5` 完全相同 ⇒
所有 Pell 家族的整数倍也全部取整。弦 ≤ 1000 的 881 组里「÷内方」取整共 **240** 组，无例外。

### 9.3 判据三 · 其余六个方向永不取整

`内方/勾方、内方/股方、天元数/勾方、天元数/股方、外方/勾方、外方/股方、外方/天元数、天元数/外方、弦方/天元数`
—— 弦 ≤ 1000 的全部 881 组里取整条数 **全部 = 0**。它们都要求 `勾 | 股` 或 `股 | 勾` 或 `勾 | 2·股` 之类；
由 `gcd(勾,股) = 1`、`股 > 勾` 立即得 `勾 = 1, 股 = 2`，而 `1² + 2² = 5` 开不尽 ⇒ 整数勾股数里无解。

### 9.4 两页互为印证

|------|------|------|
| 问 | D外/D内 哪些是整数比？ | 弦里弦外的比哪些是整数比？ |

### 9.5 新加的一列「外方 − 内方」：它是 4·勾·股，以及那一格 1680

9.2 那张 Pell 表最后加了一列 `外方 − 内方`。先把它的身份说清楚 —— **它不是新量**：

```
外方 − 内方 = (勾 + 股)² − (股 − 勾)² = 4·勾·股 = 2 × 天元数
```

展开后两个平方项互相抵消，只剩交叉项。所以这一列每一格都精确等于左边「天元数 ÷ 内方」那一格的 **2 倍**；
又因为本表 `内方 ≡ 1`，它同时也等于「外方 ÷ 内方」列减 1。**它只是同一条恒等式的第三种读法** ——
这点必须先说清楚，否则容易把 1680 当成「新算出来的东西」。

#### 撞数扫描：这六个数里，哪些落在 Leadbeater 的计数体系里

比对基准分两类：**结构常数** —— `10`（旋数，3 粗 7 细）、`7`（七级嵌套）、`1680`（总匝数）、
`175 / 176`（细旋 / 粗旋数）、`251 / 250`；**逐元素计数** —— 各元素的 Anu 数，
全部是 `18` 的倍数（例：Mg²⁴ → `432 = 18 × 24`），量级从 18 到几千。

| # | 外方 − 内方 | 质因数分解 | ÷ 1680 | 在 Leadbeater 资料库里的情况 |

| 1 | 48 | 2⁴·3 | 1/35 | 不是 18 的倍数 ⇒ 不可能出现在逐元素 Anu 数表里；结构常数中无 48 |
| **2** | **1680** | 2⁴·3·5·7 | **1** | **整值相等** —— 那条 Anu 螺旋线的总匝数 `1680 turns` |
| 3 | 57120 | 2⁵·3·5·7·17 | **34** | 库内检索「57120」**0 条命中**；只是 1680 的整数倍 |

根本没有位置（那张表里的 Anu 数全为 `18` 的倍数，量级从 18 到几千 ——
氢 18、Mg²⁴ → 432、另一处 1260 = 18 × 70）；48 既不是 18 的倍数，
也不等于库里任何一个结构常数。

至于 #3 / #5 / #6 是 1680 的整数倍 —— **那不是第二个发现，是因子结构直接决定的**，下一段两行就能算完。

#### 为什么 #3 / #5 / #6 能被 1680 整除，#4 偏偏不能

`1680 = 2⁴·3·5·7`。而 `4·勾·股` 里，**2 和 3 从来不缺**：

- **2**：勾、股一奇一偶 ⇒ 偶数那个至少含 `2²`，再乘外面的 4 就是 `2⁴`；
- **3**：若 `3 | 弦`，则 `勾² + 股² ≡ 0 (mod 3)` ⟹ `3 | 勾` 且 `3 | 股`，与本原性矛盾 ⇒ **3 必落在勾或股上**。

所以能不能被 1680 整除，**只取决于 5 和 7 是否都落在勾·股里**：

| # | 勾 · 股 的分解 | 5 在哪 | 7 在哪 | 1680 整除 4·勾·股？ |
|------|------|------|------|------|
| 3 | 119 = 7·17　120 = 2³·3·5 | **股** | **勾** | 是（商 34） |
| 4 | 696 = 2³·3·29　697 = 17·41 | **弦** 985 = 5·197 | 不出现 | 否（余 48） |
| 5 | 4059 = 3²·11·41　4060 = 2²·5·7·29 | **股** | **股** | 是（商 39237） |
| 6 | 23660 = 2²·5·7·13²　23661 = 3²·11·239 | **勾** | **勾** | 是（商 1332903） |

#4 是这一族里唯一「5 跑到弦上」的：`985 = 5 × 197`，勾、股里既没有 5 也没有 7 ⇒ `4·勾·股` 少了这两个因子，
余数正好 `48 / 1680 = 1/35`。**这不是巧合** —— 「5 必须出现在勾、股、弦三者之一，但不必在勾或股上」
是二次剩余 mod 5 的直接后果（若三者都不被 5 整除，`勾², 股² ∈ {1,4}`，和为 2 或 3，都不是 mod 5 的平方数）。

#### 反查：1680 在这张 Pell 表里只能出现一次

把 `4·勾·股 = 1680` 反解 ⇒ `勾·股 = 420`。420 拆成两数之积共 **12** 对：1×420、2×210、3×140、4×105、
5×84、6×70、7×60、10×42、12×35、14×30、15×28、20×21。其中**只有 20×21 是两个连续整数**，
而「股 − 勾 = 1」正是这张表的前提 ⇒ **1680 只能落在 #2，不可能落在别的行**。
正着算出 1680，反着只能解回 20 : 21 : 29 —— 这条反查是闭合的。

#### 口径边界：这三条不许含糊

- 这一格的 1680 是 `4·勾·股` 的一个取值；Leadbeater 那里的 1680 是「一条螺旋线绕了多少圈」的观测计数。
  **两者来源完全独立，中间没有任何推导链。**
- 所以本文档只记「**数值相等**」这一个事实。它是否为「同一件事」，**本文档不作判断** ——
  既无法证真，也无法证伪。要判，得靠结构上的独立证据（对照 `AAA_175与176_弦图判据.html`：
  细旋 175 / 粗旋 176 是从 `E(n)=25n+1` 推出来的，与这里的 `4·勾·股` 无关）。
- 由这一条**不能**反推「Pell 家族 = Anu 结构」。把数字重合当证据，是最容易自欺的一步。

## 10. 两行之间相除能得整数吗？—— 只有 ×1 与 ×(−1)

前面 §6.3 问的是「**单独一行的比值**是不是有理数（整数比）」，答案是「一条都没有」。
这里问的是一个**新问题**：把表里**两行相除**，`V_i / V_j` 能不能是整数？
（老师的原话：*「有没有可能这里面有一对是整数倍关系，比如 #32 的 (D外/D内) 除以 #1 的 (D外/D内) 等于整数？」*）

### 10.1 判据五 · 商若为有理数，只能是 +1 或 −1

记带符号精确式

```
V(勾,股) = (A + B√2) / C ,   A = 2勾² + 股² ,  B = 2勾股 ,  C = 2勾² − 股²
```

（`C` 可负：`股/勾 > √2` 时 `C < 0`，即「不可内接」那一类；页面表格显示时取 `|C|`。）

**恒等式**：`A² − 2B² = C²`（把 `(2勾²+股²)² − 2(2勾股)²` 展开即得）⟹ 可直接有理化：

```
V₁ / V₂ = [ (A₁A₂ − 2B₁B₂) + (B₁A₂ − A₁B₂)·√2 ] / (C₁C₂)
```

**判据五**：`V₁/V₂ ∈ ℚ ⟺ V₁/V₂ ∈ {+1, −1}`。

**证明**：商为有理数 ⟺ 上式 √2 的系数为零。代入 `A = 2勾²+股²`、`B = 2勾股` 因式分解（已对 1 ≤ 勾 ≤ 59 的全部有序对数值核对，**0 反例**）：

```
B₁A₂ − A₁B₂ = 2 · 勾₁勾₂ · (股₁/勾₁ − 股₂/勾₂) · (2勾₁勾₂ − 股₁股₂)
```

其中 `2勾₁勾₂ ≠ 0`，所以只能让后面两个因子之一为零：

| 情形 | 条件 | 商 | 几何含义 |
|------|------|------|------|
| ① | `股₁/勾₁ = 股₂/勾₂` | **+1** | 同一形状（互为整数倍，如 3:4:5 与 6:8:10） |
| ② | `股₁股₂ = 2·勾₁勾₂`（即 `股₂/勾₂ = 2 ÷ (股₁/勾₁)`） | **−1** | 互为「**2/r 搭档**」（见 10.2） |

有理数只有这两个取值，而 **整数 ⊂ 有理数** ⟹ 商若为整数，只能等于 `±1`；
**想凑出 ×2、×3、×4 这样的倍数，数学上办不到**。∎

### 10.2 判据六 · ×(−1) 搭档的构造式：`(股 : 2·勾)` 约分即成

给定一行 `勾 : 股`，取

```
搭档 = (股 : 2·勾) ÷ gcd(股, 2勾)
```

它的「股÷勾」恰好是原来的 `2/r`，两者乘积 = 2，商 = −1。**精细结构（0 反例）**：
把搭档写成 `λ·(股, 2勾)`（λ 为有理数），则

```
A₂ = 2λ²A₁ ,   B₂ = 2λ²B₁ ,   C₂ = −2λ²C₁
```

即**约分后：分子一模一样，分母只是变号**。所以

```
V(搭档) = − V(原形状)     精确成立（不是近似）
```

**页面上看起来是「两行完全相同」**：因为表格按 `|C|` 显示（不可内接那行取绝对值），
正负号被抹掉，两行的精确式与数值显示成同一个数。

**方向的限制**：只有当 `股/勾 ≤ 2` 时，搭档才仍是「股 ≥ 勾」的形状（`1 ≤ r ≤ 2`）。
`r > 2`（如 5:12、7:24）时搭档会翻进「股 < 勾」的镜像，本表约定下没有搭档行。

**必然推论**：`r₁r₂ = 2` 且 `r ≠ √2`（有理数不可能等于 √2）⟹ 一对里
**必然一个是 `股/勾 < √2` 的可内接行（真值为正）、另一个是 `股/勾 > √2` 的不可内接行（真值为负）**。

**搭档示例**（分子相同、分母反号）：

| 勾 : 股 | 弦 | 精确式 V | 搭档 | 搭档弦 | 搭档精确式 |
|------|------|------|------|------|------|
| 1 : 1 | √2 | (3 + 2√2) / 1 | 1 : 2 | √5 | (3 + 2√2) / −1 |
| **3 : 4** | **5** | **(17 + 12√2) / 1** | **2 : 3** | **√13** | **(17 + 12√2) / −1** |
| 4 : 5 | √41 | (57 + 40√2) / 7 | 5 : 8 | √89 | (57 + 40√2) / −7 |
| 5 : 7 | √74 | (99 + 70√2) / 1 | 7 : 10 | √149 | (99 + 70√2) / −1 |
| 8 : 15 | 17 | (353 + 240√2) / −97 | 15 : 16 | √481 | (353 + 240√2) / 97 |
| 20 : 21 | 29 | (1241 + 840√2) / 359 | 21 : 40 | √2041 | (1241 + 840√2) / −359 |
| 99 : 140 | √29401 | 19601 + 13860√2 | 70 : 99 | √14701 | −(19601 + 13860√2) |
| 119 : 120 | 169 | (21361 + 14280√2) / 6961 | 60 : 119 | √17761 | (21361 + 14280√2) / −6961 |

注意每一对里**只有一个的弦是整数**（左边），另一个必然开不尽 —— 这正是 10.3 的内容。

### 10.3 判据七 · 为什么「整数弦」表里一对都找不到（Euler 1770）

搭档也要是整数弦 ⟺ 存在本原勾股数 `(勾, 股) = (m²−n², 2mn)`（`m > n ≥ 1`、`gcd = 1`、`m−n` 为奇），使

```
Q₁ = m⁴ − m²n² + n⁴            （勾 = m²−n², 股 = 2mn 的情形）
Q₂ = m⁴ + 14m²n² + n⁴          （勾 = 2mn, 股 = m²−n² 的情形）
```

**是完全平方。**

**关键恒等式**：`Q₂(m, n) = Q₁(m+n, m−n)`（数值核对 0 反例，例如 `Q₂(2,1) = 73 = Q₁(3,1)`）。
于是两式一并归到 **Euler 1770 年的经典结论**：

> `x⁴ − x²y² + y⁴ = z²` 只有平凡解：`x = y` 或 `xy = 0`。
> Euler 在《代数》中陈述、1800 年代初补出证明，标准证法是**无穷递降**；
> 见 L. E. Dickson, *History of the Theory of Numbers*, Vol. II, Ch. XXII（p. 634 起）。

而 `x = y ⟹ 勾 = 0`、`xy = 0` 同样退化 ⟹ **非退化情形无解**：
`×(−1)` 搭档永远不可能是整数弦，**所以整数弦表里一对都找不到**。

**实测印证（两路独立复算，逐位一致）**：

- `m ≤ 20000`（弦 ≤ 4×10⁸）共 **81,061,017** 组本原 `(m, n)`，`Q₁`、`Q₂` **零命中**；
- 弦 ≤ 2000 的 **319** 种形状两两比对 **101,442** 对，商为有理数的 **0 对**；
- 页内 JS 扫描与 Python 独立扫描结果完全相同（见 10.4）。

### 10.5 一句话总结

> **「整数倍」这件事，在这张表里只有两条出路：`×1`（同一形状）与 `×(−1)`（互为 2/r 搭档）。

> （3:4 ↔ 2:3、4:5 ↔ 5:8、8:15 ↔ 15:16、20:21 ↔ 21:40、99:140 ↔ 70:99、119:120 ↔ 60:119 …）。**

### 10.6 判据八（2026-10-15 补）· 「大 ÷ 小」也一对都没有

> **问题（老师）：**把**大**的那个 D外/D内 除以**小**的（商 > 1），会不会碰巧等于 2、3、4…？
> **答：不会。** 而且是「恒不成立」，不是「还没找到」。

**更简的写法（莫比乌斯形）**：记 `r = 股 / 勾`（有理数），则

```
V(r) = D外/D内 = (r + √2) / (r − √2)
```

两行相除，把含 √2 的项归拢到一起：

```
V₁ / V₂ = [(r₁r₂ − 2) + (r₂ − r₁)·√2] / [(r₁r₂ − 2) − (r₂ − r₁)·√2]
```

记 `X = r₁r₂ − 2`、`Y = r₂ − r₁`（**都是有理数**），有理化得

```
V₁/V₂ = (X² + 2Y² + 2XY√2) / (X² − 2Y²)
```

分子里的 `2XY√2` 要消失（商才有理），**只能** `X = 0` 或 `Y = 0`：

| 条件 | 含义 | 商 |
|------|------|------|
| `Y = 0` | r₁ = r₂ ⟺ 两行**同形状**（同一勾股形的整数倍） | **+1** |
| `X = 0` | r₁r₂ = 2 ⟺ 互为「2/r 搭档」（判据六） | **−1** |

⟹ **商 ∈ ℚ ⟹ 商 = ±1** ⟹ **商 > 1 的整数（2、3、4…）永远不存在**。∎

**「含根号 2」正是要害**：只要 r₁ ≠ r₂ 且 r₁r₂ ≠ 2，√2 就消不掉，商必落在 ℚ(√2) ∖ ℚ 里

## 10.7 两种「一步出」的比值 —— D外/D内 与 b内/a外（2026-10-16 补）

页面左浮窗「通项公式 · 一步出比值」现在有两枚切换按钮。两者是**同一对 A / B / C** 的两种用法，
只差 √2 项的符号：

```
A = 2勾² + 股²      B = 2·勾·股      C = |2勾² − 股²|        （三者同除 gcd 得最简）

球直径比   2R / 2r = (A + B√2) / C        ← D 模式
棱长比     |b| / a = (A − B√2) / C        ← b 模式
```

**为什么恒互为倒数**：

```
(A + B√2)(A − B√2) = A² − 2B² = (2勾² − 股²)² = C²
⟹ 两个比值的乘积 ≡ 1
```

这一步同时说明：判据五（有理商只有 ±1）在几何上不过是「两种量长比互为倒数」的代数影子。

### 10.7.1 三条样例的精确式

| 勾 : 股 | 最简 A, B, C | D外/D内 = (A+B√2)/C | b内/a外 = (A−B√2)/C | 说明 |
|------|------|------|------|------|
| 3 : 4 | 17, 12, 1 | 17 + 12√2 ≈ 33.97056275 | 17 − 12√2 ≈ 0.02943725 | 恰为 σ⁴ 与 σ⁻⁴ |
| 20 : 21 | 1241, 840, 359 | (1241 + 840√2)/359 ≈ 6.76584789 | (1241 − 840√2)/359 ≈ 0.14780114 | 非 σ 幂 |
| 5 : 12 | 97, 60, 47 | (97 + 60√2)/47 ≈ 3.8692088 | (97 − 60√2)/47 ≈ 0.25845077 | 不可内接，量长取正 |
| 99 : 140 | 19601, 13860, 1 | 19601 + 13860√2 ≈ 39201.99997449 | 19601 − 13860√2 ≈ 0.00002551 | Pell 族，σ¹² |

**一步出内棱长**：`|b| = a ÷ (D外/D内)`（D 模式）或 `b = (b内/a外) × a`（b 模式），
两式给出同一个数，与「实时读数」表的 `#rb` **逐位一致**。

### 10.7.2 ⚠️ 数值稳定性：b 模式禁用 `(A − B√2)/C`

`A` 与 `B√2` 在 Pell 族里高度接近（如 99:140 时 A = 19601、B√2 = 19600.999974…），
直接相减是**灾难性相消**，会随勾股数增大而丢失有效数字。改用精确恒等式
`(A − B√2)/C = C/(A + B√2)` 即可把误差压回机器精度：

| 勾 : 股 | 稳定写法 `C/(A+B√2)` | 旧写法 `(A−B√2)/C` | 旧写法相对偏差 |
|------|------|------|------|
| 3 : 4 | 2.943725×10⁻² | 2.943725×10⁻² | 6.9×10⁻¹⁴ |
| 99 : 140 | 2.550890×10⁻⁵ | 2.550890×10⁻⁵ | 1.1×10⁻⁷ |
| 169 : 239 | 4.376636×10⁻⁶ | 4.376634×10⁻⁶ | 4.0×10⁻⁷ |
| 577 : 816 | 7.509120×10⁻⁷ | 7.508788×10⁻⁷ | 4.4×10⁻⁵ |

577:816 那一行旧写法第 5 位有效数字就错了 —— 而页面正是要拿这个比值去乘棱长 `a` 的。
