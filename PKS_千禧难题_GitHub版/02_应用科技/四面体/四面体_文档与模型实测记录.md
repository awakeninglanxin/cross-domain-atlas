### A-3. 文档的核心逻辑链

```text
构图（12 枚 3-4-5 三角形以棱为斜边、直角顶朝内、相互抵靠）
  ↓
中心交合 → 形成很小的倒正四面体
  ↓
Shapr3D 建模 + 实测（大棱长 50、小棱长 1.4719）
  ↓
两组相除 → 33.970563（最精确值）
  ↓
Wolfram 闭式反查 → (1+√2)⁴
  ↓
解读为「4 次白银比 √2 旋转」＝ 45° 四次旋转系统
```

### A-4. 关键数值总表（文档原值 vs 精确值）

| 量 | 文档原值 | 精确值 | 相对误差 |
|---|---|---|---|
| 大四面体棱长 a | 50 | 50（设定） | 0 |

| 小四面体外接球直径 2r | 1.8027 | 1.8026561415 | 2.4e-5 |

## C. Shapr3D 工程文件反解（完整实测记录）

### C-1. 文件格式

`.shapr` 虽然后缀为工程格式，实际是 **ZIP 容器**；解包后核心是 `workspace` —— 一个 **SQLite 数据库**，几何信息分布如下：

| 表 | 用途 | 本项目记录数 |
|---|---|---|
| SketchControllers | 草图平面：中心 (PlaneCenterX/Y/Z)、法向 (PlaneNormX/Y/Z)、U 方向 (PlaneUDirX/Y/Z) | 17 |
| SketchCurves | 每条曲线的 2D 端点（JSON 格式 Data 字段） | 87 |
| PersistentMeasurements | 持久化测量项 | 0（测量值未落库，在 UI 里） |
| Shapes / Constraints / Drawings | 实体 / 约束 / 工程图 | 若干 |

> 注意：`SketchCurves.Data` 中部分记录**没有 `start` 键**，直接按 `start` 取值会 `KeyError`。稳健做法是**递归遍历 JSON，凡含数值型 `x`、`y` 的节点都收为 2D 点**。

### C-2. 2D → 3D 重建公式

对每条曲线所属的草图平面（中心 C、法向 N、U 方向 U），令 V = N × U，则 2D 点 (u, v) 对应

```text
P₃D = C + u·Û + v·V̂       （Û、V̂ 均为单位向量）
```

### C-4. 模型坐标单位鉴定

image3 显示 Shapr3D 的测量面板读数是 **14,718.6258 毫米**，而数据库中同一条线段反解长度为 **14.718626**。

```text
14718.6258 mm ÷ 14.718626 = 1000.0  ⇒  模型单位 = 米（1 单位 = 1000 mm）
```

于是：

| 模型值（米） | 换算 mm | 与文档对照 |
|---|---|---|
| 外四面体棱长 0.050000 | **50 mm** | 文档「棱长为 50」✔ |
| 内倒四面体棱长 0.0014718626 | **1.4718626 mm** | 文档「小棱长为 1.4719」✔ |
| 放大副本 14.718626 | **14718.626 mm** | 文档实测 14718.6258 ✔ |
| 外接球半径 0.030619 | 30.619 mm → 2R = 61.237 mm | 文档实测 61.2372 ✔ |

### C-5. 核心比值（模型独立验证）

```text
b / a = 0.0014718626 / 0.0500000 = 0.0294372515
(√2 − 1)⁴                        = 0.0294372515
```

**吻合**。且模型里**内倒四面体的 6 条棱长度严格相等**（0.0014718626 × 6），
说明反解出的几何确实是「正」的倒四面体，而非测量噪声。

### C-6. 关于「放大 1000 倍」的更正

文档第 ⑨ 段写「之后把棱长放大 1000 倍」，但按 ⑪ 段的算式反推：

```text
大棱长 50 mm  → 500000 mm   倍率 = 10⁴
小棱长 1.4718626 mm → 14718.626 mm   倍率 = 10⁴
```

两处倍率一致为 **10⁴**（而非 10³）。这不影响比值结论（分子分母同时放大，比值不变），
但笔记中记为 ×10⁴ 更准确。

## D. 三条独立数据链的闭合

| 链 | 数据来源 | 得到 a/b |
|---|---|---|
| 文档实测 | 500000 / 14718.6258 | 33.970563 |
| 模型反解 | 0.0500000 / 0.0014718626 | 33.9705627 |
| 理论闭式 | (1+√2)⁴ = 17 + 12√2 | 33.9705627 |

三条链互相独立（一条来自人工读数、一条来自文件解析、一条来自纯数学），
结果一致 → 结论可靠。
