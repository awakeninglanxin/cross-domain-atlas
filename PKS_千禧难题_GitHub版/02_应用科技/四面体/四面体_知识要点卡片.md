## 卡片 1 · 正四面体公式

| 量 | 公式 | 数值系数 |
|---|---|---|
| 高 h | a√6/3 | 0.816497 |
| 外接球半径 R | a√6/4 | 0.612372 |
| 内切球半径 r | a√6/12 | 0.204124 |
| 棱切球半径 | a√2/4 | 0.353553 |
| 体积 V | √2a³/12 | 0.117851·a³ |
| 表面积 S | √3·a² | 1.732051·a² |
| 中心分高比 | 3 : 1（顶点段 : 底面段） | — |
| 二面角 | arccos(1/3) | 70.528779° |
| 中心张角（顶点–中心–顶点） | arccos(−1/3) | 109.471221° |

**自检口径**：`R : r = 3 : 1`，`h = R + r = 4r`。本项目中 `R_inner` < `r_outer`，
所以内倒四面体完全落在中央空腔里，不与外壁相碰。

## 卡片 2 · 「股四腿交合」核心机理

**一句话**：12 枚三角形的「股四腿」（长 4a/5）不是随便摆的 —— 它们 3 条一组、
一共 4 组，各自交于一条中轴上的同一点；这 4 个点就是内倒四面体的 4 个顶点。

**为什么 3 条必交于一点（证明骨架）**

| 步 | 断言 | 依据 |
|---|---|---|
| 1 | 对任一顶点 V_j，绕中轴 OV_j 转 120° 是正四面体的对称 | 旋转对称群 ≅ A₄，含 8 个 3 阶元素 |
| 2 | 该旋转把「射向 OV_j 的 3 条股四腿」循环置换 | 棱 → 棱、「i 端的股四腿」→「k 端的股四腿」 |
| 3 | 每条股四腿都与 OV_j 相交（交点在腿的内部） | 共面二维解析（参数 t = 0.758 < 1） |
| 4 | 3 个交点被旋转互相映射，而旋转固定轴上每一点 | 交点 ∈ 轴 ⇒ 被固定 ⇒ 三交点相同 |

**共面解的数值锚点**

```text
股四腿方向            û = (4/5)ĝ − (3/5)ĝ⊥        （ĝ = V₀V₃/a）
撞上中轴的参数        t = 25/(4(3√2+4)) = 0.7582521543…
交合点高度（a = 1）   z = (36√3 − 25√6)/6 = 0.1860975888…
由此读出             k = 17 − 12√2 = (√2−1)⁴ = 0.0294372515…
内倒四面体顶点        P_j = O − k(V_j − O)
```

## 卡片 3 · 白银比 σ

| 项目 | 值 |
|---|---|
| 定义 | σ = 1 + √2 |
| 数值 | 2.4142135623730950488016887242… |
| 等价写法 | cot 22.5° = tan 67.5° |
| 递推关系 | σ = 2 + 1/σ（由 σ² = 2σ + 1） |
| 连分数 | σ = [2; 2, 2, 2, …] |
| 几何出现 | 正八边形「跨 3 边对角线 ÷ 边长」 |
| 本课题的角色 | 外/内棱长比 = σ⁴ |

> 与黄金比 φ = 1.618…（满足 φ² = φ + 1）对照：白银比满足 σ² = 2σ + 1，
> 把「1」换成「2」，对应正方形/八边形系统而非五边形系统。

## 卡片 4 · 指数「4」的四重解释

| 层面 | 解释 |
|---|---|
| 结构 | 4 条中轴（每顶点一条）→ 4 个交合点 → 4 是四面体的顶点数，也是级数阶数 |
| 半角 | tan(θ/2) = (1−cosθ)/sinθ，θ = 45° ⇒ tan22.5° = √2 − 1，故 k = tan⁴22.5°、σ = cot22.5° |
| Pell | (1+√2)ⁿ 的第 4 项给出整数对 (17, 12)，满足 17² − 2·12² = 1 |
| 八边形 | 45° 是正八边形的旋转步长；σ = 该八边形的对角比，σ⁴ = 该系统的四阶封闭形式 |

## 卡片 5 · Pell 方程 x² − 2y² = 1

| n | (1+√2)ⁿ | 整数对 (x, y) | 数值 |
|---|---|---|---|
| 1 | 1 + √2 | (1, 1) | 2.4142135624 |
| 2 | 3 + 2√2 | (3, 2) | 5.8284271247 |
| 3 | 7 + 5√2 | (7, 5) | 14.0710678119 |
| 4 | 17 + 12√2 | (17, 12) | 33.9705627485 |

**递推**：`(x, y) → (3x + 4y, 2x + 3y)`（乘 (3+2√2)）。

**本课题用到**：`(17 − 12√2)(17 + 12√2) = 289 − 288 = 1` ⇒ 倒数关系成立，
这正是「外/内比」能写成简洁整系数式的根本原因。

## 卡片 6 · 关键比值速查

| 比值 | 精确式 | 数值 |
|---|---|---|
| 外/内 棱长比 a/b | (1+√2)⁴ = 17 + 12√2 | 33.9705627485 |
| 内/外 棱长比 b/a | (√2−1)⁴ = 17 − 12√2 | 0.0294372515 |
| 外/内 外接球直径比 2R/2r | 同 a/b | 33.9705627485 |
| 外/内 内切球半径比 | 同 a/b | 33.9705627485 |
| 外/内 体积比 | (1+√2)¹² | 39221.9… |
| a = 50 时 2R | a√6/2 | 61.2372435696 |
| a = 50 时 b | a(√2−1)⁴ | 1.4718625761 |
| a = 50 时 2r | b√6/2 | 1.8026561415 |

> 「比值不变性」：任何同一特征长度的外/内之比都等于 a/b。这解释了为什么老师文档里
> 「外接球半径」与「内接球半径」两种问法会得到同一个答案。

| 项目 | 说明 |
|---|---|
| 数量 | 6 条棱 × 2 = 12 枚 |
| 斜边 | 四面体的一条棱（长 a） |
| 两腿 | 3a/5（勾三）与 4a/5（股四） |

## 卡片 8 · 二维 vs 三维对照（《周髀算经》弦图 → 升维）

| 二维（赵爽弦图） | 三维（本结构） |
|---|---|
| 勾 3、股 4、弦 5 直角三角形 | 同一三角形贴在正四面体的棱上 |
| 4 枚三角形以弦为边围成外方（边 5） | 12 枚三角形以弦（棱）为斜边贴在内壁 |
| 面积关系 4 × 6 + 1 = 25 = 5² | 12 条股四腿 3 条一组交于 4 点 |
| 中央内方，边长 = 股 − 勾 = 1 | 中央内倒四面体，棱长 = a(√2−1)⁴ |
| 内方相对外方转过 45° | 内倒四面体相对外四面体倒置（中心反演） |
| 相似比 1/5（内/外） | 相似比 (√2−1)⁴（内/外） |

**升维的实质变化**：二维弦图里的内方是「平移式」的（边长 = 股 − 勾），
三维升维后内倒四面体变成「反演同伦式」的（P_j = O − k(V_j − O)），
所以相似比不再是简单的 (股−勾)/弦，而要由白马银比的四次幂给出。

## 卡片 9 · 常见误区

| 误区 | 纠正 |
|---|---|
| 「内接球半径」与「外接球半径」会给出不同比值 | 不会。任何同特征长度之比恒等于棱长比 |
| 内倒四面体是「随便放的」 | 不是。它由 12 条股四腿的交合点唯一确定，与 O 同心 |
| 内倒四面体是「最大的内接倒四面体」 | 不是。最大同心内接倒四面体棱长可达 a/3；本结构只有 0.02944a，由交合条件锁定 |
| 建模里「放大 1000 倍」 | 按算式反推实为 ×10⁴ |
| 34.0222 是另一种可能答案 | 是测量误差分支，与 33.9705627 差 5.2e-2，文档已否决 |
| 3-4-5 三角形与棱长比例无关 | 有关。斜边 = 棱 ⇒ 两腿恒为 3a/5、4a/5，这是全部推导的入口 |

## 卡片 10 · 一句话总纲

```text
12 枚 3-4-5 三角形的直角腿在正四面体中心相互抵靠，
12 条「股四腿」按 3 条一组交出 4 个点，
这 4 点是一个倒置的正四面体，其棱长恰为外棱长的 (√2−1)⁴。
于是外 / 内四面体的外接球直径比 = (1+√2)⁴ = 17 + 12√2
                                = cot⁴22.5° = 33.97056274847714…
```
