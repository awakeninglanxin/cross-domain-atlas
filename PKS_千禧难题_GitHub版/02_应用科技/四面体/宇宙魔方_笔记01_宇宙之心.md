## 三、可精确计算的部分（含实算值）

### 3.1 七角星：三重"准周期宿命"

七重对称在数学上被三处同时"排挤"，这是它天然作为"准周期/神秘"符号的原因：

**(1) 平面周期铺砌只允许 3、4、6 次对称。**
因为 n 次旋转要能作用在周期格上，必须满足 `2cos(2π/n) ∈ ℤ`（推导线见笔记 03 §5）。

```
2cos(2π/7) = 1.246979604...   非整数  ⇒ 7 次轴被排除
```

**(2) 正七边形不可尺规作图。**
cos(2π/7) 是三次不可约多项式的根：

```
cos(2π/7) = 0.623489801858734
代入 8x³ + 4x² − 4x − 1  ⇒  8.88e-16 ≈ 0（数值零点）
```

该多项式在有理数域上不可约（次数 3，非 2 的幂）⇒ cos(2π/7) 不属于尺规可作域 ⇒ 正七边形**不可作**。

**(3) 7 次旋转轴在周期晶体中不存在。**

| 星形 | 尖角 |
|------|------|
| {7/2} | 180° − 2·2·180°/7 = 77.142857° |
| {7/3} | 180° − 2·3·180°/7 = 25.714286° |

> 常见误记：把 {7/2} 当成"更尖"的那个。尖角公式是 `180° − 2m·180°/n`，m 越大越尖，所以 {7/3}（25.7°）才是细长的那种；{7/2} 与 {7/3} 互为镜像，但尖角不同。

### 3.2 六合与「倒插双四面体」（Merkaba）

视频说的「隐藏三角四面体内」，就是**两枚同尺寸正四面体互锁**：一枚顶点朝上（**阳**）、
一枚顶点朝下（**阴**），二者互为**对心点反射**。这个复合体在西方叫 **Merkaba**，
在几何学里叫**星形四面体 stella octangula**。

#### 构造（与 `AAA四面体_主界面.html` 同源）

> 与其"先摆立方体再挑对角线"，不如直接用主界面那一页的构造 —— 两页才是同一件事。

底面正三角形放 xy 平面、顶点立在 +z 轴上（棱长 E）：

```
V = { (E/√3, 0, 0), (−E/(2√3), ±E/2, 0), (0, 0, E√(2/3)) }        ← 主界面 rebuild() 同式
心 O = (0, 0, E√(2/3)/4)                                            ← 外心 = 内心
外接球 R = E√6/4        内切球 r = E√6/12 = R/3
第二枚（阴）= 对 O 作点反射  x ↦ 2O − x                             ← 点反射是等距变换 ⇒ 棱长相同、共外接球
```

取 `E = 2√2`（与旧口径一致）：

| 量 | 实算值 | 精确式 |
|------|------|------|
| 棱长 E | 2.828427125 | 2√2 |
| 高 h | 2.309401077 | E√(2/3) |
| 外接球 R | 1.732050808 | √3 |
| 内切球 r | 0.577350269 | √3/3 |
| 底面外接半径 ρ | 1.632993162 | E/√3 |
| 8 顶点两两距离谱 | 2×12、2√2×12、2√3×4 | ⇒ **构成棱长 2 的立方体** |
| 立方体体积 | 8.000000000 | 8 |
| 单四面体体积 | 2.666666667 | 8/3 |
| 双四面体体积 | 5.333333333 | 16/3 |
| **体积比 立方体 : 双 : 单** | **3 : 2 : 1** | — |

> ⚠️ **纠正**：元宝那份笔记写的是"双四面体体积比 4:2:1"，**实算不成立**。
> 正确的自洽比例是 **3 : 2 : 1**（单 = 立方体/3，双 = 立方体×2/3）。
> "4:2:1" 在立方体内接四面体的任何标准口径下都找不到对应。
> 另外一个必须说清的点：**8 顶点构成的那个立方体，是"两枚四面体的并集"本身**，
> 而不是一个外加的框 —— 所以两枚一旦**反向旋转**，立方体就不再保持（演示页里它会淡出）。

#### 俯视图（这是判读两枚关系的正确视角）

沿中轴 z 正投影：两枚各投影成一个**等边三角形**，6 个顶点落在
`0° / 60° / 120° / 180° / 240° / 300°`（等间距），叠成**六角星**（Star of David）；
两枚的**顶点都落在俯视图的圆心**（尖正朝着你）。实测：6 点半径全 = 1.632993162。

#### 反向对旋：相对夹角 = 60° − 2θ

设阳转 `+θ`、阴转 `−θ`（同一中轴）。俯视看：一枚逆时针、另一枚顺时针。精确关系是

```
两枚三角形的相对夹角 ≡ 60° − 2θ   (mod 120°)
```

推导：阳的 3 个基顶点方位角 = θ、θ+120、θ+240；阴的 = 60−θ、180−θ、300−θ。
故相对转动的**角速度是本体转速的两倍**，方向相反。于是：

| θ | 相对夹角 | 俯视形态 |
|------|------|------|
| 0° / 60° | ±60° | 张成正**六角星**（标准 Merkaba） |
| 30° / 90° | 0° | 两枚**完全重合**，擦身而过 |
| 15° / 45° | ±30° | 扭开 30°（实拍示意：`v2_th15.png` / `v2_th45.png`） |

**整体点对称只在 θ ≡ 0 (mod 60°)** 时成立 —— 数值验证：θ = 60° 时 8 顶点重新拼回立方体，
偏差 **4×10⁻¹⁶**（机器精度）；θ = 45° 时偏差 1.63（确实不对）。也就是说：
**标准 Merkaba 每 60° 复现一次**，其间是"扭开的玻璃双四面体"。

演示页里转速取「后半段各自 ±120°」：正四面体自转 120° 复原（3 次轴），
所以片段末尾与开头完全重合 —— **循环无缝**。

### 3.3 正四面体的两个硬指标

```
二面角      = arccos(1/3) = 70.5287793655°
半角正切    = √2          ⇒ 半角 = arctan√2 = 54.7356103172°
外接球 R    = a√6/4       （a = 棱长）
内切球 r    = a√6/12
R : r       = 3 : 1       （与 a 无关）
体积        = a³/(6√2)
旋转群      ≅ A₄（12 阶）   全对称群 ≅ S₄（24 阶）
```

**一个跨项目的重要呼应**：这个 54.7356° 正是主界面 `AAA四面体_主界面.html` 里「勾股形可内接」的临界角
（条件 股/勾 ≤ √2，取等号时较大锐角 = arctan√2）。也就是说：

> **正四面体自身的"魔角"，恰好就是它在勾股形推广下的结构存在边界。**

这不是巧合：两条推导都归结到同一个 `√2` 关系（tan 半角 = √2 ⟺ 股/勾 = √2）。

### 3.4 星形八面体（stella octangula）

两个互穿正四面体的并集，其**凸包就是那个立方体**，8 个外尖点 = 立方体 8 顶点。
它同时包含一个正八面体"内核"，且：

```
正四面体二面角  arccos(1/3)  =  70.528779369°
正八面体二面角  arccos(−1/3) = 109.471220631°
两者互补，和 = 180°
```

立方体与正八面体互为**对偶**，棱数同为 12 —— 六合方向若取为"面心"就得到正八面体。

## 四、可验证性边界（必须坦率标出）

**属于数学、可以复算的：**
七重对称的三重排除、cos(2π/7) 的三次多项式、倒插双四面体（Merkaba）并集成立方体的体积比 3 : 2 : 1、
正四面体二面角与 R:r、A₄/S₄ 群阶、星形八面体与正八面体二面角互补。
—— 这些是**定理**，不存在解释空间。

**属于隐喻、不可证伪的：**

| 说法 | 为什么不可证伪 |
|------|------|
| "初心内藏七彩琉璃光，隐藏于生命**炁脉**" | "炁脉"没有给出测量方法、没有单位、没有可重复的观测协议 |
| "**初始源能**" | 无守恒律表述、无作用量、无法设计实验去否定它 |
| "无形无象的**结构运行模型**" | 未指明模型是什么；"模型"若不给出输入输出映射，就不可检验 |

**本笔记的立场**：视频做的是**用真实几何为象征叙事背书**（geometric backing），
而不是**用几何证明象征叙事**（geometric proof）。这两件事必须分清：

- 几何是真的 ⇒ 可以说"七重对称确实在周期世界里被排挤"；
- 但几何为真 **并不推出** "炁脉存在"或"七色光就是生命本源的编码"。

把前者当成后者的证据，就是**论据错位**（non sequitur）。
