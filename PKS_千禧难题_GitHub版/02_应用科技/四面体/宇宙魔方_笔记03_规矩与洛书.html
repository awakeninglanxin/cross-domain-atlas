二、∞ 与"阴阳反向旋转"

"一阴一阳谓之道"可以精确化为两个方向相反的旋转：

z(t) = e^{iωt}        阳（逆时针，环绕数 +1）
w(t) = e^{−iωt}       阴（顺时针，环绕数 −1）
z · w = 1             两者互逆 —— "交感"而不"相消"

而且三角函数本身就是由这一对构造出来的：

sin(ωt) = (e^{iωt} − e^{−iωt}) / 2i
cos(ωt) = (e^{iωt} + e^{−iωt}) / 2

几何图形上的 ∞（双纽线）：最简参数式（Gerono 双纽线）

x = a·sin u
y = a·sin u·cos u = (a/2)·sin 2u

沿 u 从 0 走到 2π，会依次绕完两瓣。

⚠ 2026-10-14 更正：原先这里写「左瓣环绕数 +1 / 右瓣环绕数 −1 / 和 = 0」——这个说法不成立。环绕数的定义要求闭合曲线不经过所绕的点，而双纽线在 u = 0、π、2π 处恰好压在原点上，绕原点的环绕数无定义。硬积分 ∮ dθ（角速度）得到的 −0.2122 / +0.2122 随分割数漂移，没有极限。

可积、且数值稳定的量是「有向面积」 ∮ ½(x dy − y dx)：

性质解析值本机实测
右瓣有向面积−2/3−0.6666666667
左瓣有向面积+2/3+0.6666666667
整条 ∞ 之和02.0×10⁻¹¹

即：同一根曲线，两瓣的有向面积大小相等、符号相反，总和精确归零。这与"一元平衡旋转"（合成角动量 L₁ + L₂ = 0）在结构上是同一句话 ——「净为零」这个结论成立，只是载体是面积，不是环绕数。

2.1 球面太极双螺旋：把 ∞ 立起来的严格做法

老师给的 4 张 Python 图（E:\pythonProject\费马螺旋\）的核心，是一张能严格落在球面上的双螺旋。读到公式层面只有三行：

θ = sgn(t) · |t|^(1/n)         方位角；幂次 n 控制"绞"
φ = arctan(sinh t) = gd(t)     极角；古德曼函数 Gudermannian
(ρ, z) = (cos φ, sin φ)        球面坐标

关键在古德曼函数的两条恒等式（本机逐点实算，误差 2.22×10⁻¹⁶）：

sin(gd t) = tanh t     ⇒   z = tanh t
cos(gd t) = sech t     ⇒   ρ = sech t

于是 ρ² + z² = sech²t + tanh²t ≡ 1 —— 曲线严格落在单位球面上（不是拟合、不是近似）；且 t → ±∞ 时 z → ±1、ρ → 0 ⇒ 两条股线无限逼近南北两极却永不到达（像经线绕向极点）。这也顺手解释了观感上的"两端密、中间疏"：极区 dρ/dz → 0，同样的 t 步长挤成一团。

阴阳关系：同一条曲线的方位角相差 π 的两支，z 完全相同、xy 互为对径 ⇒ 天然的双螺旋（DNA）骨架。再引入一个反向扭转角 ψ：

θ阳 = f + ψ
θ阴 = f + π − ψ        ⇒   相对角 = π − 2ψ
ψ效果
0标准对径 180°（阴阳最"开"）
π/2两股重合（阴阳合一）
π两支互换（回到起点、互为镜像）

幂次 n 管什么：|θ|max = (4π)^(1/n) 随 n 单调递减。临界指数 n* = ln(4π) / ln π = 2.211023（此时 |θ|max = π）； n = e ≈ 2.718 ⇒ |θ|max = 2.537329（不足 π，不越对径）； n = 2 ⇒ |θ|max = 3.544908 > π ⇒ 曲线越过对径（画面里开始"自缠"）。

2.3 原 py 的两处瑕疵（照抄会把图画坏）

(a) 基本版 t ** (1/3) 在 t < 0 时是 nan。 numpy 对负底的分数次幂返回 nan （不是 −|t|^{1/3}）；t ∈ [−π, π] 的 1001 个采样点里有 500 个是 nan ⇒ 曲线断掉一半。 正确写法：sgn(t) · |t|^(1/3)。

(b) 高级版双高斯权重在 u ≈ 0 处跳变。 权重 w(u) = e^{−(u+1)²/0.1} + e^{−(u−1)²/0.1} − 0.5·e^{−u²/0.5}，t = sgn(u) · w(u)/w(±1) · 4π。 u ≈ 0 时两个正高斯都 ≈ e^{−10} ≈ 0，只剩负数项，乘上 sgn(u) 后： t(0⁻) = +6.737988、t(0) = 0、t(0⁺) = −6.737988 ⇒ 跳变 Δt = 13.475976， Matplotlib 把线段一连，就成了两条横贯整个球体的假直线。

病根一句话：w 是偶函数、sgn(u) 是奇函数，「奇 × 偶 = 奇」；奇函数在 0 处要么过 0 要么跳，而 w(0) = 2e^{−10k} − 0.5 = −0.499909 ≠ 0 ⇒ 只能跳。 Δt 与采样点数完全无关：N 从 100 加到 10⁶，Δt 一位都不变（tetra/tjump.js 已核验）。所以这是公式的连续性缺陷，不是"采样点不够"；N 越大，两段越贴到 ±6.738，跳变看着反而更陡。

另有一处"看得见、但不算错"的现象：u ∈ (0,1] 覆盖 t ∈ [−6.738, +12.566]， u ∈ [−1,0) 覆盖 [−12.566, +6.738] —— 两段在 |t| ≤ 6.738 上完全重叠，也就是曲线被画了两遍（视觉无碍，但采样翻倍、极区更密）。更反直觉的是：把权重宽度整体缩放 k 倍，曲线集合完全不变 （u ∈ [−1,1] 的 t 像始终是 [−4π, +4π]），变的只有采样点疏密。实算 k 从 0.45 → 4.20：极区（|z| > 0.99）样本占比 82.43% → 51.19%，赤道带（|z| < 0.10）0.65% → 4.12%。所以模式 ① 第 5 条路径画的是点云而非曲线 —— 曲线看不出差别，点云才看得出。

2.3.1 赤道过渡"不丝滑"的第二个独立原因（2026-10-14 二次）

老师指出「红蓝曲线在赤道面过渡不丝滑」—— 这与上面的跳变是两个独立问题：

  • 方位角 θ = sgn(t)·|t|^{1/n} 在 n = e > 1 时，dθ/dt = (1/n)|t|^{1/n − 1} → ∞（t → 0），

    弧长速度 σ = ds/dt = √(φ′² + cos²φ·θ′²) 同时在赤道发散 （实测 dθ/dt：t = 0.1 → 4.287、t = 1e−5 → 1447）。

  • 而原权重恰好把 82% 的点堆在两极、只给赤道带 0.65% ——

    采样密度与弧长速度正好反着，赤道只剩几个点，折线只能用长弦跨过去 ⇒ 看着就是「拐」。

  • ⇒ 调大 N 治不了：N 增大只会让两极更密、赤道那几根长弦的端点更明确。

w′(u) = −2(u+1)/a·e^{−(u+1)²/a} − 2(u−1)/a·e^{−(u−1)²/a} + (u/c)·e^{−u²/c}   （a = 0.1/k, c = 0.5/k）

三、规矩：天圆地方，以及"化圆为方"的不可能性

3.1 尺规到底能作什么

"规"（圆规）+ "矩"（直角尺）能作的长度，恰好是由有理数经 + − × ÷ √ 得到的数（尺规可作数的域）。这就是"规和矩是造化精妙结构的振动弧度"在数学上的最准确翻译： 它不是任意长度都能作出的，能作的长度被一个代数结构严格限定。

3.3 化圆为方为什么不可能

要把圆变成等面积正方形，需要作出长度 √π：

√π = 1.772453850905516

Lindemann（1882） 证明 π 是超越数（不是任何整系数多项式方程的根）。若 π 是超越的，则 √π 也不是代数数，更不可能属于尺规可作域 ⇒ 用规和矩作出与圆等面积的正方形，永不可能。

这给"规矩"划了一条硬边界：规与矩能作出全部二次扩张的数，但作不出超越数。 "矩"的直角是 90°（二次），它管不到 π。

3.4 阿基米德的夹逼：天圆地方的原始算法

阿基米德用内接 / 外切 96 边形把 π 夹住：

223/71 = 3.140845  <  π  <  22/7 = 3.142857

这就是"以方逼圆"—— 也是"天圆地方"在算法上最早的落地。

也就是说：交点确实"很多"（398 个），但它们一个都没跑出 Q(3​)。

复数化之后，这些点落在 Q(i,3​) 里；而

ζ₅ = e^{2πi/5} 是正五边形旋转 72° 的特征值
ℚ(ζ₅) 只在素理想 5 处分歧，ℚ(i,√3) 只在 2、3 处分歧 ⇒ 两者交为 ℚ
⇒  ζ₅ ∉ ℚ(i,√3)
