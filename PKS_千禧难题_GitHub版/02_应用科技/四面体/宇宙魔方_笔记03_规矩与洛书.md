## 二、∞ 与"阴阳反向旋转"

"一阴一阳谓之道"可以精确化为两个**方向相反的旋转**：

```
z(t) = e^{iωt}        阳（逆时针，环绕数 +1）
w(t) = e^{−iωt}       阴（顺时针，环绕数 −1）
z · w = 1             两者互逆 —— "交感"而不"相消"
```

而且三角函数本身就是由这一对构造出来的：

```
sin(ωt) = (e^{iωt} − e^{−iωt}) / 2i
cos(ωt) = (e^{iωt} + e^{−iωt}) / 2
```

**几何图形上的 ∞（双纽线）**：最简参数式（Gerono 双纽线）

```
x = a·sin u
y = a·sin u·cos u = (a/2)·sin 2u
```

沿 u 从 0 走到 2π，会依次绕完两瓣。

> **⚠ 2026-10-14 更正**：原先这里写「左瓣环绕数 +1 / 右瓣环绕数 −1 / 和 = 0」——**这个说法不成立**。
> 环绕数的定义要求闭合曲线**不经过**所绕的点，而双纽线在 u = 0、π、2π 处恰好**压在原点**上，
> 绕原点的环绕数**无定义**。硬积分 ∮ dθ（角速度）得到的 −0.2122 / +0.2122 随分割数漂移，没有极限。

**可积、且数值稳定的量是「有向面积」** ∮ ½(x dy − y dx)：

| 性质 | 解析值 | 本机实测 |
|------|------|------|
| 右瓣有向面积 | **−2/3** | −0.6666666667 |
| 左瓣有向面积 | **+2/3** | +0.6666666667 |
| 整条 ∞ 之和 | **0** | 2.0×10⁻¹¹ |

即：**同一根曲线，两瓣的有向面积大小相等、符号相反，总和精确归零**。
这与"一元平衡旋转"（合成角动量 L₁ + L₂ = 0）在结构上是同一句话
——「净为零」这个结论**成立**，只是**载体是面积，不是环绕数**。

### 2.1 球面太极双螺旋：把 ∞ 立起来的严格做法

老师给的 4 张 Python 图（`E:\pythonProject\费马螺旋\`）的核心，是一张**能严格落在球面上**的双螺旋。
读到公式层面只有三行：

```
θ = sgn(t) · |t|^(1/n)         方位角；幂次 n 控制"绞"
φ = arctan(sinh t) = gd(t)     极角；古德曼函数 Gudermannian
(ρ, z) = (cos φ, sin φ)        球面坐标
```

关键在古德曼函数的两条恒等式（本机逐点实算，误差 **2.22×10⁻¹⁶**）：

```
sin(gd t) = tanh t     ⇒   z = tanh t
cos(gd t) = sech t     ⇒   ρ = sech t
```

于是 **ρ² + z² = sech²t + tanh²t ≡ 1** —— 曲线**严格落在单位球面上**（不是拟合、不是近似）；
且 t → ±∞ 时 z → ±1、ρ → 0 ⇒ 两条股线**无限逼近南北两极却永不到达**（像经线绕向极点）。
这也顺手解释了观感上的"两端密、中间疏"：极区 dρ/dz → 0，同样的 t 步长挤成一团。

**阴阳关系**：*同一条曲线*的方位角相差 **π** 的两支，z 完全相同、xy 互为对径
⇒ 天然的**双螺旋（DNA）骨架**。再引入一个**反向扭转角 ψ**：

```
θ阳 = f + ψ
θ阴 = f + π − ψ        ⇒   相对角 = π − 2ψ
```

| ψ | 效果 |
|---|---|
| 0 | 标准对径 180°（阴阳最"开"） |
| π/2 | 两股**重合**（阴阳合一） |
| π | 两支**互换**（回到起点、互为镜像） |

**幂次 n 管什么**：`|θ|max = (4π)^(1/n)` 随 n 单调递减。
临界指数 **n\* = ln(4π) / ln π = 2.211023**（此时 |θ|max = π）；
n = e ≈ 2.718 ⇒ |θ|max = 2.537329（不足 π，不越对径）；
n = 2 ⇒ |θ|max = 3.544908 > π ⇒ **曲线越过对径**（画面里开始"自缠"）。

### 2.3 原 py 的两处瑕疵（照抄会把图画坏）

**(a) 基本版 `t ** (1/3)` 在 t < 0 时是 nan。** numpy 对**负底**的分数次幂返回 `nan`
（不是 −|t|^{1/3}）；`t ∈ [−π, π]` 的 1001 个采样点里有 **500 个是 nan** ⇒ 曲线断掉一半。
**正确写法**：`sgn(t) · |t|^(1/3)`。

**(b) 高级版双高斯权重在 u ≈ 0 处跳变。** 权重
`w(u) = e^{−(u+1)²/0.1} + e^{−(u−1)²/0.1} − 0.5·e^{−u²/0.5}`，`t = sgn(u) · w(u)/w(±1) · 4π`。
u ≈ 0 时两个正高斯都 ≈ e^{−10} ≈ 0，只剩**负数项**，乘上 `sgn(u)` 后：
`t(0⁻) = +6.737988`、`t(0) = 0`、`t(0⁺) = −6.737988` ⇒ **跳变 Δt = 13.475976**，
Matplotlib 把线段一连，就成了**两条横贯整个球体的假直线**。

> **病根一句话**：`w` 是**偶函数**、`sgn(u)` 是**奇函数**，「奇 × 偶 = 奇」；
> 奇函数在 0 处**要么过 0 要么跳**，而 `w(0) = 2e^{−10k} − 0.5 = −0.499909 ≠ 0` ⇒ **只能跳**。
> **Δt 与采样点数完全无关**：N 从 100 加到 10⁶，Δt 一位都不变（`tetra/tjump.js` 已核验）。
> 所以这是**公式的连续性缺陷，不是"采样点不够"**；N 越大，两段越贴到 ±6.738，跳变看着反而**更陡**。

> **另有一处"看得见、但不算错"的现象**：`u ∈ (0,1]` 覆盖 t ∈ [−6.738, +12.566]，
> `u ∈ [−1,0)` 覆盖 [−12.566, +6.738] —— 两段在 |t| ≤ 6.738 上**完全重叠**，
> 也就是**曲线被画了两遍**（视觉无碍，但采样翻倍、极区更密）。
> 更反直觉的是：把权重宽度整体缩放 k 倍，**曲线集合完全不变**
> （u ∈ [−1,1] 的 t 像始终是 [−4π, +4π]），变的只有**采样点疏密**。
> 实算 k 从 0.45 → 4.20：极区（|z| > 0.99）样本占比 **82.43% → 51.19%**，
> 赤道带（|z| < 0.10）**0.65% → 4.12%**。所以模式 ① 第 5 条路径画的是**点云**而非曲线
> —— 曲线看不出差别，**点云才看得出**。

### 2.3.1 赤道过渡"不丝滑"的第二个独立原因（2026-10-14 二次）

老师指出「红蓝曲线在**赤道面过渡不丝滑**」—— 这与上面的跳变**是两个独立问题**：

- 方位角 `θ = sgn(t)·|t|^{1/n}` 在 `n = e > 1` 时，`dθ/dt = (1/n)|t|^{1/n − 1} → ∞`（t → 0），
  弧长速度 `σ = ds/dt = √(φ′² + cos²φ·θ′²)` **同时在赤道发散**
  （实测 `dθ/dt`：t = 0.1 → 4.287、t = 1e−5 → 1447）。
- 而原权重**恰好把 82% 的点堆在两极、只给赤道带 0.65%** ——
  **采样密度与弧长速度正好反着**，赤道只剩几个点，折线只能用长弦跨过去 ⇒ 看着就是「拐」。
- ⇒ **调大 N 治不了**：N 增大只会让两极更密、赤道那几根长弦的端点更明确。

### 2.3.2 连续化修正（本页已实现，面板「采样参数化」/ 键盘 `−` `=` 可原/修对照）

把「双高斯权重」从**有符号位移**改当**密度**，再用累积分积回位置：

```
t(u) = sgn(s)·|s|^n ,   s = sOfL( L_tot · ∫_{−1}^{u}|w′(u)| du ⁄ ∫_{−1}^{1}|w′(u)| du )
w′(u) = −2(u+1)/a·e^{−(u+1)²/a} − 2(u−1)/a·e^{−(u−1)²/a} + (u/c)·e^{−u²/c}   （a = 0.1/k, c = 0.5/k）
```

性质（全部实测）：

| 性质 | 数值 |
|---|---|
| 端点 | `t(±1) = ±4π = ±12.566371` |
| 中心 | `t(0) = 3.67e−41` ⇒ **光滑穿过赤道** |
| 单调 / 连续 | 严格单调；最大单步随 N **线性**下降（比值 ≈ 100） |
| 断点 | 原 py 曲线 **nulls=4、4 段**；修正 **nulls=0、1 段** |
| 弦长 最大/平均（N=420，n=e） | 原 py **18.43** → 修正 **2.22** |
| 弦长 最大/平均（N=200） | 原 py **14.35** → 修正 **2.22** |
| 赤道带样本占比（k=1） | 原 py **0.65%** → 修正 **51.4%** |
| 极区带样本占比（k=1） | 原 py **82.0%** → 修正 **8.7%** |

- **密度分布与原式同源**：`|dt/du| ∝ |w′(u)|` ⇒ 采样密度沿曲线 `∝ 1/|w′|`，
  只把断点接顺、去掉重画。k 仍在起作用（修正的赤道占比 41.9% → 43.8%，随 k 单调变），
  但**均匀度始终是 O(1) 量级**（原式恒 ≈ 18~23，随 N 增长）。
- **数值稳定性的关键**：弧长表要**以 θ 为自变量**（`s = θ`，`t = sgn(s)|s|^n`）——
  因为 σ(t) 在 t = 0 发散、在 t 网格上积不出来；而 `dℓ/ds = √((dφ/ds)² + cos²φ)` 在
  `s = 0` 是有限值（n > 1 ⇒ 0），数值稳定。弧长表 `tot = 2·L[M] = 4.220658`、
  `smax = (4π)^{1/e} = 2.537328575332`。
- **修正后的写法与原式共用同一套 k 语义**：`|dt/du| ∝ |w′|` ⇒ k 越小，中段越"鼓"，
  赤道带占比越高。**「权重捏疏密、指数 n 捏绞合」这条分工不变。**
- ⚠ **实现坑（两处真 bug，都已修）**：
  ① `arcTable` 里 `tot` 若只累积 `s ∈ [0, smax]` 的**半程**弧长（= 2.110329），
     `sOfL` 会把它当**全程**用 ⇒ 除 u = 0/±1 外整段被压扁、曲线上留下假断点。
     全程必须是 `2·L[M]`。
  ② 断点判据**不能用 `|Δt| > 1`**：修正映射在 t 空间连续，但极点收尾那一步 Δt 大、
     **几何弦长却很小**（曲线本来就在收敛到极点），用 |Δt| 会误判成一个孤零零的极点。
     正确判据是**几何弦长** `d > 0.5R`。
  ③ 页面里 `cmpMaps` 必须挂在 `TJ` 上（不能只挂在 `window.__tj`），否则面板取 `TJ.cmp` 直接抛错。

### 2.4 一处"结论不成立"的更正：指数 n 的"最优"是伪结论

图 4（`指数参数优化分析.png`）的原 py 用 **YZ 投影到单位圆的双向 Hausdorff 距离**当作"对称性误差"，
再用 `minimize_scalar` 在 n ∈ [1.2, 3.5] 上求最小，得出"**n = e 最优**"。

**这条不成立。** 因为曲线在 `t = 0` 处**必过原点**（z = tanh 0 = 0、ρ = sech 0 = 1），
它的 YZ 投影**就是整个单位圆**，与圆的 Hausdorff 距离**恒为上界 1、与 n 无关**。
本页把 6 个 n 全复算一遍，结果**全部恰好 1.000000** —— 该度量对 n **完全不敏感**，
`minimize_scalar` 找到的"最优"只是数值噪声里的任意一点。

**真实分工**：**幂次 n 管绞合（θ 的径向扭转），双高斯权重管采样疏密（t 的分布）**，
两者**互不干涉**；而且"n = e 最美"这件事**与阴阳无关**（阴阳对径是结构性的，任何 n 都成立）。
若要给 n 一个硬指标，可证的只有单调关系 `|θ|max = (4π)^(1/n)` 与临界值 `n* = 2.211023`。

### 2.5 极角通项：把「太简单」的基本版升成一族花瓣曲线（2026-10-14 三次）

**老师原话**：「这个 **基本版用极角 φ = (π/2)·sin t（简谐）** 这个公式太简单了，你要改成**一个通项公式**，
然后**分多种情况画出不同的花瓣曲线**。」

参考材料：知乎《圈点圆的数学（CPR）》两篇（`zhuanlan.zhihu.com/p/2091628480580658425`、
`p/2091624493772956637`）—— 核心命题 `Geometry = Composition of Motions`、
`Fourier Series = Infinite Rotor Composition`、三维球面转子
`R₃(t) = r(cosθcosφ, cosθsinφ, sinθ)`，以及"**多一种运动用加法，多一个维度用乘法**"。
（两篇都**没有**出现 gd(t)、花瓣曲线的具体方程 —— 花瓣族是本项目自己推的。）

**(1) 通项**

```
θ(t) = t                        方位角：环向整整 1 圈
φ(t) = A · π · S(m·t)           极角：A 管幅度、m 管频率、S 管波形
S(u) = Σ_j a_j · sin(j u + ψ_j) 波形 = Rotor / 傅里叶叠加（一个转子 → 两个转子 → …）
(x, y, z) = R · ( sin φ · cos θ ,  sin φ · sin θ ,  cos φ )
```

**原「基本版」φ = (π/2)·sin t 就是 A = ½、m = 1、S = sin u 这一格** —— 它是通项的一个特例，不是另一套东西。

**(2) 为什么这条式子既能画花瓣、又是球面曲线**

赤道投影 `(x, y) = (sin φ·cos θ, sin φ·sin θ)` ⇒ 极径 `r(θ) = sin φ(t) = sin(Aπ·S(mθ))`。
**同一个 φ 既当球面高度、又当极径** —— 这是它比 2D 玫瑰 `r = cos(kθ)` 更好用的地方：
改一个 S，花瓣和球面高度同时变，不用写两套公式。

**(3) 瓣数：不是单调的**

`A = ½` 时 `r(θ + π/m) = −r(θ)`（因为 S 是 2π 周期、mπ 是 π 的整数倍），于是走的是**玫瑰曲线那套奇偶规则**：

| m | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 瓣数 | **1** | **4** | **3** | **8** | **5** |

即 `m 奇 → m 瓣`、`m 偶 → 2m 瓣`。**2→4、3→3、4→8、5→5 不是单调递增**，
这正是玫瑰曲线的本性（m 偶数时同一族瓣要"对折"才闭合）。

`A = 1` 时 `φ` 越过 ±π/2，`r(θ + π/m)` 的反号关系失效，瓣数**另算**
（m = 3、A = 1 → 赤道投影 **6 瓣**）。**所以页面里的瓣数是逐例数值实算的，不套公式**
（`petalTips()`：取 `|r| ≥ 0.995` 的局部极大，再按【点】去重 —— A = ½ 时奇数 m 的同一瓣会被正负半径各描一遍）。

**(4) 七种情况（面板「花瓣族」或 `Shift` + `,` / `.` 切换）**

| # | 名称 | A | m | S(u) | 赤道投影 | 看点 |
|---|---|---|---|---|---|---|
| 0 | 单瓣 · 原基本版 | ½ | 1 | sin u | **1 瓣** | 就是原来那条的立体样子 |
| 1 | 四瓣玫瑰 | ½ | 2 | sin u | **4 瓣** | 偶数规则 2m |
| 2 | 三瓣玫瑰 | ½ | 3 | sin u | **3 瓣** | 奇数规则 m |
| 3 | 八瓣玫瑰 | ½ | 4 | sin u | **8 瓣** | 偶数规则 2m |
| 4 | 五瓣玫瑰 | ½ | 5 | sin u | **5 瓣** | 奇数规则 m |
| 5 | 大小瓣 · 非对称 | ½ | 2 | sin u + ½ sin 2u | **4 瓣（一大一小）** | **S 换一次，瓣形就变** —— 通项的价值所在 |
| 6 | 越赤道 · 上下交替 | **1** | 3 | sin u | **6 瓣** | **A** 让 φ 越过 ±π/2，曲线穿赤道到对面半球 |

**(5) 与「高级版 φ = gd(t)」的关系**

两条路**只差一件事：极角走的是什么波形**。

| | 极角波形 | 性质 | 结果 |
|---|---|---|---|
| 花瓣族 | `S = sin`（**有界振荡**） | φ 在有限区间来回 | 花瓣（r 反复归零 → 瓣与瓣之间有尖） |
| 高级版 | `gd`（**单调趋饱和**） | φ 从 −π/2 一路爬到 +π/2 | 双螺旋，两极无限加密 |

所以"其它版本也有类似跳变"与"基本版公式太简单"是**两个独立的话题**：
前者是**双高斯 t(u) 的采样参数化**问题（§2.3.1–2.3.3，与波形无关），
后者是**极角波形本身**的表达力问题（本节）。

## 三、规矩：天圆地方，以及"化圆为方"的不可能性

### 3.1 尺规到底能作什么

"规"（圆规）+ "矩"（直角尺）能作的长度，恰好是由有理数经 `+ − × ÷ √` 得到的数
（**尺规可作数的域**）。这就是"规和矩是造化精妙结构的振动弧度"在数学上的最准确翻译：
**它不是任意长度都能作出的，能作的长度被一个代数结构严格限定。**

### 3.2 方圆比例

| 量 | 值 |
|------|------|
| 内接正方形（4 顶点在圆上）边长 | R√2 |
| 内接正方形 / 圆 面积比 | 2R²/(πR²) = **2/π = 0.636620** |
| 外切正方形（边与圆相切）边长 | 2R |
| 外切正方形 / 圆 面积比 | 4R²/(πR²) = **4/π = 1.273240** |
| 两正方形面积比 | 2 : 1（恒成立，与 π 无关） |

### 3.3 化圆为方为什么不可能

要把圆变成等面积正方形，需要作出长度 **√π**：

```
√π = 1.772453850905516
```

**Lindemann（1882）** 证明 π 是**超越数**（不是任何整系数多项式方程的根）。
若 π 是超越的，则 √π 也不是代数数，更不可能属于尺规可作域
⇒ **用规和矩作出与圆等面积的正方形，永不可能。**

这给"规矩"划了一条硬边界：**规与矩能作出全部二次扩张的数，但作不出超越数。**
"矩"的直角是 90°（二次），它管不到 π。

### 3.4 阿基米德的夹逼：天圆地方的原始算法

阿基米德用内接 / 外切 96 边形把 π 夹住：

```
223/71 = 3.140845  <  π  <  22/7 = 3.142857
```

这就是"以方逼圆"—— 也是"天圆地方"在算法上最早的落地。

## 四、洛书九宫：一个可穷举的定理

### 4.1 洛书

```
4  9  2
3  5  7
8  1  6
```

**八条线的和全部等于 15**（3 行 + 3 列 + 2 对角）。

### 4.2 三条可验证的结论

**(1) 幻和 = 15**

```
幻和 = 3(9+1)/2 = 15
九数之和 = 1+2+…+9 = 45 = 3 × 15
```

**(2) 中心必为 5**（一行证明）

四条过中心的线和 = 4 × 15 = 60。九数之和 = 45，故中心被重复计入 3 次 ⇒

```
45 + 3·(中心) = 60  ⇒  中心 = 5
```

**(3) 本质唯一：全部解恰好 8 个**

把 1–9 全排列暴力枚举（362 880 种），满足 8 线全等 15 的解恰好 **8 个**：

```
#1  4 9 2 / 3 5 7 / 8 1 6      #2  8 3 4 / 1 5 9 / 6 7 2
#3  6 1 8 / 7 5 3 / 2 9 4      #4  2 7 6 / 9 5 1 / 4 3 8
#5  2 9 4 / 7 5 3 / 6 1 8      #6  6 7 2 / 1 5 9 / 8 3 4
#7  8 1 6 / 3 5 7 / 4 9 2      #8  4 3 8 / 9 5 1 / 2 7 6
```

而 **8 恰好是正方形对称群 D₄ 的阶数**（4 个旋转 × 2 个镜像）。
即：这 8 个解只是**同一个幻方在旋转与镜像下的像**。

> **这是本页最值得强调的一句**：三阶幻方**本质唯一**。
> 不是"洛书碰巧成立"，而是"除了洛书及其 8 个对称像，别无他解"。
> 这个结论是**穷举证明**的，可复算（演示页模式 3 会循环展示这 8 个变体并逐条扫描）。

### 4.3 河图 vs 洛书

| | 用数 | 总和 | 备注 |
|------|------|------|------|
| 河图 | 1–10 | 1+…+10 = **55** | 奇数和 25，偶数和 30 |
| 洛书 | 1–9 | 1+…+9 = **45** | 幻和 15 |

两者差 10，正对应"中央 5 + 10"的说法。
**能说的**：这两个数字结构本身都成立；**不能说的**：把它们当成宇宙生成公式。

## 六、晶体学限制：为什么周期世界里没有 5 次和 7 次轴

### 6.1 定理与一行推导

设格向量 **a**。若绕某轴转 `θ = 2π/n` 后仍得到格向量，则 `R(a)` 与 `a − R(a)` 都是格向量。
要求这组向量在整数格基下的矩阵**迹为整数**：

```
tr = 1 + 2cos θ ∈ ℤ
⇒  2cos(2π/n) ∈ ℤ
```

逐一检验：

| n | 2cos(2π/n) | 判定 |
|------|------|------|
| 1 | 2.000000000 | ✓ 允许 |
| 2 | −2.000000000 | ✓ 允许 |
| 3 | −1.000000000 | ✓ 允许 |
| 4 | 0.000000000 | ✓ 允许 |
| **5** | **0.618033989** | **✗ 禁止** |
| 6 | 1.000000000 | ✓ 允许 |
| **7** | **1.246979604** | **✗ 禁止** |
| 8 | 1.414213562 | ✗ 禁止 |
| 12 | 1.732050808 | ✗ 禁止 |

**⇒ 周期晶体只允许 2、3、4、6 次旋转轴。**

### 6.2 与七角星的呼应

这一条直接解释了笔记 01 的"七角星准周期宿命"：
7 不属于 {2, 3, 4, 6}，所以**七重对称不可能周期地铺满平面**；
而正七边形又不可尺规作图（cos 2π/7 是三次不可约多项式的根）。

### 6.3 历史的转折：准晶

1982 年 **Dan Shechtman** 在铝锰合金的电子衍射图上看到了**五次对称**——
按当时的定理这"不可能"。结果是他被质疑、被要求离开研究组，
但事实最终胜出：这是一种**非周期但有序**的新物相 —— **准晶**。
2011 年获诺贝尔化学奖。

**路径分叉的教益**：

- 坚持"周期" ⇒ 只剩 2、3、4、6 次轴；
- 放弃"周期"、保留"有序" ⇒ 5、7、8、12 次轴都能出现（只是不重复）。

> 这条定理不是"禁止 5 次轴"，而是"**禁止 5 次轴 + 周期**"。
> 视频里五角星、七角星的神秘感，本质上来自这个**约束组合**，而非某个数字的神秘属性。

## 八、五柏拉图立体：ℤ³ 上能严格画出几枚（2026-10-13 新增）

### 8.1 判定表

| 立体 | 顶点 / 棱 / 面 | 在 ℤ³ 上严格可画 | 需要引入的数 |
|------|------|------|------|
| 正四面体 | 4 / 6 / 4 | **✓ 可以** | 只用 `1, √2` |
| 正六面体（立方体） | 8 / 12 / 6 | **✓ 可以** | 只用 `1` |
| 正八面体 | 6 / 12 / 8 | **✓ 可以** | 只用 `1` |
| 正十二面体 | 20 / 30 / 12 | **✗ 不行** | 需要 `φ` |
| 正二十面体 | 12 / 30 / 20 | **✗ 不行** | 需要 `φ` |

**⇒ 三维整数格族上，能"严格正"画出来的柏拉图体只有 3 家。**

### 8.2 为什么正好卡在 φ 上

立方格上的长度都是 `√(整数)` 形式，即属于域 `ℚ(√2, √3, √5, …)`；
而十二/二十面体的顶点坐标含 `φ = (1+√5)/2`，它的极小多项式是

```
f(x) = x² − x − 1        （φ 是它的根）
```

与"平方根世界"的生成元 `x² − 2` **互素**（无公共根）⇒

```
φ ∉ ℚ(√2)  ⇒  十二/二十面体顶点不可能落在一个整数格的格点上
```

**障碍不在点的数量，在代数域。** 这就解释了为什么"补交点"这条路（第 7 节）无论补多少都无效。

### 8.3 那老师（叮咚）是怎么"画出来"的？—— 绕五重轴转 72°

真正逃出整数格的是那个 **「72°」**。构造如下（已数值验证）：

1. 取一枚**格点正四面体** —— 棱长 `2√2`（就是 Merkaba 的阳四面体，顶点全在 `(±1,±1,±1)`）；
2. 绕**五重轴** `u = (0, 1, φ)/|(0, 1, φ)| = (0, 0.525731112, 0.850650808)` 每 **72°** 放一枚，共 **5 枚**；
3. 这 5 枚的顶点**去重后恰好 20 个**，与**正十二面体的 20 个顶点完全重合**（**20 / 20**）。

```
4 顶点 × 5 枚 = 20 顶点            （互不相交，无重叠）
每枚棱长 2.828427125 = 2√2 = 十二面体的面对角线
5 枚 = 5 枚正手性 + 5 枚镜像中的一半
⇒ 十二面体 = 5 枚格点四面体绕五重轴 72° 的轨道
⇒ 正二十面体 = 它的对偶（同一条轨道，取面心）
```

**关键理解**：每一枚单独看都是**严格的格点四面体**（整数坐标）；
"逃出整数格"的不是顶点，而是把它们**串起来的那个 72° 旋转** —— `cos 72° = (√5−1)/4` 里带着 √5。

这与第六节的**晶体学限制**（5 次轴被周期格排除）是同一个数学事实的两面：
> **加 72° 旋转 = 放弃"周期"** ⇒ 5 次轴得以出现，十二/二十面体随之出现。

### 8.4 偏差量化

### 8.6 「连线取交点」这条路能给出 φ 吗？（老师提示的验证，2026-10-13）

老师提示过一条思路：**生命矩阵（梅塔特隆）那 13 点的 78 条连线会产生大量次级交点**，
也许可以用「连线 → 取交点 → 交点当新顶点」这个办法，在三阶网格上凑出 5 种柏拉图立体。

这个思路值得认真验证，而且结论是**否定的**，原因很干净：

> **定理（域封闭性）**：若所有已知点的坐标都落在某个域 $K$ 里，
> 那么「过这些点画直线 / 平面，再取交点」得到的新点，**坐标仍然落在 $K$ 里**。
> （因为解线性方程组只用到 $+, -, \times, \div$。）

对两套格子分别代入：

| 出发的点集 | 所在域 | 一切交点所在域 | 能否含 φ |
|------|------|------|------|
| 三阶 64 网格的顶点（$\{−4,−2,0,2,4\}^3$） | $\mathbb{Q}$ | $\mathbb{Q}^3$ | **不能** |
| 三阶 64 网格四类点的并集（§7：$729 = 9^3$） | $\mathbb{Q}$ | $\mathbb{Q}^3$ | **不能** |
| 梅塔特隆 13 点（三角格 $\mathbb{Z}[\omega]$，$\omega = e^{i\pi/3}$） | $\mathbb{Z}[\omega]$ | $\mathbb{Q}(\sqrt3)$ | **不能** |

**梅塔特隆的精确复算**（`tetra/metaint.js`，坐标写成 $a + b\sqrt3$ 用有理数精确运算）：

```
13 点  →  C(13,2) = 78 组点对
       →  去重后  72 条不同直线          （有多点共线，78 段其实只落在 72 条线上）
       →  2556 组线对，其中 2253 组不平行
       →  去重后  398 个不同交点
       →  13 + 398 = 411 个候选点
分母最大绝对值 = 147    ⇒  全部是有理数组合 ⇒ 全部 ∈ ℚ(√3)²
```

也就是说：**交点确实"很多"（398 个），但它们一个都没跑出 $\mathbb{Q}(\sqrt3)$。**

复数化之后，这些点落在 $\mathbb{Q}(i,\sqrt3)$ 里；而

```
ζ₅ = e^{2πi/5} 是正五边形旋转 72° 的特征值
ℚ(ζ₅) 只在素理想 5 处分歧，ℚ(i,√3) 只在 2、3 处分歧 ⇒ 两者交为 ℚ
⇒  ζ₅ ∉ ℚ(i,√3)
```

**⇒ 连一个正五边形都凑不出来**，更不用说含 φ 的十二 / 二十面体。
数值搜索也印证了这一点：在全部 411 个候选点里搜「最接近正五边形」的 5 点组，
最好的结果只命中 **1 / 5** 个顶点。

> **两条互相印证的结论**：
> · §7：三阶网格把「顶点 + 双四面体棱交点」全收进来，并集**恰好是** $\mathbb{Z}^3 \cap [-4,4]^3 = 729$ —— **扩交点扩不出整数格**。
> · §8.6：梅塔特隆把 78 条线的交点全收进来（398 个），**也扩不出 $\mathbb{Q}(\sqrt3)$**。
>
> 一句话：**交点法只能「加密点」，不能「换域」。** 而 φ 是域的问题，不是点的问题。
> 所以真正能给出十二 / 二十面体的，只有 §8.3 那条路 —— **引入非有理角的旋转（绕五重轴 72°）**。

### 8.7.6 模式⑥「组合 · 重合 · 截角」—— 举一反三 · 闻一知十（14 条 · 2026-10-14 晚新增）

**由来**：老师指出「**正八面体也可以由两个四面体倒插重合得到**，在第一模式有写、但不够；
再**举一反三、闻一知十**，想想还有哪些几何体是通过重合或组合得到的，**不必局限柏拉图体，
可以扩展到欧拉几何、阿基米德几何**」。范围定为 **14 条全套**，位置定为**新增模式⑥**。

**做法：一条坐标都不写死，全部现算。** 新增几何工具模块 `CG`：

| 工具 | 语义 |
| ------ | ------ |
| `CG.planesSup(V,N)` | 顶点集 + 外向单位法向组 ⇒ 平面集 $n\cdot x=d$（$d$ = 支撑函数 $\max n\cdot p$） |
| `CG.fromPlanes(P)` | 平面集 ⇒ 顶点 / 棱 / 面（枚举三平面求交 + 逐面极角排序围多边形） |
| `CG.inter(A,B)` | 两体的平面集合起来再求交 = **交集** |
| `CG.trunc(V,N,t)` | 每个顶点加一张垂直于该顶点方向的平面，在棱上按比例 $t$ 切 ⇒ **截角** |
| `CG.dual(L,ρ²)` | **极对偶**：面平面 $n\cdot x=d$ ⇒ 新顶点在 $\rho^2 n/d$ |

**14 条清单**（V/E/F 为页内现算，与 `combo.js` 逐位一致）：

| 组 | 子页 | V/E/F | 关键量 |
| ------ | ------ | ------ | ------ |

**统一的截角比例是解出来的**（正 $k$ 面体切出全等阿基米德体）：

$$t_k=\frac{1}{2+\sqrt{2-2\cos\theta_k}}\quad(\theta_k=\text{面角})$$

⇒ C1 / C2 / C5 都得 $t=1/3$；C3 得 $\sqrt2-1\approx0.292893$；C4 得 $1/\varphi^2\approx0.276393$。
**没有一个是拍脑袋设的。**

**三个坑（都踩过）**：

1. **倒插那一枚的面法向必须整组取反**。两枚四面体互为对心点反射 $x\mapsto-x$；
   若照搬母体法向组，`planesSup` 算出 $d=\sqrt3$（应为 $1/\sqrt3$），
   交集会**退化成母体自身**（算出 4/6/4 而非 6/12/8）。正解是拿**对方**的顶点方向当法向。
2. **对偶要用「极对偶」，不能用「面心当新顶点」**。后者对柏拉图立体碰巧同形，
   但对**立方八面体**会把 8 个三次顶点放到 1.1547（真值 $\sqrt3/2=0.866$），
   且四边形面**不共面**（三积 $=4/9\ne0$）。极对偶 $n/d$ 的逐面共面度实测 $0.00\times10^{0}$ ✓。
3. **`{V}` 不等于一个立体**。A3 里缩放二十面体最初写成 `{V: ICO12.map(×k)}`，没有 `.E`；
   `pathDraw` 不吞异常、`onFrame` 记 `__errs` 后停帧 ⇒ 画面只出红虚线，
   **蓝虚线 / 青绿交集 / 提示条 / 读数表全部消失**。修法：一律 `CG.fromPlanes(CG.planesSup(V,N))`
   重建，保证 `.V/.E/.F/.planes` 四件齐全。

**验收**：14 条逐条 × 5 个时刻冒烟 ⇒ `EXCEPTIONS: 0`、`window.__errs` 全空；
数值与独立复算脚本逐位一致（棱长全等 `allUni` 全 true、欧拉数、体积比）。
