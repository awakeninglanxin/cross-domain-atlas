2. k(ρ) 在数学里的正式名字：Cayley 变换

2.1 代数身份

(a−x)/(a+x) 是分式线性变换（Möbius 变换），特例即 Cayley 变换（A. Cayley, 1846），

标准形式 f(z) = (z−i)/(z+i) 或实轴形式 (x−1)/(x+1)。

它的招牌性质：把右半平面映到单位圆盘。

把 k(ρ) 写成这个标准形式：

k(ρ) = (√2 − ρ)/(√2 + ρ)
     = (z − 1)/(z + 1)        取  z = √2 / ρ

两边恒等，不是近似（数值差 0.00e+00）。也就是说：

k 就是"归一化阻抗 z = √2/ρ"的反射系数。

2.2 双曲形式

k(ρ) = tanh( ½ · ln(√2/ρ) )        实测差 ≤ 5.6e-17
⇒  artanh k = ½ ln√2 − ½ ln ρ       （与 ln ρ 严格线性，斜率 −½）

这一步把 k 变成了双曲距离：artanh k 与 ln ρ 只差一个线性变换。

所以 ρ 轴用对数刻度时，k 的 artanh 就是"到匹配点的距离"。

Cayley 变换条目里有一句可以直接引：*"In electrical engineering the Cayley transform has been

ρ ↔ k 的曲线形状和圆图上"沿等电阻圆走"的读数规律一致：都是 Möbius 变换的几何。

年份更正（2026-10-30 晚自查）：本节初版把 Fresnel 一栏记作 1818，记错了。
1818 年那篇是菲涅耳的衍射论文（1819 年获巴黎科学院奖）；反射／折射振幅公式的推导
见于 1823 年 1 月提交法国科学院的论文，其中正弦定律、正切定律的现代形式首次给出；
1821 年他先用弹性横波模型得到等效结果。正入射式 r=(n₁−n₂)/(n₁+n₂) 记作 1823 年。

5. 🔴 边界：形式同构 ≠ 物理同一

必须写在页面上，防止被读成"发现了新物理"：

  1. 不能说"空腔就是一段失配传输线"。只能说"这套几何的比例关系可以按反射系数来读"。
  2. √2 在这里只是标度。换成 k = (a−ρ)/(a+ρ)，a 取别的值照样成立，只是"匹配点"挪位置。 所以"白银比"不是被物理选中的，是被这个几何构造选中的（内倒四面体恰在 ρ=√2 塌陷）。
  3. 检索边界：本轮查了 OEIS、维基（Cayley／Rapidity／√2）、arXiv、ScienceDirect， 没有找到把 (√2−ρ)/(√2+ρ) 当"白银比几何通项"使用的文献。 如果将来要对外宣称"这是新公式"，这一条必须先说清楚：骨架是 1823 年的，具体式没查到专文。

6. 另一条独立线索：平面直角三角形的 R/r 下确界

这一节与本文档的正四面体问题不是同一件事，但都用 σ，容易混，所以单列并划清界限。

6.1 定理

对任意直角三角形（勾 a、股 b、斜边 c），外接圆半径 R = c/2，内切圆半径 r = (a+b−c)/2：

R/r = √(1+ρ²) / ( 1 + ρ − √(1+ρ²) )        ρ = b/a

数值扫 ρ ∈ [0.5, 2.5]（步长 5e-4）得最小值 2.414213562373，落在 ρ = 1.00000，

即 1+√2。求导可证 ρ = 1（等腰直角）是唯一极小点。

任意直角三角形，R/r ≥ 1+√2；等号只在等腰直角三角形取到。

这个"特例值"是中学题（等腰直角 R/r = √2+1），但以下确界形式陈述的文献，

本轮没有检索到 —— 结论本身是初等的，几乎不可能没人做过，引用时按"初等结论"处理，别当新发现。

6.4 20-21-29 到底特殊在哪

两句话，都不涉及物理：

  1. R/r = 29/12 恰好是 σ 的第 4 个连分数收敛项（2/1, 5/2, 12/5, 29/12, 70/29…）， 偏差只有 +0.102%，是"够小又够小"的第一代成员（3-4-5 差 3.55%，太大）。
  2. 它属 Pell 三元组：三边 |b − a| = 1，通项 (2PₙPₙ₊₁, Pₙ₊₁²−Pₙ², Pₙ₊₁²+Pₙ²)，序列为 (3,4,5)、(20,21,29)、(119,120,169)… 文献里叫 "Pell spine"，是勾股树的主干。

几何上它就是"最接近等腰直角的整数直角形"，而等腰直角恰好是 R/r 取 σ 的那一点 ——

这才是它跟白银比扯上关系的唯一原因。不是核物理，不是常数巧合。

白银比是二维直角三角形的特产，不升维。 三维换成 √3 系统。

# -*- coding: utf-8 -*-
import math
s2 = math.sqrt(2); s3 = math.sqrt(3); s6 = math.sqrt(6)

# §1 k(rho) 通项：从四面体几何独立推导
def k_geo(rho):
    c = rho / math.sqrt(1 + rho*rho)      # cos = 股/斜边
    s = 1.0 / math.sqrt(1 + rho*rho)      # sin = 勾/斜边
    t = (1 + rho*rho) / (rho * (rho + s2))
    uz = c * (s6/3) - s * (1/s3)
    return (1 - 12 * t * c * uz / s6) / 3, t

def k_fml(rho):
    return (s2 - rho) / (s2 + rho)

for r in (0.75, 1.0, 1.2, 4/3, 1.4):
    assert abs(k_geo(r)[0] - k_fml(r)) < 1e-12, r
assert abs(k_geo(4/3)[1] - 25/(16+12*s2)) < 1e-12      # 与 §3.2(c) 对齐
assert abs(k_geo(4/3)[0] - (17-12*s2)) < 1e-12          # 与 §3.2(e) 对齐

# §2 Cayley / 反射系数同构
for r in (1.0, 4/3, 1.4):
    z = s2 / r
    assert abs((z-1)/(z+1) - k_fml(r)) < 1e-15
    assert abs(math.tanh(0.5*math.log(s2/r)) - k_fml(r)) < 1e-15

# §4 工程读数
import math as m
k4 = k_fml(4/3)
print("k(4/3) =", k4, " 回波损耗 =", -20*m.log10(k4), "dB  VSWR =", (1+k4)/(1-k4))

# §6 平面三角形 R/r 下确界
Rr = lambda r: math.sqrt(1+r*r) / (1 + r - math.sqrt(1+r*r))
best = min((Rr(0.5+i*0.0005), 0.5+i*0.0005) for i in range(4001))
print("R/r 最小 =", best[0], "at rho =", best[1], "  1+sqrt2 =", 1+s2)

10.6 物理对照：四组里只有一条边界是物理的

② σ 幂族σ 本身有硬出处（2D Ising kT_c/J = 2/ln σ、Ammann–Beenker 八重准晶膨胀因子 σ）；但"直径比 = σ^{2m}"无σ ★★★ / σ^{2m} ✗

为什么只有边界有物理：θ = arctan(股/勾) 是四面体几何唯一能感知的量，

换句话说：

四组不能各自对应四种物理，只能对应"同一条 θ 轴上的四段刻度"。
物理看得见的是 θ；看不见的是"弦整不整数"。

10.7 如果一定要给一个物理／工程读法：k 是折叠参数

b/a = k(ρ) = (√2 − ρ)/(√2 + ρ)
ρ → √2⁻  ⇒  b → 0   ：内倒四面体塌成一点 = 完全收拢（自锁位）
ρ > √2   ⇒  k < 0   ：已翻到外面 = 过折，机构越过死点

这对应刚性折纸 / 可展结构里的"完全折叠位置"与"过折失效"，是四组里唯一能对上真实临界现象的读法。

但它只用到 θ（或 ρ）这一连续参数，用不到四组的分组本身 —— 与 10.6 的结论一致。

所以「¹H 的 20.6 kHz 展宽」直接给出了转子选型的下界：3.2 mm 是这类样品的实际起点。这是本节唯一一句能拿去做实验的话。

🔴 一阶与二阶要分开：一阶四极项被魔角完全归零；但二阶四极展宽只按 ∝ 1/ν_rot 收缩，不归零。所以 ²⁷Al、²³Na 这些四极核必须拼命提转速 —— 魔角只解决一半问题，这一句常被略过。

11.7 偶极谱的形状：一次容易差一倍的错

两自旋 I = 1/2 的能级在 ± 上各移 d(3cos²θ−1)/4，四条允许跃迁合成两条谱线，位置为

ω = ω₀ ± (b/2)·(3cos²θ−1)      b = (μ₀/4π)γ²ħ/r³
