## 1. 先把 `k(ρ)` 的几何出身钉死（通项可独立重推）

### 1.1 已知特例

配套文档 §3.2 里，三角形的两腿取 **4a/5 与 3a/5**（即勾∶股∶斜 = 3∶4∶5），
由「令腿的 x 分量归零」解出共点参数

```text
t = 25 / (16 + 12√2) = 0.7582521543…
k = 17 − 12√2 = (√2 − 1)⁴ = σ⁻⁴
```

### 1.2 通项：把 3∶4∶5 换成任意勾股比 ρ

记 `ρ = 股/勾`，取斜边为 1，则 `cosθ = ρ/√(1+ρ²)`、`sinθ = 1/√(1+ρ²)`。
与 §3.2(b) 同一套基 `ĝ、ĝ⊥`，照抄推导步骤：

```text
t(ρ) = (1 + ρ²) / ( ρ (ρ + √2) )                 // 令 x 分量归零
z(ρ) = t · cosθ · ( cosθ·√6/3 − sinθ/√3 )        // 交点的 z 坐标
k(ρ) = ( 1 − 12·z/√6 ) / 3                       // D − k(V₃−D) 反解
```

代入化简，得到

```text
k(ρ) = ( √2 − ρ ) / ( √2 + ρ )
```

## 2. `k(ρ)` 在数学里的正式名字：Cayley 变换

### 2.1 代数身份

`(a−x)/(a+x)` 是分式线性变换（Möbius 变换），特例即 **Cayley 变换**（A. Cayley, 1846），
标准形式 `f(z) = (z−i)/(z+i)` 或实轴形式 `(x−1)/(x+1)`。
它的招牌性质：**把右半平面映到单位圆盘**。

把 `k(ρ)` 写成这个标准形式：

```text
k(ρ) = (√2 − ρ)/(√2 + ρ)
     = (z − 1)/(z + 1)        取  z = √2 / ρ
```

两边恒等，**不是近似**（数值差 0.00e+00）。也就是说：

> **`k` 就是"归一化阻抗 `z = √2/ρ`"的反射系数。**

### 2.2 双曲形式

```text
k(ρ) = tanh( ½ · ln(√2/ρ) )        实测差 ≤ 5.6e-17
⇒  artanh k = ½ ln√2 − ½ ln ρ       （与 ln ρ 严格线性，斜率 −½）
```

这一步把 `k` 变成了**双曲距离**：`artanh k` 与 `ln ρ` 只差一个线性变换。
所以 ρ 轴用对数刻度时，k 的 artanh 就是"到匹配点的距离"。

| ρ | k | tanh(½ ln(√2/ρ)) | 差 |
|---|---|---|---|
| 0.60 | +0.404233978751 | +0.404233978751 | 5.6e-17 |
| 1.00 | +0.171572875254 | +0.171572875254 | 2.8e-17 |
| 4/3 | +0.029437251523 | +0.029437251523 | 3.5e-18 |
| √2 | 0 | 0 | 0 |

## 3. 物理里"同骨架"的四处

| 领域 | 式子 | 年代 | 与本式的关系 |
|---|---|---|---|
| 光学 · Fresnel 正入射反射 | `r = (n₁−n₂)/(n₁+n₂)` | 1823 | 同骨架，a=n₁、x=n₂ |
| 微波 · Smith 圆图 | `Γ = (Z−Z₀)/(Z+Z₀)` | 1939 | **严格同构**：取 `Z/Z₀ = √2/ρ` 即得 `k` |
| 量子散射 · K 矩阵 → S 矩阵 | `S = (1−iK)/(1+iK)` | — | 同骨架（复变量） |
| 相对论 · Bondi k 因子 | `e^{−w} = √((1−β)/(1+β))` | — | 同骨架，外面多一层开方 |

Cayley 变换条目里有一句可以直接引：*"In electrical engineering the Cayley transform has been
used to map a reactance half-plane to the Smith chart used for impedance matching of transmission lines."*

`Smith 圆图` 的定义式 `Γ = (z−1)/(z+1)` 与 `k(ρ)` 是同一个函数，这解释了为什么
`ρ ↔ k` 的曲线形状和圆图上"沿等电阻圆走"的读数规律一致：**都是 Möbius 变换的几何**。

> **年份更正（2026-10-30 晚自查）**：本节初版把 Fresnel 一栏记作 **1818**，**记错了**。
> 1818 年那篇是菲涅耳的**衍射**论文（1819 年获巴黎科学院奖）；反射／折射振幅公式的推导
> 见于 **1823 年 1 月**提交法国科学院的论文，其中正弦定律、正切定律的现代形式首次给出；
> 1821 年他先用弹性横波模型得到等效结果。**正入射式 `r=(n₁−n₂)/(n₁+n₂)` 记作 1823 年。**
> 附表与 §0、§5 三处已同步改正，正文其余结论不受影响（都只用代数形式，不用年份）。

### 3.1 为什么这条年代要紧

对外只讲"形式同构"时年份无所谓；但只要写"两百年前就有"，年份就是**可被查证的具体断言**，
一旦写错，整条论证的可信度会被这一处拖死 —— 与本轮 §7.3 拒绝凑数 `137.036/4` 是同一条纪律：
**能核的必须核到年，不能核的就不写成具体历史。**

## 5. 🔴 边界：形式同构 ≠ 物理同一

必须写在页面上，防止被读成"发现了新物理"：

1. **不能说**"空腔就是一段失配传输线"。只能说"这套几何的比例关系**可以按**反射系数来读"。
2. **√2 在这里只是标度**。换成 `k = (a−ρ)/(a+ρ)`，a 取别的值照样成立，只是"匹配点"挪位置。
   所以"白银比"不是被物理选中的，是被这个**几何构造**选中的（内倒四面体恰在 ρ=√2 塌陷）。
3. **检索边界**：本轮查了 OEIS、维基（Cayley／Rapidity／√2）、arXiv、ScienceDirect，
   **没有找到**把 `(√2−ρ)/(√2+ρ)` 当"白银比几何通项"使用的文献。
   如果将来要对外宣称"这是新公式"，这一条必须先说清楚：**骨架是 1823 年的，具体式没查到专文**。

## 6. 另一条独立线索：平面直角三角形的 `R/r` 下确界

这一节与本文档的正四面体问题**不是同一件事**，但都用 σ，容易混，所以单列并划清界限。

### 6.1 定理

对任意直角三角形（勾 a、股 b、斜边 c），外接圆半径 `R = c/2`，内切圆半径 `r = (a+b−c)/2`：

```text
R/r = √(1+ρ²) / ( 1 + ρ − √(1+ρ²) )        ρ = b/a
```

数值扫 ρ ∈ [0.5, 2.5]（步长 5e-4）得最小值 **2.414213562373，落在 ρ = 1.00000**，
即 `1+√2`。求导可证 ρ = 1（等腰直角）是唯一极小点。

> **任意直角三角形，R/r ≥ 1+√2；等号只在等腰直角三角形取到。**

这个"特例值"是中学题（等腰直角 `R/r = √2+1`），但以**下确界**形式陈述的文献，
本轮没有检索到 —— 结论本身是初等的，几乎不可能没人做过，引用时按"初等结论"处理，别当新发现。

### 6.2 同一 ρ 参数化下的两个特征点

| ρ | R/r（平面三角形） | k（内倒四面体） | 说明 |
|---|---|---|---|
| 0.500 | 2.927050983 | +0.477594 | |
| 0.750 | 2.500000000 | +0.306908 | 3∶4∶5 的"勾股互换"位 |
| **1.000** | **2.414213562** | +0.171573 | **R/r 的极小点 = σ** |
| 1.200 | 2.448545774 | +0.081942 | |
| **4/3** | **2.500000000** | **+0.029437** | 本文档的 3∶4∶5 |
| 1.500 | 2.585646365 | −0.029437 | k 已反号 |
| **√2** | — | **0** | **k 的零点 = 塌陷** |

两个函数共用同一个 ρ，但**特征点不同**：`R/r` 在 ρ=1 取极小，`k` 在 ρ=√2 过零。
3∶4∶5 的 ρ=4/3 正好夹在两者之间 —— 这是它在这个系统里位置特殊的直接原因。

另一个对称性：`R/r(ρ) = R/r(1/ρ)`（勾股互换不改变外内接比，实测 ρ=0.5 与 2.0 同为 2.927050983）；
而 `k(ρ)` **没有**这个对称性（√2 是锚点）。两者不可混用。

### 6.3 整数勾股三元组：等号取不到，用 Pell 收敛对逼近

ρ 只能取有理数时 `R/r > 1+√2` 恒成立，逼近序列恰是 σ 的连分数收敛对
（`p/q = 2/1, 5/2, 12/5, 29/12, 70/29, 169/70…`），对应「近乎等腰」的 Pell 三元组：

| 三元组 (勾,股,斜) | p/q | R/r | 相对 σ 的偏差 | (R/r)⁴ |
|---|---|---|---|---|
| 3, 4, 5 | 2/1 | 2.500000 | +3.554% | 39.0625 |
| **20, 21, 29** | **5/2** | **29/12 = 2.416667** | **+0.102%** | 34.1088 |
| 119, 120, 169 | 12/5 | 169/70 = 2.414286 | +0.0030% | 33.9746 |
| 696, 697, 985 | 29/12 | 985/408 = 2.414216 | +0.00009% | 33.9707 |
| 4059, 4060, 5741 | 70/29 | 5741/2378 | +0.000003% | 33.970563 |

### 6.4 20-21-29 到底特殊在哪

两句话，都不涉及物理：

1. **`R/r = 29/12` 恰好是 σ 的第 4 个连分数收敛项**（2/1, 5/2, 12/5, **29/12**, 70/29…），
   偏差只有 +0.102%，是"够小又够小"的第一代成员（3-4-5 差 3.55%，太大）。
2. 它属 **Pell 三元组**：三边 `|b − a| = 1`，通项
   `(2PₙPₙ₊₁, Pₙ₊₁²−Pₙ², Pₙ₊₁²+Pₙ²)`，序列为 (3,4,5)、**(20,21,29)**、(119,120,169)…
   文献里叫 "Pell spine"，是勾股树的主干。

几何上它就是"最接近等腰直角的整数直角形"，而等腰直角恰好是 `R/r` 取 σ 的那一点 ——
**这才是它跟白银比扯上关系的唯一原因**。不是核物理，不是常数巧合。

### 6.5 三维不继承

三个棱两两垂直的**直角四面体**（不是正四面体），取 a=b=c 时

```text
R/r = 3(1+√3)/2 = 4.098076211
```

1..10 的 41³ 网格数值扫（对数分度，a≤b≤c 剪枝）未见更小，最小仍在 (1,1,1)；
未做解析证明。且 (3,4,5)、(20,21,29) 作为三棱分别给
4.4036、4.2915，都更大。

> **白银比是二维直角三角形的特产，不升维。** 三维换成 √3 系统。

### 6.6 🔴 与本文档正四面体 σ⁴ 的关系：两件事，别合并

| | 平面直角三角形 R/r | 正四面体内倒四面体 a/b |
|---|---|---|
| 对象 | 一个三角形 | 两个嵌套四面体 |
| 比值 | `R/r ≥ σ` | `a/b = σ⁴` |
| 四次方 | **人为取幂**，无几何意义 | **几何必然**（4 条三重轴） |
| 等号 | 等腰直角取到 | ρ=4/3 取到 |

所以：`σ⁴` 在正四面体里是"棱长比"，在平面三角形里只是"R/r 下确界的四次方"。
**两者不是同一个定理的两种说法**，只是都出现 σ⁴。对外讲述时分开讲。

### 6.7 `(R/r)⁴` 的极限：**就是 σ⁴ = 33.970562748477…**

勾股取非常大的整数解时，`股/勾 → 1`（因为整数解只能无限逼近等腰直角，取不到等号），
而 `R/r` 在 ρ=1 取**极小**，所以从**上方**单调收敛：

```text
ρ → 1⁺  ⇒  R/r ↓ 1+√2  ⇒  (R/r)⁴ ↓ σ⁴ = 17 + 12√2 = 33.97056274847714058…
```

| 3-4-5 | 3 | 39.062500000000 | 5.092e+00 | — |
| 20-21-29 | 20 | 34.108844521605 | 1.383e-01 | 36.82 |
| 119-120-169 | 119 | 33.974623948355 | 4.061e-03 | 34.05 |

**收敛律**（这一步原来没写）：误差

```text
(R/r)⁴ − σ⁴ ≈ K · (股−勾)² / 勾²      K = (58 + 41√2)/2 = 57.9913780286…
```

K 由二阶泰勒系数定出（`ρ=1` 是极小点，一阶项为 0），数值识别残差 5e-23，**未化到符号推导**，
引用时按"数值常数"处理。由此两条推论：

1. **Pell 主干每进一级，误差精确缩小 σ⁴ = 33.9706 倍** —— 表中"上一步/本步"从第三行起就锁死在
   33.971±0.002，这就是 `(R/r)⁴` 与 σ⁴ 的比值本身的行为，不是拟合。
2. **收敛很慢**：误差 ∝ 1/勾²。要做到 6 位小数需 勾 ≈ 8×10³，9 位需 ≈ 2.6×10⁵，12 位需 ≈ 8.4×10⁶。
   所以"勾股很大"在这个问题上是**很奢侈**的说法 —— 33.970563 这个 7 位数要到 4059-4060-5741 才有。

> **极限值取不到**：等号要求 ρ=1，即等腰直角三角形；`√2` 无理 ⟹ 整数直角三角形的 `R/r` 恒 > σ，
> 只能下确界逼近。这一点与 §6.1 的"≠ 取到"是同一件事，只是这里给了收敛速度。

⚠️ 别把这条与 §6.6 混起来：`(R/r)⁴ → σ⁴` 是**取极限**得到的、且"四次方"是**人为取幂**；
正四面体的 `a/b = σ⁴` 是 **ρ=4/3 时精确成立**、四次方来自**几何**（4 条三重轴）。**同一个数，两条路。**

## 7. σ⁴ 在物理中：查到什么、查不到什么

### 7.1 有硬出处的（可引用）

| 对象 | 出场 | 数值 | 校核 |
|---|---|---|---|
| **σ = 1+√2** | 二维 Ising 精确解（Onsager 1944） | `kT_c/J = 2/ln(1+√2) = 2.269185314` | `sinh(ln σ) = 1.000000000000` ✓ |
| **σ = 1+√2** | 八重准晶 Ammann–Beenker 镶嵌的膨胀因子 | 2.414213562 | 实测材料 V-Ni-Si / Cr-Ni-Si |

## 8. 原子核半径 / 施瓦西半径：不成立

### 8.1 闭式

```text
核半径     R_nuc = r₀ · A^(1/3)          r₀ = 1.25 fm

核质量     M     = A · m_u                m_u = 1.66053907e-27 kg
⇒  r_s / R_nuc = [ 2G·m_u / (c²·r₀) ] · A^(2/3)
```

### 8.2 数值

|---|---|---|---|---|
| 1（质子） | 1.2500e-15 | 2.4663e-54 | **1.973e-39** | 5.068e+38 |
| 12 | 2.8618e-15 | 2.9595e-53 | 1.034e-38 | 9.670e+37 |

| 238（铀） | 7.7464e-15 | 5.8698e-52 | 7.577e-38 | 1.320e+37 |

### 8.3 要凑到 σ⁴ 需要什么

```text
令 1.973029e-39 · A^(2/3) = 33.970563
⇒ A^(2/3) = 1.7217e+40
⇒ A = 2.2592e+60
```

单个原子核的核子数上限约 1e57，**取不到**。所以这条"映射"不成立，不是精度不够，是量级不对。

### 8.4 这个比值在物理里的真名：紧凑度

|---|---|---|

若有人问"33.97 是不是某个天体的紧凑度"，答案是：**作为纯数值，1/σ⁴ = 0.0294 对应
M/R ≈ 1.98e25 kg/m，介于白矮星与中子星之间；但这是数值巧合，没有物理机制，不写进页面。**

## 9. 复算脚本

```python
# -*- coding: utf-8 -*-
import math
s2 = math.sqrt(2); s3 = math.sqrt(3); s6 = math.sqrt(6)

# §1 k(rho) 通项：从四面体几何独立推导
def k_geo(rho):
    c = rho / math.sqrt(1 + rho*rho)      # cos = 股/斜边
    s = 1.0 / math.sqrt(1 + rho*rho)      # sin = 勾/斜边
    t = (1 + rho*rho) / (rho * (rho + s2))
    uz = c * (s6/3) - s * (1/s3)
    return (1 - 12 * t * c * uz / s6) / 3, t

def k_fml(rho):
    return (s2 - rho) / (s2 + rho)

for r in (0.75, 1.0, 1.2, 4/3, 1.4):
    assert abs(k_geo(r)[0] - k_fml(r)) < 1e-12, r
assert abs(k_geo(4/3)[1] - 25/(16+12*s2)) < 1e-12      # 与 §3.2(c) 对齐
assert abs(k_geo(4/3)[0] - (17-12*s2)) < 1e-12          # 与 §3.2(e) 对齐

# §2 Cayley / 反射系数同构
for r in (1.0, 4/3, 1.4):
    z = s2 / r
    assert abs((z-1)/(z+1) - k_fml(r)) < 1e-15
    assert abs(math.tanh(0.5*math.log(s2/r)) - k_fml(r)) < 1e-15

# §4 工程读数
import math as m
k4 = k_fml(4/3)
print("k(4/3) =", k4, " 回波损耗 =", -20*m.log10(k4), "dB  VSWR =", (1+k4)/(1-k4))

# §6 平面三角形 R/r 下确界
Rr = lambda r: math.sqrt(1+r*r) / (1 + r - math.sqrt(1+r*r))
best = min((Rr(0.5+i*0.0005), 0.5+i*0.0005) for i in range(4001))
print("R/r 最小 =", best[0], "at rho =", best[1], "  1+sqrt2 =", 1+s2)
assert abs(best[0] - (1+s2)) < 1e-9

# §8 核 / 施瓦西
G, C, mu, r0 = 6.67430e-11, 2.99792458e8, 1.66053907e-27, 1.25e-15
coef = 2*G*mu/(C*C*r0)
print("r_s/R_nuc = %.6e * A^(2/3)" % coef)
print("要等于 sigma^4 需 A =", (33.970562748477/coef)**1.5)
```

## 10. 主界面「四组」标签页：通项、组间关系、物理对照

主界面参数面板把可选形状分成四个标签页（整数弦·本原 / σ 幂族 / 弦开不尽 / 不可内接），
下面把这四组的**分组判据、通项、彼此关系**逐条写清，再回答"能不能用到物理"。

### 10.0 四组的分组判据只有三条，全是算术

| 判据 | 含义 |
|---|---|
| **P1** | 弦 ∈ ℤ（勾股弦成整数三元组） |
| **P2** | 股/勾 ≤ √2（可内接 ⟺ 较大锐角 ≤ 54.7356°） |
| **P3** | 直径比落在 ℤ[√2]，即 `1/k = σ^{2m}` |

| 组 | 判据组合 | 成员数 | 怎么来的 |
|---|---|---|---|
| ① 整数弦·本原 | P1 ∧ P2 | **32** | 由欧几里得通项**现场穷举**（弦 ≤ 1000） |
| ② σ 幂族 | P3 | **8** | 有闭式，取前 8 项 |
| ③ 弦开不尽 | P2 ∧ ¬P1 | **8** | 手工挑选（见 10.3 的隐藏规律） |
| ④ 不可内接 | ¬P2 | **8** | 手工挑选（见 10.4 的两条子族） |

> 🔴 三条判据**没有一条是物理量**。物理只看角度和长度（连续），不看"弦是不是整数"。
> 这是 10.6 全部结论的根源。

### 10.1 组① 整数弦·本原：32 条（穷举，不是挑的）

通项 = 欧几里得 `勾:股:弦 = (m²−n²) : 2mn : (m²+n²)`，`m>n≥1`、`gcd(m,n)=1`、`m−n` 为奇；
再筛 P2。P2 等价于

```text
股/勾 ≤ √2  ⟺  m/n ∈ [ (1+√3)/√2 , √2+√3 ] ≈ [ 1.93185 , 3.14626 ]
```

`弦 ≤ 1000` 时得 **32 条**，大锐角区间 **45.0411° ～ 54.6998°**。

⚠️ **「整数弦」这个条件是自动成立的**：欧几里得通项的第三项 `m²+n²` 恒为整数。
所以组① 真正的筛选只有"可内接"一条 —— 标签里的"整数弦"是通项的副产物，不是额外约束。

这 32 条里贴魔角最近的是 **308:435:533**（股/勾 = 1.412338，θ = 54.6998°，距魔角仅 0.0358°），
但它满足 `435² − 2·308² = −503`，**不是** Pell 族成员 —— 组① 里贴得最近的并不来自组②。

### 10.2 组② σ 幂族：8 条，唯一有闭式的一族

```text
勾 + 股·√2 = σ^m · ( 1   （m 为奇）
                     √2  （m 为偶） )
⟺ 股² − 2勾² = −1（m 奇） / −2（m 偶）
⟺ 1/k = D外/D内 = σ^{2m}
递推 (勾,股)ₙ₊₂ = 6·(勾,股)ₙ − (勾,股)ₙ₋₂
```

| m | (勾, 股) | 股²−2勾² | k = b/a | 1/k = σ^{2m} | 弦 |
|---|---|---|---|---|---|
| 1 | 1 : 1 | −1 | 0.171572875 | 5.828427 = σ² | √2 开不尽 |
| 2 | 3 : 4 | −2 | 0.029437252 | 33.970563 = σ⁴ | **5 整数 ✓** |
| 3 | 5 : 7 | −1 | 0.005050634 | 197.994949 = σ⁶ | √74 开不尽 |
| 4 | 17 : 24 | −2 | 0.000866552 | 1153.999133 = σ⁸ | 开不尽 |
| 5 | 29 : 41 | −1 | 0.000148677 | 6725.999851 = σ¹⁰ | 开不尽 |
| 6 | 99 : 140 | −2 | 0.000025509 | 39201.999974 = σ¹² | 开不尽 |
| 7 | 169 : 239 | −1 | 0.000004377 | 228485.999992 = σ¹⁴ | 开不尽 |
| 8 | 577 : 816 | −2 | 0.000000751 | 1331713.999975 = σ¹⁶ | 开不尽 |

**几何读法**：这一族从**下方**单调逼近魔角（θ：45.000° → 53.130° → 54.462° → 54.6888° →
54.7276° → 54.7342° → 54.735374° → 54.735570°），同时 b/a 每级缩小 **σ² = 5.8284 倍**。
即：**组② 就是"逐级逼近完全收拢"的序列**，第 8 项的内倒四面体只剩外棱的 7.5e-7。

`m = 2` 是唯一弦为整数的一条 —— 这就是 3-4-5 成为"两个家族唯一交点"的原因（判据三已证）。

### 10.3 组③ 弦开不尽：页面没写出来的隐藏规律

8 条**全部满足 股 = 勾 + 1**：

| 勾:股 | 4:5 | 5:6 | 6:7 | 7:8 | 8:9 | 10:11 | 12:13 | 16:17 |
|---|---|---|---|---|---|---|---|---|
| 大锐角 | 51.34° | 50.19° | 49.40° | 48.81° | 48.37° | 47.73° | 47.29° | 46.74° |
| 弦 | √41 | √61 | √85 | √113 | √145 | √221 | √313 | √545 |

弦 = √(2k²+2k+1)。它什么时候才是整数？

```text
弦² = 2k² + 2k + 1
⟺ (2k+1)² − 2·弦² = −1
⟺ (2k+1) + 弦·√2 = σ^(2j+1)        （σ 的奇数幂）
```

| j | σ^(2j+1) | 勾 = (a−1)/2 | 股 | 弦 = b | 在组① 里吗 |
|---|---|---|---|---|---|
| 0 | 1+1√2 | 0 | 1 | 1 | 退化 |
| 1 | 7+5√2 | 3 | 4 | 5 | **在** |
| 2 | 41+29√2 | 20 | 21 | 29 | **在** |
| 3 | 239+169√2 | 119 | 120 | 169 | **在** |
| 4 | 1393+985√2 | 696 | 697 | 985 | **在** |
| 5 | 8119+5741√2 | 4059 | 4060 | 5741 | 弦 > 1000，超范围 |

> **所以组③ 与组① 不是两个独立的集合**：它们是同一个「股 = 勾+1」族按"弦是否整数"切开的两半。
> 弦为整数的 4 个成员全部落在组①（3-4-5、20-21-29、119-120-169、696-697-985），
> 其余成员落在组③。**两个标签页并列摆放，容易让人以为这是两类不同形状的三角形 —— 其实同族。**

🔴 更关键：**这两半在角度上完全混叠**。组③ 的 θ ∈ [46.74°, 51.34°]，
组① 的 θ ∈ [45.04°, 54.70°] —— 组③ 整个区间被组① 包住。
**任何物理观测量都分不开这两组**（见 10.6）。

### 10.4 组④ 不可内接：两条子族的并，不是随手挑的

| 子族 | 参数 | 通项 (勾, 股, 弦) | 成员 | 股/勾 |
|---|---|---|---|---|
| **A** | `n = m−1`, m = 3…7 | `(2m−1, 2m(m−1), m²+(m−1)²)` | 5:12:13、7:24:25、9:40:41、11:60:61、13:84:85 | `2m(m−1)/(2m−1)` → ∞ |
| **B** | `n = 1`, m = 4,6,8 | `(2m, m²−1, m²+1)` | 8:15:17、12:35:37、16:63:65 | `(m²−1)/(2m)` → ∞ |

两族交替排列（A 给 5 条，B 给 3 条，共 8 条），所以表格看上去"股/勾 不是单调的"——
不是笔误，是两条序列交错。**亚族 A 是"相邻参数"（最细长的一支），亚族 B 是"n=1"（另一支细长族）。**

### 10.5 一个统一观察：同一个 σⁿ 被组① 和组② 各读一次

记 `σ^n = a_n + b_n√2`（a、b 为整数，由 `(a,b) → (a+2b, a+b)` 递推）：

| σ^n | a + b√2 | 组② 的读法 (勾,股) | 「股=勾+1」的读法 (勾,股,弦) |
|---|---|---|---|
| σ³ | 7 + 5√2 | (5, 7) | (3, 4, 5) |
| σ⁵ | 41 + 29√2 | (29, 41) | (20, 21, 29) |
| σ⁷ | 239 + 169√2 | (169, 239) | (119, 120, 169) |
| σ⁹ | 1393 + 985√2 | (985, 1393) | (696, 697, 985) |

- **n 为奇**：组② 取 `(勾,股) = (b_n, a_n)`；「股=勾+1」族取 `((a_n−1)/2, (a_n+1)/2, b_n)`
- **n 为偶**：组② 取 `(勾,股) = (a_n, 2b_n)`

> 换句话说：**组① 与组② 的成员成对地来自同一个 σⁿ**，只是把它的两个整数系数读成了不同的三角形。
> 这不是巧合，而是 `1/k = σ^{2m}` 与 `(2k+1)+弦√2 = σ^{2j+1}` 两条式子是同一批代数数的两种投影。

### 10.6 物理对照：四组里只有一条边界是物理的

| 组 | 物理落点 | 强度 |
|---|---|---|
| ① 整数弦 | **无**。「弦是整数」没有任何观测量会因此跳变 | ✗ |
| ② σ 幂族 | **σ 本身**有硬出处（2D Ising `kT_c/J = 2/ln σ`、Ammann–Beenker 八重准晶膨胀因子 σ）；但"直径比 = σ^{2m}"**无** | σ ★★★ / σ^{2m} ✗ |
| ③ 弦开不尽 | **无**。与组① 在角度上完全混叠（10.3） | ✗ |
| ④ 不可内接 | 越过的边界 `股/勾 = √2` **有名字**：θ = 54.7356° = arctan√2 = ½·arccos(−1/3) = **魔角**，即 `P₂(cosθ) = (3cos²θ−1)/2 = 0`（NMR 魔角旋转 MAS 用的就是它）；但"越界"本身只是这套嵌套构造失效 | 边界值 ★★★ / 越界 ✗ |

**为什么只有边界有物理**：`θ = arctan(股/勾)` 是四面体几何唯一能感知的量，
而 P1、P3 是**算术性质**，它们只改变"哪一批整数被选中"，不改变任何连续的几何量。
换句话说：

> **四组不能各自对应四种物理，只能对应"同一条 θ 轴上的四段刻度"。**
> 物理看得见的是 θ；看不见的是"弦整不整数"。

### 10.7 如果一定要给一个物理／工程读法：`k` 是折叠参数

```text
b/a = k(ρ) = (√2 − ρ)/(√2 + ρ)
ρ → √2⁻  ⇒  b → 0   ：内倒四面体塌成一点 = 完全收拢（自锁位）
ρ > √2   ⇒  k < 0   ：已翻到外面 = 过折，机构越过死点
```

这对应**刚性折纸 / 可展结构**里的"完全折叠位置"与"过折失效"，是四组里唯一能对上真实临界现象的读法。
但它只用到 **θ（或 ρ）这一连续参数**，用不到四组的分组本身 —— 与 10.6 的结论一致。

| 52.3 Ω | 253.3 pF | 0.02248 | 32.96 dB |
| 53.033 Ω（理想） | 250.0 pF | 0.03052 | 30.31 dB |

误差打到 250 pF 标称值，RL 仍 > 28 dB。**这说明「几何可实现」不等于「需要精密调谐」** —— 反过来也说明这个几何本身对工程没有约束力，见 11.5。

### 11.3 失谐：几何只管实轴上一小段（但要说清管的是相位）

把频率从 10 MHz 推开，`X = ωL − 1/(ωC)` 不再是零：

| f（MHz） | X（Ω） | \|Γ\| | Γ 相位 | RL（dB） | VSWR |
|---|---|---|---|---|---|
| 8.000 | −28.274 | 0.266155 | −68.5° | 11.50 | 1.7254 |
| 8.692 | −17.68 | 0.171573 | −70.5° | 15.31 | 1.4142 |
| 9.000 | −13.265 | 0.130982 | −69.8° | 17.66 | 1.3014 |
| 9.500 | −6.449 | 0.069029 | −61.2° | 23.22 | 1.1483 |
| **10.000** | **0.000** | **0.029437** | **0.0°** | **30.62** | **1.0607** |
| 10.500 | +6.134 | 0.066294 | +60.3° | 23.57 | 1.1420 |
| 11.000 | +11.995 | 0.119279 | +69.2° | 18.47 | 1.2709 |
| 11.505 | +17.68 | 0.171573 | +70.5° | 15.31 | 1.4142 |
| 12.000 | +23.038 | 0.220096 | +69.9° | 13.15 | 1.5644 |

🔴 **这里有两个不同的门槛，不能混成一个**（我第一版混了，是错的）：

| 门槛 | 判据 | 什么时候破 |
|---|---|---|
| **相位出界** | `Im Γ ≠ 0` | **任何失谐都立刻破**。9 MHz 时 −69.8°，11 MHz 时 +69.2° |
| **幅度出界** | `\|Γ\| ≤ 0.171573`（VSWR ≤ √2） | 要 `\|X\| > 17.68 Ω`，即 f 出 **[8.69, 11.51] MHz** |

`k(ρ)` 是**实数**，所以严格讲：只要 Γ 带上相位，它就不再是 `k` 的任何一个取值 —— 相位这道门是立刻破的。
但幅度那道门很宽：Q 只有 1.1848、带宽 8.44 MHz，所以整段 8.69–11.51 MHz 的 `|Γ|` 都还 ≤ 0.1716。

**所以「几何只管实轴上一小段」这句话，严格指的是相位，不是幅度。** 写成「一失谐就超出几何范围」是夸大 —— 幅度上没有，相位上有。

### 11.4 天线侧：λ/4 变换器

`Zin = Z₁²/ZL ⇒ Z₁ = √(Z₀·ZL)`：

| 目标 Zin | 变换段特征阻抗 Z₁ | 长度 |
|---|---|---|
| 70.71 Ω（ρ = 1） | 59.46 Ω | λg/4 |
| 50.00 Ω（ρ = √2） | 50.00 Ω | 无需变换 |
| 39.28 Ω（ρ = 1.8） | 44.32 Ω | λg/4 |

**反例同样重要**：半波偶极的辐射电阻约 73 Ω，对应 `ρ = 50√2/73 = 0.9686` —— **掉在 [1, 1.8] 之外**。这不是巧合，是段的端点。`ρ = 1` 恰好是 `Z = 50√2 = 70.71 Ω`，而偶极比它更高，所以出界。

**结论：这段几何能覆盖的「纯阻可实现区间」就是 39.3 – 70.7 Ω，两端都用得着，中间点 50 Ω 正好是标准假负载。** 这是本节唯一一句能从几何直接读出的工程话。

### 11.5 🔴 这些数字的边界（必须写清，否则就是替这页吹牛）

1. **全是设计值，没有实测。** 没有算微带线宽与介质、没有算寄生、没有做 VNA 校准。真要上板，TXLine 之类工具走一遍即可，但那不是本文档的活。
2. **不能据此说「白银比在工程上有用」。** 因为 ρ 在这里是**自由参数**：ρ 取 1.1、1.5、1.7 都同样能焊出来，σ⁴ 一次都没被用到。§5 那条「形式同构 ≠ 物理同一」在这里依然成立。
3. **唯一与 σ 沾边的是 ρ 的两个端点**（1 与 1.8），而它们来自几何（折叠范围），不是来自电磁。
4. **反过来，这一节确实证明了一件有价值的事**：`k(ρ)` 不是一个空洞的代数式子 —— 它的定义域在物理上就是「一段纯阻」，边界在 39.3 / 70.7 Ω，而段外的阻抗（如 73 Ω 偶极）确实做不出来。**这个「做不出来」是可验证的，不是修辞。**

### 11.6 魔角侧：三个展宽量级

魔角 `arctan√2 = 54.7356103172°`，`(3cos²θ−1)/2 = 0`（复算残差 0.000e+00）。它抹掉的都是二阶张量项，量级如下：

| 被抹掉的项 | 具体量级 | 不转时的样子 | 复算依据 |
|---|---|---|---|
| ¹H–¹H 偶极耦合 | **20.60 kHz** | 20 kHz 宽的双峰鼓包 | `b = (μ₀/4π)γ²ħ/r³`，r = 1.8 Å ⇒ b/2π = 20.5967 kHz |
| ¹³C 化学位移各向异性 | **20.12 kHz** | 一条宽包 | 200 ppm × 100.6 MHz（9.4 T 下 ¹³C Larmor） |
| 一阶四极耦合（²⁷Al、²³Na…） | **MHz 级** | 极宽，常宽到不可解释 | `∝ C_Q`，与 B₀ 无关 |

**转速够不够，有个直接判据：转速 ν_rot 要 ≳ 展宽。** 用 ¹H–¹H 的 20.60 kHz 做标尺：

| ν_rot | 20.60 / ν_rot | 结果 |
|---|---|---|
| 15 kHz（4 mm 转子） | 1.37 | 整条谱只放得下 1 个边带间隔 ⇒ 边带互相重叠，谱不成形 |
| 20 kHz（3.2 mm 转子） | 1.03 | 刚好，勉强分开 |
| 24 kHz（3.2 mm 高速） | 0.86 | 够用，边带清晰可分 |
| 60 kHz（1.3 mm 转子） | 0.34 | 绰绰有余 |

所以**「¹H 的 20.6 kHz 展宽」直接给出了转子选型的下界**：3.2 mm 是这类样品的实际起点。这是本节唯一一句能拿去做实验的话。

🔴 **一阶与二阶要分开**：一阶四极项被魔角**完全**归零；但二阶四极展宽只按 `∝ 1/ν_rot` 收缩，**不归零**。所以 ²⁷Al、²³Na 这些四极核必须拼命提转速 —— 魔角只解决一半问题，这一句常被略过。

### 11.7 偶极谱的形状：一次容易差一倍的错

两自旋 I = 1/2 的能级在 ± 上各移 `d(3cos²θ−1)/4`，四条允许跃迁合成两条谱线，位置为

```text
ω = ω₀ ± (b/2)·(3cos²θ−1)      b = (μ₀/4π)γ²ħ/r³
```

对取向均匀的粉末平均后：

| 特征 | 位置 | 为什么 |
|---|---|---|
| horn（尖峰） | ±b/2 = ±10.30 kHz | θ → 90°，cosθ 变化最慢，取向密度发散 |
| shoulder（外缘） | ±b = ±20.60 kHz | θ = 0，密度最低，有限值后突然截断 |
| horn 间距 | **b = 20.60 kHz** | 这就是「20 kHz 宽鼓包」指的那个数 |
| 谱全宽 | **2b = 41.19 kHz** | 两侧往外各到 b |

🔴 **我在第一版里把「单晶 θ=0 的两线间距」写成了 b，实际是 2b = 41.19 kHz。** 因为 θ=0 时 `(3cos²θ−1) = 2`，谱线落到 ±b，间距自然是 2b。**horn 间距（b）和单晶间距（2b）差整整一倍，别混。**
