1. 问题的严格表述

设 T 是棱长为 a 的正四面体，重心（＝外心＝内心）为 O。

老师文档中的原始问法：「正四面体的外接球半径与其内部核心交合形成的倒正四面体的内接球半径的比值是多少？」——同段正文（第 7～8 段）实际用的是小四面体的外接球。

这两个问法结果完全一样，原因见下面的引理 0。

引理 0（比例不变性） 任意两个正四面体的任何对应长度之比都等于其棱长之比。

证明 正四面体的所有特征长度都是棱长的常数倍：

特征长度与棱长的比
高 h√6/3
外接球半径 R√6/4
内切球半径 r√6/12
棱切球半径√2/4
体积的立方根 V^(1/3)(√2/12)^(1/3)

两个正四面体棱长分别为 a、b 时，任何同一特征长度之比 = (常数·a)/(常数·b) = a/b。故「外接球半径比」＝「外接球直径比」＝「内切球半径比」＝「棱长比」＝ a/b。∎

于是问题化归为纯几何命题：求内倒四面体棱长 b 与外四面体棱长 a 之比。本文后续一律取 a = 1（齐次性，引理 0 保证可以这样取）。

2. 构造的精确定义（把描述形式化）

老师原文（第 2 段）描述的是这样一个结构：

「正四面体内有 12 个直角三角形构成，勾 3、股 4、弦 5，把弦长 5 的边作为四面体的棱长；从每一个顶点观察，三个直角三角形的直角边相互抵靠在一起，在四面体内部形成一个三角形空隙；4 个顶点 × 3 = 12 个直角三角形相互抵靠，中心交合处形成一个很小的倒正四面体。」

把它写成可计算的公理：

定义 1（外四面体） T 的顶点为 V₀, V₁, V₂, V₃，棱长 a，重心

V₀ = ( a/√3 ,      0 ,  0 )
V₁ = ( −a/(2√3),  a/2 , 0 )
V₂ = ( −a/(2√3), −a/2 , 0 )
V₃ = (  0 ,        0 ,  a√6/3 )
O  = (  0 ,        0 ,  a√6/12 )

自检：|V₃ − V₀| = a，其余同理；|V₀ − O| = a√6/4 = R。

定义 2（12 枚勾股三角形） 对每条棱 (i, j)：在「该棱与中心 O 所确定的平面」内、朝向四面体内部的一侧，作直角三角形，使其斜边恰为该棱（长 a），两条直角腿长分别为 3a/5 与 4a/5（3-4-5 相似）。

  • 6 条棱 → 6 个镜面（每个镜面必过 O）；
  • 每条棱上放 2 枚（3a/5 腿落在 i 端 / j 端各一枚）；
  • 合计 6 × 2 = 12 枚。

定义 3（股四腿） 12 枚三角形中，长度等于 4a/5 的那条直角腿称为该三角形的股四腿。每枚恰有 1 条，共 12 条。

定义 4（内倒四面体） 12 条股四腿在中心的交合点所构成的图形，记作 T′。

关键观察（本文证明的核心）：12 条股四腿恰好两两分组，每 3 条交于一点，共交出 4 个点；这 4 点两两等距，构成一个倒置的正四面体 T′。

3. 主定理与证明

3.1 引理 1：绕中轴 120° 旋转 ⇒ 三腿共点

记 ℓⱼ 为过 O 与 Vⱼ 的直线（中轴），Rⱼ 为绕 ℓⱼ 旋转 120° 的旋转。

引理 1（对称置换） Rⱼ 是 T 的对称变换，它把「从其余三个顶点出发、落在 Vⱼ 三条棱上的那 3 条股四腿」循环置换。

证明 正四面体的旋转对称群同构于 A₄，含 8 个 3 阶元素，正是在 4 条中轴上各转 120°/240°。故 Rⱼ 是 T 的对称，固定 Vⱼ，并把棱 (i, j) 映成棱 (k, j)（{i, k} 为除 j 外的另两顶点）。「位于 i 端的股四腿」是棱 (i, j) 上那枚三角形的固有几何对象，对称变换把它映成棱 (k, j) 上「位于 k 端的股四腿」。三条腿在该 3 元集合上循环置换。∎

引理 1′（共点） 上述 3 条腿交于 ℓⱼ 上同一点 Pⱼ。

证明 由引理 2（下一节）的共面计算，每条股四腿与 ℓⱼ 都相交，且交点落在腿的内部（参数 t ≈ 0.758 < 1）。设

L_i ∩ ℓⱼ = { Q_i }

由引理 1，Rⱼ(L_i) = L_k，而 Rⱼ 保持 ℓⱼ 逐点不动，故

Q_k = Rⱼ(L_i) ∩ Rⱼ(ℓⱼ) = Rⱼ(L_i ∩ ℓⱼ) = Rⱼ(Q_i) = Q_i

最后一个等号用了 Q_i ∈ ℓⱼ 被 Rⱼ 固定。于是 Q₀ = Q₁ = Q₂ = Pⱼ。∎

这一步就是老师说的「中心交合」：3 条腿在轴上撞在同一点。

3.2 引理 2：共面二维解 —— 解出共点参数 t 与比例 k

只需算 P₃ 一个点（其它 3 点由对称群作用得出）。

取 V₀、V₃、O 三点。由定义 1，这三点全在平面 y = 0 内（xOz 平面）。

（a）建立平面内正交基

ĝ  = (V₃ − V₀)/a = ( −1/√3 , 0 , √6/3 )        // |ĝ| = 1
ĝ⊥ = ( √(2/3) , 0 ,  1/√3  )                    // |ĝ⊥| = 1，且 ĝ·ĝ⊥ = 0

（b）股四腿的方向 直角三角形 V₀ V₃ A 中直角在 A，斜边 V₀V₃ = a，腿 V₀A = 4a/5。于是 V₀A 与 V₀V₃ 的夹角 θ 满足

cos θ = (4a/5)/a = 4/5 ,   sin θ = 3/5

朝内部（即朝中轴 x = 0）的那一支方向为

û = (4/5)ĝ − (3/5)ĝ⊥
  = ( −(4√3 + 3√6)/15 , 0 , (4√6 − 3√3)/15 )        // |û| = 1（自检 |û|² = 225/225）

（取「减」号是因为 +ĝ⊥ 会使 x 分量增大，远离中轴。）

（c）令 x 分量归零，解出 t 腿上的点为 V₀ + t·(4a/5)·û，t ∈ [0, 1]。要求 x = 0：

a/√3 + t·(4a/5)·( −(4√3 + 3√6)/15 ) = 0

以 a 约去，解 t：

t = 25 / (4(3√2+4)) = 25 / (16 + 12√2) = 0.7582521543…

（d）代回求高度

z(P₃) = t·(4/5)·(4√6 − 3√3)/15
      = (4√6 − 3√3) / (3(3√2+4))            // 有理化分母 (3√2−4)，分母 → 3×(18−16)=6
      = (36√3 − 25√6) / 6
      = 0.1860975888…  (a = 1)

（e）读出比例 k 按定义 T′ 与外四面体同心反向，故 P₃ 必形如

P₃ = O − k(V₃ − O)  =  ( 0, 0, √6(1 − 3k)/12 )

令其 z 坐标等于 (d) 的结果：

√6(1 − 3k)/12 = (36√3 − 25√6)/6
⇒ √6(1 − 3k)  = 72√3 − 50√6
⇒ 1 − 3k      = 72/√2 − 50 = 36√2 − 50
⇒ k           = 17 − 12√2

再展开验证（见 §4 路径③）：

(√2 − 1)² = 3 − 2√2
(√2 − 1)⁴ = (3 − 2√2)² = 9 − 12√2 + 8 = 17 − 12√2

所以

k = 17 − 12√2 = (√2 − 1)⁴ = 0.029437251522859414…

3.3 引理 3：T′ 是 T 的「反演同伦像」

由引理 1′ 与对称群在 4 条中轴上的传递性，对每个 j 都有

Pⱼ = O − k(Vⱼ − O) = O + (−k)(Vⱼ − O)

即 T′ 的顶点是 T 的顶点关于 O 作中心反演 + 相似比 k 的像。于是

T′ ≅ T（相似），相似比 k，且朝向相反（倒置）。

3.4 主定理

定理 内倒四面体棱长 b = k·a = a(17−12√2) = a(√2−1)⁴。

推论（主结论）

2R / 2r = R / r = a / b = 1/k = 1/(17 − 12√2)

而

(17 − 12√2)(17 + 12√2) = 17² − 2·12² = 289 − 288 = 1

（这正是 Pell 方程 x² − 2y² = 1 的一组解；见 §5）故

a/b = 17 + 12√2

再展开：

(1 + √2)² = 3 + 2√2
(1 + √2)⁴ = (3 + 2√2)² = 9 + 12√2 + 8 = 17 + 12√2   ∎

最终：

2R / 2r = (1 + √2)⁴ = 17 + 12√2 = cot⁴22.5°
        = 33.97056274847714058562026469051637694283606250452337687812016…

5. 为什么指数恰好是「四次」

层面解释
结构4 条中轴（每个顶点一条三重旋转轴）交出 4 个交合点 P₀…P₃，这个「4」正是四面体顶点数，也是指数的几何出处
半角半角公式 tan(θ/2) = (1−cosθ)/sinθ，取 θ = 45° 得 tan22.5° = √2 − 1；其倒数 cot22.5° = 1 + √2 = σ，故 k = tan⁴22.5°、a/b = σ⁴
Pell(1+√2)ⁿ = x + y√2 给出 Pell 方程 x² − 2y² = 1 的全部解：n = 1→(1,1)、2→(3,2)、3→(7,5)、4→(17,12)。第 4 项即 17 + 12√2
八边形正八边形旋转步长 45°，其「跨 3 边对角线 ÷ 边长」= sin67.5°/sin22.5° = 1 + √2 = σ；σ 的四次幂即该 45° 系统的封闭形式

Pell 序列对照表（x² − 2y² = 1 的连续解）：

n(1+√2)ⁿ 展开整数对 (x, y)数值
11 + √2(1, 1)2.4142135624
23 + 2√2(3, 2)5.8284271247
37 + 5√2(7, 5)14.0710678119
417 + 12√2(17, 12)33.9705627485

上表验证：17² − 2·12² = 289 − 288 = 1，故 17 与 12 确实是 Pell 方程的解，这也解释了为什么 17 与 12 这对整数会出现在闭式里。

7. 附：完整可复算脚本

# -*- coding: utf-8 -*-
"""自检脚本：验证 12 条股四腿共点、四点等距、比值 = (1+√2)^4"""
import math
S2, S3, S6 = math.sqrt(2), math.sqrt(3), math.sqrt(6)

def sub(a, b): return [a[i] - b[i] for i in range(3)]
def add(a, b): return [a[i] + b[i] for i in range(3)]
def mul(a, s): return [x * s for x in a]
def crs(a, b): return [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]]
def dot(a, b): return sum(a[i] * b[i] for i in range(3))
def nrm(a):
    n = math.sqrt(dot(a, a)); return [x / n for x in a]

A = 5.0                                   # 棱长 a
H = A * math.sqrt(2/3)
V = [[A/S3, 0, 0], [-A/(2*S3), A/2, 0], [-A/(2*S3), -A/2, 0], [0, 0, H]]
O = [0, 0, H/4]
FACES = [(0,1,2), (0,1,3), (1,2,3), (2,0,3)]
EDGES = [(0,1), (0,2), (0,3), (1,2), (1,3), (2,3)]

def insideT(p, eps=1e-9):
    for f in FACES:
        n = crs(sub(V[f[1]], V[f[0]]), sub(V[f[2]], V[f[0]]))
        if dot(n, sub(O, V[f[0]])) > 0: n = mul(n, -1)
        if dot(n, sub(p, V[f[0]])) > eps: return False
    return True

def make_fin(i, j, legP):
    """棱 (i,j) 上、从 i 端起直角腿长 legP 的 3-4-5 三角形，返回直角顶点"""
    P, Q = V[i], V[j]
    d = sub(Q, P); L = math.sqrt(dot(d, d)); dh = mul(d, 1/L)
    m = nrm(crs(d, sub(O, P)))            # 镜面法向
    n = nrm(crs(m, dh))                   # 平面内垂直棱
    foot = add(P, mul(dh, legP*legP/L))
    alt = legP * math.sqrt(L*L - legP*legP) / L     # = 12a/25
    apex = add(foot, mul(n, alt))
    if not insideT(apex): apex = sub(foot, mul(n, alt))
    return apex

KK = 17 - 12*S2                                     # k = (√2-1)^4
PCONV = [add(O, mul(sub(O, v), KK)) for v in V]     # 4 个交合点

print("k        =", KK, " (√2-1)^4 =", (S2-1)**4)
print("b        =", A*KK)
for j in range(4):
    print("  P%d ="%j, ["%.10f"%x for x in PCONV[j]], " |P-O| = %.10f"%math.dist(PCONV[j], O))
print("四点两两距离:", ["%.10f"%math.dist(PCONV[p], PCONV[q])
      for p, q in [(0,1),(0,2),(0,3),(1,2),(1,3),(2,3)]])

print("\n--- 12 条股四腿是否穿过对应交合点 ---")
ok = 0
for (i, j) in EDGES:
    for fr, to in [(i, j), (j, i)]:
        legP = 4*A/5 if fr == i else 3*A/5
        apex = make_fin(i, j, legP)
        a0 = V[fr]; d = sub(apex, a0)
        t = dot(sub(PCONV[to], a0), d) / dot(d, d)
        err = math.dist(add(a0, mul(d, t)), PCONV[to])
        good = err < 1e-9 and 0 < t < 1
        ok += good
        print("  腿 V%d→P%d  t=%.6f  err=%.2e  %s" % (fr, to, t, err, "OK" if good else "FAIL"))
print("通过 %d / 12" % ok)

ratio = (2*A*S6/4) / (2*A*KK*S6/4)
print("\n2R/2r    = %.16f" % ratio)
print("(1+√2)^4 = %.16f" % ((1+S2)**4))
