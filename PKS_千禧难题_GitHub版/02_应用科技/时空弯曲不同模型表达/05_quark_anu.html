先把一句话说完，再展开

夸克与 anu 的关系不是一句「它们相等」，而是三层不同强度的说法叠在一起：

  1. 第一层（原观测者，1908–1933）：没有任何关系。 Besant 与 Leadbeater 从未把 anu 说成夸克——夸克在 1964 年才被提出，他们 1933 年就去世了。 他们只报告了 形状与计数。
  2. 第二层（Phillips，1979–1980）：一份具体的、可逐项核对的身份断言。 U.P.A.（＝anu）＝ φ 或 π omegon；Hydrogen Triplet ＝ u 或 d 夸克；Hydrogen Triangle ＝ 质子。 同时给出 u = 2φ+1π、d = 1φ+2π、质子 = 5φ+4π、中子 = 4φ+5π。
  3. 第三层（可算的）：这些等式不是修辞。 用 omegon 电荷 +5/9 与 −4/9 代入，每一个等式都给出标准模型要求的电荷—— 本页 §3 的电量装配台就是把这件事做成可点的按钮。

§2三层断言分开摆：谁说了什么

Layer 1 · 1908–1951
Observed Shapes
anu = 十股螺旋流，两种手性；3 股更粗；心形凹陷；依次组成 Hydrogen Triplet（3 个）→ Hydrogen Triangle。 不含任何粒子物理概念。
〔Occult Chemistry, 3rd ed.〕
Layer 2 · 1979–1980
Identity Claim
anu = φ / π omegon；quark = 3 omegon；nucleon = 3 quark = 9 omegon。给 omegon 赋电荷 +5/9、−4/9，GUT 群 SU(10)f×SU(9)c。
〔Phillips, Phys. Lett. 84B, 133 (1979)；here.pdf 假设 1〕
Layer 3 · 能算
Arithmetic Outcome
u = 2φ+1π ⇒ +2/3；d = 1φ+2π ⇒ −1/3；质子 = 5φ+4π ⇒ +1；中子 = 4φ+5π ⇒ 0； M.P.A. = 两核 ⇒ N = 18A。每一条都能独立验算。
Layer 4 · 边界
未被满足的条件
无第二人独立复现 anu；磁单极子至今未被实验发现；M.P.A. 与核素身份的对应是推断； 「为什么恰好是两个核」作者自称「成问题」。

§3可现场验算：omegon 电量装配台

下面把「形状 → 粒子身份」这一跳变成算术题。规则只有两条（二者等价于 GUT 的电荷分配）：

φ omegon 电荷 = +5/9   |   π omegon 电荷 = −4/9 各带重子数 1/9

§5边界：这个接口有多窄，必须说清楚

本目录既有的 06 号文档给出的判断是「两者之间没有可换算的界面」。 读完 here.pdf 之后，本页把这个判断修正得更精确一点：

接口确实存在的地方
  • 电荷算术：omegon 电荷一旦给定，u、d、p、n 的组成被唯一确定，且结果与标准模型一致（§3 已验）。
  • 三元组的极性二分：三 omegon 系统只有两类电荷，与「三角组分正负两种、从不混淆」的记录一致（§3.1）。
  • 计数关系：N = 18A，在 95 个样本上线性回归 β = 18.03 ± 0.03，且伪造假设被 4σ 排除。
  • 真空畴／弦的图像：与 Nielsen–Olesen 涡旋、Meissner 效应、第二类超导体条件（ξ₀ ≪ λ）同构。
接口到不了的地方
  • 磁单极子至今未被实验发现。整个方案悬在一个未观测的粒子上。
  • 无第二人独立复现 anu 的观测；原观测者的材料、样品、条件均未记录。
  • 1680 圈、koilon、心形凹陷在标准模型里没有对应物——只对上「3」而落下「7、1680、koilon」，这个对应的证据力就弱了。
  • 核心前提是推断：「M.P.A. 由两个核生成」这一条，作者本人说「为什么恰好是两个，仍然成问题」。
Leadbeater 自述计数方法（here.pdf 书页 94 转引的原文） I counted all those 1,680 turns in the wire of the Anu, not once, but many times. I tried altogether 135 different specimens, taken from all sorts of substances.
—— 这不是数学推导，而是报告一次（声称的）计数。它的地位等同于「实验记录」，不是「理论预言」； 而它的问题恰恰在于不可复现。

5.1但有一条必须替 Phillips 说清楚

「事后比对（post-hoc matching）」是这类说法最常见的批评论点：挑着像的配。 但在这一处，批评会打偏，因为：

  1. 电荷 +5/9 与 −4/9 不是为了拟合 u、d 才挑的——它们是 SU(10)×SU(9) 的生成元在这个表示下的唯一可能取值（解 QL = −1, −2 的整数解）。
  2. 一旦确定，u、d、p、n 的组成被自动锁死，没有调节余量（§3 的穷举就是证明：其他两种三 omegon 组合电荷是 +5/3 和 −4/3，标准模型里没有这种粒子）。
  3. 而且它同时给出可被否证的计数关系 N = 18A——这是「事后比对」类说法通常提供不了的东西。
所以本页的结论是：不能笼统说「两者没有界面」。更准确的说法是—— 界面很窄，窄到只剩电荷算术与计数关系两条；但这两条恰好是唯一两条可以拿去算的。 至于「anu 是否真的被看见」，本目录不做判断；本页只负责把能算的算给你看。
