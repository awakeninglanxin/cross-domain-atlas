磁荷与洛书：Ω-9 磁荷矩阵演算

Phillips 在 ESP of Quarks（1980）里把 anu 认成 SU(9) 磁单极子，整套结构可以压缩成一个五层形式系统—— ima 笔记把它命名为 Ω-9 磁荷矩阵演算。本页把它落到三件能看、能算、能验的东西上：
① 一条对每个原子核都成立的通项定理；② 洛书幻方 = Z₉ 的逐层对应； ③ 三个可现场点的部件——「质子谱排不成全幻方」穷举台、夸克普查计算器、以及 A 的尺度之桥 （同一个 A：磁荷账本里乘 18，尺度桥里开 1/3 次方）。

§1一条通项定理，与五层总表

通项定理（对任意元素、任意核素成立）
H(A, Z) ≡ 0 (mod 9)　　—— 任意原子核的总磁荷恒等于零约束，不是随元素变的公式

这不是「每个元素的磁荷不同、可以列表」的那种规律，而是一条约束：所有元素（含全部稀土）的核总磁荷一律相同，都是 0。 所以磁荷分不清镧和镥——能区分它们的是 Anu 计数（B–L 的 N、Phillips 的 n = 18A、以及误差 N − n）。 Phillips 给的两种核子磁荷谱不只是模 9 抵消，整数和就精确为零：质子 4+3−6−1 = 0；氧 MPA 总账 80(+2)/64(+1)/80(−2)/64(−1) 也精确对消。

§3质子谱排不成全幻方（可现场穷举）

把核子的磁荷多重集填进 3×3，要求每行是合法夸克行（行和 ∈ {0, ±3, ±6}）。笔记给了一条可以当场验证的小定理：质子谱能摆到「行合法、全局归零」，但列永远无法同时归零 ⇒ 排不成完全幻方。

穷举台 —— 点格子交换，或一键随机 / 一键穷举全部

用法：点一个格子选中，再点另一个格子交换（多重集不变）。右列 = 行和，底行 = 列和；绿色 = 归零。完全幻方 = 三行全 0 且三列全 0。

障碍的根源是那个反复打交道的 5(+)/4(−) 个数不对称：完全幻方要求 6/3 型谱（如 {1×6, −2×3}，可排成每行每列都是 (1,1,−2) 的排列）——那不是核子。 换句话说，「全局抵消但局部漏电」不是模型没做干净，而是 5/4 结构的数学必然。氢变体 2 的 10+/8−、稀土表里永远小于 1 的正负比、和这里「排不成全幻方」，是同一件事的三个投影。

笔记原文给出的是 (3,0,−3) 一种行组合；本页穷举发现合法行结构实为两种（多出 (−6,3,3)，即一行为三个 −2）。结论「完全幻方 = 0」两者一致，行结构数以本页穷举为准。　A 组合数学，可复算

元宝对话（老师 2026-10-14 提供）把「原子为什么比核大五万倍」拆成了一个闭式。它与上面的普查公式共享同一个 A： 磁荷账本里 A 乘 18（omegon = 18A），尺度桥里 A 开 1/3 次方（R ∝ A1/3）——一个核子数，两本账。

§5核不是 27 阶幻方，是 2A 张三阶洗牌后的并集

纯幻方数学里「3 阶 → 9 阶 → 27 阶」（9×9×9 = 729 格）确实成立，甚至可证 9 张全同洛书按对齐平铺能拼出一张 9×9 幻方。但物理不走这条路。笔记的结论很干脆：不是分形，是壁纸。

物理层级内容束缚机制
1omegon（磁荷 ±1、±2）—
2夸克 = 3 个 omegonY 形 SU(3) 弦，结点通量 0 (mod 3)
3核子 = 9 个 omegon（3 夸克），「弦状激发分成三组、每组三个」SU(9) 九涡旋结，总通量 0 (mod 9)
4核 = A 个核子块；MPA = 两个核，N = 9(A₁+A₂) = 18A核力 = 弦间残余耦合

深度锁死在 3 层，然后线性重复。第四层起 A 是任意正整数、不需要是 3 的幂，所以「升阶」这条路被钉死：

  • 「27 阶幻方」= 729 格 = 单核 A=81（⁸¹Br）的 omegon 数——但 B–L 观察的 MPA 永远是两个核、计数是 18 的倍数，729/18 = 40.5 非整，连被观察的资格都没有。
  • 「27」真正出现的位置是块数：²⁷Al = 27 个核子块，不是 27 阶幻方。块数是线性变量，阶数是平方变量，两者正交。

比「不是分形」更狠的一步：连砖块都会被拆掉重发。Phillips 对 MPA 形成的描述是——微灵视扰动把两个核的夸克溶解成 omegon 等离子体，再重新聚集成「三组、每组三个」：氢 MPA 里两个质子的 omegon 可跨原质子重组；锂 MPA 的 14 个核子块被拆成 Ad6 双夸克、H3 三重态等新群；硫核比镁核多 4p4n，多出的 8 块以「每个卵形多 2 个 u、2 个 d 聚体」的方式填进漏斗，而不是把漏斗升级成更大的幻方。

一句话收束：为什么磁荷账本对几何不敏感

在幻方的全部性质里，只有「总和为零」是排列不变的——把九个数字任意打乱，总和不动；而「每线为零」会被打乱破坏。自然界只强制了最稳健的那一条（有限能量 / 有限涡旋）。B–L 看到的漏斗、球体、四面体，相当于 9!/(2!3!3!) = 5040 种排列中的一种——每一种的总磁荷都恒为零，所以磁荷记账永远无法区分它们，几何观察与电荷账本互不约束。唯一保证穿越洗牌的是总账 Σ = 0（加法结合律：每块 0，块的和的和还是 0）。

框架自己还下了禁令，翻译成幻方语言：自由的中性幻方只许 2 行（介子）和 3 行（重子），4 行及以上的自由系统被明文排除（"欧米伽力饱和仅发生在夸克–反夸克和三夸克束缚态中"）。确实存在 4-omegon（Li4）和 6-omegon（Ad6）这样的内部子群——但它们带净电荷、嵌在 MPA 里，是大账本里的非零行，不是中性幻方。

§6与真实核物理的交叉：两套 "magic"

笔记在这里主动接上了传统核物理——真实世界里真有一个半开玩笑得名的同款概念：幻数（magic numbers）2, 8, 20, 28, 50, 82, 126。核子数填满壳层时出现额外结合能、近球形、第一激发能级飙高（Wigner 当年觉得「简直像魔法」）。双幻核（质子中子同时闭合）是稳定性巅峰：⁴He、¹⁶O、⁴⁰Ca、⁵⁶Ni、²⁰⁸Pb。

一个三方交叉点

上一轮算出「正负 Anu 比恰好 = 1」的元素表（He-4、C-12、N-14、O-16、Ne-20、Mg-24、Si-28、S-32、Ca-40）里，⁴He、¹⁶O、⁴⁰Ca 同时是真实核物理的双幻核。 两套 magic 语义不同（幻方 = 电荷对消；幻数 = 壳层闭合 = 结合能峰值），但结构角色相同：闭合即稳。

再往下挖一层，"4" 以更具体的方式现身——α 团簇物理：4n 核的 α 粒子真的按点群对称性排布：⁸Be 两 α 链状、¹²C 三 α 等边三角形（D₃ₕ）、¹⁶O 四 α 正四面体（Td 点群）。代数团簇模型预言的转振谱 fingerprint 与 ¹⁶O 实验谱吻合；著名的 Hoyle 态就是 ¹²C 里三个 α 的稀疏玻色凝聚态。

看清楚了吗："4 阶" 在真实核物理里的对应物，不是 4×4 幻方，而是「四个 9-omegon 块排成 Td 四面体」——阶数仍在块内锁 3，"4" 出现在块的数目和块间的点群几何上。（彩蛋：氧在 B–L 的七组表里恰好也归四面体组——两套体系在此撞形，笔记标记为巧合，暂不过度声称。）

「几何 → 数列 → 核性质」的真实链路：幻数是这么排出来的

3D 谐振子壳层简并度（含自旋）= (N+1)(N+2) = 2, 6, 12, 20, 30, 42, 56——pronic 数，纯球对称的产物，与任何神秘数列无关。 裸累加得 2, 8, 20, 40, 70, 112, 168；自旋-轨道劈裂后高-j 闯入轨道（如 1f₇/₂）插队重排，才得到实测幻数 2, 8, 20, 28, 50, 82, 126。 前三项与裸累加重合不是巧合——N ≤ 2 时根本没有闯入轨道。整数序列要在物理里现身，必须有离散的拓扑约束（壳层简并度，或准晶能隙标号的 K₀ 群）； 而单个原子的半径没有任何这类约束——它由 Zeff、n*、A 三个连续变量决定（见 §4-2 尺度桥）。元宝对话把这类「撞数」逐个拆穿，结论与本项目纪律一致： 拓扑数列的真实归宿是准晶（φ↔Fibonacci↔5/10 次、δs = 1+√2 ↔ Pell ↔ 8 次、青铜比 ↔ 12 次，统摄方程 x² = mx + 1），与原子半径的计算机制不相交。

三条保留意见
  1. 这套框架尚未被物理界接受。本页做的是「把它讲清楚、把它能算的算出来、把它能验的验掉」，不是「它已被证实」。它是 ESP of Quarks（1980）的再诠释链，不是标准模型。
