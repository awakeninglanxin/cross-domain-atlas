关于这个模型要说清的一点：下面这些是按航拍图实测比例做的几何重建——三圆半径相等、圆心距 ≈ 1R、每个圆正好穿过邻圆圆心；侧簇中心距侧圆圆心 ≈ 1.5R；外层珠链间距按 ≈1.11 倍递增。公开文献里没有任何一份这个图案的作图记录或原作者的构造说明，所以这不是"复原某个已公布算法"，而是一个能生成同族图案的参数发生器：参数调到与参考图一致时它就画得像，参数推到极值它就长成别的结构。

生成模型：三圆半径 1、圆心距 gap（默认 1.00）；圆簇按 s=sizeRatio 逐层缩放、n 重排布、jitter 加不规则；垫片用复数笛卡尔圆定理
k₄ = k₁+k₂+k₃ ± 2√(k₁k₂+k₂k₃+k₃k₁) 递归求第四相切圆，种子取外圆 + 三个互切等圆（ρ = √3/(2+√3) ≈ 0.4641R）。
圆数统计包含所有可见圆（含垫片）。远场为 512×512 离散傅里叶变换（视野 ±32 阶），仅作定性对照，不是严格的电磁场求解；角向谱取自同一孔径按 512 个角度径向累加的一维 DFT。
阴阳只是渲染层。亮/暗来自「倒伏带 vs 站立麦」的日照差，几何（圆心、半径、层数、相位）一个都没动，所以 ① 相位图 ② 远场 ③ 角向谱 都不受这个开关影响——切阴阳不会改变频谱。
参考航拍图的明暗规律是：每条圆的边缘都是一条宽度恒定的倒伏亮带（≈0.055 世界单位）。圆越大，亮带相对越细，看着只是一条亮边；圆一小，亮带直接把整个圆填满，于是小圆自动长成亮环——侧簇那一串小环不需要单独建模，是同一个规则的必然结果。圈内则按层深交替明暗（亮 → 暗 → 亮），三圆是左亮、中暗、右亮，三圆交叠的透镜区最暗。
圆簇递归的骨架（一分二 → 二分四 → 四分八）：中心圈外径最大，先在最外层三圆里定骨架；侧簇以 sizeRatio 逐级缩小、以 ringRatio 决定子圆圆心到父圆心的距离，nCluster=2 时每一代正好一分为二、往外越生越小——层数 levels 每加 1，圆数翻倍。
等离激元近场是另一条独立的渲染支路，不是同一件事。它的几何源不是手写死的位置，而是从圆簇这棵树里现推出来的：每个圆的圆心落在某个更大的圆里，那个「刚好装得下它的大圆」就是它的父腔——这样反推出的父子关系与 addCluster 递归出来的完全一致，所以切到「二叉分岔」时近场也跟着变成二叉分岔，不用另配参数。几何来源有两档，默认是「手绘层」：直接拿你画的那批圆当腔阵列（父子关系照样按「圆心落在谁里面」反推），另一档是按参数生成的二叉分岔树。黑白填充也吃同一棵树：按代际交替倒伏黑盘 / 站立白盘，一层压一层咬出月牙，不是另写一套死坐标。
每个腔给出两样东西：径向驻波 rad(u)=cos(π n u/2)/(1+1.9u²)（u=r/a，n 取奇数，u=1 处仍严格为 0，所以每层圆的外径天然是一道暗节，而腔心是亮腹点 —— 早先写成 sin 时腔心恒为暗点，图上看着就是「蓝圈的圆心对不上亮斑」），和角向量子数 m=子腔个数（2 个子腔 → 四极，主瓣正对两个子腔；6 个 → 六极）。腔外还有一段按 e^{-(r-a)/λL} 衰减的泄漏，从暗节起跳往外一圈圈散开。
关键在相位：代际相位=交替 时父子腔反相（成键 / 反键），两者在交叠的透镜区正好相消——暗节就压在了层的边界上，也就是参考图里红色箭头指的那几条。n = round(a/(π/k)) 说明节距由同一个 k 统一决定：半径缩一代，腔里环数就少一多半，节点线仍然落在 j·π/k 上，于是「驻波节点落在第 2 层」不是运气，而是这套量子化条件的必然结果；「一键把暗节对齐第二层」就是把 k 取整到 jπ/R₂。
这仍然是类比模型：不是 Maxwell 解，没有色散关系、没有真实边界条件，也不做模式求解。它做的事只是把「圆心/半径/代际/子腔数」映射成一张近场图，用来看形态是否自洽。所以场图模式只替换渲染层：圆心、半径、相位量化、远场 FFT、角向谱全部照旧。
