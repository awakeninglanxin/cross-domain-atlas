## 〇、一句话对照

| | 超双曲锥（单叶双曲面） | 直圆锥（二次锥面） |
| ------ | ------ | ------ |
| 曲面方程 | `X² + Z² = 1/Y²` | `x² + z² = y²·tan²θ` |
| 截面方程里的关键项 | `1/(z₀ − ȳ·sin α)²` ← **非二次** | `v²·(cos²β·tan²θ − sin²β)` ← **二次** |
| 斜切结果 | **一种**：蛋形（两端一端尖一端钝） | **三种**：椭圆 / 抛物线 / 双曲线（按 β 分） |
| 为什么不是圆锥曲线 | 截面不是二次曲线，**不属于圆锥曲线族** | 截面就是二次曲线 |
| 决定形状的参数 | `k_E`（蛋形度）、`z₀`、`α` | 半顶角 `θ`、平面倾角 `β` |

> **核心区别**：蛋形之所以不叫「某一种圆锥曲线」，是因为它来自 **双曲面** 而不是 **二次锥面**。
> 截面方程里出现了 `1/(z₀ − z·sin α)²` 这种**非二次项**，于是它跳出圆锥曲线分类体系。

## 一、超双曲锥（单叶双曲面）的构造来源

### 1.1 从毕达哥拉斯单弦琴来

Schauberger 的出发点是一条**单弦琴**：弦长 `l` 与频率 `f` 满足

```
l · f = 1
```

再把「频率比」写成「整数比 `n₁ : n`」，令 `x = n₁/n`

```
x · y = 1        ← 双曲线（第一象限一支）
```

### 1.2 绕轴旋转成单叶双曲面

把 `x·y = 1`（`x > 0` 那半支）绕 **y 轴**旋转：

```
X² + Z² = 1/Y²        （等价于 r = 1/Y，r = √(X²+Z²)）
```

这就是**单叶双曲面**（也叫「超双曲锥」）。
**A 级**：网页视图 Ⅰ 里的曲面就是按 `r = 1/y` 逐点生成的（`N_R = 46` 条经线 × `N_T = 96` 个环）。

### 1.3 斜切平面

用一个倾斜平面去截它：

```
Y = z₀ − Z · tan α
```

法向 `n = (0, 1, tan α)`（已单位化），平面过点 `(0, z₀, 0)`。

**A 级验证**：三点 `(0, z₀, 0)`、`(r, z₀, 0)`、`(0, z₀ − r·tan α / 1, ...)` 均满足平面方程（网页里平面用 `PlaneGeometry` 绘制，位置与法向即上式）。

### 1.4 求截线（把平面参数化后代入）

平面上取**面内正交基**：

```
x̂   = (1, 0, 0)                                  水平方向
ê∥  = (0, −sin α, cos α)                          面内「竖直」方向
```

于是在平面内用 `(x̄, ȳ)` 参数化：

```
X = x̄
Y = z₀ − ȳ · sin α
Z = ȳ · cos α
```

代入 `X² + Z² = 1/Y²`：

```
x̄² + (ȳ cos α)² = 1 / (z₀ − ȳ sin α)²
```

整理得**截线的显式方程**（= 六公式里的 A1）：

```
x̄ = ± √( 1/(z₀ − ȳ·sin α)²  −  (ȳ·cos α)² )
```

**这就是蛋形曲线的来源**（**A 级**：与 `egg_curve.py` / `egg_analytic.py` 的实现逐字一致）。

> ⚠️ 注意右边第一项是 `1/(...)²`，**分母带 ȳ**——这是非二次项，蛋形「不是圆锥曲线」的根源就在这一项。

## 二、黄金极限蛋的参数从哪来

### 2.1 三个参数（A 级，已复算）

源码 `egg_curve.py → EggParams` 定义：

```
z₀   = (z₁² + z₂²) / (z₁ + z₂)              截面中心高度
tanα = z₁·z₂·(z₂ − z₁) / (z₁ + z₂)          截面倾角
k_E  = R / r = z₂ / z₁                      蛋形度
      其中 R = z₂/cos α（钝端半长）、r = z₁/cos α（尖端半长）
z₁ = 尖顶高度（基音），z₂ = 钝顶高度（泛音）
```

### 2.2 黄金极限值

`k_E*` 取二次方程

```
φ k² − φ² k − 1 = 0        的正根
     φ = 1.6180339887498948
```

**A 级复算**：`k_E* = 1.9370872430462651`，而 `φk² − φ²k − 1 = 0.0`（代入后精确为零）。

取 `z₁ = 1`、`z₂ = k_E*`，于是：

| 量 | 值 | 验证 |
| ------ | ------ | ------ |
| z₀ | 1.618033988749895 | = φ（**A 级**） |
| tan α | 0.6180339887498948 | = 1/φ（**A 级**） |
| α | 31.71747441146101° | **A 级** |
| k_E | 1.9370872430462651 | **A 级** |

**★ 一条干净的等价关系（A 级）**：

```
tan α = k_E (k_E − 1) / (k_E + 1)
```

代入 `k_E = 1.9370872430462651`：

```
1.937087243 × 0.937087243 / 2.937087243 = 0.6180339887498949
```

与 `1/φ = 0.6180339887498948` 差 `1e−16`（机器精度）。⇒ **黄金蛋的标志就是 `z₀ = φ` 与 `tan α = 1/φ` 同时成立**。

> ⚠️ **一处必须作废的旧写法**：早前有一版把它写成 `k_E = 1 + √(1 + z₀² − 2 z₀ cos α)`。
> **本机实测该式给出 1.9301989829，与 1.9370872430 不符（差 0.007）**。
> ⇒ **该式作废，不采用**。请以 §2.1 的 `z₀ / tan α / k_E = z₂/z₁` 三条为准。

### 2.3 八度蛋（对照组）

```
z₁ = 1, z₂ = 2
    k_E  = z₂/z₁ = 2.000000
    z₀   = (1² + 2²)/(1 + 2) = 5/3 = 1.6666667
    tan α = 1·2·(2−1)/(1+2)  = 2/3 = 0.6666667
    α    = 33.6900675°
```

**A 级**：上列三式均按源码定义手工代入，与 `EggParams(z1=1, z2=2)` 一致。

### 2.4 一条顺带验证的对应（A 级）

Rhino 参数方程里的 `k`、`b`（见文档 01 §二 · B）：

| | 黄金蛋 | 八度蛋 |
| ------ | ------ | ------ |
| Rhino `k` | 1/φ = 0.618034 | 2/3 = 0.666667 |
| **tan α** | **0.618034** | **0.666667** |
| Rhino `b` | φ = 1.618034 | 5/3 = 1.666667 |
| **z₀** | **1.618034** | **1.666667** |

⇒ **Rhino 的 `k` 就是 `tan α`，`b` 就是 `z₀`**。两参数与几何量一一对应，不是独立参数。
（`m` 用不到，`m = 1/φ` 只是同一常数换马甲。）

## 三、直圆锥的三种截面：判据与推导

### 3.1 直圆锥

半顶角 `θ`，顶点在原点，**轴沿 y**：

```
x² + z² = y² · tan²θ
```

### 3.2 斜切平面

平面过点 `(0, z₀, 0)`，含方向 `x̂` 与 `(0, cos β, −sin β)`。
其**法向** `n = (0, sin β, cos β)`，与 y 轴夹角 `90° − β`，故**平面与锥轴夹角 = β**。

平面内参数化（`u` 沿 x，`v` 沿面内方向）：

```
x = u
y = z₀ + v · cos β
z = −v · sin β
```

### 3.3 代入求交线

```
u² + v² sin²β = (z₀ + v cos β)² tan²θ
```

展开整理，得**关于 v 的二次方程**：

```
u² = v² · A  +  2 z₀ v cos β tan²θ  +  z₀² tan²θ
```

其中

```
A  =  cos²β · tan²θ  −  sin²β
```

### 3.4 判据（**A 级，本机已用符号逻辑核对**）

判据完全由 `A` 的符号决定：

| 条件 | A 的符号 | 交线 | 几何说法 |
| ------ | ------ | ------ | ------ |
| **β > θ** | A < 0 | **椭圆** | 平面比母线更「陡」，与锥的**全部母线**相交，交线闭合 |
| **β = θ** | A = 0 | **抛物线** | 平面**平行于一条母线**，交线开口且只在一叶上 |
| **β < θ** | A > 0 | **双曲线** | 平面与**两叶锥面都相交**，交线分两支张开 |

**等价性证明（A 级）**：

```
A < 0  ⟺  cos²β tan²θ < sin²β  ⟺  tan²θ < tan²β  ⟺  θ < β
```

（`θ, β ∈ (0°, 90°)` 时 `tan` 单调。）故 `A` 的符号与 `β − θ` 的符号一致。

### 3.5 ⚠️ 反直觉提醒（**这一条最容易写反**）

`β` 是**平面与锥轴**的夹角，**不是平面与水平面的夹角**：

- `β → 90°`：平面近乎**垂直于**锥轴 → 截面**近乎圆**（椭圆的极端）
- `β → 0°`：平面近乎**包含**锥轴 → 截面张开成**双曲线**

⇒ 所以「β 越大越圆、β 越小越开」，与「平面越平越圆」的直觉**正好相反**。

> **本项目曾写反过这个判据**，网页视图 Ⅱ 已修正。若老师在其他文档里看到「β<θ 椭圆」的写法，
> 那是错的，请以 §3.4 为准。

### 3.6 网页视图 Ⅱ 的设定（A 级，与实现一致）

```
θ = 30.00°（固定，半顶角）
预设：
    椭圆    β = 45°      （β > θ，默认打开）
    抛物线  β = 30°      （β = θ）
    双曲线  β = 20°      （β < θ）
```

**双锥的构造**：顶点在**原点（腰）**，向 ±y 两端张开、越远越粗 —— 与 §3.1 的
`x² + z² = y²·tan²θ` 严格一致。用两个开口圆柱退化成锥拼成：

```
rTop = HH · tan θ                       （y = ±HH 处的截面半径）
上锥   CylinderGeometry(rTop, 0, HH)  @ y = +HH/2   世界 y=0 半径 0（顶点） → y=+HH 半径 rTop
下锥   CylinderGeometry(0, rTop, HH)  @ y = −HH/2   世界 y=0 半径 0（顶点） → y=−HH 半径 rTop
HH 由交线实际高度回推，clamp 到 [2.1, 3.6]
```

交线按 §3.3 逐点求 `u = √(u²)`；**正负两支各自成为一条独立曲线**（"拉链效应"见 `01_…md` §六）。

> ⚠️ **实现踩坑（2026-10-12，老师看图指出）**
> 最初把上下两锥写成「上锥 `(0, rTop) @ +HH/2`、下锥 `(rTop, 0) @ −HH/2`」——
> 两半在 `y = 0` 处的半径都等于 `rTop`，画出的是「**中间最粗、两端收尖**」的纺锤形，
> 与 §3.1 的顶点在原点**正好相反**；于是解析算出的交线整个飘在锥体外面。
> `three.js` 的 `CylinderGeometry(radiusTop, radiusBottom, h)` 里 `radiusTop` 在**局部 +y**，
> 而 `position.y = ±HH/2` 的平移把局部轴翻到了世界轴的两侧 —— 两个参数**都反了**。
>
> **★ 教训**：曲面走「参数化图元」、交线走「解析方程」时，两者是**两套独立来源**，
> 只靠肉眼看「形状有点像锥」是抓不住的。必须拿曲面方程（`ρ² = y²·tan²θ`）
> **逐点验网格顶点**、并单独断言「顶点在腰」（`probe_3d.py` 回归 D）。
> 参照系：视图 Ⅰ 的单叶双曲面是**逐点解析**生成（`r = 1/y`），与交线同源，所以从来没出过这类错位。

## 四、两条几何链并排看

```
                     ┌──────────────────────────────────────┐
   单弦琴 l·f=1 ──▶  │  x·y = 1  ──绕 y 轴旋转──▶  X²+Z² = 1/Y²  │  单叶双曲面
                     └──────────────────────────────────────┘
                                    │
                     平面斜切 Y = z₀ − Z·tan α
                                    │
                                    ▼
                        x̄ = ±√( 1/(z₀−ȳsinα)² − (ȳcosα)² )
                                    │
                                    ▼
                          【 蛋形 】—— 1 种，两端不对称
                          （n 端尖 / 钝由 k_E 控制）

                     ┌──────────────────────────────────────┐
   （对照片）          │        x² + z² = y²·tan²θ            │  二次锥面（直圆锥）
                     └──────────────────────────────────────┘
                                    │
                     平面斜切（平面与轴夹角 β）
                                    │
                                    ▼
                        u² = A v² + 2z₀v cosβ tan²θ + z₀²tan²θ
                                    │
                    ┌───────────────┼───────────────┐
                 A < 0            A = 0            A > 0
              （β > θ）         （β = θ）        （β < θ）
                    ▼               ▼               ▼
                 【椭圆】        【抛物线】       【双曲线】
                 （闭合）        （单支开口）     （两支张开）
```

**要点**：

- 左链只有**一种**截面（蛋形），形状由 **`k_E` 连续调节**（`k_E = 1` 退化圆，`k_E → ∞` 越细长）。
- 右链有**三种**截面，**离散地**按 `β − θ` 的符号切换；只有 `β = θ` 那个临界点是抛物线（测度零的特殊情形）。
- 蛋形**存在尖—钝不对称**（两极曲率比 ≈ 1.574，见文档 01 §5.3）；
  圆锥曲线截面**没有这种内生的两极不对称**——椭圆严格对称。

## 五、曲率层面的对照（承接文档 01）

**A 级**（长轴统一为 1，见文档 01 §5）：

| 曲线 | κ_尖端 | κ_钝端 | 尖端/钝端 | 是否闭合 | 两极是否不对称 |
| ------ | ------ | ------ | ------ | ------ | ------ |
| 黄金极限蛋 | 5.4858 | 3.4850 | 1.5741 | 是 | **是（内生）** |
| Preston 四参数拟合 | 5.4406 | 3.4695 | 1.5681 | 是 | 是（`c₁` 注入） |
| 椭圆（β=45°, θ=30°） | — | — | **1.000** | 是 | **否** |
| 抛物线 | — | — | — | 否（单支） | — |
| 双曲线 | — | — | — | 否（两支） | — |

⇒ **蛋形与「椭圆」最本质的差别，不在「长宽比」，而在「两极曲率不相等」。**
椭圆的长宽比可以任意小，但两极曲率**恒等**；蛋形即使长宽比接近 1，两极曲率仍相差 57%。

## 六、复现与自检

**网页自检接口**（浏览器控制台）：

```js
__probe()
// 返回 { s1:{attrW,attrH,cssW,cssH}, s2:{...}, three, orbit, fatalShown }
```

- `three` / `orbit` 为 `true` 表示本地 `lib/three.min.js`、`lib/OrbitControls.js` 已成功加载。
- `fatalShown` 为 `true` 表示页面顶部出现红色错误框（**不静默失败**，SOUL 铁律 51）。
- `s1` / `s2` 的 `attrW/H` 与 `cssW/H` 应**一致且非 1px**。
  ⚠️ 若见 `cssW = 1`，是 `renderer.setSize()` 第三参数缺省 `true` 写死了 `inline style="width:1px"` 所致；
  本页已用 `setSize(w,h,false)` + 显式写 `domElement.style.width/height` 规避。

**几何量测与截图是两套事实**：headless 下 `requestAnimationFrame` 会被节流，
截图前须手动调一次 `draw()`，否则可能拍到空画面（**这不代表页面坏了**）。
