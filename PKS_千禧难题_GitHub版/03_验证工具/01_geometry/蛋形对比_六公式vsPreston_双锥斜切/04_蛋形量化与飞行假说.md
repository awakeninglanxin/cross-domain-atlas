## Ⅱ　评估系统是怎么建起来的：七步链

Stoddard et al. (2017) 的实际技术路线。

### 第 1 步 · 建数据集

不是「找 1400 张图」，而是把**博物馆藏卵做了数字化形态测量**。

- **49,175 枚蛋**
- → 约 **1,400 种**（≈ 全部鸟种的 **14%**）
- → **35 个现生目 + 2 个灭绝目**

### 第 2 步 · 把每枚蛋的轮廓抽成一条平面子午线

蛋绕长轴旋转对称 ⇒ **二维子午线就完全决定形状**。并**归一到同一长度**，去掉大小影响。

- 归一化：长轴 = 1，轴向坐标 **v ∈ [−1, 1]**

### 第 3 步 · 拟合一个只有两个参数的形状模型（全链最关键的一步）

Stoddard 用的是 **Baker (2002) 两参数闭式**（由 Biggins 2018 明确指出）：

```
y(v) = T · (1 + v)^(1/(1+λ)) · (1 − v)^(λ/(1+λ))
```

- **T** = 赤道半宽 / 长轴（管「胖瘦」）
- **λ** = 不对称参数；**λ = 1 时该式退化为椭圆** `y = T·√(1 − v²)`

### 第 4 步 · 从拟合参数里抽出两个「生物学上有意义」的变量

减 1 是为了让圆（或椭圆）对应 0：

```
asymmetry    A = max{λ, 1/λ} − 1        ← 用 max 是为了正确处理近对称情形
ellipticity  E = (1/T) − 1 = (L/d) − 1  ← d = 赤道直径，L = 长轴
```

> **注意**：A 与 E 都是**无量纲形状量，与蛋的大小无关**。

### 第 5 步 · 把 1400 个点画进二维形态空间（morphospace）

A 作横轴、E 作纵轴。这一步让「形状多样性」第一次变成一个**可以看、可以测量占据域**的几何对象。

### 第 6 步 · 挂上系统发育树

取其中 **1,209 个有分子序列的种**建树，把蛋长、A、E 映射到树枝末端。这样才能区分「共同祖先遗传」与「独立适应」。

> **观察**：高度不对称的蛋在**企鹅**和**鸻鹬**里**各自独立演化出来**（平行演化）。

### 第 7 步 · 贝叶斯系统发育混合效应模型 + 飞行能力指标 HWI

这才是「评估系统」的判决环节：

```
HWI = Kipp's distance / total wing chord
Kipp's distance = 最长初级飞羽尖端 → 第一枚次级飞羽尖端 的距离
wing chord      = 腕关节 → 翼尖 的距离
```

⇒ HWI 高 = 翼尖更窄更尖 = **飞行效率 / 扩散能力更强**。

把 A、E 对**成虫体重、窝卵数、食性、巢型、巢位、发育模式、纬度 / 温度 / 降水、HWI** 一起回归。

### ★ 三个必须写清的观察（原文）

1. **蛋形是连续的**：传统分类（球形 / 椭圆 / 锥形 / 梨形）之间**没有分界**。
   A 从 **0.001 连续铺到 0.485**，E 从 **0.097 连续铺到 0.724**。
2. **「最典型的蛋形」不是鸡蛋**：密度图显示大量物种汇聚在 **A ∈ [0.1, 0.2]、E ∈ [0.3, 0.4]**，
   形状接近 **Prinia gracilis（优雅鹪莺）**的蛋，而**不是**大家熟悉的「鸡蛋」——家鸡的祖先
   红原鸡（*Gallus gallus*）的蛋形。原文直言：文献里常列的传统蛋形分类，**没有任何一类落在真正最常见的蛋形附近**。
3. **某个区域被自然「空着」**：占据域是三角形，**缺少「球形但不对称」**的蛋（原文比喻像热气球）。
   原文给出的解释是二选一：要么膜性质极端变化在演化上难以实现（受约束），要么这种形状能出现但被强烈选择淘汰（不适适应）。

### ★ 这个框架最大的伤口（Biggins 2018 点名）

**Baker 两参数式对梨形蛋（pyriform，如海雀、鸻鹬）拟合很差**，于是 Stoddard 把这类蛋**直接排除了**。原文写道：

> "…this method did not quantify the shape of pyriform eggs sufficiently accurately
> and so they were excluded from their analysis."
> —— Biggins, Thompson & Birkhead 2018, *Ecology and Evolution* **8**:9728（引 Stoddard 2017 fig. S2）

而**恰好**，梨形蛋正是「不对称度」最极端的那一端 —— 也就是说，**评估系统在最有信息量的区域失明**。
这正是后面引入 **Preston 四参数**的直接原因。

## Ⅲ　核心量化蛋形的推导过程

### Ⅲ-1　Preston 的公式族：一次项管不对称，偶数项管双锥

Preston 1953 把子午线写成「圆 × 修正多项式」，原文编号如下（**编号必须回原文数，本项目曾错位**）：

| 原文编号 | 形式 | Preston 的命名 |
| ------ | ------ | ------ |
| **Eq.(3)** | `x = b·cosθ·(1 + c₁sinθ)` | Simple Ovoid |
| **Eq.(6)** | `x = b·cosθ·(1 + c₁sinθ + c₂sin²θ + c₃sin³θ)` | 通用四参数 |
| **Eq.(6a)** | `…(1 + c₁sinθ + c₂sin²θ)` | **Standard Avian Egg-Shape** |
| **Eq.(6b)** | `…(1 + c₁sinθ)` | Simple Ovoid（"a few eggs"） |
| **Eq.(6c)** | `…(1 + c₂sin²θ)` | 两端 "**virtually alike**" |

> ★ **一处易混，先说明白**：**Eq.(3) 与 Eq.(6b) 是同一个式子**（形式与命名都相同）。
> Preston 先用 **Eq.(3)** 提出最简 ovoid（原文：*"This equation represents what I shall call the
> 'simple' or 'perfect' ovoid."*），之后在 **Eq.(4) → (5) → (6)** 的一般化体系里把它退化为
> 「只保留 c₁」的特例，即 **Eq.(6b)**（原文 p.165：*"equation (6b), that for the Simple Ovoid"*）。
> **两行并列不是写重了，而是同一对象在「提出期」与「编号期」的两个编号。**
>
> ★ 本文另给两个术语（原文原话，A 级）：把 c₂ 称为 **Biconical Term**
> （*"This has the effect of making both ends of the egg slightly more conical than in the Simple Ovoid.
> We may therefore call this the Biconical Term"*），并把**只含 c₁ 与 c₂** 的蛋形称为
> **Standard Avian Egg-Shape**（*"refer to eggs having only c₁ and c₂ terms as the Standard Avian
> Egg-Shape, for c₃ is usually zero or negligible"*）—— 这正是 **Eq.(6a)**。
>
> ⚠️ **本专题的一处历史错（已修）**：`papers/SOURCES.md` §2 初稿曾把「只用 c₁」标成 Eq.(6a)、
> 「只用 c₂」标成 Eq.(6b)，**各错一位**；同错曾进入 `src/egg_scan_preston_match.py` 的图注，
> 并印到 `figs/egg_scan_preston_match.png`。2026-10-12 回原文（p.163）逐条核正后，**源码与图均已重出**。

### Ⅲ-2　判据 A / 判据 B：对称性到底由谁决定

- **判据 A · 长轴镜像**（θ → π − θ，即 (x, y) → (−x, y)）：
  对**任意** c₁, c₂, c₃ **恒成立**（残差 ~1e−15）。这来自 `x ∝ cosθ`，与参数无关。
- **判据 B · 半周对称**（θ → θ + π，即 (x, y) → (−x, −y)，原文说两端 "virtually alike"）：

  > **半周对称 ⇔ c₁ = c₃ = 0**

  **实测（脚本 ①）**：c₂-only 的残差 **2.03e−15**（半周对称）；只要 c₁ 或 c₃ 非零，残差立刻跳到 O(0.1~1)。

- **判据 C · 端点曲率比**（Preston 1968 Eq.(2)）：

  ```
  R_B / R_P = ((1 + c₁ + c₂ + c₃) / (1 − c₁ + c₂ − c₃))²
  ```

  **实测（脚本 ②）**：7/7 与数值直算**相对差 0.0000%**；**纯双锥（c₁ = c₃ = 0）时该比恒 = 1.000000**。

### Ⅲ-3　枢纽：奇偶完全分离（Preston 1968 p.458 原文）

> "the odd and even subscripts of the 'c's are **completely separated** and there is
> **no effect of bicone on asymmetry or vice versa**"

⇒ **奇次 c ⇒ asymmetry；偶次 c ⇒ bicone，二者互不干扰。**

这正是 Preston 体系优于 Baker 两参数的地方：Baker 只有 λ 一个不对称参数，**根本没有 bicone 自由度**。

### Ⅲ-4　口径陷阱一：b 不是最大半宽（Preston 1968 p.458 亲自警告）

> "**b is not half the maximum breadth**… with the more extreme-shaped eggs, **the difference is substantial**."

**实测（脚本 ③）**：把 b 固定为 1，量出曲线真正的最大半宽：

| 算例 | b（赤道半宽） | 真量测最大半宽 | 差 |
| ------ | ------ | ------ | ------ |
| 圆 | 1.000000 | 1.000000 | 0.000% |
| 黄金蛋拟合 | 1.000000 | **1.003423** | **+0.341%** |
| 海雀（Murre）型 | 1.000000 | 1.023084 | +2.256% |
| 纯不对称 c₁ = −0.25 | 1.000000 | 1.029166 | **+2.834%** |

> ★ **这一条抓过本项目的真 bug**：主页面 `fitEgg()` 曾把拟合参数 `B` 当量测半宽用，
> JS 侧给 0.7142312，真值 0.7166758，**差 0.341%** —— 正是黄金蛋这一行的数。
> 修法：JS 改为 **20000 点真量测**最大半宽，与锥切蛋的 `cutEgg()` 统一口径。
>
> ★ **顺带抓出第二个 bug（2026-10-12 修）：Python 侧的读数自己也有独立偏差。**
> `src/egg_harmonic_symmetry.py` 对 Preston 曲线先 `unitize`（按 y 极差归一化）再取 `max|x|`；
> 而 `preston_full → preston_profile` 的轴向采样刻意取 `v ∈ [−(1−10⁻⁵), 1−10⁻⁵]`
> （避开端点处 `1/√(1−v²)` 与 `1/s³` 的奇点）⇒ **y 极差 = 0.99999·L**，
> `unitize` 于是把 x 放大 **1.00001 倍**，SI 被**系统性抬高 1×10⁻⁵ 相对量**。
> 这与 JS 侧真量测的差恰好是 `0.7166757568 × 1.00001 = 0.7166829` ——
> 两次独立偏差数值上完全吻合，可以确信根因。
> 修法：SI 改为**直接由模型算** `2·max|x| / L_true`，不再经过 `unitize`
> （`max|x|` 在轴向内部、赤道附近取得，端点排除对它无影响 ⇒ 该式为精确值）。
> 修后 Python 侧 **0.7166757563** 与 JS 侧 **0.7166757568** 只差 **5.3×10⁻¹⁰**。

### Ⅲ-5　口径陷阱二：密切圆 ≠ 内切圆；钝端由曲率半径「大者」决定

- **曲率半径**（b = a = 1 时）就是 `R = Φ²`，Φ 为该端点的多项式值。
- **密切圆**是**曲率圆**，不是「蛋内最大内切圆」—— 尖端处它会**鼓出蛋体之外**，那是几何本来的样子。
  （拿椭圆端部一试就知道：半轴 a = 2, b = 1 时端点曲率半径 = a²/b = **4**，远超短半轴 1。）
- **哪个是钝端？曲率半径大的那一端**（更平坦）。c₁ > 0 时钝端确实在 y = +a；
  **c₁ < 0 时两端角色互换**，绝不能把「钝端」钉死在 +a 上。

> ★ 本项目第一版就把「钝端」钉死在 +a，真看图时发现图注与数值对不上才抓出来。

## Ⅳ　为什么飞行能力强的鸟蛋更拉长、更不对称

### Ⅳ-1　结论本身（原文摘要）

> "…using phylogenetic models, we show that egg shape correlates with flight ability on broad
> taxonomic scales, suggesting that adaptations for flight may have been critical drivers of
> egg-shape variation in birds."
> —— Stoddard et al. 2017, *Science* **356**:1249，摘要末句

**回归结果（原文 table S2 的文字结论）**

| 被解释量 | 显著的解释变量 | 不显著的 |
| ------ | ------ | ------ |
| **蛋长（size）** | 成虫体重 ✓、窝卵数 ✓（窝大 → 蛋短）、食性 ✓（高钙 → 蛋长）、发育模式 ✓（越早成 → 蛋长） | — |
| **蛋形（A & E）** | 蛋大小（蛋长与体重的 PC1）✓、**HWI ✓**（高 HWI ⇒ 更不对称 或 更椭圆） | 窝卵数 ✗、发育模式 ✗、环境（纬度/温度/降水）✗、巢型 ✗、巢位 ✗ |

另：ellipticity 还受 PC2 正向预测（「相对体重偏大的蛋」更椭圆）。

**被这批数据直接否掉的两个经典假说**

1. 「悬崖筑巢的鸟产锥形蛋，只会原地打转不易滚落」（Lack 的经典故事）
   → 在**全鸟类尺度上找不到支持**（figs. S11–S12）。
2. 「蛋形与窝卵数相关（孵化效率最优形状）」
   → 理论最优形状**落在真实占据域之外**，只有窝卵数 n = 3 与 n = 9 两种例外还勉强在域内（fig. S11）。

> ⇒ 注意原文措辞的分寸：是「**在全鸟类尺度上不显著**」，**不是**「这些假说被证明为假」。

### Ⅳ-2　机制：为什么是「飞行能力」而不是「飞行动作」

1. 强飞行需要**流线型、肌肉化的体型**。这条选择压力**对雌雄都成立**。
2. 随之而来的是：**体型变小、腹腔减小、丢失功能性卵巢与输卵管**（鸟类把生殖器官做成「按需增重」）。
3. 这三件事**共同约束了「拉伸后输卵管的最大宽度」** ⇒ 蛋的**腰围上限被压低**。
4. 但蛋的**体积**还要够大（雏鸟要长）。在腰围受限时，唯一出路是
   **把蛋拉长 / 拉不对称** —— 因为同样的腰围下，长一点、斜一点就能塞进更多体积。
   原文：

   > "…can be accommodated by increasing ellipticity and/or asymmetry of eggs to increase
   > egg volume **while maintaining or reducing girth**."

5. **实证对应**：原文图 5A/5B —— 「同腰围下，更不对称 / 更椭圆的蛋，体积更大」。

### ★ 原文自己把两种常见误读先堵死了（引用时务必带上）

> "We do **not** suggest that a female's flight behavior during the egg formation period directly
> affects egg formation, nor do we suggest that egg shape so strongly influences the flight abilities
> of female birds during their egg-laying period that selection has produced an **aerodynamic egg**."
> —— Stoddard et al. 2017, *Science* **356**:1252

⇒ ① 不是「产卵期飞得多 → 蛋被挤变形」（不是个体层面的力学因果）；
⇒ ② 不是「蛋形是为了空气动力学」（蛋并不在飞行中承流）；
⇒ 正确的是：**普适的强飞行适应 → 雌雄都流线型化 → 雌性「顺带」产出更不对称 / 更椭圆的蛋**。

原文并坦白：连接形态适应与蛋形的**具体生理机制目前未知**，最可能落在生物物理模型里的两个量上 ——
**膜厚度分布**与**跨膜压差**。

### Ⅳ-4　★ 本项目的独立复算：把「同腰围 ⇒ 体积更大」拆到几何内核

> **C 级 · 本项目推演。**
> 下面这一段**不是 Stoddard 的原文主张**，而是本项目在 Preston 模型上把它的图 5A/5B 重算一遍之后
> 得到的**几何澄清**。Stoddard 本人的统计是 1,400 种真实数据的相关性（**A 级**），
> 两者不冲突，但**几何解释需要说准**。

**第一步：同腰围下，体积与长轴长严格成正比**

旋转体体积 `V = π ∫ x² dy`。只把形状沿**轴向**缩放 k 倍 ⇒ x 不变、dy 乘 k ⇒ **V 恰乘 k**，腰围完全不变。
⇒ **V / L 只取决于形状，与大小无关**。

实测（脚本 ⑤）：对四种形状各取 a = 0.5 / 1 / 2 / 4（L = 1 / 2 / 4 / 8）：

| 形状 | V/L 的四个取值 | 相对离散 |
| ------ | ------ | ------ |
| 椭圆 | 2.094395102 ×4 | **0.000e+00** |
| 纯不对称 c₁ = −0.20 | 2.111150263 ×4 | **0.000e+00** |
| 纯双锥 c₂ = −0.15 | 1.972770587 ×4 | **0.000e+00** |
| 海雀型 | 2.112327114 ×4 | **0.000e+00** |

离散**恰好为 0**（不是「很小」，是浮点意义上的 0）⇒ **V ∝ L 是恒等式**。
（椭圆那行 2.094395102 = 2π/3，正是长轴 2、半宽 1 的椭球体积 4π/3 除以 2，可作交叉校验。）

**第二步：那「形状畸变本身」到底加不加体积？**

把腰围**和**长轴**同时**固定（a = 1、最大半宽归一到 1），只变形状：

| 形状 | 体积 | 相对椭圆 | R_B / R_P |
| ------ | ------ | ------ | ------ |
| 椭圆（c₁ = c₂ = 0） | 4.188790 | 0.00% | 1.0000 |
| 加不对称 c₁ = −0.20 | 4.065510 | **−2.94%** | 0.4444 |
| 加双锥 c₂ = −0.15 | 3.945541 | **−5.81%** | 1.0000 |
| 两者都加 | 3.862222 | **−7.80%** | 0.3832 |

**结论**：在**同腰围 + 同长轴**的严格对照下，形状畸变本身**反而减小体积**。
所以 Stoddard 图 5A/5B 的几何内核是：**那些更不对称 / 更椭圆的蛋，在同样的腰围下更长（L 更大）**，
**体积增益来自 L**，而不是来自「形状被扭得更能装东西」。

**第三步：(V/L) 到底谁最大？—— 不能一句「椭圆最大」带过**

在 (c₁, c₂) 的 31 × 16 = 496 点网格上扫 V/L（同腰围）：

- **c₂ 的符号决定方向**：c₂ > 0（两端更钝）**抬高** V/L；c₂ < 0（Preston 说自然界多为负）**压低** V/L。
- 因此「椭圆使 V/L 最大」**不成立** —— 网格上确界 **2.179966** 出现在 (c₁ = 0, c₂ = **+0.10**)，高于椭圆的 2.094395。
- 网格下确界 **1.855851** 出现在 (c₁ = −0.30, c₂ = −0.20)。

这一点如果只做定性叙述就会被带偏。

**怎么和 Stoddard 的结论对齐？**

Stoddard 的横轴是「蛋的腰围（最宽处）」，纵轴是体积，**并没有固定长轴**。
在这个更宽松的对照下，「同腰围下更不对称 / 更椭圆的蛋体积更大」**⟺「它们更长」**—— 两者在几何上**完全等价**。
本项目的复算只是把这个等价关系明确化，并指出：**增益归因于长度，不归因于形状畸变**。

### Ⅴ-2b　同族第二个点：八度蛋 —— 它为什么必须在场

**「八度」这个名字从哪来**

- 锥切蛋族的**蛋形度** `k_E` 是一个连续参数：`z₀ = (1 + k_E²)/(1 + k_E)`、
  `tan α = k_E(k_E − 1)/(k_E + 1)` 都由它**唯一决定**。⇒ 一族无穷多条蛋形曲线。
- **黄金极限蛋**取 `k_E* = 1.9370872430` —— `φk² − φ²k − 1 = 0` 的**正根**，是个**无理数**。
- **八度蛋**取 `k_E = 2.0000000000` —— **最靠近的整数**。
  「八度」= 音乐里的 octave = **频率比 2 : 1**，取「正好翻一倍」之意。
- ⇒ 两个点是同一族里「**无理数锁定的点**」与「**整数点**」的对照。
  **它们不是两条独立公式，而是同一条公式的两次取值** —— 所以本页仍称「**六种公式**」，
  不因加了八度蛋而变成七种。

**三点差异（长轴 = 1，同口径）**

| 量 | 黄金蛋 | 八度蛋 | 变化 |
| ------ | ------ | ------ | ------ |
| 形状指数 SI | 0.716754 | 0.688927 | **−3.88%** |
| 尖端 / 钝端曲率比 | 1.574139 | 1.750000 | **+11.17%** |
| x 的 2 次谐波 | 0.007830 | 0.009233 | **+17.92%** |
| 偶次能量占比 | 0.0471% | 0.0697% | **+48.0%** |

★ **两个口径不同向**：八度蛋**更窄**（SI 小 3.88%），却**两头差别更大**（曲率比 1.75 > 1.574）。
**「更圆」与「更蛋」不是同一件事** —— 只盯一个指标，会得出方向相反的结论。

> ★ **这一节与第 Ⅳ 部分（飞行假说）直接挂钩**
>
> Stoddard 的结论是「**飞行能力强的鸟，蛋更拉长、更不对称**」。在锥切蛋族里，这两维各有明确对应：
>
> - **「更不对称」**这一维 ⇒ 由 `k_E` 往**大**走实现：`k_E: 1.9370872 → 2.0000000` 时，
>   曲率比 **1.574139 → 1.750000**（+11.17%）、偶次能量占比 **0.0471% → 0.0697%**（+48.0%）；
> - **「更拉长」**这一维 ⇒ 对应 **SI 变小**：**0.716754 → 0.688927**（−3.88%）。
>
> ⇒ **八度蛋在「不对称」上比黄金蛋更「蛋」，但同时也更窄**；换到 Stoddard 的二维形态空间，
> 它比黄金蛋更靠近**「不对称轴」正方向**。**将来若要把锥切蛋参数搬进 1400 种体系，
> 八度蛋这个点不能省** —— 它是族内「不对称侧」的代表。
> **A 级**读数 ＋ **C 级**跨体系定位解读

**八度蛋的「代价」：族内更难被别的成员逼近**

把「八度蛋自身的 Preston 四参数拟合」当目标，再让锥切蛋族 `(α, z₀)` 全平面去贴：

- 族内最优 `(α, z₀) = (28.708216°, 1.506962)`，err_max = **0.0017478（0.4843%）**；

  （0.16033% vs 黄金蛋 0.11552%，**1.388×**）—— **目标曲线自身就偏离族多一点**。

换句话说：**k_E 越往整数点走，锥切曲线越「偏」，用四参数描述它的代价也越大。** **A 级**

### Ⅴ-2c　两个 3D 蛋形曲面：本页的 2D 曲线到底是从哪里切出来的

老师给的两个 3D 曲面，一个是**老相识**（只是换了 3D 写法），一个是**全新机制**。
先把关系摆清，再往下走 —— 否则很容易把同一个东西当成两个。

> 下面的 **① / ② 沿用老师原图里的编号**：① = `x²+y²+z² = a·2^z`，
> ② = `x²+y² = 1/(b − z·sinα)² − (z·cosα)²`。**编号顺序与「新 / 旧」无关。**

**② 锥切蛋曲面 —— 就是本页 Ⅱ–Ⅴ 一直在用的那条曲线，绕 z 轴转出来的**

```
3D 曲面　x² + y² = 1/(b − z·sinα)² − (z·cosα)²
  作代换 Z = z·cosα（把「沿斜切平面量」换成「沿世界轴量」）
   ⇒　x² + y² = 1/(b − Z·tanα)² − Z²
  取正视 zx 平面（令 y = 0）
   ⇒　x² = 1/(b − Z·tanα)² − Z²
  记 Z → y、b → z₀、tanα → k，即本页 A1 形式
   ⇒　x = ±√( 1/(z₀ − y·sinα)² − (y·cosα)² )
```

⇒ **两式逐项相同**。它们不是两条曲线，是**同一条曲线的两种写法**：
一条叫「平面斜切超双曲面」，一条叫「2D 曲线绕 z 轴旋转」。
老师给的两个滑块 `(b, k)` 就是本页的 `(z₀, tanα)`。

> **链接里的参数验算**（`b = 1.5`、`k = 0.5`）　**A**
>
> `tanα = 0.5` ⇒ `α = 26.5650512°`；
> 解 `k_E(k_E − 1)/(k_E + 1) = 0.5`，即 `k_E² − 1.5·k_E − 0.5 = 0` ⇒ `k_E = 1.7807764064`；
> 反推 `z₀ = (1 + k_E²)/(1 + k_E) = 1.5000000000 ≡ b` ✓
> ⇒ 那个链接演示的是锥切蛋族里 `k_E = 1.7807764` 的那一个点 ——
> **既不是黄金极限蛋（1.9370872），也不是八度蛋（2）**。

**① 指数蛋曲面 —— 全新的第四种生成机制**

```
3D 曲面　x² + y² + z² = a·2^z
  取正视 zx 平面（令 y = 0）
   ⇒　x² = a·2^z − z²
  记 F(z) = a·2^z − z²，则正视轮廓（取 |x| 极大分支）
   ⇒　ρ(z) = √( a·2^z − z² )
```

★ **它既不是锥切、也不是曲线拟合，而是「球面 × 指数」的旋转体** ——
半径随高度按 `2^z` 指数放大，再减去 `z²` 的球面收缩。
**它是本页第一个不用「斜切平面」就能长出蛋形的机制。**

> **为什么两端都是「圆顶」而不是尖点**　**C（推演）**
>
> 端点满足 `F(z_e) = 0` 且 `F′(z_e) ≠ 0` ⇒ `ρ ≈ √(F′(z_e)·(z − z_e))`，即 `ρ ~ √ε`。
> **而 `ρ ~ ε`（线性）才是尖点**（圆锥顶点）。
> 所以这个曲面两端都是**球面圆顶**，但**两端曲率半径不相等**（`R = |F′(z_e)|/2`）——
> **这才是它成为「蛋」的原因**，也是它和「旋转椭球」的分水岭。

**两页 3D 交互画布（HTML 页 Ⅴ 视图）**

- **单一数据源**：`yaw / pitch` 只存在两根滑块里；画布拖动只把数值写回滑块，绝不另存一份。
- **所有文字都画在 canvas 上**，不用 HTML 浮层 —— `.stage canvas` 是 `width:100%` 拉伸渲染，
  浮层用 CSS px 定位必然错位。
- **金色母线 = 曲面上 `φ = 0` 与 `φ = π` 两条经线**。
  任意旋转角下它们只各自贴着曲面一侧；**只有点「正视图」（yaw 0° / pitch 0°，
  即视线沿 ±y 轴）两条经线才重合**，此时金色线 = `zx` 平面上 `x = ±ρ(z)` 的完整轮廓。
- **★ 定量自检**：正视图下屏幕的「宽 / 高」恒等于 `SI`（两者都按轴向长归一化）。
  实测金色外接盒（扣掉 2.3 px 线宽后）左 = **0.71737**（解析 `SI = 0.716754`）、
  右 = **0.78140**（解析 `SI = 0.780041`），偏差 < 0.2%。

### Ⅴ-4　优势与缺点：一张清单

**Schauberger 锥切蛋的优势**

- **参数少且物理可构造**：2 个参数，(α, z₀) 都有明确的几何意义。
- **能回答「这个形状从哪来」** —— 而 Preston/Baker 只能回答「长什么样」。
- **黄金比锁定，无需数据**：α = arctan(1/φ)、z₀ = φ 时给出唯一「极限蛋」，方程是**推出来的**，不是拟合出来的。
- **同源自洽**：同一组 (α, z₀) 同时决定 3D 锥面、切平面、2D 蛋形、端点曲率 ——
  多个视图共用一套参数，不会「同源双图脱节」。
- **同族可连续调参**：`k_E` 一个数就同时决定 α、z₀、SI 与端点曲率比 ——
  从黄金蛋（`k_E* = 1.9370872`）走到八度蛋（`k_E = 2`），曲率比就从 1.574139 抬到 **1.750000**。
  一条曲线族覆盖「更圆 ↔ 更蛋」的连续谱，而 Preston 族要同时动 4 个数才能做到。
- ⚠️ **一条已作废的「优势」**：本清单原先称「谐波更纯：2 次谐波 0.0246 vs 0.3504，差 14 倍」——
  经复算**不成立**（那是极角口径两个 bug 叠加的伪影）。改用**弧长 EFD** 后，
  黄金蛋 0.007830 与 Preston 0.007825 **只差 0.06%**。
  详见 Ⅴ-2 表下的更正框与 [03 号 md §2](03_谐波奇偶性与跨行业应用.md)。
- **端点曲率有解析式**：`κ_end = 2/|F′(t_e)|`，可与 Preston 的
  `((1+c₁+c₂+c₃)/(1−c₁+c₂−c₃))²` 做同口径对账。

**Schauberger 锥切蛋的缺点**

- **自由度不足**：2 个 vs 需要 4 个。**纯双锥蛋在族内不可达**（最优仍差 2.6~2.8%）。
- **不能独立拨动不对称与双锥**：Preston 的「奇偶完全分离」是锥切蛋做不到的。
  对比之下 Baker 连 bicone 自由度都没有 —— 所以三者里**只有 Preston 是完备的**。
- **「拟合」与「生成」不是一回事**：面对一枚真实鸟蛋，锥切蛋族只能给出「族内最优」，
  Preston 能给「任意精度的描述」。**用错场景会把两者误当竞争者。**
- **覆盖不了全部蛋形**：SI 可达范围 0.415 ~ 0.990，只是 Stoddard 三角形态空间里的一条 **2 维子流形**。
- **没有配套的统计评估体系**：截止本页写作时，**没有任何公开的跨物种蛋形数据库用锥切蛋参数建过模**，
  因此它在「飞行假说」这类宏观演化问题上**暂时无法产出可比较的结论**。

**一句话定位（本项目结论）**

两者**不是竞争关系，而是分工**：

- 要做**量化与统计**（评估系统、飞行假说、跨物种比较）⇒ 用 **Preston 四参数**
  （Biggins 2018 的明确推荐；Baker 两参数是被批评的那个）。
- 要做**生成机制与参数方程**（形状为什么是这样、如何从几何原理构造）⇒ 用 **Schauberger 锥切蛋**。

> **★ 真正的空白在这里**：Schauberger 蛋形真正站得住的优势是「**几何可构造 + 参数少 + 同源自洽**」，
> 且 `k_E` 一个数就能连续扫过「更圆 ↔ 更蛋」的全谱（黄金蛋 → 八度蛋：曲率比 1.574139 → 1.750000）。
> 但**目前没有任何生物学评估体系去度量这个优势**。如果要把这条优势变成可比较的科学结论，需要
> ① 把锥切蛋的 (α, z₀) 也搬进 Stoddard 式的 1400 种形态空间（**八度蛋这个「不对称侧」代表点不能省**）；
> ② 检验「(α, z₀) 的某个组合」是否与 HWI 有独立于 A、E 的相关性。
> ⚠️ 原写的「谐波更纯 / 反对称更干净」**已作废** —— 见 Ⅴ-2 表下的更正框。
> 这是本专题下一轮的候选方向。

### Ⅵ-2　三条结论

**结论一 · 评估系统的骨架是「两步降维」**

Stoddard 团队没有直接用傅里叶描述子的高维系数（那是 **Attard et al. 2017** 的路线），
而是走了「**2 参数形状模型 → 2 个生物学变量**」：

```
Baker 两参数 (T, λ)  ⟶  asymmetry A + ellipticity E  ⟶  二维形态空间
```

好处是每个轴都有生物学可解释性（「不对称」与「胖瘦」），代价是**该两参数模型对梨形蛋失准**，
于是**最极端的那一端被排除在分析之外**。这个取舍是整个体系最大的结构性弱点，也是 Biggins 2018 的立论点。

> ⇒ **因此元宝的说法是错的**：论文用的是 Baker (2002) 两参数闭式，**不是** EFD；
> 且**梨形蛋被排除**。真正用傅里叶技术的是 **Attard, Medina, Langmore & Sherratt (2017)**。

**结论二 · 「飞行能力强的鸟产更拉长、更不对称的蛋」，机制是「腰围受限下的体积补偿」**

不是蛋在飞行中受力变形，也不是蛋形为了气动 —— 原文明确否定了这两种误读。真正的链条是：

```
强飞行 ⇒ 流线型体型 + 丢失功能性卵巢/输卵管 ⇒ 拉伸后输卵管最大宽度受限
       ⇒ 用拉长与不对称在同样腰围下塞进更大体积
```

这条链条**在全鸟类尺度上成立**，在鸻鹬、雀形目等小类群内部未必成立（原文自己保留）；
企鹅是「不会飞却是高度不对称蛋」的反例，合理的化解是「**流线型体型**」比「飞行」更本质。

**结论三 · Schauberger 锥切蛋与 Preston 体系是分工，不是竞争**

- **Preston 四参数**赢在**完备性**（4 个自由度可逼近任意蛋形；奇偶分离可独立拨动不对称与双锥）
  与**配套的生物学评估体系**（1400 种数据库 + 统计模型）。
- **Schauberger 锥切蛋**赢在**可解释性与参数经济**（2 个几何参数就能生成，能回答「形状从哪来」），
  且 `k_E` **一个数就能连续扫过「更圆 ↔ 更蛋」的全谱**
  （黄金蛋 → 八度蛋：曲率比 1.574139 → 1.750000，SI 0.716754 → 0.688927）。
- ⚠️ **原先写的「谐波更纯、差约 14 倍」已作废** —— 那是极角口径两个 bug 的伪影，
  改用弧长 EFD 后黄金蛋与 Preston 只差 0.06%，见 Ⅴ-2 表下的更正框。
- 但它的**硬伤同样明确**：2 个自由度做不出「两端曲率完全相同」的双锥蛋（族内最优仍差 2.6~2.8%），
  且至今**没有任何公开数据库用它的参数建过模** —— 所以在「飞行假说」这类问题上暂时无话可说。
- ★ **本轮新增的「指数蛋」（`x² + y² + z² = a·2^z`）是第三条路**：
  它**不用斜切平面**，而是「球面 × 指数」的旋转体，只有一个旋钮 `a`，
  结构与锥切蛋族的 `k_E` 一样是单参数；但两者在「形状空间」里走的是**不同的弧**
  —— `a` 同样在「更窄 + 更不对称」上同向推进，却**推得陡得多**（曲率比可从 1.0003 冲到 113），
  详见 **Ⅴ-2d**。
