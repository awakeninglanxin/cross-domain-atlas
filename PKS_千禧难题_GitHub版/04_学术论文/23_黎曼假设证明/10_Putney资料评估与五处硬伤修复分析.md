## 二、五处硬伤修复分析（逐条：病根 → 修法 → 修复后暴露什么 → 判定）

> 先给总原则：**五处硬伤的性质不同。技术性错误可以"改写"，但改写后结论随之消失；结构性缺陷无法修补，修补等于换一个新证明。** 下面逐条给出精确判定。

### 硬伤 ① M2 对象错配（P_M ≠ S_stat）

**病根**：§6.2 把 Riemann–Siegel 主和 P_M = Σ_{n≤M} n^(-s) 直接替换为围绕 n₀=t/2π 的"平稳区和" S_stat。但文中存在两个互相矛盾的 M：§2.4 取 M≈⌊t/2π⌋，§3.1 取 M=⌊√(t/2π)⌋（后者才是 RS 的正确截断）。t=10⁶ 时两者差 400 倍，且 n₀ 根本不在主和区间内。更深层：相位 -t·ln n 的导数 -t/n 在 n>0 上永不为零——**主和区间内不存在平稳点**，这正是 RS 主和难处理的根本原因。

**正确的修法（如果要研究 RS 主和）**：主和 S(t)=Σ_{n≤√(t/2π)} n^(-1/2-it) 没有平稳点，处理它的正确工具是离散指数和估计（van der Corput 方法）或 Hardy–Littlewood/Landau 的 Θ 函数变换路线——这就是 Hardy 定理（临界线上有无穷多零点）的标准证法。

**修复后暴露什么**：用正确的工具处理主和，得到的最多是已知结论（Hardy 定理级别），**不会产生任何"新矛盾"**。原核心方程 I_δ + Θ·conj(I_{-δ}) = O(t^(-1/4)) 不是从 ζ(s)=0 推出来的，是错误代换"换"出来的——伪矛盾的来源就是代换本身。

**判定：❌ 不可修复**。这不是笔误，是论证的承重墙。修复它 = 证明垮塌。

### 硬伤 ② B4 交比条件恒等于 1

**病根**：按文中定义 (A,B;C,D) = (A-C)/(B-C) : (A-D)/(B-D)，而实际取 A=B=Q_C，代入后分子分母完全相同，交比恒为 1，与 σ、δ 完全无关。后续"经过冗长但直接的代数计算（省略中间步骤）→ Δ_CR = δ·K"无中生有。

**正确的修法（如果坚持射影框架）**：交比有区分度的前提是四个点两两不同。需要重新选取四个真正不同的对象（如两个零点 s₁,s₂ 与两个固定点），并独立证明交比的非平凡性质——但那样 Δ_CR=δ·K 这一步就完全没有依据了，等于从零重造整个射影路线。

**修复后暴露什么**：射影几何在 RH 中的正确用法只有一个：**函数域上的 RH**（Weil 1948 / Deligne 1974），用的是代数曲面上 Frobenius 不动点的 Castelnuovo–Severi 不等式——对标对象是 Spec Z 上的算术几何（Connes 路线），不是 ζ 零点的交比。

**判定：❌ 不可修复**（定义层面退化）。射影路线清零，资产迁移至函数域 RH 对标（见 08 号文档阶段 2）。

### 硬伤 ③ 误差项与主项同阶，且 σ<1/2 时发散

**病根**：§4.3 自己算出 Euler–Maclaurin 误差 O(t^(1/2-σ))，而主项是 (t/2π)^(1/2-σ)·I——比值 O(1)，误差与主项一样大。文中却写"O(t^(1/2-σ)) = o(1)（当 σ>0）"，这需要 σ>1/2；临界线左侧 σ<1/2 时直接发散。§4.4 又把余项悄悄改成 O(t^(-1/4))，与 §4.3 相差 t^(3/4-σ) 倍。

**正确的修法**：诚实的误差控制要求完整 RS 公式——主和截断在 M=⌊√(t/2π)⌋ 并加上 RS 修正项，此时总误差才是 O(t^(-1/4)) 量级。单独的 Euler–Maclaurin 逼近做不到这个精度。

**修复后暴露什么**：把误差诚实写出后，"矛盾"立即消失——等式两边都泡在同阶噪声里，推不出 σ=1/2。

### 硬伤 ④ 无算术输入（D–H 测试不通过）

**判定：❌ 不是修复一处，是换一个证明**。
