0先把话说清楚

你要的答案是「能不能攻破」。诚实的答案是：不能，我也不会假装能。 但「不能」有两种。一种是还没找到，一种是这条路结构上走不通。 这次的收获是第二种，而且可以写成定理。

三条，全部精确为零，不是「很小」

① 偶 test function 下，Weil 和沿 σ 方向的一阶变分恒等于 0。数值上打出 0.000000e+00，不是 1e-16。

② 奇 test function 下，素数项恒等于 0。数值上同样打出 0.000000e+00。

③ 而 Weil 判据要用的 test function 必然是 f∗f*，自相关， 它的实部恒为偶。所以 ① 对 Weil 判据永远成立。

把这三条拼起来，就是下面这句话——它是这次唯一值得写下来的东西：

算术 / 灵敏度二难

要算术（素数项存活）⇒ 必须偶对称 ⇒ 一阶响应为零 ⇒ 只能看见 δ²。

要一阶灵敏（能线性地看见 σ 偏离）⇒ 必须奇对称 ⇒ 素数项相消 ⇒ 对 ζ 与 D–H 一视同仁，零信息。

两端是同一个对称性的两侧。临界线是 Weil 泛函的驻点，驻点条件自动满足，它不提供任何推力。 RH 是一个二阶命题（Hessian 的符号），不是一个一阶命题。

3为什么会是一阶为零：一句话的定理

把 (3) 对 δ 求导，在 δ = 0 处取值：

∂δ ĥ(γ;0) = ∫ h(u)·u·eu/2·cos(γu) du (4)

看那个 u。它把偶函数变成奇函数：h 偶 ⇒ h(u)·u 奇 ⇒ 奇 × 偶 × 偶 = 奇 ⇒ 在对称区间 [−L, L] 上积分为 0。 只有当 h 是奇函数时，h(u)·u 才是偶的，一阶项才活。

命题（可严格证明，本次数值精确验证）

设 h 实值、偶、支撑 [−L,L]。则对任意零点 ρ = ½+iγ， 把 ρ 沿 σ 方向移动 δ（保持共轭对称），其 Weil 和贡献的一阶变分为零：

d/dδ |δ=0 [ ĥ(½+δ+iγ) + ĥ(½+δ−iγ) ] = 0

所以临界线是所有偶 test function 下 Weil 和的二阶驻点。 任何只做到一阶的论证——无论几何多漂亮——在这条线上都看不见任何东西。

4那换成奇基不就行了？——不行，这就是二难

图 2 里青线明显更好用：它一阶就能分辨 σ。那为什么不干脆用奇基？因为 Weil 显式公式的素数项是

Σpm (log p / pm/2) · [ h(m log p) + h(−m log p) ] (5)

方括号那一对。对奇 h，h(−u) = −h(u)， 所以这一对恒等于零。整条素数项消失。

为什么 Weil 判据也躲不开

你可能会想：那就用混合的 h = 偶部 + 奇部，两样都要。几何上可以。但 Weil 判据 不许 —— 它要求 test function 形如 f ∗ f*，因为正定性的来源就是它：

W(f∗f*) = Σρ |f̂(ρ)|2 ≥ 0 (6)

而 f∗f* 是自相关：

(f∗f*)(u) = ∫ f(v) f(v−u) dv (7)

自相关恒满足 g(−u) = g(u)，即共轭偶。 它的实部是偶函数。所以 (4) 式那个一阶积分，对 Weil 判据永远为零。

这堵墙的完整形状

正定性的来源（模平方 / 自相关）与一阶灵敏度（奇性）在结构上互斥。 Weil 判据天生是一个二阶判据：它在临界线方向的梯度恒为零， 唯一携带信息的是 Hessian 的符号——而那是一个无限维的符号问题。

对你给的材料的直接回答

你问「Schauberger 书里提到的几何等方法」能不能用。答案是：它的几何是对的，但用错了方向。 双曲锥、蛋形、内爆涡旋刻画的是一阶（切触、曲率、包络）的结构； 而 RH 的信息全部藏在二阶（Hessian 的符号）里。 把一阶工具对准二阶问题，无论画得多准，梯度都恒为零——你会一直得到「看起来对但证不了」。
