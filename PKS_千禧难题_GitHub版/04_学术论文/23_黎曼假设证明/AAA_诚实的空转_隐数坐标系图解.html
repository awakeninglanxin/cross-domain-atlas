诚实的空转

刘元杰把黎曼假设搬进「隐数坐标系」w = es： 变换每一步都对，机器确实在转，但输出轴没有接上任何东西。 这不是嘲讽，是一个可以逐项结清的账目。本文把这四步拆成图，把账结清， 然后回答真正的问题——要接上输出轴，该换掉的到底是什么。

对象：刘元杰《The Riemann Zeta Function in Hidden-Number Coordinates》， aiXiv: aixiv.260827.000002 v1.1（2026-09-02）；作者已于 2026-09-01 公开撤回
判据：Davenport–Heilbronn 测试（本文 §4 的两组零点均为自行计算，非引用）
性质：图解 + 判据 + 一条路线的提案。本文不证明黎曼假设，§7 逐条说明为什么不能这么宣称。
同系列：黎曼假设 · 临界线与算术之墙（含 13 节完整背景与 Aizawa 混沌实验） · 为什么攻不进去 · 算术 / 灵敏度二难

§0一句话

「空转」在机械上有个精确定义：齿轮咬合、转速正常、扭矩为零。 判据不是"看起来像不像在干活"，而是功率表上输出端有没有读数。 对应到数学里，这张功率表就是信息账本：进入变换的信息，减去离开变换的信息， 差值能不能是正数。

刘元杰的账本，差值是 0。而这个 0 不是他手艺不行—— 它是一个定理，不是一次失误。本文 §2 给出这个定理的三行证明， §4 给出它的实验版本：一个只差 Euler 积的函数，走同样的每一步，结论是假的。

本文的判决 变换正确、推导诚实、增益为零。三步几何（换坐标、认反演、求不动圆）只用到指数函数的代数性质， 一个字都没用到 ζ 的算术结构；而剩下的第四步——"环域里的零点都不离开那个圆"—— 就是黎曼假设本身，他在摘要里自己标了 remaining。 三步真、一步空，合起来是空转。

§1他的四步，逐帧

先把他的论证完整复述一遍，一步不多、一步不少。这一步很重要： 后面所有的批评都必须落在这四步里的某一步上，否则就是空对空。

  1. 换坐标。令 w = es，s = σ + it。 于是 |w| = eσ，arg w = t。 临界带 0 < σ < 1 被映成环域 1 < |w| < e。 正确
  2. 认反射。函数方程 ξ(s) = ξ(1−s) 里的 s ↦ 1−s， 在 w 坐标里是 w ↦ e/w——一次以原点为中心的反演。 正确
  3. 求不动圆。反演的不动点满足 w = e/w，即 |w|² = e， 故 |w| = √e。代回 |w| = eσ： eσ = e1/2，σ = 1/2。 正确，且是恒等式
  4. 断言。环域内每个零点的反演轨道都退化在 |w| = √e 上。 这就是 RH

前三步一共用了三样东西：指数的代数性质、反射、模长。 三样都不含 ζ 的任何信息——你把 ζ 换成任何一个满足 f(s) = f(1−s) 的函数， 这三步一个字都不用改。这正是问题所在。

这里值得停一下，因为刘元杰的第三步其实是漂亮的： 它把"临界线"这个坐标无关的东西，换成了"某个反演的不动圆"这个几何对象。 在此之前，临界线只是"实部等于二分之一"，一句纯粹关于坐标的话； 之后它成了"在 w ↦ e/w 下不动的点的集合"，一句关于结构的话。 这是坐标变换该有的产出：让不变量现身。

但"让不变量现身"和"证明关于它的命题"是两件事。 前者的收益可以很大——黎曼本人、戴德金、韦伊都靠换坐标拿到过真东西； 后者的收益恰好是零，而且必须有零，下一节说为什么。

§2折叠：一张信息账本

w = es 有一个绕不开的性质：以 2πi 为周期。 所以它在临界带里不是单射——s 与 s+2πi 被压到同一个 w 上。

项目里 800 个非平凡零点，最高到 T = 1183.713，在 w 平面上要绕 188.39 圈。这个几何量是实打实的：每一圈（长度 2π）里平均住着 log(T/2π) 个零点，在 T=1183.7 处约 5.24 个， 最后一圈实测 5 个。相邻零点的角度间隔约 1.20 弧度，随高度按 2π/log(T/2π) 变密：T=1012 时 0.244 弧度，10100 时 0.028 弧度。

2.1 先说准：折叠丢的到底是什么

直觉上会说"零点被压成一团了"。这句是错的，必须收回。 因为卷起来的是角度 t，而半径是 |w| = eσ： σ 一个比特都没丢。最后一圈那 5 个零点，在圆上的角度是

4.746   5.698   6.312   7.627   8.757  （弧度）—— 跨 4.01 弧度，占了大半圈

它们分得很开，根本没叠在一起。所以"折叠导致零点混淆"这条论据站不住， 2026-09-02 那份复审里关于折叠的表述需要收紧（结论不变，理由要换）。

口径修正 折叠真正丢的是圈数 k（t = θ + 2πk），不是半径，也不是零点本身。 而黎曼假设只谈半径——所以折叠对 RH 无害。
这比"有害"更糟：无害意味着这个变换对 RH 根本没有作用。

2.2 二难：要么用不了环域上的定理，要么白干

那折叠还有没有一点麻烦？有，但它不在零点上，在函数上。

ζ(log w) 在环域 1<|w|<e 上不是单值函数： 绕原点一圈，它的值要乘上什么都不变，但你回不到出发的那一叶。 所以凡是"在环域上"的复分析工具——辐角原理、Rouché、Phragmén–Lindelöf、Montel 紧性—— 一条都不能直接用，除非先把分支提上去。

2.3 为什么"换坐标"有时候真的有用

这里必须说句公道话，否则上面那段会误伤所有几何化尝试。

黎曼本人也换过坐标，而且换完就拿到了东西。他把 ζ(s) 换成 θ 函数：

π−s/2 Γ(s/2) ζ(s) = ½ ∫0∞ ts/2−1 ψ(t) dt,   ψ(t) = Σn≥1 e−πn²t

关键差别在这里：θ 函数有一条模变换公式 ψ(1/t) = √t·ψ(t) + (√t−1)/2。 它是一条新的函数方程，而且这条方程来自 n ↦ n² 的整数结构（Poisson 求和 + 格点自对偶）。 换句话说，黎曼换的不是坐标，是对象：把一个 Dirichlet 级数换成一个自对偶的模形式， 于是多拿到一条方程。

同样是"换"，差别在哪：

黎曼：ζ → θ刘元杰：s → w = es
换掉的是对象（级数 → 模形式）坐标（同一个函数，换个写法）
新增方程模变换 ψ(1/t) = √tψ(t) + …无
新方程来自整数格点的自对偶（算术）—
信息增益正 解析延拓、函数方程、显式公式的起点 零 同构重标号

这条对照给出了一个可以现场使用的判据，比"有没有 Euler 积"更好用： 换完之后，你手上有没有多出一条方程？ θ 函数有；w = es 没有——它只是把 ζ(s) 重新写成 ζ(log w)， 一个字的数学内容都没变。

§3反向为什么推不动：一根轴就够了

刘元杰自己说得很准：「从正向来推导能成立，不代表反向来推导也能成立。」 这句话不只是一句自我批评，它可以精确地写成一行几何。

3.1 把问题压到一根轴上

环域里的信息其实只有两个数：半径 |w| 和角度。 黎曼假设只谈半径，而 |w| = eσ，所以这根轴直接就是 σ：

σ = ln|w|  ∈  (0, 1) (3.1)

反演 w ↦ e/w 在这根轴上变成 关于中点的镜像 σ ↦ 1−σ；不动点只有一个：σ = 1/2。 于是三件事各自变成一句话：

命题在 σ 轴上的样子强度
函数方程 ξ(s)=ξ(1−s) 零点集在 σ ↦ 1−σ 下不变（成对） 已知
临界带内无例外所有零点落在 (0,1) 里 已知
黎曼假设所有零点只有一个值：σ = 1/2 未解

看出问题了吗："在镜像下不变"比"只有一个值"弱了整整一级。 一个集合完全可以既对中点对称、又整体避开中点——比如 {0.3, 0.7}。

3.2 「那一跃」的准确位置

于是"正向能推、反向推不动"就不需要再靠感觉描述了，它是下面这对陈述：

正向 成立

若每个轨道都退化成单点，则零点集对镜像对称。
这是恒真：单点集的镜像还是它自己。

反向 不成立

若零点集对镜像对称，则每个轨道都退化成单点。
这是假的：{0.3, 0.7} 就是反例，而且 D–H 函数真的给出了一个。

所以"那一跃"不是某个不等式没证出来，也不是误差项没估好。 它是从"等变"到"平凡"的那一跨：

ℤ/2 作用等变  ⟹  ℤ/2 作用平凡 (3.2)

这两者之间没有任何纯几何的桥。你可以有一整个对称的集合，而它在对称中心处空无一物。 要跨过去，必须引入一条额外的选择原则，而这条原则不能来自对称性本身—— 它只能来自 ζ 的算术结构（欧拉积 / 素数 / 互反律）。 这就是"算术之墙"在几何语言里的样子：墙不在证明的某一步，墙在对称与唯一之间。

本节结论 刘元杰的第三步（求不动圆）回答的是"不动点在哪"， 而 RH 问的是"为什么所有点都必须是不动点"。 前者是一个求根公式，后者是一个全称命题。 他用一个求根公式，去换一个全称命题——这就是空转发生的那一秒。

§4硬证据：D–H 函数真的越界

上一节说"对称集合可以避开中心"。这不是假想，有一个函数真的做到了， 而且它和 ζ 共享除了欧拉积以外的一切。

4.1 那个函数

Davenport–Heilbronn 函数（1936）。取模 5 特征 χ（χ(2) = i），令

α = (√(10−2√5) − 2)/(√5 − 1) = 0.2840790438…
f(s) = ½(1−iα)·L(s,χ) + ½(1+iα)·L(s,χ̄) (4.1)

它满足同型的 Riemann 函数方程：令 g(s) = (π/5)−s/2 Γ((s+1)/2) f(s)， 则 g(s) = g(1−s)。 本文用 mpmath（dps = 25）验算，残差 |g(s) − g(1−s)| ≈ 1.3×10−27。

它还满足：在 σ>1 的半平面有零点（这一点反而比 ζ 更"坏"）； 临界线上有无穷多零点（Hardy 型定理对 f 同样成立）； 属于扩展 Selberg 类，近似函数方程、Riemann–Siegel 展开、Stirling 分析全套照搬。 它唯一缺的是欧拉积。

4.3 这条证据的性质：不是评价，是反驳

D–H 测试 f 与 ζ 共享：函数方程、σ>1 的行为、Hardy 型定理、 近似函数方程 / Riemann–Siegel、Stirling 与 Γ 分析、以及任何坐标变换（包括 w = es）。
它唯一缺的是欧拉积。所以：任何只用这份清单的证明，若成立，就会同时证明 f 满足 RH—— 而上面那个零点说 f 不满足。因此该证明必然在某处出错。

请注意这个论证的形状：它不需要读懂全文，也不需要找出具体哪一行错了。 它只检查一件事——输入清单里有没有欧拉积。 没有，就结束。这就是"可操作判据"和"主观评价"的区别。

也正因如此，"折叠丢信息"那条论据其实不必要： 即使 w = es 是一个完美无损的双射， 这条判据照样杀死证明。坐标变不变换，与能不能证明，是两件不相干的事。

§5出口：从搬点，到搬配对

诊断到这里已经很清楚了。刘元杰搬的是点：每个零点 ρ 被搬到 eρ。 而 Weil 的显式公式搬的是配对：{ρ, 1−ρ} 这一对，连同它们上面的一个二次型。

这个区别不是措辞上的。点没有符号，配对才有。

5.1 配对长什么样

取一个紧支撑的测试函数 f，做乘性自相关 g = f ∗ f∼（f∼(x) = f(1/x)/x）。 它的 Mellin 变换满足一条恒等式：

ĝ(s) = f̂(s) · f̂(1−s̄) (5.1)

右边这个乘积，就是"配对"两个字的全部内容：它把 s 和 1−s̄ 绑在一起。 现在把 s 换成零点 ρ 再求和：

RH  ⟺  W(f ∗ f∼) := Σρ ĝ(ρ) ≥ 0   对一切 f (5.2)

为什么它等价？如果 ρ = 1/2 + iγ，则 1−ρ̄ = ρ， 于是 (5.1) 退化成 |f̂(ρ)|²，求和自然是非负数——RH 成立时，这个二次型是"平方和"。 反过来，只要有一个零点偏离，就可以挑一个 f 把某一项做成负的，求和随之翻负。 这一条是 Weil (1952) 的判据，Bombieri 后来有详细整理。

请注意 (5.2) 和 §3 的关系：ρ 与 1−ρ 正是刘元杰那个反演的两端。 他只是把这对点分别搬了过去（还发现它们乘积恒为 e）， 但从没问过：这一对点上的二次型取什么符号？

一句话 他找到了那个反演，却没问反演下的二次型。 找到不动点，只能说明"若在线上则对称"；问二次型的符号，才能反过来约束"哪些点可以在线上"。

5.2 真正让它不空转的，是下一步

到 (5.2) 为止，还是纯分析的，还是不含算术。把欧拉积请进来的，是显式公式： 左边是零点求和，右边是素数求和，两者恒等。

2 Σγ>0 ĥ(γ)  =  2∫−LL h(u) cosh(u/2) du  −  2 Σpm ≤ eL (ln p / pm/2) h(m ln p)  +  Archimedean (5.3)

其中 ĥ(t) = ∫−LL h(u) cos(tu) du。 左边含全部非平凡零点；右边只含 p ≤ eL 的素数。 支撑 L 越小，右边要的素数越少——L = 2.565（即 eL = 13）时， 只用到 2, 3, 5, 7, 11, 13 这六个素数，却精确等于所有零点的信息。

本项目已经把这个引擎对拍到 4.5×10−14（L=ln13，前 800 个零点， Archimedean 截断 600；详见 11_Weil正定性数值实验）。 这不是信任问题，是可以重跑的：算术侧与谱侧，两条完全独立的计算路径，对上了。

5.3 把两件事拼起来：环域反演型

现在把 (5.2) 放进 w 坐标。因为 ρ ↔ w、1−ρ ↔ e/w， Weil 二次型就是环域 1<|w|<e 上、按反演 w ↦ e/w 配对的零点求和。 两边一对照，结构立刻清楚：

刘元杰拿到的Weil 要的
搬什么点 ρ ↦ eρ配对 {ρ, 1−ρ} ↦ {w, e/w}
反演的作用找到不动圆 |w| = √e在每一对之间放一个二次型
给出的条件"若在线上，则轨道退化"（必要条件）"配对求和 ≥ 0"（等价条件）
算术输入无有（显式公式把求和换成素数）
能否被 D–H 反驳是否

最后一行是关键，值得单独说：Weil 判据不会被 D–H 反驳，因为它用了欧拉积。 对 D–H 函数，(5.2) 的二次型会取负值——这正是它离线的原因。所以判据本身是有内容的： 它把"ζ"和"不是 ζ 的东西"分开。

§6一条能接上输出轴的路：ARF

把 §3 的几何和 §5 的二次型缝在一起，得到一条判据链。 我给它一个名字，只为方便引用：环域反演型（Annular Reflection Form，ARF）。 它不是新定理——它是 Weil 判据在 w 坐标下的重述。 它的价值只在两处：把"点"换成"矩阵"，以及把刘元杰的圆接到 Weil 的二次型上。

6.1 三层：每一层给你什么、不给你什么

图 6｜三层判据链。每一层都"看起来像"在推进，但只有第三层改变了命题的可操作性。 判断一份工作停在哪一层，只需问一个问题：它的式子里有没有出现素数？

6.2 L3 的可执行形式

在 L3 上，RH 变成一个关于有限维矩阵的命题。取 L > 0， 把测试函数限制在支撑 [−L, L] 内，用一组基 {hj} 展开， 二次型就成了一块 Gram 矩阵：

RH  ⟺  对每个 L，QL ⪰ 0 (6.1)

其中 QL(j,k) 只含 p ≤ e2L 的素幂。 （支撑翻倍是因为自相关 f ∗ f∼ 把区间从 L 撑到 2L—— 这一条本项目踩过坑，记录在 03_算术侧Weil算子矩阵.py 的注释里。）

这个形式的好处是它真的能算，而且算出来的东西可以自检：

6.3 缺口只有一个，而且它有名字

(6.1) 里"对每个 L"这四个字，就是全部的难度。 单个 L 的半正定是有限的、可证的；把 L 推到无穷，需要一致控制。 而这个一致控制有一个已知的等价物——de Bruijn–Newman 常数 Λ：

RH  ⟺  Λ ≤ 0   ·   Rodgers–Tao (2020)：Λ ≥ 0   ⟹   RH ⟺ Λ = 0 (6.2)

所以"间接证明"在这里有一个非常具体的目标形态：

间接证明该长什么样 不要去证"每个零点都在线上"——那个命题没有可下手的对象，它是关于一个不可数集合的逐点断言。 要去证"负特征值不允许出现"——那是一个关于矩阵族的符号条件， 可以用区间算术逐段认证。两者等价，但后者每一步都能落地。

6.4 这条路的代价，说在前面

等价不降难度。如果 RH 难，ARF 也一样难，一分不少。 把它摆出来的理由不是"这条路更容易"，而是：

  • 它可证伪。若某个 L 处 QL 出现超出误差的负特征值， RH 就假了。这是一个可以立刻检验的失败条件——不像"某一步推导有问题"那样无从下手。
  • 它的每一步都有数值对手。算术侧和谱侧是两条独立路径，可以互相对拍； 对不上就说明代码或公式写错，不会悄悄混过去。
  • 它天然排斥空转。素数没进来，QL 就写不出来—— 这正是 D–H 判据要的那道门槛。这条路上，空转是写不下第一行的，不是"写了但没用"。

6.5 一句提醒

本文不声称 ARF 是新东西。如果你去查 Bombieri 关于 Weil 二次型的综述、Connes–Consani 的 prolate 工作、或者 Chuk 的区间算术证书，会发现同一套机器，而且比这里精密得多。 本文能加的只有一样：把它和刘元杰的反演圆接上，从而说清楚"那一步"缺的到底是什么。 至于这个接法值不值得写下来，取决于它能不能被别人反驳——这是唯一的标准。

§7边界与自检

这一节是给本文自己用的。判据如果不拿来量自己，就只是武器。

7.1 做了什么 / 没做什么

做了

  • 自算 D–H 函数两组零点（临界线 29 个 + 离线 1 对），函数方程残差 1.3×10−27
  • 把"折叠"的口径收紧：丢的是圈数，不是半径，所以对 RH 无害
  • 把问题压到一根 σ 轴上，把"那一跃"定位成「等变 ⟹ 平凡」
  • 把刘元杰的反演圆接到 Weil 二次型上，给出 ARF 三层
  • 指出缺口 = L → ∞ 的一致控制 = Λ = 0

没做

  • 没有证明黎曼假设，也没有提出新定理
  • 没有算出 Λ，也没有改进任何已知界
  • 没有把 L 推到 2.0 以上（float64 地板）
  • 没有做区间算术，所以 L3 的数值只是"与 RH 一致"，不是证书
  • 没有核验刘元杰论文全文，只核到摘要与公开撤回声明
