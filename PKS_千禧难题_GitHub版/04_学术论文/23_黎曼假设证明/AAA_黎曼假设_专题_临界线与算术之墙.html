五条最要紧的事实

  1. RH 不是「ζ 函数难算」，而是「零点不许离开一条线」。这是一个全称命题的排除： 要排除无穷多个可能偏离的零点，而不是算出某一个值。
  2. 决定性的判据不是「看起来对不对」，而是 D–H 测试。若一个「证明」只用了函数方程、 近似函数方程、Stirling 这类工具，它就自动适用于 Davenport–Heilbronn 函数； 而那个函数已知在临界线外有零点。于是这个证明必然在某处出错——不需要读完它。
  3. 本项目栽在「没有算术输入」。全文检索 Euler 积 / 素数 / prime 命中 0 次。 这不是文风问题，是可机械核验的结构性判据。
  4. 错误的具体位置可以指到行。M2 把两个不相交的求和对象等同（t=106 时差 400 倍）； B4 的交比因 A=B 恒等于 1；误差项与主项同阶。三处都不是笔误。
  5. 转向之后最诚实的成果，是一次对拍。用 ≤13 的素数算出的算术侧，与用 800 个零点算出的谱侧， 吻合到 4.5×10−14。这验证了机制，但没有证明 RH——两者是两回事。

§1命题：一句话，二百六十年

黎曼 1859 年那篇八页论文做了两件事：把 ζ 从实变量推到复平面，然后指出——素数的分布规律， 被零点位置牢牢锁住。命题本身可以用一行写完。

ζ(s) = Σn≥1 n−s = Πp 素数 (1 − p−s)−1，  Re(s) > 1 Euler 积

左边是加法（把所有整数加起来），右边是乘法（把所有素数乘起来）。这条等号就是算术基本定理的解析形式， 也是整件事的枢纽：ζ 的每一个特殊性质，最终都来自右边。经解析延拓后，ζ 满足函数方程

ξ(s) = ½ s(s−1) π−s/2 Γ(s/2) ζ(s)，  ξ(s) = ξ(1−s) 对称轴 σ = 1/2

函数方程把 s 与 1−s 配对，于是「中心线」σ = 1/2 自动出现。 但请注意：对称性只说明这条线是特殊的，不说明零点必须待在上面。 零点可以成对地对称分布在线的两侧——函数方程会照样成立。这正是后面所有错误的分水岭。

黎曼假设 ζ(s) 的全部非平凡零点都满足 Re(s) = 1/2。 平凡零点是负偶数 −2, −4, −6, …（由 Γ 因子产生，不参与命题）。

为什么「看起来都在线上」不等于「证明」

把 1012 以前的零点全查一遍，仍然只是有限个。有限个样本无法排除第 1013 个、 第 10100 个、乃至第无穷多个偏离。而 RH 恰恰是一个关于「所有」的命题。 这就是为什么数值验证再强，也只能改写「已验证到哪里」这一栏，改不了命题状态。

一个容易混淆的区分 ζ 函数（解析延拓、特殊值、函数方程）是已知 260 年的标准工具，物理学界天天在用； RH（零点全在线上）是另一件事。Casimir 力、热核展开、量子混沌能谱用的是前者， 不依赖后者。§6 会把这条界线逐项标出来。

2.1 Davenport–Heilbronn 函数：一个长得像 ζ、但不是 ζ 的对象

1936 年，Davenport 与 Heilbronn 造了一个函数，用模 5 的两个 Dirichlet L 函数拼起来：

f(s) = ½(1 − iα)·L(s, χ) + ½(1 + iα)·L(s, χ̄)，  α = (√(10 − 2√5) − 2) / (√5 − 1)，  χ(2) = i D–H 1936

它有一个要命的性质组合：

性质D–H 函数 f

2.3 墙的精确说法：不是「素数太多」，而是「二次型不正」

「因为 Euler 积有无穷多个因子，所以难」——这句话听着顺，但它是错的，而且错得有价值。 Connes–Consani–Moscovici 2024 的 prolate 论文开篇就纠正了这一点：

存在只依赖「n 以下素数」的 Euler 因子的性质 P(n)， 它对一切 n 成立 ⟺ RH。也就是说，不需要无穷多素数； 难的是把有限截断的正性一路保持到极限。 Weil 正定性的有限形式：支撑在 [n−1/2, n1/2] 的试验函数上 Qn ≥ 0

这个修正很关键，因为它把「墙」从一个无法下手的哲学障碍，变成了一个可以数值逼近的算子正性问题。 §5 的实验就是冲这一点去的。但它同时也说明：本项目原来那种「用几何形状挑出 σ=1/2」的思路， 连墙的位置都没摸到——它压根没进到场里。

§3本项目做过什么：M1–M6

先说清楚这段的性质：它不是「我们差点证出来了」，而是「我们把一条死路走到了尽头」。 把过程留着，是因为每一步的动机都合理，错在第一步的等价替换。

3.1 起点：Servi 的几何观察

Dante Servi 在《Riemann's Hypothesis. This is why it is true.》里画了一组图： 把 ζ 的部分和 PN(s) = Σ n−s 看成复平面上首尾相接的向量链， 他观察到链的前半段与后半段之间存在某种「完美调谐」，并用悬链多边形（funicular polygon） 与伪回旋线（pseudo-clothoid）来描述。

这个观察本身没有错——向量链确实会随 σ 改变形状。错的是下一步：把「形状看起来对称」 当成了「可以推出 σ=1/2」。

3.2 三阶段「严格化」

阶段想做的事工具
① 代数化把「图上看着重合」翻译成复平面变换群下的等式镜像 / 旋转 / 缩放 / 平移 → 群作用
② 射影化把欧氏几何抬到射影几何，声称能锁定唯一性齐次坐标、交比不变量、Möbius 变换
③ 分析化把有限图形推广到无穷级数Riemann–Siegel 公式、平稳相位法、菲涅尔积分

三个阶段各自都有真实内容，问题出在它们的接口：第 ② 步的交比条件是退化的（§4 硬伤②）， 第 ③ 步的求和对象被换掉了（硬伤①）。接口一断，六模块再工整也没用。

3.3 六个模块，以及它们各自的死因

M1 · 桥梁定理 尺度可用

用 Riemann–Siegel 把部分和与完整 ζ 接起来： PM(s) = −χ(s)·conj(PM(conj s)) + O(t−1/4)。 双尺度 n0 = t/2π 与 M = √(t/2π) 在这写下时还是对的。

M2 · 平稳区渐近 硬伤①

把主和 PM 换成了围绕 n0 的「平稳区和」Sstat。 但相位 −t ln n 的导数是 −t/n，在 n>0 上恒不为零——主和区间里根本没有平稳点。

M3 · 乘子模估计 硬伤③

Stirling 给出 |χ(s)| = n0−δ(1+O(1/t))。 估计本身没错，但配套的 Euler–Maclaurin 余项 O(t1/2−σ) 与主项同阶，且 σ<1/2 时发散。

M4 · δ≠0 矛盾 硬伤②

射影交比 (PC,PC;P1,P2)： 第一个点重复 ⇒ 按定义恒等于 1，与 σ、δ 完全无关。所谓 ΔCR = δ·K 是从 0 里变出来的。

M5 · δ→0 收口 硬伤⑤

「零点数至少按 log T 增长，与 ≪ T1−η 矛盾」—— 但 log T ≪ T1−η，根本不矛盾。反证链条空转。

M6 · 有限 t 排除 依赖前五

用紧性 + 围道积分 + 幅角原理排除 0 < t ≤ T0。 方法本身是标准的，但它排除的是「已经由 M1–M5 缩小到有限区域的例外」—— 前提没了，这一步也就无处落地。

（二）那条曲线到底是什么形状？

把向量链的曲率算出来，结论很干净：设弧长 s(k) ≈ k1−σ/(1−σ)， 则曲率

κ = dφ/ds = (−t/n) / n−σ = −t·nσ−1 = −t / ((1−σ)·s) κ ∝ 1/s

κ 与弧长成反比，这是双曲 / 对数型螺线。回旋线（clothoid）的定义恰恰相反：κ ∝ s。 所以目录里那份 黎曼假设的clothoids线证明.docx，命名本身就不成立。 更关键的是：曲线族的类型与 σ 无关，σ 只进入比例常数 t/(1−σ)。 换句话说，单看形状，数学上挑不出 σ = 1/2；要挑，就必须用长度或相位匹配——而那正是硬伤①出错的地方。

§3 小结 M1–M6 不是「差一点」的证明，而是在第一步就把对象换掉了。 换掉之后，后面每一模块都可以写得很整齐——因为它们分析的是一个不存在的量。 这就是为什么复审只需要看两行：M 的定义，和交比的定义。

§4复审：五处硬伤，0/5 可修

2026-09-02，独立第三方对三份草案做了逐行复审。对本项目的结论很直接： 五处硬伤，性质不同，但没有一处能靠打补丁救活。下面按「病根 → 如果硬要修 → 修完还剩什么」写。

硬伤 ① · M2 把两个不相交的求和对象等同

病根：§2.4 取 M ≈ ⌊t/2π⌋，§3.1 又取 M = ⌊√(t/2π)⌋（后者才是 RS 截断）。 然后 Qk 被定义成围绕 n0 = t/2π 的和， 而 n0 根本不在 [1, M] 里。两个指标范围不相交，却被要求由同一个 Möbius 变换相连。

如果硬要修：回到正确的主和 S(t) = Σn≤√(t/2π) n−1/2−it， 用 van der Corput 离散指数和，或 Hardy–Littlewood/Landau 的 Θ 函数变换——这就是 Hardy 定理的标准证法。

修完剩什么：最多得到已知结论（临界线上有无穷多零点）。原来的核心方程不是从 ζ(s)=0 推出来的， 是换出来的；伪矛盾的来源就是这次代换本身。

判定❌ 不可修复 · 承重墙

硬伤 ② · 交比条件恒等于 1

病根：按文中定义 (A,B;C,D) = ((A−C)/(B−C)) : ((A−D)/(B−D))， 实际代入的是 A = B = PC。分子分母逐项相同，交比恒为 1，与 σ、δ 无关。

如果硬要修：交比有区分度的前提是四点两两不同。要重新选四个真正不同的点， 并独立证明其非平凡性质——但那等于从零重造整条射影路线。

修完剩什么：射影几何在 RH 里的正确用法只有一个——函数域上的 RH（Weil 1948 / Deligne 1974）， 用的是代数曲面上 Frobenius 不动点的 Castelnuovo–Severi 不等式。对标对象是 Spec ℤ 上的算术几何， 不是 ζ 零点的交比。

判定❌ 不可修复 · 定义层面退化

硬伤 ③ · 误差项与主项同阶，σ<1/2 时发散

病根：§4.3 自算 Euler–Maclaurin 误差 O(t1/2−σ)， 主项是 (t/2π)1/2−σ·I，比值 O(1)。文中却写「= o(1)（当 σ>0）」—— 这要求 σ>1/2；σ<1/2 时该项直接发散。§4.4 又把余项悄悄改成 O(t−1/4)， 与 §4.3 相差 t3/4−σ 倍。同一份证明里余项量级不自洽。

如果硬要修：诚实控制误差需要完整 RS 公式——主和截断在 ⌊√(t/2π)⌋ 并加修正项， 这样总误差才是 O(t−1/4)。单独用 Euler–Maclaurin 达不到。

修完剩什么：把误差写对之后，「矛盾」立即消失——等式两边泡在同阶噪声里，推不出 σ=1/2。

判定🔶 技术上可改写，改写后结论不复存在

硬伤 ④ · 全文没有算术输入

可机械核验的事实：对 Riemann_Hypothesis_Complete_Proof.md 全文检索—— euler 命中 3 次，全部是 Euler–Maclaurin 求和公式； 欧拉积 / Euler 积 / 素数 / prime 命中 0 次。

如果硬要修：必须引入 ζ 特有的算术输入——Euler 积 Σp −ln(1−p−s)、 素数计数、Möbius 函数、显式公式。所有活着的等价命题都带这些：Weil 正定性、Li 判据、 Nyman–Beurling（Möbius 输入）、Robin/Lagarias。

修完剩什么：加入算术输入后，整个论证就不再是原来的 AFE 框架——等于放弃原证明，换一个新论证。

判定❌ 不是修一处，是换一个证明 · 结构性

硬伤 ⑤ · M5 的「矛盾」根本不是矛盾

病根：原文反证「若有无穷多偏离零点，Noff(T) 至少按对数增长， 与 Noff(T) ≪ T1−η 矛盾」。但 T1−η → ∞ 且 log T ≪ T1−η，两个都是无穷，谈不上矛盾。 另外 Selberg 密度定理在 σ = 1/2 + C/log T 处的正确形式是 N ≪ T·e−C/4·log T，不是 T1−η。

如果硬要修：要证 Noff(T) 有比 T1−η 更强的上界—— 这本身就是极难的零密度问题（Guth–Maynard 2024 是当前最好，仍远未到「排除无穷多」）。

判定🔶 局部可删改，删改后 M5 无结论

§5数值转向：把算术装进实验

判据说「要 Euler 积」，那就找一个既能装进算术、又能真的算的等价形式。 Weil 显式公式是目前唯一同时满足这两条的路。

5.1 一句话说清它为什么有希望

2 Σγ>0 ĥ(γ) = 2∫−LL h(u) cosh(u/2) du − 2 Σpm≤eL (ln p / pm/2) h(m ln p) + Archimedean 项

左右两边是两种完全不同的数据：左边只用零点 γ，右边只用 ≤ eL 的素幂。 显式公式说它们恒等。所以当试验函数的支撑被限制在 [−L, L] 时， 「前几个素数的信息」与「全部零点的信息」在数学上是同一个数。

5.7 诚实边界（这一段比结果重要）

  1. 不证明 RH。谱侧 Gram 是 FTF 型，正定性是构造性的； QN > 0、λn > 0 都是「与 RH 一致」的必要条件，不是充分条件。
  2. 没达到 Connes 的 10−55。本包用 float64 + cos⁴ 闭式基，目标是复现机制与正确性自检； 2.6×10−55 需要 prolate 最优窗 + 60 位以上精度 + 区间算术。
  3. 双重截断。谱侧取前 K 个零点，Archimedean 项在 Tarch 截断。 早期把 L≥2 的 ~1e−11 残差归因为「float64 噪声地板」，该归因被 04 号脚本推翻—— 真凶是 Tarch=150 的截断；提到 600 后 float64 与 mpmath(dps=40) 一致到 1e−14。
  4. zetazero() 默认零点在临界线上——用它做谱侧，在结构上不可能证伪 RH。 这正是 D–H 判据要提醒的：数值自洽 ≠ 证明。

§8临界圆：换一副坐标，到底换来什么

前面七节讲的是「怎么证、为什么证不出来」。这一节讲另一条完全不同的路子： 不做新不等式，只做一次变量替换。它来自刘元杰的「隐数坐标系」（2026-08-27 挂在 aixiv 的自存档稿）， 核心只有一行字：w = es。

8.1 一步替换，四件东西换位

定性 这是等价重述，不是推进。它的价值在「看得见」，不在「证得出」。 把它当望远镜可以，当锤子不行。

9.2 要变成数学对象，必须补上四样东西

(a) 算子定义

必须写出一个（或一族）算子 H，其谱精确等于 ζ 的零点：本质自伴、谱离散纯实、谱点与零点一一对应。画图不算。

(b) 边界条件唯一

不允许任何自由参数。Berry–Keating 的 H = xp 就死在这一步：边界条件无法无歧义固定，差一点就差一个常数。

(c) 排斥机制

必须证明：任何 Re(ρ) > 1/2 的「假零点」都对应一个不稳定 / 非自伴 / 破坏全局正性的模态。这是全场最难的一步。

(d) 从极限到逐点

「t → ∞ 时收敛」不等于「每个 t 都成立」。把渐近当全称，是最常见的一种偷换。本页的 3D 就停在这里。

9.5 那只漏斗：它是涌现的吗

不是。它是手画的，没有方程。代码里就两行幂律： r(u) = r₀(1−u)1.65、 y(u) = y₀ − 1.06u1.08，指数 1.65 与 1.08 没有推导，只是调到顺眼； 紫色螺旋的转角 a(u) = 6.2πu + 0.25t 同样是手写的。没有向量场，没有积分，没有解。 所以它在画布上已经带了标签——「手绘 · 无方程」。

那它在数学上本该是什么？只有一个答案站得住：稳定流形 Ws(p) = { x : φt(x) → p，t → ∞ }， 即给定流 ẋ = F(x) 后，收敛到不动点 p 的全部初值的集合。 只有它是「自然而然长出来的」：由 F 唯一决定，不是画的。

漏斗之所以长成漏斗，机制只有一个：横向收缩。把 p 处线性化， 特征值 Reλj < 0 的方向张成 Es， Ws 在 p 附近与 Es 相切，横向偏离按 e(Reλ)·t 指数收缩——这才叫「被吸回来」。 手绘漏斗的全部毛病就集中在这：它没有 λ，所以它不吸任何东西，只是看起来像在吸。

10.3 一个反身的事实：混沌与「落在一条线上」互斥

顺着上一段往下推，会得到一个对本题很不利、但必须说出来的结论。

一维吸引子上的流只能有两种命运：周期轨道，或准周期环面塌缩后的闭合曲线。 真正的混沌需要正 Lyapunov 指数，而正指数会把横向的不确定性指数放大—— 它不允许轨道被压到一条没有厚度的线上（Ruelle–Takens 之后这是常识）。

所以，要把这个桶形壳压成一条线，只有一条路：把参数推进周期窗口。 在那种参数下系统退化成可积的，吸引子确实变成闭合曲线—— 但那时它已经不是混沌吸引子了，它是一族闭轨，任何「混沌」的说服力都消失了。

图 10 里把 d 从 3.5 拖到 5.0，做的就是这条路的一半： λ₁ 从 +0.09 掉到 0，维数从 2.28 掉到 2——掉到 2 就停住了。 再往下不是靠调参数能到的，得换系统。

方向反了 「用混沌吸引子证明零点全在线上」这句话里，两个词是打架的。 混沌给的是厚度和统计（§6 图 7 的 GUE 正是这个厚度的指纹）； 而 RH 要的是零厚度。 你能从混沌里拿到的最好东西，是「零点像 GUE」，不是「零点在一条线上」。

算术 无。方程里没有一个素数，换任何初值行为都一样 全部内容都是算术。Euler 积是唯一的入口，也是唯一的锁

10.5 「造一个含素数的流」为什么堵死

直觉的下一步是：那就造一个动力系统，让它的吸引子恰好是 ζ 的零点集。 这条路只有三个出口，每个都堵着：

出口一 · 把 Euler 积塞进初值

初值编码了素数，轨道自然「知道」素数。 但这样你证明的只是「这个初值的轨道如何」，等于把待证命题藏进了初值。循环。

出口二 · 把 Euler 积塞进向量场

要求向量场在每一点都「知道」全体素数。 素数分布不是任何有限维流的积分曲线——它能写出的最接近的东西， 是 ψ(x) 的显式公式，而那已经是恒等式，不是动力学。

出口三 · 什么都不塞

那你的系统就是一个「同型函数」。 D–H 判据立刻适用：它在某个 σ > 1/2 的地方也有吸引子。 你会「证明」一个假命题。这是三条里最容易发生、也最危险的一条。

唯一的合法出口

让「演化」不是假设的，而是已经存在的—— 也就是问：ζ 自己有没有一个内蕴的热流？有。那就是下一条。

10.6 那一跃的正确坐标：Λ

de Bruijn（1950）与 Newman（1976）给了一个不靠猜的演化：把整函数按热方程流。

Ht(z) 满足   ∂H/∂t = ∂2H/∂z2，  H0 = ξ   ⟹   Ht(z) = ∫ ξ(z+u) e−u2/(4t) du / √(4πt)
Λ := inf { t : Ht 的全部零点为实数 } de Bruijn–Newman 常数

这一步之所以是「正确的出口」，因为它不是我们造的流—— 它是 ξ 自带的热流，Euler 积已经完整地待在 H0 = ξ 里面了。 不需要额外塞任何东西，也就不会掉进 10.5 的三个坑。

然后三条事实，一条比一条硬：

1950 · de Bruijn
t ≥ 1/2 时，零点全实
热流流得够久，所有共轭零点对都会被压到实轴上。这一步只用了 ξ 的实性与增长阶，很稳。
1976 · Newman
猜想 Λ ≥ 0
即「还没到 t = 0，零点就已经全实了」这件事不该发生得那么早。这是一个比 RH 更强的陈述。
2020 · Rodgers–Tao
Λ ≥ 0　（已证）
用多尺度熵/能量方法证出。这是近二十年这条线上最硬的一块砖。
等价关系
RH　⟺　Λ ≤ 0
因为 H0 = ξ，而「ξ 的零点全实」正是 RH。 Λ ≤ 0 意味着 t = 0 这一刻零点就已经全实。
与 Rodgers–Tao 合起来：RH ⟺ Λ = 0。
这就是那一跃的坐标 你要的「一次结构性的不可能」，数学上确实存在，它的名字叫 Λ = 0。

它满足你的全部要求：把无穷多次验证压成一个实数的符号。 Λ 是一个数，不是八百万个零点；判它是否为零，是一次结构性判定，不是逐点核对。

但它不是免费的。左边（Λ > 0）是 Rodgers–Tao 封死的，右边（Λ = 0）就是 RH 本身，中间没有真空。 你换到了一个更好的位置——从一个关于无穷多点的命题，换成了一个关于一个实数的命题—— 但距离没有缩短。

10.7 那么「那一跃」到底缺什么

把上面的东西收拢，缺的可以精确列出来。它不是缺一个更聪明的几何直觉，而是缺一个不等式：

要素现在有什么缺的那一块
载体热流 Ht，Euler 积天然在内已有
下界Λ ≥ 0（Rodgers–Tao 2020）已有
上界无缺　Λ ≤ 0，即「零点从不离开实轴」
等价性RH ⟺ Λ = 0，双向都清楚已有

而且这个不等式不能靠「稳定性」得到。原因很朴素：零点不是吸引子。 在零点附近 ζ(s) ≈ ζ′(ρ)(s − ρ)，这是一次幂，不是指数衰减—— 「横向 Lyapunov 指数」在这个对象上根本没有定义。 任何要给零点谈「回复力」的尝试，都必须先有一个真实的流；而目前已知的唯一内蕴流就是热流； 而热流已经被打到 Λ ≥ 0 了。这个圈闭得很死。

所以，回到最初那个问题

「不在线上的轨道，几何上能不能存在？」

答：能，而且很容易。D–H 函数里就有一整族；Epstein zeta 里也有； 甚至 ζ 的某些变体里，离线的零点比在线的还多。 几何上不存在任何力量禁止一条零点跑到别处去——这正是 RH 难的原因。

真正禁止它的是算术。而算术进入的唯一已知通道是 Euler 积； Euler 积被装进「流」的唯一已知方式是热流； 热流给出的唯一量化判据是 Λ； 而 Λ 的上界，就是 RH。

结论 那一跃不在几何里，在算术里。

几何直觉能告诉你「应该有一条线」，但它永远不能告诉你「只有一条线」。 前者是这个桶形壳给你的——而且它给错了：壳有厚度； 后者只能来自 Euler 积。

所以你的判断是对的：一旦「结构性不可能」成立，Vp 就不再是无穷次验证。 只是那个「结构性不可能」不是几何形状的不可能，是 Λ ≤ 0 这个不等式的不可能。 它已经被人找到了位置，还没有人跨过去。

顺带一句关于 §9 那个漏斗：它是手绘的形状叙事，不是积分出来的。 本节图 10 才是真流场跑出来的形状——而且它不是漏斗，是一个中间鼓、两端收的桶形壳。 这恰好说明形状叙事的局限：真壳有厚度、有维数，手绘漏斗两样都没有。两者并排看，就是本节的全部论点。

11.1 函数域已经证了，证法长什么样

这是整件事里最容易被忽略、也最有建设性的一条：「用射影几何证明 RH」在函数域上已经存在。 Weil 1948 对曲线、Deligne 1974 对高维，都证了。但它的引擎不是「临界线上的几何」，而是算术侧的对象：
