## 2. 为什么 C/D 推不到 A/B（三条，按硬度排序）

### 2.1 规则层：C/D 比「A 不成立」更弱

Clay 官方把四条并列，是为了"保留问题核心的同时给解题者合理回旋余地"：

- **A**：R³，**所有**光滑快速衰减无散初值，**f ≡ 0** ⇒ 全局光滑、能量有界。
- **B**：T³，**所有**光滑周期无散初值，**f ≡ 0** ⇒ 全局光滑周期解。
- **C**：**存在**一组 (u₀, f)（f 光滑、快速衰减）⇒ 无全局光滑有界能量解。
- **D**：T³ 上的同款"存在"。

所以 **C 是"存在一个坏例子"，A 是"所有例子都好"**，中间隔着一个"你可以自己挑外力"的自由度。
C 成立**完全不能**推出 A 假；反过来也一样。**四条不是两对否定命题。**

### 2.2 技术层：把 f 拿掉，构造就散架

OpenAI 的机制靠外力在环形区维持振荡脉冲、用雷诺应力抵消背景奇异残差。
令 `f ≡ 0`，这份抵消消失，残差在 `t ↑ T*` 时无界——**既可能爆得更快，也可能直接衰减**，行为未知。
取 `f_ε → 0` 也不行：Clay 要求 f 光滑且满足衰减条件，δ 逼近等于让外力在奇点处变奇异，属于**规避问题**。

### 2.3 反证层：CIV（2026-09-17，arXiv:2609.20803，项目稿转述）🔶

Constantin–Ignatova–Vicol 的结果大意：在「各向异性 Type II 角平均界 + 收缩核上精确轴对称 + 外力空间实解析」下，
解在假想奇点处**必然正则**。由于 `f ≡ 0` 是实解析的特例 ⇒ **这一类构造在无外力时自动失效**。

> 这条比 2.2 更狠：2.2 说"推不过去"，2.3 说"推过去会得到相反结论"。
> ⚠️ 该 arXiv 编号与定理条件来自项目内部转述，**尚未逐字核对原文**，引用时请标 🔶。

## 3. A/B 的真实结构（三行就能说完，但每行都是一堵墙）

1. **唯一的全局先验界是超临界的。** Leray 能量不等式控制 `‖u‖_{L²}`，在 `u_λ = λu(λx, λ²t)` 下 `‖u‖_{L²} → λ^{-1/2}‖u‖`，
   即**越细的尺度越管不住**。而所有临界量（`L³`、`Ḣ^{1/2}`、`BMO^{-1}`）**都没有先验界**。
2. **爆破判据是好的，缺的是控制它的量。** BKM：`T* < ∞ ⟺ ∫₀^{T*}‖ω‖_∞ dt = ∞`。
   Prodi–Serrin / ESS 给了 `L^q_tL^p_x`（`2/q+3/p ≤ 1`，含端点 `L^∞_tL³_x`）的正则判据——**条件，不是结论**。
3. **局部理论已经到顶。** CKN：合适弱解的奇异集抛物 Hausdorff 维数 ≤ 1。**允许孤点/奇点线存在**，排不掉。

> 所以缺的不是"更聪明的估计"，而是**一个既有先验界、又能控制 `∫‖ω‖_∞dt` 的量**。
> Tao 2014 的障碍定理进一步规定：这个量**不能**只经由"能量恒等式 + 范数黑箱"得到。

## 4. 五个缺口 → 五条能动手的事

| # | 缺口（来自 `01` §5.6） | 现在能做什么 | 验收标准（做到什么算完） | 需要什么 |
|---|---|---|---|---|
| **A** | `‖∇ξ‖` 的下界（相干性可能自发出现） | 在既有 32³/64³ 数据上做**条件统计**：按 `\|ω\|` 分位分层，统计 `\|∇ξ\|²` 的分布随时间的漂移；检验"相干化"是否真的发生 | 给出 `P(\|∇ξ\|² < ε \| \|ω\| > λ‖ω‖_∞)` 随 `t` 的曲线；若该概率单调升，缺口 A 的"坏情形"被数值坐实 | 现有 `_diagnostics.py`，无需新算力 |
| **B** ★ | 非局部核的**一致下界**（把"非轴对称"量化进 Biot–Savart 积分） | 把猜想写成**显式不等式**：给定"非轴对称度" `δ_na`（如中心线曲率×长度、两丝非共面夹角），断言 `⟨Q⟩ ≤ -c(δ_na) < 0`；再在已知反例族（轴对称、Type II）上验证它**确实失效** | 得到一个"错就会被数值打脸"的陈述：给出 `c(δ_na)` 的候选形式 + 在 3 个流场上的符号检验 | 纯数学；文献里找 `∇⊗∇Δ^{-1}` 的核估计 |
| **C** | dyadic 求和的闭合 | 把 `Ω_λ(t) = {\|ω\| ≥ λ‖ω‖_∞}` 上的估计写成 dyadic 块，检查每块的常数是否可加 | 给出块常数表；若某一块发散，缺口定位到该块 | 调和测度/极大函数那套工具 |
| **D** | 拓扑冒泡（HMHF 型临界梯度集中）的排除 | 精读 HMHF 文献，列出"若发生冒泡，则与哪条已知定理冲突" | 一张"冒泡 ⇒ 矛盾"的对照表；冲突不上就说明这条路还开着 | 文献 + 耐心 |
| **E** | 面积/体积项余项消去（CKN 未闭合项） | 复算 CKN 局部能量不等式的余项，看在本项目构造下能否用"非轴对称"吸收 | 余项 ≤ 主项的显式常数比 | 手工分析 |

> **排序建议**：**A → B → E → C → D**。
> A 最便宜且能直接判"猜想 β 的坏情形是否存在"；B 是唯一的真数学硬骨头；C/D 依赖 B 的中间产物。

## 5. 为什么建议先做 B（T³）再做 A（R³）

不是因为 B 更简单到能证，而是因为**B 少一层技术噪声**：

| | A（R³） | B（T³） |
|---|---|---|
| 空间 | 非紧，需"快速衰减"控制无穷远 | 紧流形，无边、无无穷远 |
| 工具 | 需要处理低频/空间衰减 | Fourier 级数、Littlewood–Paley 干净 |
| 常数 | 常带"无穷远处小量"假设 | 无此负担 |
| 若证出 | 顺带给出 B（一般不能反推） | 不给出 A |

> 现实做法：**先在 T³ 上把"非轴对称 ⇒ 耗尽"做成定理（哪怕是条件性的），再补 R³ 的衰减估计。**
> 反过来先攻 A，会在"无穷远"和"临界性"两件事上同时卡住。

## 6. 换一个"更聪明的模型"能不能搞定？（直接回答）

**不能。** 理由不是算力，也不是智商：

| 事实 | 含义 |
|---|---|
| OpenAI 用**约 1 万并发 agent、88 小时、270 万条消息、1300 亿输出 token**，做出来的是 **C/D** | 最强的系统 + 最大规模的算力，**选的是有外力那条路** |
| 同一批系统此前的成果（欧拉无外力）也**不是** NS 无外力 | 无外力 NS 至今没有任何系统宣称拿下 |
| 2026-10-06 的 722 篇手稿：372 族、约 4000 道题、平均 3 小时 Pro 算力/题；**10-07 因一个符号错误撤回 3 篇**（连带依赖） | 批量产出会**成串**出错；`Nature` 也指出这批**不含**剩余千禧问题的解 |
| 形式化率口径：官方说约 42%，独立复核给出 24% / 36%（分子对不上任何清单） | **连"验证率"本身都需要验证** |

> **结论**：换模型最多把"读 166 页论文、扫文献、找缺口、写形式化骨架"的速度提上去；
> 它不会把 0% 变成 100%，因为缺的是**一件全世界都没有的数学工具**（缺口 B），不是缺一个更快的搜索器。

### 6.1 如果一定要选，按任务分配（而不是"选一个最强的"）

| 任务 | 该用什么 | 说明 |
|---|---|---|
| 吃下 166 页论文 + CIV 全文，做逐条引用比对 | **长上下文档**（能一次装下全文并给页码定位的模型） | 这类活计对"上下文长度 + 引用纪律"敏感，对"聪明"不敏感 |
| 找反例 / 提策略 / 多路并行试探 | **推理档 + 多 agent 编排** | 单模型单轮没用；要的是并行试错 + 交叉分发（OpenAI 自己就是 Codex 做汇总） |
| 把结论钉死 | **Lean 4 + mathlib** | 只有它能给"机器可查"；但注意**忠实性缺口**：形式证明只保证"证明匹配形式陈述"，不保证"形式陈述就是你想说的那句话" |
| 判断值不值得做 | **人**（数学同行） | 陶哲轩那条：机器可查的正确 ≠ 有价值 |

> 所以我的建议不是"换个更聪明的模型"，而是：**换验证回路**——把每一个"我觉得"都换成"跑一次/查一次/形式化一次"。
> 这也是本仓库唯一真正累积下来的东西。
