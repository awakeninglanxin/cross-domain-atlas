先把三个口径说清楚，否则一定吵架：
① 数学界口径：一道题"解决"＝有完整证明并通过同行评议。按这个口径，七题里只有庞加莱猜想（Perelman 2003）算确认解决。

③ 本仓库口径：一道题"建立连接"＝在 PKS 框架里给出了解释路径或证明框架。按这个口径是 0 道未解决。

2.3 C/D 为什么推不到 A/B（三条，按硬度排序）

  1. 规则层：C/D 允许自选外力（见上表），A/B 要求 f ≡ 0 且对所有初值成立。逻辑上无通道。
  2. 技术层：那套构造靠外力在环形区维持振荡脉冲、用雷诺应力抵消背景奇异残差。令 f ≡ 0，抵消消失、残差无界—— 既可能爆得更快，也可能直接衰减。取 f_ε → 0 也不行：Clay 要求 f 光滑且满足衰减条件，δ 逼近等于让外力在奇点处变奇异，属于规避问题。
  3. 反证层：项目稿记录的 CIV（arXiv:2609.20803，转述，未逐字核）称，在外力空间实解析（f ≡ 0 是特例）等条件下， 该类型构造在假想奇点处必然正则。⇒ 不只是"推不过去"，而是"推过去会得到相反结论"。

A 级庞加莱猜想 · 已由他人解决

拓扑学 ｜ Perelman 2002–2003，三篇预印本 ｜ 本仓库仅收录方法

项目里是什么：不是证明，是导读。里奇流、W-熵泛函、带手术的里奇流这套工具被整理进 七题总览，用于说明"什么样的证明才算证明"。

B 级黎曼假设 · 完整框架，可逐步审

数论／复分析 ｜ 19 篇 · 236 KB · 4 个 py ｜ 全仓库做得最深的一道

项目主张：M1–M6 六模块化证明，路径是 Dante Servi 几何 → 代数化 → 射影几何化 → 分析化。 另有 3D 几何证明路径（ζ 锥体 + 双锥 + 蛋形闭合）， 以及 GUE 量子混沌五篇（Montgomery 对关联 / Odlyzko 数值验证 / 随机矩阵 / Hilbert–Pólya / Keating–Snaith）作为独立旁证。 另有 07 三方独立复审（DH 测试） 与 09 审查图集。

我的判断：这道题的可信度反而是六题里最高的——不是因为它更接近证明， 而是因为它主动撤回了一条对自己有利的数据，并且把"L7 证明 = 0%"写在表里。 一个会撤自己数据的文档，比一个宣称"全部已解决"的总表可靠得多。

缺什么：缺 L7（证明）本身。文件里写得很直白：「现有路线推不动它」。 五个缺口（A–E）与可执行动作见 05_A与B还差什么。

建议的对外说法：「外部刚把有外力那一半（C/D）宣称做掉了；我们攻的是无外力那一半（A/B），目前 0%，但已画出一张带五个缺口的作战地图。」

D 级杨-米尔斯质量间隙 · 概念桥

量子场论 ｜ 2 篇 · 33 KB

项目主张：质量间隙 = Anu 1680 匝（= 8!/24 = 二阶魔方排列数）的振动谱禁区； 360°/7 ≈ 51.43° 螺旋倾角 → 7 匝相位回零 → 几何固有超导（无质量规范玻色子）；打破超导 → 间隙打开。

D 级P vs NP · 概念桥

计算复杂性 ｜ 1 篇 · 19 KB

项目主张：Anu 的 7 芒星被三把数学锁唯一锁定（Milnor 异 7-球面 + 陀螺拓扑互锁 + 群论）， 拆解 Anu = 破坏 Möbius 环 ⇒ 不可约；对应"验证容易、构造困难" ⇒ NP 完全性；7 个 koilon 泡泡在 Möbius 环上的排列 ≈ 图同构。

问题在哪：「不可约」是几何直观，不是复杂性类之间的分离证明。 要证 P≠NP，必须给出对所有算法的下界——目前唯一的桥是类比。

建议的对外说法：「给了一个几何直觉上的类比」。

D 级BSD 猜想 · 概念桥

数论／椭圆曲线 ｜ 1 篇 · 19 KB

项目主张：椭圆曲线是双曲锥截面的特例（退化到圆→椭圆）；Anu→E2→E3→E4 的群论梯； Anu 间拓扑纠缠由辫群 B_n 描述；BSD 的"秩" ≈ 辫群表示的自由生成元数量。

建议的对外说法：「提出秩与辫群生成元数的对应猜想」（这本身是个可发表的猜想，但还不是证明）。
