## 二、五层的「共因」：同一层其实缺的是同一件东西

同层问题之间不是「都重要」这种弱关联，而是**它们卡在同一个缺失的工具上**。这是本文件最重要的一张判断。

| 层 | 共同缺失 | 表现 | 一旦补上 |
|---|---|---|---|
| T0 | **代价函数**：没有把「放弃哪条公理」换算成「失去哪些已测事实」的记账法 | P01 算不出比例、P02 列不出表、P03 给不出判据、P06 写不出等价命题 | 所有「为什么」类问题会立刻分成「有答案」与「原则上无答案」两类 |
| T1 | **参数空间的几何**：没有测度、没有信息度规、没有「有效维数」 | P09 只能数参数、P10 说不清代为何重复、P16 说不清两个能标、P18 说不清「紧」 | 「为什么是这个点」变成「这个点在内禀几何里是否特殊」 |
| T2 | **粗粒化映射**：从微观到宏观的那一步没有统一写法 | 面积律、ETH、拓扑序、孤子、核结合能，全是「低能为什么忘了微观」的变体 | 涌现从哲学词变成可计算的投影算子 |
| T3 | **元语言**：物理理论本身的语法没有被形式化 | 证明论强度、唯一性定理的地位、变分的本体论，都只能靠「品味」谈 | 「物理理论能说什么」有了句法边界 |
| T4 | **判决阈值**：只问「能不能测」，不问「测到多少才算了结」 | 每个实验都能再提高一个量级，永远不结案 | 争议从「等更好的实验」变成「先定结案标准」 |

> 换句话说：T0 缺的是**账本**，T1 缺的是**地图**，T2 缺的是**投影**，T3 缺的是**语法**，T4 缺的是**判据**。

## 三、T0 地基（P01–P08）：答了会重排整个物理

### P01｜物理定律里，有多少是被结构逼出来的，多少只是恰好如此？

**问法**　给一个「必然性预算」。标准模型 19 个参数里，把唯一性定理能钉死的部分剥离——Lovelock 定死引力方程的二阶形式、Weinberg 定死自旋 2、Coleman–Mandula 定死对称群只能是庞加莱×内禀、CPT、自旋统计——剩下多少个是自由的？能不能定义一个指数：**被定理约束的自由度 ÷ 总自由度**？如果这个指数只有 0.2，那说明我们还有大量定理没发现；如果接近 0，那 144 问里一大半「为什么」其实无解，只能问「有多少」。

**为什么排第一**　它决定后面 63 个「为什么」的期望值。物理学家谈「美」「自然」「唯一」时，从来没有先算过这个预算，所以争论永远停在品味层面。先算比例，再决定要不要问为什么。

**同层共振**　P49（唯一性定理能否替代实验）、P53（变分原理是否只是重写）——三者都在问「数学结构对物理的约束力到底有多强」，只是分别从定理、实验、变分三个入口。

**答它要什么**　把每一条唯一性定理的**前提**列成清单，并区分「前提是物理假设」还是「前提是数学定义」。这一步做完，比例才有意义。

**顺带解锁**　P09（知道预算才知道 19 个参数该压到几维）、P22（相的分类也是「哪些结构被逼出来」）、P49（预算给出定理覆盖率）、P53（变分若只是重写，就不计入预算）。

**接 144**　直接推进「美是判据吗」「数学为什么有效」「变分原理统治物理」三问；对「α 的机制」给出期望值上限。

### P02｜量子力学与引力之间，必须放弃的是哪一条？

**问法**　不要问「哪个理论对」，问「哪个牺牲品最便宜」。列三张代价表：① 放弃幺正性（信息真的丢）；② 放弃定域性/等效原理（视界处不再是空的空间）；③ 放弃「时空是流形」（底层是因果集、非交换几何）。每张表必须写清：会连带失去哪些**已测**事实（洛伦兹不变、能量守恒、黑洞熵、CMB 谱、等效原理 10⁻¹⁵），以及最小可检验后果是什么。哪张表净损失最小？

**为什么排第二**　这是物理学唯一还在的「内部矛盾」，且所有路线（弦、圈量子、因果集、全息）真正的分歧就在这张表上。但从来没有人把「代价」写成可比的形式，所以路线之争一直是阵营之争。

**同层共振**　P07（面积律是不是引力专属）——如果面积律在无引力系统里也成立，那「放弃时空流形」的代价就小得多；P03（时间是否基本）——放弃流形必然要先放弃「时间是参数」。

**答它要什么**　把「放弃」翻译成「修改哪条公理或哪个范畴」，而不是「换一个理论」。需要一份「已测事实 → 依赖哪条公理」的依赖图。

**顺带解锁**　P03（三条路对时间的态度不同，表一列就分出胜负）、P28（面积律的强弱决定全息是否是必选项）、P34（引力波速=c 在哪条路里被保住）、P35（无毛在哪条路里失效）、P38（复杂度=体积只在全息路里成立）。

**接 144**　黑洞信息、火墙悖论、时间是涌现的吗、宇宙波函数——这四问的答案全部由 P02 的选择决定。

### P03｜时间是基本量，还是从代数结构里读出来的？判据是什么？

**问法**　如果时间是涌现的，它必须留下痕迹。两条候选痕迹：① 可观测代数不交换（Tomita–Takesaki 模流给出一个由态决定的一参数自同构群）；② 「热时间」假设（Connes–Rovelli：时间由热态与哈密顿量共同定义）。问：**哪些观测能区分「时间是真参数」与「时间是模流」**？是温差、纠缠谱、还是 CPT 的微小偏离？给出一个可算的偏离量。

**为什么排第三**　时间是「演化」「因果」「初条件」「幺正性」的共同前提。它一旦不是基本的，这四样全要重写——而 144 问里所有涉及「演化」的问题都会跟着变。

**同层共振**　P06（诠释等价性也依赖「时间是不是参数」，因为 GRW 是随机过程，需要真时间）、P08（两个箭头都以时间为基础）。

**答它要什么**　把「模流」写成一个可观测量的代数条件，并算出它对已知实验的偏离（量级估计即可）。这是纯数学物理的活，不需要新实验。

**顺带解锁**　P28（面积律有一个「时间版本」：模哈密顿量）、P35（霍金辐射的温度需要一个「时间」来定义）、P38（复杂度=体积必须指定「对谁的时间」）、P54（RG 的「尺度」与「时间」是不是同一个流）。

**接 144**　「时间在量子引力里是什么」「Page–Wootters」——这两问会被 P03 直接改写问法。

### P04｜为什么基本方程是二阶的？三阶为什么不存在？

**问法**　Ostrogradsky 定理：含高于二阶导数的非退化拉氏量，必然带一个负能「鬼」。这是不是「二阶」的硬理由？如果是，二阶就不是审美，而是**稳定性**的必然。再往下：为什么 Dirac 是一阶、Schrödinger 是一阶、而场方程是二阶——这三种「阶」能不能统一成「某个一阶系统的平方」？如果能，那「阶」就不是基本概念。

**为什么排第四**　这是「物理方程长什么样」最底层的约束，而 144 问只对引力问过（且归因于 Lovelock）。把它推广到全部物理，等于给「为什么世界可预测」找一个代数理由。

**同层共振**　P05（作用量的相位结构决定方程的阶）、P50（EFT 只留低阶算子，正是二阶性的低能表现）。

**答它要什么**　把 Ostrogradsky 定理从「自由论」推广到「有相互作用 + 有规范约束」的情形；并检查是否有物理上可接受的「鬼」被隐藏（例如 F(R) 引力等价于标量-张量）。

**顺带解锁**　P05（相位 = S/ħ 与「二阶」是否同源）、P27（Schwinger 击穿是一个二阶场论的指数效应）、P50（EFT 的算子展开就是以二阶为起点）、P53（变分原理的阶数）。

**接 144**　「引力为什么二阶」——把它从引力专属升级为全物理约束，答案从「Lovelock」变成「无鬼」。

### P05｜为什么世界是复的，而作用量是实的？

**问法**　`e^{iS/ħ}` 里的 `i` 从哪来？为什么相位恰好是 `S/ħ`，而不是 `S/ħ²`、也不是某个非线性函数 `f(S)`？如果把 `ħ` 读作「作用量的量子」，那么「作用量可以被量子化」就意味着相空间是辛流形——几何量子化正是这么做的。问：**「一个物理系统」能不能被定义为「一个辛流形 + 一个极化 + 一个预量子化线丛」？** 这个定义会不会自动排除耗散系统、或自动包含引力？

**为什么排第五**　它比 Born 规则更底层。144 问追问了「概率为什么是模方」，但没有问「为什么相位是作用量除以 ħ」——而后者才是量子力学为什么长成这个样子的第一因。

**同层共振**　P04（阶数由相空间结构决定）、P06（诠释等价性建立在复振幅之上，如果振幅结构变了，等价性命题也要变）。

**答它要什么**　把「辛 + 极化 + 预量子化」这套定义与标准公理体系对照，看它多出/少了什么；再检查耗散（非辛）系统在这个定义下是否被排除——如果被排除，那「耗散是基本还是有效」就成了可判定问题。

**顺带解锁**　P26（射影结构：全局相位为什么不可观测）、P27（振幅可加性 → 干涉 → 真空击穿是同一套复结构的效应）、P39（量子度量学的极限来自复结构的 Fisher 信息）、P50（半经典展开就是 ħ 的幂级数）。

**接 144**　「为什么是复希尔伯特空间」「Born 规则能不能推出来」——P05 给出更上游的答案或证伪。

### P06｜三个「不可区分」的量子诠释，能否被一条定理证明永久等价？

**问法**　把「等价」写成精确命题：在什么类别的可观测量上、什么误差内、多少个自由度下，多世界 / GRW / Bohm 给出相同的统计？如果能证明（例如在非相对论、有限自由度、有限精度下），那诠释之争就降级为**本体论偏好**，物理学不必再谈；如果不能，必有一个实验窗口（GRW 的随机加热 ~10⁻¹⁵ K/s、Bohm 的平衡弛豫时间）。

**为什么排第六**　144 问「波函数是实在的还是认识论的」，但那是本体论问题，永远吵不完。换成「等价性能不能被证明」，就变成一个可判定的数学问题，而且答案两边都有用：证明了就结案，证不了就给出实验方向。

**同层共振**　P41（弱测量是否能区分诠释——如果弱值在三个诠释里给出不同统计，等价性立刻破）、P03（GRW 需要真时间，时间若不基本，GRW 就被排除）。

**答它要什么**　一个「诠释」的形式化定义（否则无法证明等价）；以及一个误差度量（总变差？KL？）。这是逻辑学 + 泛函分析的活。

**顺带解锁**　P27（如果诠释等价，真空击穿的「测量」解释就不依赖诠释）、P41（弱值成为判据）、P55（拓扑量子化的精确性是否诠释无关）。

**接 144**　「波函数是实在的吗」「测量为什么会坍缩」「观察者必须有意识吗」——三问会被重写为「等价性定理的边界在哪里」。

### P07｜面积律是引力的性质，还是信息的一般性质？

**问法**　最大熵正比于边界面积（`S ≤ A/4G`），这条在**没有引力**的系统里成立吗？设想一个没有引力的量子场论：它的最大熵是体积律还是面积律？换句话说：**面积律 ⟺ 引力存在？** 若是等价，全息原理就不是「引力的性质」，而是「任何自洽量子理论的性质」，那它的地位要从「猜想」升到「定理」。

**为什么排第七**　它决定全息原理的身份。现在全息是「有证据的猜想」，如果面积律能被证明等价于「存在自旋 2 无质量粒子」，全息就变成必然。

**答它要什么**　在无引力系统里算最大熵——技术上可以用「把系统与其互补部分的最大纠缠」来定义，但要证明上界是面积型。目前只有 AdS/CFT 与若干玩具模型。

**顺带解锁**　P28（面积律的微观起源）、P34（如果面积律普适，引力波速=c 就是「无质量自旋 2」的推论）、P35（无毛是面积律的几何表现）、P38（复杂度=体积需要面积律做前提）。

**接 144**　「黑洞熵为什么正比于面积」「全息原理」「Bekenstein 界」——三问合并成「面积律的适用范围」。

### P08｜热力学箭头与宇宙学箭头，是同一个箭头吗？

### P09｜19 个参数能不能压缩成少数边界条件加跑动？

**问法**　如果所有参数来自一个统一能标的少数输入，低能 19 个数的联合分布就不该是「独立均匀」——它们应落在一个低维流形上。问：**用什么统计量能测出「参数空间的有效维数」？** PCA、Fisher 信息矩阵、还是 Kolmogorov 复杂度？现有数据支持几维？

**顺带解锁**　P10（有效维数若远小于 19，代的重复就是一个约束）、P16（两个能标的比值是否由跑动自动给出）、P17（Higgs 数量是否也是被压缩出来的）、P19（荷与质量的不同压缩方式）。

### P10｜为什么「代」重复，而「力」不重复？

**问法**　三代费米子量子数完全相同、只有质量不同；而规范群只有一套。为什么**物质**复制三份，**相互作用**不复制？如果存在「两套 SU(2)」，世界会怎样（宇称恢复？两个弱角？）？这个不对称有结构原因，还是只是「我们这一支」？

### P11｜为什么自然界一个无质量标量都没有？

**问法**　理论上无质量标量最「自然」（Goldstone 玻色子、moduli、quintessence）。但观测上，除 Higgs（有质量）之外一个都没有——第五力的上限把它压得极严。问：**是「没有」，还是「耦合被屏蔽」**（chameleon、symmetron）？判据：Casimir 尺度（μm）的偏离、中子星冷却、等效原理的 10⁻¹⁵。

**为什么排这**　它是「为什么没有第五力」的精确版，而且与宇宙学常数（真空能）、暗能量（quintessence）直接挂钩。144 问过「第五力怎么屏蔽」，没问「为什么根本没有」。

**同层共振**　P18（α 微调与「没有新标量」是同一类精细调节）、P47（自然性判据在这里最吃紧）。

**顺带解锁**　P02（给出「哪条路可被排除」）、P39（精度极限）、P06（如果引力能制备纠缠，诠释的边界要重画）。

**接 144**　「普朗克尺度是什么」——从「不可及」转到「桌面能测什么」。

### P58｜0νββ 能定出中微子是 Majorana 吗？

**问法**　无中微子双 β 衰变的半衰期 ∝ 1/m_ββ²。问：**「没看到」是在排除 Majorana，还是在逼近「核矩阵元」的不确定性？** 判据：多个核（⁷⁶Ge、¹³⁶Xe、¹³⁰Te）的一致性。

**为什么排这**　它是「中微子是不是自己的反粒子」的唯一判决实验，而这个答案决定 leptogenesis 能不能成立。

**同层共振**　P15（重子生成）、P43（两个 Δm² 的比值）。

**答它要什么**　把核矩阵元（NME）的误差从 2–3 倍压到 30% 以内——这需要多个核的一致测量，而不是单个核的极限。

**顺带解锁**　P15（leptogenesis 是否可行）、P43（质量序：正序/倒序给不同的 m_ββ）。

**接 144**　「中微子质量是 Dirac 还是 Majorana」——给出判决路径。

### P59｜质子会衰变吗？

**问法**　GUT 预言 p → e⁺π⁰，寿命 10³⁴–10³⁶ 年。Super-K 已排除 10³⁴。问：**「没看到」排除了哪些群？** 剩下的 SO(10)/E₆ 是不是只能靠「调整」活下来？

**为什么排这**　它是「大统一」唯一不依赖新粒子的判决实验。如果质子寿命被推到 10³⁵ 以上，大统一就从「预言」退化为「拟合」。

**同层共振**　P15（重子生成能标）、P16（统一能标）。

**答它要什么**　把「质子寿命 → 群与能标」的映射算准（包括 Higgs 三联态的质量不确定性），再与 Super-K/Hyper-K 的极限对比。

**顺带解锁**　P15（GUT 重子生成是否还与数据相容）、P16（统一能标的上限）。

**接 144**　「质子为什么寿命这么长、哪些统一方案还活着」——给出判决线。

### P60｜中子有电偶极矩吗？

**问法**　SM 预言 d_n ~ 10⁻³² e·cm，实验已压到 10⁻²⁶。问：**这个 6 个数量级的差距，是「新 CP 破坏」的窗口，还是「SM 算错了」？** 判据：格点 QCD 的 θ 项、强 CP 问题。

**为什么排这**　它是「新 CP 破坏」最干净的探针——因为中子 EDM 对强 CP 与弱 CP 都敏感，且没有「树图污染」。

**同层共振**　P15（重子生成需要 CP 破坏）、P19（θ 项为何小）。

**答它要什么**　把 QCD θ 项的贡献（强 CP）与弱 CP 的贡献分开；这需要格点 QCD 把 θ 依赖算准。

**顺带解锁**　P15（CP 破坏的来源）、P19（θ 项为何被压到 10⁻¹⁰）。

**接 144**　「θ_QCD 为什么小于 10⁻¹⁰」——从「为什么小」转到「怎么测」。

### P61｜常数真的不变吗？

**问法**　α 的宇宙学漂移（Webb 的 10⁻⁶ 证据，后被质疑）。问：**「常数漂移」的判据是什么？** 类星体吸收谱、原子钟比对、Oklo 反应堆。

**为什么排这**　如果常数变，「定律」这个概念本身就要改——这是 P01 的实证版本。

**同层共振**　P01（必然性预算）、P08（箭头）。

**答它要什么**　把三类观测（类星体、原子钟、Oklo）的系统误差对齐，给出一个共同的 Δα/α 上限。

**顺带解锁**　P01（若常数变，「必然性」要重定义）、P08（漂移是否与箭头同源）。

**接 144**　「定律为什么是定律」「α 随能量跑动」——补上「随时间漂移」。

### P62｜等效原理能撑到 10⁻¹⁸ 吗？

**为什么排这**　它是「引力是不是度规」的最后一道实验防线，而且精度还有空间。

**同层共振**　P11（无质量标量）、P34（引力波速=c）。

**答它要什么**　把「第五力」与「非度规引力」的偏离信号分开（前者与成分有关，后者与质量无关）。

**顺带解锁**　P11（第五力的耦合强度）、P34（度规理论的边界）。

**接 144**　「等效原理为什么成立」——补上「撑到多高」。

### P63｜真空是稳定的吗？

**问法**　125 GeV 的 Higgs 让真空处于「亚稳」（边缘）。问：**「亚稳」的寿命远超宇宙年龄，这个差距是巧合还是人择？** 判据：顶夸克质量的精度、早期宇宙为何没先衰变。

**为什么排这**　它是 P18 的极端案例：如果真空亚稳是「边缘」，那「为什么没已经衰变」就是一个真实的精细调节问题。

**同层共振**　P17（Higgs 数量）、P18（微调）。

**答它要什么**　把顶夸克质量与 Higgs 质量的误差压到能判定「稳定/亚稳/不稳定」的精度；再检查早期宇宙（暴胀）是否会触发衰变。

**顺带解锁**　P17（额外 Higgs 会改势的形状）、P18（微调的另一个「边缘」）。

**接 144**　「真空稳定性」「v=246」——补上「宇宙为什么还活着」。

### P64｜时间晶体是真的「时间对称破缺」吗？

**同层共振**　P29（热化的边界）、P30（可积/周期驱动）。

**顺带解锁**　P29（热化的边界：时间晶体是「不热化」的极端）、P30（周期驱动系统的可积性）。

## 八、顺藤摸瓜：八条主链

> 读法：`→` 表示「解决了左边，右边基本就跟着开」。括号里是「为什么能顺带」。

### 链 A｜地基链（最长的一条）
```
P01 必然性预算
 → P49 唯一性定理的地位（预算要靠定理覆盖率来算）
 → P48 证明论强度（定理的前提要对，得先知道形式系统多强）
 → P51 渐近级数（形式系统里「真」与「可证」的差别，在级数上先出现）
 → P50 EFT 为何成功（级数的合法性决定 EFT 的合法性）
 → P04 为什么二阶（EFT 的起点就是二阶算子）
 → P05 为什么复/实（二阶 + 辛结构 = 量子化的起点）
```
**一句话**：这条链是「先算账、再谈定理、再谈语言、最后谈形式」。走通它，T0 的前五个问题会一起松动。

### 链 B｜量子引力链（最硬的一条）
```
P02 放弃哪条
 → P35 无毛（放弃等效原理 ⇒ 视界有毛）
 → P36 霍金辐射的热性（无毛 ⇒ 谱只依赖 M）
 → P07 面积律（热性 ⇒ 熵=面积）
 → P28 纠缠面积律（面积律的量子信息版）
 → P38 复杂度=体积（面积律 + 全息 ⇒ 体积对偶）
 → P03 时间是否基本（「体积」需要时间定义）
```
**一句话**：这条链的入口是「选牺牲品」，出口是「时间不是基本的」。中间任何一环断了，全息就只是猜想。

### 链 C｜宇宙链

```
**一句话**：从「为什么时间有方向」一路到「宇宙怎么结束」，七个问题共用一组 CMB 数据。

### 链 D｜参数链
```
P09 有效维数
 → P10 代重复/力不重复（最大的简并）

```
**一句话**：参数空间的形状 → 简并结构 → 群的紧致性 → 必然性比例。这条链闭合，P01 才有数。

### 链 E｜涌现链

P20 非费米液体

```
**一句话**：从「准粒子失效」到「精确测量」，这条链证明「低能不记得微观」可以有定量形式。

### 链 F｜核与致密链
```
P25 核结合能峰
 → P26 中子星最大质量
 → P44 QCD 相图临界点
```
**一句话**：三个问题共用「强作用在高密端的行为」这一个未知。

### 链 G｜测量链
```
P06 诠释等价性

**一句话**：如果诠释不可区分，测量就只剩「精度」这一个真问题；而精度极限又直接决定桌面量子引力能不能做。

P45 5σ 够吗

```
**一句话**：统计阈值 → 张力判定 → 自然性 → 必然性。这条链是「我们凭什么相信一个结论」的四级台阶。

## 十二、怎么用这份清单

1. **先读第二节（五层共因）**。它告诉你这 64 问其实只有 5 个缺口，不是 64 个。
2. **再读第八节的链 A 与链 B**。这两条是主脊，其余六条是支链。
3. **要动手时，从第九节的前四个开始**（P01、P02、P03、P05）。这四个不需要新实验，只需要把已有的定理重新组织一遍——是「一个人一张纸」能推进的。
4. **要实验时，从 T4 开始**（P57–P64）。它们每一个都有明确的「结案阈值」，而不是「再提高一个量级」。
5. **不要按编号顺序读**。编号是重要度，不是依赖顺序；依赖顺序看第八节。
