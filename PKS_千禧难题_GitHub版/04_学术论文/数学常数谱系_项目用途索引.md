### √2 = 1.41421356（x²−2=0）

### ∛2 = 1.25992105（x³−2=0，也是 x¹²−16=0）

> **本表里最惊人的一处重合**：立方倍积的 ∛2，与十二平均律大三度 `2^(4/12)`，是**同一个数**。

```
∛2 = 2^(1/3) = 2^(4/12) = 1.259921
```

- 左边是立方倍积 —— 尺规三大不可能作图之一（Wantzel 1837）
- 右边是十二平均律的大三度 —— 4 个半音
- 古代"不许你作图"的数，恰好是"每台钢琴都在用"的数
- 与纯律 5/4 = 1.25 差 **13.686 音分**，这个差就是"有理闭合"与"无理均分"的代价

项目里两侧都出现了：

- `log(∛2)/log(1/φ)` —— ANU 蛋形场约束里"从 1 缩到 ∛2 需要跨多少格 φ 刻度"
- `2^(4/12)` —— keely 页的反例，残差非零

### 2^(1/12) = 1.05946309（x¹²−2=0）

一个半音的频率比。**它是"处处用、却处处破坏整数闭合"的那个数**。

- `2^(s/12)`，s = 0,2,4,5,7,9,11 ⇒ C D E F G A B（钢琴白键）
- 除 C 外全是无理数 ⇒ 不存在精确整数复位周期，闭合残差**必然**非零
- 脚本原话：若把某管改成平均律频率（如 261.63），该管就引入无理音程

### φ = 1.61803399（x²−x−1=0）

**生长与分割**的常数。要"连续长大 / 自相似 / 最优填充"的地方是它；"恰好卡住"的地方一般不是它。

### 1/φ = 0.61803399

它有一个很特殊的用法：**当对数的底** —— 不是当比值，是当"尺子的刻度数"。

- `log(16)/log(1/φ)` ⇒ 螺旋漏斗的 t 上限（缩到 1/16 要跨几格黄金刻度）
- `log(32)/log(1/φ)` ⇒ 32 倍伸缩的螺旋泵

把 φ 当底，等于**把"黄金分割"变成一把可数格子的尺**。

### χ = 1+√2 = 2.41421356（x²−2x−1=0）

白银比。与 φ 是**同一族方程 x²−Tx+1=0 在 T=6 与 T=3 的两个解** —— 不是两个世界，是同一条轴上的两个采样点。

- `|y_max|/|y_min| = 1+√2` —— 临界蛋形（切割面刚好相切）的极值比
- `χ² = 3+2√2 = 5.828` —— 拉糖机 4 棒特征值，与 3 棒的 φ² 效率**完全相同**（都是 1.7627）

> χ 的领地是**边界条件**（临界 / 极值 / 归一化）；φ 的领地是**过程动力学**（生长 / 分割 / 收敛）。

### √(2/3) = 0.81649658（3x²−2=0）

只在 Keely 三环里出现一次，但它是**"三环等面积"的精确解**：

```
r₁ = r₃/√3,  r₂ = r₃·√(2/3)
实际尺寸 D₃ = 0.866 mm ⇒ r = 0.2500 / 0.3536 / 0.4330 mm
壁厚 t_Au = 0.1036 mm, t_Pt = 0.0794 mm
```

要求 `π(r₂²−r₁²) = πr₁²` ⇒ `r₂² = 2r₁²`，配合 `r₁ = r₃/√3` 即得。

## 3. 超越数

### π = 3.14159265

出现最多、也最"不显眼"的数：一半时间在当**角度换算**，一半时间在当**周期**，很少当"圆周长/直径"用。

| 用在哪 | 公式 | 说明 |
|------|------|------|
| 羊角螺线 | `x = aπ·sin t/t` | π 是把"圈"换算成长度的比例 |
| 所有 DXF 螺旋 | `2π = 一圈` | `t_min = 2π/(n+1)`、`t_max = 2π + 2n·2π` |
| 真空磁导率 | `μ₀ = 4π×10⁻⁷` | 4π 来自立体角归一化 |
| 面积 | `A = πr²`、`π(r₂²−r₁²)` | 三环、线圈、声压面积 |

### 1/(2π) = 0.15915494

**每单位角对应多少"个周期"**。两个完全不相干的地方各出现一次：

- `(1/2π)·ln(t/2π)` —— 黎曼 ζ 零点的平均密度（Riemann–von Mangoldt）。整个"零点为什么挤在临界线"的论证，分母就是 2π
- `b = ln2/(2π)` —— 螺旋扭转率，每 2π 弧度把某个量翻一倍

### e = 2.71828183

角色几乎只有一个：**把"每次按比例变"写成连续函数**。所有 `exp` 都是它。

- `z = t^e · z_v` —— "阴阳-t 的 e 次方"版锥高拉伸，比 t² 陡、比 t³ 缓
- `(e^x − 1)/(e − 1)` —— 把任意实数压到 [0,1]，分母 e−1 保证 x=1 时取到 1（**用 e 当标尺端点**）
- `exp(b·θ)` —— 所有指数螺旋 / 对数螺线

### ln2 = 0.69314718

**最"低调但最要命"的数**。它是"翻倍"的对数度量：倍数 = 2 ⇒ 对数增量 = ln2。

| 用在哪 | 公式 | 说明 |
|------|------|------|
| 统一螺旋 | `r = 2^(-θ/π) = e^(-(ln2/π)·θ)` | 底其实是 2，写成 e 时 ln2 冒出来；每半圈半径减半 |
| 螺旋扭转 | `b = ln2/(2π)` | 每圈翻一倍（想每圈 ×φ 就写 lnφ，同一位置换常数就是换设计） |
| 滤波器 | `ln2/(f_rep/f_c)` | −3 dB 半功率的时间常数 |
| **被否掉** | `2ln2 = 1.3863` | 曾试作三环半径分界，**打不出 1:2:3 等面积**，最大偏差 >5% ⇒ 废弃，改用 √n |

> 最后一条是全表唯一"这个常数在这里用错了"的记录。**保留它，比删掉它有用**。

### π/ln2 = 4.5319 rad = 259.7°

两个超越数相除，得到一个**有物理含义的角度**：

```
θ = π/ln2  ⇒  r = 2^(-1/ln2) = e^(-1)
```

这是恒等式不是近似。**π、ln2、e 三个常数在同一根曲线的一个点上会合。**

### 1/e = 0.36787944

"衰减到 36.8%"的那条线。工程上叫时间常数；项目里它是螺旋走过 259.7° 时的半径。

### √(2π) = 2.50662827

高斯积分的归一化常数，决定菲涅尔积分在无穷远处收敛到什么值：

```
I₀(∞) = √(2π)·e^(-iπ/4)
```

√(2π) 是模长，−π/4 是相位。两者任一改变，零点就不落在 Re(s)=1/2。

## 4. 普适常数与"项目常数"

### δ = 4.66920161（Feigenbaum）

倍周期分岔的**普适标度**：所有一维单峰映射走向混沌时，分岔间距都按 δ 收缩，与具体方程无关。

- `amp_decay = 1/δ = 0.214` —— DNA 音乐的"阴"声部衰减系数
- 与 Fibonacci `1/φ = 0.618` 并列成两种衰减方案：一个"生长型自相似"，一个"混沌型自相似"
- `δ = 4.669…` —— NS 方程映射里，Logistic 分岔图被视为涡旋在湍流边界的自相似结构

出处：`01_基础理论/26_音乐谐波/DNA音乐/dna_yinyang_v2.py`、`01_基础理论/PKS几何_NS方程映射.md`

### α = 1/137.036

项目里最"大胆"的一处用法：**把 α 当成蛋形尖端与钝端的曲率比**，而不是耦合强度。

- `α = R₀/R_c` —— R₀ 尖端曲率半径、R_c 钝端基准曲率；k_E→1 时曲率差消失、α 漂移 ⇒ Anu 解体
- 同一比值的另一种几何读法：双曲锥（磁性）尖端曲率 ÷ 直锥（电性）基准曲率

出处：`01_基础理论/14_anu结构与精细结构常数的关系/Anu_Alpha_Fine_Structure.md`

### 137.5°（黄金角）

> **不是 137 那个精细结构常数**。数值接近纯属巧合，项目里两处都出现，别混。

- `twist = 360/φ² ≈ 137.5°` —— 蛋形动画每帧旋转步长
- 分流道角度 137.5° —— 流体分配布局（与叶序同源）

### (1+√2)⁴ = 33.9705627

一个**从纯几何里涌现、再被逆推认出来**的数：

- 大四面体棱长 50、`R = 50√6/4`；中心倒小四面体 `r = 0.90135`
- `R/r = 33.970563 = (3+2√2)² = χ⁴`
- 四种几何读法：√2 = 正方形对角线比 → 1+√2 = 45° 旋转的代数表达 → 四次方 = 4 次白银比旋转

### j₀,₁ = 2.40482556 / j′₀,₁ = 3.83170597

**这是本项目里"口径用错一步全错"最贵的一课。**

- **膜**（夹紧边，如 Margaret Watts Hughes 的 eidophone）用 `j` 零点，基模 `j₀,₁ = 2.4048`

## 5. 把这 29 个数摆在一起，看出五件事

### ① 一条螺旋串起五个常数

```
r = 2^(-θ/π) = e^(-(ln2/π)·θ)
```

| 角度 | 半径 | 坐上来的常数 |
|------|------|------|
| θ = π/2 | 0.7071 | **1/√2** |
| θ = π | 0.5 | **1/2** |
| θ = 2π | 0.25 | **1/4** |
| θ = π/ln2 | 0.3679 | **1/e**（恒等式，非近似） |

所以"π 转角、2 翻倍、e 衰减、ln2 是翻倍的对数、√2 是四分之一圈"——**不是五个知识点，是一根曲线的五个刻度**。

### ② ∛2 有两个身份，其中一个古人证过"作不出来"

```
∛2 = 2^(1/3) = 2^(4/12) = 1.259921
```

左边立方倍积（尺规不可能，Wantzel 1837），右边十二平均律大三度（4 个半音）。
同一个数：一边"不许你作图"，一边"每台钢琴都在用"。与纯律 5/4 差 13.686 音分。

### ③ 有理 / 无理 在这里不是审美，是「能不能严丝合缝」

- Keely 14 项比值素因子全在 {2,3,5} ⇒ 精确闭合，残差 **0**
- 换成 `2^(s/12)` ⇒ 读数立刻"近似闭合"，**残差不是算得不够准，是它在数学上不可能为零**
- 反例：`2ln2 = 1.3863` 试作三环分界，打不出 1:2:3，被明确废弃

这是整个项目里"数论差异变成工程指标"最干净的一处。

### ④ 大部分"漂亮比例"来自等面积 / 等体积，不是来自审美

- Keely 三环半径 `√1 : √2 : √3`（0.2500 / 0.3536 / 0.4330 mm），唯一理由是让三环截面积相等
- 蛋形曲线用 `F(n+1)/F(n+2)` 而不是直接写 φ，因为要画的是有限层，必须落在有理数上
- Schauberger 蛋形在相切临界条件下给出 `1+√2`，那是方程的解，不是他挑的

> **判据**：一个常数若是从约束解出来的，它能被验算；若是先有数再找理由，换个参数就散架。

### ⑤ 边界：不是所有地方都该出现 φ

Keely 装置数字统计下来是 **12 / 7 / 9 / 15 / 18 / 32 / 120 / 360 / 33⅓ / 105 / 140** ——
**13、21、34、55、89、144 一个都没出现**。Fibonacci 只出现在 Dale Pond 的解释层，且原文自标"尚未实验验证"。

同理：

- π 在这些脚本里多数时候只是**角度换算**，不是"圆的性质"
- e 多数时候只是**指数函数的记号**

这一条的用处是反向的：**想判断某处"常数"是不是硬凑的，先看它在约束方程里解不解得出来。**
