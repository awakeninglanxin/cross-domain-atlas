02源头：EEQT 是怎么走到 IFS 上的

三段链条。每一段都有原文可查，不是我们的引申。

① EEQT：单系统的历史是一条"算法"，不是一个微分方程

EEQT = Event-Enhanced Quantum Theory（事件增强量子理论），Blanchard 与 Jadczyk 在 1990 年代的一系列论文里提出的框架。 它想干的事很具体：把 von Neumann 的两种过程——连续酉演化（U 过程）和测量导致的投影塌缩（R 过程）—— 合成一个对象：一个分段确定性过程（piecewise deterministic process, PDP）。

"in EEQT a history of an individual quantum system, coupled to a monitoring device, as in every real world experiment, is described by a process or an algorithm rather than by a differential equation." Jadczyk & Öberg, quant-ph/0204056, §1

机制很朴素：量子系统耦合一串两态探测器。探测器翻转 = 一次"事件"；每次事件，量子态就断掉连续演化、瞬间跳到新状态。

"with each flip of the detector, with each 'event', the quantum system state vector breaks its continuous evolution, and instantaneously jumps to a different state — it 'rejuvenates' and it starts another cycle of a peaceful, continuous evolution — till the next catastrophe." 同上

原文层 同一段里作者自己点了题： "The EEQT algorithm generating quantum jumps is similar in its nature to a nonlinear iterated function system (IFS) and, as such, it generically produces a chaotic dynamics for the coupled system." —— 翻译过来：EEQT 的跳变算法天生就是一个非线性 IFS，因而内在地产生混沌动力学。 这不是我们硬套分形，是原文就写着的。

② 跳变算子 = 洛伦兹推速 = 球面的 Möbius 变换

为什么跳变会长成几何映射？Jadczyk 2006 年那篇（quant-ph/0604023）摘要第一句就给了答案：

"Positive matrices in SL(2,C) have a double physical interpretation; they can be either considered as 'fuzzy projections' of a spin 1/2 quantum system, or as Lorentz boosts." quant-ph/0604023, abstract

原文层 同一个正矩阵，两种读法：当成自旋 1/2 的"模糊投影"（模糊度 = 探测器分辨率）， 或者当成一个洛伦兹推速（推速 = 模糊度）。Lounesto 在会上猜这些映射保角，Jadczyk 用 Clifford 代数证了： 它们是 S²（天上的球，≅ 黎曼球 P¹(C)）的 Möbius 变换。

原文式 (1.1)：q ∈ B³（单位球内部），p ∈ S²
φq(p) = [ (1 − q²)·p + 2(1 + q·p)·q ] / [ 1 + q² + 2(q·p) ]

本页把 q 取成 q = ε·n：n 是某个顶点的单位方向，ε = ‖q‖ ∈ (0,1)。 于是页面上那个 ε 不是我们发明的旋钮——它就是原文里探测器的模糊度，也是洛伦兹推速。

③ 对称阵列 ⇒ 球面上的自相似图纹

原文层 2002 年那篇论文的标题直接就叫 《Quantum Jumps, EEQT and the Five Platonic Fractals》——五个柏拉图立体正是原文的样板。 立方体那个例子：8 个顶点、‖qi‖ = 0.74、10⁸ 个点，作者的原话是

"The pattern shows distinct self-similarity — circles with circles." quant-ph/0604023, Fig.1 说明

03这套公式和"混沌吸引子公式"到底是什么关系

这是本页最该说清楚的一节。因为两者画出来都是"一坨复杂纹路"，很容易被当成同一件事。它们不是。

一句话

结论先行 Lorenz / Rössler / Aizawa 那一类是确定性连续流，混沌来自"拉伸 + 折叠"，不变集本身就是分形（2 < D < 3）； EEQT 量子分形是离散随机映射，每一步都共形、零拉伸，不变集根本不分形（严格 D = 2，只有测度是多重分形的）。 两者共用"维数"这个词，但一个量的是集合，一个量的是测度。

为什么"集合"的维数天差地别 —— 一个严格论证

性质 ① 说 φq 把 S² 打到 S²；性质 ② 说它把 ±n 都固定住，所以它是 S² 上的双射（有逆，逆也是同样的形式）。 既然每个 φi 都是双射，那么满足 A = ∪i φi(A) 的闭集 A 就不可能是"一小块"：φi(A) 与 A 一样大，N 个这样的拷贝一叠，只能是整个 S²。

⇒ 对任意 0 < ε < 1： 吸引子（集合）= S²　，严格 DH ≡ 2

那为什么画出来明显不是一片均匀的灰？因为分形性在测度里。 Jadczyk 自己在 Fig.1 的说明里就把"从没被访问的区域"和"常被访问的区域"分开讲： the dark areas are those that are (almost) never visited。 "几乎从不"访问 —— 概率处处为正，但小到大可以忽略。你在图上看到的每一根丝、每一个空洞，都是密度的起伏，不是"那里没有点"。

这一条同时否掉了一个很常见的误读 图上那些看起来很"分形"的空洞，不是集合的空洞。把 ε 调小、点加多，空洞会被填平； 真正不会变的是：这些丝、这些圆，都只是测度的等密度线。

那它们的"亲缘关系"到底在哪

不是没有。两者都是"压缩率谱的泛函"——这句话是本节真正的答案：

  • ODE 这边：维数由 Lyapunov 指数谱 {λi} 决定。λi 就是"每个方向上一单位时间伸/缩多少"。3 维耗散流里 λ1>0、λ2≈0、λ3<0， 于是 DKY = 2 + (λ1+λ2)/∣λ3∣，必然落在 2 与 3 之间、且总比 2 多一点点。
  • EEQT 这边：没有拉伸，所以 λ 谱退化成一个数——ρ=(1−ε)/(1+ε)。 想估维数只能套 Moran 方程 N·ρs=1，解出 s = lnN / ln(1/ρ)。 注意 ρ→0 时 s→0；ρ→1 时 ln(1/ρ)→0 使 s→∞，只能靠"N 个拷贝叠不过球面"这个几何上限把它截在 2。 所以它永远到不了 2 以上。
同一件事的两种写法：
ODE：D = f(λ1, λ2, λ3)　—— 谱
IFS：D = f(ρ1, …, ρN; p1, …, pN)　—— 每步压缩比与概率
两者都是"把一张压缩率表积分成一个数"。

顺带一提：正因为没有拉伸，EEQT 这边的"混沌"其实名不副实——它没有对初始条件的敏感放大，只有对随机选择序列的依赖。 原文说 "generically produces a chaotic dynamics" 指的是耦合系统（量子态 + 探测器）的轨道不收敛， 不是指有一个正 Lyapunov 指数。这个区别在图上就看得出来：Aizawa 是丝带被拉长又折回，量子分形是拷贝被压小再嵌套。

04ε 与维数：一次对"波谷"的实测检验

这里要交代清楚一件事："ε 从小到大变化，DH 会出现波谷"这个前提，实测不成立。 下面是全部证据，包括为什么不可能成立。

测法

  • 5 个柏拉图立体，每个 N 个探测器；ε 从 0.05 扫到 0.97，步长 0.02，共 47 点。
  • 每个 ε 采 41 万点（1024 条独立链 × 400 步，已扣 200 步预热）。
  • 三种投影各自用固定窗口做盒计数（Lambert/正射用 [−1.06,1.06]²，球极用 [−3,3]²）， 尺度取 16、32、…、1024 格；只保留"20 ≤ 盒数 ≤ N/30"的尺度做 log–log 回归。
  • 固定窗口是必须的：若每个 ε 各自用百分位自适应窗口，窗口会随 ε 漂移，制造出假的波谷（第一版就踩了这个坑）。
  • ε ≥ 0.93 时占用盒数太少、回归窗口塌陷，估计子本身失效——这一段只作参考，不参与单调性判定。

曲线

所以前提不成立 DH(ε) 不是"振荡出波谷"，而是"从 2 平滑塌到 0"的一条单调曲线，只有一个拐点（膝）。 在 ε 上找"最丰富图纹"这件事，靠 DH 的极值是找不到的——得换判据。

为什么不可能有波谷 —— 三条

  1. 概率处处为正。 pi(r) = (1+ε²+2ε ni·r)/(N(1+ε²))，对 ε<1 有下界 (1−ε)²/(N(1+ε²)) > 0。 没有哪个探测器是"绝对不可能被选中"的，所以球面上每个方向都可能被访问。
  2. 映射是双射。 见 §03：∪φi(A) = A 的唯一闭解就是 S²。集合的维数恒等于 2，压根没有随 ε 变的东西。
  3. 所以盒计数量到的是"有效维数"。 Deff(ε, δ) 是分辨率 δ 下的一个统计量： 它测的是"密度高于阈值的那部分占多大"，随 ρ 单调收缩。单调函数的平滑塌缩，本来就不会生出极值。

要小心 这不是说"量子分形不分形"。它分形，只不过分形性住在测度里。 要把 DH 真的压到 2 以下，必须让概率在某个开集上恰好为 0（把某些探测器彻底关掉、或只允许半空间跳变）， 那时支撑集才会真的缩成一个 Cantor 集，DH 才会是"真维数"。本页用的是处处为正的平滑模式，所以不会。

多重分形谱：分形性确实在测度里

如果分形性在测度里，那 D0、D1、D2 应该分得开（D0 > D1 > D2）。 实测正是如此——这是"测度是多重分形"的直接证据，也是本节最硬的一张表：

D0 与 D2 差 0.19～0.73，且几乎每行都是 D0 > D1 > D2。 均匀测度这三者会相等；差得越开，说明测度的局部标度指数分布越宽 —— 这就是"分形在测度里"的量化版本。

替代判据：用膝点定 ε，再用 Deff=1.50 定图

既然没有波谷，就找真正有物理含义的特征点。曲线从平台（≈1.94）往下掉的那个膝，对应 "自相似拷贝刚好开始分开"——从这之后，球面上才长出可分辨的层次。膝点位置随 N 增大而右移，因为顶点越密， 拷贝必须压得越小才能互不重叠。

拟合出来的规律 把膝点换算成压缩比 ρknee = (1−ε)/(1+ε)，再除以该几何的最小球心角 θmin， 比值几乎是个常数：

ρknee ≈ θmin / 6　　⇒　　ε* = (1 − ρknee) / (1 + ρknee) = (6 − θmin) / (6 + θmin)　θmin 用弧度

偏差 −0.075 ~ +0.045。立方体（+0.012）与十二面体（+0.002）几乎严丝合缝；四面体偏得最多，因为它只有 4 个顶点， 最近邻角就是最大角（109°），边缘效应明显。所以这条式子应当当成量级与趋势的规律，不是精确定律。

于是 ε 这样定 在实测曲线上取 Deff = 1.50 的那一点（线性插值）。为什么是 1.50：往下（D→2）纹理会糊成一片， 往上（D→1.0）只剩稀疏的点阵；1.50 附近是"层次最多、又还连成片"的中间带。 27 张图各自的 ε 见下表，每个值都在曲线上可复算。
