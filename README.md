# 跨界总入口 · Cross-Domain Atlas

一组**跨主题研究性网页**的合集。入口是 [`index.html`](index.html)（= `AAA_跨界总入口_总网页.html`），
从这一页可以走进十几个子项目，每个子项目内部又有自己的交互页、参数台与推导页。

> ⚠️ **性质声明**：这些页面是**研究笔记 / 可视化实验**，不是同行评议论文。
> 页面里大量标注了「不成立 / 待验证 / 示意比例 / 仅为计数恒等式」之类的口径，
> 请按页面自己写的等级来读，不要把"能画出来"当成"被证明"。

---

## 快速开始

**不要直接双击 html**（部分页面用 `fetch` / ES module，`file://` 下会被 CORS 拦住）。
在仓库根目录起一个静态服务：

```bash
python -m http.server 8801
# 然后打开 http://127.0.0.1:8801/
```

或任何静态服务器（`npx serve`、nginx…）都行。

## 完整性

发布前用无头 Chrome **逐页真实加载**做过检查（2026-10-19）：

- 入口页 **105 个本地链接 → 105 个 HTTP 200**
- 91 个子页面全部加载成功，**JS 报错 0**
- 资源层唯一 404：`api/state`（`中国三人象棋_专利版` 原页面调用的后端接口，静态站没有后端，属预期）

如果发现某页缺图/白屏，多半是原页面里的历史死链（源目录本身就没有那个文件），
欢迎开 issue 指出具体页面与资源路径。
