Milnor 七维怪球 · 28 种微分结构动态演示

七维球面 S⁷ 上恰有 28 种两两不微分同胚的光滑结构（Frank Adams / Kervaire–Milnor：Θ₇ ≅ ℤ/28）。 每个元素都由 S³ 丛 over S⁴ 的粘合映射 ξ(u,v) = (u, uʰvuʲ) 驱动，同调球条件 h + j = 1， 判定不变量 λ = (h−j)²−1 (mod 7) 与 28μ ≡ h(h−1)/2 (mod 28)。
标准球面（n = 0） S³ 丛可实现：共 16 个（含标准球面） 非丛元素：12 个（仅连通和）
τ 相位
速度 0.50×
结构映射 ξ_{h,j}
S³ → M⁷ → S⁴
结构映射视图：蓝 / 绿曲线是两条参考圆在 ξh,j(u) 下的像，紫色网络是二维球面 w=0 的像， 橙色圆环是 Hopf 纤维（u 的轨迹），橙点 = 当前 u。拖动旋转，滚轮缩放。 切换不同元素，观察两条参考圆的像如何被"拧"。
纤维扫掠视图：把参考圆 A（w-z 圆）的像随 Hopf 纤维参数 τ 一路搬过去，得到的正是 ξh,j 在环面 S¹×S¹ 上的轨道族 —— 每一根纬线是"某一时刻参考圆的像"（颜色由蓝到橙表示 τ 的推进）， 细灰线是把 θ 固定、让 τ 跑遍的经线。结构越"怪"，这张网缠绕得越密：相对扭转率 = (h−j) − 1， h−j = 1 时最平缓（标准球面），h−j 越大越纠绞 —— 这正是两个七维球面之间难以找到微分同胚的几何体现。 勾选「叠加标准球面的轨道族」可做对照。 采样层数会随 k 自动加密（每「遍」扭转至少 6 层）：把 u(τ)=(cosτ,sinτ,0,0)、 v(θ)=cosθ+sinθk 代进 ξ 可以直接算出 ξh,j(u(τ),v(θ)) = ( cosθ·cos((h+j)τ), cosθ·sin((h+j)τ), −sinθ·sin(kτ), sinθ·cos(kτ) ) —— 后两个分量在 τ 走一圈时转了 k 圈，层数不够就会把扭转采样掉，几支球面画成一个样。 拖动旋转，滚轮缩放。
密铺全貌视图：前面两个视图只盯着一条 Hopf 纤维上的 u；这里让 u 跑遍 S³ 的一整张网格 （Hopf 坐标 (χ,ψ) 铺底空间 S²、φ 铺纤维方向），把参考圆的像一层层堆满 —— 得到 S⁷ 的一个「切片」。 这是讲解视频里最复杂、层数最多的那张画面。曲线的集合就是 { ξh,j(u, v(θ)) : u ∈ 网格 ⊂ S³, v ∈ 参考圆 }。 看点：色相绕底空间经度铺开，所以同一条纤维上的几层颜色相近、不同纤维之间颜色拉开，便于数层； 把 h+j 从 1 换成 0（丛层 M(h,−h)），结构立刻塌下去 —— ξ0,0 甚至只剩一条曲线。 曲线条数用左上「密铺密度」切换，密档对显卡压力较大。
