一、这页在讲什么（三分钟）

元宝把「双层石墨烯转 1.1° 就超导」拆成一条可推广的公式链。三个式子撑起整页：

① 魔角 = 界面耦合矩阵的谱 θ_k = 2 θ_TBG · cos( kπ / (N+1) ), k = 1 … ⌊N/2⌋, θ_TBG = 1.1° —— Khalaf et al., PRB 2019（文献）；N 层均匀链就是路径图 P_N 的本征值 ② 天花板：λ ≤ 2 ⇒ 均匀链的魔角永远 ≤ 2.2° （路径图谱半径趋于 2 ⇒ 这条约束卡死了后面所有"把贵金属比塞进来"的尝试） ③ 尺度级联：M ≡ 1/[2 sin(θ/2)]，L_j = a · M^j，j_max = ⌊ln(D/a)/ln M⌋ θ=1.1° ⇒ M = 52.088；D=10 μm ⇒ j_max = 2.685 ⇒ 真实器件只装得下 2 代
数值成立 上面三个式子的关键数我全部复算过（_check/_syn/ 现场算，不是抄页面）： 2cos(π/5) − φ = 0.00e+00；2sin(0.55°) = 0.019198 ⇒ M = 52.088； ln(10000/0.246)/ln(52.088) = 2.685。与页面标称一致。

二、六条跨页联系

下面每条都按同一格式交代：同构的是什么量 / 差异在哪 / 能拿去做什么判据 / 去哪个页面看。 分级：A = 可现场复算；B = 有推理链、前提需认可；C = 形式呼应，非同构。

L1φ 的唯一性：魔角谱里只有黄金比能直接当放大倍数 A 级 · 可复算
同构的量：贵金属比族 λ_m = (m + √(m²+4))/2 与魔角放大倍数 λ_k = 2cos(kπ/(N+1)) 是同一个符号 λ。
硬事实：λ_0 = 1.000（平凡）、λ_1 = φ = 1.618034 ✓ —— 从 m=2 起全部越过天花板： λ_2 = 2.414214、λ_3 = 3.302776、λ_4 = 4.236068，都 > 2。 ⇒ φ 是唯一「非平凡且能直接当 λ」的贵金属比；银比、铜比、铝比只能改走耦合比 ρ 那条通道。
落到物理上：N=4, k=1 时 2cos(π/5) = φ（差 0.00e+00）⇒ 四层交替转角石墨烯的魔角 θ = 1.1° × φ = 1.7798°，而文献实测 1.78° —— 黄金比在这里不是一个比喻，是能直接读出来的物理放大倍数。
差异 / 边界：这一步只用均匀链（所有界面等强）。一旦让界面耦合不等，λ 换成了「字」的谱，φ 的特权就转移到 ρ 上，不再是唯一。
→ 这条是给本项目「φ 特权」体系补的一块新砖：φ 不只是「最难有理逼近」，还是「唯一能当魔角放大倍数」的那一个。 可接到 Anu 七级螺旋主界面 的 φ 叙事，也可接到 aizawa.html 的 d=4.618 = φ+3（同一个 φ 在层数上的读数）。
L2平带：动能项被关掉之后，线性框架必然失效 A 级 · 有实验
同构的量：魔角处费米速度 v* → 0 ⇒ 带宽 W → 0 ⇒ U/W → ∞。 单粒子（线性）图像的分母没了，强关联接管。这正是09_Dynasphere 页「P1 · 闭合 vs 维持」那条判据的实物版本。
关系：P1 节的结论是「线性驻波无条件待得住 ⇒ 『需要主动维持』= 非线性的可观测判据」。 魔角给出的是同一件事的反面证据：当线性项（动能）被关掉时，体系不会「没事发生」，而是被相互作用改写—— 2018 年 MIT 看到的关联绝缘体与超导穹顶就是改写后的产物。
可用的判据：把 P1 的稳定域判据换成「W/U 跨过 1」这一个无量纲数。 魔角体系里它是可测的（Manchester 2026 PRX：0.3 nm 近距屏蔽 ⇒ 超导完全抑制、Tc 掉一个数量级以上、关联绝缘态同时消失 ⇒ 直接排掉电声机制）。
差异：P1 谈的是相空间里的轨道稳定性（Hénon 映射的 λ_u），魔角谈的是能带宽度。两个「线性失效」的语言不同，不能互相代入数值。
→ 建议插入点：09 页 P1 节末尾加一小段「现实中的同一判据：魔角平带」，附曼彻斯特屏蔽实验。这条能把 P1 从数学类比升级为有实验支撑的判据。
L3七分支递归：Hexaflake 的 7^d 与 Anu 的 7³ —— 用维数分开它们 A 级 · 判据
同构的量：两边都是「1 个母体 → 7 个子体」的递归。Hexaflake：一个六边形 = 中心 1 + 六个角各 1， 第 d 层有 7^d 个、最小半径 R/k^d。Anu：7 级 spirillae，7³ = 343（E2）。
关键差异（这才是能用的）：Hexaflake 每一层挖掉 2/9 面积 ⇒ D = ln7/ln3 = 1.771244，是个真分形。 而真实的莫尔嵌套是空间填充的（面积放大 M²、子原胞也是 M² 个）⇒ D = ln(M²)/ln M = 2，整数维，不是分形。
判据：一个「七分支递归」是不是分形，只看它有没有留空洞。同样的 7， 挖空 ⇒ D=1.771；填满 ⇒ D=2（或 3）。光凭「有 7」判不出来。
Anu 的答案（已算出来 · 2026-10-17 第 18 轮）：拿 Anu 自己的逐级半径比 ρ = √(1+(π·fill)²)/T（fill=1、T=7 ⇒ 0.4709869）代入同一个公式 ⇒ D = ln7 / ln(1/ρ) = 2.584467。它既不是 2 也不是 3，而且这两头是被不等式夹死的： 7ρ² = 1.5528 > 1（面积上装不下 ⇒ 不可能是二维铺砌）、 7ρ³ = 0.7313 < 1（体积上填不满 ⇒ 也不可能填满三维）。 1680 = 8!/24 = 7!/3 是计数恒等式，不含维数信息 —— 这点得说清楚，别让「七级」自动被读成「分形」。
口径：那个 ρ 来自「匝刚好相接（fill = 1）」这个建模选择；fill 拖到 0.5 ⇒ ρ = 0.2660137 ⇒ 同一个公式给出 D = 1.469490。所以 2.584467 不是 Anu 的固有常数，是「匝相接」的推论。
→ 已实装到 09 页 图 3t-b「第五套：Hexaflake」： 四套七（空间细分 / 七层物质 / 七个自由度 / 七种装配）+ 第五个成员 Hexaflake（标尺，不是体系）， 含可拖细分级数 n 的雪花画布、一条 D 数轴尺（1.771 / 2.000 / 2.584 / 3.000）与 11 条运行时自检。
L4守恒律：放大倍数 × 可见级数 = 常数 B 级 · 推理
式子：M^{j_max} ≈ D/a ⇒ j_max = ⌊ln(D/a)/ln M⌋。 M 与 j_max 互为反比，乘积被样品跨度 D/a 锁死。
为什么值得跨项目用：这是一条与物理无关的几何守恒 —— 任何「多级嵌套 + 有限视场」的结构都受它约束。 魔角页用它解释了「实验上永远只看到 2–3 代不是技术限制而是几何必然」：θ=1.1° 时 M=52.088， D=1 μm → 2.10 代、D=10 μm → 2.69 代、D=100 μm → 3.27 代。
用到本项目：anu 的 1680 匝 / 7 级细分同样受这条约束。给定「设备分辨率」就能算出最多看得见几级 —— 这条可以直接做成一个小读数，回答「为什么不继续往下画」。
差异 / 边界：魔角页里这条是初等代数，不是新物理（元宝自己在 §9 里也这么写）。 拿来做工程判据可以，不能当研究成果引用。
→ 与 黄金极限蛋外鞘 的相似律是同一类「无量纲组守恒」思路（那边守的是 σ_J/σ_Ω/κ/ρ_J）。
L5拍频：空间的莫尔 ↔ 时间的呼吸，同一个 |1−e^{iα}| A 级 · 恒等式
同一个表达式：莫尔倒格矢 Δg = 2g·sin(α/2) 就是两套周期图案的差频， 而 |1 − e^{iα}| ≡ 2 sin(|α|/2)（复平面两单位相量之差）。实测：α=0.55° 差 1.7e-18、α=1.15° 与 30° 差 0.0e+00。
跨到时间上：黄金极限蛋页 的呼吸周期 T_b = 10.618 是拿 φ 去规避锁相；魔角页的 M = 1/[2sin(θ/2)] 是拿小角去放大一个微观失配。 两者都是「近共振 ⇒ 小分母变大周期」这同一台机器：一个作用在波矢上，一个作用在相位上。
差异（必须说清）：机制同、数不同。莫尔放大的是角度失配，呼吸规避的是频率比的有理逼近； M=52.088 与 T_b=10.618 之间没有等式关系，不许把它们写成同一个常数。
可用的判据：凡是出现 1/[2sin(·/2)] 的地方，都是「两个几乎一样的周期在打架」。 这个形状可以当探针：见到它就去找那对近简并的母周期。
→ 接到 aizawa.html（呼吸 / 孔径）与螺旋项目的锁相判据（Arnold 舌、d=6 唯一极限环）。
L6十二重准晶：θ=30° 那一步跨进无周期态 C 级 · 形式呼应
页面的结论：莫尔「无限级」没有靠一代代嵌套实现，真正的出口是 θ=30°（石墨烯六重对称下的最大无公度角） ⇒ 两层在原子尺度就直接无公度 ⇒ 十二重准晶（dodecagonal quasicrystal），衍射图样 12 重自相似点阵（Ahn et al., Science 2018）。
形式呼应：12 这个数在幻方真理表体系里出现在 mod12；Searl 的 12 段环也用它。
但必须降级：这里的 12 = 石墨烯六重对称 × 2（两套格子互转），是几何来源； mod12 的 12 是模运算周期。两者数值相同、来源不同，不构成同构。写成「呼应」可以，写成「同一结构」就是硬凑。
→ 只在需要强调「12 这个数在不同体系里反复出现」时引用；不作为证据链的一环。

三、口径三分（哪些是文献、哪些是推演）

原文层 · 文献确立 θ_k = 2θ_TBG cos(kπ/(N+1))（Khalaf PRB 2019；实验 3/4/5 层 ≈ 1.57°/1.77°/1.95°）； 天花板 θ_∞ = 2θ_TBG = 2.2°；螺旋体系多代莫尔 a_M / a_MM / a_MMM； 强关联配对（Manchester PRX 2026 近距屏蔽实验）；supermoiré 碎裂超导穹顶 + Hofstadter 蝴蝶（EPFL Nat. Phys. 2026）。
推演层 · 元宝自标外推 把界面耦合图推广到加权路径图 / 准晶字（前提：能独立调控每个界面的 t 且保持共同莫尔周期）； 贵金属比作为 ρ、蝶形谱形状、「ρ=λ_m 时自相似性最强」。
元宝自己写明：这与 EPFL 的 supermoiré 路线是竞争关系，不是同一件事 —— 一旦各界面转角不同，单周期假设失效，这套「谱=魔角」映射不再严格成立。这条自我限定是整份对话里最有价值的一句话。
本页自算 φ 的唯一性（λ_m 表）、2cos(π/5) ≡ φ、θ_4层 = 1.7798°、 M = 52.088、j_max = 2.685、D_Hexaflake = 1.771244、 |1−e^{iα}| ≡ 2sin(α/2) 残差。这些数不是抄页面的，是归档时现场复算的。
未采用 arXiv 2512.11248 声称「多层石墨烯超导转角构成斐波那契数列」（含 440 K 的 Tc 声称、作者自承机制是推测）。 元宝已判定与本页谱构造无关、不应互相印证。本归档保留这条记录，但不把它当支撑 —— 两个「斐波那契」出处不同，不能对拼。
