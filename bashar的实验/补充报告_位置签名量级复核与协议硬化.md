## 一、量级对照：缺口第一次被算成一个数

本项目此前只写了「引力红移 4×10⁻¹⁷ —— 物理存在，但现有方案测不到」。
**本报告把「测不到」补成一个可比的数。**

| 量 | 数值 | 依据 |
|------|------|------|
| 铜球（声学通道）可测分辨率 | 10⁻⁶–10⁻⁷ | 铜壳声学模 Q ≈ 10³–10⁴，峰质心定位到线宽千分之一 |
| 铜球（电磁通道）可测分辨率 | 10⁻⁷–10⁻⁸ | 铜腔 Q₀ ≈ 1.2×10⁴，拟合 S21 到线宽 10⁻³–10⁻⁴ |
| **水平位移的已知引力位信号** | **≈10⁻²¹** | 3 m 水平位移，ΔΦ/c² |
| 垂直 33 cm（对照，非同题） | ≈3.6×10⁻¹⁷（NIST 实测 ≈4×10⁻¹⁷） | Chou / Hume / Rosenband / Wineland 2010，铝离子钟 |
| 垂直与水平之比 | ≈10⁴ | ΔΦ 之比 |
| **本项目缺口** | **13–14 个数量级** | 铜球分辨率 ÷ 水平信号 |

### 1.1 为什么水平信号小 10⁴ 倍

**GR 的红移只认 ΔΦ（位差），不认方向。** 水平方向没有另一套定律，只是信号更小：

| 位移方式 | ΔΦ/c² | 说明 |
|------|------|------|
| 垂直 33 cm | ≈3.6×10⁻¹⁷ | 完美球体也成立 |
| 水平 3 m（典型地区） | ≈10⁻²¹ | **完美球体严格为零**；真实地球全靠垂线偏差、大地水准面起伏、局部质量异常 |

> **对既有文案的修正建议**：第 11 章现有表述容易读成「水平方向可能是另一套物理」。
> 建议改为：**不是「水平方向可能有新东西」，而是「水平方向的旧东西太小」。**

### 1.2 这个问法已被系统搜索并排除

「频率是否依赖位置／方向」在物理里的正式名字是**局部位置不变性（LPI）/ 局部洛伦兹不变性**，挂在 SME 框架下被系统搜索过：

| 实验 | 排除精度 |
|------|------|
| ³He/¹²⁹Xe 微波激射器 | ≈10⁻³² GeV |
| 两个 Yb⁺ 光钟、量子化轴非平行 | 未观测到 1×10⁻¹⁹ 以上的调制 |
| Hughes–Drever 型实验 | δ ≈ 10⁻²² |

**含义**：本项目要声称的效应，若真在铜球灵敏度上显现，将比已知物理允许的大约 **10¹⁴ 倍**。
按本项目一贯的写法，这不等于「不可能」，而是**必须给出「为什么别的实验没看见」的理由**——目前这个理由不存在。
→ **建议在第 11 章单列一条「已知排除边界」，作为诚实清单的一部分。**

## 二、三个伪装者：把「信号弱」换成「三重伪影」

> 这条是本报告**最可执行的部分**。既有的第 3 章（环境控制）已有温度、地面微动、声反射等条目，
> 但**没有给出「怎么把它们和位置分开」的判别式**。以下三条每条都带判别式。

| 伪装者 | 机理与量级 | **判别式** |
|------|------|------|
| **① 涡流阻尼** | 铜是导体，在磁场中振动感生涡流，阻尼 **∝ B²**。地磁场 25–65 μT 且**室内不均匀**（钢筋、电缆、电器），水平移动 1–2 m 变化可达 μT 量级 → **换位置 Q 真的会变** | **分开拟合 f₀ 与 Q**：涡流主要动 **Q**，真频移主要动 **f₀**。**禁止只报峰值位置** |
| **② 温度梯度** | 3 m 长桌两端温差几 K 很正常。电磁通道 1.65×10⁻⁵/K，几 K 即 10⁻⁵ 量级——**比目标大两个数量级** | 球周围**至少四点测温**，把温度作为**协变量进回归**，而不是「稳定了就不管」 |
| **③ 声学驻波** | 1 kHz 波长 34 cm，10 kHz 只有 **3.4 cm**；3 m 桌面上声场在厘米尺度剧烈起伏 → **换位置必然换声场** | 激励源**随球一起移动**，或改用**压电贴片直接贴球上**（后者更干净） |

### 2.1 与本规范既有误差预算表的一处口径差异（待裁定）

| 面向 | 规范现有写法 | 本报告补充口径 |
|------|------|------|
| 地磁涡流阻尼 | `Q_mag ~ 10⁸` → **可忽略**（比机械 Q 高十几个数量级） | **最阴险的一个**：阻尼 ∝ B²，换位置 Q 真会变 |

**这两条不矛盾——是两个问题：**

- **量级上**：涡流阻尼远小于机械阻尼 → 「对 Q 的绝对值影响可忽略」**仍然成立**；
- **相关性上**：它是**位置相关**的 → 对两条路径是伪影：① 若拿 Q 当位置签名 → 直接撞上；② 若只看峰质心 → 阻尼变化会把表观峰位推走。

→ **建议处置（未直接改表）**：在该行「可忽略」后补一句限定——
**「作为损耗量级可忽略；但它是位置相关的，若用 Q 或峰质心做判据，必须分离 f₀ 与 Q。」**

## 三、屏蔽：从「常量」改成「四档可调变量」

### 3.1 硬事实

| 项 | 值 |
|------|------|
| 法拉第笼的工作机理 | 靠**电荷再分布**，主要挡**电场** |
| 低频磁场靠反射能不能挡 | **不能**——只能靠**吸收** |
| 铜在 50 Hz 的趋肤深度 | 约 **9 mm** → 要挡工频磁场，铜板得**几厘米厚** |
| 铁在 50 Hz 的趋肤深度 | 约 **1 mm** |
| **mu-metal（坡莫合金）** | 约 **0.1 mm**，靠**高磁导率吸收** |
| 使用条件 | 必须是**连续壳**，不是网；且会**饱和**，强场下失效，需**分层设计** |

**参照实现**：CUORE 实验的法拉第室即为此类结构。

### 3.2 设计变更：把屏蔽做成自变量

**原设计**：「置于隔离舱」（恒定条件）。

**问题**：如果「空间地点频率」本身就是某种场效应，**屏蔽可能连信号一起屏掉**。

**变更**：**屏蔽等级作为可调变量，四档并列**：

| 档 | 配置 | 作用 |
|------|------|------|
| S0 | 不屏蔽 | 暴露全部外部场 |
| S1 | 只挡电场（导体壳／法拉第笼） | 分离电场效应 |
| S2 | 加 mu-metal 连续壳 | 分离低频磁效应 |
| S3 | 全屏蔽 + 恒温 | 光电热磁全压 |

**判据**：效应四档**都在** → 不是电磁耦合；随屏蔽等级**单调衰减** → 是外部场。
**这一步本身就把「是什么」和「有多少」分开了。**

> 这是本报告里**最值得采纳的一条**——它把一个可能毁掉实验的取舍（屏不屏）变成了一个**能出结论的实验维度**。

## 四、两个判别实验（新增，成本极低）

### 4.1 对照组：「不该有反应」的样本

**做法**：放一只**实心铜球**或一个**石英振荡器**，与空心球一起换位置。

| 观察 | 结论 |
|------|------|
| 对照组**也**出现位置签名 | 是**环境**（桌子、房间、温度），不是球 |
| 对照组不动、空心球动 | 是**球** |

### 4.2 整桌旋转 90°：判「跟桌子走」还是「跟房间走」

**做法**：把整张桌子转 90°，重测。

| 签名行为 | 结论 |
|------|------|
| 跟着**桌子**走 | 球的属性（或桌面几何属性） |
| 跟着**房间**走 | 环境属性 |

> 4.1 与 4.2 与既有的**双球交换法**互补：
> 双球交换法消的是**加工差异**（已在本规范内）；这两个新实验消的是**环境归属**。三者正交，建议并列写入。

## 五、待裁定一：通道优先级（电磁模 vs 机械模）〔2026-10-08 已裁定：并列双通道 → 规范 §12.4〕

| 面向 | 规范 §10（第 10 章）现有口径 | 外部复核口径 |
|------|------|------|
| 首选 | **薄壳弯曲模（120–460 Hz）** ✅ | **电磁模** |
| 理由 | 对表面／边界**极敏感**——那正是信号所在 | 温度敏感度**低 10 倍**、Q 值**高 1–2 个数量级** |
| 频率温度系数 | −150 ppm/K（机械模） | 声学 −1.7×10⁻⁴/K vs 电磁 −1.65×10⁻⁵/K |
| Q | 声学铜壳模 10³–10⁴ | 铜腔实测 **Q₀ = 12,160**（TM010, 12.8 GHz）、10,000（10.2 GHz） |

**注意**：本规范第 3 章的误差预算表**本来就同时列了「温度（铜腔振动）」与「温度（机械模）」两行**——
说明双通道的结构已经存在，缺的只是**优先级声明**。

**裁定建议（未采纳，待定）**：**并列双通道，不二选一。**
理由：第 3 章自己已把温度列为「首要任务」——若目标是 10⁻⁷ 的位置签名，温度即第一约束，
电磁通道在同等恒温投入下更易达标；但弯曲模的**表面敏感性**是位置效应的**物理入口**，丢掉它等于换掉命题。
两者测的是**同一对象的不同耦合通道**，本身就是最好的交叉验证。

## 六、待裁定二：采集方式（同步 vs 轮扫）〔2026-10-08 已裁定：读出方式提为显式自变量，组合 ② 为默认 → 规范 §5.3 / §12.5〕

- **外部建议**：八点阵列改**同步采集**——八点若轮流扫描，**时间漂移会混进空间差异**；同步采才能分离「位置」与「时间」。
- **现有方案**：第 5 章为**开环扫描协议**（逐点顺序采集）。

**判定**：两者**不是同一层面**——开环扫描是**激励策略**，同步采集是**读出策略**，可以并存。

**建议**：把读出方式提为显式自变量，列出四种组合：

| 组合 | 激励 | 读出 |
|------|------|------|
| ① | 开环 | 逐点轮扫（现有） |
| ② | 开环 | 八点同步（**新增**） |
| ③ | 闭环 | 逐点轮扫 |
| ④ | 闭环 | 八点同步 |

**待定的是「是否需要补做 ② 与 ④」**——若同步采样的成本可接受，② 应当成为默认。

## 七、进 SOP 的一条防伪条款

外部复核指出常数识别工具的**输入门槛**：

| 项 | 量 |
|------|------|
| PSLQ 类工具的输入门槛 | **50 位**有效数字起步（复杂情形 100 位以上） |
| 高精度识别的精度约束 | 找长度 n、系数 d 位的关系 → 需要 **n × d 位**精度 |
| **本项目现有可靠有效数字** | **6–7 位** |
| **缺口** | **约 43–44 位** |

**且工具不会报错**：精度不够时，它们会给出「看起来很漂亮但完全错误」的闭式（学界称 **impostor／冒牌货**）。

→ **建议写入报告规范（SOP）**：

1. **任何声称「识别出常数结构」的结论，必须同时报告**：① 有效位数；② 所用工具及版本；③ 是否交叉验证（≥2 个工具）。
2. **低精度下 PSLQ 仍可用作「反证」**：找不到整数关系 = 大概率不是简单常数组合。**这个方向是可靠的，正向识别不可靠。**
3. 若有效位数 < 50 位，**禁止**宣称「识别出结构」。

> 这是一条**廉价的防伪条款**：只要规定了「必须报有效位数」，冒牌货就没有藏身之处。

## 十一、一句话

**这份复核没有提供任何新的物理机制。它提供的是一把尺子（13–14 个数量级）、一张三行伪影清单，**
**和一个把屏蔽从常量改成变量的思路。这三样都不改变命题，只让命题变得「能被干净地否掉」——**
**而按本规范自己的话：一个做得干净的零结果，本身就够发表。**
