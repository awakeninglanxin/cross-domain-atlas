克拉德尼图形：圆盘与方盘是两族不同的函数，不是同一块板换个形状

砂粒在振动板上的花纹，1787 年由克拉德尼（Ernst Chladni）系统记录，两百多年后成了声学、 乐器制作、乃至"声致图形（cymatics）"的入门实验。本页把两族板的本征函数、砂粒为什么会停在节线上、 以及一个能真正跑起来的交互台放在一起——公式是真的解，砂粒是真的在梯度上下坡， 不是滤镜。

01两族板：从"换个形状"到"换一套函数"

老师的书里把这件事分成两种实验，这个分法是对的，而且比"圆的和方的"要深一层。振动板的花纹由 板的本征函数决定，而本征函数的形式完全由坐标系的可分离性决定：

　方盘（矩形 / 正方形）圆盘
坐标系直角坐标 (x, y)，x、y 方向各自独立极坐标 (r, θ)，径向与角向分开
本征函数 w = cos(nπx)·cos(mπy) ± cos(mπx)·cos(nπy)
两项之和 = "和式"（sum），之差 = "差式"（difference）		 w = Jn(k·r)·cos(nθ)，k = j′n,s/R
Jn 是第一类贝塞尔函数；j′ 是 Jn′ 的第 s 个零点
节线长相 直线族：一组近乎平行的横线 + 一组竖线，交叉成网格；差式则变成"斜向十字 + 边缘弧"。 所有节线都通到板边。 辐条 + 同心圆：n 条过圆心的直径（辐条），加若干个同心节圆。 n=0 时一条辐条也没有，只剩圆环——这就是书里那一列"纯圈"。
退化 / 陷阱 n = m 时差式恒等于 0（两项相消），整个板不振。所以 5×5 表里那条对角线必须标灰， 不能画。另外 (n,m) 与 (m,n) 图像完全一样（差式只差一个负号），表是沿对角线镜像对称的。 n=0 时 cos(0·θ)=1，角向信息全丢，只剩径向；这是合法的，不是 bug。 另外 Jn′ 在原点有个零（n≥2 时），扫零点要从 r>0 开始，不然会算出 k=0 的"整板平移"。
频率标度 简支边界下 f ∝ n² + m²；自由边要用 cos/cosh 组合，标度偏移但趋势相同。 f ∝ (j′n,s)²。这是 k² 关系（板弯曲波是色散的，ω ∝ k²）， 不是弦的 ω ∝ k。
书里对应 n, m = 1…5 的 5×5 表（本页 §04） 3 行 × 5 列 = 15 个圆花（本页 §05，对应 p.48）
一句话记住差别：方盘的节线是"直的被边界截断"，圆盘的节线是"圆的和辐射的"。 它们不能互相近似——把方盘做圆，不会得到圆盘的花纹；把圆盘做大，也不会出现网格。 原因是这两族函数的正交基不同，不是同一个解的两种画法。

03砂粒为什么停在节线：它是被"赶"出去的，不是被"吸"过去的

很多人第一反应的图景是"节点像磁铁把砂吸住"，这是反的。节线上板根本不动，砂粒在那里只是 没有理由离开；而波腹处板动得最猛，砂粒被弹得最高，落地时就不一定回原位了。净效果是从波腹向节线 输运。

定量的说法：板上一点 (x,y) 的加速度幅值是 a(x,y) = ω²·A(x,y)。砂粒每次"跳起—落下"的 水平漂移量与局部加速度的梯度成正比，取时间平均后就是一个确定性的漂移速度：

vdrift ∝ −∇(A²)　　　　（砂粒朝振幅平方下降最快的方向走）

注意是 A² 而不是 A。这一点在代码里差不了几行，但物理上决定了"节线附近收敛得多快"： A² 的梯度在 A 小的地方也小，所以砂粒靠近节线时会自己减速，不会冲过头来回震荡。

本页的粒子循环就三行核心：

g = ∇(A²)[p]　→　p −= K·g　→　p += ξ·A(p)

第三行 ξ·A(p) 是随机项，强度正比于该点振幅——这是让模拟"像真的"的关键。 如果噪声是均匀的，砂粒会被随机游走慢慢糊满整块板，节线永远是毛的；只有"振幅大→跳得乱、振幅小→ 几乎不动"，砂粒才能真的停在线上。这条规则在所有像样的克拉德尼模拟里都能找到 （例如 evoluteur/cymatics 的 README 就写明了这个思路）。

可自己验的一件事：把"板厚"从 1.0 mm 调到 3.0 mm，频率会涨 3 倍（f ∝ h）， 但花纹一模一样——因为节线位置只由 n,m（或 n,s）决定，与频率无关。这正是实验里 "加厚板子只能改音高、改不了图样"的原因。要改图样，只能改驱动频率去命中另一个模态。
但上面这套"粉落节线"只对板成立。书 p.48 那台 eidophone（绷膜 + 侧管）是气泵： 粉被气流带走，堆在振动最大的地方，也就是腹点。所以本页多了一个开关 ——"砂粒堆腹点（膜/气流口径）"，勾上以后粒子的运动方向整支反过来（沿 +∇(A²) 上坡， 到振幅 >0.94 处粘住）。

怎么判断该用哪个？看照片：粉堆成"团"的地方是腹点，粉铺成"细线"的地方是节线。 书里 p.55 的方板图是细白线 → 节线；p.48 的圆花是成团的亮块 → 腹点。 第 07 格（只有一个中心大堆）是决定性证据：基模没有内部节线，正中间只可能是腹点。

这张图版怎么读（四族，按节线形状分）：
  • 格子型（第 1 行 1、4、5 格，第 2 行 3、5 格…）：两组互相垂直的直线，数出来就是 (n,m)，频率 f ∝ n²+m²。这是唯一能"数一条得一个数"的一族。
  • 对角型（画着 X 的那几格）：来自差式组合 cos(nπu)cos(mπv) − cos(mπu)cos(nπv)， n≠m 时才存在；n=m 时恒为 0（所以 5×5 表对角线必须留空/标灰）。
  • 弯曲型（节线是波浪/双曲线）：|n−m| 较大的差式组合，节线被"拉弯"穿过中心区。
  • 中心环型（中间一个椭圆/圆，外面挂几条线）：高阶差式组合，节线在中心附近收拢成一个闭合环。
关键一点：理想方板里，和式与差式是同一频率的两种组合（二重简并）—— 所以书里常把"格子"和"X"两格画在同一音高位置。真实板子边缘自由，两者会裂开一点点， 这就是为什么实拍图里"X"格的中心常常有点歪。

0515 张圆花：从照片反推 (n,s)，再算 Hz

这一节跟上一版换了内容：老师把原书照片给过来了，所以下面 15 格是照片本身， 不是我按结构画的。同时有一个模型更正必须先讲清楚，不然频率全错。

更正：这 15 张不是"板"，是"膜"。 p.48 的正文写得很明白：这些圆纹是 1880 年代 Margaret Watts Hughes 用一台 eidophone 拍的—— "a hollow base with a membrane stretched across it and a tube attached to its base with a mouthpiece at the other end"。 膜边缘是夹紧的，所以边界条件是 Jn(kR)=0，用 jn,s； 不是自由边圆盘的 j′n,s（上一版我用的是这个，对这 15 张是错的）。 两套零点差得不小：j0,1=2.4048，j′0,1=3.8317，差 37%。

膜和板的物理也不是同一套：板是弯曲波，ω ∝ k²（要板厚、要 E/ρ）； 膜是张力波，ω ∝ k（只要张力与面密度）。所以这 15 格的频率只有一条式子：

fn,s = jn,s · c / (2πR)　，　c = √(T/σ)

R 是膜半径，T 是面张力（N/m），σ 是面密度（kg/m²）。照片里没有比例尺，书上也没写她唱的是哪个音， 所以绝对 Hz 不能从图里"算出来"，只能"标定出来"；但比值是硬的： fn,s / f0,1 = jn,s / 2.4048，这一列不依赖任何假设。

左上 #nn = 书里自左至右、自上而下的序号 右上圆点：● 确定　● 较可信　● 存疑 点格子 → 送进 §02，看该 (n,s) 的理论图
怎么从一堆亮斑读出 (n,s)：三条判据

判据 0：亮的是腹点，不是节点。平板上粉被振离腹点、落在节线上（所以方盘图里白线是节线）； 这台装置是"空腔 + 管"，粉被气流带走，堆在振动最大处。证据就在第 07 格： 整格只有一个中心大堆——那是基模 (0,1) 的腹点，不可能是节点（基模没有内部节线）。

判据 1：数一圈亮堆的夹角 → n。节直径与节圆相交，腹点成对出现，故同一环上相邻两堆夹角 ≈ 180°/n，即 n ≈ 180° / 夹角。但人声是从侧管灌进去的，激励本身不轴对称， 经常有一两个腹点被压制——所以"少数了一个"是常态，不是判错。

判据 2：数环 → s。内部节圆数 = s−1；反过来数"亮环"的层数，也能定 s（腹点带夹在节圆之间）。

判据 3：环半径比值交叉验证。第 i 个节圆在 r/R = jn,i / jn,s， 这个比值对 n 敏感（n=3 时内环在 0.50R，n=6 时在 0.66R），可以反过来排除 n。

分辨率上限：原书这一版每格只有约 92 像素（手机翻拍书页，整幅 790×1920）， 而且书页略斜（圆被压成轻微椭圆），所以本页给出的 n 误差约 ±1、s 误差约 ±1。 凡标灰点的行，请当"候选"看，不要当结论用。

06频率：Chladni 定律是经验式，别拿它当定理用

板弯曲波的色散关系是 ω = k²·√(D/ρh)（k 的平方，不是弦的 ω = ck）， 所以：

f = k² / (2π) · √( D / (ρh) )　，　D = E h³ / [ 12(1 − ν²) ]
√(D/ρh) = h · √( E / [12(1 − ν²)ρ] )　→　f ∝ h（板越厚，音越高，线性）

把钢的参数代进去（E=200 GPa，ν=0.30，ρ=7850），厚度 1 mm 时 √(D/ρh) ≈ 1.528 m²/s。 于是 300 mm 的方盘、n=m=1 给 53 Hz，n=m=5 给 2666 Hz；150 mm 半径的圆盘、j′4,3=12.68 给 1736 Hz。都在人耳灵敏段，所以"播放音调"按钮是真的能听见的。

Chladni 定律 vs 贝塞尔严格值

先分清两套零点，别混：下面这条经验式是板的（Chladni 当年用的金属板，自由边 → j′）； 而 §05 那 15 张 eidophone 圆花是膜（夹紧边 → j）。两套零点不能互相代入： j′0,1=3.8317 对 j0,1=2.4048，差 37%；而板是 k² 律、膜是 k 律， 所以两者的频率差还不是同一个倍数（随 k·R 变）。§02 里"夹紧边"那个勾选，就是在这两套之间切换。

书上常见的经验式是 f = C·(m + 2n)²（m = 节直径数，n = 节圆数，不是径向阶 s）。 它是经验拟合，不是解，而且常数 C 每块板都得重拟。把 (n+2c)²（c = 实际数出来的节圆数） 和精确值 j′² 并排看，比值是这样的：

n 辐条s 径向阶j′n,s c 节圆f = j′²Chladni (n+2c)²比值

红底 = 比值 > 3.2（纯辐条模态），蓝底 = 比值 < 2.4（节圆多的模态）。 比值不是常数，就是这张表要说的事。

结论（本页最该记住的一条）：比值落在 1.77 – 3.67（跨一个因子 2.1）， 说明没有哪一个 C 能把 15 个模态同时套住。同一列 c 内比值随 n 单调缓降， 是"两条曲线形状本来就不同"，不是"差一个常数"。所以：
  • 用它排序、估数量级、讲"为什么图越复杂音越高"可以；
  • 用它反解频率不行——必须解 Jn′ 的零点再乘 k²；
  • 书上如果只给频率不给模态号，那条频率只能当"大致落在哪个八度"，不能反推 n,m；
  • c 越大经验式越好用（c=2 那五行起伏只有 15%），c=0 的纯辐条族误差最大。

07模型边界：这页算不出来的六件事

模型给的真实板里的偏差方向 / 怎么补
cos·cos ± 两项 自由边矩形板的严格解是 cos·cosh ± cosh·cos 的组合（含指数项） 节线会整体内缩一点，越靠边越明显；低阶几乎看不出，高阶边缘处会偏。 要精确就得解双调和方程（DC-Creatives-Club/vibrational-modes-plates 那类有限差分）。
纯 Jn(kr) 严格解是 Jn 与 In 的线性组合，系数由边界条件定 节圆半径偏大约几个百分点；边缘附近的节线形状会变钝。
板是均匀、各向同性、等厚 轧制钢板有残余应力和厚度公差 简并模态劈裂：(n,m) 与 (m,n) 本来同频，实测会差几 Hz，于是两个模态会混合， 拍出"既不像和式也不像差式"的杂图。这就是现场演示时"Why 这次的花纹和上次不一样"的主要来源。
砂粒只做漂移 砂粒真的在跳（hop）、有摩擦、有回弹、有大小分布 真实砂纹有颗粒感与堆积厚度，细砂上线更细、粗砂会成"墙"。本页的粒子是点， 所以线宽只由数值阈值决定，不能用来判断砂的粒径。
膜就是理想 Jn 解 真实膜有空气附加质量（两面贴着空气，等效面密度变大）、张力会蠕变、 粉本身也有质量；振幅大到非线性时，模态之间会锁频/混频 空气附加质量让频率整体偏低（几 % 到十几 %）；张力蠕变让频率随时间往下漂—— 这正是 eidophone 这类装置"图样会自己变形"的物理原因，也是 §05 里同一模式拍出两种样子的合理解释之一。 注意：夹紧边的均匀膜用 Jn 是精确的，不需要像板那样加 In 修正。
频率是线性本征值 驱动点、支撑点、换能器质量都会移动模态，非线性还会让频率随振幅漂 实测共振频率通常比理论值低几个百分点；支撑点本身必须落在节线上，否则把模态"压死"。
所以：这页能告诉老师"这个模态长什么样、为什么长这样、频率大致在哪个量级"， 不能告诉老师"我这块板在 1.234 kHz 时会出第 5 号图"。后者只能实测。 任何号称能从频率反推图样的网页（包括本页）都只在该板的理想模型里成立。
