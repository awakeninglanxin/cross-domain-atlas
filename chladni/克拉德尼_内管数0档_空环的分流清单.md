# 内管数 0 档：把「内环不存在」这一档真正接进全页

> 2026-10-24。老师原话：「定位到参数 A4 基准频率的下面，内管数目前是（3–15），把 3 这个下限改成 0，
> 也就是允许没有内管对应 0，一直到最多 15。」
>
> 改一个 `min="3"` 是一分钟的事。真正的工作量在**它下游**：全页有十几处拿「第一根管」当样本、
> 十几处拿 `tubeCount()` 当除数。0 这一档一旦进来，那些地方要么抛异常、要么把 `NaN` 送到屏上。
> 本文记录**每一处怎么分流的**、以及三个只有在这种退化档才会露头的坑。

---

## 一、先定语义：0 到底是什么意思

| | 7 根（默认） | 0 根 |
|---|---|---|
| 内环 | 7 管，全同音 B♭ | **一根都没有** |
| 外环 24 管（8 套 × 3） | 有 | **照旧有**（惰性谐振器，不进发声） |
| 外环的基准音 | 内环那个音 × `ftrip` | **内环本该是那个音** × `ftrip` |
| 发声 | 七正弦叠加 | 没有音源（0 个振荡器） |
| 内环那一族读数 | 数值 | **「—」+ 一句「没有对象可算」** |

**外环基准音这一条是 0 档能自洽的关键。** 外环 24 管是按「内环那个音 × `ftrip`」标定的；
如果删掉内环就让 `tubeFreqs()[0]` 变成 `undefined`，24 根管会一起变成 `NaN`（整圈消失）。
所以空环时锚到 `innerAnchorHz() = tonicHz() × 2^(woct−3)` —— **内环本该是那个音**。

实测：0 管与 7 管两档的 24 根外环频率**逐根相对误差 0.00e+0**，跨度仍是 **8.000000×**，
最低音 `921.621333 Hz` = `inner × ftrip`（现算对账，不是「看起来没变」）。

## 二、分流清单（28 处替换，18 个逻辑分支）

### 1. 唯一真源
```js
function nT(){ return Math.max(0, Math.min(15, Math.round(TUBE.nt))); }
function noInner(){ return tubeCount() === 0; }
function innerAnchorHz(){ return tonicHz()*Math.pow(2, TUBE.woct - 3); }
```

### 2. 统计层（两个函数各开一个空环分支，返回字段与正常档**一个不少**）
- `tubeStats()`：`list:[]`、`gAvg/gMin = 0`、`gMinI = −1`（哨兵，调用方靠它判空）、
  `massTube/massRatio = 0`、`cOwn/leak = 0`、`r0Min7 = 0`（管距约束无意义）。
- `acouStats()`：`list:[]`、`n = 0`、`beat = 0`、`beatPair = [−1,−1]`、`span = 1`、
  `fMax/Lmin/Lmax = 0`。**不用 NaN 顶上** —— NaN 会一路渗到屏上变成「NaN g」。

### 3. 显示层（宁可写「—」，不写 0）
屏上凡是「以某根管为样本」的格子，一律写 `—` 并给一句原因：

| 位置 | 0 管时写的字 |
|---|---|
| 管数 | `0 根（无内管）` |
| 音阶下限 / 上限 / 跨度 | `—（0 根内管，没有音阶）` / `—` / `—` |
| 律制差 | `—（无内管，两个律制都无处可比）` |
| 平均耦合 `⟨g⟩` | `—（无内管）` |
| 拍频 | `—（0 根管，没有拍频）` |
| 同频源个数 | `—（无内管）` |
| 声学卡整表 | 一行说明 + 全部 `—` |
| 管长波形图 | 一段实话：「没有管子就没有可比较的对象」 |
| 布阵小图 | 画空环 + `0 根内管 / （无布阵可画）` |

**为什么不用 0**：`0 Hz`、`1.00×`、`0.0 音分` 都是**具体的、错的数**，比「—」更容易被当成结论。
这一页的口径三分（无原文⇒立论 / 有原文⇒原文层 / 能复算⇒数值成立）在这里落成一句话：
**没有对象可算的时候，不许算出个数来。**

### 4. 物理层
- `drawTube3D()` 的右上读数：`⟨g⟩ = —（0 根内管，没有可评的管）`，首行 `无内管 · …`。
- 七管闭环流（回收）：`AQ` 增加 `tubeCount() > 0` 条件 —— **没有管就没有七个涡胞**。
  （不关的话 `CELLN = 0` ⇒ `cos(0·θ) ≡ 1` ⇒ 每个粒子都被判成「进了喷口」。）
- 族谱 `m ≡ 0 (mod N)`：`mm % 0` 是 `NaN` 而不是 0，族谱碰巧也是空的，但那是**巧合不是判据**；
  改写成显式 `inRing = (tubeCount() > 0) && (mm % tubeCount() === 0)`。
- `dualStats()`：内环角向系数 `C_m = 0`（没有任何源）—— 这是**真值**，不是占位。

## 三、三个只有退化档才露头的坑

### 🔴 坑 1：`parseInt('0') || 7` 把 0 吞回 7

```js
// 改前
setTune('nt', parseInt(this.value, 10) || 7);
```
`parseInt('0')` 返回 **0**，是 falsy ⇒ `|| 7` 立刻把它换成 **7**。
表现是「滑杆拖到最左端、松手就弹回 7」—— 看着像滑块坏了，实际是一行默认值写法。
改后把「0」和「解析失败」分开认：
```js
var v = parseInt(this.value, 10);
setTune('nt', isNaN(v) ? 7 : v);
```

### 🔴 坑 2：`L[−1].name` 抛在 rAF 里 ⇒ 画面**冻结在上一帧**

`drawTube3D()` 里 `'最弱 ' + L[st.gMinI].name`，空环时 `gMinI = −1` ⇒ `L[−1]` 是 `undefined`
⇒ 读 `.name` 抛 `TypeError`。这件事特别坏：`drawTube3D` 是每帧调的，
**抛一次就把整条 `requestAnimationFrame` 链打断**，画面停在上一帧 ——
看起来像「卡住」而不是「报错」，控制台不打开就永远发现不了。

同一类还有 `lhudDrawSpr(gm)` 里的 `gm[0].r`（布阵小图），也是每帧跑。
两处都改成显式空环分支。

### 🔴 坑 3：`noteName(0)` 在空音阶上给 `NaN`，而且**不报错**

`scaleSteps()` 返回 `[]` 时，`st[Math.min(0, −1)]` 是 `undefined` ⇒ 音级 `NaN` ⇒
屏上打出 `0.0 音分 @ NaN（纯律 vs 平均律）`。**没有异常、没有空白，只有两个字「NaN」**。
抓到它的是探针里那条「31 个读数格里没有 NaN」的断言，不是看图。

## 四、一条必须说清的物理事实

**0 根内管 ≠ 盘面没有七瓣图案。**

这一页的七瓣是 **`S.N = 7` 个振子**的相位（φᵢ = m·αᵢ）做出来的，
内管只是「管口在腹点圆上做局部声流」。页面自己的判词就写着：

> 「七瓣图案不是这七根管做出来的，是 7 个振子的相位在 f₇ 上做出来的；管只负责在腹点圆上做局部声流。」

所以 0 管档下盘面**仍然**是七瓣 —— 那是正确的，不是漏改。
被关掉的只有「七管声流 / 七涡胞回收」这一路。
