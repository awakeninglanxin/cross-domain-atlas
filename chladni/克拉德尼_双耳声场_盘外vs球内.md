## 〇、结论先行

老师问的是「有没有充分运用左声道」。**没有。** 改前整页只有一个 `StereoPannerNode`，`pan = r·cosθ`，一维；而且 `TUBE.view`（2D 俯视 / 3D 透视 / 球腔）**根本没进音频链**——三档声音逐位相同。所谓「球腔 3D 的置身球内感」，改前一分钱都没实现。

改后是两条**互不相同**的物理链，同一根管并行跑两套双耳解，切档靠耳增益交叉淡化：

| 指标 | 盘外（plate） | 球内（cavity） | 说明 |
|---|---|---|---|
| 耳间线索的类型 | **传播时差 + 刚性球衍射相位**，随 f 单调 | **模态场的相位**，只在 0° / 180° 两簇 | 性质不同，不是量级不同 |

### 老师问的「柏拉图立体等分点」

球腔档新增**源云**：把 N 个声源重排到球面等分点上（赤道 3/4/5 等分、正四面体、金字塔式、正八面体、正立方体、正二十面体、正十二面体）。**这不是装饰**，它把 ℓ 阶模态**严格**灭掉：

| 档 | t-设计阶 | 两耳 | 方位 |
|---|---|---|---|
| 赤道 4 等分 · 八面体 · 立方体 · 二十面体 · 十二面体 | t=1 / 3 / 3 / 5 / 5 | **逐位相同**（ILD ≡ 0，倾斜也改不了） | 无 |
| 正四面体 · 四棱锥·金字塔 | t=2 / 0 | **逐位相同**（不中心对称，但 x 投影对称） | 无 |

一句话：**11 个点集里只有 4 个有左右方位**；其余 7 个是"完美全向包裹"（两耳完全一致，任何朝向都一样）。而 `t` 越高越像点声源——**"更高级的柏拉图立体"给的是更彻底的包围感，不是更炫的方位**。详见 §五。

## 二、盘外：刚性球散射精确解（真 HRTF）

听者在盘外：`y = −0.35 m`，耳高于盘面 `0.22 m`，**朝盘心**。头部是刚性球，半径 `a = 87.5 mm`（两耳距 175 mm）。

### 2.1 第 15 轮的做法是「假 HRTF」，第 16 轮换掉了

第 15 轮用的是**对侧耳一阶低通**：`fc = (c/2πa)/max(0.2, sin|α|)`。它只有一维头影，没有球面衍射，也没有任何仰角依赖。第 16 轮换成 **Rayleigh 刚性球散射的精确解**（平面波入射、硬球、声压取在球面上）：

```
p(γ, x) = Σ_{n=0}^{N} (2n+1) · iⁿ · P_n(cos γ) · [ j_n(x) − (j_n′(x)/h_n′⁽²⁾(x)) · h_n⁽²⁾(x) ]
x = k·a = 2πf·a/c          γ = 声源方向与「耳朝外方向」的夹角
```

一阶低通仍留在代码里，但**只作对照**：面板上「精确 / 一阶」两个数并排，差额记在 `hrtfDiff`（默认配置实测 **1.324 dB**）。`hrtfDiff` 就是「假 HRTF 到底假多少」这个数，以前只能嘴上说。

两个**解析极限**当判据（这是「对不对」的唯一硬标准，一阶低通连边都够不着）：

| 极限 | 精确解必须给 | 实测 |
|---|---|---|
| `x → 0`（50 Hz，两耳都要） | `\|H\| → 1`、`∠H → 0` | 1.000510 / 1.000448，ILD **0.00053 dB** |
| `x → ∞`、`γ = 0`（20 kHz 正对） | `\|H\| → 2`（+6.0206 dB，刚性壁前压力加倍） | **1.99546**（+6.001 dB） |
| `x → ∞`、`γ = π`（背面） | 随 x 单调下降 | 0.914 → 0.803 → 0.657 → 0.522 → 0.389 → 0.276 → 0.181（x=16…128） |

### 2.2 三处「能算出来、不报错、量级完全不物理」的坑

**① `iⁿ` 不能省。** 省掉之后 γ=0 低频给 `1.242`（应 1.003）、20 kHz 给 **19.53**（应 2.00）。原因：γ=0 时 `P_n(1)=1` 对所有 n 成立，没有 `iⁿ` 的交替符号，`Σ(2n+1)·[j_n − …]` 就变成各项同号相加。**只有拿上面两个极限当判据才抓得住**。

**② `h_n⁽²⁾` 在小 x 有 1e37 量级**（`y_n ~ (2n−1)!!/x^{n+1}`），复除法符号错一步就溢出成 `|H| = 2.89e39`。所以必须**先把 `q = j′/h′` 算成比值再乘 h**，不让 `h` 单独进分子。

**③ 不能每阶各调一次 Bessel 函数。** `y_n` 每阶从 0 递推上来是 O(N)，`legP(l,x)` 也是 O(l)；24 管 × 2 耳 × 44 阶 = 20 万次/帧。改成：

- `spaJY(nmax,x)` 一次填满 `j` 与 `y` 两个数组 ⇒ O(N)
- `y` 用**向上**递推（它是主解，稳定）；`j` 用 **Miller 反向**一遍填满再按 `j₀` 锚定
- `P_n` 按阶推进 `P_n = ((2n−1)c·P_{n−1} − (n−1)P_{n−2})/n`

**截断阶数**：`N = ⌈x⌉ + 12` 与 `⌈x⌉ + 80` 在 x=1.6…32 上一致到 **0.005%** ⇒ 12 够用。（x=256 ≈ 160 kHz 时 `+40` 已经不收敛，与 `+16` 差 16%——那个频率不在音频带里，但也说明「N 一次给够」这句话有边界。）

另外验证了一条**精确的结构恒等式**（比拟合一个渐近律扎实）：

```
(1/2)∫_{-1}^{1} |p(γ)|² dcosγ  =  Σ_n (2n+1)·|A_n|²
```

5 个 x 上相对差 ≤ **4.5e-6**。它一次检掉：权重 `(2n+1)`、`P_n` 的按阶推进、`iⁿ` 的逐阶推进、`q = j′/h′` 的符号。

> ⚠️ 我原先在这份文档里写过「背面服从 `(ka)^{−1/3}` 阴影律」——**那是记错的，已删**。实测 `|H(180°)|·x^{1/3}` 在 x=16 处到顶(2.30)就回落，x=64→256 的有效指数从 −1.34 漂到 −1.70，**不成单一幂律**。探针里那条判据换成了上面那条恒等式。

### 2.3 延时：单频下 τ ≡ 相位，但要小心 DelayNode 的上限

```
τ = d/c − ∠H/(2πf)      （单频下这与相位是恒等，不是近似）
```

🔴 **`DelayNode` 上限 0.006 s**（建图时 `createDelay(0.006)`），`AudioParam` 超限会**静默钳位**：相位当场错掉，不报错。200 Hz 时 `1/f = 5 ms`，加 1.17 ms 传播就顶到上限了。处置：`DMAX = 0.0052`，超出就**整周期地退**（单频下 τ ≡ τ + k/f，退整周期完全等价）。

🔴 两耳**都**要写延时。第 15 轮只给远耳写、近耳恒 0，那等于把「共同传播时延」扔了，于是「声源远近」只剩音量差、没有到达时间差。

## 三、头动：两种**不同**的物理，不能共用一套

第 15 轮我写的是「头部转动 / 双耳动态：**没有**，听者朝向固定」。第 16 轮加上了，`SPA.rot = {yaw, pitch}`，Shift + 拖鼠标转头（60 ms 节流，`spaHeadApply`）。

关键的一点：**盘外和球内的头动不是同一件事**，所以代码里也没共用一套。

| | 盘外（plate） | 球内（cavity） |
|---|---|---|
| HRTF 依赖什么 | 只依赖 `γ`（相对**头**的夹角） | 依赖两只耳在**世界坐标**驻波里的位置 |
| 转头发生了什么 | **声场跟着头一起转** | 场**不动**，变的是耳在哪 |
| 头转 π 后逐管 ILD | **精确反号**（残差 5.9e-15 dB） | **不反号**（残差 **0.204 dB**） |

最后两行是这一节最硬的判据，而且是**一对**：

- plate 反号是解析必然。`ILD_i = 20log₁₀(g(û·R̂)/g(−û·R̂))`，头转 π 就是 `R̂ → −R̂` ⇒ 分子分母互换 ⇒ 精确取反。跟管子怎么摆**无关**。
- cavity **不许**反号。球腔的场钉在世界上；`ILD_i(π)` 等于「把源搬到对跖点」的 ILD，而不是 `−ILD_i(0)`。七根管是奇数环、没有对跖伙伴，所以两者本就不该相等。

所以探针把这两条写成对照：**plate 必须 ≈0，cavity 必须明确 ≠0**。如果哪天有人「顺手」把球腔也按头转处理，cavity 那条会立刻变红。

### 3.1 俯仰（pitch）：绕的是**耳轴**，所以耳朵一动不动

🔴 这是我在写判据时才发现、而且一开始判据写错了的一条：**pitch 绕头的右轴转，而两耳正好在这根轴上** ⇒ 刚性球 + 无耳廓的模型里，俯仰对 ILD / ITD / 相位**严格零影响**。

实测：`pitch = 0.5 rad` 后两耳位置偏差 **0.00e+0 m**，盘外逐管 ILD 变化 **0.00e+0 dB**；但报出来的仰角变了 **28.61°**。

真实人靠**耳廓**（pinna）的谱形凹槽分辨俯仰，本模型没有耳廓，所以**给不出**那一半信息。面板上已经把这句话写死，不圆场。

球腔档 pitch 仍有效（`ILD` 变 **0.213 dB**）——不是因为它有了俯仰感，而是因为**耳体积抖动点**（`SPA_JIT` 那 7 个点）是按头坐标摆的，头一俯，抖动点跟着转，耳在驻波里换了几毫米位置。

### 3.2 抖动点必须跟着头转（否则对称性判据当场失效）

`SPA_JIT` 是**头坐标**里的 7 个点（±右 / ±前 / ±上 + 原点）。第 15 轮它被固定在世界 `x/y/z` 上，于是 yaw=π 时两耳不再严格互换——上面那对判据根本立不起来。

改成沿 `BB.R / BB.F / BB.U` 展开：

```js
H = spaCavHv(f, u, {
  x: eb.x + BB.R.x*jj[0] + BB.F.x*jj[1] + BB.U.x*jj[2],
  y: eb.y + BB.R.y*jj[0] + BB.F.y*jj[1] + BB.U.y*jj[2],
  z: eb.z + BB.R.z*jj[0] + BB.F.z*jj[1] + BB.U.z*jj[2] }, nn*R, null, cap);
```

> 顺带一个口径提示：抖动点从「世界轴」换成「头轴」之后，球腔整档 L/R 平衡从 −12.23 dB 变成 **−14.85 dB**。这不是新 bug，是抖动方向的物理含义变对了（耳朵的体体积是长在头坐标系里的）。

### 3.3 延时连续性

转头是连续的，延时不能跳周期（跳一个周期 = 咔哒）。实测相邻 5.7° 之间延时变化最大 **5.32% 周期**（判据：< 50%）。两档所有延时都在 **0.447 ms（盘外）/ 0.542 ms（球腔）** 以内 —— 远低于 `DMAX`，不会被钳位。

## 四、球内：刚性壁模态展开（cavity）

这是本轮的主体。球腔 3D 档的听者**在球心**，耳朵在球心两侧 87.5 mm。

### 4.1 第一道坎：画面用 Dirichlet，声音必须 Neumann

画面画的是球面上 `ψ = 0` 的节线（视觉要「球壳上有花纹」），那是 **Dirichlet** 边条件：

```
j_ℓ(kR) = 0        ⇒ 本征值 x_{ℓs}，如表 4.4934 / 5.7635 / 6.2832 …
```

但**声音不能用它**：外环 24 管正压在 `r = R` 上，Dirichlet 下 `j_ℓ(kR) ≡ 0` ⇒ 一个模态都激不出来。实测 `Σ|j_ℓ(kR)| ≈ 1e-16`。

**刚性壁是 Neumann**，本征值取球 Bessel 导数的零点：

```
j′_ℓ(kR) = 0       ⇒ x′_{ℓs}
f_{ℓs} = x′_{ℓs} · c / (2πR)
```

反向验证：在 Neumann 零点上 `|j_ℓ(kR)| ≥ 1.52e-2 ≠ 0`。（这一条必须验，否则「换了个零点表」和「换对了」在数值上看不出区别。）

`R = 12 英寸球 / 2 = 152.4 mm`：

| 模态 | 零点 | 频率 |
|---|---|---|
| ℓ=1 偶极（最低） | 2.081576 | **745.63 Hz** |
| ℓ=2 | 3.342094 | 1197.15 Hz |
| ℓ=0 呼吸（刚性壁上） | 4.493409 | **1609.55 Hz** |
| ℓ=1 第二阶 | 5.940370 | 2127.86 Hz |

共 **579 个模态**（f ≤ 24 kHz，ℓ 到 63）。

### 4.2 传递函数

球腔内受迫解，源在 `r_s`（某根管，都在壁上）、耳在 `r_e`（距球心 87.5 mm）：

```
H(f, γ_耳) = Σ_{ℓ,s}  (2ℓ+1) · j_ℓ(k r_s) · j_ℓ(k r_e) · P_ℓ(cos γ_耳)
                      ────────────────────────────────────────────────
                            ‖j_ℓ‖² · k²_{ℓs} · (1 − (f/f_{ℓs})² + i (f/f_{ℓs})/Q_{ℓs})
```

角向那一坨来自球谐加法定理：

```
Σ_m Y_ℓm(Ω_s)·Y*_ℓm(Ω_e) = (2ℓ+1)/(4π) · P_ℓ(cos γ)
```

`γ` 是源方向与耳方向的夹角。两耳关于球心**镜像**，`cos γ` 只差一个负号 ⇒

```
P_ℓ(−x) = (−1)^ℓ · P_ℓ(x)
```

**这是两耳唯一的差别来源。** 偶数 ℓ 两耳同相、奇数 ℓ 两耳反相。也正因为如此，球内的耳间线索是「0° / 180° 两簇」，而**不是**传播时差——两耳到球心等距，路径一样长。

模平方积分有闭式（在 Neumann 零点上化简）：

```
‖j_ℓ‖² = R³/2 · [ j_ℓ² − j_{ℓ−1}·j_{ℓ+1} ]  =  R³/2 · j_ℓ² · ( 1 − ℓ(ℓ+1)/x² )
```

### 4.3 带宽从哪来

刚性壁本身不耗能，Q 无穷 ⇒ 传递函数是**一根根针**，数值上等于只在模态频率上有值。真实球壳有损耗，用 Sabine 折算：

```
V = 14.827 L      S = 0.29186 m²      α = 0.05（硬壳，取低值）
RT60 = 0.161·V/(S·α) = 163.576 ms
σ = ln1000/RT60 = 42.23 1/s
bw = σ/π = 13.442 Hz           Q_{ℓs} = f_{ℓs}/bw
```

### 4.4 模态重叠 M(f)：为什么低频「一根根」、高频「糊成一片」

```
M(f) = 模态密度(f) × bw        密度按 (2ℓ+1) 计权（否则 ℓ 高阶被严重低估）
```

| f | M(f) | 听感 |
|---|---|---|
| 1 kHz | **0** | 模态稀疏，听到的是分立共振 |
| 3.26 kHz | 1 | 转折点 `fc` |
| 8 kHz | **4.44** | 已进入扩散场 |

所以「球内有没有空间感」不是一个答案：**745 Hz 附近是几个尖锐的腔共振，8 kHz 附近才是混响场。** 这也是为什么不能拿一个 pan 系数糊过去。

### 4.5 直射被混响掩蔽：临界距离

```
r_c = 0.057·√(V/RT60) = 17.161 mm
耳到壁 = R − 87.5 mm = 64.90 mm
DRR = 20·log10(r_c / r_耳) = −11.55 dB
```

🔴 **这里是本轮的一处口径修正。** 面板原先算的是 `20·log10(r_c / R) = −18.97 dB`，即「把听者贴在球壁上」。听者明明在球心附近、耳离壁只有 64.9 mm，直射声走 64.9 mm 而不是 152.4 mm。按球半径算把直射**少算了 7.41 dB**，会把「混响有多掩蔽」讲得比实际严重一倍。已改成按耳到壁，面板标签也随之写成 `DRR(耳)`，探针新增一条独立复算钉死这个口径（同时打印按 R 会得的错值作对照）。

## 五、球腔声源云：把 N 个源放到球面等分点上

老师原话：

> 「可以把外阵子 N 的点位置设计赤道 3 等分，或 4 点对应 4 面体的顶点，或赤道 5 等分（或类似埃及金字塔的顶点），或者 6 点对应八面体顶点，等等，你可以把柏拉图几何体用上去，在球面放等分点，这样的音效很震撼」

这一节回答的是：**它凭什么震撼，以及哪儿其实不震撼。** 结论先说：

- 球面上等分点不是装饰，它把 ℓ 阶模态**严格**灭掉（不是变小，是零），所以「球里的声音」和「盘上那圈声音」是两种物理。
- 12 个档里只有 **4 档**真能给出左右方位（赤道 3/5 等分、三棱锥、五棱锥，17–21 dB）；**5 档**（赤道 4 等分、正八面体、正立方体、正二十面体、正十二面体）两耳**逐位相同**，任何倾斜都改不了。
- 中间那一档最有意思：**正四面体和四棱锥也不给方位**，但它们**不中心对称**——这直接推翻了本项目里流传过的一句话（见 §5.4）。
- 与「有几根管」**完全无关**：7 根管和一个等效源给出同一条场（§5.7）。

### 5.1 唯一带方向依赖的因子

球腔里，源 `s_i` 对 ℓ 阶模态的贡献是

```
(2ℓ+1)·j_ℓ(k·r_s)·j_ℓ(k·r_e)·P_ℓ(cos γ_i) / (‖j‖²·k²_{ℓs})        γ_i = 源 i 到耳的方向角
```

N 个**同半径、等权、同相**的源求和时，只有最后那个 `P_ℓ` 里含源的位置，而且它能提到求和号外面做的只有一件事：

```
Σ_i P_ℓ(u·s_i)          u = 观察方向（耳）
```

所以「点集设计」唯一能控制的就是这个和。若它对 `0 < ℓ ≤ t` 与**任意** u 都恒为 0，整个 ℓ 阶就被灭掉了。这条性质有名字：

**球面 t-设计**：`Σ_i f(s_i) = N/(4π)∫f dΩ` 对所有次数 ≤ t 的多项式成立。

判据量取

```
E_ℓ = max_u | Σ_i P_ℓ(u·s_i) | / N
```

`E_ℓ ≡ 0` 才是「灭了」。用 `max_u` 而不是随便取个方向，是因为加法定理保证：这个 max 为 0 ⇔ 该阶所有 `2ℓ+1` 个分量全为 0。

🔴 **判据成立的前提三条，少一条那个 t 就是假话**：① 所有点**同半径**（半径不同 ⇒ `j_ℓ(k·r_s)` 提不出求和号）；② **等权**（权重随管变 ⇒ 变成 `Σ w_i P_ℓ`，t 阶不再归零）；③ **同相**（源之间有固定相位差 ⇒ 多一个不被设计覆盖的因子）。这三条决定了后面的实现方式（§5.7）。

### 5.3 表里的零不是偶然

两种机制，都能一行说清：

1. **中心对称**（每个点都有对跖伙伴）：`s → −s` 时 `P_ℓ(−t) = (−1)^ℓ P_ℓ(t)`，奇阶求和整体反号、而集合不变 ⇒ 奇阶全灭。赤道 4 等分、八面体、立方体、二十/十二面体的**所有奇阶**都是这么零的。
2. **赤道正 N 边形**：方位角只有 `m ≡ 0 (mod N)` 的项存活；`m=0` 项里带一个 `P_ℓ(0)`，奇 ℓ 时它为零 ⇒ 奇数阶的零一直保持到 `ℓ = N`。赤道 3 等分的 ℓ=1、赤道 5 等分的 ℓ=1/ℓ=3 就是这一条。

第 3 个可当锚的细节：**金字塔式的 E_ℓ 有精确下界**。取 `u` 沿轴，赤道环全落在 `cos γ = 0`，只有顶点贡献 1 ⇒ `E_ℓ ≥ 1/N`，且奇 ℓ 时恰好等于 1/N。实测：三棱锥 ℓ=1,3 都是 **0.250 = 1/4**，四棱锥 ℓ=1,2,3,5 都是 **0.200 = 1/5**，五棱锥 ℓ=1,3 都是 **0.167 = 1/6**。一条解析值钉住三个档，这比「看起来对」硬。

### 5.4 🔴 两耳相同的真判据：耳轴投影对称

这一节是本轮**推翻自己**的地方，写清楚。

耳在 ±x̂，两耳声压分别是 `Σ_ℓ c_ℓ A_ℓ` 与 `Σ_ℓ c_ℓ (−1)^ℓ A_ℓ`（其中 `A_ℓ = Σ_i P_ℓ(x_i)`、`x_i = s_i·x̂`）。两耳相等 ⇔ **所有奇阶 `A_ℓ = 0`**。而 `P_ℓ` 只依赖 `x_i`、奇 ℓ 时是奇函数，所以

```
{s_i·x̂} 这个多重集关于 0 对称  ⇒  奇阶 A_ℓ ≡ 0  ⇒  两耳逐位相同
```

中心对称只是它的**充分**条件之一。按这条判 11 个档，与实测**一一对应，无一例外**：

| 判据 | 档 | 实测 max\|ILD\| |
|---|---|---|
| x 投影对称（7 档） | 赤道 4 等分、**正四面体**、**四棱锥**、正八面体、正立方体、正二十面体、正十二面体 | 全部 **0.000 dB** |
| x 投影不对称（4 档） | 赤道 3 等分、赤道 5 等分、三棱锥、五棱锥 | 17.20 / 21.25 / 19.82 / 17.27 dB |

🔴 **本项目里流传过三句错话，全部被这张表打死**：

1. **「非中心对称 ⇒ 有方位」是伪定律。** 正四面体的 x 分量是 `{+,+,−,−}/√3`，成对 ⇒ 两耳完全相同（7 个频率全 0.000 dB）。四棱锥同理（`{1,0,−1,0,0}`）。我第一版探针只挑了 4 个"配合"的点集就把这条写成了定律——**那是自证，不是验证**。
2. **「中心对称 ⇒ 两耳恒相同」是对的，但不能反推。** 探针 §5 那 25 组（5 个中心对称点集 × 5 个倾斜角）残差 7.71e-15 依然成立。
3. **「低于门限频率就没有方位」是错的。** 门限灭的只是**远场多极矩**；两耳之间还差一样东西——源在半径 R 上、耳不在球心，各源到耳的 `1/r` 距离本来就不同，这部分不进 `P_ℓ` 展开、灭不掉。实测赤道 3 等分（t=1、门限 1197 Hz）在 100 Hz 仍给 **−3.84 dB**。所以面板只报「哪些阶被严格灭」，一个字都不提「无方位」。

顺带说清「为什么 t=0 反而最像有方位」：t=0 意味着连 ℓ=1 都没灭，最低阶（偶极）活着，所以低频就有方向性；反之 t=5（二十面体）把 ℓ≤5 全灭，只剩 ℓ≥6，低频极其"糊"——**t 越高越像点声源（全向），t 越低越有方位**。这与"柏拉图立体更高级所以更好听"的直觉正好相反。

不过 t=0 那三档（金字塔式）的 ℓ=1 是**纯轴向**的：`Σ s_i = ẑ ≠ 0`，水平方向分量为 0 ⇒ 给不出左右，只给得出「头顶有东西」。面板里写成「ℓ=1 仅存轴向」。

### 5.5 倾斜 0–90°：谁是方位开关，谁白拖

点集绕世界 y 轴倾斜。**倾斜不改变 t**（球面设计在旋转下不变；探针 90 格，最大残留 2.19e-15），它只改「两耳是否相同」。实测 11 档 × 6 个角：

| 行为 | 档 | 数据 |
|---|---|---|
| **倾斜白拖** | 赤道 4 等分、正四面体、八面体、立方体、二十/十二面体 | 6 档全场 ≤ 0.5 dB；正四面体最大 **0.15 dB** |
| **方位开关** | 四棱锥·金字塔 | 0.00 → 7.55 → 6.39 → 10.24 → 11.64 → **11.99** dB |

正四面体为什么"白拖"也值得一句：它在 xz 平面的投影本身**中心对称**，绕 y 转多少度 `{(c+s), (c−s), −(c+s), −(c−s)}` 都成对，所以除了一帧量化残差，倾斜对它真的无效。四棱锥相反：顶点在轴上，一倾就被带出对称面。

🔴 **「90° 就全向」也是伪定律。** 赤道 3/5 等分转到 90° 确实归零（整个环落进"到两耳等距"的那个平面，这是**退化**），但三棱锥/五棱锥在 90° 仍有 **8.09 / 13.91 dB**——顶点还在轴上。两个数一对比就知道「90° 回零」只属于纯赤道环。

### 5.7 合成场与管数无关（这是最关键的一条实现决定）

N 个等权同相源在耳处的合成压是

```
(1/N) · Σ_i H(s_i → 耳)
```

——**一个复数和**。所以云档不需要 N 条音频链：算出这一条合成场，每根同频管拿同一组参数、幅度按 `1/n` 均分，整档总和恰好等于它。**7 根管 = 1 个等效源**，物理一致。

🔴 第一版是「管 i → 第 `i mod N` 个云点」。默认只有 7 根内管，N=12 时有 5 个点没源 ⇒ 点集根本不是 t-设计，实测 ILD 3.36 dB（应为 0）。**点集的 t 是整集的性质，不能一片一片分给管**。改成整集合成之后，管数、管长、管径、材质一律不影响这个 t。

🔴 **合成顺序不能反**：必须「先把 N 个源**相干**相加 → 再对 7 个抖动点做功率平均」。反了就等于假装各源互不相干，整阶的归零会被完全抹掉——数值上还能跑，只是那个 t 变成了假话。

⚠️ 代价：每次 `N × 7 × 2` 次模态和（N=20 时 280 次 × 579 模态）。所以按「频率 | 上限 | 云档」做缓存，`spaCavGeo` 只在切档/转头/改参时跑，不在每帧跑。

### 5.8 画面上怎么认

球腔 3D 里，24 根管子仍画在原位（腔体里的实物），云点是**单独一层**：先算投影与最近点距 `dmin`，再连"棱"——凡距离 ≤ `1.35 × dmin` 就连一条。这个阈值对所有柏拉图立体成立：同立体的棱等长，对跖对（距离 2）永远落在阈值外；金字塔式的顶点到腰点 1.414、腰点之间 1.732（1.225 倍），1.35 把两种棱一起收进来。

像素判据（不是"看着有"）：按管位档 **0** 个青像素（不干扰既有画面）；5 个档 54 / 120 / 136 / 289 / 299 像素；正二十面体是正四面体的 **5.4 倍**；近侧亮心占 45%（远近层次真画出来了，不是一堆同样淡的点）。

⚠️ 写探针时我犯过一个错：判「像素数随点数单调」。八面体 120 像素 vs 立方体 136 像素——**像素 = 点数×点面积 + 棱数×棱长 + 抗锯齿/遮挡**，6 个点画 12 条棱比 8 个点画 12 条棱还暗。换成三条不会误判的：每档 ≥ 点数×6、12 点档 > 4 点档×2、近侧亮心占比 > 15%。

## 六、卷积混响：只给瞬态，稳态**不能**再卷一次

第 15 轮我写的是「混响**时间响应**（早期反射、尾巴）：**没有**，RT60 只被用来折模态带宽」。第 16 轮加了真卷积混响（`IR` 由**同一套模态**生成），但有个必须先说死的边界。

### 6.1 边界：稳态单频不能再卷积

球腔那套解析解

```
H(f) = Σ A / (1 − r² + i·r/Q)
```

**本身就是这条链路的稳态响应**，里面已经含了混响——模态的有限 `Q` 就是衰减。再拿由它生成的 IR 去卷积一次，等于把每个模态的 `Q` **平方**，混响时间直接砍半。那不是「加混响」，是**重复计入**。

所以卷积只用于**瞬态**（起振、换挡、点击试听）——瞬态才有「稳态解给不出的尾巴」。对纯正弦，卷积路径与解析路径**必须逐位一致**，而这正好是可以做的判据。

### 6.2 IR 怎么造

每一阶是一个二阶谐振子的冲激响应：

```
h_k(t) = C_k · sin(ω_k t) · e^{−σt}          σ = π·bw = 42.23 1/s
```

⚠️ **所有模态的 σ 相同**（`bw` 与 f 无关，见 §4.3），才能提出公因子 `e^{−σt}`。若哪天把 `bw` 改成与 f 相关，这条就崩，必须逐模态各带一个包络。

要求 `ℱ[h_k]` 逐阶等于解析模态项：

```
ℱ[h_k](ω) = C_k·ω_k / (ω_k² − ω² + 2iσω)
解析       = A·P·ω_k² / (ω_k² − ω² + 2iσω)        （分母同口径 ⇔ Q = ω_k/2σ）
⇒  C_k = A·P·ω_k
```

### 6.3 四个坑，全是「有混响、不报错、听着像那么回事」

**① 幅度多乘一个 `ω_k`（写成 `A·P·ω_k²`）。** 峰值归一化会把整体音量抹掉，所以「响度不同」永远看不出来；留下证据的只有**谱形**。最低模 745 Hz 到 12 kHz 上限，`ω` 差 16 倍 ⇒ 等于给谱加了 16 倍倾斜。实测 2 kHz 与 6 kHz 的「IR/解析」比值相差 **360 倍**（5.3e-5 vs 1.9e-2）。

**② 少乘两个 `ω_k`（写成 `A·P/ω_k`）。** 同一个比值从 **+998%** 一路漂到 **−76%**。两次都是「试听脉冲听着挺像混响」。

**③ 归一化除以 `hpk` 而不是 `hpk·sr`。** `magAt` 算的是**连续时间**谱 `X(f)`；`ConvolverNode` 卷的是**离散**样本，其 DTFT 与连续谱差一个采样率因子：`DTFT(f) = (1/T)·Σ_n X(f − n/T)`，奈奎斯特内就是 `X(f)/T`。少了 48 kHz，离散增益比解析值大 **48000 倍**——实测「max|H| 归一到 48062 而不是 1」，试听脉冲是一声爆响。

**④ 归一化按小时域峰值。** 第 15 轮的写法是「归一化到峰值 0.5」。两个毛病：① 电平随 RT60 漂（同一套模态换个混响时间音量就变）；② 一个 0.24 s 的 IR 把峰值顶到 0.5，拿 1.5 ms 脉冲去卷 ≈ `Σ|click|·0.5` 的爆音。

所以改成按**频域峰值**：

```
max_f |H_IR(f)| = 1       两耳共用一个常数
```

这等于「把球腔传递函数的绝对增益标成 1」，而且这条**本身可验**（探针 §9 直接查，实测 `1.0013 @ 748 Hz`，归一后时域峰值 `2.40e-2`，安全）。两耳必须共用同一个常数——各自归一会把 ILD 抹平，而 ILD 才是双耳的全部意义。

### 6.4 验证：IR 的 DFT 必须还原解析 H

| 判据 | 实测 |
|---|---|
| `max_f \|H_IR(f)\|`（240 点对数网格） | **1.0013**（判据 ≤2%） |

## 七、五个坑：每个都「看着对、其实是错的」

这一节是这篇文档真正的价值。五条都是本轮实测踩出来的，不是推演。

### 坑 1 · 归一化里漏了 `1/k²_{ℓs}` ⇒ 级数怎么加都不收敛

物理项是 `1/(k²_{ℓs} − k²)`。若为了省事写成

```js
A = (2l+1)*jS*jE / (m.I * (1 - (f/m.f)**2))     // ❌
```

等价于**悄悄乘了一个 `k²_{ℓs}`**，把高阶模态按 `k²` 加权。收敛速度从 `Σ1/s⁴` 掉到 `Σ1/s²` ⇒ 怎么抬高频率上限都不收敛。

实测：模态上限 6 kHz → 48 kHz，`|R|` 从 3.9e4 漂到 1.5e5，ILD 在 4.8 ~ 14.5 dB 之间乱跳。

```js
A = (2l+1)*jS*jE / (m.I * kk * kk)              // ✅ kk = 2πf/c
```

改后 6 档上限对照：≥18 kHz 与 48 kHz 的参考一致到 `|L| 0.18% / ILD 0.16 dB / 相位 0.04°`。

**教训**：错的不是符号，是归一化。量纲看起来都对，级数就是不收敛。

### 坑 2 · 漏掉均匀模（k=0）

模态表从 `x = 4.4934` 开始扫，漏掉了 `k = 0` 那一项（`ψ ≡ 1`，整个腔一起压缩）。它在密封腔里**真实存在**，且 `f → 0` 时按 `1/k²` 发散，最终支配全场。不补它，低频 ILD 不收口。

系数必须与 (ℓ,s) 项**同口径**——那批项把角向归一里的 `1/(4π)` 提到了外面没写：

```js
var A0 = -3/(4*Math.PI*R*R*R*kk0*kk0);        // ✅ 带 4π
```

🔴 第一次写成 `−3/(R³k²)`（漏 4π，差 12.6 倍），把 400 Hz 的 ILD 从 `+5.67 dB` 掰成 `−10.2 dB`——**比不加还错**。

修正后的低频收口（教科书极限：`f→0` 时波长 ≫ 腔尺寸 ⇒ 腔内是均匀压力场 ⇒ 两耳必须相同）：

| f | ILD | 判据 |
|---|---|---|
| 20 Hz | **−0.46 dB** | ≈ 0 ✅ |
| 40 Hz | **−1.89 dB** | 小 ✅ |
| 745.6 Hz | 0.02 dB（相位 178.6°） | ℓ=1 共振：电平相同、严格反相 ✅ |
| 400 Hz | +4.37 dB | 近场开始起作用 |
| 900 Hz | −9.28 dB | 多模干涉 |

「745.6 Hz 电平差 0.02 dB 但相位 178.6°」这一条特别有说服力：它同时验证了「ℓ=1 是偶极、两耳对称」和「奇偶律没写反」。

### 坑 3 · 球 Bessel 的数值：两段老办法都不行

| 办法 | 失效区 | 现象 |
|---|---|---|
| 幂级数 | `√(2ℓ) < x < ℓ` | 灾难性相消，正负项抵消到 1e-20 量级 |
| 上升递推 | `x ≈ ℓ` | 误差按 `(e·x/2n)^n` 爆炸，只是**勉强**稳定 |

后果不是「精度差一点」，而是**造出成百上千个假零点**：ℓ=57 报 **751 个「模态」**，而那里 `|j′|` 高达 **0.55**，根本不可能是零点。假零点让归一化 `(1 − ℓ(ℓ+1)/x²)` 趋 0 ⇒ 单项爆炸，模态求和一度冲到 **7.6e13**。

最终分三段：

```js
function jlSafe(l, x){
  if (l < 0) return Math.cos(x)/x;
  if (x < 1e-12) return l === 0 ? 1 : 0;
  if (l === 0) return Math.sin(x)/x;
  if (x > 1.6*l + 2) return jlUp(l, x);        // 远处：上升递推（稳且便宜）
  return jlMillerN(l, x);                      // 过渡带：Miller 反向递推
}
```

导数同理，**必须走同一个 `jlSafe`**：

```js
j_ℓ′ = j_{ℓ−1} − (ℓ+1)/x · j_ℓ        // 两项都不能用发散的 jlS
```

效果：模态表从「n=6903、ℓ 到 65、ℓ=57 有 751 个」变成「**n=579**、每 ℓ 平滑递减、`max|j′| ≤ 1.94e-16`」，页面初始化从 2076 ms 降到 **60 ms**。

### 坑 4 · Web Audio 的 `lowpass` 把 `Q` 按 **dB** 解释

```js
bq.Q.value = 0.5;      // ❌ 本意是线性 Q=0.5
```

实测：线性 Q = `10^(0.5/20)` = **1.0588** ⇒ 截止频率附近出现 **+1 dB 共振峰**。

后果非常具体：**被头挡住的那只耳反而更响**。同侧/对侧判反，实用 ILD 变成 `+1.30 dB`（应为负）。

改 Butterworth（`SPA.qdb = −3.0103` ⇒ 线性 `1/√2`）后才无峰。

### 坑 5 · 确定性起振错开，把相干场搅成随机和

原来每根管这样起步：

```js
o.start(t + i * 0.000731);     // ❌ 等于给同频 7 根管灌任意初相
```

同频 7 根管本该相干叠加，错开 0.731 ms 却等于随机化初相 ⇒ 左耳 `|Σ| = 0.10`，而单根是 `0.5 ~ 1.5`。

改统一 `o.start(c.currentTime + 0.012)`。`sin(0) = 0`，同时起步不会「啪」。

## 八、耳体积平均：点耳会坐在节点上

点耳（一个数学点）在某些频率正好落在驻波节点上，会读出 **37 dB** 的假「单侧」。物理上耳朵有尺寸，所以取 `jit = 12 mm` 的 7 点体积平均：

- **功率取能量平均**：`√mean|H|²`
- **相位取相干平均**：`arg Σ H`

扫频起伏从 48 dB 降到 **22.4 dB**。剩下的 22.4 dB 是真实的模态干涉，不是数值噪声——判据要放在「会出问题那一档」，所以 `ILD(f)` 的断言按「球内 ≫ 盘外」写，不按绝对阈值写。

## 九、怎么把它变成声音（单频 ⇒ 无近似）

管是单频正弦，所以复数增益可以**精确**拆开，不需要任何滤波器近似：

```
|H|  → GainNode.gain
∠H   → DelayNode.delayTime = (−∠H / 2πf) mod (1/f)
```

单频下「延时」与「相位」是**恒等**的，不是近似。所以渲染出来的耳间相位/电平可以拿解析模型逐位对——实测：

| 项 | 误差 |
|---|---|
| 耳间相位（6 组） | **< 0.06°** |
| ILD（6 组） | **< 0.049 dB** |
| 两档电平对齐 | **−0.06 dB** |

切档靠**耳增益交叉淡化**（0.25 s），不是改延时（改延时会爆音）。

### 10.4 🔴 本轮最贵的一条：**判据测的是机器，不是页面**

全仓并行跑（每批 4 个 Chrome）时，`_probe_traj` 报 7 项红、`_probe_orbit` 报 1 项红、`_probe_part` 报 2 项红：

```
✗ 外摆：转角 ≈ 360°·t/T（±20%）   295.3° vs 392.2°
✗ 实时角速度不低于设定值的 80%      wR=22.198
✗ 实心盘 p50 ≥ 25                  p50=22.0
```

单跑复验：`part` 立刻 **33/33 全绿**（亮度是分布量，掉帧时砂还没铺开），`traj` 降到 4 红，`orbit` 仍 1 红。再往下查，根因只有一个：

```
主循环   var dt = Math.min(0.05, 帧间隔)
本机 headless 软件渲染实测 17.8 fps ⇒ 帧间隔 ~56–68 ms ⇒ 每帧只积分 50 ms
⇒ 动画按墙钟的 0.74–0.83 走；而判据拿的是**墙钟**
```

`22.07 / 30 = 0.736` 正好是这个比值。60 fps 时夹取不生效、两者相等 —— 也就是说**这条判据测的是机器快慢，不是页面对错**。它不是"放宽一点就能过"的问题，是判据的**时间基准选错了**。

修法（不是调阈值）：

1. 页面暴露两个时钟：`wt = Σ min(0.05, 帧间隔)`、`wraw = Σ 帧间隔`，外加 `LFPS`（用**原始**帧间隔算的 EMA）。
   ⚠️ 顺便发现面板那个 `cFps` 读数用的是**夹取后**的 dt ⇒ 掉帧时高估帧率（17 fps 显示成 20）。已在注释里写明两者不许混用。
2. `traj` 采样改成「凑够 **12 s 模型时间** 才停」，峰值间隔也用模型钟。
3. `orbit` 改断**积分恒等式** `wR = wM · (Δwt/Δwraw)`：总量 ≤2%、逐段 ≤12%（一段 400 ms、一帧 40 ms ⇒ 边界量化上界 10%）。

修后：`traj` **59/59**、`orbit` **27/27**、`part` **33/33**，且都是单跑与串行跑一致。

⚠️ 这条教训有两个连带发现，都记在 §5.9：`_probe_orbit` / `_probe_traj` 测的是**7 节点页**不是我一直在改的 Keely 页（改探针前先看 `PAGE` 常量）；以及 §6b 第一版把 `chk()` 的两个参数写反了 ⇒ 恒真式，靠「标签印成 `true`」才看出来。

### 🔴 另一条老教训：精度不够的「独立复算」等于伪证人

第一版探针拿 **Simpson 8000 点积分表示**复算 `j_ℓ` 当裁判，把**正确**的 `jlSeries`（与 60 位真值差 1e-14）判成「183 组全错，最大相对差 1.512 @ ℓ=15, x=2.5」。

查证：`j₂₀(2) = 7.63e-20`，Simpson 算出 `−1.62e-11`——**符号都反**。积分绝对误差底噪 ~1e-16，把小量级的值整个吞掉。

所以加了 §0b **裁判自检**：先用 60 位 Decimal 真值验裁判自己。**「独立」不是「随便换个算法」，是「换一个精度足够的算法」。**

其他几条探针自坑（都记下来，免得再犯）：

- `Math.atan2(pL.re, pL.im)` 参数顺序写反 ⇒ 凭空 95° 偏差 ⇒ 把「渲染与模型完全一致」判成 33 FAIL
- `Math.abs(biquadLP(...).re)` 只取实部 ⇒ 90° 相位点算成 0 ⇒ 盘外报「≤24 dB」
- `let iW` 声明在 `{}` 内、外面引用 ⇒ `ReferenceError`
- 扫频走点耳 `cavH` 而非 `cavAt` ⇒ 48 dB 假起伏
- `__ch.spatial()` 按 `toFixed` 交数 ⇒ 探针用 1e-9 容差复算判成「67/67 全错」= **舍入假红** ⇒ 全部改全精度交出

## 十一、明确不成立 / 没做的

按铁律，写清边界：

| 项 | 状态 |
|---|---|
| 盘外 HRTF：**球面衍射** | **成立**（第 16 轮）。Rayleigh 刚性球精确解，两个解析极限逐位对上 |
| 盘外 HRTF：**耳廓（pinna）/ 耳道 / 躯干散射** | **不成立**。刚性球没有耳廓凹槽，所以**前后镜像分不出、俯仰分不出**（后者见 §3.1）。面板已写死 |
| 仰角的头部相关滤波 | **部分**。刚性球解里 `γ` 含仰角 ⇒ 有真实的仰角依赖；但没有耳廓，所以「前上 / 后上」仍然同声 |
| 头部转动 / 双耳动态 | **成立**（第 16 轮），yaw + pitch，Shift+拖。⚠️ pitch 对 ILD/ITD **严格无影响**（耳在旋转轴上），不是 bug |
| 混响**时间响应**（早期反射、尾巴） | **部分**。球腔档有真卷积混响（IR 由同一套模态生成），但**只用于瞬态**；稳态单频再卷一次 = 把 Q 平方（§5.1）。盘外档**不做**——盘子上方没有房间 |
| IR 里的**早期反射**（离散墙面反射） | **没有**。球腔是「模态展开」，IR 是 147 个衰减正弦的和，不是几何声学的镜像源。球腔太小、模态太稀（745 Hz 以下一根根），镜像源法在这里不适用 |
| 听者**移动**（不是转头） | **没有**。`SPA.lisY/lisZ` 是常量，只有朝向可变 |
| 壁面弹性 / 球壳共振（结构声） | **没有**。刚性壁假设，`α=0.05` 是一个取值而非实测 |
| 球内两耳「前后分不出」 | **仍然分不出**。球心处两耳只在左右轴上有差别；`P_ℓ(−x)` 只给出同相/反相，不含前后信息 |
| 多普勒 / 管本身在动 | **没有**。管位置静态 |
| **辅助音频（轨迹 `TAUD` / 挂挡 `AAUD`）走双耳链** | **没有**。它们仍是 `StereoPanner` 一维。本轮的处置是：**球腔档下 `trajPan()` / `autoPan()` 强制回 0**——与其拿「盘面的左右」冒充「球内的耳间差」，不如不做方位。要真做，得让 `spaCavAt` 能吃「沙粒位置」（它现在只吃管索引），已列为挂账 |
| 「这个声场听起来像真的在球里」 | **未验证**。我能证的是模型与渲染一致、极限行为正确，听感请老师过目 |
| 球面等分点「音效很震撼」 | **部分成立、口径要看清**。7 个点集是**完美全向**（两耳逐位相同 ⇒ 方位为零、只剩包裹感）；4 个点集才有 17–21 dB 方位。**"哪个更震撼"是听感，不在这里下结论** |
| 「低于门限频率就没有方位」 | **不成立**（本轮证伪）。门限灭的是远场多极矩；近场 `1/r` 几何不在 `P_ℓ` 展开里。实测赤道 3 等分在 100 Hz 仍给 −3.84 dB |
| 「非中心对称 ⇒ 两耳不同」 | **不成立**（本轮证伪）。正四面体、四棱锥都是反例（ILD = 0.000 dB）。见 §5.4 |
| 「90° 倾斜就全向」 | **不成立**（本轮证伪）。只有纯赤道环会退化归零；带轴顶点的金字塔在 90° 仍有 8.09 / 13.91 dB |
| 云点是 **N 条独立音频链** | **没有，也不需要**。整档是**一条合成场** `(1/N)Σ H(s_i→耳)`，每根管拿同一组参数按 `1/n` 均分。好处是管数无关，代价是听不出"12 个离散声源"（那是另一个做法，本页没做） |

> 关于辅助音频那一条，探针 §9b 是**双向**判的：球腔档必须恰好为 0，盘外档必须真的随相位走
> （设 `phIn=0, relPh=0`，扫 `phOut = 0 / π8 / π4 / 3π8` ⇒ `cos(8·phOut)` 必须给 `+1/−1/+1/−1`，
> 实测最大偏差 **0**）。只判「球腔档是 0」不够——画面静止时 `D ≡ 0`、`cos D ≡ 1`，光看几拍
> 采样会「恰好通过」，把「pan 根本不依赖相位」也判成绿。

## 十二、自己复算

页面把全部中间量挂到了全局 `__ch`（F12 控制台可直接调）：

```js
__ch.spatial()                    // R / f1 / RT60 / rc / rEar / drr / 579 个模态 / 盘外逐管 / 球内逐管
__ch.cavH(1843, 0.3, +1)          // 球内复数增益：f, 耳横向偏移 ux, 耳 ±1
__ch.cavAt(1843, 3)               // 第 3 根管、耳体积平均路径（面板/渲染用的就是这条）
__ch.cavConv(1843, 3, [6000,12000,18000,24000,36000,48000])   // 收敛自检
__ch.jl(7, 5)                     // 球 Bessel
__ch.jlp(7, 5)                    // 球 Bessel 导数
/* ── 第 16 轮新增 ── */
__ch.hrtf(9000, 1, -1)            // 刚性球散射精确解：f, cosγ_左, cosγ_右 ⇒ |H|、∠H、x、N
__ch.setHead(0.6, 0.15)           // 转头（弧度）：yaw 绕 z，pitch 绕耳轴
__ch.head()                       // 两耳 / 前 / 上 的实际向量
__ch.irSamples(0.35, -0.35, 48000, 0.25)   // 球腔 IR 的样本（探针拿它自己 DFT，不听页面结论）
__ch.irInfo()                     // 上次构建的 IR 元数据（n / len / sig / RT60 / fcap / 峰值）
__ch.click()                      // 试听脉冲（返回 ok / cgL / cgR / vol / ir）
__ch.auxPan()                     // 辅助音频的一维 pan 现值（球腔档必须为 0）
/* ── 第 17 轮新增（源云 / 柏拉图立体）── */
__ch.cloudList()                  // 12 个档：id / 名称 / 群 / 表 t / 点数
__ch.cloudPts('ico12')            // 点集坐标（单位球）；第二参 tilt（弧度）
__ch.cloud()                      // 当前云：n / t / cen / mirX / tiltInert / cnt / even
__ch.cloudInfo('tetra4')          // 任一点集的静态信息（不依赖当前选中档）
__ch.cloudSet('octa6', 0)         // 切档 + 倾斜（弧度）
__ch.cloudLobe('ico12', 5, 0,0,1) // Σ_i P_ℓ(u·s_i)/N —— t-设计的定义量（面板的 t 唯一出处）
__ch.cloudGate(5)                 // 第 6 阶门限：{ l:6, x:7.851078, f:2811.9 }
__ch.cloudField('pyr4', 1843)     // 合成场：gs / ph / ts / ild / N；第 3 参 lOnly，第 4 参 tilt
```

要验「t 是真的」，`__ch.cloudLobe(id, ℓ, u)` 对任意 u 都必须为 0（ℓ≤t）；要验「两耳相同」，`__ch.cloudField(...).ild` 必须是 0 —— **而 `cen` 与 `mirX` 会告诉你"为什么"**：`cen=false, mirX=true` 就是正四面体那种情况（不中心对称、却因耳轴投影对称而两耳相同）。

要验「级数真收敛」，改 `cavConv` 的上限数组看 `|H|` 是否稳；要验「奇偶律」，把第二参数（耳符号）取 +1 / −1 比相位差是否 180°。
要验 HRTF 对不对，只看两个端点：`__ch.hrtf(50,1,1).magL` 必须 ≈ 1，`__ch.hrtf(20000,1,1).magL` 必须 ≈ 2。**中间任何一个频点"看着合理"都不能说明什么。**

页面里凡是运行时算的量都**不写死**：面板显示的数、探针断言的数、`__ch` 交出的数，三者同源。改公式只需改一处。

### 13.1 第 17 轮加的三行（源云）

| 行 | 内容 | 点一下 |
|---|---|---|
| 源云（球腔档） | 档名：`按管位` / `赤道 3 等分` / `正四面体` / … | 循环切 12 档 |
| t-设计 · 灭到 ℓ | `t=5 灭ℓ≤5 ·f6₁2.81k`；t=0 时写 `t=0 · ℓ=1 仅存轴向` | — |
| 点集倾斜 · 两耳 | 角度 `30.0°`，每点 +15°，>90° 归零 | 绕世界 y 转点集 |

三行都只在球腔档可用，其它档写 `球腔档才生效` / `t=—（按管位，不抑制）`。

🔴 **这里改掉过两句"格式正确但内容是错的"话**，都是同类问题：判据跟着实现变，屏幕没跟着变。

1. `ILD` 那行的尾巴原来写 `· 中心对称` / `· 镜像对称`。对**正四面体**这两个词都是假的——它既不中心对称，也不关于 x=0 镜像对称，两耳却完全相同。现在只写 `· 两耳相同`（这是 `ildSyn` 那个数自己说的，永远真），原因放进按钮 `title`。
2. `t=0` 那格原来写「仅ℓ=1轴向灭」，**说反了**：ℓ=1 是"只剩轴向"（水平分量为 0），不是"轴向被灭"。
3. 倾斜按钮的 `title` 原来按 `cen` 分支，会说「中心对称 ⇒ 倾斜无效」。现在按 `mirX` / `tiltInert` 分三种：**拖也白拖**（5 个中心对称 + 正四面体）/ **一倾就出方位**（四棱锥）/ **当前已有方位**。

还有一处**已删掉**的假信息：`⚠ 24∤N`。那是第一版「管 i → 第 i mod N 个点」时的判据（点数必须整除管数才等权）。现在云档是整集合成场、与管数无关，那句话就成了"屏幕上的一句错话"。连同 `spaPanel` 里那段注释一起删。
