## 0. 一句话结论

**能反推的：是哪个模式（n,s），以及它相对基模的倍数（j/j₀₁）。**
**不能反推的：绝对 Hz。** 不是算不出来，是**缺一个标定量**——膜半径 R 与波速 c=√(T/σ)
都没有记录，书上一个数字也没有。给 R 和 c，Hz 立刻出来；不给，就只能给倍数。

## 1. 先更正边界条件：这是**膜**，不是板

| | 板（p.55 那 40 格） | 膜（p.48 这 15 格） |
|---|---|---|
| 装置 | 金属板，中心支顶，**四周自由** | eidophone：空心腔 + **绷紧的膜**，边缘夹紧 |
| 边界条件 | 弯矩=0、剪力=0 → J<sub>n</sub>′(kR)=0 | 位移=0 → **J<sub>n</sub>(kR)=0** |
| 零点 | j′, j′<sub>0,1</sub>=**3.8317** | j, j<sub>0,1</sub>=**2.4048** |
| 色散 | ω ∝ **k²**（弯曲波） | ω ∝ **k**（张力波） |
| 频率式 | f = k²/(2π)·√(D/ρh) | **f = j·c/(2πR)** |
| 需要的材料量 | E、ν、ρ、h（板厚） | **只** T、σ（等效成 c 一个量） |

差 37% 的零点，加上"k² 还是 k"的色散，两套数字不能互换。
上一版网页对这 15 格用了 j′，**是错的**，这一版已改（§02 里"夹紧边"勾选）。

## 2. Hz 的唯一式子

```
f(n,s) = j(n,s) · c / (2πR)          c = √(T/σ)
```

- `j(n,s)`：J<sub>n</sub> 的第 s 个零点，**只由模式决定，是硬数**
- `c`：膜上的横波速度（m/s）
- `R`：膜半径（m）

换算成"倍数"更好用：

```
f(n,s) / f(0,1) = j(n,s) / 2.4048      ← 不依赖 R、c，也不依赖她唱了哪个音
```

**这一列才是"反推"真正能给出的东西。**

## 5. 标定怎么定：两条可行的路

**路 A（有实物，最硬）**
1. 量出膜半径 R；
2. 用信号发生器扫频，找出基模（整片同相、中心振幅最大）那一点的频率 f₀；
3. `c = 2πR·f₀ / 2.4048`，全表立即可算。

**路 B（只有照片，只能估）**
1. 照片里若有一个已知尺寸的参照物（管子直径、手指、硬币），先估 R；
2. 按橡胶膜的量级取 c ≈ 20–40 m/s（0.2 mm 乳胶大约在这个区间；膜越紧、越薄，c 越大）；
3. 得到的是一个**区间**，不是一个数。本页默认值就取这个区间的中段（34.2 m/s）。

**不要做的事**：拿"她唱的是 C 大调"直接当 f₀。书上只写了 "sang diatonic scales"，
没写哪个调、没写哪个八度。任何"她唱的是 C3"都是加进去的假设，不是读出来的事实。

## 6. 为什么这一套"唱音阶"会出这 15 张图

膜的泛音**不是整数倍**（这是鼓不成调的原因）。前 12 个模之间的间隔（音分）：

```
(0,1)→(1,1)  +806     (1,1)→(2,1)  +507     (2,1)→(0,2)  +125
(0,2)→(3,1)  +251     (3,1)→(1,2)  +164     (1,2)→(4,1)  +136
(4,1)→(2,2)  +179     (2,2)→(0,3)  +48      (0,3)→(5,1)  +23
(5,1)→(3,2)  +185     (3,2)→(6,1)  +31
```

**关键的两处**：`(2,2) → (0,3)` 只差 **48 音分**，`(0,3) → (5,1)` 只差 **23 音分**——
都**不到一个半音**。也就是说：

- 她唱一个音，如果正好落在密集区，**可能同时激起两个模**，拍出来的就是"两族花纹叠在一起"的杂图；
- 如果落在稀疏区（如 (0,1)→(1,1) 的 806 音分空档），**中间一大段音都激不起清晰图样**；
- 15 张图之所以排不出漂亮顺序，就是因为**它们本来就不在一条音阶上**。

这解释了第 1 格那条 S 形螺旋：两个 (1,s) 简并模被同时激起、相位差 90°，拍出来就是旋转的螺旋。

## 7. 书上有没有频率可以校对？

**没有。** p.48 的说明文字只写了装置、粉、以及 "sang diatonic scales"，**一个频率数字都没有**。
所以我上一版说"顺便验证书上标的频率对不对"，是**没核过原书就许的诺**，这里更正：

- 能对的：**图样**（是不是 8 条、几层环）；
- 对不了的：**数值**。哪怕给了 Hz，也没有可比的另一列。

如果老师手上有那本书的后续页（有些版本会给 Watts Hughes 的图配"她唱到哪个音"），
