# 七瓣摆线为什么看起来不对称 —— 成因、反证与复算

> 对象：`AAA_克拉德尼_7节点三振子_响应式.html` → 沙粒「轨迹形态」示意档（`S.traj = 1` 外摆 / `2` 内摆）
> 触发问题：*「02_epi.png 里摆线看起来非对称，是因为那 7 根管 / 7 音阶不是同一个音导致的吗？」*
> 一句话答案：**不是**。与七管、与七音阶、与板模态**一点关系都没有**；不对称 100% 来自
> 「引导圆半径按 11 s 呼吸胀缩」与「七个瓣在时间上等间隔出现」这两件事撞在一起。
> 全部数字由 `_diag_sym.cjs` 现场跑出（Chrome + CDP 真跑页面，不是手算）。

---

## 0. 结论先行

| 说法 | 判定 | 依据 |
|---|---|---|
| 七根管音高不同 ⇒ 摆线不对称 | **不成立** | 换掉耦合口径 / 板模态 m / 七管频率，601 个预演点**逐位相同**（§2） |
| 七音阶跨度 15/8 不是纯八度 ⇒ 不对称 | **不成立** | 同上；预演点根本不含任何频率量 |
| 呼吸（11 s 内外胀缩）⇒ 不对称 | **成立，且是唯一原因** | 呼吸摆幅 0 ⇒ 七个瓣尖半径**完全相同**（极差 0.01%，§3） |
| 不对称是「随机抖动 / 越跑越歪」 | **不成立** | 是一组**冻结的固定梳齿**，每个周期一模一样（§4） |

七管、七音阶、板模态在这一档里**根本没有参与运算**：示意档是一条解析式，
入参只有 `{瓣数 N, 局部摆幅 a, 呼吸摆幅 A_b, 呼吸周期 T}` 四个量，没有频率、没有 m、没有管。

## 1. 先把「不对称」量出来

做法：把预演曲线（601 点）按极角分成 N 段，取每段最大半径 = 该瓣的瓣尖半径；
再算七瓣的极差与相邻瓣的角间隔。**不看图，只读数。**

示意档默认参数：`N = 7`、局部摆幅 `a = 0.12 R`、呼吸摆幅 `A_b = 0.10 R`、`T = 11 s`。

| 工况 | 七瓣瓣尖半径（R） | 极差 | 相对 | 角间隔（理想 51.43°） |
|---|---|---|---|---|

| **[B] 关呼吸 Ab=0** | 0.6200 ×7 | **0.0000 R** | **0.01%** | 51.4 51.6 51.4 51.4 51.4 51.6 51.4 |
| [C] 加大呼吸 Ab=0.25 | 0.6246 0.4112 0.2524 0.2788 0.4670 0.6676 0.7358 | 0.4834 R | 98.4% | 54.0 51.4 43.5 53.7 53.3 52.0 52.2 |
| [D] 小摆幅 a=0.05 | 0.6219 0.5353 0.4858 0.5137 0.5960 0.6690 0.6802 | 0.1944 R | 33.2% | 51.7 52.1 52.1 51.9 51.1 50.4 50.7 |
| [E] 大摆幅 a=0.28 | 0.6206 0.5370 0.5033 0.5458 0.6315 0.6957 0.6909 | 0.1924 R | 31.9% | 51.3 49.3 51.1 51.3 52.4 52.2 52.4 |
| [F] 内摆 默认 | 0.6210 0.5484 0.5414 0.6057 0.6912 0.7342 0.7034 | 0.1928 R | 30.4% | 53.2 53.4 53.2 50.3 50.5 49.2 50.3 |
| [G] 内摆 Ab=0 | 0.6200 ×7 | 0.0000 R | 0.01% | 51.8 50.4 51.8 51.8 51.8 50.4 51.8 |

两条一眼可读的结论：

1. **只要 `A_b = 0`，七个瓣尖就完全相等**（[B]、[G]：极差 0.01%，已到数值噪声）。
   所以不对称不是「画歪了」「渲染问题」，而是**呼吸这一项**造出来的。
2. 改 `a`（[D]、[E]）几乎不动极差（0.1944 / 0.1924 vs 默认 0.1945）——
   说明**局部摆幅不是主因**，主因只有 `A_b`；这也解释了为什么把「循环」调大调小都觉得没救。

## 2. 反证：换掉七管 / 七音阶 / 板模态，预演点一个都没动

如果不对称真来自「七根管的七音阶不是同一个音」，那么**换掉音高就该换掉图形**。
于是逐个改，比 601 个预演点（全量，不是抽样）：

| 改什么 | 具体动作 | 601 个预演点 |
|---|---|---|
| 耦合口径 | `mouth`（1/4λ）→ `waist`（活段 L/2，音高 ×2）→ `mq3`（×4/3） | **逐位相同** |
| 板模态 | `m = 3`、`m = 25` | **逐位相同** |
| 七管频率 | 音阶 / 律制 / 管长全变（当前七管 233.1…437.0 Hz） | **逐位相同** |

> 这一条是硬证据：**同一条曲线，逐位相同**，不是「看起来差不多」。
> 换成一句话：这一档里根本没有「频率」这个输入。

**顺带澄清一个可能的误会**：有人会觉得「七根管频率不同 ⇒ 七根管的驱动强弱不同 ⇒ 七重对称破了」。
在当前默认几何下这条也不成立 —— 七根管都在 `r = 0.770 R`，而 `m=7, s=1` 的腹点在 `0.7737 R`，
所以七根的径向耦合 `g` **全都是 1.000**（管表里那一列可查）。音高只改 `L = c/(4f)` 与管质量
（最长 372 mm / 最短 198 mm，质量比约 1.88:1）。质量差理论上会破缺对称，
但本页的负载模型是**把七根的质量加成一个总量**进一阶扰动 `Δf/f`，
它只改板频，不进沙粒轨迹。**两条路都不通向「瓣大小不等」。**

## 3. 真因：呼吸调制 × 七瓣在时间上等间隔

### 3.1 方程

示意档的曲线是两条旋转的叠加（页面「说明栏」里就是这一行）：

```
P(t) = R(t)·ê(ω_c·t + φ) + a·ê(ω_l·t + φ)
R(t) = ρ + A_b·sin(2πt/T)          引导圆半径 —— 就是「内外呼吸」
ω_c  = 2π/T                          引导圆心绕盘 1 圈 / 呼吸周期
ω_l  = ∓k·ω_c                        外摆 k = N−1（反向）；内摆 k = N+1（同向）
```

写成复数一目了然：

```
z(t) = e^{iωt}·[ R(t) + a·e^{−i(k+1)ωt} ]
```

**方括号里第二项以 `(k+1)ω` 转** ⇒ 整条曲线有 `N = k+1` 重对称。
**但第一项 `R(t)` 是以 `ω` 转的、而且还带着 11 s 的正弦调制。**
当 `R` 是常数时，`R + a·e^{−iNωt}` 严格 N 重对称（[B] 实测 0.01%）；
一旦 `R` 开始以 `ω` 呼吸，这个 N 重对称就被打破 —— 因为**七个瓣出现在不同的呼吸相位上**。

### 3.2 七个瓣各自落在哪个呼吸相位

曲线在一个 `T` 内重复 N 次（N 个瓣），所以第 i 个瓣尖出现在

```
t_i = i·T/N          ⇒      呼吸相位 = 2πi/N
```

于是七个瓣尖半径必然是一条正弦的**七点抽样**：

```
r_i = ρ_eff + A_b·cos(2πi/N − φ)
```

实测拟合（最小二乘，N=7）：

| 工况 | 拟合振幅 | 相位 | 最大残差 |
|---|---|---|---|
| 默认 `A_b = 0.10` | **0.1000** | 102.3° | **0.00052 R** |
| `A_b = 0.25` | **0.2497** | 78.6° | 0.00376 R |
| `A_b = 0` | 0.0000 | — | 0.00003 R |

**拟合振幅 = 设定的呼吸摆幅**（0.1000 vs 0.10），残差 5e-4 R。
这就是「不对称」的全部内容：**不是七个数乱掉，是一个正弦被抽了七下。**

所以形状是**可预测**的：想让哪一瓣最大，把呼吸相位 `φ` 转到那个瓣上就行；
峰值与谷值之比固定 ≈ `(ρ_eff + A_b)/(ρ_eff − A_b)` ≈ 0.635 / 0.435 ≈ 1.46（默认档实测 1.44）。

### 3.3 为什么角间隔也会偏（50.4°–52.0°）

瓣尖的**半径**在变，瓣尖的**极角**也会跟着挪一点：局部圈把尖顶推出去的方向
随 `R` 变，投影到极角上就有一个小偏移。实测偏离理想值 51.43° 最多 ±0.8°；
把呼吸加到 0.25（[C]）时偏离放大到 ±5°（43.5°–54.0°）。这与极差同源，不是第二个原因。

## 4. 它是「冻结」的，不是「越跑越歪」

呼吸周期与引导圆的旋转周期**共用同一个 `T`**（`ω_c = 2π/T`），所以每个 `T` 之后
相位关系完全复原 ⇒ 图形是**一组冻结的梳齿**，这一圈与下一圈逐位相同。
不是随机抖动，也不是慢慢漂移。

> 这一点对判断很重要：如果看到「这一帧和下一帧形状不一样」，那是渲染/取景的问题，不是模型在漂；
> 反过来说，既然它冻结，就不能靠「多跑一会儿等它匀过来」来解决 —— 它永远不会自己匀。

## 5. 附带发现：「8 个小圈」其实是 7 个 + 接缝

外摆档（`k = 6`，7 瓣）数出来的小圈是 **8** 个，看着像多了一个。
把每个小圈的起点极角打出来：

```
20°, 73°, 123°, 174°, −134°, −82°, −30°, 22°
```

首尾两个 **22° 与 20°** 是同一个圈 —— 它横跨了曲线的 `t = 0` 接缝，被数组切成了两段。
**真实的环数 = 7**，与瓣数一致。内摆档（7 瓣）数出来正好 7 个（接缝恰好落在 0° 附近，没被切）。

> 这类「接缝重复计数」在环形数据上很常见：判周期结构时要么首尾闭合、要么按角度去重，
> 直接数「负向极角区段」必然多算一个。

## 6. 想要「对称的瓣 + 还在呼吸」，三条路（含代价）

| 方案 | 怎么做 | 结果 | 代价 |
|---|---|---|---|
| **A. 关掉呼吸** | 呼吸摆幅 `A_b = 0` | 七瓣完全相等（实测极差 0.01%），只剩「七瓣绕圈」 | 丢掉老师要的「内外呼吸」，退回普通摆线 |
| **B. 让呼吸与瓣同频**（推荐） | 把呼吸角频率改成 `ω_b = N·ω_c`，即 `R = ρ + A_b·sin(N·2πt/T)` | 每个瓣都落在同一个呼吸相位 ⇒ **瓣尖全等**，而两瓣之间的路径依然内外胀缩（呼吸还在，只是每瓣呼吸一次） | 呼吸的「听觉/视觉周期」变成 T/N（默认 11/7 ≈ 1.57 s），不再与 11 s 的板呼吸同步；这一档本来就是几何示意，与板无关，所以物理上不吃亏，但**与「11 s 呼吸」的叙事脱钩** |
| C. 保留现状，把它当「签名」 | 不动 | 图形是**确定**的：`r_i = ρ_eff + A_b·cos(2πi/7 − φ)`，可复算 | 需要接受「七个瓣不一样大」这个事实并写进说明 |

方案 B 的数学验证（一行）：把 `R(t) = ρ + A_b·sin(Nωt + φ)` 代入 `t_i = iT/N`，
得到相位 `2πi + φ ≡ φ`（mod 2π）⇒ 七个 `R(t_i)` **完全相同** ⇒ 七个瓣尖全等，
而 `t` 在 `(t_i, t_{i+1})` 之间时 `R` 仍在变 ⇒ 呼吸的视觉还在。
**本页目前**是方案 C（保留现状）；要切 B 只改 `buildGhost()` 与 `stepSand()` 里
`KT.Ab*Math.sin(S.trajT*KT.wc + S.trajPh0)` 这一处的频率系数（`KT.wc → KT.wc*N`），
两处必须同改，否则「预演虚线」与「实走轨迹」立刻分家。

## 7. 复算方法（任何人都能重跑）

```
node _diag_sym.cjs
```

脚本做四件事（全部在真实页面上跑，不是离线模型）：

1. 对当前档取 601 个预演点，按极角分 N 段取每段最大半径 = 瓣尖；
2. 输出极差 / 相对极差 / 相邻角间隔；
3. 逐个关掉可疑因素（`A_b`、`a`）重测；
4. 换耦合口径、换板模态 m、换音阶，比对 601 个点是否**逐位相同**。

关键自查口（页面内）：`__ch.ghostPts()`（全量预演点）、`__ch.trajPlace(r, θ)`（把追踪粒摆到指定半径/角）、
`__ch.trajA(v)` / `__ch.trajB(v)` / `__ch.trajN(v)`（三个参数）。

## 8. 边界（这份文档不回答的）

- 示意档**不是**物理结论：它不从声辐射力 / 板场梯度推出来，页面三处（chip title、读数卡、
  说明栏）都标了「不生效（纯运动学）」。问「真实沙粒往哪走」要切回物理档。
- 物理档里**确实**有「内外呼吸」：实测单粒 `r/R` 在 0.527–0.784 之间随 11 s 来回，
  但累计转角只有 **3.0 °/s**（摆线必须有切向分量，这里没有）—— 所以物理档画出来是来回线，
  不是摆线。见归档 §8.33。
- 七管的音高**不影响**这一档，但它影响别的量：管长 `L = c/(4f)`、管重、辐射效率 `σ=(ka)²/2`、
  与板模态的失谐 `δ`、以及七根之间**能听见的最慢拍**。这些在「声学耦合」节里有各自的读数，
  与轨迹是两码事。
