# 最优腹点 R 的公式与推导（2026-10-24 换真实板模型）

## 一、公式

$$\boxed{\ \rho_* = \frac{j'_{m,s}}{j_{m,s}}\ }$$

- `j_{m,s}`：贝塞尔函数 `J_m` 的第 s 个零点 —— 相当于「尺子的刻度」，1 格 = 1 个波谷
- `j'_{m,s}`：`J_m'` 的第 s 个零点 —— 「到山顶」的那一格（山顶处斜率为 0，所以用导数零点）
- 两者相除 ⇒ 把「第几格」换算成「占半径的百分之几」，结果恒在 0~1，乘 R 就是毫米

**大白话**：圆盘抖出某个花纹时，抖得最猛的那一圈，在半径的百分之几处。

推导三步：
1. 点力做的功 = F·W(ρ) ⇒ 耦合系数 ∝ 该点的模态位移 |W(ρ)|
2. 要耦合最大 ⇒ 最大化 |W|
3. dW/dρ = 0 ⇒ 对 W = J_m(j_{m,s}ρ) 就是 J_m'(j_{m,s}ρ) = 0 ⇒ ρ = j'_{m,s}/j_{m,s}

## 二、与材料无关（尺度不变）

分子分母同量纲，一除就没了。材料、厚度、大小只改**频率**：
`f ∝ (h/R²)·√(E/ρ)`。换成铝，只是音高变了，花纹位置一点不变。

类比吉他弦：换粗细只换音高，不换「弦分成 2 段还是 3 段」的形状。

管材料、管径完全不进这个公式（管只当负载，改变的是 Δf/f 与辐射效率 σ=(ka)²/2）。

## 三、⚠️ 但这个公式有个前提，而 Keely 的盘不满足

`W = J_m(k r)` 是**膜**（∇²W = −k²W）的解，隐含「外缘夹死」（W(R)=0）。
Keely 的盘是**板**（∇⁴W = k⁴W），**外缘自由** ⇒ 边缘弯矩为 0、位移不受约束。

两者方向相反：

| 模型 | s=1 腹点 | 盘沿 g |
|---|---|---|
| 膜（外缘夹死） | m=7: **0.7737** / m=8: **0.7892** | **0** |
| 板（外缘自由，真） | m=7: **1.000** / m=8: **1.000** | **1.000** |

独立复算（RK4 打靶，`_calc_ode.py`，步长 N=400/800/1600 三档同值，ν=0.33）：
解 `W = J_m(kx) + A·I_m(kx)`，`A` 由弯矩 = 0 定，`k` 由「弯矩 = 0 + 等效剪力 = 0」的 2×2 行列式 = 0 定。

**标定**：m=0 给出 kR = 3.01146，经典值 3.0115（差 0.001%）。
**α 敏感性**：内孔夹紧 α=0.05…0.25 根不变 —— m≥1 的模态在圆心附近本就不动。

**挖空这一条踩了三轮**（都是「看着改了其实没改」）：

## 八、一条必须说清的事实（不替页面圆场）

本页默认档（β=0.55 螺旋在）下，砂**并不形成 7 条节径**：七重角向矩 `m7 ≈ 0.04`（1 = 全挤在节径上，
0 = 角向均匀）。也就是说「砂堆节线」这件事只在把螺旋压下去、且沙粒档的梯度权重为 1 时才成立。
所以两档在画面上的差别，主要来自：① 中心真挖空 ② 孔内点改画小尘埃 + 压暗
③ 法向汇聚只剩 45% ⇒ 低振幅带堆积明显更松（实测 3–30 个百分点的波动区间，方向稳定、幅度不稳）。
`m7` 和 `lowFrac` 都只当**诊断量**打印，不当断言 —— 图案一直在转、4 s 内到不了稳态，
同一配置两次跑的直方图能完全反过来，拿单帧阈值下结论就是假绿。
