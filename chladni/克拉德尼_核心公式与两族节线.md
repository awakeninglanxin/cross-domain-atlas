## 0. 一句话

振动板的花纹 = **板的本征函数**的节线（位移恒为 0 的曲线）。
本征函数的形式由坐标系是否可分离决定，所以**方盘与圆盘是两族不同的函数**，
不是"同一个解换个边界形状"。

---

## 1. 薄板方程：为什么是 k 的四次方

克拉德尼实验里的板是**薄板**（厚度 h ≪ 边长 L，通常 h/L < 1/50）。它的横向位移 w 满足
Kirchhoff–Love 双调和方程（自由振动、无外载）：

```
D·∇⁴w + ρh·∂²w/∂t² = 0
```

其中弯曲刚度

```
D = E·h³ / [ 12·(1 − ν²) ]
```

E = 杨氏模量，ν = 泊松比，ρ = 密度，h = 厚度。

设 `w = W(x,y)·e^(−iωt)`，得

```
∇⁴W − k⁴W = 0 ，   k⁴ = ρh·ω² / D
```

**关键**：`k⁴` 而不是 `k²`。于是

```
ω = k²·√(D/ρh)          ← 板弯曲波是"色散"的，ω ∝ k²
f = k²/(2π)·√(D/ρh)
```

对比弦/膜：`ω = c·k`（线性、无色散）。**这一条差别，是"板"和"鼓"所有不同的源头**——
鼓（膜）的泛音不是谐波，板的更不是（板的频率差得比鼓还多）。

### 数值常数（钢）

| 量 | 值 |
|---|---|
| E | 200 GPa = 2.00×10¹¹ Pa |
| ν | 0.30 |
| ρ | 7850 kg/m³ |
| √(D/ρh) = h·√(E/[12(1−ν²)ρ]) | h × **1.528 m²/s** |

例：h = 1 mm → √(D/ρh) = 1.528 m²/s。

## 2. 方盘：两个余弦的乘积，加还是减

矩形板在直角坐标下可分离：`W = X(x)·Y(y)`，边界为自由边时严格解是
`cos·cosh` 的组合，但**图样的拓扑**用下面的驻波模型就能完整复现（这是所有教学页面的做法）：

```
W(x,y) = cos(nπx)·cos(mπy) ± cos(mπx)·cos(nπy)
```

x, y ∈ [−1, 1]（已按半边长归一），n, m = 1, 2, 3…

- **和式（+）**：节线呈"网格"，横竖两组近直线交叉，全部延伸到板边。
- **差式（−）**：节线呈"斜十字 + 边缘弧"，同样都通到板边。
- **n = m 时差式恒等于 0**：两项逐点相消，`W ≡ 0`，**整块板不振**。
  这就是所有 5×5 图版里对角线必须涂灰的原因。
- **(n,m) 与 (m,n) 同图**：和式逐字对称；差式交换后整体变号，而花纹只看 `|W|`，故相同。

### 节线数

`cos(nπx)` 在 (−1,1) 内恰有 **n 个零点** → n 条竖节线；`cos(mπy)` → m 条横节线。
所以 **n、m 就是两个方向的节线条数**，可以直接数图验证。

### 频率（简支近似）

```
k = π·√(n² + m²) / L        （L = 边长）
f ∝ n² + m²
```

自由边会有一个与 n,m 有关的修正项（cosh 项带来的），**趋势不变、绝对值偏低**。
本页正文里已声明这是"理论值"。

## 3. 圆盘：贝塞尔，不是正弦

极坐标可分离：`W = R(r)·Θ(θ)`，角向给 `Θ = cos(nθ)`（n = 0,1,2…，周期性要求），
径向给**贝塞尔方程**：

```
R'' + R'/r + (k² − n²/r²)·R = 0   →   R(r) = J_n(k·r)
```

`J_n` 是第一类贝塞尔函数。**它不是正弦**：振幅衰减、零点间距不均（越往外越密）。

### 边界条件决定用哪套零点

| 边界 | 条件 | n=0 的第一个零点 | 物理对应 |
|---|---|---|---|
| **自由边（free）** | `J_n′(kR) = 0` | j′₀,₁ = **3.8317** | **金属板**：中心顶住、四周自由（书 p.55 那 40 格） |
| **夹紧边（clamped）** | `J_n(kR) = 0` | j₀,₁ = **2.4048** | **绷紧的膜**：边缘被压死（书 p.48 那 15 格，eidophone） |

**这是复现图版时第一个会踩的坑**：用错成 `J_n(kR)=0`，圈数会多一圈，
而且"整板上下拱"那个模态会直接消失。反过来，把膜当板算，频率会整体偏高约 1.6 倍。

> **2026-10-18 更正**：书 p.48 那 15 张圆花是 **Margaret Watts Hughes 用 eidophone（绷膜 + 侧管）** 拍的，
> 所以那 15 格属于**夹紧边的膜**，用 `j`；p.55 的 40 格是方板，用 `j′`。
> **一张书页里同时出现两套零点**，这是最容易看漏的地方。
> 另外膜的色散是 `ω = c·k`（线性），不是板的 `ω ∝ k²`——见 §"膜与板是两套式子"。

实现方式（页内 40 行，无任何库）：

```
J_n(x) = Σ_{k≥0} (−1)^k /(k!(n+k)!) · (x/2)^(2k+n)      // 幂级数，n≤6、x≤40 时相对误差 ~1e-15
J_n′(x) = [J_{n−1}(x) − J_{n+1}(x)] / 2                // n=0 时用 −J_1
零点：从 x=0.04 起以 0.02 步长扫符号变化，再二分 80 次
```

**注意**：n ≥ 2 时 `J_n′(0) = 0`，原点本身就是一个零点。扫描必须从 r > 0 开始，
否则会把 k = 0（整板刚体平移，无花纹）当成第一个模态。

### 节圆数 vs 径向阶 s

`s` 是"第 s 个正零点"，**不等于**节圆数。实际节圆数 = `J_n` 在 (0, kR) 内的零点个数：

| | s=1 | s=2 | s=3 |
|---|---|---|---|
| n=0 | 1 圆 | 2 圆 | 3 圆 |
| n=1 | 0 圆 | 1 圆 | 2 圆 |
| n=2 | 0 圆 | 1 圆 | 2 圆 |
| n=3 | 0 圆 | 1 圆 | 2 圆 |
| n=4 | 0 圆 | 1 圆 | 2 圆 |

**n=0 那一列整体错开一位**，原因是 J₀ 的第一个零点（2.4048）落在 j′₀,₁ = 3.8317 之内，
而 J₁…J₄ 的第一个零点都大于各自的 j′ₙ,₁。所以第一列是"纯圈"（1/2/3 圈），
其余各列是"0/1/2 圈 + n 条辐条"。**这不是 bug，是贝塞尔函数的性质**。

## 4. Chladni 经验定律 vs 精确值

书上常见的经验式：

```
f = C·(m + 2n)²        m = 节直径数，n = 节圆数
```

它是**经验拟合**，不是解。注意两个坑：一是公式里的 n 是**节圆数**（不是上面的径向阶 s）；
二是常数 C **每块板、每种边界都得重拟**。

把 `(n+2c)²`（c = 实际节圆数）与精确的 `j′²` 并排，比值 `f/(n+2c)²`：

| n 辐条 | s | j′ | c 节圆 | f = j′² | (n+2c)² | 比值 |
|---|---|---|---|---|---|---|
| 0 | 1 | 3.8317 | 1 | 14.68 | 4 | **3.67** |
| 1 | 1 | 1.8412 | 0 | 3.39 | 1 | **3.39** |
| 2 | 1 | 3.0542 | 0 | 9.33 | 4 | 2.33 |
| 3 | 1 | 4.2012 | 0 | 17.65 | 9 | 1.96 |
| 4 | 1 | 5.3176 | 0 | 28.28 | 16 | **1.77** |
| 0 | 2 | 7.0156 | 2 | 49.22 | 16 | 3.08 |
| 1 | 2 | 5.3314 | 1 | 28.42 | 9 | 3.16 |
| 2 | 2 | 6.7061 | 1 | 44.97 | 16 | 2.81 |
| 3 | 2 | 8.0152 | 1 | 64.24 | 25 | 2.57 |
| 4 | 2 | 9.2824 | 1 | 86.16 | 36 | 2.39 |
| 0 | 3 | 10.1735 | 3 | 103.50 | 36 | 2.87 |
| 1 | 3 | 8.5363 | 2 | 72.87 | 25 | 2.91 |
| 2 | 3 | 9.9695 | 2 | 99.39 | 36 | 2.76 |
| 3 | 3 | 11.3459 | 2 | 128.73 | 49 | 2.63 |
| 4 | 3 | 12.6819 | 2 | 160.83 | 64 | 2.51 |

**读法（这才是本表的价值）**：
- 比值不是常数，而是落在 **1.77 – 3.67**，跨一个因子 2.1。
  说明**没有哪一个 C 能把 15 个模态同时套住**。
- 在同一列 c 内，比值随 n **单调缓降**（c=0：3.39 → 1.77；c=1：3.16 → 2.39；
  c=2：2.91 → 2.51）。这不是"差一个常数"，是**两条曲线的形状本来就不同**——
  经验式在高 n 端偏"陡"，精确值偏"缓"。
- c 越大，比值越平（c=2 那三行 2.87/2.91/2.76/2.63/2.51，起伏只有 15%）。
  所以经验式对**多圈模态**比对**纯辐条模态**好用。

**结论**：
- `C(m+2n)²` 可以用来**排序**、估数量级、讲"为什么图案越复杂音越高"；
- **不能**用来反解频率，更**不能**从频率反推模态号；
- 若非要拟合，必须按 c 分族给不同的 C（c=0 一族 C≈1.8–3.4，c=2 一族 C≈2.5–2.9，
  这个 C 本身还随 n 漂）。

## 5. 频率换算速查（钢，1 mm 厚）

`f = k²/(2π) × 1.528`

| 情形 | 参数 | k (1/m) | f (Hz) |
|---|---|---|---|
| 方盘 300 mm, n=m=1 | k=π√2/0.3 | 14.80 | 53 |
| 方盘 300 mm, n=m=5 | k=π√50/0.3 | 104.72 | 2666 |
| 圆盘 Ø300, j′₀,₁ | k=3.8317/0.15 | 25.54 | 159 |
| 圆盘 Ø300, j′₄,₃ | k=12.6819/0.15 | 84.55 | 1736 |
| 圆盘 Ø300, j′₅,₄ | k=17.3128/0.15 | 115.42 | 3235 |

**厚度只改音高不改图样**：`f ∝ h`，h 从 1 mm 到 3 mm 频率 ×3，节线位置一个像素都不动。
要改图样，只能改驱动频率去命中**另一个模态**。

## 5b. 膜与板是两套式子（p.48 与 p.55 必须分开算）

同一张书页上并排放着两种实验，物理量却完全不同：

| | 板（p.55，40 格） | 膜（p.48，15 格） |
|---|---|---|
| 回复力 | 抗弯刚度 D | 张力 T |
| 色散 | `ω = k²·√(D/ρh)` | `ω = k·√(T/σ)` |
| 频率 | `f = k²/(2π)·√(D/ρh)`，**要板厚** | `f = j·c/(2πR)`，`c=√(T/σ)`，**只要 c 与 R** |
| 零点 | j′ | j |
| 泛音间距 | 越往上越疏（k² 律） | 均匀（k 律），但**不是整数倍** |
| 音高随尺寸 | `f ∝ 1/L²` | `f ∝ 1/R` |

**两条最实用的推论**：

1. **板缩小一半，频率 ×4；膜缩小一半，频率 ×2。** 这是判断"这两个峰是不是同一个模态"最快的办法。
2. **膜只要一个材料参数 c**（T/σ 合成一个数），所以对膜"反推 Hz"的门槛比板低——
   但代价是 c 本身必须靠标定，照片给不出来。具体做法见 `克拉德尼_反推模态号与Hz_方法.md`。
