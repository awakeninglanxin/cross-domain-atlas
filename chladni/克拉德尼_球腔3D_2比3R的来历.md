## 一、先说结论（三句话）

1. **2/3 R 在球形场里算得出来**：最低阶纯径向呼吸模 ℓ=0, s=1 的径向推力峰在 **0.662586 R**，与 2/3 = 0.666667 相差 **0.61%**（12 英寸球上 1.24 mm）。
2. **换回 2D 圆盘这个数就没了**：同一个量（推力最强那圈）在 2D 盘上是 **0.7656 R**，与 2/3 差 **14.8%**。所以老师「2/3R 建立在 3D 球形场」这句是对的。
3. **但 2/3 不是「四面体密堆积」解**：四球两两相切、球心成正四面体，得到的是 **0.550510 R**，与 2/3 差 **17.4%**。「胶子球」这个想法在几何上完全自洽（间隙球只有夸克球的 22.5%），只是它给出的数不是 2/3。

## 二、推导：ℓ=0, s=1 的径向推力峰

球腔驻波（刚性壁，Dirichlet）：

```
u(r,θ) = j_ℓ(k r) · P_ℓ(cos θ),     k 由 j_ℓ(kR) = 0 定，取 R = 1
```

最低阶 **ℓ=0, s=1**（纯径向「呼吸」，整个球一起胀缩）：

```
j₀(x) = sin x / x,      j₀(k) = 0  ⇒  k = π
u(r)  = sin(πr) / (πr)
∂u/∂r = −π · j₁(πr)                        （因为 j₀′(x) = −j₁(x)）
```

推力最强的那层球壳 = `|∂u/∂r|` 的极大 = `|j₁|` 的极大。

`j₁` 的第一个极大在 **x\* = 2.08157598**（解 `tan x = x/(1 − x²/2)`，也就是 `j₁′(x) = 0` 的那个根），于是

```
ρ* = x* ÷ π = 2.08157598 / 3.14159265 = 0.6625862 R
```

与 2/3 = 0.6666667 比：

```
相对偏差 = −0.612%      12 英寸球（304.8 mm）上 = 1.24 mm
```

**0.61% 在工程上就是同一个圈。** 这也解释了 Keely 原件为什么把内环定在「12 英寸球的 2/3 球径」——他量的是球，不是盘。

## 三、为什么 2D 圆盘算不出这个数

**关键在于比的是同一个物理量。** 这一页原来混用过两个量，必须分开：

| 量 | 定义 | 2D 盘 m=0, s=1 |
|---|---|---|
| **位移腹点** | `\|J_m(kr)\|` 最大 | 纯膜：**0**（盘心）；本页真实板 `pkPlate()`：**1.000**（盘沿） |
| **推力峰** | `\|dJ_m(kr)/dr\|` 最大 | **0.7656**（`j′₁,₁ ÷ j₀,₁ = 1.84118378/2.40482556`） |

拿「位移腹点」去比 3D 的「推力峰」，会得出「2D 是 0」这种错结论 —— 我第一版就是这么错的，探针当场抓出来（`planPeak(0,1)` 返回 1.0 而不是 0）。

正确的对照：

| | 推力峰 ρ | 与 2/3 的差 |
|---|---|---|
| 2D 圆盘 m=0, s=1 | **0.765621 R** | **+14.84%** |
| 3D 球腔 ℓ=0, s=1 | **0.662586 R** | **−0.61%** |
| 两者相差 | **0.103034 R** | |

**压成圆盘偏了整整一成。** 这就是老师说「2/3R 是建立在 3D 球形场」的量化含义。

## 四、球的物理意义：为什么是「呼吸模」

ℓ=0 的场只依赖 r，不依赖 θ：

- 球心 `u = 1`（最大），球壁 `u = 0`
- `|u|` 无内部零点 ⇒ **没有内部节球面**，粒子不会被「困」在某一层
- 但 `|∂u/∂r|` 在 0.6626R 处最大 ⇒ **那一层球壳被推得最狠**

所以「最强推力球壳」和「振幅最大处」在球腔里是**两层不同的球面**：振幅最大在球心，推力最大在 0.66R。这一点在 2D 盘上不一样（2D m=0 的振幅最大也在中心，推力最大在 0.7656R）。

页面的径向曲线（右下信息卡）画的就是 `|∂u/∂r|` vs `r/R`，三条竖线分别是：

- 紫虚线 `0.550510R` —— 四球全相切（老师假设）
- 金点线 `0.666667R` —— 2/3
- 金实线 `0.662586R` —— 推力峰（与 2/3 几乎重合，这就是重点）

## 五、老师的四面体假设：算它给多少

### B1 四球全相切（最紧，球心成正四面体）

四个半径 r 的球两两相切 ⇒ 球心构成边长 2r 的正四面体。

```
球心到重心     = 2r · √6/4 = √(3/2)·r = 1.2247449 r
外接球（刚好包住）= (√(3/2) + 1)·r      = 2.2247449 r
⇒ 球心距  ρ = √(3/2)/(√(3/2)+1)        = 0.5505103 R
⇒ 每球半径 r = 1/(√(3/2)+1)             = 0.4494897 R
```

**中心那个间隙球**（Kepler 四面体间隙，正是老师说的「胶子」）：

```
r_c = (√(3/2) − 1)·r = 0.2247449 r = 0.1010213 R
⇒ 胶子球只有夸克球的 22.47%
```

这个几何**完全自洽**：**四个**球撑开四面体（每个顶点一枚），中心塞进一个五分之一大小的胶子球。
四球体积占比 0.3633。

> 🔴 **2026-10-24 老师指正后的更正**：原文写「**三个**夸克球撑开四面体」是**错的** ——
> 四面体有 4 个顶点，撑开它必须 4 个球。3 个等球两两相切、又都贴壁时，球心只能落在
> **赤道面**上成一个等边三角形（`r₃ = 1/(1+2/√3) = 0.464102 R`、`ρ₃ = 0.535898 R`、
> 体积占比 0.2999），**三个球心围出的体积恒为 0 ⇒ 撑不出四面体**。
> 物理上的「3」是**颜色数**（r/g/b），几何上的「4」是**顶点数**，两个数没有关系，不能互相套。
> 页面「夸克 / 胶子球」组的第 1 颗 chip 就是这个反例（拖视角就能看出是平的一片）。

### B2 / B3 另外两种构型（对照用）

| 构型 | 约束 | ρ | 球半径 | 体积占比 | 三球互相切? |
|---|---|---|---|---|---|
| B1 四球全相切 | 最紧 | **0.550510** | 0.449490R | 0.3633 | 是 |
| B2 三球贴壁 + 两两相切 | 无中心球 | 0.535898 | 0.464102R | 0.2999 | 是 |
| B3 精确 ρ=2/3 | 反解 | **0.666667** | 0.333333R | 0.1481 | **否**（留 0.488R 缝） |

**B3 值得单说**：把 2/3 当已知反解，得到的是「四个**一样大**的 R/3 球，三个贴壁、一个居中」。这时三球**互不相切**（球心间距 1.1547R，而直径只有 0.6667R，缝 0.488R）。所以精确 2/3 对应的是「四球等大」而不是「密堆积」，体积占比只有 0.1481，比密堆积松 59%。

### 结论

```
四面体密堆积 ⇒ 0.550510 R，与 2/3 差 −17.42%   ← 不是 2/3 的来源
球腔基模     ⇒ 0.662586 R，与 2/3 差 −0.61%    ← 才是
```

但两个数**不冲突**，它们量的是两件事：

- **0.5505R** = 几何上「最多能塞多大」
- **0.6626R** = 波场里「推得最狠」

页面上紫圈（密堆积）明显在金圈（推力峰）**之内**，一眼能看出来。

### 1. 视图三档，`v ? 1 : 0` 会把 2 吞成 1

```js
TUBE.view = (v === 2 ? 2 : (v ? 1 : 0));
```

手势要按档取各自的相机：

```js
function viewCam(){
  if (TUBE.view === 2) return SPH;
  if (TUBE.view === 1) return TUBE;
  return null;

```

### 2. 🔴 `j_ℓ′(0)` 是 ∞−∞，不是 0

```js
function jlpS(l, x){
  if (Math.abs(x) < 1e-12) return l === 0 ? 0 : (l === 1 ? 1/3 : 0);
  return jlS(l - 1, x) - (l + 1)/x*jlS(l, x);
}
```

不特判的话，径向渐变从 `rr=0` 取色会得到 `rgba(255,196,110,NaN)` ⇒ `addColorStop` **抛异常** ⇒ 整幅只剩背景（实测亮度一路 9.8，球根本没画出来）。

### 3. 🔴 同心圆画法在正交投影下必然变成靶心

第一版按 34 条同心球壳逐条描边 —— 正交投影下球壳本来就投影成同心圆，结果整幅是靶心，毫无球感。

改成 **radial gradient 连续填充** + **加强经纬线**（近侧 0.44、远侧 0.12，整组 clip 在球内）+ 轮廓线 + 左上高光。

### 4. 🔴 中心柔光会把径向分布整个盖反

第一版有个以球心为原点的金色柔光（内亮外暗），实测球心 34.7 > 推力峰 24.2 —— 正好相反。删掉后：球心 18.3 → 0.35R 41.0 → **0.6626R 101.4** → 球壁 42.8，单峰，峰位就是 ρ*。

### 5. 🔴 白点不能按「砂」的规则推

第一版用 `a = −sgn(u)·∇u`（干砂规则）。ℓ=0 的力纯径向向外、没有内部零点 ⇒ 620 个点**全部塌到 r=0.985 的球壁上**（实测 `r∈[0.9850, 0.9850]`，散布 0.0000R），画面上是个空壳。

物理上正确的改法是**换身份**：白点是示踪粒子，跟随的是**声速场**（`v ∝ ∇u`），不是被声辐射力推。再乘一个整体振荡 `cos(ωt)`（≈0.35 Hz，慢放）：半周期向外、半周期向内 —— 球腔的呼吸。改完 `r∈[0.226, 0.988]`，散布 0.76R。

### 7. 示踪粒子轨迹：为什么原来「没有」，现在怎么加

> 老师 2026-10-24：「球腔 3D 为何没有示踪粒子轨迹展示呢？」

原来**确实只有当前帧**：620 个白点在呼吸里动（`sphStep` 积分 r/θ + `cos(2.2t)` 振荡），
但一个历史点都没存 ⇒ 画面上看不出「往哪走」。2D 盘面有那条 `TRACE` 橙线，球腔没有对应物 ——
不是漏画一行，是**数据结构上没有承载者**：`TRACE` 是单个粒子的 (x,y)，而球腔是 620 个 (r,θ,φ)。

加的时候有四个取舍，每个都有代价：

| 取舍 | 取什么 | 为什么不取另一个 |
|---|---|---|
| 条数 | **6 条**样本 | 620 条 = 36.8k 段线，本机掉到个位数 fps；而且 u 与 φ 无关 ⇒ 620 条是同一组弧绕轴复制，糊成一片 |
| 坐标 | **世界坐标 (x,y,z)** | 存屏幕坐标的话，视角一转旧点就整体错位；世界坐标每帧重投影，轨迹跟着球转 |
| 时间基准 | **累计模型时间**（每 0.018 s 推一行） | 按调用次数推：主循环每帧调 3 次子步、探针连调 60 次，「历史有多长」会随帧率变 |
| 窗口 | **1.51 s**（84 行）＝ 呼吸的半行程 | 0.72 s（1/4 周期）实测在收缩相只剩 20–30 px 短线；更长会把「来回」叠在一起绕成团 |

#### 🔴 坑 1：轨迹不能用带扩散抖动的 φ

第一版直接把粒子位置的 φ 写进缓冲。实测 1.8 s 后 24 条轨迹**糊成一团白网**，把经纬网格全盖住。
根因：`sphStep` 里 φ 每步有 `(rand−0.5)·2.2·√dt` 的**随机游走**（≈±0.19 rad/步）—— 那是
「亚网格扩散」的替身，不是运动。把它画进轨迹 = 把数值噪声当物理。

改法：φ 拆两半 —— `phs`（种子相位，恒定）+ `phj`（扩散抖动，累积），
显示用 `ph = phs + phj`（保持原来那种气体感的散布），**轨迹只取 `phs`**。
副产品是一条硬判据：ℓ 阶场与 φ 无关 ⇒ 同一轨迹的 (x,y) 叉积必须是**常数**
（实测偏差 7e-9；把 `phs` 换回 `ph` 立刻变成 2.9e-2，差 6 个数量级 —— 变异测试验过）。

#### 🔴 坑 2：等距索引选样本 ⇒ 抽到的粒子根本不动

第一版样本按 `floor(k·620/6)` 取，抽到 r≈0.985 的粒子。
`j_ℓ′(k·R)=0` 本来就是**球壁的边界条件** ⇒ 壁上径向速度恒为 0 ⇒ 轨迹只有 **23 px**
（900 px 画布上 2.5%），屏幕上就是个点 —— 这就是「加了等于没加」。

改法三步：
1. **按半径分 6 层**（让轨迹铺在不同半径上，能看出哪层流得动）；
2. 每层取 **|∇u| 最大**的那个（不是随机、不是平均 —— 平均专挑最没戏的位置）；
3. 层边界用**实际** r 范围（`cbrt` 播种下是 0.27–0.98，写死 0.02 会让最内层永远空），
   并把 r > 0.94 的排除出候选池（那段 |∇u| 极小，是死水）。

实测 6 条样本的半径跨度 0.66–0.99（旧版是 0.985–0.988，几乎没有跨度）。

#### 🔴 坑 3：球在整体呼吸，别拿「某一时刻的轨迹长度」当判据

`osc = cos(2.2t)` 每 1.45 s 过零一次，那一刻**所有**粒子速度同时≈0、轨迹同时缩到最短。
更狠的是：620 个粒子的 `rmean` 实测在 **0.086 ↔ 0.955** 之间周期约 4 s 振荡 —— 这是**整体呼吸**，
不是各自小幅振动。收缩相粒子全挤在球心一小团（截到那一相会以为粒子塌缩了），轨迹也最短；
扩张相粒子才洒满球内。

所以「截一张图看轨迹多长」会随机假红。两件事都按这个改：
- 判据改成**跨 5 次采样（3 s）取最长**：实测 max 167 px；
- 截图脚本等 `rmean > 0.55` 的扩张相再拍（否则拍到的是球心一团）。

同样地，「所有样本都不贴壁」也是**错判据**：呼吸的外推半周期会把粒子推到 r=0.988 停住，
贴壁是真实结果，不是缺陷 —— 这条判据写好后又删掉了。

#### 画出来是什么样

- 颜色**暖白**（255,240,210）：青色是声源云点、金色是 ρ* 与 2/3 标记线，再借哪个都会被读错。
- 三段渐隐（老 0.08 / 中 0.34 / 新 0.80），远侧一律 ×0.55。
- **ℓ=0 时是沿半径的直线**（纯呼吸，φ 与 θ 都不动）；ℓ≥1 才有弯曲的子午弧。
- 轨迹长度**本身就是周期性的**：速度过零时变短。这是呼吸模的真实行为，不做平滑。

### 8. 视角预设：正视图 / 俯视图 / 等角视图

三个角度不是随口给的，按 `sphProj` 的深度式反解：

```
深度 d = (x·sin yaw + y·cos yaw)·cos p − z·sin p
```

| 档 | yaw | pitch | 反解依据 |
|---|---|---|---|
| 正视 | 0 | 0 | 屏幕 (x, −z)、深度 y ⇒ 沿 −y 看，z 竖直朝上 |
| 俯视 | 0 | **−π/2** | 屏幕 (x, −y)、深度 **+z** ⇒ 从 +z 往下看（+π/2 会是**底视**） |
| 等角 | π/4 | **arctan(1/√2) = 35.264°** | 视线 v ∝ (sin yaw·cos p, cos yaw·cos p, −sin p) 要 ∝ (1,1,−1) |

等角那条是被**验出来的**，不是抄的：三根坐标轴的屏幕长度实测 `0.816497 / 0.816497 / 0.816497`
（差 < 1e-9），深度 `0.5774 / 0.5774 / −0.5774`。

#### 🔴 坑 4：俯视在正交投影下必然变成圆盘

pitch = −90° 时球壳被压成正圆，纬线成同心圆、经线成放射线。这是**正确的极投影**，
不是渲染坏了 —— 不要偷偷改成 88° 假装有立体，也不要当 bug「修」。
这个角度的用处是读**方位对称性**（比如声源云在赤道面上的分布、金字塔点集的方位）。

#### 🔴 坑 5：pitch 夹取会把预设弹回去

### 10. 角向阶 m：为什么粒子不转、也没有摆线

老师 2026-10-24 两句话：「为何球腔 3d 的粒子没有旋转的现象」＋「没有摆线运动或特殊运动」。

#### 10.1 不是漏画，是这个模态没有「绕」这个自由度

```
u = j_ℓ(kr) · P_ℓ(cosθ)        （m = 0）
∂u/∂φ ≡ 0   ⇒   v_φ ≡ 0
```

两个层次，第二个更根本：

1. **这一族场与 φ 无关**（轴对称）。620 个粒子 = **620 条互不相交的子午弧**，
   合起来看着就是「整体在呼吸」。它们不会相交、不会绕轴，因为没有任何力推它们转向。
2. **速度场是标量场的梯度** `v ∝ ∇u` ⇒ `∇×(∇u) ≡ 0`，**无旋**。
   而「绕」的本质就是**旋度**。指望一个无旋场自己转起来，一开始就缺了那个量 ——
   这和盘面页得出的结论是同一条（那里也是靠「从外部注入角动量」才画出摆线）。

实测把这条钉死：m=0 时 `gφ` 在 120 个网格点上是**精确的 0**（不是 1e-9），
粒子方位角位移 `phc` 跑满 3 个周期仍然是 **0.0000**。

#### 10.2 m ≠ 0：唯一「真」的转法

换成连带勒让德并让它带行波相位：

```
u = j_ℓ(kr) · P_ℓ^m(cosθ) · cos(mφ − ωt)
∂u/∂φ = −m · j_ℓ · P_ℓ^m · sin(mφ − ωt)      ⇒  gφ ∝ m
```

- `P_ℓ^m` 用递推（Condon–Shortley）：
  `P_m^m = (−1)^m (2m−1)!! sin^m θ`，`P_{m+1}^m = x(2m+1)P_m^m`，
  `P_ℓ^m = [x(2ℓ−1)P_{ℓ−1}^m − (ℓ+m−1)P_{ℓ−2}^m]/(ℓ−m)`。
  与解析式逐点对表：ℓ=1m1 ⇒ −sinθ、ℓ=2m2 ⇒ 3sin²θ、ℓ=2m1 ⇒ −3cosθsinθ、
  ℓ=3m2 ⇒ 15sin²θcosθ、ℓ=3m3 ⇒ −15sin³θ，误差 **7.1e-15**。
- `dP_ℓ^m/dθ` 用恒等式（不做数值微分，省得挑步长）：
  `dP/dθ = −[(ℓ+m)P_{ℓ−1}^m − ℓ·cosθ·P_ℓ^m] / sinθ`（ℓ=1m0 ⇒ −sinθ 校验通过）。
- 按峰值归一：`max|P_ℓ^m| / amax = 1`，切 m 时速度量级不跳。

图样转速 `Ω = ω/m`（ω = 2.2 rad/s，与原来的「呼吸」共用同一个慢放频率）：

| m | Ω | 一圈 | 局部振荡周期 |
|---:|---:|---:|---:|
| 1 | 2.200 rad/s | 2.86 s | 2.86 s |
| 2 | 1.100 rad/s | 5.71 s | 2.86 s |
| 3 | 0.733 rad/s | 8.57 s | 2.86 s |

⚠ **图样一圈是 2.86·m 秒，但把 φ 固定看振荡周期永远是 2.86 s**
（`cos(mφ−ωt)` 里 ω 没变）—— 这两个数经常被混成一个。

验证方式不是「看着像」，而是**转 frame 里场必须站住**：
`u(φ + Ωt, t) = u(φ, 0)` 在 24 个 φ × 15 个时刻上偏差 **1.7e-16 ~ 6e-16**。
对照组把 Ω 故意乘 1.6（偏 60%）⇒ 偏差立刻到 **0.15 ~ 0.42**（这条用来证明上一条不是恒真）。

#### 10.3 但它仍然不是摆线 —— 这一条必须说明白

一阶速度场一个周期的**时间平均几乎为 0**。实测（ℓ=3, m=1）：

| 量 | 1 个周期（2.86 s） | 3 个周期（8.59 s） |
|---|---:|---:|
| max\|phc\|（单粒最大方位位移） | 0.138 rad（7.9°） | 0.210 rad |
| mean\|phc\|（平均） | 0.020 rad | **0.049 rad** |
| 净环流档 mean\|phc\| | 1.119 rad | **3.427 rad** |

⇒ 不开环流档：**摆幅夹住、不累积** ⇒ 轨迹是**闭合花瓣**，不是摆线。
摆线要有「净环流」，那是**二阶量**（Rayleigh streaming，∝ v²/ωa，比一阶小两个量级以上）。

所以页面给两个 chip：`角向阶 m`（真实物理）＋`二阶声流`（**示意档，默认关**，
剖面 `0.85·sin(πr)·sinθ`，壁面与极轴处为 0）。**开它才有绕圈的摆线，但那是画出来给人看的，不是解出来的。**

#### 10.4 五个坑

1. 🔴 **`m > ℓ` 时 `P_ℓ^m ≡ 0`** ⇒ 整场恒 0 ⇒ 屏上 620 个粒子**全消失**（看起来像渲染崩了）。
   两处都要兜：`sphStep` 里兜底夹、`syncSphRead` 里夹回并**把 chip 置灰**。
   只置灰不夹会留下「屏上写着 m=3 而 ℓ=1」的假状态。
2. 🔴 **`sphAmax` 不能对 m=0 采样**：`P_ℓ(1) = 1` 是精确值。采样 400 点时 θ=π/400 处给 0.99997
   ⇒ 整场偏 3e-5 ⇒「m=0 必须逐位退回旧式（Δ<1e-12）」这条判据当场假红（实测 6.3e-5）。m=0 直接给 1。
3. 🔴 **尾迹窗必须改**：m=0 时半个行程 84 行 / 1.51 s 够用；m≥1 时局部振荡周期是 2.86 s，
   窗口短于一个周期就只剩一段开口弧，看不出「绕」⇒ 160 行 / 2.88 s。
4. 🔴 **样本选择要把 gφ 算进去**：`|∇u|² = gr² + gθ² + gφ²`。只算前两项会专挑
   「径向不动、φ 方向最活跃」的那种粒子**漏掉** —— 那恰恰是新模态想要的主角。
5. **float32 与「严格 0」**：尾迹缓冲是 `Float32Array`，`atan2` 会把量化误差放大到 1e-7 量级
   ⇒ m=0 的行内 φ 跨度实测 **9.6e-8**，判据只能写 `< 1e-6`，写 `=== 0` 是自欺。
   （另：`sphRevSec()` 里误用了未定义的 `m` ⇒ 一调用就抛，被探针当场抓住。）

🔴 **33.970563 的身份要说准**（老师 2026-10-24 追问：「这个 (1+√2)⁴ 有没有体现在
空气粒子被压缩的最小体积那个小球 r 上？」）

- **几何上成立，而且是恒等式**：`k = (3√2−4)/(3√2+4)` ⇒
  `1/k = (3√2+4)²/(18−16) = 17+12√2 = (1+√2)⁴`。
  实测 33.970562748477185 vs 33.970562748477136，差 **5×10⁻¹⁴**（浮点级）。
  所以画布上那个 22 px 白球标的没错：**`r_空腔 = R/(1+√2)⁴`**。
- **但它不是「空气压缩球」**：式子里没有 γ、p₀、ρ₀、c 任何一个气体量，只有 3-4-5。
  换介质（空气 → 水 → 真空）这个数一个字都不变。
- **定量反证**：把空气绝热压到 `(kR)³ = 2.5509×10⁻⁵` 的体积，需
  `p/p₀ = (V/V₀)^(−γ) = 2.6955×10⁶` ⇒ Δp ≈ **2.73×10¹¹ Pa ≈ 322.7 dB SPL**；
  而 120 dB 时 ΔV/V = 1.41×10⁻⁴、半径比 **0.999953** —— 与 0.029437 差三个数量级以上。
  线性声学在 ~190 dB 就崩了。这个半径不在任何可实现的声场里。
- **真要找「压缩最狠处」**：`p = −B∇·u = Bk²ψ ∝ ψ`，球心 `ψ(0)=j_ℓ(0)`：
  ℓ=0 时 = 1（压强腹点），ℓ≥1 时 ≡ 0（压强节点，不压缩）。
  所以「最小体积球」在 ℓ≥1 的球腔里**不存在**；ℓ=0 时退化成**一个点**，
  有效尺寸由 λ 定，与 33.97 无关。
- **6103.456 ¢ 只是 `1200·log₂(1/k)` 的形式换算，不是声学事实**：它有音分的前提是
  「某个长度 ∝ 1/f」；这里没有任何长度与频率挂钩，纯数折音分只是给比值换单位。

**通项（2026-10-24 21:50 老师追问「怎样调参或调音程比才能刚好，有没有通项」）**

把勾股比记成 `ρ = 股/勾`，空腔半径就是一条**闭式函数**（与三角形的绝对大小无关）：

```
k(ρ) = (√2 − ρ) / (√2 + ρ)          反解：ρ = √2·(1 − k)/(1 + k)
```

- `ρ = 4/3` ⇒ `k = 1/33.970563`（3-4-5）
- `ρ = 1`   ⇒ `k = (1+√2)⁻² = 0.171572875`（等腰直角）
- `ρ = √2`  ⇒ `k = 0` ⇒ **空腔塌成一点**、12 条股腿全过球心，音程 **600.000 ¢**（三全音）
  —— 这就是代码里「可内接条件 ρ ≤ √2」的真正含义：越过它 k 变负，内倒四面体翻到外面。

**为什么 33.970563 那么整**：把 1/k 写进 Q(√2)，`1/k = A + B√2`，
其中 `A = (2+ρ²)/(2−ρ²)`、`B = 2ρ/(2−ρ²)`，恒有 `A² − 2B² ≡ 1`
（401 个 ρ 逐点实测，max 残差 2.3×10⁻¹⁰）⇒ 任何 ρ 都满足 Pell 方程
⇒ **总能**写成 `(1+√2)^t`，`t = ln(1/k) ÷ ln(1+√2)`。**t 只能是偶数**
（奇数 n 的 (1+√2)ⁿ 范数是 −1，与恒等式 +1 矛盾）。

| t | ρ | 音程 | 空腔 | 是整数勾股数组吗 |
|---|---|---|---|---|
| 2 | 1 | 0.000 ¢ | 0.171573 R | 否（1, 1, √2） |
| **4** | **4/3** | **498.045 ¢** | **R/33.970563** | **是（3-4-5）★ 唯一** |
| 6 | 7/5 | 582.512 ¢ | R/197.995 | 否（5, 7, √74） |
| 8 | 24/17 | 597.000 ¢ | R/1154.0 | 否（17, 24, √865） |
| 10 | 48/34→1.413793 | 599.485 ¢ | R/6726.0 | 否 |
| ∞ | √2 | 600.000 ¢ | 0（塌陷） | — |

🔴 **结论：(1+√2)⁴ 是唯一解**，不是随手挑的漂亮数 —— t 取偶数 Pell 解时，
只有 ρ = 4/3 的三角形三边是整数。要「刚好」只能把勾股比调到 **4:3 / 498.045 ¢**；
ρ 再往 √2 靠（7/5、24/17…）空腔会继续变小，但那些三角形斜边非整数。

### 13. 振子点集：全部内接于球（2026-10-24 老师指正）

**症状两条**
1. 「球腔 3D」里所有点集都缩在球心附近悬着，接不到球壁 —— 老师：「你没有把其它柏拉图几何体嵌入到球内」。
2. 「三锥」不是正四面体 —— 老师：「3锥对应四面体，你没有画对，是球内接一个正四面体」。

**根因 1：半径用错了来源**

`CL.rho` 复用了 `SPA.ringR = 0.77373`。那是 m=7 内圈管的黄金比峰位（j′₇,₁/j₇,₁），**只对 m=7 成立**；
被当成「云点半径」以后，四面体/立方体整体缩到 77.4%，屏上就是悬空。
改 `SPA.cloudR = 1.0`，并在两处同步：`spaCloudGet` 的 rho、`__ch.cloudField` 的 rho。
🔴 后者原来还硬写着 `SPA.ringR` ⇒ §9「整档 ILD ⟷ 单频合成场」从 ≤0.05 dB 掉到 7 dB 差。
那是**接口没同步**，不是物理变了 —— 两条路各用一个半径，对拍当然对不上。

**根因 2：锥的纬度一律落在赤道**

旧定义 = 赤道环 + 极点。n=3 时侧棱 √2、底棱 √3，**不是正四面体**。
改成**等棱内接 n 棱锥**：底面 z = −h、底半径 √(1−h²)、锥尖在北极，
由「侧棱 = 底棱」得 `h = 1 − 1/(2sin²(π/n))`：

| n | h | 底面 z | 棱长 | 是什么 |
|---|---|---|---|---|
| 3 | 1/3 | −0.333333 | 1.632993 | **正四面体**（与 tetra4 同一枚，只是尖朝上）|
| 4 | 0 | 0 | 1.414214 | 半个正八面体（底面正好落赤道）|
| 5 | −1/√5 = −0.447214 | +0.447214 | 1.051462 | 等棱五棱锥（底面沉到赤道下方）|

五枚柏拉图立体的棱长（顶点都在 r=1 上算出来的，不是另设缩放）：
四面体 4/√6 = 1.632993、八面体 √2 = 1.414214、立方体 2/√3 = 1.154701、
二十面体 4/√(10+2√5) = 1.051462、十二面体 4/(√3(1+√5)) = 0.713644。

**根因 3：只连棱、没有面**

线框贴在金色球壳上，跟球自己的经纬线混成一片 —— 「看不出是个立体」的一半原因在这里。
按参考页《视频③》§5 的次序补三层：面（淡青 0.05）→ 棱（暗底 + 亮青两道）→ 顶点（光晕 + 白边）。
面按面心深度从远到近排，否则近面先铺、远面后压，前后就反了。
拓扑（棱 + 面）在切档时算一次、缓存在 `CLD.topo`：
面 = 「诱导子图恰为 k-环（每点度 2 + 连通），k ≥ 4 再验共面」，取**最小** k
⇒ 四面体/八面体/二十面体 3、立方体 4、十二面体 5。

**一个必须记住的副产品：同一枚体，换个朝向 ILD 从 0 跳到 8.5 dB**

pyr3 与 tetra4 是**同一枚**正四面体（两两距离谱逐项相同，Δ < 1e-12），但 pyr3 ILD = 8.53 dB、
tetra4 = 0.000 dB。判「两耳是否相同」看的是**耳轴投影 {s_x} 是否关于 0 对称**：
tetra4 的 x 分量 {+, +, −, −} 成对；pyr3 尖朝上，x = {0, .943, −.471, −.471} 不成对。
这条比「非中心对称就有方位」那个伪定律硬得多。

**判据修正（都是「测机器」而不是测页面）**

- `_probe_sphere` ⑤b「青色像素**个数**随 |cos| 走」：贴壁后只剩 r = 0.651（阈值 0.75）。
  点贴壁会被球壳高光与示踪粒子随机遮挡，个数的噪声淹掉了 3% 的膨胀。
  改判「青像素到球心的**平均半径**」—— 遮挡不改变径向重心：实测 r = 0.906、跨度 8.9 px ≈ 0.03·SC。
- `_probe_platonic` 新增 §3b 四条：所有 |p| = 1、每个锥恰好 2n 条等长棱、h 逐档等于 1/3 · 0 · −1/√5、
  pyr3 ≡ tetra4（距离谱逐项相同）。6b/6c/6d 的档位名单按新语义重排：
  pyr3 从「t=0 的对称档」变成「t=2 但**有**方位」（它是尖朝上的正四面体）。
- `_probe_sphere` 的 rho 断言 0.77373 → **1.0**（判据跟着实现改，不许两边各说各话）。

**验证**：`_probe_platonic` 36 → **41 项**、`_probe_sphere` 保持 **146 项**；
全量 26 个脚本 **1233 项 / 0 FAIL**。

### 14. 三处改动：Keely 和弦阶梯 / 外接球 R 可调 / 信息卡可收起（2026-10-24 晚）

**① 挡位阶梯下面的 Keely 和谐音程比（和弦 1:2:4）**

位置：独立一行、紧跟「挡位阶梯」，只放**一颗**按钮（再点一次退回上一组）——

数学（全部现算，不抄结论）：

| 量 | 值 | 说明 |
|---|---|---|
| 步长 | 2/1 = **1200.000000 音分** | 和弦 1:2:4 的相邻比 = 八度 |
| 阶梯 | **2 / 4 / 8 / 16 / 32**（5 挡） | 从 2¢ 起、上限 45¢，`keelyGears()` 生成不是写死 |

## 八、不算 / 没做

- **方位结构只做到 m ≤ 3，且没有「两个模态叠加」**：m≠0 是简并 ±m 叠出来的行波，
  但页面没有做「ℓ=2 与 ℓ=3 同时驱动」的复合图样（那需要给每个模态独立的幅度/相位，是另一件事）。
- **二阶声流是示意**：`0.85·sin(πr)·sinθ` 那条剖面不是解出来的，不模拟 Rayleigh streaming 的量级。
  它只负责把「净环流长什么样」画出来，默认关。
- **真实球（不是刚性壁）**：这里有 `j_ℓ(kR)=0`（Dirichlet），真实弹性球的边界条件涉及球 Bessel 与面内应力耦合，没有做。2D 那边已经有真实板（`NU_P`），3D 没有。
- **质子的物理量**：本文只给「几何/波场」推导，**没有**声称这就是质子内部结构。夸克/胶子只是几何类比，ρ 与球半径 r **无关**（纯几何），所以不能通过选夸克尺寸把 0.5505 调成 0.6667。
  🔴 **更进一步：22.47% 这个比值与实验不可比，不是「差多少」的问题。**
  夸克与胶子都是**点粒子**（无内禀半径，实验只给上限 ≲10⁻¹⁹ m）⇒ 两者「半径之比」没有定义。
  目前唯一谈得上的「半径」是**分布半径**（形状因子 / GPD）：质子电荷半径 **0.8409 fm**（CODATA），
  夸克质量半径 ≈ **0.54 fm**、胶子质量半径 ≈ **0.84 fm** ⇒ **胶子比夸克大**（约 1.56 倍），
  与「胶子只有夸克的 22.47%」**方向相反**。所以 22.47% 只是「球腔密堆」这个模型内部的
  一个纯几何数（Kepler 四面体间隙 ÷ 球半径），**不能**用来说明质子里胶子比夸克小。
