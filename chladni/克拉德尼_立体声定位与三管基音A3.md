## 一、立体声：一条公式，三处音频，两条硬边界

**公式只有一条**（两页同名函数 `panOfTube`）：

```
pan = r · cos θ        （不归一，最大值 = 管心半径）
```

不归一是有意的：盘心附近的管本来就该「偏中」，硬拉到 ±1 是编的。左耳放在盘心左侧 ⇒ 屏幕 `+x` 方向走**右声道**（`+1` = 右）。

### 1.1 三处音频各自的 pan 来源

| 音频 | 文件 | pan 取自 | 走什么时间尺 |
|---|---|---|---|
| 主发声 `AUD` | 两页都有 | 每根管自己的 `(r, θ)` ⇒ `panOfTube(L)` | 静态：管不动，pan 就不动 |
| 轨迹 `TAUD` | 两页都有 | 与画虚线/做包络**同一份** `trajAt()` 求出的沙点 `x`（代表粒 ρ = `TAUD_RHO` = 0.62） | 引导圈 0.09 Hz ⇒ 11 s 扫一遍 |
| 挂挡 `AAUD` | 仅 Keely | 7 与 8 两模态**干涉项**的强侧方位 `D`（见 1.3） | 画面相位 8 s/圈 ⇒ 约 2 Hz 走一圈 |

### 1.2 两条硬边界（写进页面注释，也写进浮窗 ⑥）

- **前后分不出来**。`StereoPannerNode` 只有一个左右维度 ⇒ 盘心正前 / 正后的管 `pan ≈ 0`，落在同一处。要三维必须换 `PannerNode(HRTF)` 并给听者朝向，本页不做。
- **不能按真转速贴位置**。Keely 外环 2000 rpm = 33.3 圈/s，听觉在那个频率上分辨不出「移动」，只会把 pan 变成 33 Hz 抖动（听起来像破音）。所以两边统一取**画面相位**（`SPIN_VIS = 0.125`，8 s/圈），真转速只进数字。这与 §8.50「画面速度与真转速脱钩」是同一条决定。

### 1.3 挂挡音频的 pan 不是编的 —— 推导与复算

两模态叠加（`ψ₇`、`ψ₈` 为各自图样的方位角）：

```
w(θ) = cos(7θ − 7ψ₇) + cos(8θ − 8ψ₈)
```

展开 `w²` 并去掉快振荡（周期 2π/7、2π/8、2π/15 的那些项平均为 0，只剩差频项）：

```
⟨w²⟩ = 1 + cos(θ − D),      D = 8ψ₈ − 7ψ₇
```

⇒ 全盘**只有一个「响的一侧」**，方位就是 `D`，所以 `pan = cos D`。

数值复核（枚举 7200 个 θ 找 ⟨w²⟩ 峰位，与闭式对比）：

| ψ₇ | ψ₈ | 闭式 D | 枚举峰位 | 差 |
|---|---|---|---|---|
| 0.000 | 0.000 | 0.00° | 0.00° | 0 |
| 0.300 | 0.300 | 17.19° | 17.20° | 0.01° |
| 0.300 | 0.450 | 85.94° | 85.95° | 0.01° |
| 1.100 | 0.200 | 10.50° | 10.50° | 0 |

**🔴 单一模态本身左右严格对称**：`|cos mθ|²` 在 `x → −x` 下不变，`∫` 过盘心恒定。所以给「一个模态」加 pan 是编的；不对称**只来自 7 与 8 的干涉项**。这条也是「为什么挂挡音频可以有 pan，而纯单模态不能」的全部依据。

## 二、三管基音（3rd）改成 A3 = 216 Hz

### 2.1 旧口径的两个问题

1. **基音用错基准**：`fBase = tubeFreqs()[0]` = 内环主音 **B♭3 = 230.405 Hz** ⇒ `ftrip = 2` 时 3rd = **460.81 Hz**。这个数不是七音阶里的任何一个音（音阶是 B♭3 C4 D4 E♭4 F4 G4 A4，最高 A4 = 432.01）。
2. **读数冻结（真 bug）**：`setTxt('vTFtrip', …)` 原本挂在 `syncDual()` 的 `if (!on) return` **后面** ⇒ 单环档下这行永远不刷新，停在开机那一次算的值 **466 Hz**（那是 A4=440 时代留下的）。屏上「466」与真值「460.8」差 5 Hz，因为看着「差不多」一直没人发现。

### 2.2 新口径

```
fBase = a4Hz() / 2 = 216.005 Hz      （A3，全站锚 A4 = 432.01 的一半）
3rd = fBase × ftrip
```

`ftrip = 2` ⇒ 3rd = **432.01 Hz = A4**，正好落在七音阶最高音那个音级上（旧的 460.8 谁也不是）。

现算（`wave = λ/2`，`a0 = 19 mm`，等比档 `a ∝ 1/f`）：

| 管 | f / Hz | L / mm | a / mm | ka | η = (ka)²/2 |
|---|---|---|---|---|---|
| 3rd | 432.01 | 397.0 | 19.0 | 0.0752 | 0.283% |
| 6th | 864.02 | 198.5 | 9.5 | 0.0752 | 0.283% |
| 9th | 1296.03 | 132.3 | 6.3 | 0.0752 | 0.283% |

`ka` 三根恒等 ⇒「等比 a∝1/f」这一档真的做到了等响；「同径 Ø19」档 ka 差 3 倍、η 差 9 倍（低音管基本哑）。

### 2.3 读数口径

屏上是 **「倍数 · 基音」**：`2.0× · 216 Hz` = 「倍率 2.0×，基音 216 Hz」。**实放频率**看同一张卡下面的 3rd/6th/9th 表（432.0 / 864.0 / 1296.0）。这不是笔误，是把「设定」和「实际」分开摆。

## 四、左列浮窗（两页各一块）

- **刷新策略**：不挂在 80+ 个控件上，而是在帧循环里按 `LHUD.acc > 0.22`（≈4.5 Hz）统一重算。理由：任何一条改参数的路径都可能改这里的数，逐个挂必漏 —— 「改了参数浮窗不动」就是这么来的。
- **重建表格只在签名变了时做**：4 Hz 重建会抖，也会冲掉鼠标选区。
- **落位**：7 节点页 `left:12; bottom:64`（让开 `#hud` 那 34 px）；Keely 页 `left:12; bottom:150`（让开两行 `#soundDock`）。都必须 `position:fixed` 挂 body 直下 —— 塞进 `#cvWrap` 会被 `pointer-events:none` 的 `#hud` 与画布压住。
- **布阵小图**（`#lSpr`）：按管序把 `(θ, r)` 连成**闭合折线**，点的半径 ∝ 该处驱砂强度 `g`。等分档是一个正圆、微/大幅螺旋是**偏心圈**（视觉上像蛋形偏移）、黄金角是玫瑰状折线。
  ⚠️ 别把它当「螺旋」宣传：`tubeGeom()` 的微/大幅螺旋**只改半径不改角度**（`th = 2πi/nt` 恒定），只有黄金角改角度。图上照实画。
- **实测不遮挡**（DOM 量，不靠眼看）：`#lhud` 与 `#soundDock` / `#btnSound` / `#mountChips` 三处矩形**均不重叠**（间隙 ~10 px）。

## 六、没做 / 待定

1. **Keely 页三管基音仍是 B♭5 = 921.6 Hz（L = 93 mm）**，未跟着改成 A5 = 864 Hz。理由：它要装进 12 英寸球，净高 183 mm，B♭4 = 186 mm 就顶住了，B♭5 的 93 mm 才有余量；换 A5 是 99 mm 也能装，但要不要跟着换成 A 系等老师一句话。
2. **前后方向**不做（`StereoPanner` 一维），要三维得换 HRTF。
3. **振子「自转」**：轴对称回转体绕自身主轴转，角动量守恒，不给盘传递净力/扭矩；λ/4 管口近似点源，绕轴自转也不改变辐射场 ⇒ **对图纹零贡献**（不成立）。SEG 滚筒的实质是「筒里的偏心质量在转」，那是另一样东西（相位递增的偏心转子阵列），已在 §8.23「kHz 行波是死路」里定过性。
