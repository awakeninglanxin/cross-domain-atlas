## 2. 本页的算法（可逐条复现）

### 2.1 振幅场

```
方盘和式： W(u,v) = cos(nπu)·cos(mπv) + cos(mπu)·cos(nπv)
方盘差式： W(u,v) = cos(nπu)·cos(mπv) − cos(mπu)·cos(nπv)     u,v ∈ [−1,1]
圆盘：     W(u,v) = J_n(k·r)·cos(nθ) ，  k = j′_{n,s} ，  r ≤ 1
```

- 场网格 `G = 192`（给粒子梯度用），显示图 `FW = 320`（给板面底纹用）。
- 每格归一化：`a = |W| / max|W|`，`A² = a²`。
- 节线判定：`a < 0.045` → 计入"节线占比"读数。

### 2.2 砂粒

```
初值：方盘在 [−0.985, 0.985]² 均匀撒；圆盘在 r < 0.98 内按面积均匀撒
每帧 2 个子步，每个粒子：
    a  = sampA(u,v)                      // 双线性采样归一振幅
    g  = ∇A²(u,v)                        // 中心差分，步长 2/(G−1)
    gn = |g| + 0.35                      // 饱和项，防止节线附近暴走
    stick = (a < 0.03) ? 0.25 : 1        // 已到节线就"粘住"
    u ← u − 0.0055·gx/gn·stick
    v ← v − 0.0055·gy/gn·stick
    u,v ← u,v + ξ·a ,  ξ ~ U(−0.020, 0.020)   // 噪声强度 ∝ 局部振幅
    边界：方盘夹到 ±0.985；圆盘按 r=0.985 径向投影回来
```

**三个参数各管一件事，改之前要知道改的是什么**：

| 参数 | 值 | 变小 | 变大 |
|---|---|---|---|
| 下坡强度 K | 0.0055 | 收敛慢，砂纹细而稀 | 收敛快，但节线会被"冲"得来回晃 |
| 噪声 NOISE | 0.020 | 线极细极锐（像细砂） | 线糊、颗粒感强（像粗砂） |
| 饱和 gn 偏置 | 0.35 | 大梯度处步长更大，边角易堆积 | 全局变慢、更均匀 |

**噪声 ∝ 振幅这一条不能省**。若噪声均匀，砂粒会随机游走糊满整板，节线永远是毛的。
"振幅大→跳得乱、振幅小→几乎不动"才是砂粒能**停在**线上的唯一机制。

### 2.3 频率

```
fac = h · √( E / [12(1−ν²)ρ] )          // 钢：h × 1.528 m²/s
方盘：k = π√(n²+m²)/L
圆盘：k = j′_{n,s}/R
f = k²/(2π) · fac
```

### 2.4 贝塞尔

```
J_n(x)  = Σ (−1)^k/(k!(n+k)!)·(x/2)^(2k+n)      // n≤6, x≤40，相对误差 ~1e-15
J_n′(x) = [J_{n−1} − J_{n+1}]/2                  // n=0 用 −J_1
j′ 零点：x 从 0.04 起，步长 0.02 扫符号变化 → 二分 80 次
```

已与公开标准表逐位核对（见 `克拉德尼_核心公式与两族节线.md` §3）。

### 2.5 性能实测（本机 Chrome，ThinkPad）

- 场重建（320² + 192² 两次求值）：**约 30–45 ms**，只在换模态时做一次；
- 粒子 14000 个 × 2 子步：**每帧约 4 ms**（含一次 14000 段的 path 填充）；
- 拖动滑块：可感到一次"顿"，但不到卡的程度。要更顺可把粒子降到 6000。

## 3. 五条模型边界（网页 §07 的详细版）

| # | 模型给的 | 真实板里的 | 偏差方向 |
|---|---|---|---|
| 1 | `cos·cos ±` 两项 | 自由边严格解含 **cosh** 项（指数型） | 节线整体**内缩**，越靠边越明显；低阶几乎看不出 |
| 2 | 纯 `J_n(kr)` | 严格解是 J_n 与 **I_n（双曲贝塞尔）**的线性组合 | 节圆半径偏大约几个百分点，边缘节线变钝 |
| 3 | 均匀、各向同性、等厚 | 轧制板有**残余应力 + 厚度公差** | 简并**劈裂**：(n,m) 与 (m,n) 本应同频、实测差几 Hz → 两模态**混合**，拍出"既不像和式也不像差式"的杂图。**这是现场演示"这次花纹和上次不一样"的主因** |
| 4 | 砂粒只做漂移 | 真砂在**跳**（hop）、有摩擦、有回弹、有粒径分布 | 真实砂纹有**颗粒感与堆积厚度**；细砂线细、粗砂成"墙"。本页粒子是点，线宽只由数值阈值决定，**不能用它判断粒径** |
| 5 | 频率是线性本征值 | 驱动点、支撑点、换能器质量都移动模态；非线性还会让频率随振幅漂 | 实测共振通常比理论**低**几个百分点；**支撑点必须在节线上**，否则把模态压死 |

### 一句话结论

这页能回答"**这个模态长什么样、为什么长这样、频率在哪个量级**"；
不能回答"**我这块板在 1.234 kHz 时会不会出 5 号图**"。后者只能实测。

## 4. 要更准，三条路（按成本排）

1. **换边界函数**（改 20 行）：方盘加 cosh 项、圆盘加 I_n 项。
   能把第 1、2 条边界消掉，代价是要解一个 4×4 的边界条件行列式定 k。
2. **上有限差分**（借 `vibrational-modes-plates`）：直接在板上解双调和方程，
   任意边界（自由/简支/夹紧/局部支撑）都能进。缺点是慢（秒级/模态），不适合网页实时。
3. **做反演**（借 `pyChladniPlate`）：不管模型，从**照片**反推模态号。
   这是唯一能直接回答"书上这一格到底是几号"的办法，也是核对图版最硬的手段。

## 5. 复现核对清单

- [ ] 方盘 n=m 差式：板面应**完全无花纹**（W≡0），不是"花纹很淡"
- [ ] 方盘 (2,3) 与 (3,2)：花纹应**逐点相同**
- [ ] 圆盘 s1·n0：应有 **1 个**同心节圆（不是 0 个、不是 2 个）
- [ ] 圆盘 s1·n1：应**没有**节圆，只有 1 条过圆心的直径
- [ ] 改板厚 1→3 mm：频率 ×3，**花纹一点不动**
- [ ] 改板尺寸 300→200 mm：频率 ×(300/200)² = 2.25，花纹不动
- [ ] 扫频巡演：应看到 n 增大时"辐条增多"，s 增大时"圈增多"，两者不混
