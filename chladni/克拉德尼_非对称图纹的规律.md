## 0. 一句话结论

**图纹的对称性只由两个量决定：`g = gcd(m 集)` 和「各模态方位相位 ψ 能不能被同一个 φ 对齐」。**
前者给转动阶，后者给有没有镜面。`g = 1` 且镜面对齐无解 ⇒ **C1，完全非对称**。
这两条都是**解析可判**的，不需要画一张图去试 —— 这就是「避免暴力穷举」的那把钥匙。

## 2. 判据一：转动对称阶 = gcd(m 集)

合成档的场（与页面 `fieldAt()` 同一口径）：

```
u(r,θ) = Σ_k a_k · J_{m_k}( j_{m_k,1} · r ) · cos( m_k θ + ψ_k )
```

绕中心转 `2π/q`，要求每一项都不变：

```
cos(m_k(θ + 2π/q) + ψ_k) = cos(m_k θ + ψ_k)  ∀θ
⟺  m_k · 2π/q ≡ 0 (mod 2π)
⟺  q | m_k        对每一个 k
⟺  q | gcd(m_1, m_2, …) = g
```

**结论：转动对称群 = C_g，`g = gcd(m 集)`。**
要完全没有转动对称 ⇒ 必须 **g = 1** ⇒ m 集两两互素（更强、也更好记）。

> 页面第 8 组 {3,5,7,11} 与第 9 组 {6,9,12} 就是这条的对照：
> 前者 g=1，转 120° 残差 **1.691**（完全不重合）；后者 g=3，转 120° 残差 **0.0000**（严格重合）。
> 两个数字都由探针 `_probe_asym.cjs` 用 `__ch.uAt()` 实测得到，不是推测。

## 3. 判据二：镜面存在 ⟺ 一个**超定**方程有解

关于过原点、与 x 轴成 φ 的轴作镜像：`θ → 2φ − θ`。要求

```
cos(m(2φ − θ) + ψ) ≡ cos(mθ + ψ)
```

`cos A = cos B` 只有 `A ≡ ±B` 两条路。取 `+` 会要求 `2mφ ≡ 2mθ`（对一切 θ 不可能，除 m=0）；
取 `−` 得

```
−mθ + 2mφ + ψ ≡ −mθ − ψ (mod 2π)
⟺  ψ_k + m_k·φ ≡ 0 (mod π)        对每一个 k
```

**这就是全部。** 一个未知数 φ，|m 集| 个方程：

| 模态数 | 方程数 | 有解？ | 后果 |
|---|---|---|---|
| 1 | 1 | 总有（φ 取 `−ψ/m`） | 单模态必有一面镜（经典 Chladni 图形的 C_mv） |
| 2 | 2 | 需一条线性同余成立 | **常常近似成立** ⇒ 视觉上仍像对称 |
| ≥3 | ≥3 | 一般**无解** | C_g，手性 |

**量化这个「有没有解」的量（本页用的唯一标量）：**

```
E(φ) = max_k  dist( (ψ_k + m_k·φ)/π , ℤ )
E*    = min_{φ∈[0,π)} E(φ)
```

- `E* = 0` ⇒ 存在精确镜面（D_g）
- `E* > 0` ⇒ 手性（C_g）
- 上限 0.5；经验上 **E\* ≳ 0.10 肉眼已看不出对称**（下面 §4 用实测残差校准过）

## 4. 判据三：为什么「整体相位」「等间隔 δ」都破不了对称

这是最容易被忽略、也最容易白忙一场的一条。

**(a) ψ_k = m_k·φ₀（整体旋转）**

```
cos(m_k θ + m_k φ₀) = cos(m_k(θ + φ₀))
```

只是把整张图转了一个角。`E*` 因此**严格不变**（探针里有一条断言专门钉它，
用 4096 点扫 φ 时残差 ≤ `m_max/nPhi`，那是离散误差，不是数学误差）。

**(b) 等间隔相位递进 δ 给出的 arg c_m**

页面的 `modeCoefs()` 算的是 `c_m = Σ_i e^{i(φ_i − m·α_i)}`，其中 `α_i = 2πi/N`、`φ_i = i·δ`。
等比级数求和：

```
c_m = Σ_{i=0}^{N−1} e^{i·i·(δ − 2πm/N)}
    = e^{i(N−1)Ψ/2} · sin(NΨ/2) / sin(Ψ/2),      Ψ = δ − 2πm/N
⇒  arg c_m = (N−1)/2 · δ − (N−1)π·m/N + (0 或 π)
```

前项与 m 无关，中间项 **正比于 m**，末尾的 π 只给 `(−1)^m` 的符号。
所以 `arg c_m ≡ 线性于 m` ⇒ 又回到 (a) ⇒ **δ 调到任何值都破不了镜面**。

**(c) 结论：破镜必须让每个模态有自己独立的相位基准。**
物理上这就是「**不同 m 配不同的振子组**」—— 各通道没有共同的时钟，`ψ_k` 一般非线性于 m。
本页合成档因此改成 `psiOn=1`：每模态带自己的 `ψ_k`（组合按钮里是优化过的值，
手工加减 m 时用 `planPsi()`：`ψ_k = frac(k²/φ²)·2π`，k² 那一层就是「非线性」的来源）。

**(d) 反例（2 个模态不够）**

| 组合 | ψ | E\* | 实测二维镜像残差 |
|---|---|---|---|
| {4,7} | (0, π/2) | **0**（精确有镜面） | 0（严格重合） |
| {4,7} | (0, 0.5 rad) | 0.033 | 小 ⇒ 肉眼近似对称 |
| {4,5,7} | 优化 | 0.137 | 0.690 |

两个方程一个未知数，几乎总能「差不多对上」。**≥3 个模态才真正无解。**

## 5. 判据四：E\* 大 ≠ 画面非对称（局部为零陷阱）

实测抓到的一条硬教训（探针第一版就栽在这里）：

> 第 4 组 {5,8,13}，`E* = 0.191`，但在 **r = 0.5 单环**上量镜像残差只有 **0.105**。

原因：`J₁₃(0.5 × 16.47) ≈ 0` —— m=13 在那一环上几乎不出力，场上只剩 5 和 8 两个模态，
而两个模态本来就容易近似对齐。**E\* 是相位空间的判据，画面还要求每支模态在可见区有幅值。**

所以判据链必须是两条：
1. `E* > 0`（相位空间：镜面方程无解）—— **必要**
2. 二维实测残差（5 个半径 × 360 点合并）> 阈值 —— **充分性检查**

改成二维后同一组实测 **0.790**，与 E\* 方向一致。

## 6. 九组新设计（替换原来的 3 4 5 9 12 15 19 20 25）

设计规则，按优先级：

1. **反链**（任意两个互不整除）+ `g = 1`。有整除对时 `N_k = m_k` 会顺带激发整数倍（§7）。
   注意「两两互素」比这更强、但**不是必须**：{6,7,8} 里 gcd(6,8)=2，却互不整除，完全合法。
   我第一版把判据写成两两互素，是过头了（会把合法组合判死）。
2. **≥3 个模态**，一般 3–5 个。模态越多超定越强，E\* 越大。
3. **N = 组内最大 m**：最大那支落进退化档（满相、合力 `N·F`），其余支按 `N/gcd(N,m)` 分类。
4. **频率跨度** `f ∝ j_{m,1}²`，跨度 = max/min。跨度小 ⇒ 接近「同族但仍互不整除」，最刁钻；
   跨度大 ⇒ 靠近不可听化边界，只作几何演示。
5. **内外环音程比** = `frac_out / frac_in`（`f = c/(4·frac·L)`），由装法给：2:1 / 1:1 / 4:3 / 1:2。

## 7. 「不同 m 配不同 N」的物理代价（必须说明）

一个模态 m 用 N_k 个振子（相位递进 φ_i = m·α_i，α_i = 2πi/N_k）时：

```
c_m = Σ_{i=0}^{N_k−1} e^{−i·m·2πi/N_k} = { N_k,  N_k | m
                                          { 0,    其它
```

- 取 **N_k = m_k** ⇒ `c_m = m_k`，**满相、耦合最大** —— 这是「每个模态配自己的振子组」要的效果。
- 代价：`N_k = m_k` 会**顺带激发 m_k 的所有整数倍**（m=3 的组会点亮 6/9/12…）。
  所以 m 集必须取**反链**（任意两个互不整除）。前 8 组都满足；第 9 组故意违反当对照。

页面上的 `S.N` 只有**一个**值（画阵列、算同族表用），取组内最大 m。
真正的「每模态 N_k」活在组合的定义里（`COMBOS[i].ms`），chip 上标 `N` 是那个阵列值。

## 10. 没做 / 留给下一轮

1. **拍频型（近简并）时间演化没做。** 计算已找到 147 组 `|Δj|/j < 3%` 的简并对，
   最强的一组是 `(m=16,s=2) j=25.4170 ↔ (m=20,s=1) j=25.4171`（rel 0.00%）。
   做成「两模态以拍频慢转」需要给场加时间项 `cos(ω_k t + ψ_k)`，会改变粒子动力学，
   不属于本次「换组合」的范围 —— 要做单独一轮，且必须重跑 `_probe_traj`。
2. **手工加减 m 的相位只是通用方案**（`planPsi`），不保证最优：{4,5,7,12} 的 E\* 只有 0.092。
   组合按钮里的是优化值（0.137）。若要把手工态也做到最优，得在小集合上跑 `bestPsi`，
   代价是每次改 m 多 ~10 ms（可缓存，但没做）。
3. **GPU 这一轮不需要。** 上面所有量都是解析式 + 小规模采样（1024 点 E\* 扫描、
   5×360 点二维残差、16 组 δ 维网格搜索），CPU 几秒内跑完。
   真正需要 GPU 的是下一步：`10⁵` 组 (m 集, ψ) × 粒子积分的长程轨迹统计，
   或 3D 球腔的全场可视化。要开再找老师连 autoDL。
4. **页面第 9 组之外没有「对称对照」了**（原来还有 C2/C5）。只留 C3 一个，是因为
   9 个位置里要留 8 个给非对称样本。要更多对照可以加回去。
