# 目标模态 × 振子频率：每个 m 到底该把振子设成多少

> 对应网页：`AAA_克拉德尼_7节点三振子_响应式.html`（「目标模态」标题双击可打开本文件）
> 建 2026-10-22 · 所有 j 零点与本机 Bessel 自算吻合，Hz 两列请先看 §2 的口径警告

---

## 0. 一句话

**不是「每个振子一个频率」，而是「每个 m 一个共用频率 + 一组相位」。**

- **频率**：N 个振子**全部**跑在同一个 `f_m` 上。差一点都不行 —— 频率是「选模态」的唯一手段。
- **相位**：第 i 个振子（角度 αᵢ = 360°·i/N）的相位是

```
φᵢ = m · αᵢ = 360° · m · i / N        (i = 0, 1, …, N−1)
```

- **幅值**：全部相同。幅值不等只会把模态「弄脏」，不会帮你选 m。

所以「对应不同 m 应该怎样独自设置」= **查 §2 拿 f_m，查 §3 拿 φᵢ**。两件事都做到，才叫「独自」。

---

## 1. f_m 从哪来

薄板弯曲波：`ω ∝ k²`，于是

```
f = k² · c / (2π)          c = √( D / (ρh) ),  D = E h³ / (12(1−ν²))
```

`k` 是径向波数。这里有一个**必须交代的口径差**：

| | 用的是哪个 k | 说明 |
|---|---|---|
| 场/图样（0 节线、2m 个瓣） | `k = j_{m,1} / a` | j 是 J_m 的**第一零点**，页面 `JZ[]` 表就是它 |
| 页面上的 Hz 读数 | `k = m / a` | 量纲代理：沿盘缘一圈走 m 个整周期 ⇒ k≈m/a。**不是本征值** |

两者不是一个数：m=1 时差 **14.7 倍**，m=7 时差 **2.5 倍**。§2 把两列并排放，**看比值，别看绝对值**。

`m/a` 那一列还有一个硬伤：**m=0 时它给 0 Hz**（图上「页面 Hz」那一格就是 0.0）。所以它只能当排序刻度用，不能当频率用 —— 这也是页面里那句「不要用 C(m+2n)² 算 Hz」的同一个坑。

## 3. 相位表：这才是「每个振子各自」的部分

`φᵢ = 360° · m · i / N`，i 从 0 数到 N−1，振子按角度 `αᵢ = 360°·i/N` 均布。

以 **m = 7**（页面默认的 7 节点）为例：

| N | 各振子相位 φ₀ … φ_{N−1} | 能不能激出 m=7 |
|---|---|---|
| 3 | 0°, 120°, 240° | 能（7 mod 3 = 1，激的是"7 那一族"） |
| 4 | 0°, 270°, 180°, 90° | 能（7 mod 4 = 3） |
| 5 | 0°, 144°, 288°, 72°, 216° | 能（7 mod 5 = 2） |
| 6 | 0°, 60°, 120°, 180°, 240°, 300° | 能（7 mod 6 = 1） |
| **7** | **0°, 0°, 0°, 0°, 0°, 0°, 0°** | **能**（模 7 恒等 ⇒ 激的是「m≡0 (mod 7)」那一族：0, 7, 14…） |
| 8 | 0°, 315°, 270°, 225°, 180°, 135°, 90°, 45° | 相位是逐点 −45°，等价于 m=1 的镜像 |
| 12 | 0°, 210°, 60°, 270°, 120°, 330°, 180°, 30°, 240°, 90°, 300°, 150° | 能（7 mod 12 = 7） |

**N=7 与 m=7 的「全 0°」是这套方案最容易误读的一处**：7 个振子均布，第 i 个相位转 `360°×7/7 = 360°`，转一圈回到原点 —— 7 个振子全同相。

> **🔴 2026-10-23 更正：早先这里写的是「不能激出 m=7」，那是错的。**
> 相位全 0 恰好让 7 个振子**全部落在 `cos(7θ)` 的 +1 反节点上**（`cos(7·2πj/7) = 1`），
> 每个振子都满额做功 ⇒ `c₇ = 1`，是**所有 N 里耦合最强的一个**。
> 「全 0°」的真正代价是两条别的：
> ① `c₀ = 1` 也满额 ⇒ m=0（轴对称呼吸）与 m=7 **在相位上分不开**；
> ② **驱动合力 `|Σe^{iφⱼ}| = 7 ≠ 0`**（其它任何 N 都恰好为零）⇒ 整盘被同相往上推。
> 详见 `克拉德尼_3-6-9与gcd_在盘上的落点.md` §4。

## 4. 三个别名陷阱（相位能不能区分 m 的边界）

在 N 个等隔点上采 `cos(mθ)`，有两类 m 与 m₀ **逐个点相同**，光靠相位永远分不开：

| 类型 | 判据 | 例子 |
|---|---|---|
| 同族（正阶别名） | `m ≡ m₀ (mod N)` | N=3, m₀=7 ⇒ m=1,4,7,10,13 一族 |
| 反射别名（负阶别名） | `m ≡ −m₀ (mod N)` | N=8, m₀=7 ⇒ m=1 与之逐个相同（0°,315°,… 就是 −45°） |

这两类都必须靠**频率**分开，相位分不开。页面里「带红点的 m 与当前目标同族」就是把这两类都算进去 —— 早期版本只算正阶、漏了反射（N=8 时 m=7 的红点会少一个 m=1），2026-10-22 已修。

由此得到两条实用判据：

1. **想激出单独的 m，至少要 `N > 2m`**。否则 m 与 N−m 落在同一组相位上，你没法只激一个。
   ⇒ m=7 需要 **N ≥ 15**；页面 N 上限 15，刚好够 m=7 用，m=8 起就不够了。
   <br>⚠ **2026-10-23 补一句：上面这条 `N ≥ 2m+1` 用的是 `f ∝ m²` 的代理。**
   真实薄板 `f ∝ j²`，按真零点，把上侧混叠拉到 9 倍以上要 **m=3 → N ≥ 12、m=7 → N ≥ 21**
   （代理只给 7 和 15）。**本页 N ≤ 15 只够 m ≤ 4 用真口径彻底干净。**
   页面现在把「真值 / 代理值 / 所需最小 N」三个数一起摆出来，别只信代理那个。
2. **`N = m` 时相位全 0°**（见 §3），这是最坏的一种，但**坏的原因不是「激不出来」**：
   `c_m = 1`（耦合最强、最省功率），坏在 `c₀ = 1` 也满额、且**合力 = N·F ≠ 0**。
   一句话：**N=m 不是「推不动」，是「推得最狠却分不清推的是哪个，还把整盘一起抬起来」。**

   | 口径 | N=m 的代价 | 实测 |
   |---|---|---|
   | 模态力 | `c₀ = c_m = 1`（同幅） | 1.000 / 1.000 |
   | 位移 | m=0 鼓包只有 `~1/Q` 量级 | Q=100 → **0.15 %**；Q=5 → 3.0 % |
   | 功率 | **不费，最省**（振子全在反节点上） | `c_m` 全场最大 |
   | 合力 | **≠ 0**（其它 N 恒为 0） | 1.000 vs 0.000 |

## 5. 实操：一台信号源 + N 路相位

```
[正弦信号源 f_m] ──┬── 相位 0°    ── 功放 ── 振子 0 (α=0°)
                   ├── 相位 φ₁     ── 功放 ── 振子 1 (α=360°/N)
                   ├── …          
                   └── 相位 φ_{N−1} ── 功放 ── 振子 N−1
```

- **不要**给每个振子单独一台信号源 —— 各自晶振差几 ppm，相位会慢慢漂，图样会转、会花。
- 一路源 + 数字延时（`Δt = φ/360° / f_m`）或 N 路 DDS 共时钟，是最稳的做法。
- 振子**必须均布在同一个半径上**，而且半径要避开该模态的节圆；落在节圆上的振子等于没装。
- 盘心是节点（`J_m(0)=0`，m≥1 时中心位移为 0）⇒ **中心固定不会破坏 m≥1 的模态**，这是 Chladni 盘中心支顶的原因。
- 扫频找 f₁ 的顺序：先把 N 个振子**同相**驱动（= 激 m=0），从低往高扫，第一个"整片同相鼓包"就是 f₀₁；然后按 §2 的 `f_m/f₁` 乘上去。

## 6. 页面上的 Hz 读数怎么用

- HUD 右下角的 `f ≈ 529.4 Hz` 是 `k = m/a` 口径，**只用来比较 m 之间谁高谁低**；
- 面板「同族最近 m」那一栏的**频率比**才是滤波难度；
- 想跟真机对，先把 `a`、`h`、材料换成真值，再按 §2 用零点口径重算一遍，最后**扫频校准**。

**一句话**：比值可信，Hz 待标定。给一个没标定过的绝对频率，比给比值更容易把人带错。

1. **JZ 表只到 m=14 → 已修**。`buildMode` 里 `JZ[Math.min(m, JZ.length-1)]` 会把 m=15 夹成 JZ[14]=18.900078 ⇒ 径向形状写成 m=14 的、角向还是 15 瓣，静悄悄错一层。2026-10-22 已补 `19.994431`。
