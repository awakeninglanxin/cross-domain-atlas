13D 磁面演示台 —— 磁轴 · 嵌套磁面 · 磁力线

AI 那两族解的核心承诺是四句话：∇·B = 0、B·∇ψ = 0（存在嵌套磁面）、(∇×B)×B = ∇p（处处受力平衡）、处处光滑。其中第二句——磁面真的嵌套、磁力线真的绕得住——是唯一能"用眼睛验"的一条。

怎么读这张图：磁力线每绕大环一圈（φ 增加 2π），就沿极向（截面方向）前进 ι·2π；跑 T 圈后极向一共转过 k = ι × T 圈。

👉 决定「闭合还是铺满」的是 ι 本身，不是 k。设 ι = m/n（最简分数）——ι 是有理数 ⇒ 磁力线绕大环 n 圈就精确回到起点，是一条闭合曲线，此后无限重复；ι 是无理数 ⇒ 永不闭合，绕下去稠密地织满整层磁面。

⚠️ 别被画出来的段数误导。你选的 T 若不是 n 的整数倍，屏幕上那条线只是闭合曲线的半截／三分之一，起止点（绿环 vs 红球）当然对不上——那说明「这段没画完」，不说明磁力线不闭合。典型例子 ι = 5/2（n = 2）：T 取 2 / 4 / 6 / 8 / 10 时首尾重合，T 取 5 时终点落在闭合曲线对侧、净差 0.5 圈，但磁力线照样闭合。点 ⌖ 跳到最短闭合圈数 可以直接把 T 设到 n 上验证这一点。

✅ 「重合」与「闭合」的逻辑关系（容易绕晕，一次说清）：起止点精确重合意味着 ι·T = 整数，于是 ι = 整数/T 必为有理数 ⇒ 磁力线必然闭合。所以「精确重合」是「闭合」的充分条件；反过来「不重合」却推不出「不闭合」（T 没取到 n 的整数倍而已）。闭合的真正判据始终是 ι ∈ ℚ，与 T 无关。

把 ι 拖到 2（第一族）再看 √2（第二族）—— 同一个环，同一个磁面，命运完全不同。这就是这两族解最直白的可验证差异。

⚠️ 边界声明（务必先读）：这个 3D 场是一个运动学玩具场——它严格满足 ∇·B = 0、磁面严格嵌套、ι 可任意指定，但它 不满足力平衡 (∇×B)×B = ∇p。缺的恰恰是 Landreman 那两族解真正的贡献：力平衡 + 处处光滑 + 初等函数显式可写。

本页演示的是"力平衡之外的那部分"——旋转变换如何决定磁面是被"闭合的磁力线"还是"稠密的磁力线"填满。这一点，玩具场与真解完全一致（Landreman 原文就用到了它："For irrational ι, any equilibrium pressure would have to be constant on each torus because the field lines are dense on it."）。

另外：图上没有线圈。两族解都不带实体线圈方案——"怎么把这个场造出来"是另一门学问，属于冷水之一。

2庞加莱截面 —— 判别「闭合 vs 缠满」的标准工具

3D 里磁力线看着都像一团毛线，肉眼分不出闭合与缠满。判别的标准做法是庞加莱截面：只在 φ = 0 这个平面上记录磁力线每次穿过的位置 (r, θ)。ι 有理 → 反复落在同几个点；ι 无理 → 落点连成一条闭合曲线，把整层磁面铺满。

右边这半张图是本项目的关切点。把 ι 设成有理数（比如 2 或 5/2）并把 ε 拖大 —— 你会看到嵌套的圆环被撕成一串串"岛链"（磁岛 / island）。这正是仿星器圈最怕的事：

  • 有理面 ι = m/n 上，磁力线绕 n 圈后闭合，与线圈磁场的傅里叶谐波共振；
  • 磁面被撕成磁岛，磁场拓扑被破坏（VMEC 这类"假设嵌套磁面"的求解器自己算不出磁面破裂）；
  • 有理面上还会冒出 J ∼ 1/x 型奇异平行电流，物理上不成立。

把 ι 换成 √2（第二族实取的无理值）再把剪切调大 —— 岛链消失，磁力线老老实实把磁面铺满。真实仿星器要的就是后者。

🔧 想看磁岛？照这个配方调：

  1. 把 ι 剖面切到「带剪切 ι(r)」、剪切强度拉到 0.60、共振谐波 m 设为 4；
  2. 点一下 ⌖ 对准共振面 —— 它会把最外那层磁面精确放到某条 ι = j/m 上；
  3. 然后把 扰动强度 ε 从 0 慢慢往上拖。你会看到那层圆环被撕成一串岛链，而没落在共振面上的层基本安然无恙。

⚠️ 关键的一点，也是真实物理：磁岛只在「有剪切 + 落在有理面」的地方长出来。把剪切拉回 0（ι 变成严格常数）再加大 ε —— 岛长不出来，磁力线反而会整体径向漂移、磁面被直接推散。

这正好解释了为什么第一族（ι ≡ 2，常数、无剪切）虽然是有理面却不是好设计，而第二族（带剪切、几乎每层无理）才接近工程实际 —— 与整理文档 03 §四"闭合 vs 缠满"的结论一致。

本图的扰动模型是示意性的扭转型磁场线映射 r ← r + ε·sin(mθ)，θ ← θ + 2π·ι(r)，与整理文档 07 §S3 提出的检验实验同构。它不是 MHD 平衡解，只用于演示"共振 → 磁岛"这一机制。

"不重复落点数"判据已做数值验证：有理 ι = m/n ⇒ 落点塌缩到 n 个位置（ι = 2 → 1 个；5/2 → 2 个；7/3 → 3 个）；无理 ι（√2、φ−1）⇒ 落点几乎不重合。洁净场的"散布"指标同时命中了文档 04 的解析锚点 —— 铺满时散布 = r₀（实测 0.0800 / 0.1450 / 0.2100，逐位相等）。

3真实装置有理面尺 —— 设计目标被量出来了

"让 ι 避开低阶有理数"到底是口号还是真在做？归档 Zenodo 大包后拿到了三台真实装置的 VMEC 平衡文件（wout_*.nc），把它们的 ι 剖面直接摆到有理数尺上量。分母 n 越小，共振越危险：n = 1、2 的磁岛最宽。

实测结论：三个构型全部避开了 n ≤ 6 的低阶有理面，而且用了三种不同的避开策略——

  • HSX（真实运行装置）：把整条 ι 剖面抬到 1 以上，直接绕开 1/1；跨度 0.064，有剪切。
  • precise QA（准轴对称）：把 ι 挤在 5/12 附近，但压窄跨度，只跨 2 个高阶面。
  • precise QH（准螺旋对称）：最极端——跨度只有 0.0034，n ≤ 20 一个有理面都不跨，离最近的 −5/4 还有 5.0×10⁻³。

这不是巧合，是明确写进优化目标的设计。→ 这条证据把 07 文档的"桥 A"从"措辞相似"抬到了"在真实装置数据上量得到同一个设计目标"。

数据坑（已踩）：VMEC 的 iotas[0] 是轴心占位 0、不是真 ι；部分 wout 轴心是 NaN。必须优先读 iotaf 并滤掉非有限值，否则有理面全被算到 s ≈ 0.0005、剪切算成 1059。本图数据来自文档 07 的实测表。

冷水四盆（每盆都是硬边界）

解只是"受力平衡"，不等于扰动下不崩。MHD 稳定性（Mercier 判据等）、湍流、新经典输运、高能粒子约束——一个都没碰。
② GSJT 族不能当设计

③ 没有线圈

④ 工程三座大山原封不动
材料（扛中子）、氚自持、能量增益 Q——聚变真正的卡点全在这些 measurable 的工程问题上。

④ 方法论：启动老问题的成本被压到极低
一个研究者、一个对话框、20 分钟，提示词与验证脚本全公开可复现。但分工必须说清：AI 负责提出构造，人负责验证正确性与判断价值。这是"AI 挤进发现新数学结构环节"的第二次出现——两次都验证同一条：AI 的产出必须过"独立验证"这关才算数。

对外引用时用这个口径：AI 没有解决核聚变；它做的是——一组人 + AI 把 Grad 悬了 59 年的"完美三维磁笼子不存在"猜想推翻了，给了仿星器理论地基一个存在性确认，给了数值仿真界一把精确标尺。离发电还隔着稳定性、材料与氚自持、能量增益三座大山。

7SEG ↔ Anu ↔ 仿星器 —— 真正共享的是一条防共振的数学

这条桥是老师要的、也是本目录认为最值得写进正式笔记的一条。它不靠形状相似，靠可以算。

桥 A：两个领域独立长出了同一条设计铁律

SEG（磁齿轮消音）项目内仿星器（磁面保护）教科书
两个"绕数"定子磁极数 N 与滚筒磁极数 P环向绕数 1 与极向绕数 ι
灾难gcd(N,P) = d > 1 ⇒ 每 N/d 圈周期性对齐 ⇒ "嘎嘣嘎嘣"振动、定点磨损ι = m/n（低阶分数）⇒ 与线圈谐波共振 ⇒ 撕出磁岛 + J ∼ 1/x 奇异电流
处方gcd = 1（互质）+ lcm 尽量大ι 无理（最好带剪切、逐层变化）
数学身份同一个：旋转数的丢番图逼近——避开低阶有理逼近。KAM 理论下它们甚至是同一个定理的两件外衣。

桥 B：二次无理数在两侧同时以"最无理"身份出场

⚠️ 2026-10-08 口径下修（据一手 PDF 实测）：Landreman 第二族实际取的是 ι = √2 = 1.41421356…，不是黄金比 φ。

所以这条桥的正确说法是："二次无理数（φ = (1+√5)/2 与 √2）在两侧同时以'最无理'身份出场"——不要说成"两边都是黄金比"，那是此前从元宝转述推出的过度推断，现已下修。

冲突三条（物理内核的硬边界）

① 拓扑不同（最致命）
Anu 螺旋绕自己的中心轴缠——像一根弹簧、闭合于自身；仿星器是环面结：绕大环一圈的同时绕截面转圈，两个周期叠在一起。甜甜圈上拧的麻花 ≠ 一根弹簧。
② 磁场不能有源和汇
Anu 的正负 = "力涌出的泉"与"力流入的洞"——有源有汇；但磁场满足 ∇·B = 0（无磁单极），磁力线无头无尾。这是方程层面的硬约束，不是设计偏好。
③ 量级差三个数量级
真实仿星器 ι ∈ 0.1 ~ 2；1680 匝意味着绕一圈转 1680 次——磁剪切大到任何等离子体瞬间撕碎、电流密度爆掉，且没有线圈能造出这种场。

口径收束：同构在表面，分歧在方程。Anu 与仿星器共享螺旋、嵌套、轴、手性、靠流动维持这套几何词汇——足以让 Anu 成为一个漂亮的直觉模型；但它们不共享拓扑（弹簧 vs 环面结）与守恒律（有源汇 vs ∇·B = 0）。

Anu 给的是图像，图像不能替你算数；方程才能。

另注：SEG 的滚筒在转，场是时间相关的；而 MHD 平衡（含这次两族解）说的是静场。所以 SEG 与"仿星器平衡"之间不存在直接的方程对应——能对应的只是设计原则层（桥 A / B），不是解层。

04 · 方法论的落点

分歧的实质不是"灵视真假"，而是它在认知流水线上的位置。两边其实共享同一条流水线，只是把"判定权"放在了不同环节：

直觉 / 灵视（提出结构） → 可计算化（写成数 / 不等式） → 数值 / 实验判定 → 累积

据此本项目的三条规则：① 保留输入通道（灵视/直觉产出的结构按 S1–S2 入表、可计算化）；② 判定交还可仲裁环节（凡要写成"结论"，必须过数值/实验关——本页每个滑块都是按这个标准做的，可由第三方重跑复核）；③ 给灵视一条明确的升级通道（预登记预测：产出一条先于实验、可量化、随后被证实的预测即升级；截至 2026-10，这样的记录数为 0）。

灵视可以当猜想生成器，不能当判定器。这条流水线上缺的从来不是"看到"，是"仲裁"。
