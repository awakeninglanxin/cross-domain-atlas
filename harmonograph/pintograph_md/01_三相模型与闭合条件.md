# 01 · 三相 pintograph 模型与闭合条件

> 来源：与元宝的对话（三相相位差 120° 波形编程实现）整理
> 主题：三个振子、时间相位与空间方向都相隔 120° 的画图模型

---

## 0 一句话总纲

> **等频等幅时笔尖走出正圆；频率一错开，圆就裂成三瓣结 / 编织网 / 星芒。闭合 ⟺ 三频率可公度。**

---

## 1 核心方程

三个振子，时间相位与空间方向都相隔 120°（Δφ = 120°）：

```
s_k(t) = A_k · e^(−d_k·t) · sin(2π·f_k·t + k·Δφ)      k = 0,1,2
z(t)   = Σ_k s_k(t) · e^(i·k·Δφ)
Δφ     = 120°  （可调 0°→120°，用来观察序分量）
```

- `A_k`：振幅；`d_k`：阻尼（d>0 时衰减螺旋，就是真 harmonograph 笔迹）；`f_k`：频率
- 关键性质（已数值验证）：**等频等幅时 |z| 恒为 1.5 → 笔尖走出正圆**，这就是三相电机的恒幅旋转磁场

与网上现成实现的差别：最接近的只有 EEVblog 那种把三相分别当 X/Y/Z 的 3D Lissajous，以及电机里的空间矢量（Clarke 变换）——本模型把后者当成了画笔轨迹。

| 1 | 频率比扫描 | 1:1:1（圆）、1:1:2、1:2:3、2:3:4、1:2:5、3:5:7，小整数比图案闭合 |

## 3 闭合条件（严格可证）

> **闭合 ⟺ 三个频率可公度（两两之比为有理数）⟺ ∃T 使 f₁T、f₂T、f₃T 全为整数。**

为什么可证：把笔迹写成指数形式（q = e^{i120°}）：

```
z = (A/2i)·[ Σ q^{2k}·e^{+iω_k t} − Σ e^{−iω_k t} ]
              └─ 正序侧：三个正向旋转矢量 ─┘   └─ 负序侧 ─┘
```

笔迹 = 三项正序外摆线 − 三项负序外摆线。它是 6 个指数项的线性组合，而标准 120° 下这 6 个系数恒不为零。三角多项式 T-周期的充要条件就是所有频率都是 1/T 的整数倍 —— 判据得证。
数值验证：闭合案例回环误差 1e-15 量级。

---

## 4 最小周期（也是复杂度度量）

```
D = 三频率最简分数分母的最小公倍数
n_k = f_k · D
g  = gcd(n₁, n₂, n₃)
T  = D / g          ← 最小周期
T 内第 k 相振动 n_k/g 次
```

所以 **形状只由整数比决定**：2:4:6 和 1:2:3 图案完全一样，只是画得快一倍（T = 0.5 vs 1）。

---

## 5 反直觉结论：三相标准下没有 3 重对称

要 z(t+τ) = e^{iα}·z(t)：

- 正序侧要 e^{+iω_kτ} = e^{iα}
- 负序侧要 e^{−iω_kτ} = e^{iα}

两者只能同时成立于 **α = π**。所以标准三相下旋转对称最高只有 **2 重**，3 重及以上不存在（除非退化成圆）。

| 对称性 | 判据 |
|---|---|
| 2 重中心对称 | 整数比最简后非零项全为奇数（取 τ = T/2） |

独立数值检测器在 12 组上交叉验证，100% 吻合：

| 频率比 | 中心对称 |
|---|---|
| 1:3:5 | 是 |
| 3:5:7 | 是 |
| 5:7:9 | 是 |
| 1:2:3 | 否 |
| 2:3:4 | 否 |
| 1:4:7 | 否 |

## 6 三个坑

| 写法 | 实际后果 |
|---|---|
| 1 : √2 : 3 | 永不闭合，稠密填满 |
| 1 : 1.01 : 0.99 | 数学上闭合，但周期从 1 暴涨到 100，看着像一直在进动 |
| 加阻尼 d>0 | 衰减，永不重复（真 harmonograph 就是靠这个出味） |

**想出漂亮闭合图案，最实用的一招：三个小整数、互质、别用小数。** 另外负频率（如 1:-2:3）照样闭合，只是图案镜像。

## 8 推广：振子数 m 取奇数

三相只是 **m = 3** 的特例。把模型推广到 m 个振子（时间相位与空间方向都相隔 Δ = 360°/m）：

```
s_k(t) = A_k · e^(−d·t) · sin(2π·f_k·t + k·Δ)      k = 0 … m−1
z(t)   = Σ_k s_k(t) · e^(i·k·Δ)                    Δ = 360°/m
```

- **m 取奇数（3 / 5 / 7 / 9 / 11）**：每相地位等价、两两不成直径对立 ⇒ 支撑集 {±ν} 的对称性分析与三相完全一致 ⇒ **旋转阶仍被锁在 ≤ 2**（除非全同频退化成圆）。这才是「三相 120° 族」的自然推广。
- **m 取偶数**：出现直径对立（Δ·m/2 = 180°）⇒ 支撑集不再对称 ⇒ **镜像对称被解锁**。所以 4 相 90° 是**另一类机器**，不属于本族。

| m（振子数） | Δ = 360°/m | 旋转阶上限 | 镜像对称 |
|---|---|---|---|
| 3 | 120° | 2 | 无 |
| 5 | 72° | 2 | 无 |
| 7 | 51.4° | 2 | 无 |
| 9 | 40° | 2 | 无 |
| 11 | 32.7° | 2 | 无 |
| 4（偶数，对照） | 90° | 2 | **有**（属另一类） |
| 6（偶数，对照） | 60° | 2 | 视配置 |

**所以探索台的振子数滑块只给奇数档位 3 / 5 / 7 / 9 / 11。** 想要镜像对称就走「旋转叠加 + 镜像」，或换 4 相 90° 另一套机器。

> 附：状态条对 m 个振子同样实时报「闭合 / 整数比 / 周期 T / 对称阶（≤2）」，
> 判据与三相完全相同 —— 因为奇数相对奇数相，结构不变。
