# 三相 120° 相位差 · 频率可调 画图机

不是经典的**四相 XY 双参数** harmonograph（`x` 两个正弦 + `y` 两个正弦），
而是**三个振子**，彼此的时间相位与空间方向都相隔 **120°** —— 也就是三相电机里
"空间矢量 / Clarke 变换"的几何。

## 核心方程

```
s_k(t) = A_k · e^(−d_k·t) · sin(2π·f_k·t + k·Δφ)        k = 0, 1, 2
z(t)   = Σ_k s_k(t) · e^(i·k·Δφ)          →  x = Re(z), y = Im(z)
Δφ = 120°
```

* `f1 = f2 = f3` 且等幅 ⇒ `|z|` 恒定 ⇒ 笔尖走出**正圆**
  （三相等幅、120° 相差 ⇒ 合成矢量为恒幅旋转矢量，这正是三相电机旋转磁场的原理）
* 频率比取不同整数 ⇒ 三瓣结、编织网、星芒、蕾丝球等**闭合图案**
* 频率比非整数 / 近整数失谐 ⇒ 缓慢**进动**，永不重合
* 加阻尼 `d` ⇒ 衰减螺旋，即真正的 harmonograph 笔迹
* Δφ 从 0° 拧到 120°：抵消成一点 → 椭圆 → 正圆；取 −120°（负序）图案镜像

## 曲线闭合判据（`closure.py`）

**结论：三相等幅、标准 120° 分布时，笔迹闭合 ⟺ 三个频率可公度（两两之比为有理数）
⟺ 存在 T>0 使 f₁T、f₂T、f₃T 全为整数。**

### 为什么（可证明）

把 z(t) 写成指数形式（q = e^{i120°}，φ_k = θ_k = k·120°）：

```
z = (A/2i)·[ Σ_k q^{2k}·e^{+iω_k t}  −  Σ_k e^{−iω_k t} ]
     └── 正序侧：三个正向旋转矢量，权重 1, q, q² ──┘  └ 负序侧 ┘
```

即笔迹 = 三项正序外摆线 − 三项负序外摆线。它是 6 个指数项 e^{±iω_k t} 的线性组合，
而在标准 120° 设置下这 6 个系数**恒不为零**（q^{2i}−1≠0，q^{2i}+q^{2j}≠0），
所以三角多项式 T-周期的充要条件（所有频率都是 1/T 的整数倍）直接给出判据。

### 最小周期

```
把 f_k 写成最简分数 → D = 分母的最小公倍数, n_k = f_k·D, g = gcd(n_1,n_2,n_3)
最小周期 T = D / g       T 内第 k 相振动 n_k/g 次 ← 这就是图案复杂度
```

例：`f = (2,4,6)` → 最简比 1:2:3 → T = 0.5，图案与 `f=(1,2,3)` 完全相同（只是画得快一倍）。
**形状只由整数比决定，与频率的绝对大小无关。**

### 旋转对称：只有 2 重，没有 3 重

要求 z(t+τ) = e^{iα}·z(t)，正序侧给出 e^{+iω_kτ}=e^{iα}，负序侧给出 e^{−iω_kτ}=e^{iα}，
两者只能同时成立于 α=π ⇒ **标准三相设置下不存在 3 重及以上的旋转对称**。

> **2 重（中心）对称 ⟺ 整数比化为最简后，非零项全为奇数**（此时 τ = T/2）

数值检测器 `symmetry()` 与这条规则在 12 组随机组合上 100% 吻合：`1:3:5`、`3:5:7`、
`5:7:9` 中心对称；`1:2:3`、`2:3:4`、`1:4:7` 不对称。

### 三条常见"不闭合"陷阱

| 情形 | 后果 |
|---|---|
| 无理比（1 : √2 : 3） | 永不闭合，稠密填满区域 |
| 小数失谐（1 : 1.01 : 0.99） | 数学上闭合，但周期从 1 暴涨到 **100** → 看起来一直在进动 |
| 加阻尼 d>0 | 衰减，永不重复（真正的 harmonograph 笔迹） |

## 三种有特点的频率规律（`patterns.py`，等幅前提）

先说两条由恒等式直接推出的**对称性定理**（21 组样本 100% 吻合，并代回真实曲线验证到 1e-15）：

- **T1 旋转对称**：除正圆外，最高只有 **2 重（中心对称）**。
  正序侧要 e^{+iω_kτ}=λ、负序侧要 e^{−iω_kτ}=λ ⇒ λ=±1 ⇒ λ 只能取 −1。
  **2 重中心对称 ⟺ 最简整数比全为奇数**（等价：支撑集 {±ν_k} 中所有元素同奇偶）。
- **T2 镜像对称**：**除正圆 (f₁=f₂=f₃) 外，永不出现镜像对称轴** —— 所有非圆图案都是手性的（有旋向）。
  推导：λ 需同时满足 λ=±1（k=0）与 λ=±q²（k=1），无解。

所以"美"不来自镜像/多重对称，而来自下面三种**可预测的结构**：

### 规律一 · 编织带族　f = (a, b, b) 且 **b > a**

闭式（已验证到 1e-15）：

```
x = sin(ω_a t) + ½·sin(ω_b t)      y = (3/2)·cos(ω_b t)
```

`y` 退化成**单一频率** ⇒ 整条曲线是"横向起伏的带"，正是 guilloche / 编织纹的样子。

| 性质 | 结论 |
|---|---|
| **花瓣数** | **= 2b，完全由重复的那个频率决定，与 a 无关** |
| a 的作用 | 只控制带上的波纹密度（每周期 a 个横向波、b 个纵向往返） |
| 三种放置 | (a,b,b) / (b,a,b) / (b,b,a) 花瓣数相同，形状互为旋转 |

扫了 b ≤ 9 的全部组合，b>a 时 `花瓣 = 2b` **无一条例外**。
推荐：`1:5:5`(10瓣) · `2:7:7`(14瓣) · `3:8:8`(16瓣) · `5:9:9`(18瓣)

### 规律二 · 玫瑰族　f = (n, n+d, n+2d) 等差数列

闭式（已验证到 1e-15）—— 两个反向旋转的**变幅**矢量，各自是玫瑰线生成器：

```
P(t) = e^{iω₂t}·e^{i240°}·[1 − 2cos(2πd·t + 60°)]
N(t) = e^{−iω₂t}·[1 + 2cos(2πd·t)]
```

| 性质 | 结论 |
|---|---|
| **花瓣数** | **= 2n + 4d**（47 组扫描 45 组命中） |
| **穿心** | 在 t = (2/3+m)/d 处 **精确穿过圆心**，共 **d 次**（A=B=0 ⇒ \|z\|=0） |
| 例外 | n ≡ 3 (mod 6) 且 d ≡ 0 (mod 4) 时花瓣少 2 |

推荐：`1:2:3`(6瓣) · `2:3:4`(8瓣) · `5:6:7`(14瓣) · `7:9:11`(22瓣)

### 规律三 · 中心对称族　最简整数比**全为奇数**

由 T1，这是唯一能拿到的非平凡对称：图案**稳、平衡**；含偶数则不对称，更有手写/动感。

**与规律二叠加就是最优解**：等差 + `n 奇、d 偶` ⇒ 三频全奇 ⇒
**既玫瑰（花瓣 2n+4d、穿心 d 次）又中心对称**。

推荐：`1:3:5`(10瓣) · `3:5:7`(14瓣) · `5:7:9`(18瓣) · `7:9:11`(22瓣) · `1:5:9`(18瓣)

### 速查配方

| 想要 | 取法 |
|---|---|
| 带状编织纹 | 两同一异、重复的那个较大：`(a, b, b)`, b>a → 花瓣 2b |
| 玫瑰 + 中心尖点 | 等差数列 `(n, n+d, n+2d)` → 花瓣 2n+4d、穿心 d 次 |
| 稳重平衡 | 全奇数比；最好 `n 奇 + d 偶` 的等差 |
| 密蕾丝 | 三频互异、互质、数值大且不成等差，如 `5:8:11`、`7:11:13` |
| 千万别用 | 无理比（永不闭合）；`1:1.01:0.99`（周期暴涨到 100） |

命令：`python patterns.py theorems` / `forms` / `sweep --max 9` / `figure`

## 三种规律能叠加吗？（`hybrid.py`）

**先分清两类东西**：① 和 ② 是**结构原型**（决定形态），③ 是**对称性修饰**（决定稳不稳）。
所以按"家族成员"计，①② 只能二选一，③ 是免费加在任一上的。

| 组合 | 可行 | 说明 |
|---|---|---|
| ① + ② | **✗ 结构互斥** | ① 要求至少两频相等，② 要求 d≥1 即三频互异。穷举 1..12 全部三元组，**交集 = 0** |
| ① + ③ | ✓ | 如 `5:7:7` — 全奇的编织带 |
| ② + ③ | ✓ | 如 `5:7:9` — n 奇、d 偶的等差 |
| ①+②+③（按家族） | ✗ | 因①②互斥，唯一的"交集"是退化情形 d=0 即 `n:n:n` → 正圆（结构退化） |
| ①+②+③（按**视觉特征**） | **✓ 可以！** | 见下 |

### 但三者的"视觉特征"可以同时出现

① 族在特殊 (a,b) 下会**精确穿过圆心** —— 而"中心尖点"正是 ② 的标志性特征。
放置 A = `(a, b, b)`（互质、b>a）的穿心判据，**711 组穷举、0 例外**：

```
穿心  ⟺  b ≡ 3 (mod 6)  且  gcd(a,6) = 1  且  a + b ≡ 2 (mod 4)
穿心时刻恒为 t = 1/12, 5/12, 7/12, 11/12 —— 恰好 4 次, 与 b 无关
```

**更妙的是**：`b≡3 (mod 6)` ⟹ b 奇；`gcd(a,6)=1` ⟹ a 奇
⟹ 最简比全为奇数 ⟹ **③ 中心对称是免费的**（30 个穿心组合，30 个全奇，无一例外）。

所以只要造出"带尖点的编织带"，③ 自动跟上 —— 三种效果同时到手：

```
f = (1, 9, 9)     花瓣 18 = 2b   穿心 4 次   中心对称   ← 推荐
f = (5, 9, 9)     花瓣 18        穿心 4 次   中心对称
f = (7, 15, 15)   花瓣 30        穿心 4 次   中心对称
f = (11, 15, 15)  花瓣 30        穿心 4 次   中心对称
f = (1, 21, 21)   花瓣 42        穿心 4 次   中心对称
...  (b = 9, 15, 21, 27, 33, 39, 45, ...)
```

### 那到底更美吗？

诚实讲：**叠加 ≠ 更好看**，是"更密、更工"。

- **①+③（如 `5:7:7`）**：中心是空的，编织带干净舒展 —— 最像钞票防伪的 guilloche 底纹。
- **②+③（如 `5:7:9`）**：花瓣从中心发散，最像玫瑰窗 —— 视觉焦点明确。
- **①+②+③（如 `1:9:9`）**：编织带上多了一条贯穿圆心的主轴，密度高、工艺感强，
  但中心不再通透。**要"呼吸感"选前两者，要"密不透风的织物感"选叠加。**

命令：`python hybrid.py check` / `figure`

扫描 n ≤ 16 的全部互质三元组（**3433 组**），结果：

|---|---|
| 旋转阶 > 2 的组合 | **0**（2958 组 1 重，474 组 2 重） |
| 镜像轴总数 | **0** |

| 穿心最多 | `9:2:16`、`15:1:8` 达 10 次 |

**结论：放大 N 只会让图案更密更繁，不会让对称性变高。** 因为天花板是定理，不是采样不足。

### 两个天花板定理（对任意相数 m、任意频率成立）

```
z = (1/2i)[ Σ_k q^{2k}·e^{+iω_k t} − Σ_k e^{−iω_k t} ]      q = e^{iΔ},  Δ = 2π/m
```

- **R) 旋转对称 ≤ 2 重**（圆除外）。
  支撑集永远同时含 +ν_k 与 −ν_k（负序侧系数恒为 −1/(2i) ≠ 0），
  要求 z(t+τ)=λ·z(t) 必须同时有 e^{+2πiν_k u}=λ 与 e^{−2πiν_k u}=λ ⇒ λ=1/λ ⇒ λ=±1。
  **与 m、与 N 都无关** —— 实测 m=3,4,5,6 的旋转阶都是 2。
- **M) 镜像对称 ⟺ m | 4**。由 λ² 需同时等于 e^{4ikΔ}（k=0 给 λ²=1，k=1 给 λ²=e^{4iΔ}）
  ⇒ 4Δ ≡ 0 (mod 2π) ⇒ m|4。所以 **m=3（120°）永不镜像，m=4（90°）解锁**。
  实证：m=4、Δ=90° 下搜到 **160 组**有镜像轴（如 `1:2:3:4`）；m=3 下扫 3433 组为 0。

### 想要高对称？三条路

1. **接受 2 重**（全奇整数比）—— 3 相 120° 的天花板
2. **换 4 相 Δ=90°** —— 解锁镜像对称轴（`polyphase(..., m=4)`）
3. **旋转叠加** —— 同一条曲线复制 fold 份、各转 2π/fold，强制 fold 重对称；
   再加镜像得二面体 D_fold（2·fold 条对称轴）。
   **这正是真实 guilloché / 钞票防伪底纹的做法**：单条曲线是手性的，多层叠加才有花窗感。

交互页面的「旋转叠加 3/4/5/6 重」+「镜像」就是这条路。

### 穿心判据（含一处修正）

- **等差族 (n, n+d, n+2d)：恒穿心，恰好 d 次**，时刻 t = (2/3+m)/d。
  （⚠️ 修正：之前用粗网格误判"d≡0 mod 3 时不穿心"，加密局部搜索后确认
  `1:4:7` 在 t=2/9、`1:7:13` 在 t=7/9 处 |z| ≈ 3e-16，确实穿心。）
- **三频互异非等差**（n ≤ 12 全扫）：
  mod 3 余数覆盖 **{0,1,2} → 100% 穿心**（228/228）；
  两个余数 → 约 25~30%；单一余数 → 0%。

命令：`python bigsweep.py sweep --max 16` / `verify` / `figure`


## 原生 6 重 / 7 重：不靠叠加，靠频率（`native.py`）

**先直接回答**：上一轮那张 6 重图**不是**频率给的 —— 底稿 `5:6:7` 虽是等差数列，
但 6 重来自旋转叠加。在标准 3 相 120° 模型里，`1:7:13` 实测只有 **2 重**（支撑集
恒为 {±ν}，λ 只能取 ±1）。**任何频率组合都给不出原生 6 重/7 重。**

但换个机器就行 —— 关键是把支撑集做成**单向**（挣脱 ±ν 成对）：

```
z(t) = Σ_k e^{+i·2π f_k t}        f_k 取负号即反向旋转
```

### ★ 单向三矢量 + 等差数列 → 恰好 d 重

闭式（验证到 1e-14）：

```
z(t) = e^{i·2π(n+d)t} · [ 1 + 2·cos(2π·d·t) ]
        └ 旋转 ┘        └── 幅值调制 ──┘
```

| 性质 | 结论 |
|---|---|
| **旋转对称阶** | **= d**（公差），gcd(n,d)=1 时 |
| 花瓣数 | **= 2d** |
| 穿心 | **2d 次**，时刻 t = (1/3+k)/d 与 (2/3+k)/d |

```
6 重  →  f = 1:7:13   5:11:17   7:13:19      (12 瓣, 穿心 12)
7 重  →  f = 1:8:15   2:9:16    3:10:17      (14 瓣, 穿心 14)
```

### ★ 双向两矢量（更省振子）

| 配置 | 对称阶 | 6 重 | 7 重 |
|---|---|---|---|
| 反向 (+a, −b) | **(a+b)/gcd** | (1,−5) | (1,−6) (2,−5) (3,−4) |
| 同向 (+a, +b) | **|a−b|/gcd** | (1,7) | (1,8) |

（这正是万花尺的规律：外摆线 p+q 瓣、内摆线 p−q 瓣。）

### 物理实现：6 个振子

每个旋转矢量由**一对正交振荡器**合成（李萨如圆）：

```
sin(2πft)·e^{i·0}  +  sin(2πft+π/2)·e^{−i·π/2}  =  −i·e^{i·2πft}
```

验证：`z_pairs = (−i)·z_rotary`，相对误差 2e-15。
所以 3 个矢量需 **6 个振子** —— 这就是"旋转摆 harmonograph"的原理，
而标准 3 相 120° 模型只用 3 个振子，代价就是被锁在 2 重。

### 叠加法的隐藏规律（附带发现）

| 底稿 | 叠加 fold | 结果 |
|---|---|---|
| 不对称（含偶） | N | 恰好 **N 重**，N 份副本全不重合 |
| 2 重对称（全奇） | N **奇** | **2N 重**（π 对称与 2π/N 生成 2N 阶群）|
| 2 重对称（全奇） | N **偶** | 只有 N 重，且副本成对重合（**浪费一半墨**）|

实测：`(7,9,11)`（自身 2 重）叠加 7 重 → 实测 **14 重** ✓；叠加 6 重 → 6 重，副本 3/6 重合。
`5:6:7`（自身 1 重）叠加 6 重 → 恰好 6 重，副本 6/6。

## 你要的那个模型：m 个频率 + 间隔 360°/m（`mfold.py`）★

**你的直觉对，但有个必须补的零件。** 先说实测结果：

```
linear: z(t) = Σ_{k=0}^{m-1} sin(2π f_k t + kΔ)·e^{i kΔ},  Δ = 2π/m
```

| m | 频率 | 实测对称阶 |
|---|---|---|
| 4 | 1,2,3,4 / 1,3,5,7 | **1 重 / 2 重** |
| 5 | 1,2,3,4,5 / 1,3,5,7,9 | **1 重 / 2 重** |
| 6 | 1,2,3,4,5,6 / 1,3,5,7,9,11 | **1 重 / 2 重** |
| 7 | 1..7 / 1,3,5,7,9,11,13 | **1 重 / 2 重** |
| 8 | 1..8 / 全奇 | **1 重 / 2 重** |

**一个都拿不到 m 重。** 原因：`sin(θ) = (e^{iθ} − e^{−iθ})/(2i)`，代入后

```
z = (1/2i)·[ Σ_k q^{2k}·e^{+i·2πf_k t}  −  Σ_k e^{−i·2πf_k t} ]      q = e^{iΔ}
```

支撑集**永远同时含 +f_k 和 −f_k**。要 z(t+u) = λ·z(t) 就必须
e^{+2πiνu} = λ 且 e^{−2πiνu} = λ ⇒ λ = 1/λ ⇒ **λ = ±1**。
等差连续整数连"全部 ν·u 为半整数"都做不到 ⇒ 只有 1 重；全奇才勉强 2 重。

> **单个 sin 振子本身就是两个反向旋转的矢量 —— 这是原罪，与 m、与频率都无关。**

### ★ 补上这个零件就成立：每个频率用一对正交振荡器

```
sin(A)·e^{iθ_k}  +  sin(A + 90°)·e^{i(θ_k − 90°)}  =  −i·e^{i(A + θ_k)}
                                                        ↑ 纯单向旋转矢量
```

反向分量被抵消，支撑集只剩 `{f_k}`。于是：

```
旋转阶 = D / gcd(|ν₀|, D)        D = gcd{|ν_k − ν₀|}
```

**等差 f_k = n + k·d  ⇒  D = d  ⇒  阶 = d / gcd(n, d)**
取 **d = m、gcd(n,m)=1 ⇒ 恰好 m 重**。

| 目标 | 频率 (n=1, d=m) | 振荡器 | 实测 |
|---|---|---|---|
| 4 重 | 1, 5, 9, 13 | 8 | 4 重 ✓ |
| 5 重 | 1, 6, 11, 16, 21 | 10 | 5 重 ✓ |
| **6 重** | **1, 7, 13, 19, 25, 31** | **12** | **6 重 ✓** |
| **7 重** | **1, 8, 15, 22, 29, 36, 43** | **14** | **7 重 ✓** |
| 8 重 | 1, 9, 17, 25, 33, 41, 49, 57 | 16 | 8 重 ✓ |
| 12 重 | 1, 13, 25, … , 133 | 24 | 12 重 ✓ |

（残差均 ~1e-14：z(t+u) = e^{2πi/m}·z(t) 严格成立。）

### 闭式（已验证 1e-13）

```
z(t) = e^{i·2πn·t} · (1 − w^m)/(1 − w),      w = e^{i·2π(d·t + 1/m)}
|z(t)| = |sin(π·m·d·t)| / |sin(π·d·t + π/m)|        ← 玫瑰线
```

### 最少要几个振荡器？—— 矢量个数不限制阶！

阶只由**频率支撑集**决定，与用了几个矢量无关。所以：

```
要 6 重 → 频率 (1, 7)  → 2 个矢量 → 4 个振荡器
要 7 重 → 频率 (1, 8)  → 2 个矢量 → 4 个振荡器
要 8 重 → 频率 (1, 9)  → 2 个矢量 → 4 个振荡器
```

**想要 m 个不同频率，就得 2m 个振荡器；只想要 m 重对称，4 个振荡器就够。**
代价换的是图案的繁复度，不是对称阶。

命令：`python mfold.py check` / `figure`
交互：页面选相数 m(2..8)、模型「正交对」，点「设为 m 重等差」一键出 m 重


## ★ 等差不是必需的：真正的条件是「同余」（`congruence.py`）

**直接回答：不是。** 等差只是"同余"里最均匀、最好记的那一种。

```
z(t+u) = λ·z(t)  ⟺  e^{i2πν_k u} = λ  ∀k
                 ⟺  (ν_k − ν₀)·u ≡ 0 (mod 1)  ∀k
                 ⟺  所有频率落在同一个模 D 的同余类,  D = gcd{|ν_k − ν₀|}

                 ⟹  阶 = D / gcd(|ν₀|, D)        ← 充要
```

等差（ν_k = n + k·d）只是"步长 = d、每个余数取一次"的同余。
**只要所有 ν_k ≡ n (mod D)，跳着取、乱序取，阶完全一样。**

| 频率 | 差 | 等差？ | D | 实测阶 |
|---|---|---|---|---|
| 1, 7, 13 | 6, 6 | 是 | 6 | **6 重** ✓ |
| 1, 7, 19 | 6, 12 | **否** | 6 | **6 重** ✓ |
| 1, 7, 31 | 6, 24 | **否** | 6 | **6 重** ✓ |
| 1, 9, 25 | 8, 16 | **否** | 8 | **8 重** ✓ |
| 1, 13, 37 | 12, 24 | **否** | 12 | **12 重**（只用 3 个频率！）✓ |

残差均 ~1e-14。

### 等差有多"少数派"？

穷举 3 个频率（上限 79）、恰好 6 重的组合：**479 组，其中等差仅 23 组（4.8%）**。
非等差占 **95.2%**。所以"等差 ⇒ 对称"是充分不必要 —— 它是最好记的充分条件，不是必要条件。

### 那等差到底好在哪？—— 不是阶，是"均匀度"

| 同为 6 重 | 频率 | 花瓣 | 墨量 |
|---|---|---|---|
| 等差 | 1, 7, 13 | 12 | 4.65 |
| 非等差 | 1, 7, 19 | 18 | 6.91 |
| 非等差 | 1, 7, 31 | 30 | 10.47 |

等差时相位**等间距**分布，幅值因子是干净的 Dirichlet 核 `(1−w^m)/(1−w)`，
图案是最规整的玫瑰 —— **这就是你要的"中心对称性美"的来源：均匀，不是等差。**
非等差时相位疏密不均，同一个 6 重骨架上会长出更密的次级花瓣（墨量翻倍），
更繁复但没那么"干净"。

**一句话：等差给你的是"最均匀的 6 重"，不是"唯一能 6 重的"。**

### 另一个模型下条件完全不同

线性振子（双向支撑集 {±ν}）下，阶只能是 1 或 2，判据是**约分后全为奇数** ——
与等差毫无关系。例：`1,7,13` 全奇 → 2 重；`2,8,14` 约分成 `1,4,7` 含偶 → 1 重。
可见"等差"在双向模型里根本不产生高对称。

命令：`python congruence.py check` / `figure`
页面：状态条会显示"同余判据 gcd(差)=D=6，阶 = D/gcd(|ν₀|,D) = 6（非等差照样成立）"


### 追问：差值必须成整数倍吗？（`python congruence.py multiples`）

**你观察到的 6→12、8→16、12→24 确实是倍数 —— 但那是我挑例子时挑整齐了。
"互成整数倍"是充分不必要，真正必要的是 gcd。**

| 频率 | 差值 Δ | 互成倍数？ | D = gcd(Δ) | 倍数 m=Δ/D | 阶 |
|---|---|---|---|---|---|
| 1, 7, 13 | 6, 6 | 是 | 6 | [1,1] | 6 重 |
| 1, 7, 19 | 6, 12 | 是 | 6 | [1,2] | 6 重 |
| **1, 7, 16** | **6, 9** | **否** | **3** | [2,3] | **3 重 ✓** |
| **1, 11, 26** | **10, 15** | **否** | **5** | [2,3] | **5 重 ✓** |
| 1, 9, 21 | 8, 12 | 否 | 4 | [2,3] | 4 重 ✓ |

`9 不是 6 的倍数`、`15 不是 10 的倍数` —— 照样对称（残差 ~1e-14）。

**只需要"所有差值都是某个公共 D 的整数倍"** —— 而 D 就是它们的最大公约数，
对整数频率来说这是**自动成立**的（gcd 按定义整除每个差值）。所以"整数倍"这个说法
在整数频率下是句废话；真正的信息量在 **D 有多大**。

### 完整判据（三项都要看）

```
阶 = D / gcd(|ν₀|, D)        D = gcd{|ν_k − ν₀|}
```

第二个因子会**吃掉阶**：

| 频率 | Δ | D | ν₀ | gcd(ν₀,D) | 阶 |
|---|---|---|---|---|---|
| 1, 7, 13 | 6, 6 | 6 | 1 | 1 | **6 重** |
| **3, 15, 21** | 12, 6 | 6 | 3 | **3** | **只剩 2 重** |
| 2, 8, 14 | 6, 6 | 6 | 2 | 2 | 只剩 3 重 |
| 5, 11, 17 | 6, 6 | 6 | 5 | 1 | 6 重 |

`3,15,21` 差值很整齐，但首项 3 与 D=6 有公约数 3 ⇒ 阶被吃掉 3 倍。

**极端陷阱**：若 ν₀ 是 D 的整数倍（如 `1,2,3`：D=1、ν₀=1），则 λ ≡ 1 恒成立
⇒ **完全没有旋转对称**（曲线仍闭合，只是不转）。同理 `1, 1.5, 2`（D=0.5、ν₀=1）。

### 非整数频率

有理频率照样成立，阶仍为整数：`1, 5/2, 4` → D=3/2、ν₀/D=2/3 → **3 重**；
`1, 7/2, 6` → **5 重**。
无理（如 `1, 1+√2, 1+2√2`）→ 既不对称也不闭合。

命令：`python congruence.py multiples` / `fig2`
页面：状态条现在显示完整分解 —— `Δ=6,9　gcd(差)=D=3　倍数 m=2,3　gcd(ν₀,D)=1　⇒ 阶=3`


### ★「n 个频率 ⇒ Δ 都是 n 的倍数」—— 必要非充分

你的观察抓到了一条**真实的规律，但只是单向的。**

**必要性（可证，成立）**

```
阶 = D/gcd(|ν₀|,D)  ⇒  阶 | D        又  D | Δᵢ  （D 整除每个差值）
                    ⇒  阶 | Δᵢ
所以:  n | 阶   ⟹   n | 每个 Δᵢ
```

即：**想要阶是 n 的倍数，Δ 就必须都是 n 的倍数。**
穷举验证：n=2/3/4/5 分别检验 480 / 9,600 / 192,000 / **3,840,000** 组，**反例 0 个**。
（这也解释了我之前给的例子为什么"看起来"都满足——我要的 6、12 重都是 3 的倍数，
所以 Δ 被逼成 3 的倍数，是结果不是原因。）

**充分性（不成立）**

Δ 都是 n 的倍数，**不能**保证阶是 n 的倍数 —— gcd(ν₀, D) 会把因子 n 吃掉：

| 频率 | Δ | Δ 都是 n 的倍数？ | D | ν₀ | gcd(ν₀,D) | 阶 |
|---|---|---|---|---|---|---|
| 1, 7, 13 | 6, 6 | 是 | 6 | 1 | 1 | **6 重** ✓ |
| **3, 6, 9** | **3, 3** | **是** | 3 | 3 | **3** | **1 重** ✗ |
| 3, 9, 15 | 6, 6 | 是 | 6 | 3 | 3 | 2 重 ✗ |
| 5, 10, 15 | 5, 5 | 是 | 5 | 5 | 5 | **1 重** ✗ |

反例数：n=3 有 2050 个、n=4 有 1727 个、n=5 有 505 个。
`(3,6,9)` 是最刺眼的一个 —— Δ=[3,3] 整齐到极致，却**完全没有旋转对称**。

**补一个条件就充分**

加上 **gcd(ν₀, D) = 1** 后，`阶 = D`，于是 n | D ⇒ n | 阶。
穷举：n=3/4/5 分别 4030 / 1918 / 1749 组，**反例 0 个 ★**。

**实用口诀**：想让 n 个频率出 n·k 重对称 ——
① 所有 Δ 取 n 的倍数　② 首项 ν₀ 与 D 互素（最省事：**ν₀ = 1**）

命令：`python congruence.py divisible` / `fig3`
页面：状态条会提示"Δ 都是 n 的倍数，但阶不是 —— 被 gcd(ν₀,D) 吃掉了"


### 批量反例通项公式（`counterexample.py`）

**充要条件**

```
反例 ⟺  n | D   且   n ∤ D / gcd(|ν₀|, D)        D = gcd(Δᵢ)
```

**★ 通项 C（最一般）**

```
首项  ν₀ = n·a
差值  Δᵢ 任取, 只要 gcd(Δᵢ) = n·q
⟹  D = n·q,   gcd(ν₀, D) = n·gcd(a, q),   阶 = q / gcd(a, q)
要求  n ∤ q/gcd(a, q)
```

覆盖率：n=3 的 332 个反例、n=4 的 339 个反例，**通项 100% 覆盖**。

**★ 特例 A（等差，最好记）：阶 = q**

```
f_k = n + k·(n·q),  k = 0..n−1,  且 n ∤ q
⟹ Δ 全为 n·q（n 的倍数 ✓）,  D = n·q,  gcd(ν₀,D) = n,  阶 = q（不是 n 的倍数 ✗）
```

| n | q | 频率 | Δ | 阶 |
|---|---|---|---|---|
| 3 | 1 | **3, 6, 9** | 3, 3 | **1 重** ✗ |
| 3 | 2 | **3, 9, 15** | 6, 6 | **2 重** ✗ |
| 3 | 4 | 3, 15, 27 | 12, 12 | 4 重 ✗ |
| 3 | 5 | 3, 18, 33 | 15, 15 | 5 重 ✗ |
| 4 | 3 | 4, 16, 28, 40 | 12,12,12 | 3 重 ✗ |
| 5 | 2 | 5, 15, 25, 35, 45 | 10×4 | 2 重 ✗ |

（q 取 1,2,4,5,7,8,10,11,… 即所有非 n 倍数，可无限批量生成。）

**★ 特例 B（极端）：阶恒 = 1，完全无旋转对称**

```
q | a  即 ν₀ 是 D 的倍数  ⟹  阶 = 1
最简形式:  f_k = (k+1)·d    （d 任意正整数）
⟹ Δ 全为 d, D = d, gcd(ν₀,D) = gcd(d,d) = d, 阶 = 1
```

`2,4,6`　`3,6,9`　`4,8,12`　`5,10,15`　`7,14,21`　`10,20,30` —— **统统只有 1 重**。
这是"等差到极致反而完全无对称"的整族反例，也是最能说明
「Δ 是 n 的倍数」为什么只是必要条件的地方。

**判据口径提醒**：约掉公共因子不改变曲线与阶（只改变速度），所以
`(3,6,9)` 与 `(1,2,3)` 是同一条曲线。但"Δ 是否为 n 的倍数"在约分前后会变 ——
页面按**你输入的原始频率**判定，与这里的公式一致。

命令：

```
python counterexample.py check           # 验证三个通项 + 覆盖率
python counterexample.py figure          # 生成图 fig17
```


## ★ 最省振荡器实现任意 m 重：4 个是硬下界（`minimal.py`）

顺着"阶只由频率支撑集决定、与矢量个数无关"推到底，得到完整的**最小性通项**。

### 4 个振荡器是硬下界

| 振荡器数 | 能达到的旋转阶 | 理由 |
|---|---|---|
| 1 | 无（退化为**线段**） | 单个 sin 振子，实测协方差特征值比 = 0 |
| 2 | 无穷阶（圆） | 1 个正交对、单频率，\|z\| 恒定（1e-16） |
| 3 | **实测 20 组全部 1 重** | 奇数个配不成对；混合模型（1 正交对 + 1 线性振子）支撑集 `{ν₁, ±ν₂}` 仍含 ± 对 |
| **4** | **任意正整数 m** | 2 个单向旋转矢量 ✓ |

有限 m ≥ 2 至少需要 **4 个振荡器**。

### 通项（4 振荡器，覆盖全部 m）

```
同向:  (ν₁, ν₂) = (1, 1 + m)   ⇒  阶 = m,  花瓣 = m
反向:  (ν₁, ν₂) = (1, 1 − m)   ⇒  阶 = m,  花瓣 = m
一般:  阶 = |ν₁ − ν₂| / gcd(ν₁, ν₂)
```

m=2→(1,3)　3→(1,4)　4→(1,5)　**5→(1,6)**　**6→(1,7)**　**7→(1,8)**　8→(1,9)　…　20→(1,21)
实测 m = 2..20 全部 ✓，残差 ~1e-14。

**最小频率跨度**：要 m 重需 |ν₁−ν₂| = m·g，取 ν₁ = g 最省 ⇒ 归一化后**跨度恰好 = m**。

### 加振荡器只买花瓣，不买阶

k 个矢量（2k 振荡器），阶仍为 m，但 **花瓣数 = m·(k−1)**：

| (k, m) | 频率 | 振荡器 | 阶 | 花瓣 |
|---|---|---|---|---|
| (2, 6) | 1, 7 | 4 | 6 | 6 |
| (3, 6) | 1, 7, 13 | 6 | 6 | 12 |
| (4, 6) | 1, 7, 13, 19 | 8 | 6 | 18 |
| (5, 6) | 1, 7, 13, 19, 25 | 10 | 6 | 24 |

(k,m) = (2..5)×(5..8) 共 16 组全部吻合。每加 2 个振荡器，花瓣 +m，**阶不变**。

### 效率结论

```
4 振荡器 → 任意 m 重 ⇒ 效率 m/4，随 m 无上限
2k 振荡器 → 仍是 m 重 ⇒ 效率 m/(2k)，更低
```

**想省硬件，永远用 4 个振荡器；多出来的只买繁复度。**

### 与万花尺完全同构

| 万花尺 | 这里 |
|---|---|
| 外摆线花瓣 = R/gcd(R,r) | (1, 1+m) 同向 |
| 内摆线花瓣 = R/gcd(R,r) | (1, 1−m) 反向 |
| 只用 2 个齿轮出任意瓣数 | 只用 2 个矢量出任意重数 |

命令：`python minimal.py check` / `figure`
页面：预设 `◈最省 4 振荡器 5 重 (1,6)`、`◈最省 7 重 (1,8)`、`◈最省 12 重 (1,13)`


### 4 个振荡器在平面上怎么摆（`layout.py`）

**★ 先给结论：两对之间的夹角 θ 完全随便，只影响朝向，不影响对称阶。**

```
z = Σ_k (−i)·e^{i(2πν_k t + θ_k)}        阶 = gcd(Δᵢ)/gcd(全体频率)
                                          ↑ 式子里根本没有 θ
```

实测 (ν₁,ν₂) = (1, 1+m)，m = 5,6,7,8,12，θ 分别取
(0°,0°)、(0°,90°)、(0°,180°)、随机 —— **阶恒为 m**，残差 ~1e-14。

**唯一硬约束：每个矢量内部必须正交（90°）**

```
振子 2k   : sin(2πν_k t)        沿 θ_k
振子 2k+1 : sin(2πν_k t + 90°)  沿 θ_k − 90°
合成      = −i·e^{i(2πν_k t + θ_k)}      ← 单向旋转矢量
```

若 4 个振荡器**不配成正交对**（4 个各自独立的 sin 振子），支撑集变成
`{±ν₁, ±ν₂}` 成对 ⇒ **阶被锁死在 2**，频率再漂亮也没用。

**最省物理实现：共轴布置 θ₁ = θ₂ = 0**

两组共用同一对轴，于是

```
x(t) = sin(2πν₁t) + sin(2πν₂t)
y(t) = −cos(2πν₁t) − cos(2πν₂t)

z = −2i·cos(π(ν₁−ν₂)·t) · e^{iπ(ν₁+ν₂)t}      ← 玫瑰线闭式
|z| = 2·|cos(π·Δν·t)|        花瓣数 = Δν = m
```

（闭式实测误差 ~1e-15，|z|max = 2，花瓣数 = m 全部吻合。）

**关键省法：同轴的两个振子可以直接叠加成一个驱动信号。**

| 实现方式 | 需要的执行器 |
|---|---|
| 机械摆式 harmonograph | 4 个摆（2 个拉 X，2 个拉 Y） |
| X-Y 平台 / 绘图仪 | **2 个**（X 电机 + Y 电机） |
| 激光振镜 | **2 个**（X 振镜 + Y 振镜） |

所以"4 个振荡器"是 **4 个信号自由度**，但物理执行器最少只要 2 个。

**对偶布置 θ₂ = 180°**

```
z = −i·[e^{iA} − e^{iB}]   ⇒   |z| = 2·|sin(π·Δν·t)|
```
同样是 m 个花瓣，只是相位差半个周期（cos 版与 sin 版）。

命令：`python layout.py check` / `figure`
图：`fig19_layout.png` —— 上排四种布置的方向示意，下排对应图案

## 用法

```bash
python three_phase_harmonograph.py gallery                       # 一次生成整套示例图
python three_phase_harmonograph.py draw --freqs 1 2 3            # 画单张
python three_phase_harmonograph.py draw --freqs 1 2 3 \
       --damping 0.05 0.05 0.05 --out my.png
python three_phase_harmonograph.py draw --model pintograph3 \
       --freqs 1 -3 5 --paper-rot 1 --out pg.png
python make_sweep_gif.py                                          # 生成扫描动画
```

依赖：`numpy`、`matplotlib`（`Pillow` 用于 GIF）。
