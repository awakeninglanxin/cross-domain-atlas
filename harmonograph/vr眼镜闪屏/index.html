闪屏 · 线框立体PHOTIC DRIVING / BINOCULAR STEREO

真双目视差（每帧渲染两遍，两台虚拟相机错开一个瞳距）+ 双眼独立频闪通道。 手写投影、无第三方库、离线可用；几何只是载体，闪烁的频段才是主角。

DESKTOP 电脑版 → 整窗画布 + 右侧参数面板；空格暂停、F 全屏、1/2/3 切输出模式、H 收面板。 MOBILE 手机版 → 全屏 + 锁横屏 + 屏幕常亮；左右两屏区各给一只眼；点屏暂停、长按 1.2 秒结束。
  • 8–30 Hz 是光敏性癫痫最敏感的区间，没有病史也可能首次中招；有癫痫史 / 偏头痛 / 孕妇 / 儿童请勿使用，同屋的人也在暴露范围。
  • 默认亮度 60%、3 秒渐亮、5 秒渐暗；首次先点「试 3 秒」。出现眼痛、恶心、眩晕、幻视停不下来立刻停。
  • 幻方四相数默认基频 6Hz（θ 段）⇒ 全部频率都在 8Hz 以下；切 α/β 会进入敏感区，界面会亮橙色警告。
