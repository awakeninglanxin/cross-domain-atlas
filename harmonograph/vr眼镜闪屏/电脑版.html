规则 A：a+d = b+c（两条对望线和相等）。换算 k = 基频 / max(|a|,|b|,|c|,|d|)， 四个数字按比例缩到基频以内 ⇒ 频率天然可是分数（如 220/221×6 = 5.973Hz）。 基频取 6Hz（θ 段）时全部频率都落在 8Hz 以下，避开光敏敏感区；取 α/β 会进入 8–30Hz。
图形 = x=sin(a·t)−sin(d·t)、y=cos(b·t)−cos(c·t)，t 走满公共周期 T = 2π/gcd(四数) —— 浑天仪探索器同款口径，曲线精确闭合（整数输入时 T = 2π）。

六角数 · 三对六频（3D）开

三对 = x / y / z 三轴（六角幻方 6 个角区数字和，对望 180°）。 x 对给左眼、y 对给右眼、z 对只塑形。

公式与 E:\pythonProject\program\calabi*.py 一致：x = Re[e^{iφ₁}cosh(z)^{2/n}]、y = Re[e^{iφ₂}sinh(z)^{2/n}]、 z₃ = cosα·Im z₁ + sinα·Im z₂（z = u+iv，v∈[0,π/2]）。n² 张 sheet 组成整张曲面； 相位层数 >1 即「多个相位合并」，逐层错色相。采样有预算（总段数 ≤ 5200），n 大时每轴采样自动降。 频率仍走「自由 / 会话」——图形与频闪解耦，任何色盘都可用。

观感

默认上下两屏、面积对等：四相数时 上 = a、下 = c（下排左格），左右 = a / b（上排两格）； 四象限 = 左上 a / 右上 b / 左下 c / 右下 d。六角数取 x₁y₁ / x₁x₂ / y₁y₂，线框场景用左/右眼频率。
背景闪 100% = 纯黑 ↔ 纯白全对比（不像以前是灰蓝薄雾）；调低则峰值灰度下降。⚠ 全白满屏频闪最刺激，先试 3 秒。
红青模式下背景同样会分区闪，但白底相位两只眼都亮、视差会被冲淡 —— 要「立体 + 背景闪」请用 VR 分屏 / 裸眼并排。

视差 0–12：>2 很快会眼酸、复视、眩晕，≥6 多数人已无法融合（只剩重影，当装饰用）； 畸变按你的盒子调：边缘弯就加大，中心发虚就减小。
静态色盘带 ±6° 慢漂移；流彩·全谱 42°/s 循环、马卡龙流光 24°/s 高明度粉彩流动。
