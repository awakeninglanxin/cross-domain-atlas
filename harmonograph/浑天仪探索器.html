为什么是「六角」而不是「六阶」：六角幻方（magic hexagon）是蜂窝状的， 边长 n 个格、共 3n(n−1)+1 格，三个方向各有 2n−1 条行、行和都等于 M。 n=3（1..19, M=38）解唯一；n≥4 不存在用 1..N 的「正常」六角幻方 （整除性证明：M = s/(2n−1) 要求 2n−1 | 5）， 只能用起点不为 1 的「非正常」解 —— 本页 n=4（3..39, M=111）与 n=5（15..75, M=305）就是这种， 页内已自校验（三方向全部行和相等 + 数字无重无漏）。
6 个角天生是 3 对：六边形的对角顶点 (u,v) 与 (−u,−v) 关于中心对称， 三对正好喂给 x / y / z 三轴，相位差 π（对望 180°）⇒ 每轴变成差式。
但有一条硬事实：四角幻方满足 a+d = b+c，是因为奇数阶幻方中心互补； 六角幻方没有这个性质 —— 我穷举了 n=3 的全部 9! 种互补分配，0 个解。 所以三对和（25/18/28）不会自动相等。相等要靠「互补锁 / 配平三对和」手动给， 而它们的差别本身就是 3D 图「漂移 vs 自对称」的开关。

公式乘上 e^(−dᵢt)：d≠0 时包络会额外衰减， 图纹由外向内收成螺线；四频全同且 d 也全同时， 相消退化依然成立（e^(−dt) 可提出去）， 只是残差会被压得更小 —— 这也是您怀疑的「damping 其实不是 0」那条线索。

为什么线不会闪没：本页的画布是「白纸 + 彩墨」，直接往纸上刷黑， 墨会一起被埋掉。所以这里的做法是把纸和墨一起反相 —— 图形先画进一张同尺寸的 离屏层，每帧把它贴回画布后，再按分区用一种「差值」方式压一层灰度 L： out = |层 − L|。L=0 就是原图（白纸彩墨），L=255 是完全反相 （黑纸 + 补色墨，线照样清楚），中间连续过渡。
四个分区各算各的相位：错开 90° 就是「转着闪」，错开 180° 就是 上/下（或左/右）交替、面积对等 —— 正好对应二阶方四相数的四个数字各带一个相位。 区序按 左上→右上→右下→左下，90° 错相时看起来是顺时针转。
图形 / 3D 两个画布可以各开关；中心放大那张小图恒为白底，不参与频闪 （它只用来读空腔，闪起来反而看不清）。
⚠️ 频闪警告：3 Hz 以上就属于频闪内容，8~30 Hz 是光敏性癫痫最敏感的一段。 有癫痫史、偏头痛、光敏感，或看了头晕恶心，请立刻停下 —— 默认 1.6 Hz 是给观感用的安全档。

v28 新增｜四象限 ↔ 二阶方四相数（规律 A）：勾上「四相数联动」后， 四个分区各用自己的频率（不再整屏一个 Hz）： fᵢ = 基频 × vᵢ ÷ 均值，区序恒为 左上 a → 右上 b → 右下 d → 左下 c （就是把二阶方 [[a,b],[c,d]] 原样铺回屏幕）。
① 平均基频归一：四相数动辄几千几万（S=4410 的四角是 1095~1110），直接当 Hz 是荒唐的； 除以四数均值再乘面板基频 ⇒ 只保留比值，数字再大也等价压进 0.2~30 Hz。 均值恒等于面板上那个基频，所以调基频 = 整体快慢，不改相对关系。
② 规律 A 的可见形式：a+d = b+c ⇔ 两条对角的频率均值都等于基频 ⇒ 对角两区同拍（互相同步），相邻两区按差值形成慢拍；差值为 0 时四区整体同步。 面板读数会直接写出 a+d 与 b+c 是否相等。
③ 上下 / 左右 / 整屏也按同一口径分频：上 = a+b、下 = c+d；左 = a+c、右 = b+d。 相位用累加器积分（∫f dt），改频率时不跳相。
