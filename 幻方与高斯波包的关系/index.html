高斯波包 × 幻方：一张能算的映射

幻方给的是离散的各向同性——每一行、每一列、两条对角线的和都相同。高斯包络给的是达到测不准下界的窗。两者真正能接上的地方只有一处：波包中心时刻，每条线的相干和。其余都是类比。

M1　格点 → 原子n² 个格值变成 n² 个载波，每个挂同一个高斯窗。窗宽由带宽或时长定，两者差 39 倍。
M2　线和 → 相干和幻和不是频率，是"中心时刻同相叠加"的幅度。相位一乱，线和就散。
M3　泛对角 → 环面破对角就是绕过边界。高斯搬上环面变成 θ 函数，重叠率可算。

对称叠加：把 n 阶幻方的 8 个等距变体（4 旋转 + 4 镜像）当成 8 个波场在空间里相加。线性叠加对每个频率分量独立，所以它等价于把每格的振幅换成 ak = |Σv eiφv(k)| / m、相位换成 ψk = arg(Σv eiφv(k))。两个后果值得先知道：奇数阶的中心格是唯一不动点（8 个变体都把它放在同一处 ⇒ 权重恒为 1），偶数阶没有不动点（所有权重都被轨道平均压过，6 阶甚至出现权重为 0 的频率——那个 agent 的心跳被对称性彻底抹平）。m 是去重后的场数，小于名义值就说明这个幻方自身带对称性。

    §2　三个映射，逐个写成公式

    M1　格点 → 原子：一个格值换一个载波

    格 (i,j) 的值 v_ij  →  载波频率 f_ij = F(v_ij)
原子      ψ_ij(t) = A(f_ij) · exp(−(t−t₀)²/2σ²) · cos(2π f_ij t + φ_ij)
整张幻方  Ψ(t) = Σ_{i,j} ψ_ij(t)          （共 n² 个原子，共用同一个 σ）

    三种频率映射任选：线性（f=v，代码原样）、八度（f₀·2^(3·u)）、黄金比（f₀·φ^(4·u)），其中 u=(v−v̄)/(v_max−v_min) 把格值归一化到 [−½,½]。

    高斯窗有一条硬恒等式：对 g(t)=exp(−t²/2σ²)，其频谱标准差是 σ_f = 1/(2πσ)，所以

    σ_t · σ_f = σ · 1/(2πσ) = 1/(2π) = 0.1591549
换成半功率宽（功率包络的二阶矩）：Δt·Δf = 1/(4π) = 0.0795775
    这一条是同源自证，不是独立验证。σ 和 B 本来就是同一件事的两种刻度，乘起来当然常数。它的用处不是"证明物理"，而是：你不可能同时把波包做窄又把带宽做窄，改一个另一个必反着动。

    M2　线和 → 相干和：幻和在声场里到底是什么

    取中心时刻 t=t₀，此时每个原子的包络都等于 1，于是第 L 条线（一行/一列/一条对角）的瞬时幅度是

    Ψ_L(t₀) = Σ_{(i,j)∈L} A_ij · cos(φ_ij)      （实部）
|Ψ_L| ≤  Σ_{(i,j)∈L} A_ij                  （等号成立 ⟺ 该线上所有 φ 相同）

    若 A≡1 且 φ≡0，则 |Ψ_L(t₀)| = Σ_{(i,j)∈L} v_ij = S——幻和就是这条线在中心时刻的相干幅度。这就是 M2 的全部内容，也只有这一句是真的。

    可以直接量的一句话：幻方 ⟺ 波包中心时刻，2n+2 个方向的相干和全部相等。各向同性比 min/max = 1.000000。这不是比喻，是能算的。

    反过来说：相位规则一改，这句话就废了。项目里用的是"按格序均分一圈"φ_ij = (i·n+j)·2π/n²，它有一个解析后果——同一列里相邻格的相位差恰好是 n·2π/n² = 2π/n，n 个相位正好绕满一整圈：

    列相干 = |Σ_{i=0}^{n−1} e^{i·i·2π/n}| = 0   （n ≥ 2，严格为零，不是"很小"）
行相干 = |Σ_{j=0}^{n−1} e^{i·j·2π/n²}| / n = sin(π/n) / [n·sin(π/n²)]  → n=15 时 0.9927

    换句话说：现行相位规则把幻方的各向同性单向打穿了——行还剩 99.3%，列被严格清零，对角只剩 6%。幻和 1695 在这儿一分钱都不剩。这不是小数点问题，是性质问题。

    格序 φ=(i·n+j)·2π/n²sin(π/n) / [n·sin(π/n²)]0（严格）sin(π/n)·cos(…)

    表里是闭式，不含任何凭印象写的数。面板切相位，下表会印出对应的数值——n 越大，行相干越接近 1（n=27 时 0.9977），所以"行看起来正常"这件事本身是个陷阱：真正被清零的是列。

    最反直觉的是最后一行：±π 交错把 2n 条行列线全废了，却让两条对角完好无损（面板 11 个可选阶数逐个实测，全部 1.000000）。原因是两条对角线上的 ±1 符号是常量（主对角 i＋i 恒偶，副对角 i＋(n−1−i)=n−1 恒定），所以它俩从头到尾同相。这说明"2n+2 条线"不是一类东西：对角是全局线，行列是局部线，选相位规则时必须分开对待。

    M3　泛对角 → 环面：高斯搬上环面就是 θ 函数

    完美幻方的"破对角"（broken diagonal）本质是越过边界后从另一侧接上，也就是模 n 卷绕。所以它的正确拓扑是环面 T²，而不是平面。把高斯放到周期为 T 的环上，它不再是一个高斯，而是一串：

    ψ_θ(t) = Σ_{k∈ℤ} exp(−(t−t₀−kT)²/2σ²)
相邻像的重叠率  r = exp(−(T/σ)²/2) = exp(−1/(2r_s²))，r_s = σ/T

    r_s = 0.125（代码里的 T/8）⇒ r = e^(−32) = 1.27×10⁻¹⁴，可以当孤立波包；r_s = 0.25 ⇒ r = 3.35×10⁻⁴；要到 r_s ≈ 0.1 以下才配得上"等于一个高斯"。面板上拖动 σ/T，第四张图会立刻从"单峰"变成"梳子"。

    M3b　从 T¹ 搬到 T²：泛对角幻方真正的家（本版补算）

    M3 上面那段只做了一维环 T¹，一个数 r 就够。但泛对角幻方的"折对角"是同时沿两个方向卷绕，它的家是 T²。搬到二维之后，重叠率不再是一个数，而是三个——因为同一个环面里，包到"自己的像"有三条不同距离的路：

    一维：r = e−(L/σ)²/2　（L = 环面边长，一个数说了算）
    二维：沿轴最近像 (L, 0)　　d = L　　　r轴 = e−(L²/2σ²) = r
    　　　斜向最近像 (L/2, L/2)　d = L/√2　　r斜 = e−(L²/4σ²) = √r
    　　　沿对角绕回 (L, L)　　d = L√2　　r绕 = e−(L²/σ²) = r²

    三个值差得很远（σ/L = 0.25 时：3.35×10⁻⁴ / 1.83×10⁻² / 1.13×10⁻⁷）。但这三个都不是判据。"绕回值"根本没有信息量——走到 (L,L) 就是下一个周期的峰，函数值本来就是 1 的邻居，拿它当重叠率是把周期化本身当成重叠。真正决定"波形会不会被环面折叠污染"的是谷底：

    轴向谷底（在 (L/2, 0)）：　G ≈ 2·e−(L²/8σ²)　（左右两个像等距 L/2）
    对角谷底（在 (L/2, L/2)）：G = 4·e−(L²/4σ²) = 4√r　（四个角像等距 L/√2）
    比值 C = 对角谷 / 轴谷 = 2·e−(L²/8σ²)
    C = 1　⟺　e−(L²/8σ²) = ½　⟺　σ = L / (2√(2 ln 2))　⟺　FWHM = L

    这条临界值是干净的：包比格子窄（FWHM < L）时，对角方向的谷底更低——对角线反而更"干净"；比格子宽（FWHM > L）时，轴向更干净。临界点恰好落在"高斯半高宽正好等于一个格子边长"上，不是随便某个数。

    σ/LFWHM/L轴谷（数值求和）对角谷（数值求和）C 数值C 解析

    数值列是在 T² 上对像格求和（±10 个周期，收敛到 1e−15）后在两个谷点上取的；解析列是 C = 2e^(−L²/8σ²)。σ/L ≤ 0.30 时两者吻合到 3 位；σ/L = 0.50 时偏差 25%，因为那时旁像已经多到"最近两像"的近似不够用了——这不是公式错，是近似条件失效，如实留着。

    这一条把 M3 的说法修正了：一维里"σ/T 越小越像单个高斯"是对的，但搬到 T² 后，约束变紧了、而且分方向。要两个方向都不被污染，得同时满足 FWHM ≪ L（轴向）与 FWHM ≪ L/√2·…（对角谷底 4√r ≪ 1）。后者比前者严 √2 倍。所以"环面上放一个干净的高斯"在二维比一维更费事——这条一维图上看不出来。

    但 T² 上有个更硬的问题：标准构造根本给不出"4n 条线"

    搬到 T² 后，"线"从 2n+2 条变成 4n 条（n 条行 + n 条列 + n 条斜率+ 折对角 + n 条斜率− 折对角；其中 2 条普通对角被数两次）。泛对角幻方要求这 4n 条全部等于幻和。实测三种标准构造，一种都不是泛对角：

    n构造斜率+ 族坏的条数
    （共 n 条）    		斜率− 族坏的条数
    （共 n 条）    		泛对角？

    规律很清楚，而且是两条：

    • 斜率+ 族：n 不被 3 整除时，n 条全部等于幻和（n=5,7,11,13,17,25 实测全 0 坏）；n 被 3 整除时坏 2n/3 条（n=9→6，15→10，21→14，27→18）。
    • 斜率− 族：永远只成立 1 条（就是副对角），坏 n−1 条。这条与 n 无关，10 个阶数逐个实测全中。

    所以 de la Loubère 最好也只是"半泛对角"（n+1 条折对角成立），而 n=15 恰好是 3 的倍数——连那一半都保不住，30 条折对角里只有 6 条成立。这就是为什么"高阶幻方 = 波包"这个印象在 15 阶上特别容易出问题：默认那张表本身就不是各向同性的。

    要真泛对角，得换构造——而 n=15 正好卡在无解的那一类

    最省事的一族是线性拉丁族：M[i][j] = n·((i + t·j) mod n) + ((s·i + j) mod n) + 1。它要成为泛对角，四个条件同时成立：

    gcd(t, n) = gcd(s, n) = 1　（行列各自跑遍完整剩余系）
    gcd(1 ± t, n) = 1　　　　 （两族折对角各自跑遍）
    gcd(s ± 1, n) = 1

    实测：n = 5,7,11,13,17,19,23,25,29,31 全部有解；n = 3,9,15,21,27 全部无解——正好是 3 的倍数。这不是巧合，可以证明：若 3 | n，条件 3 ∤ (1+t) 且 3 ∤ (1−t) 要求 t ≢ ±1 (mod 3)，而 mod 3 只剩 t ≡ 0；但 gcd(t,n)=1 又不许 3 | t。矛盾 ⇒ 无解。

    所以 15 阶泛对角幻方存在（已知定理：n ≥ 4 且 n ≠ 4k+2 时可造），但造不出来靠线性族——必须上非线性构造（例如"正交拉丁方 + 局部换位"）。本页没做这一步，如实挂着。
    同时提醒：屏幕上"n=15 那张表很规整"，它规整的是行列；折对角 30 条里只有 6 条成立、24 条不成立。这个差别在色块图上看不出来，只有把 4n 条线逐条求和才暴露。

    §3　三样东西不能同时要

    把两份代码合起来用，会撞上一个硬冲突。三条诉求各自都合理：

    1. 幻和不变：每条线的 Σ A_ij 相等（各向同性）；
    2. 分形衰减：A(f)=2^(−½·八度距离)，高频格自动变轻（−3 dB/oct 滚降）；
    3. 单一 σ：所有原子共用同一个高斯窗（否则包络不统一，M2 不成立）。

    ①+② 冲突：A 只跟 f 走，而一条线上各格的 f 不同 ⇒ 加权线和一般不再相等。面板勾上"分形衰减"，下表会给出 加权线和的散布（max/min−1）；n 越大、映射越宽，散布越大，几千个百分点都有可能。

    ②+③ 倒是相容的，代价是波包不再"等能量"：高频格既窄又轻。

    结论：想要"幻和在声场里能被听见"，就必须放弃分形衰减权，或者接受"只有全同相 + 等权"这一个特例。项目里"幻方 + 分形波包"同时上，两条不变性只能保一条。这不是设计缺陷，是两条约束在数学上就不共容。

    §4　能说什么、不能说什么

    能说
    幻方是一个离散线性约束：n² 个格值，2n+2 条线，每条线的和相等。它的秩、零空间、可满足性边界都能精确算。
    能说
    高斯窗是唯一同时达到时间-带宽下界的窗（Δt·Δf = 1/4π）。所以用它去"读"幻方，是信息损失最小的一种读法。
    能说
    "线和 = 中心相干和"只在等权 + 同相下成立，且可当场数值验证（各向同性比 1.000000）。
    不能说
    不能说幻和的数值（1695 / 9855 / 4410）本身等于某个频率或某种"能量"。它是格值之和，单位随映射走；换映射就换数。
    不能说
    不能说 729 个原子叠加就是"27 维"或"分形维"。原子数 n² 是计数，与维度无关。
    不能说
    不能说这套东西有生理/疗愈效应。页面里所有数字都是信号处理量，没有一个做过听感或临床对照。
