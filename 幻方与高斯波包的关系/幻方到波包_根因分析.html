一句话结论："像高斯"是视觉错觉，真相是 等幅梳状谱的阵列因子（Dirichlet 核）。 幻方在这里没有能力把包络变成高斯——因为"同振幅"这一条就把功率谱钉成平顶矩形， 而矩形谱的傅里叶对偶唯一地是 sinc 型。真正让高阶越来越"像"的，是主瓣变宽后的平滑度与 格序相位在高阶趋近线性斜坡这两件事，不是高斯机制。
下面的四行图直接给出反证：时域一条漂亮的钟形，频域却是一堵平墙。

一、四组对照：左列幻方，右上波包，右下 FFT

同一个映射、同一套相位规则（数字 → 频率、格序 → 相位、振幅全同），只换阶数。 看第 3 行（n=15）和第 4 行（n=25）：时域那条包络确实是一副干净钟形；但每行下面那幅频谱从头到尾是一堵等高的平墙，一根齿都不矮。

读法：左列色块按格值深浅（浅金＝小、深紫＝大），n≤9 时格内印数字。右上：复合波包 |Ψ(t)|（紫实线）与其同宽高斯的拟合（灰虚线）——在主瓣内二者几乎重合，一过主瓣立刻分开：紫线不是单调下落，而是反弹成 −13 dB 的旁瓣再振荡，高斯没有这个。右下：把同一个波包做 FFT，前 N=n² 根齿高度严格相等，之后骤然归零，是一堵带陡边的平墙，不是钟形。

这里就足以判死"幻方产生了高斯波包"这个说法。 高斯的傅里叶对偶是高斯。频域是平顶，时域就不可能是高斯——这是傅里叶变换的硬约束，不是近似程度问题。 所以正确的问题是：为什么平顶谱的 sinc 主瓣看起来那么像钟形？ 答案在第四节，偏差表算到 3% 以内。

二、第一层根因：频率集合与幻方无关

幻方是 {1,…,n²} 的一个双射排列。所以不管怎么排， "哪些频率被用到"这件事是固定的：

fk = f0 + k·Δf ,  k = 0,1,…,N−1 ,  N = n²

一共 N 个频率，等间隔，一根不多一根不少。幻方唯一能决定的是：哪个频率配哪个相位。

把它写成复信号的基带形式（A 为共同振幅，σ 为把数字映到频率序的置换）：

Ψ(t) = A · Σk=0N−1 exp[ i( 2π fk t + φσ(k) ) ]  =  A·ei2πf0t · Σk exp[ i( 2π kΔf·t + φk ) ]

这一步之后，振幅 A 已经彻底离开求和号。这是全部机制的分水岭：

  • 幅度谱 = 每个 k 上恰好一根、高度都是 A ⇒ 平顶；
  • 相位 φ 只改"这些矢量怎么排"，改不了每一根的模长；
  • 由帕塞瓦尔，总能量 Σ|A|² = N·A² 与 φ 完全无关。
所以幻方的作用被严格限制在一个自由度上：把同一份总能量，在时间轴上重新分配。 它可以让能量聚成一个尖峰（相位有序），也可以让它摊平成一片噪声（相位散乱）， 但它永远不能把能量按高斯分布摊到频率轴上——因为频率轴上的分配在"同振幅"三个字写下时就已经定死了。

三、第二层根因：平顶谱 ⇒ 只能长出 sinc

先取最干净的一档：相位全同相（φ≡0，相当于把这个"阵列"正对着看）。此时求和是等比级数，闭式解：

D(u) = Σk=0N−1 ei2πku = eiπ(N−1)u · sin(πNu) / sin(πu)   ⇒   |Ψ| = | sin(πNu) / sin(πu) |

这就是 Dirichlet 核。它的三个特征全部由 N 与带宽 B = NΔf 决定，与幻方无一毫关系：

量闭式本页实测说明
峰值N·A—N 个矢量全部同向
主瓣半高全宽0.886 / B—FWHM×B 为无量纲常数
第一旁瓣−13.26 dB—矩形加权的固有值，与 N 无关

第一旁瓣 −13.26 dB 是"矩形窗阵列因子"的教科书常数。本页对 n=5…31 逐个实测，全部落在 −12.8 ~ −13.3 dB（见下表），不随阶数漂移。这一条本身就是证据：如果包络真是高斯，旁瓣应该不存在；它不但存在，还死死钉在矩形窗那个数上。

所以"波包"这个词是对的，"高斯"这个词是错的。 宽度 0.886/B、旁瓣 −13.26 dB、尾巴按 1/t 衰减——这是"带宽受限的等幅梳状谱"的标志，也就是所有相控阵、所有矩形窗 FFT、所有同振幅频率梳的共同形状。 幻方只是给这个形状挑了一个相位、定了一个时移。

四、第三层：为什么主瓣看起来就是钟形（算到 3% 以内）

这不是玄学，是泰勒展开。把 sinc 主瓣和同半高宽的高斯都归一到中心 1，展开到四阶：

sin x / x = 1 − x²/6 + x⁴/120 − …      exp(−x²/6) = 1 − x²/6 + x⁴/72 − …

二阶项完全相同（都是 −x²/6），差别只从四阶开始，且系数之比 120 : 72 = 5 : 3。 在 x < 1.4（即主瓣范围内，x 是"到半高点的倍数 × 1.8955"），四阶项本身只有 0.03 量级， 两者之差 不到 3%。人眼在一条曲线上分辨不出 3%。

s = 距中心 / 半高半径sinc（实际）同宽高斯相对偏差判断

上表运行时算。s ≤ 1（主瓣内）偏差都在 3% 以内；到 s = 1.25 立刻崩到 −13%，s = 1.5 差一半——主瓣内一样，主瓣外立刻不一样。而人眼看图，注意力恰恰集中在主瓣。

这就是"像"的全部来源：不是幻方造出了高斯，而是任何"中心成峰、两侧单调落"的光滑曲线，在主瓣内都和同宽高斯差不到 3%。 判别必须看两个地方：① 旁瓣有没有（有 ⇒ 不是高斯）；② 频谱是不是高斯（平顶 ⇒ 不是高斯）。本页两处都查了。

五、为什么"高阶"更像：三条独立原因，一条渐近律

5.1 主瓣绝对宽度变窄，图上被"拉满"

主瓣宽 0.886/B，B = NΔf = n²Δf。阶数翻倍，主瓣窄 4 倍。若画图时固定"显示 ±2 个主瓣宽"， 那么 n 越大，视野越窄、主瓣占的像素越多、采样点越密，曲线越光滑。低阶（n=3，只有 9 个频率分量） 时整条曲线只有十几个有效采样，锯齿明显，反而不"像"。

5.2 格序相位在高阶趋近线性斜坡（这是真机制）

定义相干度 R：它是"把相位整体拧一个线性斜坡后，能留下多少同向分量"，也就是峰值能到理论值 N 的几成：

R = maxτ | (1/N) Σk exp[ i(φk − 2πkΔf·τ) ] | ,    P = N·A·R ,   峰值增益(dB) = 10·log10N + 20·log10R

下面是本页对奇数阶（连续摆数法 / de la Loubère）逐个实测的结果。R 单调趋近 1，而且收敛得很有规律：

nN=n²R（格序相位）1−Rn²(1−R)第一旁瓣 dBFWHM×B

最后一列 n²(1−R) 是最值得看的一格：从 n=15 起它稳定在 8.0 ~ 8.2，几乎不随阶数变。 也就是说 1 − R ≈ 8.2 / n²，R 以 n−2 的速度收敛到 1。必须标明：这是实测渐近律，不是定理； 能给出的解析依据只有量级：de la Loubère 的格序索引与数字之间是一个幅度 O(n) 的锯齿， 折算到相位上是 O(1/n) 的偏差，平方后正好给 1−R ∝ n−2，系数 8.2 由数值定。

为什么要强调收敛到 1：R→1 意味着"格序相位 ≈ 线性相位"。而线性相位只是时间平移，形状完全不变 （本页自检里专门验了这一条：把全同相档平移 1/B 之后，与线性相位档的 |Ψ(t)| 逐点重合到 1e−12， 峰值也完全相同）。所以高阶幻方的波包 = 标准 Dirichlet 核平移一下。它能不像一个规整的钟形吗？

5.3 收敛的目标是 sinc，不是高斯——而且是按 1/n² 一直在收敛

把各阶剖面各自按主瓣宽归一化（横轴 s = (t−t*)/FWHM），再与极限形状逐点对比。 这里必须先纠正一个我原来也这么以为的说法：并不是"高阶一到某个点就锁死"。实测是一直按 1/n² 收敛，只是到 n≈25 以后偏差已经小于峰值的 1%，肉眼分辨不出来了。

nR与极限 sinc 的最大偏差第一旁瓣 dBFWHM×B状态

"与极限 sinc 的最大偏差"的算法：取 s = −2.2 … +2.2 共 13 个点， 与 N→∞ 时的极限形状 |sin(2.783s)/(2.783s)| 逐点比，取最大绝对差（2.783 = π·0.886，由"半高点在 s=1"定出）。 s=0 处按极限值 1 处理。

表里最后两列值得并排看：偏差 ×n² 稳定在 5.0 ~ 5.4，而上一节的 1−R 乘 n² 稳定在 8.0 ~ 8.2。 两个不同定义的量、同一个 1/n² 律——说明它们出自同一个机制：格序相位与线性斜坡的差是 O(1/n) 的锯齿， 平方后进相干度就是 n−2。

准确的说法是："高阶更像理想 sinc，按 1/n² 收敛，但永远不会更像高斯。"
n=3 → 15 是"从歪到正"（偏差 0.387 → 0.023，旁瓣 −2.4 dB → −13.0 dB）； n=15 → 31 还在降（0.023 → 0.0056），但已经小于峰值 1%，图上再看不出。 再往上加阶数，形状只会更接近 sinc、不会更接近高斯，宽度只会更窄（0.886/B，B = n²Δf）。 这条上限是数学定死的：平顶谱 ⇔ sinc，与阶数无关。

5.4 反例：4 的倍数阶完全不收敛（这条最能说明问题）

n（4k 构造）NR第一旁瓣 dB形态

4 的倍数用"对角替换法"，位置与数字的关系被那两族对角线打断，R 无论阶数多高都卡在 0.516 附近， 旁瓣测出来是 0 dB（即根本没有主瓣，能量摊成一片）。这时时域完全不像波包，是一团起伏的噪声。

这一条把"高阶 = 更像高斯"证伪成"高阶 + 连续摆数法 = 更像理想 sinc"。 在阶数相近（15 与 16）、带宽口径相同、振幅全同的条件下，只换构造法，峰值就差 — dB（23.2 vs 18.3）。 所以起作用的是排列的规则性，不是"阶数"本身。老师在 Searl 真理表上看到的高阶幻方像波包， 是因为那类构造的格序是均匀倾斜的；换一种构造就散了。

5.5 三条原因之外，还有一条"陷阱"

幻方的核心约束是每行、每列、两条对角线的格值和相等。这条约束干了什么？它强制数字在空间上均匀铺开—— 每行都取遍全域、平均值都等于 (N+1)/2。折算到相位上，就是相位在圆周上分布均匀。

而 R 要的是"有序"，不是"均匀"。相位越均匀，Σeiφ 越接近 0，R 越小。 所以"幻和"这件事本身对峰值是不利的。n=25 的 R = 0.987 之所以还这么高， 恰恰是因为 de la Loubère 的格序近似线性（有序），它偏离了严格均匀。

结论有点反直觉，但账算得出来： "幻和（均匀）"与"高峰值（有序）"在数学上是两个方向的要求。 de la Loubère 之所以两件事同时占住，是因为它本身就是"均匀倾斜填充"—— 既让每行每列举遍全域（均匀），又让格序随数字近似匀速推进（有序）。 4k 法的对角替换毁掉了后半条，于是只剩均匀、丢了有序，峰值掉一大截。

六、最后那格：数值一览（本节由页面自检时同步刷新）

峰值增益 = 20·log10(P / √N)，即"峰值比均方根高多少 dB"。理论上限是 10·log10N； R = 1 时取到上限。n=25 时上限 — dB，实测 — dB。

七、要把包络真做成高斯，只有一条路

上面四节已经把出口堵死了：同振幅 ⇒ 平谱 ⇒ sinc。所以想拿高斯包络，必须放弃"同振幅"。

ak = exp[ −(k − k0)² / (2σ²) ] ,  φk 保持线性   ⇒   幅度谱 = 高斯，包络 = 高斯，FWHM×B = 0.441

对比现在的 0.886——同样带宽下，时间宽度可以窄一倍。这是唯一能从这套结构里榨出来的真实收益。 代价是：SEG 式"每一格同权"的设定被放弃，幻方的等和性质也就跟着失效（因为格值不再等于频率权重，而等于振幅权重， 两边不能同时满足）。

换句话说：幻方给的是"同权重"，而"同权重"恰恰排除了高斯。 这是结构性的取舍，不是实现细节。
