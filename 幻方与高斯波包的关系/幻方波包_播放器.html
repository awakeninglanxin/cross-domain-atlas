§1 怎么听：一个周期是什么

"一个周期"不是随便截一段，而是严格数学周期。频率取等间隔梳：

fv = Δf · (m + v − 1)，  v = 1…n²，  m = round(55 / Δf)

这样每根频率都是 Δf 的整数倍，周期 T = 1/Δf。再把 Δf 量化成 Δf = sr / len（len 为整数样本数）， 于是每一根在 t = T 处相位增量恰好是 2π·(m+v−1)——整数圈，端点严格连续，循环无咔哒。

这条是判据，不是形容词。页面自检里的"端点相位偏差"就是 max |fv·T − round(fv·T)|，正常应打印 0.000e+0。 另外放了一条变异测试：故意把 m 偏移 0.5（fv 不再是 Δf 整数倍），偏差必须变成 0.5 —— 判据有分辨力，不是恒真式。

与此无关但常被误用：|x[0] − x[len−1]| / 相邻差中位数 这类"首尾差"指标。 它在尖峰陡峭处会给出 4 以上的值，看着像"不连续"，其实完全连续；反过来在全同相时给出 1.55，看着正常其实也在 t=0 处是尖点。所以这里不用它——用相位整数圈判定。

§2 level 和 step 到底能调什么

把"level/step 式"的方阵落成一个可穷举的六参数族，两个方向各给一组线性型：

M[i][j] = n · ((pr·i + qr·j + cr) mod n) + ((pc·i + qc·j + cc) mod n) + 1

其中 (pr,qr,pc,qc) 是 step（两个方向的步长），(cr,cc) 是 level（两个方向的偏移）。 这个族里能精确复现 de la Loubère，而且有闭式：

M[i][j] = n · ((i + j + (n+1)/2) mod n) + ((i + 2j + 1) mod n) + 1   (n 为奇数)

页面自检会把它与经典"右上斜走、撞墙回退"的算法逐格比对（n=3…21 全等），并顺带验出这类表全部是 泛对角幻方（两条折对角也各自为 S）。

2.1 第一个硬结论：线和不是一个"可逼近"的量

只要方阵是 1…n² 的双射，总和就被钉死为 n²(n²+1)/2。所以：

若 2n+2 条线的和全部等于 T，则 n·T = n²(n²+1)/2  ⟹  T = n(n²+1)/2  （唯一可能值）

也就是说，"让线和接近目标 T"在幻方族里没有梯度：T 取对 ⇒ 残差严格 0；T 取错 ⇒ 整族无解， 不存在"很接近"的中间态。下面这张搜索表会把这件事当场跑出来——把目标改成 S ± 1，命中数立刻掉到 0。

注意 S 是行和：n=9 时 S = 9×(81+1)/2 = 369。平均格值 (n²+1)/2 = 41 不是线和。

2.2 第二个硬结论：level 几乎不碰线和

行和 = n·Σj((pr·i+qr·j+cr) mod n) + Σj((pc·i+qc·j+cc) mod n) + n。 当 gcd(qr,n)=1 时，j 遍历完整剩余系，Σ 恒为 n(n−1)/2，与 cr 无关。 所以 level 只在"该方向系数退化"时才有影响：

线 k 的和受 level 影响  ⟺  该线上的系数与 n 不互素

表的每一行就是一条线，最后一列是这条预测。常见情形：pr=qr=1 时 pr−qr=0， 所以 只有副对角会随 cr 变，10 条行列和两条对角中的主对角都纹丝不动。

2.3 那"自动搜索"在搜什么

搜的不是"多接近"，而是"哪些 step 组合能命中"。判据可以 O(1) 化，不必建表：

  • 双射 ⟺ gcd(pr·qc − qr·pc, n) = 1（矩阵可逆）
  • 行和与 i 无关 ⟺ gcd(qr,n)=1；列和与 j 无关 ⟺ gcd(pr,n)=1
  • 下半部分同理：gcd(qc,n)=1、gcd(pc,n)=1
  • 对角要各自成立，再对 level 解一个线性同余

所以搜索是 O(n⁴) 筛系数 + O(n²) 定 level，n=15 也在一瞬。结果会告诉我们： "两参数 (level, step) 一个幻方都造不出"，而六参数能——这个差别就是"为什么 level 单独加不够"。

§3 音频侧的四条硬事实

3.1 频率集合被双射锁死，可听差异只能来自相位

不同构造的 n² 个数字是同一集合 {1,…,n²}，所以频率集合完全相同。差别只可能在"哪根频率拿哪个相位"。 页面里把相位规则一切换，就能听出来：

相位规则de la Loubère线性拉丁随机排列DL 与随机是否同一条波形

关键的是数字序和全同相两行：它们让 DL 与随机排列的波形逐样本完全相同（页面自检直接比对 buffer，差值 0）。 因为 φ 只依赖数字 v（或干脆不依赖任何东西）时，整个波形只依赖集合 {1…n²}，与"谁坐哪"无关。 而格序与棋盘两行差得很明显——它们让相位挂到格位置上，于是"数字→格"的配对开始起作用。

换句话说：相位规则决定"排列是否可听"。格序相位是幻方的指纹；数字序和全同相会把它彻底抹平。 这也解释了为什么同一张表换个相位规则，crest 会从 10.40 掉到 3.92——不是音高变了，是相干结构变了。

3.2 峰均比（crest factor）决定"听起来多响"

归一化到同一峰值后，RMS 越低越"虚"。等幅相干叠加天生高 crest：

de la Loubère 的 crest 随 n 一路涨（n=5 → 9 → 15 是 4.83 → 10.40 → 16.54），因为斜线排列让大量频率在某一时刻近乎同相—— 这正是前几轮"规模越大越容易全体同相"的可听版本。随机排列 crest 最低、最"糊"，也最像噪声。

这张表用 8000 Hz 轻量口径算（切换参数时不卡）。同一构造在 24000 Hz 口径下 n=15 的 crest 是 20.43 而不是 16.54—— 差别全在"峰值那一个采样点有没有被采到"，crest 对采样率敏感，对相对次序不敏感。想看准确值，看上面那张音频指标表的 24000 Hz 版本。

3.3 为什么"一个周期"听起来像节拍

实测峰位不在周期末尾，而在开头几个百分点处：n=5 / 9 / 15 分别是 0.117T / 0.084T / 0.059T—— n 越大越贴边（每升一阶约缩到上一档的 1/1.4，不是"减半"）。原因是格序相位把 (k−1)/n² 挂到频率索引上， 两串足够"近似线性"的地方就对齐一次，最优点被推到 t≈0 附近；斜线绕圈越多，对齐点越散，主峰也越窄。

一周期 0.25 s ⇒ 每秒 4 次"击"；0.5 s ⇒ 每秒 2 次。这就是它听起来像节拍器而不是和弦的原因： 能量集中在周期里极短的一瞬，其余时间是振铃。想让声音"平"下来，得把相位打散（棋盘档）或换数字序—— 棋盘档的 crest 只有 4.78，峰也散成十几个（页面上"峰数"一栏会跟着变）。

3.4 可听带

n=21、Δf=4 时最高频约 1816 Hz；Δf=2 时周期 0.5 s、频带收窄到 880 Hz。 频率越高、同一周期内塞进的振荡越多，峰值就越窄——这就是 §3.2 里 crest 随 n 上升的另一个视角。

§4 能说什么，不能说什么

能说：① 在这个六参数族里，de la Loubère 有精确闭式且必为泛对角；② 线和在双射约束下只有唯一可能值， 不存在"逼近"；③ level 只影响系数退化的那些线；④ 一个周期可以做到端点严格连续（相位整数圈，实测偏差 0）； ⑤ 相位规则决定排列是否可听，数字序会把所有同阶幻方抹成同一个波形。
不能说：① 这些波包不是高斯——频域平顶 ⇒ 时域必为 sinc 型（见 根因页）；② 六参数族不覆盖所有幻方，例如 n=4 的 Criss-Cross 就不在这个族里； ③ 本页没有引用 Searl 真理表的原始数字（本机没有那份原表），level/step 是按结构同构复现的参数化，不是对原文的转述； ④ 真实听感还取决于你的扬声器与音量，"好听"不是可复算的量。
