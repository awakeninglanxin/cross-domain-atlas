② 公式底稿 R1–R12 模型内核

▸ 内核：一个振子驱动全部几何

R1 韵律振子（本模型核心公设）： λ̈ + η λ̇ + ω²(λ−½) = 0 ， ω = 2π/T。
η=0 ⇒ λ(t) = ½(1−cos ωt) = sin²(πt/T) ∈[0,1]，严格周期闭合，λ(0)=λ(T)=0
R2 零和账本：E = ½λ̇² + ½ω²(λ−½)² = 常数（η=0）；
生成 G(t)=κλ̇⁺、辐射 R(t)=−κλ̇⁻ ⇒ Q(t)=G(t)+R(t) ≡ 0（逐时刻，不是只在一周期平均）
把「反对熵与热死」翻译成数学，就是把阻尼项 η 强行设为 0。R1 的 sin² 与前面几轮那条「全局呼吸 λ(t)=sin²(πt/T)」是同一个式子 —— 这里补上了它是从哪个方程来的。

▸ 形态：一条母线走完 平面→锥→球→锥→平面

R3 统一母线（柱坐标 θ∈[0,2π)、v∈[0,π]）：
ρ(v,θ;λ) = H(λ) + [1−H(λ)]·[ α(λ)(1−|cos v|) + (1−α(λ)) sin v ]·[1 + ε₄ A(λ) cos4θ ]
z(v;λ) = S(λ) cos v
R3′ H(λ)=H₀(1−λ)² （洞半径）　S(λ)=Smin+(1−Smin)λ （极轴/赤道）
α(λ)=4λ(1−λ) （锥度权重，中态最大）　A(λ)=λ² （四阶节拍在球面态最强）
R3″ 相位读法：λ=0 → 平面环带 + 立方边界；λ≈0.5 → 双锥；λ=1 → 真球（+4 碳振幅）；
λ 上升段 = 吸气 / 生成，λ 下降段 = 呼气 / 辐射 ⇒ 一个 λ 周期自动给出「锥→球→锥→平面」

▸ 静止的光：立方波场边界

R4 固定边界盒：|x|,|y|,|z| ≤ a（永不随时间变 = 罗素的「静止」）；
内部超二次曲面（Lamé）：|x/a|n+|y/a|n+|z/a|n=1 ， n(λ)=2+(nmax−2)(1−λ)
λ=1 ⇒ n=2 球；λ=0 ⇒ n=nmax 趋近立方 —— 「球是立方收缩、立方是球膨胀」
3D-B 用精确径向解 r(d) = a / (|dx|n+|dy|n+|dz|n)1/n 绘制，不是近似插值
R5 光/势场（自设标量场，非 QFT 场）：
Φ(x,t) = A₀ λ(t) · e−(r/σ)² · [1 + ε₄ cos4θ sin²θ] · ∏i=x,y,z cos(π xi/2a)
在立方边界上 Φ≡0 ⇒ 边界「静止」；本模型只用它算切片与通量，不解 □Φ+V′=0

▸ 两向通量与守恒

R6 Jgen = −κ ∂zΦ ẑ （向心 / 吸气，蓝）　Jrad = +κ ∂zΦ ẑ （离心 / 呼气，橙）
Jgen + Jrad ≡ 0 逐点成立；箭头方向随 sign(λ̇) 整体翻转
R7 连续性记账：∂tρm + ∇·(ρmv) = 0。本模型只写守恒式、不解流体 —— 这一行专门提示：从这里开始，物理内容是空的，只有记账格式
