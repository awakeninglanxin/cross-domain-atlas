判据一 · 洛伦兹不变：它不是场方程，是 ODE 流

V1 ∂μ∂μφ + V′(φ) = 0,　 ℒ = ½(∂φ)² − V(φ)　（双曲型 PDE，无外鞘／壁／轴／截面，无全局同步的 t）
V2 dX/dt = f(X),　柱坐标 (ρ,θ,z)、固定 ρe(z)、w = Ω₀/(ρ+rc)3/2　（一开头就挑了「外鞘静止系」）
冲突点为什么过不了洛伦兹不变
呼吸 λ(t)=sin²(πt/T)全场同一时刻一起变形 = 全局绝对同时性；相对论里没有这个 t
庞加莱截面 z=L、周期 T*、锁相整数圈 k全都依赖「同一个时间切片」；换 boost 观测者，截面不同时、周期不守恒、闭合解不再闭合
w = Ω₀/(ρ+rc)3/2 里没有 c内快外慢的剪切若照搬到相对论得加约束 Ωρ<c；没有 ⇒ 本来就是非相对论造形模型
§5 把轮廓套进 Alcubierre 度规拿欧氏 3D 曲面当泡壁输入；度规协变但输入来自耗散 ODE + 全局呼吸，两层不兼容。且泡壁要违反 NEC 的负能量，跟「吸引子自动贴壁」是两码事

判据二 · 无耗散：吸引子 ≡ 相空间收缩

V3 (d/dt) ln δΓ = ∇·f < 0　·　δΓ(t)/δΓ₀ = e(∇·f)t　·　无耗散（哈密顿／刘维尔）⇒ 相体积守恒 ⇒ 根本不会有奇怪吸引子
① 相体积 δΓ(t)/δΓ₀ 曲线（log₁₀ 纵轴）

按刘维尔定理解析积分，纵轴取 log₁₀ 让差 20 倍的三条线同屏。Lorenz ∇·f = −(σ+1+β)、Rössler 轨道平均 ⟨x⟩≈0.17414 ⇒ ⟨∇·f⟩≈−5.3259（RK4，dt=0.02、burn-in 5000 步、采样 60000 步）、Thomas ∇·f = −3b；灰平线 = 哈密顿/KAM 恒 1。橙虚线是文档场的定性示意，明确标注「非数值积分」 —— 它的实证只有 k_R=k_Z=0 ⇒ 5/5 第一步 NaN、CFL 1.49×10⁷⁴，说明「软壁是承重墙」＝靠耗散把相空间压进有界域。

② 3D 相体积元（可拖拽、会动）

同一初始球按真实谱 M(t)=diag(eλ₁t, eλ₂t, eλ₃t) 演化。耗散：Lorenz 谱 (+0.906, 0, −14.572)，球被压成薄片，Σλ=−13.667=∇·f；KAM：谱 (+1.30, 0, −1.30)，拉成长纤维但体积恒 1；真空：连初始球都不画 —— 没有相轨道，δΓ 不适用。λ₁ 固定 0.906，改 σ/β 后 λ₃ 按 Σλ=∇·f 重算（示意约束，非重新数值求谱）。

③ Minkowski 同时性判据

左：水平金线＝静止系同时面（λ(t) 全场同相位 ✓）；橙斜线＝boost 后同时面（穿过一串不同 t ⇒ 相位不齐 ✗）。右栏：|Φ| 是洛伦兹标量、对 β 恒 1；周期 / 截面 / 整数圈是坐标系依赖量，随 β 漂移。boost 后周期漂移曲线标注为示意，不是精确相对论公式。

④ 三栏对照矩阵

「洛伦兹不变 + 无耗散 + 混沌」不是不能共存：经典 Yang–Mills 场的时空混沌、相变期格点里的湍流级联都可以。但产物是场位形的时空混沌，不是「一条被吸到低维奇怪吸引子上的轨道」。ABC 流是无耗散的（稳态 Euler 解、∇·u=0、Beltrami、流线混沌），但一是非相对论流体方程、二挑出流体静止系，仍不洛伦兹不变。

换成洛伦兹不变无耗散的标量场后：没有吸引子、没有唯一闭合目标、没有全局截面，锁相要改成作用量–角变量的共振条件。闭合环是耗散吸引子上的周期轨道；锁相整数圈依赖绝对时间；外鞘不变流面依赖固定边界 —— 每一条都恰好依赖被否掉的那两样。

收尾判据：看到「吸引子」先找散度，负的就是耗散；看到「外鞘 / 截面 / 周期 T / 全局呼吸」＝已经挑了静止系；看到「真空」＝要求洛伦兹标量 + 可逆哈密顿演化，两样都不给。
