破缺形状族：椭圆、蛋形、梨形都算，但破的东西不一样

「破缺」= 出现坐标无关的背景张量，等频面不再是正圆。任何非正圆都算；形状是背景张量的角动量指纹：椭圆是偶 l（中心对称），蛋形多破一层——有头尾，l=1 奇宇称（k → −k 不再一样）。下面用谐波展开统一驱动绘图。

① 调参（公式直接驱动绘图）

—

有效幅度 δeff(E) = —；宏观多畴平均后 ⟨κ⟩L = —；局域二阶 ⟨κ(x)κ(x)⟩ ∝ δeff² = —；奇偶不对称量 Δodd = max|r(θ)−r(θ+π)| = —（蛋形专属可观测量，正反方向光速差）。

② 专门公式（SME 参数化，非张氏动量公式）

① ℒphoton = −¼ FμνFμν + ½ εκλμνAλ(k̂AF)κFμν − ¼ Fκλ(k̂F)κλμνFμν  ；  ℒfermion = ½ i ψ̄(γν + cμνγμ) ↔∂νψ − m ψ̄ψ

SME 把所有可能的破缺写成「背景张量系数 × 常规算符」；(k̂AF)(d) 只在奇 d（CPT-odd），(k̂F)(d) 只在偶 d（CPT-even）。系数按粒子 sector 独立。

② κij = δeff ( n̂in̂j − ½ δij )  ,  n̂ = (cos θ₀, sin θ₀)  （无迹四极，2D 版）
③ ω² = c² ( k² + κij ki kj )  ⇒  等频面   k(θ) = k₀√(1 + δeff cos2(θ−θ₀)) ≈ k₀[1 − ½δeff cos2(θ−θ₀)]
④ vg = ∇kω ， 一般形状 r(θ) 的法线偏角   tan ψ = − r′(θ)r(θ)

r′≡0（正圆）时 ψ≡0；任何 r′≠0 都让能流／力线偏离径向。这就是「力线歪掉」。

⑧ 谐波展开（本页绘图所用）： r(θ) = 1 + A₁ cos(θ−θ₀) + A₂ cos2(θ−θ₀) + A₃ cos3(θ−θ₀)  ,  A₂ = −½δeff
⑧′ r′(θ) = −A₁ sin(θ−θ₀) − 2A₂ sin2(θ−θ₀) − 3A₃ sin3(θ−θ₀)  ⇒  β = r′/r ， n̂ ∝ êr − β êθ

A₁≠0 → 一头大一头小的蛋形（limaçon 型，l=1 偶极）；A₃≠0 → 梨形／三瓣（l=3 八极）。l=1 就是「有上游和下游」。球谐分解里 l=0 各向同性、l=1 偶极、l=2 四极、l=3 八极，各可单独测量。

⑨ Δodd = maxθ | r(θ) − r(θ+π) | = 2|A₁| + 2|A₃|  （偶 l 项全部抵消）

这是蛋形与椭圆最硬的区别：椭圆 r(θ)=r(θ+π)，正反方向光速相同；蛋形 Δodd≠0，正反方向光速不同。非对称环形腔专门测这个（odd-parity），已达 10⁻¹⁵；宇宙源光谱偏振把 parity-odd 系数压到 <10⁻¹⁶；真空双折射给 (kAF) 约 10⁻⁴³ GeV、双折射型 (kF) 约 10⁻³⁷。蛋形对应的奇宇称类，反而比椭圆被压得更死。

⑤ δeff(E) = δ₀ ( E / Λ )d−4  ；  d = 3,4 → 低能不抑制（早该看见，已被排除）；d ≥ 5 → 随 E 放大
⑥ ⟨κ⟩L = κ₀ / √N ， N = ( L / ξ )³  ；  ⟨κ(x)κ(x)⟩ = κ₀² ≠ 0（局域）

宏观大尺度一阶矢量确实平均掉；但局域二阶关联不随 N 消失，原子自旋、腔模这类探针感受的正是它，表现为各向异性／恒星日调制。宏观看不见 ≠ 没被测过。

⑩ 洛伦兹群 = rotations ⊕ boosts  ：  形状（l=1,2,3）破的是旋转各向同性；boost 破缺另算，表现为随地球自转／公转的恒星日调制

任何带固定优先轴的形状（椭圆或蛋形）在 boost 下都会变形，因此都算洛伦兹破缺；但「是不是蛋形」和「boost 有没有破」是两个独立问题，别混成一个。

⑦ mij = m(δij + κij) ， mij dvjdt = q( Ei + εijk vj Bk )  ⇒  ωc(θ) ≈ (qB/m)[ 1 − δeff cos2(θ−θ₀) ]

示意式（忽略相对论 γ 与 κ 对 v×B 的高阶耦合）：回旋频率随方向变，正圆轨道变椭圆；若再叠加 l=1，轨道变成一头尖的蛋形闭合线并进动。

③ 四张图：宏观 / 微观 / 力线轨道 / 形状指纹

宏观 · 多畴平均

青虚线 = 不变时的正圆等频面；实线 = 当前形状；箭头 = 能流法线。宏观 ⟨κ⟩→0，几乎重合，箭头仍沿径向。

微观单畴 · 破缺示意

优先轴 θ₀ 用橙虚线标出。蛋形时 r(θ)≠r(θ+π)，一端鼓一端收，法线不再过中心。这是参数化可能性，不是已观测事实。

力线检验 · 回旋轨道

青 = 洛伦兹不变的正圆回旋；橙 = 各向异性后的椭圆／蛋形轨道 + 进动。箭头显示力不再恒垂直于半径。

形状指纹 · r(θ) 与 r(θ+π)

上方极坐标里青/橙两条闭合线错开 = 正反方向不同（Δodd≠0）；下方曲线是 r(θ)−r(θ+π)。椭圆模式此值恒为 0。

④ 能标跑动：为什么「宏观无、微观可能有」

横轴 log₁₀(E/Λ)，纵轴 log₁₀ δeff。d≥5 时低能被 (E/Λ)d−4 压到近乎零（宏观），高动量转移 Q² 或阈值过程才放大。灰横线是光子 sector 10⁻¹⁸ 量级的取向各向异性界；右上角「阈值放大」对应 GZK／真空契伦科夫：无契伦科夫辐射已把 n=3 色散参数压到 η ≲ 10⁻¹⁴。

边界声明：本页画的是主流 SME 式「如果破缺发生会长什么样」的参数化示意，不是已观测事实，也不是张祥前统一场论的示意图。形状由球谐／自旋加权球谐分解分类（Kostelecký & Mewes 2009），奇 d ↔ CPT-odd、偶 d ↔ CPT-even；无质量光子要求 CPT-even 双折射模型里 j<2 的系数为零，所以 l=1 主要落在 CPT-odd 那一支。宏观平均为零确实成立（⑥式），但结论与「科学家误以为光速不变」相反：正因为局域二阶量不消失，实验才把各向异性压到 10⁻¹⁸ 以下；微观开放的是 d≥5 的参数空间，不是任何跨尺度、无能标的经典矢量场。
