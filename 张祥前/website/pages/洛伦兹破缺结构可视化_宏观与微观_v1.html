洛伦兹破缺长什么样：从宏观平均到微观单畴

这里「破缺」不是力线断了，而是：时空里出现一个坐标无关的背景张量 κij，于是等频面由圆变畸变、能流／力线不再沿径向、带电粒子回旋轨道由正圆变椭圆，并随地球转动出现恒星日调制。图由下方公式实时计算绘制。

① 调参（公式直接驱动绘图）

当前有效幅度 δeff(E) = —；宏观多畴平均后 ⟨κ⟩L = —；但二阶残余 ⟨κ²⟩ ∝ δeff² = —（实验测的正是这一项）。

② 专门公式（SME 参数化，非张氏动量公式）

① ℒphoton = −¼ FμνFμν − ¼ (kF)μνρσ FμνFρσ  ；  ℒfermion = ½ i ψ̄(γν + cμνγμ) ↔∂νψ − m ψ̄ψ

标准模型扩展把所有可能的洛伦兹破缺写成「背景张量系数 × 常规算符」；系数按粒子 sector 独立，不是凭空一句话。

② κij = δeff ( n̂in̂j − ½ δij )  ,  n̂ = (cos θ₀, sin θ₀)  （无迹四极，2D 版）
③ ω² = c² ( k² + κij ki kj )  ⇒  等频面   k(θ) = k₀√(1 + δeff cos2(θ−θ₀))

δeff=0 时是正圆 → 各向同性；δeff≠0 时沿优先轴压缩、垂直方向拉伸 → 出现「方向」。

④ vg = ∇kω ， tan ψ = − 1k dkdθ = − δeff sin2(θ−θ₀)1 + δeff cos2(θ−θ₀)

ψ 是能流／力线偏离径向的角度。洛伦兹不变时 ψ≡0；破缺时 ψ≠0，这就是图中「力线歪掉」的来源。

⑤ δeff(E) = δ₀ ( E / Λ )d−4  ；  d = 3,4 → 低能不抑制（早该看见，已被排除）；d ≥ 5 → 随 E 放大
⑥ ⟨κ⟩L = κ₀ / √N ， N = ( L / ξ )³  ；  ⟨κ²⟩ = κ₀² ≠ 0

接住「交流平均为零」的类比：宏观一阶矢量确实平均掉，但二阶方差不会消失，而精密实验找的就是各向异性／恒星日调制。宏观看不见 ≠ 没被测过。

⑦ mij = m(δij + κij) ， mij dvjdt = q( Ei + εijk vj Bk )  ⇒  ωc(θ) ≈ (qB/m)[ 1 − δeff cos2(θ−θ₀) ]

修正后的洛伦兹力：回旋频率随方向变，正圆轨道变椭圆并进动 —— 下图右侧画的就是它。

③ 三张图：宏观 / 微观 / 力线轨道

宏观 · 洛伦兹不变

青虚线 = 不变时的等频圆；橙实线 = 当前 δ 下等频面；箭头 = 能流／力线法线方向。宏观多畴平均后 ⟨κ⟩→0，两者几乎重合，箭头仍沿径向。

微观单畴 · 破缺示意

优先轴 θ₀ 用橙虚线标出；等频面被压成四极畸变，法线不再过中心的径向（ψ≠0）。这是参数化可能性，不是已观测事实。

力线检验 · 回旋轨道

青 = 洛伦兹不变的正圆回旋；橙 = mij 各向异性后的椭圆 + 进动。箭头显示力不再恒垂直于半径。

④ 能标跑动：为什么「宏观无、微观可能有」

横轴 log₁₀(E/Λ)，纵轴 log₁₀ δeff。d≥5 时低能被 (E/Λ)d−4 压到近乎零（宏观），高动量转移 Q² 或阈值过程才放大（微观／高能）。灰横线是光子 sector 10⁻¹⁸ 量级的取向各向异性界；右上角「阈值放大」区对应 GZK／真空契伦科夫：无契伦科夫辐射已把 n=3 色散参数压到 η ≲ 10⁻¹⁴。

落在这里，且被排除：全空间同一个确定矢量 C、伽利略式 C−V、拿来算 5 吨飞碟与质量归零，属 d≤4 宏观各向异性，没有 Λ、没有系数表、没有跑动

边界声明：本页画的是主流 SME 式、可检验的洛伦兹破缺「如果发生会长什么样」，不是张祥前统一场论的示意图，也不构成任何破缺已被观测到的主张。宏观平均为零确实成立（⑥式），但结论与「科学家误以为光速不变」相反：正因为 ⟨κ²⟩ 不消失，实验才用二阶量把各向异性压到了 10⁻¹⁸ 以下；微观可能性开放的是 d≥5 的参数空间，不是任何跨尺度、无能标的经典矢量场。
