## 三、六个核心概念（从图注归纳）

1. **磁闸（Gate）**——出现 27 次。含"双闸（Dual Gate）""闸面（Gate Face）""常规测试闸（Conventional Test Gate，图注自称'我们测试最多的设计'）"。即让磁通"单方向放行"的装置段。
2. **交换力脉冲（Exchange Force Pulse）**——图 40–52 整块。这是 HJ 笔记里**最重要的机理词**（与 Bearden 称他为"Magnetic Exchange Force 先驱"呼应）：可能是"脉冲式交换力"的机构设计图。
3. **感应斥出（Induction Expulsion）**——图 94–97。系统名，配"高响应测力计"（1994-07）测试。
4. **扭转电机（Twist Motor）**——图 189–203，含构造照片、描述、示意图，**1996-11-15** 与交换力脉冲画在一起——说明它是"交换力脉冲"的一个实机实现。
5. **失衡 / 自旋对齐系统（Imbalanced / Spin Alignment System）**——图 90–93。四个示意图。
6. **磁体谱系**——Texas 磁铁（好/坏）→ 香蕉磁铁（吸引/排斥）→ 分层磁铁 → 分层+滤波器 → 无磁多层 → **钕环 / 钕衔铁 / 密排定子**。可见一条明显的"材料与结构迭代"线。

## 四、怎么读这些图（数据形式的解读）

- **测量形式**：几乎每个 run 都有三件套——`x-axis / y-axis / z-axis`（三轴分量）+ `Magnitude`（合成量值），部分加 `Contour Plot`（等高线，用于看空间分布）。这是**三轴测力/测场**的标准输出。
- **Run 编号**：约 Run 045–121（如 045、064、065、093、095、096、099–102、107、108、114–116、121），加"b-run"系列（1985-11 批：51–55；1996 批：72、77、79、96–99、100–109、113、121）——b 可能指"baseline/另一配置"，含义待考。
- **切分方式**：`1st half / 2nd half / 1st fourth / last fourth`（前/后二分之一、四分之一）——把循环分段统计。
- **坐标系顺序**：`xyz` 与 `zyx` 两种排列并存（可能对应两种测点布置）。
- **日期锚点**（图注中残留）：1985-10-07、1985-11-11、1985-11-14；1994-07 系列；1996-11-15。
- ⚠️ **局限**：全套影像**没有配套文字说明**（没有实验条件、结论、参数表）。单凭图注无法重建实验，**判读须谨慎**——这也是它作为"附录"存在的意义：给懂上下文的人（如 Denny）做底稿。

## 五、与史论论文的接口（为什么 Denny 要汇编它）

- 史论论文参考文献 **[126]–[131]** 全部是 HJ 相关：书《The Secret World of Magnets》+ **本附录** + 4 项专利。
- 使用场景：讨论 **Sprain 装置**（类别 3 的旋转磁柱塞）时，论文写道——Sprain 的装置"**也许还可以借鉴 Howard Johnson 在'自旋电子学与磁门控'方面的发现**，制造出'磁转移点被显著增强或选择性抑制'的扇区"。
- 词汇链：HJ 的"**Magnetic Exchange Force**" → Denny 的核心词"**mass-energy exchange / routed exchange**"——两份资料在"**交换力（exchange force）**"这一概念上直接接轨。
- 这也是为什么本附录被收进"无工质推进"主题文件夹：它是史论所讨论的"磁门控型装置"的**历史实验根据**。
