D

闭眼闪光眼罩：VR 外壳 + 最优三色 + 全视野漫射

打开就是试跑台：屏幕控制在首屏，不用往下找。它是一台左右眼双屏的模拟器（螺旋 / 同心圆 / 棋盘 / 对数摆线涡旋 / 双摆线叠加，左旋与右旋镜像对照，可一键全屏、全屏后空格暂停、可换 6 档单色且不含蓝、8 档波形（连续 3 + 脉冲 5）带波形预览、占空比对数刻度一直下到 0.1 %、还可模拟戴红青 / 线偏 / 圆偏眼镜看屏幕，勾上单屏合一就把两幅叠成一张、戴上眼镜合成一个带视差的 3D 像；参数在右侧可拖动浮窗里，宽屏时浮窗停靠在眼屏右边、不压住画面）。往下是可拖动的三维结构（七层光通道、可爆炸 / 剖面 / 看光路）、最优三色推导、剂量计算、电气与十三道装配工序。核心结论两条：把眼睑透射、视见函数、LED 电光效率三条曲线乘起来，每瓦效力最优点落在 620 nm，最优三色是 620 / 590 / 505 而不是 RGB——660 深红是「透射最高、效率最差」的陷阱；而双眼的镜像是生理默认，不是特效，真机右板必须做成左板的镜像布线。
