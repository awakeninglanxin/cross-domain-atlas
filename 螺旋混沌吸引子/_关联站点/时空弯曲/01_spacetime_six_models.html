把每匝 n 球写成 勾 a + 股 b = n（要求 a ≥ 1），再要求 弦 c = √(a²+b²) 也是整数 —— 满足这个的 n 就是「可闭合阶」。 上一条只枚举了 3…12，所以只看得到 7；下表放开到 n ≤ 100， 由页面现场枚举（不是手打的），并已与下面那条闭式通项公式互相验证。
通项公式（2026-10-12 立 · 已与暴力枚举 127/127 对拍，零偏差）
N 可闭合  ⟺  N = g·(u² + 2uv − v²)，其中整数 u > v ≥ 1、g ≥ 1
　勾 a = g·2uv　股 b = g·(u²−v²)　弦 c = g·(u²+v²)　中孔 = g·|u²−2uv−v²|
等价（Pell 形）：令 s = u+v、t = v ⇒ N = g·(s² − 2t²)，条件变成 s > 2t ≥ 2。 （反解 u = s−t；这条形式的好处是：只出现一个平方差，能直接拿去跟 Pell 方程 x²−2y² 的既有工具接）

三条推论
① 7 = 最小的可闭合阶（u=2, v=1, g=1 → 3+4=7，弦 5，中孔 1） ⇒ 这就是「建议每匝 ≥ 7 球」的全部来源（独立复核通过）。
② g 任取 ⇒ 7 的倍数全部可闭合：n = 7g → 勾 3g／股 4g／弦 5g、中孔 g。 这正是扫描件《勾股定理之弦外之音》那张 7×7 … 70×70 的表 —— 那里反复出现的 「天元数」就是 g，而「弦外之弦实 N²−c²」恒等于 4Δ = 24g²、「里弦实」= g²，两条都逐行吻合。
③ 49 = 7² 是第一个「有两种不同整数拆法」的阶： 21+28（弦 35·中 7，7g 族）与 9+40（弦 41·中 31）。 ⇒ 七级递推在 7 → 7² 这一步第一次分叉（下一节 ④ 就是讲这个）。
④ 七阶 ↔ anu 的「七级螺旋」：两个系统共用同一个闭合模数 7
anu 侧（文档原文，不是本页推出来的）：Anu = 10 条封闭螺旋线（3 粗 + 7 细）， 每根线 1680 匝；内部是 七级螺旋 g→f→e→d→c→b→a，且细线严格 7 倍率。

§2底部那把钥匙：4GM/c²b

光线掠日偏折  α = 4GM/(c²b) (t 与 r 各出一半)
步骤内容结果
1只算时间分量（爱因斯坦 1911）2GM/(c²b)  ＝牛顿值
2只算空间分量（各向同性坐标）2GM/(c²b)
3两者相加（1915 完整 GR）4GM/(c²b)
41919 爱丁顿日食实测支持 4GM/(c²b) ✓
物理读法
慢速物体（苹果、行星）几乎感觉不到空间弯曲，因为空间项的贡献被 (v/c)² 压制。 所以下落 = 时间的梯度。只有 v → c（光）时，空间项才重新变成「一半」。
