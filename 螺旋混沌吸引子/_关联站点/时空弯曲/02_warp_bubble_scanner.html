§1代价的解析标度：Mwarp = −(1/36)·v²R²/Δ

对 tanh 形状函数做数值积分，在 R ≫ Δ 极限下比例系数收敛到常数 1/36 = 0.02778（本页右侧读数里 M/(v²R²/Δ) 一栏就是它）。 三条推论直接读出来：

依赖含义物理后果
∝ v²速度一超光速，代价二次方上涨v 从 1c 到 3c，|M| 变 9 倍
∝ R²泡的表面积泡大一倍，代价四倍
∝ 1/Δ壁越薄越贵（导数 (df/dr)² 发散）想把壁压薄来省能量？代价反涨
这里已经埋下了量子层级的炸弹
经典层只要求「有负能量」，量级还算温和。但一旦把量子不等式（QI）叠加上去，它会反过来 约束壁厚 Δ，而 Δ 又出现在分母上 —— 于是负能量总额被推到天文数字。这正是 §4 的内容。

§2为什么负能量必须长成一个环面

ρ ∝ − (x²+y²)/r² · (df/dr)²

两个因子相乘，形状就被锁死了：

  • (df/dr)² 只在泡壁上非零 → 把密度限制在 r ≈ R 的一层壳里。
  • (x²+y²)/r² = sin²θ 在航向轴（θ=0）上为零、在赤道（θ=π/2）上为 1 → 壳在「两极」被抹掉，只在「腰带」留下。

两者相乘：一层去掉两极的球壳 = 一个环绕航向轴的环面（甜甜圈）。左侧热图里那两个亮斑就是它的横截面。

推论一：飞船在泡心很舒服
泡内 f = 1，度规在泡内是严格平直的闵可夫斯基度规 —— 飞船处于自由落体，感受不到加速度， 也不是「被推着走」，而是泡带着它一起被时空本身搬走。这就是曲速引擎与普通火箭的根本差别。
推论二：航向轴是唯一「免费」的地方
因为因子 sin²θ 的存在，正前方与正后方的轴线上 ρ = 0。这解释了为什么某些改良方案 （Van den Broeck 1999 的「颈口」结构）把负能量搬到更细的环上就能省下数量级。

把上面这句话变成一个能算出数的问题 —— 三个量、一个评分、三个哨兵

上面那段是**定性**的。要判断它对不对、要挑出最优的形状，必须先回答一个可计算的问题： 「把 §7 那条母线做成一层厚 Δ 的壳，它到底接住了多少 §1 要求的负能量？」 三个量都只用本页同一条 ρ 公式（唯一来源在 assets/js/warp-opt.js），无需引入任何新假设：

★ 三件事必须写在明处，否则这个模型会被误读：
① 它不是一个度规求解器。它固定在 Alcubierre 的 ansatz 里（平直区 = r < R、壁在 r ≈ R）， 只问「把负能量摆在哪儿最划算」；换 f(r) 的改良（Natário / Lentz）不在射程内。
② κ 与 v 无关（v² 在分子分母同时出现），只依赖 R/Δ —— 所以寻优只需一个无量纲输入。
③ 壳厚取成 §1 的 Δ（最公平的取法），于是有一条**天花板**：见下面那张卡片。

★ 球壳接住的是 64.3833%，不是 100% —— 这是算出来的、不是估的
(df/dr)² ∝ sech⁴u（u = (r−R)/Δ），而 sech⁴ 的**有效宽度是 4Δ/3**，比壳厚 Δ 还宽。 于是厚度 Δ 的壳只装得进 sech⁴ 峰的中段，覆盖全部立体角的球壳只能接住
κceil = ∫−1/21/2sech⁴u du ⁄ ∫ℝsech⁴u du = (tanh½ − tanh³½/3)·2 ⁄ (4/3) = 0.6438326526
适用边界（数值实测，别把这句话说满）：κceil 是「径向带宽 = Δ、覆盖全部立体角」 这一类形状的上限 —— 球壳达到它，而 R/Δ ≥ 10 时五个候选族没有一个能超过它（本页 κ/κceil 一栏最大就是 1.000）。但 R/Δ ≲ 4 时前提垮掉（§1 的 1/36 定律本来也要求 R/Δ ≥ 6）： 实拍 R/Δ = 2 时超椭球族到 1.027、蛋形族到 1.003 —— 它们用更宽的径向带 把 sech⁴ 的尾巴也啃下来一块。所以准确说法是：κ 本身没有普适上限；有上限的是 Φ = κ/(A/R²) —— 多接住的那些要靠更多材料换，Φ 反而未必更高。
⇒ 想全接住，得把壳做到 ~4Δ 厚，材料代价 4 倍 —— 没有免费午餐。 这一条把 §4 的量子不等式接上了：QI 把 Δ 钉在普朗克尺度，代价就跟着一起致命。 本页 κ/κceil 一栏读作「把球壳那份厚度预算用到了几成」。

    寻优给出的三条结论（含对上面那句论断的修正）

    结论一：不加约束 ⇒ 赤道细带胜出，正是「环面」直觉的极限状态
    自由情况下最优解落到幂律颈族 B = 1、h → 最小，也就是一圈贴在赤道腰带上的细带， Φ 达到球壳的 1.50 倍。这条把 §2 的直觉量化了：单位制造面积上，赤道确实最划算。
    结论二：但只要要求「装得下东西」，球壳立刻反超 —— 而且 Φ 与带宽无关
    细带的围出体积只有球壳的 4.5%（装不了东西），而且 Φ 与带宽无关： 带再细，Φ 都是同一个数（尺度不变）。所以「不约束」时根本不存在唯一最优解 —— 必须钉住 Vin 或 A 才谈得上「最优」。一旦钉住： 等表面积与等体积两种情况的最优解都是球壳（κ 顶到天花板，κ/κceil = 1.000）。
    结论三（对上面那句论断的修正）：负能量不是「只在腰带」，而是「按 sin²θ 加权在整壳体上」
    严格说 ρ 只在轴线上（θ = 0、π）为零，是**一个测度零的集合**；sin²θ 是一条很宽的分布 —— 数值上 90% 的负能量落在离赤道 ±34° 以内（fraction = 1.5·Δθ），但 ±62° 以内仍是肉眼可见的量。 所以正确的说法是：「必须贴在 r ≈ R 的壳层上，赤道最强、两极最弱，但并不为零」； 3D 视图里看到的那个「甜甜圈」是 22% 显示阈值切出来的观感，不是 ρ 的真实支撑集。

    这条修正不动结论（负能量确实向赤道集中，环面确实是最省材料的极限形状）， 但它改掉了「环面」这个说法本身 —— 因为按支撑集讲，那是整张球壳。

    §4四道闸门：为什么 1994 年以来这条路一直没通

    闸门 1：WEC / NEC 被处处违反

    TμνUμUν = −(v²/32π)·[(∂f/∂x)² + (∂f/∂y)²] < 0

    「这个类别的时空里，能量密度没有一处为正」（原文：the energy density for this class of spacetimes is nowhere positive）。

    闸门 2：量子不等式（Pfenning–Ford 1997）把壁厚钉在普朗克尺度

    把 (8) 式代入 QI，得到对采样时间与壁厚的联合约束：

    t₀ ∫ (v²/r²)(df/dr)² dt/(t²+t₀²) ≤ 3/(ρ²t₀⁴)  ⟹  Δ ≤ (3/4)√(3/π) · vb/α²

    取 α = 1/10：

    Δ ≤ 10² · vb · LPlanck   除非 v 极大，壁厚不能高于普朗克尺度

    对应的负能量总额：

    E ≲ −3 × 10²⁰ · Mgalaxy · vb
    这就是那个著名数字的来源
    比可观测宇宙总质量还大约十个数量级。注意：这是量子不等式给出的约束，不是经典爱因斯坦方程的要求 —— 两者差着约 30 个数量级（本页右侧把两层并列显示）。

    闸门 3：光锥 / 视界问题

    泡壁内部的视界使船长无法在泡形成后向前发指令去关闭前壁 —— 那需要超光速信号。这就是「你没法按需启动/刹车」的根源。

    闸门 4：闭合类时曲线（CTC）

    两个泡串联（Krasnikov 管）可构造出闭合类时曲线，即时间机器。这是物理上最被忌讳的副产品。

    年份方案做了什么结果
    1994Alcubierre首次给出超光速泡度规；靠前缩后胀搬运需要处处为负的 WEC 违反能量
    1999Van den Broeck把负能量压缩到细颈上，泡内体积做大总量降到几倍太阳质量量级（经典层）

    2021Lentz构造双曲（soliton）解，声称处处正能量密度，且可由导电等离子体＋经典电磁场供能声称成立；有效争议

    读法
    这条线的走向很清楚：从「能不能超光速」转向「能不能用正能量」。 2021 年 Bobrick–Martire 的分类把「曲速引擎」拆成三类之后，Lentz 式解是否算数才有了可判定的标准； 2024 年 Fuchs 等人给出一支可正质量化的恒速解 —— 这是目前最值得盯的方向。

    §6与 anu / 微观灵视的联系（预留接口）

    曲速泡的负能量环面与 anu 的 10 条「线圈」结构在几何描述层面有可对话之处： 两者都是「一条绕轴的能量流形成闭合拓扑，轴的端点/极点处量值为零」。 这属于结构性类比，不构成物理断言；把它写成可检验命题，需要先给出 anu 的场方程。

    §7anu 最简参数曲线 → 蛋形环面 ↔ 直锥体

    本项目的 anu 几何起点是一条**最简可控参数方程**（本机出处： 01_基础理论/14_anu结构与精细结构常数的关系/DXF生成程序集/anu3d曲线.py）：

    x(t) = −k(c − arctan sin t)·sin(dt) / (cos t + b)   ·   y(t) = −k(c − arctan sin t)·cos(dt) / (cos t + b)   ·   z(t) = a·arctan(1 + cos t) + b

    取 d = 0，则 sin(dt) ≡ 0、cos(dt) ≡ 1，曲线落到 (x = 0) 子午半平面里， 成为一条闭合的蛋形母线；把它绕中轴 z 旋转 360°，就得到本页 3D 视图里那个蛋形环面。 它是有孔的甜甜圈（亏格 1），孔沿航向轴贯通 —— 而航向轴正是 Alcubierre 泡里唯一 ρ = 0 的「免费通道」。

    四个参数各自管什么（实测，不是命名猜测）

    「直锥体」是哪来的 —— 它不是随便找的参照物

    本机 16_schauberger…/DXF生成程序集/01_直锥螺旋管/ 里那份 「最简原始模版用于生成直锥螺旋管」是所有螺旋程序的共同祖先，其母线是 r(t) = R₀ + (R₁−R₀)·t，一条直线；同目录 README_程序族详解.md 写明： 「直锥是蛋形在螺距恒定时退化版」。所以「直锥体」与「蛋形环面」是同一族的两端 —— 母线一个直、一个蛋。这就是本节要做的对照。

    对照的公平约定
    两个对照体共用同一条 z 轴、同一个 +z 朝向、同一个轴向跨度、同一个腰半径（r 最大处）。 于是两条母线唯一的差别只剩：直线 vs 蛋形闭合环。差异全部归因到形状本身。

    泡画在哪：每个对照体各得一个独立的泡

    右侧浮窗 ⑤ 的 泡心 决定「泡」画在谁的哪里。选「各自…」时，蛋形环面与直锥体 各自带一个完整的泡（泡壁半径同为 Rs、共用同一份负能量点云，只是整体平移到该体自己的中心）， 同时主泡收起 —— 否则三个泡在并排视角下两两相交，谁也看不出泡心搬到了哪。两个口径：

    几何原点 = 该对照体自身坐标系的 (0, 0, 0)　·　质心 = 旋转面（薄壳）的形心，在轴上

    两者都换算成同一个归一 ζ，再走唯一那条 Z(ζ) = sc·(ζ·A + zOff)。 默认参数 + 赤道对齐下：原点的泡心在 z = −4.136（两者同高，都落在 ζ = 0 那层）； 质心的泡心在 z = +3.457（蛋形）／ +1.800（直锥）。直锥形心有闭式 h·(底+2·顶)/(3(底+顶))：锥 → h/3，柱 → h/2，与采样密度无关。 图上用小黑点标出泡心位置，不靠读数板口头声明。

    母线对照（归一化：横轴 ρ̃/R，纵轴 z/R，等比例——形状对照不能被拉伸）

    紫晕 = Alcubierre 子午面 |ρ|（灰虚线 = 泡壁 f=0.5）· 红实线 = 蛋形母线 · 橙实线 = 直锥母线

    这张图就是整个对照的要害，三句话读完：

    • 紫晕极其薄、只贴在 ρ̃ = R 那条赤道带上 —— 泡壁越薄（Δ/R 越小）它越像一根头发丝。 所以「负能量环面」在真实参数下是一圈细腰带，不是一个大甜甜圈。
    • 橙线是一条直线（直锥的母线），从底面 (1, 0) 直接收到轴上一点。
    • 红线是闭合的蛋形环：它最宽的地方正好落在 z = 0、ρ̃ = R 那一点上 —— 这不是巧合，是「赤道对齐」按定义摆出来的。
    一句话结论
    直锥与蛋形环面共用轴、共用跨度、共用腰半径，唯一的差别就是母线：直线 vs 闭合环。 直线给出一个没有孔的锥面（顶部是曲率奇点）；闭合环给出一个有贯通孔的环面 —— 而那个孔，正好套在「ρ ≡ 0 的航向轴」上。

    与 PKS「α = 曲率比」命题的关系 —— 一句诚实的结论

    项目里有一条主张（PKS_Millennium_Egg_超双曲锥到射影几何_完整分析.md §4.3）： 电性走线性分支得直锥、磁性走倒数分支得蛋形，而 α = R₀/R_c = 蛋形尖端曲率 / 直锥基准曲率 ≈ 1/137.036。 本页把这条主张当真做了两个检查，结论如下（都可当场复算）：

    检查结果判定
    先问：本页到底"算"出了哪个数？ 只有 rmin/rmax = 0.064042。链条是 (a,b,c) = (3, 2.76, −0.92) → anu 最简母线（唯一来源 AnuRevolve.meridian） → rmax = 0.748573、rmin = 0.047940 → 0.064042。 这就是"自然涌现"的全部含义：由参数经一条公式链落下来的数。 涌现值
    那 0.007297 是怎么来的？ 它不是涌现出来的 —— 它是 1/137.036 这个写在代码里的常数的十进制写法 （CODATA 的 α 目标值）。页面只是把 holeRatio 拿它当分母做除法。 换句话说：这个数可以从本页得到，但只在「先把它当输入」的前提下。 外部目标
    若 R_c 指直锥母线的曲率半径直锥母线是直线 ⇒ κ ≡ 0，曲率半径 ≡ ∞，比值为 0 或未定义定义待补
    取孔/腰半径比 rmin/rmax 当 α，用默认参数0.064042，与 1/137.036 = 0.007297 差 8.8 倍不符
    这个比值能不能被调到 1/137.036？能。单独动 b：b* = 1.0605（c = −0.92 固定）
    单独动 c：c* = −0.79930（b = 2.76 固定）    		可调量
    灵敏度Δc = 10⁻³ ⇒ 比值变 ±7.1%；要钉在 1% 内，c 需准到 ~10⁻⁵
    ★ 那项目里 α 的另一条路线呢？
    （舒伯格公式 — 导读.md §五：α⁻¹ ≈ 20φ⁴）    		 φ = (1+√5)/2 = 1.618033989 ⇒ 20φ⁴ = 137.082039， 与 CODATA 的 α⁻¹ = 137.035999 相对偏差 +0.0336%（纯 φ 算出来的，没有自由参数）。 反向看：若把 20φ⁴ 当成定义，则 (α⁻¹/20)^¼ = 1.617898 vs φ = 1.618034，差 1.36×10⁻⁴。
    复算脚本 _check/_syn/probe_alpha.js（连同下面那条 rmin/rmax 路线一起打）    		 数值成立
    所以：现在这条 α 命题还不是「预测」，而是「可调量」—— 但项目里另有一条是「数值成立」的
    rmin/rmax 在本参数族里由 (b, c) 两个自由参数连续控制，范围是从 0 到 0.0789， 1/137.036 落在可达区间内部 —— 想让它等于 α，只需把 b 或 c 拧到上面那两个值。 要把 α 变成可证伪的预言，必须先有一条独立确定 b 或 c 的方程（例如把 b 与 1/b 的 ab = 1 极化原理写成对参数本身的约束），否则「算出了 1/137」只是一个巧合级别的吻合。

    ★ 区别在这里：rmin/rmax 那条路要把参数拧过去才等于 α（可调量）； 而 20φ⁴ = 137.0820 这条**一个自由参数都没有** —— φ 是黄金比、(20, 4) 是公式里数出来的，值与 CODATA 的 α⁻¹ 差 0.0336%。 这才是本项目里唯一具备「涌现」资格的 α 路线（出处 舒伯格公式 — 导读.md §五）。 不过它是否算导出，仍取决于「20」和「4」的来历能否独立说明 —— 本页只负责把数值复算出来， 并对两条路线给出不同的判定，不替它们下物理结论。

    本条只陈述可以从代码/闭式复算的事实，不对 α 的物理来源下结论。
