把「时间梯度 = 引力主项」接进双曲锥 / 陀螺拓扑框架

页面 ① 的模型 5 已给出结论：慢速物体感受到的引力，几乎全部来自 gtt 的梯度。 这一页把它推到几何层：先用一个可当场验算的恒等式把「时间慢」与「空间流」焊死， 再把它接到双曲锥（等距嵌入）与陀螺拓扑互锁（涡线联数）两个框架上，最后给出三条写清了交付物的接口。

L0 恒等式 → L1 从 gtt 到力 → L2 双曲锥 → L3 陀螺互锁 → L4 三条可检验接口

§0起点：一个要当场验算的恒等式

Gullstrand–Painlevé 坐标（页面 ① 模型 4）与 Schwarzschild 静态坐标（模型 5）描述同一个几何，只是时间切片不同。 把两者分量对齐：

ds²GP = −(1−β²)dt² + 2β dt dr + dr² + r²dΩ²，  β(r) = √(rs/r) 河流模型
ds²Sch = −(1 − rs/r)dt² + dr²/(1 − rs/r) + r²dΩ² 时钟速率场

两者共用同一个 gtt = −(1 − rs/r)。于是立刻得到本页最重要的东西：

CORE IDENTITY
(dτ/dt)²  +  β²  =  1
(dτ/dt)² = −gtt = 1 − rs/r   ·   β² = 1 + gtt = rs/r

「时间慢」与「空间在流动」不是两件事，它们是同一个单位圆的余弦与正弦。 视界处 (dτ/dt)² = 0 同时就是 β² = 1 ——「钟停」与「流速达光速」是同一句话的两种说法。 右侧两条分量条会实时保持平方和为 1（这条恒等式可以当场验算）。

为什么这一条足以支撑整个 PKS 接口
只画「空间弯曲」的图（①的模型 1、2）只显示了这条恒等式的一半； 只谈「时间慢」的图（模型 5）也没说明另一半为什么等价于流速。 有了 (dτ/dt)² + β² = 1，就能把「时间梯度」翻译成「场」，从而与任何以场 / 流语言写成的模型对话 —— 这是双曲锥（流道）与陀螺互锁（涡线）能被接进来的唯一入口。

§1L1：从 gtt 到力 —— 只有一项活下来

弱场静态极限 ds² = −c²(1 + 2Φ/c²)dt² + (1 − 2Φ/c²)dx⃗²。把测地线方程在慢速极限展开，含 v/c 的项全被压掉：

Γⁱtt ≈ (1/c²)·∂ⁱΦ  ⟹  d²xⁱ/dt² = −∂ⁱΦ  ⟹  g⃗ = −∇Φ

而 Φ = −(c²/2)(1 − (dτ/dt)²)：牛顿的力就是时间梯度的负号。 关键点在于——力可以从一个标量场 Φ 导出。只要目标模型也能给出一个标量场， 两者就可以在同一张纸上比较，而不必先争论「空间弯曲还是时间弯曲」。

§2L2：双曲锥 —— 等距嵌入的第三条路

Flamm 抛物面（页面 ① 模型 2）是把 t = const 空间切片等距嵌入平直三维空间的唯一旋转面解，剖面是抛物线。 工程与传统文献里被反复提起的「双曲锥 / 蛋形 / 内爆漏斗」则是另一族剖面：

曲面剖面方程喉部行为出处 / 用途
Flamm 抛物面z = 2√(rs(r − rs))z ∝ √(r−rs)：垂直切进喉部Flamm 1916；Schwarzschild 空间切片的等距嵌入唯一解
双曲漏斗（单叶双曲面）ρ̃ = a·√(1 + (z/c)²)ρ̃ → a：有最小半径Schauberger 内爆漏斗；流体聚流 / 涡管成型
锥面ρ̃ = k·|z|退化为一点（尖顶）双曲面的渐近锥
必须说清楚的一步
形状相似 ≠ 物理等价。 Flamm 抛物面是「爱因斯坦方程某个解的空间切片」； 双曲漏斗目前只是「被工程实践证明好用的流道形状」。要把两者接起来， 必须写出双曲漏斗对应的 gtt(z)，再检查它是否满足场方程 —— 这就是 §4 接口 ① 的交付物。

但有一个真正可做的动作：把时间梯度「画」到双曲锥上

给定沿轴的势 Φ(z)，钟速 τ̇ = √(1 + 2Φ/c²) 在锥面上生成一族等值线。 由 §0 的恒等式，这族等值线同时就是流速等值线。于是「双曲锥里流体为什么加速」有了一个候选的几何解释： 流体沿时间梯度最陡的方向走。下方 3D 的第一个模式就是这样画的 —— 锥面按 τ̇ 着色，流线沿最陡下降方向螺旋下行，颜色越红表示钟越慢。

§3L3：陀螺拓扑互锁 —— 涡线才是那个不变量

页面 ① 的模型 6 把曲率拆成潮汐场 E（拉伸/挤压）与参考系拖曳场 B（扭转）。 真正能在拓扑上「锁住」结构的是后者：B 的积分曲线（vortex lines）是闭合或螺旋的流管， 流管之间的联数（linking number）是整数型拓扑不变量。

一个可直接引用的结论（Nichols et al. 2012，稳态黑洞）
  • 慢转黑洞：方位角方向的涡线是闭合的。快转黑洞：涡线不再闭合，而是向外螺旋。
  • 无论快慢，都存在两个涡区：一个逆时针涡从北极区升起，一个顺时针涡从南极区升起。
  • 涡线可以接到视界上（在正标量曲率处）。
出处：Nichols et al. 2012，“Visualizing spacetime curvature via frame-drag vortexes and tidal tendexes II: Stationary black holes”，03_时空可视化与嵌入/

「南北极各出一个反向涡」正是「陀螺拓扑互锁」在 GR 侧最接近的实物： 两个手性相反、彼此穿插的闭合流管。它们之间只有两种可能 —— 联数为 0（可分开）或联数 ≠ 0（锁住）。 磁通管、涡管、超流体量子涡旋都用这套语言；把它移到引力侧，就是把 vortex line 当成客观的、可计数的几何对象。

本页 3D 的「陀螺互锁」模式画的是什么
三个两两相扣、互相垂直的环（任意两环之间联数 = 1，即 Hopf 链），每环绕自身轴自旋。 措辞要准：这不是 Borromean 环（三环中任意两环都能分开的那一种），而是两两相扣。 另设「Kerr 双反向涡管」模式，画南北极反向上升的两个螺旋涡管。

⚠ 边界声明（请保留）
以上三条都是结构性类比的候选接口，不是已成立的物理等价。 任何一条要落地，都必须先写出对应的度规或场方程，并给出可与标准 GR 区分的可观测差异。 在写出方程之前，它们属于「值得试的路线」，不属于「结论」。
