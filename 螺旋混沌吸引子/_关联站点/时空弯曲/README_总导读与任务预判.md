## 一、本目录要解决什么问题

老师发来的两个元宝链接，核心是同一个问题：

> **「时空弯曲」到底该怎么画？为什么有人画橡胶膜、有人画线框网格、有人画河流？这些图哪张是真的？**

元宝给的答案方向是对的（"没一张图画全，关键看你要解释什么"），但它把**出处、编号、原文用词**都糊掉了。本目录做四件事：

1. **把它们提到的论文全部下载落地**（不再只是文字里的 `arxiv.org/abs/...`）
2. **把每张图的数学载体写清楚**（度规 / 联络 / 曲率张量，具体到哪一项在起作用）
3. **把元宝说错的地方标出来**（例如把 Braeck & Grøn 的论文记成 Hamilton & Lisle）
4. **核对库内原文**（`ligo tube` vs `Fohat` —— 已用精确词检索证伪）

| 控件 | 取值 | 说明 |
|---|---|---|
| 摆法 | `环上公转` / `弹簧线圈` | 环＝平面 y=0 上 n 个球，半径 R；弹簧＝`(x,y,z)=(R cos t, R sin t, kRt)`，t ∈ [−Tπ, Tπ] |

> **k 为什么是「算出来」的，不是挑出来的**：两类邻居 —— 同匝相邻（左右，弦 = 2R sin(π/n)，
> 还带一个 z 台阶）与相邻匝同相位（上下，纯竖直 = 螺距 P = 2πkR）。要求「上下/左右等距」就是解
> `sin²(π/n) = π²k²(n²−1)/n²`，`d左右² − d上下²` 对 k **单调递减** ⇒ 根唯一。面板上的「间距均匀度」＝ dUp/dSame。
> **n = 1 时这个条件退化**（只剩「上下」一类，任何 k 都均匀）⇒ k 是**自由参数**，由「装得下 + 不重叠」涌现
> （实测 k ≈ 0.050，「每匝 1 球」= 竖直一列）。⚠️ 旧版在模块里硬写 `if (n<=1) k=0`，
> 把 k 打死之后页面只好再补一条「perTurn ≤ 1 就强制 1 匝」——**补丁盖症状，根因没动**，两条已删。
> `T = 1` 时不存在「上下」邻居（`dUp = NaN`，不是 0）；`M = 1` 时 `dmin = Infinity`（不是 0）。

### 泡心：每个对照体各一个独立的泡（2026-10-11 加）

#### 出画救援：极端参数下不许把内容甩出画布（2026-10-11 同批）

`_shot_egg.js` 把「可见内容投影到屏幕」后量到：直锥自由参数拉到「底 2.0×腰 / 高 1.4×Δz」时，
**下沿溢出 −53 px**。规则（`fitCameraIfCropped()`，只在 ⑤ 对照体可见时管）：

- 判据用**余量**，不用「是否 rebuild」——余量为正就**一律不碰相机**。
  这是为了两件事：① 主泡随 (v, R, Δ) 长大是页面既有表达，一律自动取景会把它压平；
  ② 「各自·质心 / 各自·几何原点 / 不画」三张图必须同比例才能对照。
- 用户一旦自己拖过 / 滚过相机（`controls` 的 `start` 事件），**自动取景立即交还用户**，
  哪怕内容已被裁；点「⌖ 框住对照体」或切布局时才交回自动。
  断言里为此配了一条**反证**（相机 102.2 → 164.9，余量 −115 → +69），免得「让路」这条断言空洞地绿。

> ⚠️ **两轴的尺必须一样**（`_check/egg_test.js` 盯着这条）：
> 母线对照图的横轴单位是蛋形腰半径（＝泡半径 R），纵轴**也必须是 R**，不能再拿 ζ 当纵轴。
> 换算系数 `A = Δz/腰半径 ≈ 1.2325`。忘了乘 A，图就被各向异性拉伸 ——
> 图上量出 90° 的锥，表里却写着 **78.11°**，两者互相打脸。
> 现在断言直接量母线在图上的像素斜率，要求它等于 `(底−顶)/(高·A)`，与表中的全顶角同源。

### §2-2 形状寻优：自动搜最大推力（2026-10-12 加）

§2 原来只把「负能量为什么必须长成环面」讲成定性论证。现在补上**可复算的自动寻优**：
在 Alcubierre 的解答内（**不是解度规**，这点页面上写明了），拿页面自己那条 ρ 去扫形状。

**评分**：`Φ = κ/(A/R²)`，其中 `κ = E_shell/E_need`（壳真正接住的负能量占所需的比例）、
`A` = 壳侧面积、`V_in` = 围出体积（Pappus）。五族母线：球壳 / 单锥 / 超椭球 / 幂律颈（Van den Broeck 式）/ 蛋形。
**约束三档**：等表面积（A = 4πR²）、等体积（V = 4πR³/3）、自由。

**关键结论**（R/Δ = 100，v = 1，球壳基线 Φ = 0.051232）：

| 约束 | 冠军 | 蛋形最优 a/b/c | 蛋形 Φ / 球壳 | 蛋形 ζ → 世界心 |
|------|------|------|------|------|
| 等表面积 A = 4πR² | 球壳（超椭球自己搜到 p = q = 2，就是球壳） | 0.858 / 3.100 / −1.038 | 0.371 | 0.4368 → (−21.67, 0, 1.02) |
| 等体积 V = 4πR³/3 | 球壳（同上） | 0.832 / 3.100 / −0.663 | 0.374 | 0.4416 → (−21.67, 0, 0.95) |
| 自由（不限） | **幂律颈 B = 1, h = 0.03**（赤道细带）Φ = 0.076783 = **1.4987 × 球壳** | 0.800 / 2.850 / −0.850 | 0.424 | 0.4254 → (−21.67, 0, 0.90) |

1. **κ 天花板 0.6438326526**（不是 1）——球壳只接住 `sech⁴u` 有效宽度 4Δ/3 里的那一段。
   原先三处写成 **0.6438530**（数字换位），已按闭式 `(tanh½ − tanh³½/3)·2/(4/3)` 与独立高精度积分改正。

   R/Δ ≥ 10 时五族无人越顶；**R/Δ = 2 时超椭球到 fill = 1.027、蛋形 1.003**（用更宽的径向带啃 sech⁴ 尾巴）。

## 七、一句话总结

> **时空弯曲不是「一张图」，是「一条从度规到观察者的投影链」。**
> 换观察者，图就换；换要解释的现象，载体就换。
> 本目录把这条链的每一环都落了地——**图有出处，公式有编号，术语有原文**。

> **夸克与 anu 的关系同理，不是「相等」而是三层叠加**：
> 原观测者只报形状与计数（第一层）；Phillips 给出可逐项核对的身份断言（第二层）；
> 代入 φ = +5/9、π = −4/9 后，**3-omegon 的 4 种组合中只有 2 种给出标准模型夸克电荷，且恰好是 u 与 d**（第三层，可现场验算）。
> 但界面到此为止——**形态学与度规之间没有可换算的通道，磁单极至今未被实验发现**。
