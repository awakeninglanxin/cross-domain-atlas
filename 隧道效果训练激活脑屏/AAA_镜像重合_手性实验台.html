实验台：轴 / 模式 / 权重

三个旋钮的组合就是元宝那版的全部功能。区别只在：这里的画面是当场算的，权重连续可调。

镜像重合层 y 轴 · 重合 · w=0.50
w=0 原图 ／ w=0.5 完全重合 ／ w=1 取镜像　·　也可把图片直接拖到画布上

三个模式的差别：重合是线性插值 (1−w)·原 + w·镜像，w=0.5 即两者等权平均； 增亮是 screen 混合 原 + w·(255−原)·镜像/255，暗处提亮、亮处趋于饱和（所以偏过曝）； 残差 ×6 是 |原 − 镜像| × 6，把被抹掉的那点旋纹放大到看得见，此模式下 w 不参与。

④

为什么是「几乎没变」而不是「完全没变」

一张图关于竖直中轴的自反程度，可以写成一个可算的比值。设镜像映射为 m(x) = W−1−x：

ρ(轴) = mean| I(x,y) − I(m(x),y) | / mean I ← 本页用「/255 与 /平均亮度」两种口径

若 ρ = 0，图关于该轴严格对称，镜像重合毫无信息。实测本页底图：y 轴 7.61%、x 轴 11.08%， 上下比左右更不对称 1.45 倍；换成元宝那张底图，同样的运算给出 3.9% 与 25.4%（6.5 倍）。 两处方向一致、幅度不同——幅度属于底图，方向属于变换。

而重合之后必然严格自反，这是恒等式而非物理性质：

out(x) = ½(I(x) + I(W−1−x)) ⇒ out(x) ≡ out(W−1−x)

本页把这条恒等式当成自检跑：对重合结果逐像素验 max|out(x) − out(W−1−x)|， 应当为 0（若底图宽为偶数，中缝落在两列之间，则 172/173 两列逐行严格相等）。① 里第 5、6 行就是它。

反过来，若把这条恒等式读成「所以这张图有某种对称性」，就错了——它只说明平均运算的作用， 对图像本身没有任何断言。这也是下面那条诚实线的起点。

⑤

接到拉马努金：镜像 ≠ 模变换

这一节是给「应用地图」⑤ 那段收口的：像素镜像看起来像 τ → −1/τ，其实不是同一个东西。

把图画在半平面上的复坐标当成 τ。那么两种「翻」在数学上是不同类型：

操作在 τ 上是什么性质对 j(τ) 的作用
像素镜像（左右）τ → τ̄反全纯（anti-holomorphic）j(τ̄) = conj j(τ)，值一般变
B 按钮 / 模群 Sτ → −1/τ全纯（holomorphic）j(−1/τ) = j(τ)，值不变
T 变换τ → τ+1全纯j(τ+1) = j(τ)，值不变

j 的 q-级数系数是整数，所以 j(τ̄) = conj j(τ) 是可当场验的恒等式。下面是本页实算（不是查表）：

共轭对称自检 · j(τ̄) = conj j(τ) 取 τ 与 τ̄ 各算一遍 q 级数，比实部与虚部
这条差别正好说明「为什么会看错」 镜像重合抹掉的是手性，模群 S 变换抹掉的是标度；前者是反全纯反射，后者是全纯分式变换。 两者在画面上都表现为「翻过来看着差不多」，但一个改变 j 的值（只把虚部取负），另一个让 j 纹丝不动。 画面相似 ≠ 变换同类——这正是 ⑤ 里「数得清门，不等于造得出门」的同一条毛病。
⑥

诚实话：这一页什么都没证明

三条界限 一、自反误差 0 是恒等式，不是物理不变性。它只说明「平均之后必然对称」，跟这张图原来有没有对称性、 跟任何守恒律都无关。把它当成「发现了对称性」就是拿算术冒充物理。
二、残差读数只是这张图的性质。本页两张底图给出 7.61%/11.08% 与 3.9%/25.4% 两组数，差别一倍多—— 换帧、换尺寸、换压缩等级，数都会变；它不能被引用成「莫比乌斯图的手性下界」。 底图是本地 GIF 的一帧、JPEG 有损压缩过，压缩噪声会混进残差里——所以本页的数是这张底图在这个压缩等级下的数。
三、镜像重合动不了任何物理读数。它改的是像素，不改 ds²、不改 b′(r₀) < 1、 不改 ρ+p_r = −1/(4πa²)、不改 ANEC 违反。视觉上的「更柔更正」不是证据，只是观看条件。
