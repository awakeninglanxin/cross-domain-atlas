数学链（三层同源）
① 视皮层映射：视网膜 (r, θ) → V1 的 Schwartz 复对数近似 x = ln r, y = θ；远场密度 ∝ 1/r² 使复对数成为唯一保密度共形映射。 皮层上的平行条纹经逆映射即为 Klüver 形式常量中的隧道 / 漏斗 / 螺旋（Ermentrout–Cowan 1979；Bressloff, Cowan, Golubitsky, Thomas & Wiener 2002）。
② 工程实现：隧道深度 z = 1/r + t·speed（透视消失点）；Droste 剪切 θ′ = θ + twist·ln r 把直条纹卷成螺旋； 颜色用 Iñigo Quílez 余弦调色板 c = a + b·cos(2π(c·t + d))。
③ 本地整合：对数螺旋 r = a·e^{kθ} ⇔ ln r = ln a + kθ，在 log-polar 里是斜率 k 的直线 —— 因此 DDD 的「螺旋扩张 k」与 shader 的 twist 是同一坐标变换的两个旋钮。
④ 镜像 / 双向 / 缝方向：水平镜像即 θ → π−θ，手性反转而 ln r 不变 —— 颜色相位 ct 只依赖 z、ln r 与 sin θ，故两屏天然同色；分屏右屏直接对 uv.x 取负做几何镜像， 不再用「旋向反号」代替镜像（旧做法会把颜色相位也反号，造成一紫一红）。 反向影像层取 a2B = (π−θ) + twist·ln r − spin·t，与原层各算一次图案场后混合或取亮， 即顺、逆时针同时叠加的编织纹。GLSL atan(y,x) 的 ±π 分支切割默认落在 −x（屏幕左）， 把输入坐标旋转 −(β−π) 后分支即落到方位角 β，默认 β = π/2（屏幕正上方）。

结论（必须说清）：原片没有几何隧道。整段是同一个 AI 生成母题 —— 闭眼人面线描、 眉心一处小螺旋（第三眼）—— 叠加强烈的径向缩放拉丝（zoom blur），人眼把放射条读成「隧道壁」， 中心暗核读成「隧道尽头」，「涟漪」实为拉丝的疏密与色相漂移。因此把几何环数调多调少都不会更像原片。
量化靶子：主色玫瑰 #ED9ACE／品红 #BF4EA4／薰衣草 #AD96B8／ 长春花蓝 #8FA8E8／珊瑚 #E89988，色相集中在 260–355°； 径向亮度 0.42–0.69 属高调且到边缘不压黑（故本样式自动关掉渐晕）； 角向分布为顶光：60–120° 近白 (0.97,0.93,0.98)，180–240° 暗紫红 (0.54,0.24,0.46)，300–330° 偏蓝 (0.34,0.40,0.64)。
实现：style 三档（几何 / 光云·粉紫 / 光云·素白）；rayField 用 3 组整数角系数 cos(a2·arms·k + lnr·m − t·v) 造长短不一的径向拉丝（整数系数保证 atan 分支处无缝）； biliPal 按上式实测色带插值；亮度 = 0.36 + 0.40·顶光 + 0.20·拉丝 + 0.13·云 + 0.10·几何， 再扣中心暗核与左下暗紫；最后叠颗粒噪点。原片的人面线描不复制（那是作品题材，不是光效）。

三视频特效 · 可验证算法链（本地 mp4 逐帧真看 + 外网公式）
① 地包天圆环：demoscene 3D tunnel 的极坐标查找表 depth = R / r（即 1/z 透视消失点）生成同心环带； 球面折射把中心区 uv.y 按 exp(−1.3r) 权重翻转，得到「下半过曝、上半暗」的地包天构图； 上方亮弧用高斯环带 exp(−((r−r₀)·k)²)，中心花心用 cos(N·θ) 瓣； 红蓝金散边是 R/G/B 三通道分别按 uv·(1±ca) 采样（径向色差）。
② 黄金比螺旋分形结构：Shadertoy 社区相位场 v = ln(l)/(4·ln φ) − a/2π（l=|U|，a=−atan(U.x,U.y)）， 等值线 abs(fract(v)−0.5) 即每转 90° 半径 ×φ = 1.618 的对数螺旋； 本页再用 TRS 递归（每层缩放 φⁱ、旋转 i·90°，3 层叠加）做离散自相似， 用 Vogel 叶序 θ = n·π(3−√5) = 137.507°、r = c√n 的 Fibonacci 分室近似外壳放射分格； 整数角系数保证 atan 分支处无可见缝。
③ 黄金涟漪：sin(d·k − t) 同心等值环；Rocaille 式 domain warping （p += a·sin(p.yx·k + t) 两级）把环带扭成熔金流纹； 3×3 波源按 sin(d·10 − t·5)·exp(−2.2d) 叠加（Vanta RIPPLE / Godot caustics 的结构）， 再用 3 阶值噪声的 sin((px+py)·5 + n·7 − t) 高次幂做细密焦散高光。 调参备注：初版两级 warp 取 0.42 / 0.18 时同心环被扯成火焰漩涡，逐张实拍后降到 0.22 / 0.08 并把环频 9 → 15、环权重 0.34 → 0.46，才恢复素材里可数的 3–4 圈低频同心环。
⚠ 口径：三个 mp4 是本地素材，只做了逐帧抽图与视觉结构归纳，没有原工程文件； 上列公式是可独立查证的开源 / 文献算法，用来复现同类结构，不等于原视频的精确实现； 「地包天」「门罗式」均为结构近似。

音频数学链（双耳节拍 / 门罗技术与后续研究）
① 现象与边界：Dove 1839 发现、Oster 1973《Auditory Beats in the Brain》(Sci. Am.) 使之成为研究工具。 左耳 fL、右耳 fR ⇒ 脑内感知 |fL−fR| 的拍音；空气里并不存在该频率， 故必须耳机。Licklider 等 1950 给出边界：载波明显低于 1000 Hz（400 Hz 以下更好，3 kHz 以上 ASSR 基本测不到）、 拍频约 1–35 Hz。神经通路：上橄榄复合体（第一个双侧汇聚核团）→ 下丘 → 内侧膝状体 → 听皮层， EEG 上表现为 ASSR / FFR。
② 门罗 Hemi-Sync：Robert Monroe 1975 起注册专利，把「两耳整合」解释为 hemispheric synchronization。 关键不是单一拍频，而是 complex layered combinations of binaural beats and other sound signals （官网原文）：多对载波/拍频叠加 + 粉红噪声 + 引导语，按 Focus 10/12/15/21… 层级编排。 后续 Monroe Sound Science (MSS) 官网明确说包含「binaural beats plus many other types of sound technology (i.e. phase modulation)」，目标是 Focus 间更平滑的过渡、克服双耳节拍难以夹带 Gamma 的局限， 并加入「随练习时长动态变化的时间维度」；具体技术参数保密。 故本页只做「多层叠加 + 相位调制 + 扫描」的结构性近似，Focus 预设均为社区推测，不是官方配方。
③ 开源算法：SBaGen 的 tone-set carrier±beat/2 / amp（振幅 0–100 且总和 ≤100）、 pink/amp、spin:<µs>:<beat>/<amp> 左右反向延迟粉噪、-> 整段渐变； Wundark 用 左 f / 右 f+Δf 并在时间轴相邻点线性插值； Gnaural 用独立左右频率 + 分段 session + 淡入淡出；brain-beats 把噪声按 ±6 dB/octave 分成 13 色、 单耳=先相加、等时=脉冲 AM。本页把两套频率约定、四种合成、6 色噪声、AM/PM 都做成可对照的旋钮。
④ 证据边界（必须如实说）：Ingendoh / Posny / Heine 2023（PLOS ONE）系统综述 14 项 EEG 研究， 5 项支持夹带、8 项矛盾、1 项混合，异质性过大无法定量合并；且所有把节拍嵌入粉红噪声的研究都报告无夹带。 Garcia-Argibay 2019 荟萃分析（22 研究 / 35 效应量）行为层面 Hedges' g ≈ 0.45，「任务前听」优于「任务中听」； Orozco Perez 2020（eNeuro）发现单耳拍夹带更强、双耳拍产生独有跨频/跨半球连接模式； Gao 2014 未测到夹带但测到脑区间相位锁定值变化 —— 即门罗可能「结论对、机制错」。 2025 年一项约千人居家研究反而发现通用双耳节拍降低复杂学习任务成绩。

① 管壁明暗：从管内看，内壁法线 N = (−cosθ, −sinθ, 0)，与光源方向做 max(dot(N,L),0) 即 Lambert 漫反射 —— 一侧亮一侧暗，这是圆柱体积感的主因；再叠环脊 sin(z·rings·0.3 + 2θ) 扰动法线做出凹凸。
② 大气透视：exp(−z·0.026·fog) 让远端（r→0，z 大）退入雾色，符合真实空气散射的纵深规律。
③ 管壁半径起伏：把深度场写成 z = z₀ + 0.42·sin(3θ+z₀·0.55) + 0.24·sin(6.5θ−z₀·0.8)， 隧道壁不再是完美旋转面，接近岩洞 / 血管的有机形态。
④ 透视视差：真实相机横移时，屏幕位移 ∝ 1/深度，故写成 uv += drift·(0.20+0.80·r) —— 近端动得多、远端几乎不动。默认关闭，因为它会让画面中心轻微游移；需要手持感时再开。

眼镜格式说明（照实写，不夸大）
· 红青 / 红蓝：标准 anaglyph，左眼取 +sep、右眼取 −sep 两套视角，按 R / GB 通道合成。 gSat 在「纯亮度立体（重影最小）→ 全彩立体（色彩最好）」之间连续插值； gGhost 按 crosstalk 反向扣除红镜漏的绿蓝、青镜漏的红。淘宝几块钱的红青眼镜即可观看。
· 偏光四格式：网页无法自己产生偏振光。这里生成的是偏振三维系统所需的视图排布格式 —— 隔行（行交错偏振显示器）、左右 / 上下压缩（双投影 + 偏振片，或 VR 盒）、棋盘（DLP Link）。 必须配合对应的偏振硬件与偏振眼镜才有效果；在普通屏幕上，隔行/棋盘会表现为细横纹或格子，这是正常现象，不是 bug。
· 性能：红青 / 红蓝要算两遍场景，帧率约降一半；偏光四格式每像素只算一遍，性能与裸眼相同。
· Canvas2D 降级模式下眼镜功能不可用（需逐像素双采样，2D 后端不实现）。
· 三档引擎自动降级：① WebGL · GLSL 完整着色器 → ② WebGL · 精简 （完整版在你机器的驱动 / ANGLE 上编译不过时自动换成这一档，仍是真 WebGL 实时动画） → ③ Canvas2D 降级（浏览器完全拿不到 WebGL 时才用，画面是简化同构版）。 顶部状态条里的「引擎」显示当前档位，鼠标悬停可看到具体失败原因，便于排查。 三档共用同一套参数与预设，切档不丢设置。
